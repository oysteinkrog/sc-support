So richten Sie eine statische IP auf FLIR Blackfly GigE-Kameras ein

Einführung

Dieser Support-Artikel beschreibt, wie Sie Ihre Blackfly (oder Blackfly S) GigE-Kameras mit einer statischen IP-Adresse konfigurieren. Für den normalen Betrieb ist dies nicht erforderlich, da SwingCatalyst die IP-Konfiguration automatisch übernimmt.

Voraussetzungen

  • Die SpinView-Anwendung (Teil des Spinnaker SDK).

  • SwingCatalyst.

  • Eine oder mehrere FLIR Blackfly (oder Blackfly S) GigE-Kamera(s).

Spinnaker installieren

  • Laden Sie den Spinnaker-Installer herunter und führen Sie ihn aus.

  • Klicken Sie mit der rechten Maustaste auf den Spinnaker-Installer und führen Sie ihn als Administrator aus.

  • Aktivieren Sie „Camera Evaluation" und klicken Sie auf „Weiter".

  • Folgen Sie den Anweisungen auf dem Bildschirm, um die Installation fortzuführen.

  • Starten Sie den Computer nach Abschluss der Installation neu.

Statische IP am Ethernet-Adapter einrichten

Jede Kamera und jeder Netzwerkadapter muss eine eigene eindeutige statische IP-Adresse haben. Wenn Sie beispielsweise einer Kamera eine statische IP-Adresse zuweisen, stellen Sie sicher, dass der Netzwerkadapter mit einer entsprechenden IP aus der unten stehenden Matrix „Empfohlene statische IP-Konfiguration" konfiguriert ist.

Warnung

Konfigurieren Sie Netzwerkadapter anhand der zugehörigen Kamera, nicht anhand der Adapternummer. Ändern Sie die Einstellungen nur für identifizierte Kameras; lassen Sie alle anderen unverändert. Wenn Sie eine Kamera an einen anderen Adapter anschließen, ist eine Neukonfiguration für die ordnungsgemäße Funktion erforderlich.

Gehen Sie in der Systemsteuerung zu „Netzwerk und Internet", dann zu „Netzwerk- und Freigabecenter" und klicken Sie auf „Adaptereinstellungen ändern".

Hier sehen wir eine Liste der auf dem Computer vorhandenen Netzwerkadapter. In unserem Fall möchten wir „Ethernet 2" und „Ethernet 3" mit dem Gerätenamen „Intel Pro/1000" konfigurieren. Es ist wichtig, dass wir nur die für die Kameras verwendeten Netzwerkadapter konfigurieren und keine anderen, da dies die Internetverbindung beeinträchtigen kann.

Klicken Sie mit der rechten Maustaste auf den Netzwerkadapter, den Sie ändern möchten, und klicken Sie auf „Eigenschaften". Scrollen Sie dann nach unten zu „Internetprotokoll Version 4 (TCP/IPv4)" und klicken Sie auf „Eigenschaften".

  • Wählen Sie „Folgende IP-Adresse verwenden".

  • Geben Sie eine IP-Adresse aus der unten stehenden Matrix für die empfohlene statische IP-Konfiguration ein.

  • Geben Sie die Subnetzmaske 255.255.255.0 ein.

  • Wählen Sie „Folgende DNS-Serveradressen verwenden" – diese können leer gelassen werden.

  • Klicken Sie auf „OK".

Empfohlene statische IP-Konfiguration

Ethernet-Adapternummer IP des Ethernet-Adapters Subnetzmaske Gateway Verbunden mit Kamera Kamera-IP
1 10.0.1.1 255.255.255.0 10.0.1.1 1 10.0.1.10
2 10.0.2.1 255.255.255.0 10.0.2.1 2 10.0.2.10
3 10.0.3.1 255.255.255.0 10.0.3.1 3 10.0.3.10
4 10.0.4.1 255.255.255.0 10.0.4.1 4 10.0.4.10

Das Gateway kann auch an der Kamera eingestellt werden.

Statische IP an der Kamera einrichten

Wiederholen Sie diese Schritte für alle weiteren Kameras, für die Sie eine statische IP festlegen möchten. Um auf die Kamera-IP-Konfiguration zuzugreifen, öffnen Sie die SpinView-Anwendung und klicken Sie mit der rechten Maustaste auf die Kamera, die Sie konfigurieren möchten.

  • Klicken Sie mit der rechten Maustaste auf die Kamera in der Geräteliste und wählen Sie „GigE Configuration".

  • Klicken Sie auf „IP Configuration".

Geben Sie die IP und die Subnetzmaske gemäß der unten stehenden empfohlenen IP-Konfigurationsmatrix ein.

  • Geben Sie die IP-Adresse der Kamera ein; verwenden Sie die IP-Adresse aus der Matrix, z. B. für Kamera 1.

  • Geben Sie die Subnetzmaske ein, z. B.: 255.255.255.0.

  • Das Standard-Gateway kann leer bleiben oder Sie verwenden die IP-Adresse des Netzwerkadapters, mit dem die Kamera verbunden ist.

  • Deaktivieren Sie DHCP.

  • Klicken Sie auf „Set Current and Persistent IP Configuration".

Empfohlene statische IP-Konfiguration für Kameras

Kamera-Nr. IP Subnetzmaske Gateway
1 10.0.1.10 255.255.255.0 10.0.1.1
2 10.0.2.10 255.255.255.0 10.0.2.1
3 10.0.3.10 255.255.255.0 10.0.3.1
4 10.0.4.10 255.255.255.0 10.0.4.1

Die Gateway-IP ist die IP-Adresse des Netzwerkadapters, mit dem die Kamera verbunden ist.

Beispielsweise ist Kamera 1 mit Netzwerkadapter 1 verbunden.

SpinView verwenden, um Jumbo Frames zu aktivieren und die Netzwerkadapter für die Kameras zu optimieren

Bitte beachten Sie, dass diese Änderungen an allen Netzwerkadaptern vorgenommen werden müssen, die mit Ihren Kameras verbunden sind.

  • Klicken Sie in SpinView mit der rechten Maustaste auf die Kamera und wählen Sie „GigE Configuration".

  • Klicken Sie auf „Configure Adapter Properties".

  • Klicken Sie auf „Ja", wenn Sie dazu aufgefordert werden.

  • Klicken Sie auf „Weiter".

  • Klicken Sie auf „Auto Fill All".

  • Klicken Sie auf „Weiter".

  • Aktivieren Sie „Enable Media Optimization".

  • Klicken Sie auf „Weiter".

  • Klicken Sie auf „Configure", um die Änderungen zu übernehmen.
