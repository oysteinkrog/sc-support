So installieren Sie AVT Manta/Prosilica GigE-Kameras

Dieser Support-Artikel beschreibt, wie Sie eine AVT GigE-Kamera mit einem Computer verbinden, wie Sie das System konfigurieren und welche Hardwareanforderungen für die Verwendung einer GigE-Kamera gelten.

Hardwareanforderungen

Für die Einrichtung und Installation von GigE-Kameras benötigen Sie einen oder mehrere freie Netzwerkanschlüsse an Ihrem Computer.

Wir empfehlen die Verwendung einer der folgenden Netzwerkkarten, da diese vom Hersteller getestet und für die Kompatibilität freigegeben wurden:

  • Intel Pro 1000 GT (PCI, 1 Port)

  • Intel Pro 1000 PT (PCIe x1, 1 Port)

  • Intel CT (PCIe x1, 1 Port)

  • Intel Pro 1000 PT Dual Port (PCIe x4, 2 Ports)

  • Intel Pro 1000 PT Quad Port Low Profile (PCIe x4, 4 Ports)

Es ist auch möglich, die meisten anderen Gigabit-Netzwerkkarten zu verwenden, jedoch muss die Karte unbedingt „Jumbo Frames" unterstützen.

Wenn Sie mehr als eine Kamera verwenden möchten, kann es in einigen Fällen auch erforderlich sein, einen Gigabit-Netzwerk-Switch zu verwenden. Die meisten Gigabit-Switches funktionieren, aber es ist wichtig sicherzustellen, dass der Switch ebenfalls Jumbo Frames unterstützt.

  • Netgear GS105 Gigabit-Switch 5-Port

Hardwareinstallation und Driver

Für Allied Vision Tech (AVT)-Kameras lesen Sie bitte die Herstellerdokumentation (Seiten 19–26), die am Ende dieser Seite verlinkt ist.

Die wichtigsten Schritte sind:

  • Laden Sie die Driver von https://www.swingcatalyst.com/drivers herunter

  • Installieren Sie die Driver und achten Sie darauf, die Installation des „Filter" zu akzeptieren.

  • Konfigurieren Sie die Netzwerkkarte so, dass sie „Jumbo Frames (9K)" akzeptiert.

  • Deaktivieren Sie alle Netzwerkmodule auf der Netzwerkkarte mit Ausnahme des AVT-Filters und IPv4.

Wenn Sie unsicher sind, wie Sie einen dieser Schritte durchführen sollen, lesen Sie bitte die oben verlinkte Herstelleranleitung. Sie enthält eine umfassende Schritt-für-Schritt-Erklärung aller Vorgänge.

Anschließen der GigE-Kamera(s)

Um eine einzelne GigE-Kamera anzuschließen, verwenden Sie einfach ein normales CAT5e/6-RJ45-Netzwerkkabel, um die Kamera direkt mit der Gigabit-Netzwerkkarte/-Port zu verbinden.

Wenn Sie mehr als eine Kamera anschließen möchten, können Sie mehrere Netzwerkkarten oder in einigen Fällen einen Netzwerk-Switch verwenden, um mehrere Kameras an eine einzelne Karte anzuschließen.

Die Verwendung eines Netzwerk-Switches ist nur in bestimmten Fällen möglich (wenn die Gesamtbandbreite aller Kameras die eines Gigabit-Ports nicht überschreitet). Bitte kontaktieren Sie uns, wenn Sie unsicher sind, ob dies in Ihrem Fall möglich ist.

Zwei Kameras an eine einzelne Netzwerkkarte/-Port anschließen

In einigen Fällen ist es möglich, 2 Kameras an eine einzelne Netzwerkkarte/-Port anzuschließen.

Dies wird derzeit für folgende Kameras unterstützt:

  • AVT Manta G-033/G-034/G-046

  • AVT Prosilica GC650

Eine statische IP am Ethernet-Adapter einrichten

Sobald den Kameras statische IP-Adressen zugewiesen wurden, müssen Sie die Netzwerkadapter, die Sie verwenden möchten, mit einer statischen IP konfigurieren. Diese muss so eingestellt werden, dass sie zu jeder angeschlossenen Kamera passt.

Das bedeutet: Wenn Sie die Kamera trennen und an einen anderen Ethernet-Adapter anschließen, funktioniert sie nicht, ohne neu konfiguriert zu werden.

Warnung:

Die unten genannte Nummer des „Ethernet-Adapters" bezieht sich nicht auf die tatsächliche Nummer des Netzwerkadapters, sondern dient lediglich zur Veranschaulichung. Bitte konfigurieren Sie jeden Netzwerkadapter kameraspezifisch, d. h. wenn Sie zwei Kameras angeschlossen haben, konfigurieren Sie diese nacheinander und beziehen Sie sich auf die Tabellen für Ethernet-Adapter 1 und 2. Ändern Sie die Einstellungen an keinen Netzwerkadaptern, an denen keine identifizierten Kameras angeschlossen sind.

  • Klicken Sie mit der rechten Maustaste auf den Ethernet-Adapter, der mit der Kamera verbunden ist.

  • Klicken Sie auf „NIC Settings".

  • Aktivieren Sie Jumbo Frame.

  • Setzen Sie die Empfangspuffer auf den Maximalwert.

  • Setzen Sie die Sendepuffer auf den Maximalwert.

  • Klicken Sie bei „Internet Protocol Properties" auf „Open".

  • Konfigurieren Sie den Netzwerkadapter gemäß der nachstehenden Tabelle.

Empfohlene statische IP-Konfiguration für jeden Ethernet-Adapter

Eine statische IP an der Kamera einrichten

Stellen Sie sicher, dass Ihre Lynx-Kamera(s) angeschlossen ist/sind. Wenn Sie die Kamera nach dem Start der Anwendung angeschlossen haben, fahren Sie mit der Maus über das Menü „GigE" und klicken Sie auf die Schaltfläche „Aktualisieren".

Dieser Vorgang muss für alle angeschlossenen Lynx-Kameras wiederholt werden, für die Sie eine statische IP eingerichtet haben.

Bitte beachten Sie, dass Sie zunächst die statische IP für Kamera 1 und anschließend für Netzwerkkarte 1 festlegen müssen. Wenn Sie Kamera 1 abgeschlossen haben, fahren Sie mit Kamera 2 fort usw. Die genannten Nummern entsprechen nicht den tatsächlichen Namen der Netzwerkadapter, z. B. „Ethernet 2", sondern dienen lediglich zur Veranschaulichung.

  • Klicken Sie mit der rechten Maustaste auf die Kamera in der Liste und klicken Sie auf „Modify IP".

  • Ändern Sie die Auswahl von DHCP oder LLA auf Static IP.

  • Konfigurieren Sie die IP-Adresse und die Subnetzmaske gemäß der nachstehenden Beschreibung.

  • Die IP muss für jede Kamera unterschiedlich sein.
