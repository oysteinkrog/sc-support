Einrichtung mehrerer Displays mit Swing Catalyst

So richten Sie mehrere Displays ein

Dieser Supportartikel behandelt die Einrichtung und Konfiguration mehrerer Displays unter Windows. Er zeigt die Einrichtung des Feedback-Bildschirms in Swing Catalyst und die Verwendung mehrerer Display-Szenarien in Swing Catalyst sowie die Navigation und das Verschieben von Fenstern mit mehr als einem Monitor.

So richten Sie mehrere Displays unter Windows ein:

  1. Stellen Sie sicher, dass Ihr Computer mehrere Displays verbinden kann. Einige Computer oder Laptops haben Einschränkungen, z. B. maximal 2 Displays.

Bei Setups mit mehr als zwei Displays benötigen Sie entweder eine Grafikkarte, die die erforderliche Anzahl von Ausgängen unterstützt, oder wenn Sie das Display einfach spiegeln möchten, kann dies mit HDMI-Splitter erfolgen (siehe unten).

  1. Überprüfen Sie, dass Sie die erforderlichen Kabel zum Anschluss Ihres Displays haben. Die häufigsten Verbindungstypen heute sind: HDMI, DVI oder Display Port. Letzterer erfordert häufig einen Adapter. Die meisten heutigen Computer haben einen HDMI-Anschluss, aber einige Laptops haben HDMI mini oder Display Port.

Es ist wichtig zu beachten, welcher Anschlusstyp vorhanden ist, damit Sie den geeigneten Adapter haben, wenn nötig.

  1. Verbinden Sie Ihren Monitor mit Ihrem Computer und klicken Sie mit der rechten Maustaste auf den Desktop und wählen Sie Anzeigeeinstellungen.

If the display has been successfully detected it should show more than one display.

To set your display as the main display, check the “Make this my main display” box.

Note: You may want to set your main display to display 1 (i.e the first output on the graphics card).

If you wish to extend the desktop to your secondary display select the option under Multiple displays.

Please note that if the display you’re connecting to has a higher or lower resolution the image might be slightly different. The DPI also might be different causing the text to be larger or smaller than what you might be used to. Use the recommended resolution where possible.

Now that we have more than one display set up in Windows, make sure you have the orientation right (i.e that the monitor on the right is to your right). Having this sorted helps a lot in navigating; especially if it’s more than two displays.

Note: Windows 7 has a different configuration for displays, but the overall process is the same.
