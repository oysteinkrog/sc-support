So exportieren Sie Student-Daten in Swing Catalyst

Dieser Artikel beschreibt, wie Sie alle Kontaktinformationen Ihrer Students exportieren können, die in Ihrer Swing Catalyst-Datenbank gespeichert sind.

Möchten Sie Rohdatenwerte exportieren? Lesen Sie, wie Sie Daten exportieren, z. B. Kraftdaten: export-raw-data.md

Öffnen Sie in Swing Catalyst den Explorer und klicken Sie anschließend auf die Schaltfläche „Exportieren".

Klicken Sie auf „Student-Kontaktinformationen".

Wählen Sie aus, wo die CSV-Datei gespeichert werden soll:

Hinweis: Möglicherweise müssen Sie die Datei in „students.csv" umbenennen, damit sie von Ihrem Tabellenkalkulationsprogramm erkannt wird.
