So verwenden Sie Foresight GC3 / Bushnell Launch Pro mit Swing Catalyst

Einführung

Dieser Support-Artikel beschreibt, wie Sie den Foresight GC3 oder Bushnell Launch Pro mit Swing Catalyst einrichten.

Der Foresight GC3 verfügt über WLAN und WiFi Direct sowie USB und Ethernet als verschiedene Möglichkeiten, eine Verbindung zum Launch Monitor herzustellen.

Bitte beachten Sie, dass WLAN in diesem Zusammenhang keine direkte Verbindung zum GC3 bedeutet – das wird WiFi Direct genannt. WLAN ist das Netzwerk, über das sich der GC3/BLP mit einem vorhandenen drahtlosen Netzwerk verbindet.

Voraussetzungen

  • Computer mit einem freien USB-Anschluss, Ethernet-Anschluss oder WLAN (zusätzlich zur Internetverbindung).

  • Swing Catalyst 10.0 oder höher

Note: Wenn Sie HD-Kameras mit Swing Catalyst verwenden möchten, empfehlen wir, FSX separat auszuführen (d. h. nicht gleichzeitig mit Swing Catalyst) oder auf einem anderen Computer.

Bitte stellen Sie sicher, dass Sie mindestens eine NVidia GeForce 1080 oder besser verwenden und dass der PC die Empfehlungen von Foresight angemessen erfüllt.

Verbindung und Einrichtung

  1. Verbinden Sie den GC3 über USB, WLAN* oder Ethernet.

  2. Unter Einstellungen -> Hardware -> Launch Monitor sollte eine Auswahl von Launch Monitor(s) mit verschiedenen Schnittstellen aufgelistet sein.

  3. Stellen Sie sicher, dass Sie den Launch Monitor auswählen, den Sie verwenden möchten, sowie die Schnittstelle, über die Sie eine Verbindung herstellen möchten:

*** Wenn Sie eine Verbindung über WLAN herstellen, ist es wichtig, dass Sie über eine andere Möglichkeit für den Internetzugang verfügen, da dieser zur Nutzung des GC3 über das Internet validiert werden muss.**

Fehlerbehebung

Der Foresight GC3 wird nicht als verbunden angezeigt oder löst nicht aus

Es gibt einen bekannten Fehler im Foresight SDK, der die Versionen 10.0 bis 10.1.0 von Swing Catalyst betrifft.

Dieser Fehler verursacht, dass Swing Catalyst keine Daten vom GC3/BLP empfängt.

Workaround:

  • Schließen Sie Swing Catalyst und verbinden Sie den GC3 / Launch Pro über USB mit Ihrem Computer.

  • Stellen Sie sicher, dass der Foresight GC3 auf Ihrem Computer angezeigt wird. Er wird als Massenspeichergerät unter „Dieser PC" angezeigt.

  • Laden Sie den Workaround herunter und entpacken Sie ihn von: https://cloudfront.swingcatalyst.com/files/GC3-BLP-Workaround.zip

  • Öffnen Sie den entpackten Ordner und doppelklicken Sie auf „Workaround.exe". Es öffnet sich ein Eingabeaufforderungsfenster, in dem versucht wird, eine Verbindung zu Ihrem Launch Monitor herzustellen und zu trennen.

Weitere Vorschläge zur Fehlerbehebung:

  • Schließen Sie das Gerät an einen anderen USB-Anschluss am Computer an, wenn es nicht angezeigt wird.

  • Wenn Sie über WiFi Direct verbunden sind, stellen Sie sicher, dass Sie auf anderem Wege Internetzugang haben oder einen separaten WLAN-Dongle verwenden.

  • Versuchen Sie, eine Verbindung über eine andere Schnittstelle herzustellen, z. B. wenn Sie WLAN verwendet haben, versuchen Sie es mit Ethernet oder USB.

  • Stellen Sie sicher, dass keine andere Software gleichzeitig versucht, eine Verbindung zum Gerät herzustellen.

Der Foresight GC3 ist verbunden und löst aus, aber die Aufnahmen enthalten keine Daten

  • Versuchen Sie, das GC3/BLP-Gerät neu zu starten.

  • Stellen Sie sicher, dass Sie einen Schläger mit korrekt platzierten Aufklebern verwenden.

  • Stellen Sie sicher, dass sich keine anderen kamerabasierten Launch Monitors in der Nähe befinden, die die Fähigkeit des GC3/BLP zur Ballverfolgung beeinträchtigen könnten.

Weitere Hinweise zur Fehlerbehebung finden Sie in den folgenden Fehlerbehebungsartikeln von Foresight.
