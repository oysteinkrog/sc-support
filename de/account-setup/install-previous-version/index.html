Wie man eine frühere Version von Swing Catalyst installiert

Wie man auf eine ältere Softwareversion zurückwechselt

Dieser Support-Artikel beschreibt, wie man eine frühere Version von Swing Catalyst installiert.

Wenn Sie ein Beta-Benutzer sind und die vorherige stabile Version installieren möchten:

  • Bitte deaktivieren Sie „Beta-Versionen zulassen" nachdem Sie die vorherige Version installiert haben.

Beim Zurückwechseln zu einer älteren Softwareversion wird SwingCatalyst automatisch versuchen, eine passende Datenbankversion zu finden und zu laden. Bei jedem größeren Release, z. B. 9.8 -> 10.0, 10.0 -> 10.1, ändert sich die Datenbankversion. Das bedeutet, dass Aufnahmen, die mit der neueren Version erstellt wurden, in der alten Version nicht verfügbar sind. Wenn Sie wichtige Aufnahmen haben, die Sie sichern oder speichern möchten, empfehlen wir dringend, diese vor dem Zurückwechseln zu exportieren.

Daher ist es wichtig, dies zu berücksichtigen, wenn Sie die Softwareversion zurücksetzen möchten.

Wie man SwingCatalyst deinstalliert

  • Öffnen Sie die Windows-Einstellungen. Klicken Sie mit der rechten Maustaste auf das Windows-Symbol in der Taskleiste und wählen Sie Einstellungen.

  • Klicken Sie in den Einstellungen auf Apps und scrollen Sie nach unten, bis Sie SwingCatalyst sehen, oder geben Sie Swing in die Suchleiste ein.

  • Klicken Sie auf SwingCatalyst und dann auf Deinstallieren.

  • Klicken Sie auf Ja und folgen Sie den Anweisungen auf dem Bildschirm.

Eine frühere Version installieren

Ältere Versionen von SwingCatalyst finden Sie in unserem Software-Archiv.

https://www.swingcatalyst.com/downloads/archives (nach unten zum Download-Bereich scrollen):

  • Klicken Sie auf die Version, die Sie installieren möchten, um die Installationsdatei herunterzuladen.

  • Heruntergeladene Dateien werden in der Regel im Ordner Downloads gespeichert.

  • Doppelklicken Sie auf die Version, die Sie installieren möchten, und folgen Sie den Anweisungen auf dem Bildschirm.
