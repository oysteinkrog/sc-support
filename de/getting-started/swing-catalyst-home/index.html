Erste Schritte - Swing Catalyst Home

Einführung

Dieser Artikel ist die Anleitung für die ersten Schritte mit Swing Catalyst Home.

Es kann zu geringfügigen Abweichungen zwischen Ihrem Produkt und den Screenshots in dieser Anleitung kommen.

Anforderungen

  • Ein gültiges Home-Abonnement

Swing Catalyst 9.7 oder neuer (Welche Version habe ich?)

  • Computeranforderungen:

Bitte beachten Sie, dass Swing Catalyst nur auf Windows 10/11 läuft.

Foresight (FSX 2020/Play empfohlene PC-Spezifikationen) – Gilt für Foresight-Kunden.

Installation der Software und des Lizenzschlüssels

Mit jeder neuen Swing Catalyst-Lizenz erhalten Sie eine Begleit-E-Mail mit Anweisungen. Wenn Sie die E-Mail nicht finden können, überprüfen Sie bitte Ihren Spam-Ordner oder durchsuchen Sie Ihren Posteingang.

Befolgen Sie die Anweisungen zum Herunterladen und Installieren von Swing Catalyst. Nach der Installation geben Sie den Lizenzschlüssel ein, wenn die Software danach fragt.

Beispiel-E-Mail:

Haben Sie Probleme bei der Installation des Lizenzschlüssels? Bitte lesen Sie unseren Schritt-für-Schritt-Artikel.

Verbindung einer oder mehrerer Kameras

Bitte lesen Sie diese Liste der unterstützten Kameras.

Wenn Sie eine FLIR-, IDS- oder AVT-Kamera verwenden, müssen Sie möglicherweise die entsprechenden Treiber herunterladen und installieren. Bitte lesen Sie unseren Treiberbereich. Wenn Sie eine FLIR-Kamera verwenden, lesen Sie bitte unsere dedizierten Kameranutzungsanleitungen.

Hinweis: Wir empfehlen, sicherzustellen, dass FSX und Swing Catalyst nicht ausgeführt werden, bevor Sie Kameratreiber installieren. Nach der Installation der Treiber müssen Sie möglicherweise Ihren Computer neu starten.

Im Hauptmenü finden Sie Einstellungen, indem Sie auf das Zahnradsymbol klicken.

Erkannte Kameras werden automatisch in der Kameraliste aufgeführt.

Um die Kamera zu verwenden, muss ihr ein Winkel zugeordnet werden.

Wählen Sie einen Winkel aus, indem Sie auf das deaktivierte Symbol klicken und die Kamera aktivieren, indem Sie “OFF” in “ON” ändern.

Verbindung mit einem Launch Monitor

Unter “Hardware-Einstellungen” können Sie zwischen unterstützten Launch Monitoren wählen.

In Version 9.7 und 9.8 können Sie Ihren Launch Monitor in der Liste auswählen, ihn auf “EIN” schalten und “Als Auslöser verwenden” aktivieren.

In Version 10.0 und später aktivieren Sie einfach die Launch Monitor-Unterstützung und drücken die Suchschaltfläche. SwingCatalyst sollte alle verbundenen und kompatiblen Launch Monitore erkennen.

  • Stellen Sie sicher, dass der Launch Monitor eingeschaltet und mit dem PC verbunden ist.

  • Wir empfehlen immer, wenn möglich eine kabelgebundene Verbindung zu verwenden, z. B. USB oder Ethernet statt WiFi.

Für eine detailliertere Beschreibung zur Einrichtung Ihres Launch Monitors finden Sie in folgenden Leitfäden:

  • Foresight GCQuad/GCHawk

  • Foresight GC3 / Bushnell Launch Pro

  • Foresight GC2*

  • Flightscope X-Series

  • FullSwing (E6)

  • FlightScope Mevo+

*Die Foresight GC2-Integration unterstützt keine gleichzeitige Verbindung mit FSX. Um die GC2 mit FSX zu verwenden, muss Foresight GC2 (Sim) ausgewählt werden.

Wenn Sie einen Launch Monitor als Auslösegerät ausgewählt haben, wird Ihr Schwung im Erfassungsmodus automatisch aufgezeichnet. Wenn Sie keinen Launch Monitor haben, kein Problem – Sie können stattdessen ein Mikrofon als Auslöser verwenden!

Benutzer erstellen

Erstellen Sie einen Benutzer, indem Sie diese Schritte ausführen und einen Schwung aufzeichnen.

Ein Benutzer wird automatisch generiert, wenn Sie Swing Catalyst zum ersten Mal ausführen. Dieser Benutzer wird auf Grundlage der Lizenzdetails generiert. Wenn Sie die Profilinformationen bearbeiten möchten, können Sie dies gerne tun.

Klicken Sie im Hauptmenü auf “Start”

Klicken Sie auf die Dropdown-Schaltfläche “Benutzer auswählen” und klicken Sie auf “Neu”:

Hinweis: Ein Benutzer wird automatisch auf Grundlage Ihrer Lizenzdetails generiert. Wenn Sie diese bearbeiten oder einen neuen Benutzer hinzufügen möchten, können Sie dies durch Klicken auf “Neu” oder “Bearbeiten” tun.

Geben Sie einen Namen ein und klicken Sie auf “Speichern”

Einige Home-Lizenzen haben eine maximale Benutzerbeschränkung, die begrenzt, wie viele Benutzerprofile in Swing Catalyst gespeichert werden können.

Werfen Sie einen Blick auf die Swing Catalyst-Benutzeroberfläche und einige der Menüs und Schaltflächen.

Die Analysis-Menü-Symbolleiste

Von links nach rechts: Menü, Explorer, Benutzer wechseln, Erfassen, Erfassungsoptionen und Layout.

Das Swing Catalyst-Symbol ist auch die Menü-Schaltfläche, die einen schnellen Zugriff auf Einstellungen und das Beenden der aktuellen Sitzung ermöglicht.

Benutzer wechseln

Erfassen

Um einen Schwung aufzuzeichnen, müssen Sie sich im Erfassungsmodus befinden.

Wenn Sie auf die Schaltfläche “Erfassen” klicken, wechseln Sie automatisch vom Wiedergabe- in den Erfassungsmodus.

Das grüne Symbol “Erfassung bereit” signalisiert, dass das System bereit zur Erfassung ist. Mit Swing Catalyst Home werden Sie diesen Modus automatisch beim Start einer Sitzung aktivieren!

“Erfassung bereit” bedeutet einfach, dass der Erfassungsmodus aktiviert ist und Swing Catalyst aktiv Daten streamt. Die Daten werden nur gespeichert, sobald ein Auslöseereignis auftritt, z. B. (manueller Auslöser, Launch Monitor, Mikrofon).

Erfassungsoptionen

Wählen Sie zwischen verschiedenen Auslöseroptionen wie Mikrofon oder Launch Monitor, und ändern Sie Erfassungsmodi.

Layouts

Sie können verschiedene Layouts in Swing Catalyst über die Dropdown-Schaltfläche “Layout” auswählen.

Swing Catalyst merkt sich das zuletzt verwendete Layout im Wiedergabe- und Erfassungsmodus.

Wie in der Ikonographie dargestellt, unterscheiden sich die Layouts darin, was angezeigt wird und wie es angezeigt wird.

Beispiel des Layouts “Einzelne Aufnahme” mit 2 Kameras.

Das Layout des Modus “Vergleich” mit einer Kamera:

Hier sind die Aufnahmen in zwei separate “Ansichtsfenster” (A und B) unterteilt. Wenn wir uns den unteren Bildschirmrand genauer ansehen, werden zuvor aufgezeichnete (oder geöffnete) Aufnahmen im Stapel angezeigt.

Der Stapel

Der Stapel zeigt die letzte Aufnahme mit den neuesten Aufnahmen ganz links.

In diesem Beispiel ist die Aufnahme mit einem orangefarbenen A gekennzeichnet, um anzuzeigen, dass diese Aufnahme im “Ansichtsfenster A” geöffnet ist. Die orangefarbene Unterstreichung der Aufnahme zeigt an, dass sie ausgewählt ist.

Sie können schnell Informationen zu einer Aufnahme anzeigen, indem Sie diese einmal anklicken:

Es ist auch möglich, eine Aufnahme mit einer Bewertung (1-3 Sterne) zu versehen. Sie können beispielsweise im Explorer nach Bewertung filtern

Swing Catalyst zeigt Benachrichtigungen unten rechts auf dem Bildschirm an, wenn Sie sich im Erfassungsmodus befinden.

Der Aufnahmefortschritt und der Status werden durch den Fortschrittskreis im Stapel angezeigt. Mit der Schaltfläche “Aufnahme verwerfen” können Sie die Aufnahme jederzeit abbrechen.

Auf den Indikator kann geklickt werden, um weitere Details zu sehen, was gerade verarbeitet wird.

Auswahl der Kameralayouts

Im gleichen Dropdown-Menü “Layout” können Sie je nach Layout die Anzahl der verschiedenen Kamerawinkel auswählen, die angezeigt werden sollen. Im Wiedergabemodus (beim Anzeigen eines aufgezeichneten Schwungs) hängt die Kameraauswahl ausschließlich davon ab, wie viele Kameras zur Erstellung der Aufnahme verwendet wurden.

Im Erfassungsmodus hängt die Anzahl der sichtbaren Kameras davon ab, wie viele Kameras auf Ihrem System aktiviert sind, und ob die Lizenz die Anzahl der Kameras unterstützt, die Sie verwenden möchten.

Kamerawinkel wechseln

Wenn Sie Aufnahmen mit mehr als einer Kamera haben, können Sie die angezeigte Kamera durch Anklicken des Kamerasymbols ändern.

Es ist auch möglich, von hier aus einige kleinere Kameraeinstellen vorzunehmen, wie zum Beispiel Spiegelung und Drehung des Kamerawinkels. Diese Änderungen gelten nur für die Aufnahme und können hilfreich sein, wenn Sie einen Linkshänder mit einem Rechtshänder vergleichen möchten usw.

Zeichenwerkzeuge

Wie im obigen Screenshot zu sehen ist, befinden sich die Zeichenwerkzeuge auf der linken Seite der Software.

Mit Zeichenwerkzeugen können Sie auf das Videobild zeichnen, sowohl auf bereits aufgezeichnete Videos als auch auf den Live-Video-Feed (während der Aufnahmemodus aktiv ist).

Das Linienwerkzeug bietet eine Auswahl verschiedener Linientypen, mit dem Standard-Werkzeug “Linie” können Sie eine gerade Linie zwischen zwei beliebigen Punkten erstellen.

Es gibt drei verschiedene Linienstärken zur Auswahl.

Unterschiedliche Farben erleichtern die Unterscheidung zwischen verschiedenen Linien.

Zoom- und Schwenk-Werkzeug

Ganz unten in der Symbolleiste unter den Zeichenwerkzeugen befindet sich das Zoom- und Schwenk-Werkzeug sowie die Schaltfläche “Videobild ausfüllen”.

Es ist auch möglich, das Videobild zu vergrößern und zu manipulieren, indem Sie die Strg-Taste halten und gleichzeitig das Mausrad scrollen.

Explorer

Sie können Ihre Aufnahmen hier ganz einfach verwalten. Der Explorer ist in drei “Abschnitte” unterteilt:

Auf der linken Seite befinden sich die im System registrierten Benutzer, in der Mitte alle Aufnahmen des jeweiligen Benutzers und auf der rechten Seite der Vorschaubereich.

Aufnahmen werden automatisch in Sitzungen gruppiert und nach Datum sortiert.

  • Klicken Sie auf einen Schwung und er wird automatisch im Bereich “Vorschau” (rechts) angezeigt.

Sie können Aufnahmen auch öffnen, indem Sie mit der rechten Maustaste klicken und auswählen, in welchem Viewport Sie sie öffnen möchten, oder Sie ziehen sie alternativ in die Bereiche “Aufnahme hier ablegen” am unteren Rand.

Ressourcen & Troubleshooting

Hier finden Sie Ressourcen und Tipps zur Fehlerbehebung, um die häufigsten Probleme zu lösen.

Häufigste Probleme

Die häufigsten Probleme, denen Benutzer gegenüberstehen, sind normalerweise mit extern angeschlossener Hardware verbunden, sei es eine Kamera, ein Launch Monitor oder eine Sensorplatte. Etwas so Einfaches wie ein defektes Kabel (zum Beispiel ein zu langes Kabel oder ein inkompatibler USB-Verlängerer) kann Probleme verursachen. Daher zielt dieser Abschnitt des Leitfadens darauf ab, Ihnen zu helfen, das Problem zu lösen oder die Ursache des Problems einzugrenzen.

Kamera(s) werden nicht in der Kameraliste angezeigt

Wenn die Kamera nicht in der Kameraliste angezeigt wird, wird sie nicht erkannt oder nicht ordnungsgemäß verbunden.

  • Wenn die Kamera nicht in der Kameraliste angezeigt wird, wird sie höchstwahrscheinlich nicht in Windows erkannt oder wird von einer anderen Anwendung verwendet. Versuchen Sie, die Kamera zu trennen und erneut anzuschließen.

  • Die Kamera wird möglicherweise nicht von Swing Catalyst unterstützt.

  • Für The Imaging Source-Kameras: Wenn der Herstellertreiber installiert ist, müssen Sie ihn möglicherweise deinstallieren, damit die Kamera funktioniert.

  • Ethernet- (Netzwerk-) / GigE-Kameras erfordern möglicherweise eine IP-Konfiguration.

Keine Daten empfangen

Dies weist darauf hin, dass Swing Catalyst keine Videobilder oder Daten zur Verarbeitung empfängt.

Beispiele für Ursachen dieser Fehlerart können sein:

  • Schlechtes Kabel/Verbindung: Versuchen Sie, die Kamera zu trennen und an einen anderen USB-Anschluss anzuschließen.

  • Fehlerhafte Einstellungen: (Besonders bei Web-Kameras und DirectShow-Kameras). Überprüfen Sie die Belichtungseinstellung. Wenn Auto deaktiviert ist und die Belichtung sehr hoch eingestellt ist, kann die Bildrate erheblich sinken.

  • Eine Lösung für Web-Kameras kann darin bestehen, “Zeitstempel manuell” zu aktivieren (siehe Bild unten)

Ein Fehler ist aufgetreten

Diese Fehlerart tritt häufig auf, wenn die Kamera von einer anderen Anwendung verwendet wird. Besonders Web-Kameras können leicht von Drittanbieter-Software verwendet werden. Versuchen Sie, andere Programme zu schließen und Swing Catalyst neu zu starten.

Verlorene Frames / Unzureichende Daten empfangen

Verlorene Frames bedeuten, dass die Videobilder/Daten, die von der Kamera zum Computer übertragen werden, in unterschiedlichem Maße verloren gehen. Besonders bei mehreren Kameras ist dies nicht gut, da plötzlich eine Kamera Teile des Schwungs vermisst. Swing Catalyst warnt davor, und wenn das System zu viele Frames verliert, ist es nicht möglich, eine Aufnahme auszulösen.

Ursachen hierfür könnten sein:

  • USB3-Kamera an einem USB 2.0-Anschluss angeschlossen.

  • Verwendung von schlecht konstruierten Kabeln oder Verlängerungskabeln.

  • Überschreitung der empfohlenen Kabellänge.

  • USB3-Kamera an einen USB-Hub angeschlossen, an dem andere Geräte angeschlossen sind und die gleiche Bandbreite nutzen.

  • Ethernet-Kamera an einen Netzwerkanschluss angeschlossen, der nicht ordnungsgemäß konfiguriert ist oder keine Jumbo Frames unterstützt.

  • Kamera verbraucht zu viel Bandbreite im Vergleich zu der auf dem System verfügbaren.

Tipps:

Für USB-Kameras empfehlen wir, die Bildrate (und/oder den Gerätelink-Durchsatz – für FLIR-Kameras) zu senken, um den Bandbreiteverbrauch zu reduzieren.

  • Reduzieren der Bildrate (und/oder des Gerätelink-Durchsatzes).

  • Wenn Sie mehrere Kameras verwenden, versuchen Sie, einige Kameras zu trennen oder zu deaktivieren. Meldet das System immer noch verlorene Frames?

  • Überprüfen Sie die Kabelverbindungen. Sind die Kameras an einen USB-Hub oder eine Verlängerung angeschlossen? Versuchen Sie, sie direkt an den Computer anzuschließen.

  • Versuchen Sie, andere Software zu schließen, die CPU- und Grafik-intensiv ist, um Ressourcen freizugeben.

Launch Monitor Fehlerbehebung

  • Artikel zur Unterstützung von Launch Monitoren

Hier finden Sie eine Liste häufiger Probleme mit Launch Monitoren und deren Lösungen.

Szenario: Gerät nicht verbunden

Im obigen Beispielszenario ist der Launch Monitor in den Einstellungen aktiviert, aber das Gerät ist nicht verbunden / wird nicht erkannt.

Empfohlene Schritte zur Fehlerbehebung:

  • Überprüfen Sie, ob das Gerät noch eingeschaltet ist.

  • Versuchen Sie, das Gerät neu zu starten.

  • Versuchen Sie, sich über USB oder Ethernet zu verbinden, wenn möglich, anstatt über WiFi.

  • Versuchen Sie, sich mit der Software des Herstellers zu verbinden, um zu bestätigen, ob eine Verbindung möglich ist.

Szenario: Aufnahmen werden nicht ausgelöst.

Launch Monitor ist verbunden und wird erkannt, löst aber nicht aus, wenn sich die Software im Erfassungsmodus befindet.

Empfohlene Schritte zur Fehlerbehebung:

  • Stellen Sie sicher, dass die Auslöseroption aktiviert ist.

  • Erscheinen Ball- und/oder Schläger-Daten auf dem Gerät? (Können Sie überprüfen, ob es außerhalb von Swing Catalyst funktioniert?).

  • Gibt es Warnungen zu verlorenen Frames oder unzureichenden Daten? Swing Catalyst wird nicht ausgelöst, wenn die Kamera Frames verliert.
