Kako postaviti više zaslona sa Swing Catalyst

Kako postaviti više zaslona

Ovaj članak podrške pokriva postavljanje i konfiguraciju više zaslona u sustavu Windows. Pokazuje kako postaviti zaslon povratne informacije u Swing Catalyst i kako se koriste scenariji s više zaslona u Swing Catalyst, kao i kako navigirati i premještati prozore s više od jednog monitora.

Kako postaviti više zaslona u sustavu Windows:

  1. Provjerite da je vaše računalo sposobno za povezivanje s više zaslona. Neka računala ili prijenosna računala imaju određena ograničenja, kao što je maksimalno 2 zaslona.

Za postavljanja s više od dva zaslona trebate ili grafičku karticu koja može pružiti potreban broj izlaza, ili alternativno, ako želite samo zrcaliti zaslon, to se može učiniti s HDMI razdjeljačima (više o tome u nastavku).

  1. Provjerite da imate potrebne kablove za povezivanje sa svojim zaslonima. Najčešće vrste veza trenutno su: HDMI, DVI ili Display Port. Potonja često zahtijeva adapter. Većina računala danas ima HDMI priključak, međutim neka prijenosna računala imaju HDMI mini ili display port.

Važno je primijetiti koji je priključak spojen, tako da imate odgovarajući adapter ako je potreban.

  1. Spojite svoj monitor na računalo i desnom tipkom miša kliknite na radnu plohu te odaberite Postavke zaslona.

If the display has been successfully detected it should show more than one display.

To set your display as the main display, check the “Make this my main display” box.

Note: You may want to set your main display to display 1 (i.e the first output on the graphics card).

If you wish to extend the desktop to your secondary display select the option under Multiple displays.

Please note that if the display you’re connecting to has a higher or lower resolution the image might be slightly different. The DPI also might be different causing the text to be larger or smaller than what you might be used to. Use the recommended resolution where possible.

Now that we have more than one display set up in Windows, make sure you have the orientation right (i.e that the monitor on the right is to your right). Having this sorted helps a lot in navigating; especially if it’s more than two displays.

Note: Windows 7 has a different configuration for displays, but the overall process is the same.
