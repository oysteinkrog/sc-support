Slik setter du opp Basler GigE-kameraer med Swing Catalyst

Denne supportartikkelen dekker Oppsett og konfigurasjon av Basler-kameraer med Swing Catalyst.

note: For å bruke Basler-kameraer med Swing Catalyst trenger du en Halcon USB-dongle og en lisens. Ta kontakt med contact@swingcatalyst.com for å kjøpe en lisens.

Instruksjoner for installasjon og konfigurasjon av Halcon finner du her:

halcon-setup.md

Viktig:

Sørg for at du har MVTec Halcon driver Filter installert – kameraene vil ikke fungere som de skal uten dette. Sørg også for å fjerne avhukingen for eventuelle andre Filter-driver som er installert, f.eks. Basler Filter Driver.

Sørg for at Swing Catalyst er tillatt på både private og offentlige nettverk i Windows Defender-brannmuren.

example:

Stille inn IP-adressen til kameraene

IP-Oppsett

Hvert kamera og Ethernet-kort (NIC / nettverksgrensesnittkontroller) bør konfigureres med statiske IP-er på forskjellige subnett (og nettverksmaske)

note: NIC IP er IP-adressen til nettverkskortet på datamaskinen din, og kamera-IP er IP-adressen til kameraet. … indikerer et Område, ettersom dette er et eksempel på IP du kan sette.

Eksempler for enkelt- eller fler-kameraoppsett (med ett eller flere nettverkskort / adaptere):

Kameraer på nettverksadapter 1: nic ip: 10.0.1.1 cam ip: 10.0.1.10 … 10.0.1.20 subnet mask:255.255.255.0

Kameraer på nettverksadapter 2: nic ip: 10.0.2.1 cam ip: 10.0.2.10 … 10.0.2.20 subnet mask: 255.255.255.0

Kameraer på nettverksadapter 3: nic ip: 10.0.3.1 cam ip: 10.0.3.10 … 10.0.3.20 subnet mask: 255.255.255.0

Kameraer på nettverksadapter 4: nic ip: 10.0.4.1 cam ip: 10.0.4.10 … 10.0.4.20 subnet mask: 255.255.255.0

Først må vi sette opp IP-adressen til kameraet. Dette gjøres via Pylon IP Configurator.

Trykk på start-menyknappen på tastaturet og skriv pylon ip – da skal IP Configurator dukke opp. Hvis den ikke gjør det, har du sannsynligvis ikke programvaren installert.

For å installere Pylon-programvaren, se: https://www.baslerweb.com/en/sales-support/downloads/software-downloads/ og se etter: pylon 5.1.0 Camera Software Suite Windows.

Klikk på kameraet og velg deretter Static IP

Sett IP-adressen til kameraet og nettverksmasken i henhold til eksempelet ovenfor.

Konfigurere Basler GigE-kameraer via Halcon

I Swing Catalyst, gå til Innstillinger-fanen og deretter til Kameraer.

Klikk på Avansert.

  • Gå til Konfigurasjon-fanen.

  • Aktiver avkrysningsboksen GtlNumBuffers og skriv inn 200 som verdi.

Sette opp Basler GigE-kameraer:

La oss se på hvordan du stiller inn eksponering, lukkerhastighet og Bildehastighet.

note: Hvis du ikke får opp innstillingene og får en feilmelding i Swing Catalyst, må du sjekke brannmurinnstillingene i Windows. Prøv å slå av brannmuren for å sjekke om det er den som blokkerer Swing Catalysts tilgang til kameraene.

Hvis innstillingene fungerer og du kan strømme uten problemer, sørg for at Swing Catalyst er tillatt på både offentlige og private nettverk i Windows Defender-brannmuren.

Utvid AcquisitionTrigger-fanen og skriv inn maksimal (eller lavere) Bildehastighet, og klikk deretter på Enable Acquisition Frame Rate. Dette lar deg definere Bildehastigheten. Merk: Bildehastigheten kan begrenses av eksponeringsverdiene.

Stille inn eksponeringsverdier

Det er vanligvis best å bruke manuell eksponering for statiske omgivelser, som innendørsstudioer. Fullt automatisk eksponering kan føre til at Bildehastigheten endres og gi et inkonsistent bilde. I dette tilfellet bruker vi ikke Auto-eksponering, siden vi ønsker å ha kontroll over dette selv. Generelt anbefales en eksponeringstid på under 2000 (2 ms).

Stille inn Gain-verdier

På samme måte som med eksponering er det best å sette Gain til manuell ved statiske / innendørs lysforhold. Jo høyere eksponering, desto mer kornete blir bildet, og jo lengre tid tar videokodingen sammenlignet med lav Gain.

For å sette manuell Gain, endre Gain Auto fra Continuous til Off, og pause og spill deretter av Avspillingen for å laste innstillingene på nytt. Sett Gain-verdiene ved å endre tallverdiene i Gain (Raw).

Endre bildestørrelse, interesseområde, Region of Interest og mer

I noen tilfeller ønsker du å redusere bildestørrelsen for å fokusere på et bestemt område av videobildet, for eksempel for å se kølle og ball ved Impact i detalj.

Dette kan gjøres med interesseområde, også kjent som AOI, og ROI, Region of Interest. Å redusere den totale bildestørrelsen med denne funksjonen kan også gi deg økt Bildehastighet.

Lagre innstillinger til kameraet

Det er viktig å lagre innstillingene til kameraet. Hvis dette ikke gjøres, vil alt du har konfigurert gå tapt.

Sørg for at du setter Default Set Selector og Default Startup Set. Det finnes forskjellige brukersett å velge mellom, og i teorien kan du ha forskjellige innstillinger lagret på hvert sett. Det vil si at du kan velge «User Set 1» som standard og deretter trykke på User Set Save for å lagre de gjeldende innstillingene til den profilen.
