Kaip nustatyti kelis ekranus naudojant Swing Catalyst

Kelių monitorių nustatymas

Šis pagalbos straipsnis apima kelių monitorių nustatymą ir konfigūraciją Windows sistemoje. Jame parodoma, kaip nustatyti grįžtamojo ryšio ekraną Swing Catalyst ir kaip naudoti kelių ekranų scenarijus Swing Catalyst, taip pat kaip naviguoti ir perkelti langus naudojant daugiau nei vieną monitorių.

Kelių monitorių nustatymas Windows sistemoje:

  1. Įsitikinkite, kad jūsų kompiuteris gali prisijungti prie kelių monitorių. Kai kurie kompiuteriai ar nešiojamieji kompiuteriai turi apribojimų, pavyzdžiui, maksimaliai 2 ekranai.

Jei norite nustatyti daugiau nei du ekranus, turite turėti vaizdo kartę, galinčią suteikti tiek išėjimų, kiek jums reikia, arba, jei norite tiesiog atspindėti ekraną, tai galima padaryti naudojant HDMI splitterius (daugiau apie tai žemiau).

  1. Patikrinkite, ar turite reikiamus kabelius monitorių prijungimui. Labiausiai paplitę ryšio tipai šiandien yra: HDMI, DVI arba Display Port. Pastarasis dažnai reikalauja adapterio. Dauguma šiandieninių kompiuterių turi HDMI prievadą, tačiau kai kurie nešiojamieji kompiuteriai turi HDMI mini arba display port.

Svarbu žinoti, kokia yra prievado, prie kurio jungiatės, tipo, kad turėtumėte reikiamą adapterį, jei jis reikalingas.

  1. Prijunkite monitorių prie kompiuterio ir dešiniuoju pelės mygtuku spustelėkite darbalaukį ir pasirinkite Display Settings.

If the display has been successfully detected it should show more than one display.

To set your display as the main display, check the “Make this my main display” box.

Note: You may want to set your main display to display 1 (i.e the first output on the graphics card).

If you wish to extend the desktop to your secondary display select the option under Multiple displays.

Please note that if the display you’re connecting to has a higher or lower resolution the image might be slightly different. The DPI also might be different causing the text to be larger or smaller than what you might be used to. Use the recommended resolution where possible.

Now that we have more than one display set up in Windows, make sure you have the orientation right (i.e that the monitor on the right is to your right). Having this sorted helps a lot in navigating; especially if it’s more than two displays.

Note: Windows 7 has a different configuration for displays, but the overall process is the same.
