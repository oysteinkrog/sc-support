วิธีใช้กล้อง Web Camera (การเชื่อมต่อแบบ DirectShow) กับ SwingCatalyst

  • หมายเหตุ: กล้อง USB ได้รับการทดสอบในสภาพแวดล้อมห้องปฏิบัติการ

การเชื่อมต่อกล้อง

เปิดใช้งานกล้องจากเมนูการตั้งค่า

คลิกที่ไอคอนรูปเฟือง

เมนูการตั้งค่า

โปรดทราบว่าประเภทการเชื่อมต่อกล้องจะถูกระบุไว้ เช่น DirectShow, Spinnaker:

หากตรวจพบอย่างถูกต้อง กล้องจะปรากฏในรายการกล้องโดยอัตโนมัติ

เพื่อใช้งานกล้อง จำเป็นต้องกำหนดมุมของกล้อง ให้คลิกที่ไอคอน “Disabled” และเลือกมุม จากนั้นสลับสวิตช์ “OFF” เป็น “ON” เพื่อเปิดใช้งานกล้อง

กล้อง Dragon ถูกเปิดใช้งานและกำหนดให้เป็นกล้องมองจากหน้าไม้ด้านขวา (หมายความว่ากล้องหันหน้าไปยังผู้ใช้จากด้านขวา)

การตั้งค่ากล้องขั้นสูง

การตั้งค่ากล้องขั้นสูงช่วยให้คุณสามารถเปลี่ยนชื่อกล้อง, สะท้อนภาพและหมุน, ครอบตัด, ปรับภาพวิดีโอ และเปลี่ยนแปลงการตั้งค่าต่าง ๆ ได้

หมายเหตุ: Auto ใช้ได้เฉพาะกับคุณสมบัติบางอย่างเท่านั้น เช่น ไวต์บาลานซ์ การรับแสง และโฟกัส

หากมีการเปลี่ยนแปลงที่ผิดพลาด คุณสามารถกู้คืนค่าเริ่มต้นได้โดยคลิก “Restore defaults”

การแก้ไขปัญหา

อัตราเฟรมต่ำ:

อัตราเฟรมอาจลดลงเนื่องจากการตั้งค่าการรับแสงบนกล้อง

โดยค่าเริ่มต้นกล้องส่วนใหญ่จะตั้งค่าการรับแสงแบบ Auto หากแสงไม่เพียงพอ เวลาการรับแสงต่อเฟรมจะสูงขึ้น และกล้องจะไม่สามารถให้อัตราเฟรมสูงสุดได้

หากการรับแสงสูงเกินไป อัตราเฟรมจะลดลง และการบันทึกจะมีความเบลอมากขึ้น

เฟรมที่หลุดหาย:

หากกล้องมีการหลุดของเฟรม (ในกรณีนี้คือไม่สามารถให้ FPS ตามที่ควรจะเป็น) อาจทำให้เกิดสิ่งแปลกปลอมในภาพได้

  • ตรวจสอบให้แน่ใจว่ากล้องเชื่อมต่อโดยตรงกับคอมพิวเตอร์ และควรเชื่อมต่อกับพอร์ต USB ที่อยู่ด้านหลังของคอมพิวเตอร์

  • คุณอาจต้องลองใช้พอร์ต USB ต่าง ๆ เพื่อหาพอร์ตที่เหมาะสมที่สุด โดยทั่วไปควรหลีกเลี่ยงพอร์ต USB ที่อยู่ด้านหน้าของคอมพิวเตอร์ตั้งโต๊ะ เนื่องจากการแสดงออกไม่ดี (มักให้อัตราเฟรมที่ต่ำกว่า)

การเลือก Media Type ที่แตกต่างกัน

โดยปกติ DirectShow และ SwingCatalyst จะเลือก Media Type ที่ดีที่สุดโดยอัตโนมัติ และไม่จำเป็นต้องเปลี่ยนแปลง อย่างไรก็ตาม บางกรณีหรือสถานการณ์อาจจำเป็นต้องทำ:

  • หากคุณมีกล้อง Web Camera ที่รองรับ 60 FPS ที่ความละเอียด 1920x1280 แต่ได้รับเพียง 30 FPS

  • ความละเอียดของวิดีโอดูเล็กกว่า/ด้อยกว่าเมื่อเทียบกับแอปพลิเคชันอื่น

  • คุณกำลังประสบปัญหาเฟรมหลุดหายและ/หรือรับข้อมูลได้ไม่เพียงพอ

รูปแบบบางอย่างใช้แบนด์วิดท์น้อยกว่ารูปแบบอื่น หากกล้องรองรับรูปแบบ RAW8, GREY8 หรือรูปแบบการถ่ายภาพ 8 บิตอื่น ๆ รูปแบบเหล่านี้จะดีกว่า Media Type ประเภท RGB หรือ MPEG เนื่องจากต้องใช้แบนด์วิดท์น้อยกว่าอย่างมาก
