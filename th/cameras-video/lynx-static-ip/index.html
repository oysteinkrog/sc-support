วิธีตั้งค่า IP แบบ Static บนกล้อง Lynx GigE

บทนำ

บทความสนับสนุนนี้อธิบายวิธีกำหนดค่ากล้อง Lynx ของคุณด้วย IP แบบ Static สำหรับการใช้งานทั่วไปไม่จำเป็นต้องทำสิ่งนี้ เนื่องจาก Swing Catalyst จัดการการกำหนดค่า IP โดยอัตโนมัติ

ข้อกำหนด

  • แอปพลิเคชัน MVS (ใช้สำหรับกำหนดค่า IP)

  • Swing Catalyst เวอร์ชัน 9.8.5 หรือใหม่กว่า

  • กล้อง Swing Catalyst Lynx GigE

  • การตั้งค่ากล้องที่ใช้งานได้อยู่แล้ว

การติดตั้งแอปพลิเคชัน MVS

  • ดาวน์โหลดและแตกไฟล์แอปพลิเคชัน MVS Client: https://swingcatalyst.s3.amazonaws.com/drivers/MVS_STD_3.4.1_220407.zip

  • ติดตั้ง MVS โดยทำตามคำแนะนำบนหน้าจอ

  • ยกเลิกการเลือก “Open release notes”

  • คลิก Finish

การตั้งค่า IP แบบ Static บน Ethernet Adapter

เมื่อกำหนด IP แบบ Static ให้กับกล้องแล้ว คุณจำเป็นต้องกำหนดค่า Network Adapter ที่ต้องการใช้งานด้วย IP แบบ Static ด้วยเช่นกัน โดยต้องกำหนดค่าให้ตรงกับกล้องแต่ละตัวที่เชื่อมต่ออยู่

หมายความว่าหากคุณถอดกล้องออกและต่อเข้ากับ Ethernet Adapter อื่น กล้องจะไม่ “ทำงาน” หากไม่ได้กำหนดค่าใหม่

Warning:

หมายเลข “Ethernet Adapter” ที่อ้างอิงด้านล่างไม่ใช่หมายเลขที่ผูกกับ Network Adapter จริง แต่ใช้เพื่อการอธิบายเท่านั้น โปรดกำหนดค่า Network Adapter แต่ละตัวตามกล้องแต่ละตัว เช่น หากคุณมีกล้องเชื่อมต่อสองตัว ให้กำหนดค่าทีละตัวตามลำดับ และอ้างอิงตารางสำหรับ Ethernet Adapter 1 และ 2 ห้ามเปลี่ยนการตั้งค่าบน Network Adapter ที่ไม่มีกล้องเชื่อมต่ออยู่

  • คลิกขวาที่ Ethernet Adapter ที่อยู่เหนือกล้องที่เชื่อมต่อ

  • คลิก “NIC Settings”

  • เปิดใช้งาน Jumbo Frame

  • ตั้งค่า Receive Buffers เป็นค่าสูงสุด

  • ตั้งค่า Transmit Buffers เป็นค่าสูงสุด

  • คลิก “Open” ที่ “Internet Protocol Properties”

  • กำหนดค่า Network Adapter ตามตารางด้านล่าง

การกำหนดค่า IP แบบ Static ที่แนะนำสำหรับ Ethernet Adapter แต่ละตัว

นี่คือตัวอย่างการกำหนดค่าด้วย IP แบบ Static โปรดสังเกต IP ของ Ethernet Adapter และกล้องที่เกี่ยวข้อง

หมายเลข Ethernet Adapter IP ของ Ethernet Adapter Subnet Mask Gateway เชื่อมต่อกับกล้อง IP ของกล้อง
1 10.0.1.1 255.255.255.0 10.0.1.1 1 10.0.1.10
2 10.0.2.1 255.255.255.0 10.0.2.1 2 10.0.2.10
3 10.0.3.1 255.255.255.0 10.0.3.1 3 10.0.3.10
4 10.0.4.1 255.255.255.0 10.0.4.1 4 10.0.4.10

การตั้งค่า IP แบบ Static บนกล้อง

ตรวจสอบให้แน่ใจว่ากล้อง Lynx ของคุณเชื่อมต่ออยู่ หากคุณเชื่อมต่อกล้องหลังจากเปิดแอปพลิเคชันแล้ว ให้เลื่อนเมาส์ไปที่เมนู “GigE” และคลิกปุ่มรีเฟรช

กระบวนการนี้ต้องทำซ้ำสำหรับกล้อง Lynx ที่เชื่อมต่อทุกตัวที่คุณได้ตั้งค่า IP แบบ Static

โปรดทราบว่าคุณต้องตั้งค่า IP แบบ Static บนกล้องตัวที่ 1 ก่อน จากนั้นจึงตั้งค่า Network Card ตัวที่ 1 ตามลำดับ เมื่อดำเนินการกับตัวที่ 1 เสร็จแล้วจึงดำเนินการกับตัวที่ 2 เป็นต้น หมายเลขที่อ้างอิงไม่ใช่ชื่อจริงของ Network Adapter เช่น “Ethernet 2” แต่ใช้เพื่อการอธิบายเท่านั้น

  • คลิกขวาที่กล้องในรายการและคลิก “Modify IP”

  • เปลี่ยนการเลือกจาก DHCP หรือ LLA เป็น Static IP

  • กำหนดค่า IP Address และ Subnet Mask ตามคำอธิบายด้านล่าง

  • IP จะต้องแตกต่างกันสำหรับกล้องแต่ละตัว

การกำหนดค่า IP แบบ Static ที่แนะนำสำหรับกล้อง

หมายเลขกล้อง IP Subnet Mask Gateway
1 10.0.1.10 255.255.255.0 10.0.1.1
2 10.0.2.10 255.255.255.0 10.0.2.1
3 10.0.3.10 255.255.255.0 10.0.3.1
4 10.0.4.10 255.255.255.0 10.0.4.1
