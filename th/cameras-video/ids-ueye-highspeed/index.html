วิธีการติดตั้งและเตรียมใช้งานกล้องความเร็วสูง USB

บทความสนับสนุนนี้จะอธิบายวิธีการติดตั้งและเตรียมใช้งานกล้อง USB 2.0 หรือ 3.0 สำหรับใช้งานใน Swing Catalyst

กล้อง USB ต่อไปนี้ได้รับการรองรับในเวอร์ชันล่าสุดของ Swing Catalyst:

USB 2.0:

  • IDS uEye UI-1220LE-C-HQ

  • IDS uEye UI-1220LE-M-HQ

USB 3.0:

  • IDS uEye UI-3220CP-C-HQ

  • IDS uEye UI-3240LE

  • IDS uEye UI-3240CP Rev. 2

หมายเหตุ: คุณไม่สามารถใช้กล้อง USB 3.0 และ 2.0 ร่วมกันได้ เนื่องจากในกรณีส่วนใหญ่จะทำให้เกิดการสูญเสียเฟรม เว้นแต่คุณจะมีตัวควบคุมโฮสต์แยกต่างหากสำหรับ USB 2.0 และ 3.0

ข้อกำหนดด้านฮาร์ดแวร์และการติดตั้ง

USB 3.0:

ในการใช้งานกล้อง USB 3.0 คุณต้องมีคอมพิวเตอร์ที่มีพอร์ต USB 3.0 ทั้งนี้ควรทราบว่าคอมพิวเตอร์บางรุ่นอาจไม่สามารถใช้อัตราเฟรมสูงสุดของกล้อง USB 3.0 ได้ เนื่องจากกล้องเหล่านี้ในปัจจุบันถูกจำกัดด้วยแบนด์วิดท์สูงสุดที่มีบนพอร์ต USB 3.0

ในหลายกรณี จำเป็นต้องใช้ตัวควบคุม USB 3.0 เฉพาะที่ผู้ผลิตจัดเตรียมไว้เพื่อให้ได้อัตราเฟรมที่เหมาะสมที่สุดบนกล้องบางรุ่น

ดู: อุปกรณ์ USB3 ที่แนะนำ

ในกรณีที่เกิดปัญหานี้ แนะนำให้ลด “pixel clock” ลง ซึ่งจะทำให้อัตราเฟรมสูงสุดลดลงด้วย

กล้อง USB ไม่จำเป็นต้องใช้แหล่งจ่ายไฟภายนอก และสายเคเบิลที่ต้องใช้มีเพียงสาย USB 3.0 ที่ได้รับการรับรองสำหรับ machine vision เราไม่แนะนำให้ใช้สายที่ยาวเกิน 5 เมตร ทั้งสำหรับ USB 3 และ USB 2

สำหรับระยะทางที่ยาวกว่านั้น จำเป็นต้องใช้สาย Active USB repeater และสำหรับกล้อง USB 3.0 จะต้องได้รับการรับรองว่าสามารถใช้งานกับกล้อง machine vision ได้

สำหรับกล้อง USB 2.0 สายใดก็ได้ที่เป็น USB A ต่อ Mini-B จะสามารถใช้งานได้ถึง 5 เมตร

การติดตั้งซอฟต์แวร์

ก่อนที่คุณจะสามารถใช้งานกล้อง USB ได้ คุณต้องติดตั้งไดรเวอร์ก่อน โดยสามารถดาวน์โหลดไดรเวอร์ที่จำเป็นได้จากเว็บไซต์ต่อไปนี้:

https://www.swingcatalyst.com/drivers

หลังจากดาวน์โหลดไดรเวอร์แล้ว (เลือก 32 บิต หรือ 64 บิต ขึ้นอยู่กับเวอร์ชัน Windows ของคุณ) กรุณาเรียกใช้ไฟล์และทำตามคำแนะนำบนหน้าจอ

การกำหนดค่าและการใช้งาน
