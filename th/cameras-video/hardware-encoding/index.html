การใช้เอนโคเดอร์วิดีโอฮาร์ดแวร์ใหม่เพื่อเร่งความเร็วในการประมวลผลวิดีโอ

ใน Swing Catalyst 9.3 ขึ้นไป มีการเพิ่มการรองรับการใช้การ์ดกราฟิกของคอมพิวเตอร์เพื่อเร่งความเร็วในการประมวลผลวิดีโอ

คุณสมบัตินี้ใช้ประโยชน์จากชิปบนการ์ดกราฟิกที่ออกแบบมาเฉพาะสำหรับการเข้ารหัสวิดีโอ ช่วยให้ CPU ไม่ต้องรับภาระงานที่ใช้ทรัพยากรการประมวลผลสูงนี้ ขึ้นอยู่กับการ์ดกราฟิกและ CPU ที่ใช้งาน สิ่งนี้อาจช่วยปรับปรุงเวลาในการเข้ารหัสวิดีโอได้อย่างมีนัยสำคัญ อย่างไรก็ตาม อาจเป็นไปได้เช่นกันว่าเวลาในการเข้ารหัสจะแย่ลงเมื่อเปลี่ยนการตั้งค่าเหล่านี้

เอนโคเดอร์มาตรฐานคือ CPU MPEG-4

โปรดใช้ฟีเจอร์เปรียบเทียบประสิทธิภาพที่มีอยู่ในตัวเพื่อดูว่าเอนโคเดอร์ใดทำงานได้ดีที่สุดสำหรับคุณ

การ์ดกราฟิกที่รองรับ (เอนโคเดอร์ h264):

  • NVIDIA NVENC: การ์ดซีรีส์ GeForce ที่แนะนำ เช่น ซีรีส์ 1070, 1080, 2060, 2070, 2080

  • Intel QuickSync: CPU Intel รุ่นใหม่ส่วนใหญ่มีฮาร์ดแวร์เฉพาะสำหรับการเข้ารหัสวิดีโอ CPU ที่แนะนำสอดคล้องกับข้อกำหนดคอมพิวเตอร์ที่เราแนะนำ*

  • CPU Intel บางรุ่นไม่มีชิปกราฟิกในตัว จึงไม่รองรับ Intel Quicksync

รายชื่อ CPU Intel ที่รองรับ Quicksync: https://ark.intel.com/content/www/us/en/ark/search/featurefilter.html?productType=873&0_QuickSyncVideo=True

การ์ดกราฟิก AMD ไม่ได้รับการรองรับ

การรันการเปรียบเทียบประสิทธิภาพเอนโคเดอร์

  • NVIDIA NVENC

  • Intel QuickSync (QSV)

  • MPEG4 (CPU)
