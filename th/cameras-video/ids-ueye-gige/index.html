วิธีการตั้งค่ากล้อง IDS uEye GigE ให้ทำงานร่วมกับ Swing Catalyst

สำหรับการเตรียมตัวกล้อง USB โปรดดูบทความนี้: ids-ueye-usb.md

หมายเหตุ: บทความนี้ถือว่าคุณได้ติดตั้งไดรเวอร์ uEye ที่พบได้ที่: https://www.swingcatalyst.com/drivers

บทความนี้ครอบคลุมการตั้งค่าที่อยู่ IP ของทั้งกล้องและการ์ดเครือข่าย

หมายเหตุ: Swing Catalyst ไม่รองรับ IDS AOI (area of interest) สำหรับกล้อง IDS

อะแดปเตอร์เครือข่ายที่รองรับและการกำหนดค่า:

โปรดดู: gige-network-setup.md

หมายเหตุ สำคัญสำหรับการแสดงออก: หากคุณมีการ์ดเครือข่าย Intel โปรดดาวน์โหลดและติดตั้งไดรเวอร์ Intel เนื่องจากจะให้ตัวเลือกในการตั้งค่าอัตรา interrupt moderation ซึ่งอาจไม่มีให้ใช้งานด้วยไดรเวอร์ของ Windows

การตั้งค่ากล้อง IDS uEye GigE ของคุณ

ขั้นตอน:

ก่อนดำเนินการ ให้ติดตั้งไดรเวอร์ IDS uEye จากนั้นค้นหาและเปิดแอปพลิเคชัน IDS Camera Manager (สามารถพบได้ที่: C:\ProgramData\Microsoft\Windows\Start Menu\Programs\IDS)

แอปพลิเคชัน IDS Camera Manager:

สังเกตคำเตือนที่ด้านล่างของแอปพลิเคชัน มีคำเตือนหลายรายการที่อาจปรากฏขึ้นเนื่องจากการตั้งค่าที่อยู่ IP ไม่ถูกต้อง หรือเกี่ยวกับเฟิร์มแวร์ของกล้อง

ตัวอย่าง:

หมายเหตุ เกี่ยวกับการกำหนดค่าที่อยู่ IP และคำแนะนำของเรา**

**

คำแนะนำของเราคือให้มีการ์ดเครือข่ายหรืออินเทอร์เฟซเครือข่ายเฉพาะสำหรับกล้องแต่ละตัว อย่างไรก็ตาม สำหรับรุ่น IDS UI-3220 คุณสามารถใช้กล้องสองตัวต่อพอร์ตเครือข่ายหนึ่งพอร์ตโดยใช้สวิตช์เครือข่าย (ดูการใช้สวิตช์เครือข่าย)

การเตรียมตัว IP ที่เราแนะนำ:

กล้องแต่ละตัวและการ์ด Ethernet (หรือที่เรียกว่า NIC) ควรได้รับการกำหนดค่า IP แบบสถิตบน subnet ที่แตกต่างกัน (และ subnet mask)

ตัวอย่าง:

กล้องบนการ์ดเครือข่าย 1: nic ip: 10.0.1.1 cam ip: 10.0.1.10 … 10.0.1.20 subnet mask:255.255.255.0

กล้องบนการ์ดเครือข่าย 2: nic ip: 10.0.2.1 (subnet ต่างจาก nic1) cam ip: 10.0.2.10 … 10.0.2.20 (subnet ต่างจาก nic1) subnet mask: 255.255.255.0

การเปิดใช้งาน uEye network service

หมายเหตุ: หากคุณใช้กล้องประเภทต่างๆ จากผู้ผลิตหลายราย การเปิดใช้งาน uEye network service อาจทำให้เกิดปัญหาเมื่อใช้กล้องจากผู้ผลิตรายอื่น

คลิกที่ ETH network service

เลือกอะแดปเตอร์เครือข่ายที่คุณต้องการกำหนดค่า (ในกรณีนี้คืออะแดปเตอร์พอร์ตคู่)

กราฟิกของการ์ดเครือข่ายจะเป็นสีเทา เนื่องจากยังไม่ได้ตั้งค่าอย่างถูกต้อง จำเป็นต้องเปิดใช้งาน uEye network service เพื่อให้กล้องมองเห็นได้บนเครือข่าย

ตรวจสอบให้แน่ใจว่าได้ตั้งค่าที่อยู่ IP และ subnet mask ตามที่แนะนำ (ดูด้านบน) จากนั้นคลิก Enable uEye network service และคลิก Apply changes (ตอนนี้คุณได้ตั้งค่าที่อยู่ IP แบบสถิตสำหรับอะแดปเตอร์พอร์ตคู่หนึ่งตัวแล้ว!)

การเตรียมตัว IP แบบอัตโนมัติ (สำหรับ IP แบบกำหนดเองดูด้านล่าง)

หากต้องการใช้การกำหนดค่า IP แบบอัตโนมัติ ให้คลิกที่ Automatic ETH configuration และคลิก OK

IDS Camera Manager จะตั้งค่าที่อยู่ IP บนการ์ดเครือข่ายและกล้องโดยอัตโนมัติให้คุณ

หมายเหตุ: เราแนะนำการเตรียมตัว IP แบบกำหนดเองเมื่อใช้กล้องหลายตัว

การเตรียมตัว IP แบบกำหนดเอง

กลับมาที่ IDS Camera Manager ขณะนี้คุณควรเห็นกล้องที่แสดงรายการอยู่ เนื่องจากคุณได้ตั้งค่าที่อยู่ IP แบบสถิตของอะแดปเตอร์เครือข่ายไว้ก่อนหน้านี้ ตอนนี้คุณจำเป็นต้องตั้งค่า IP แบบสถิตของกล้อง เพื่อให้อะแดปเตอร์เครือข่ายและกล้องสามารถสื่อสารกันได้อย่างถูกต้อง

ทำเครื่องหมายในช่อง Expert Mode ตามที่แสดงที่นี่:

สังเกตคำเตือนด้านบนที่แสดงเป็นสีแดง

คลิก Manual ETH configuration:

ในภาพหน้าจอด้านบน ที่อยู่ IP ของกล้องถูกตั้งค่าเป็น 10.0.1.10 (การ์ดเครือข่ายของเราคือ 10.0.1.1) ป้อนค่าตามภาพหน้าจอด้านบนและคลิก OK

หมายเหตุ การตั้งค่าที่อยู่ IP แบบสถิตไม่ใช่สิ่งจำเป็น แต่แนะนำอย่างยิ่ง เนื่องจากการกำหนดค่า IP แบบอัตโนมัติอาจก่อให้เกิดปัญหาจากความขัดแย้งของที่อยู่ IP เช่น ที่อยู่ IP เดียวกันถูกใช้งานที่อื่น เราแนะนำอย่างยิ่งให้ตั้งค่าแบบสถิตสำหรับการติดตั้งในสตูดิโอทั้งหมด

ทำซ้ำขั้นตอนเดิมสำหรับกล้องและ NIC อื่นๆ ตามการกำหนดค่า IP ที่เราแนะนำด้านบน

การกำหนดค่าอะแดปเตอร์เครือข่ายสำหรับใช้กับกล้อง IDS uEye

เมื่อคุณได้ตั้งค่าที่อยู่ IP แบบสถิตสำหรับทั้งกล้องและการ์ดเครือข่ายแล้ว ต่อไปเราจะกำหนดค่าอะแดปเตอร์เครือข่ายเพื่อการแสดงออกที่ดีที่สุด

จาก Control Panel\Network and Internet\Network Connections ดับเบิลคลิกที่อะแดปเตอร์ที่คุณต้องการกำหนดค่า ในกรณีของเราคือ Ethernet 4, Intel (PRO/1000 PT Dual port)

ดับเบิลคลิกที่อะแดปเตอร์เครือข่ายที่คุณต้องการกำหนดค่า

คลิกแท็บ Advanced หมายเหตุ: การกำหนดค่าจะแตกต่างกันสำหรับอะแดปเตอร์เครือข่ายแต่ละตัว และขึ้นอยู่กับไดรเวอร์ โปรดอ้างอิงเอกสารประกอบของการ์ดเครือข่ายของคุณสำหรับข้อมูลเฉพาะเกี่ยวกับวิธีการเปลี่ยนการตั้งค่าที่แสดงด้านล่าง

ตรวจสอบให้แน่ใจว่า Interrupt Moderation เปิดใช้งานอยู่ และ Interrupt Moderation Rate ถูกตั้งค่าเป็น Extreme

หากคุณไม่มีตัวเลือก Extreme ให้ตั้งค่าเป็น High

ในบางกรณี การปิด interrupt moderation อาจช่วยได้หากอัตรา interrupt moderation ค่าสูงไม่มีผล แต่ตราบใดที่คุณมีการ์ดเครือข่ายที่แนะนำ ตัวเลือก High และ Extreme ควรจะมีให้ใช้งาน การเปิดใช้งาน interrupt moderation มีความสำคัญอย่างยิ่งในการลดการใช้งาน CPU เมื่อจัดการกับแพ็กเกจจำนวนมาก โดยเฉพาะกับกล้องความละเอียดสูงหรือ FPS สูง

อัตรา interrupt moderation:

เปิดใช้งานการรองรับ Jumbo Packets (ตั้งค่าเป็น 9014 Bytes):

Receive Buffers:

แนะนำให้ตั้งค่านี้ให้สูงที่สุดเท่าที่จะทำได้ ซึ่งสามารถช่วยหลีกเลี่ยงเฟรมที่หล่นหายเมื่อใช้กล้องหลายตัวและหรือกล้อง GigE ความละเอียดสูง

การใช้สวิตช์เครือข่าย:

หากคุณต้องการใช้สวิตช์เครือข่าย สิ่งสำคัญคือสวิตช์ต้องรองรับ Jumbo Frames ขนาด 9KB และอะแดปเตอร์เครือข่ายต้องได้รับการกำหนดค่าให้ใช้ Jumbo Frames ขนาด 9KB อย่างไรก็ตาม ในบางกรณีสวิตช์บางตัวอาจทำงานได้ไม่ดีกับขนาดเฟรม 9KB ในกรณีเหล่านั้น แนะนำให้ลดจาก 9KB ลงมาเป็นค่าที่ต่ำกว่าและทดสอบการเตรียมตัวใหม่อีกครั้ง

การใช้กล้องใน Swing Catalyst

หลังจากกำหนดค่าที่อยู่ IP และอะแดปเตอร์เครือข่ายตามคำแนะนำด้านบนแล้ว คุณสามารถเริ่ม Swing Catalyst และกล้องควรจะปรากฏในรายการกล้อง

ตั้งค่ามุมของกล้องและเปิดใช้งานกล้อง จากนั้นคลิก Configure

ตรวจสอบให้แน่ใจว่า pixel clock อยู่ที่ค่าสูงสุด (หรือลดลงหากเฟรมหล่นหาย)

ตั้งค่า shutter speed และ Gain (โปรดทราบว่าค่าเหล่านี้อาจเปลี่ยนแปลงได้มากขึ้นอยู่กับความต้องการ ประเภทของกล้อง และปริมาณแสงที่มี)

การแก้ไขปัญหากล้อง IDS

หากเฟรมหล่นหายหรือมีปัญหาการซิงค์กับกล้อง IDS uEye GigE ของคุณ ให้ใช้ยูทิลิตี uEye Cockpit

คลิก Live Video

คลิกไอคอนเล่น จากนั้นคลิกที่ไอคอนประแจ

สังเกตการใช้งานแบนด์วิดท์ที่แสดงอยู่ ภายใต้แท็บ Camera ให้เพิ่ม Pixel clock และทำเครื่องหมายในช่อง Max ใต้ Frame rate (Freerun) จากนั้นลดเวลาเปิดรับแสง (shutter speed) ลง

หลังจากตั้งค่ากล้องให้สตรีมแบบสดแล้ว คลิกที่ มุมมอง -> Performance Overview

มุมมอง Host Performance มีประโยชน์มากในการแก้ไขปัญหาหากคุณมีปัญหาด้านความเสถียรและเฟรมที่หล่นหาย

การใช้แถบสถานะใน uEye Cockpit เพื่อระบุเฟรมที่หล่นหายหรือปัญหาการเชื่อมต่อขณะสตรีมวิดีโอ:

ความละเอียดของกล้อง เฟรมที่ได้รับ เฟรมที่แสดง เฟรมที่ล้มเหลว และจำนวนครั้งที่พยายามเชื่อมต่อใหม่ตามภาพหน้าจอ:

Transfer OK และ Frame rate สามารถเห็นได้ในแถบสถานะเช่นกัน:

อัปเดตล่าสุด: 2023-12-19 | ดูบนเว็บไซต์สนับสนุนทางการ
