คอมพิวเตอร์แสดงหน้าจอสีน้ำเงิน (Bluescreen) เมื่อเชื่อมต่อ USB ดองเกิลสิทธิ์การใช้งาน Halcon

มีปัญหาเกี่ยวกับ USB ไดรเวอร์สำหรับดองเกิลสิทธิ์การใช้งานที่ใช้กับลูกค้า Halcon โดยดองเกิลนี้เป็น USB “Flexera” สีเขียว

ไดรเวอร์ที่รวมมากับ Halcon 12 ทำให้ Windows หยุดทำงานและแสดงหน้าจอสีน้ำเงิน

เพื่อหลีกเลี่ยงหน้าจอสีน้ำเงิน เราแนะนำให้ลบไดรเวอร์เก่าออกหากติดตั้งไว้ ไม่ว่าจะโดยการถอนการติดตั้ง Halcon หรือลบไดรเวอร์ด้วยตนเอง

ระบบที่ได้รับผลกระทบ:

  • Windows 10 เวอร์ชัน 2004 Build >= 19041.423, 20H2, 21H1 หรือ 21H2

  • Windows 11

เราแนะนำให้ถอนการติดตั้ง Halcon แล้วปฏิบัติตามคำแนะนำวิธีติดตั้งไดรเวอร์ใหม่ในบทความสนับสนุนนี้

การถอนการติดตั้ง Halcon

  • เปิด Add or Remove programs

  • ในส่วน Apps & features ให้ค้นหา “halcon”

  • คลิกรายการที่ปรากฏในรายการ แล้วคลิก “Uninstall” และ “Uninstall”

  • คลิก “Yes” เพื่อดำเนินการถอนการติดตั้ง Halcon รอให้โปรแกรมถอนการติดตั้ง Halcon เริ่มทำงาน จากนั้นคลิก “Uninstall” เพื่อลบ Halcon

ตัวเลือกทางเลือก: การลบไดรเวอร์ USB ดองเกิล Halcon ด้วยตนเอง

ตัวเลือกนี้สามารถใช้ได้หากคุณไม่ต้องการรีบูตคอมพิวเตอร์ หรือด้วยเหตุผลบางอย่างไม่ต้องการติดตั้ง Halcon ใหม่ สำหรับวัตถุประสงค์ส่วนใหญ่ควรใช้ตัวเลือก “การถอนการติดตั้ง Halcon” แทน

เมื่อไดรเวอร์ถูกติดตั้ง ไดรเวอร์จะถูกจัดเก็บไว้ในที่เก็บไฟล์ Windows DriverStore ซึ่งอยู่ที่:

C:\Windows\System32\DriverStore\FileRepository

โดยปกติในการลบไดรเวอร์ คุณจะต้องไปที่ Device Manager แล้วถอนการติดตั้งอุปกรณ์และเลือกลบไดรเวอร์ แต่เนื่องจากการเสียบ USB ดองเกิลทำให้ Windows หยุดทำงาน เราจึงต้องลบออกด้วยตนเอง Windows จะค้นหาไดรเวอร์ที่เหมาะสม (ใหม่) เมื่อเราติดตั้งไดรเวอร์ใหม่

วิธีลบไดรเวอร์อุปกรณ์โดยใช้ pnputil

คำแนะนำด้านล่างใช้ “เครื่องหมายคำพูด” ล้อมรอบข้อความที่ควรพิมพ์ลงในบรรทัดคำสั่งโดยไม่ต้องใส่เครื่องหมายคำพูด

  • เปิด Command Prompt

  • ใน Command Prompt ให้พิมพ์ “pnputil -e” เพื่อแสดงรายการไดรเวอร์ที่ติดตั้งทั้งหมด

  • มองหาไดรเวอร์ที่ตอนต้นของผลลัพธ์ที่มีชื่อแพ็กเกจประกอบด้วย Sentinel HASP หรือ SafeNet

  • ลบแต่ละรายการโดยรันคำสั่ง “pnputil /delete-driver drivername.inf /uninstall”

  • ตัวอย่างการลบไดรเวอร์ที่มีชื่อผู้เผยแพร่ oem53.inf ให้พิมพ์: “pnputil /delete-driver oem53.inf /uninstall” แล้วกด Enter

โปรดทราบว่าผลลัพธ์จาก pnputil ในกรณีนี้มาจากระบบที่ทำงานได้ปกติซึ่งมีไดรเวอร์ที่อัปเดตแล้ว (ไม่มีภาพหน้าจอของไดรเวอร์เก่า)

สำหรับระบบที่ไม่ทำงาน ควรแสดงรายการไดรเวอร์ที่คล้ายกันแต่มีผู้ให้บริการแพ็กเกจไดรเวอร์ที่แตกต่างกัน

การติดตั้งไดรเวอร์ USB ดองเกิลสิทธิ์การใช้งาน Halcon ใหม่

คำแนะนำด้านล่างใช้ “เครื่องหมายคำพูด” ล้อมรอบข้อความที่ควรพิมพ์ลงในบรรทัดคำสั่งโดยไม่ต้องใส่เครื่องหมายคำพูด

  • ดาวน์โหลดและแตกไฟล์ไดรเวอร์ใหม่ คลิกขวาที่ไฟล์ zip ที่ดาวน์โหลดมาแล้วคลิก “Extract All” และ “Extract”

  • เปิด Command Prompt (หากคุณปิดไปก่อนหน้านี้)

  • คัดลอกที่อยู่ของโฟลเดอร์ไดรเวอร์ที่แตกไฟล์แล้ว เช่น C:\Users\stian\Downloads\haspdinst_8.53

  • ใน Command Prompt พิมพ์ “cd” แล้ววางที่อยู่ของไดรเวอร์ที่แตกไฟล์แล้ว เช่น “cd C:\Users\stian\Downloads\haspdinst_8.53”

  • พิมพ์ “haspdinst.exe /install” ลงใน Command Prompt แล้วกด Enter

  • การติดตั้งจะดำเนินการต่อไป
