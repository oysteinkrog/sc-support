วิธีการตั้งค่า Halcon เพื่อใช้งานร่วมกับ Swing Catalyst

การเปิดตัว Swing Catalyst 6.0 นำมาซึ่งการรองรับมาตรฐาน machine vision ที่พบบ่อยที่สุดสามมาตรฐาน

  USB3 Vision                      GigE Vision                             GENiCAM

ก่อนที่คุณจะเริ่มต้น

บทความนี้ส่วนใหญ่ครอบคลุมการติดตั้ง Halcon การติดตั้งใบอนุญาต และการตั้งค่าเบื้องต้นของกล้อง Ximea USB3 เราไม่สามารถรับประกันความเข้ากันได้กับเวอร์ชันที่ใหม่กว่า และ SwingCatalyst รองรับเฉพาะ Halcon 12 เท่านั้น

สำหรับข้อมูลเพิ่มเติมเกี่ยวกับวิธีการตรวจสอบว่ากล้องของคุณรองรับ Halcon หรือไม่ โปรดดูที่: วิธีค้นหาว่ากล้องของคุณรองรับมาตรฐานใดสำหรับการใช้งานร่วมกับ Halcon

WARNING

SwingCatalyst รองรับเฉพาะ HALCON เวอร์ชัน 12 เท่านั้น

  • Halcon 12 รองรับ: GenAPI v2.4.1

ไดรเวอร์ดองเกิลใบอนุญาต USB ไม่เข้ากันกับ Windows 10 และ 11!

เมื่อคุณติดตั้ง Halcon สิ่งสำคัญมากคือต้องยกเลิกการเลือก “Install Driver for USB Dongles” ระหว่างการติดตั้ง มิฉะนั้นคอมพิวเตอร์ของคุณจะขัดข้องเมื่อเริ่มต้นระบบ

สำหรับรายละเอียดวิธีการติดตั้งไดรเวอร์ USB ใหม่ โปรดดูบทความสนับสนุนของเรา:

  • คอมพิวเตอร์แสดงหน้าจอสีน้ำเงินเมื่อเชื่อมต่อดองเกิลใบอนุญาต Halcon USB

โปรดดูบทความที่เกี่ยวข้องกับกล้องของคุณเพื่อกำหนดค่าใน SwingCatalyst หลังจากติดตั้ง Halcon แล้ว สำหรับการกำหนดค่าเฉพาะของผู้จำหน่าย

ความต้องการด้านฮาร์ดแวร์:

  • ดองเกิลรองรับกล้องแบบ Universal หรือใบอนุญาตที่ผูกกับการ์ดเครือข่าย

  • กล้อง (หนึ่งตัวหรือมากกว่า) ที่รองรับมาตรฐาน USB3 Vision, GigE Vision หรือ GenICam

  • พอร์ต USB สำรองสำหรับดองเกิลใบอนุญาต

โปรดตรวจสอบให้แน่ใจว่าฮาร์ดแวร์ของคุณเข้ากันได้กับคำแนะนำของผู้ผลิต

หมายเหตุ: การกำหนดค่ากล้องเฉพาะของผู้ผลิตสามารถพบได้ที่ส่วนล่างของบทความนี้

ข้อมูลเพิ่มเติม

  • ข้อมูล Ximea USB3 Vision: http://www.ximea.com/en/usb3-vision-camera/usb3zone

  • ข้อมูล Point Grey USB3 Vision: http://www.ptgrey.com/usb3-vision-cameras

  • ข้อมูล Basler USB3 Vision: http://www.baslerweb.com/en/support/knowledge-base/frequently-asked-questions

  • GenICam (Generic Interface for Cameras): http://www.emva.org/standards-technology/genicam/

ความต้องการด้านซอฟต์แวร์

  • ไฟล์ใบอนุญาต Halcon คุณควรได้รับไฟล์นี้ทางอีเมล

  • โปรดตรวจสอบให้แน่ใจว่าคุณกำลังใช้งาน Halcon เวอร์ชันล่าสุดที่ติดตั้งไว้ หากคุณได้รับคำเตือนใน SwingCatalyst โปรดติดต่อฝ่ายสนับสนุนเพื่อขอความช่วยเหลือ

การติดตั้ง Halcon

  • สามารถพบ Halcon runtime ได้ในหน้าดาวน์โหลดของเรา หรือสามารถดาวน์โหลดโดยตรงจากที่นี่

  • เมื่อดาวน์โหลดแล้ว คลิกขวาที่ไฟล์และเลือก “Extract All”

  • เปิดโฟลเดอร์ที่แตกไฟล์แล้วเรียกใช้งานตัวติดตั้ง

  • เปิดตัวติดตั้งและทำตามคำแนะนำบนหน้าจอพร้อมกับคำแนะนำทีละขั้นตอนด้านล่าง

  • เลือก “Install x64 version”

  • จาก “Choose Components” คุณสามารถยกเลิกการเลือกส่วนประกอบทั้งหมด ยกเว้น “Runtime x64”

  • ในส่วน “Additional Drivers” โปรดตรวจสอบให้แน่ใจว่ายกเลิกการเลือก “Install driver for USB dongles” ซึ่งเป็นสิ่งสำคัญ

  • หากคุณมีกล้อง GigE ให้ตรวจสอบให้แน่ใจว่าเลือก “Install MVTec GigE Vision Streaming Filter”

  • สำหรับการติดตั้งไฟล์ใบอนุญาต ให้เลือก “I have a license file that should be installed” และระบุตำแหน่งของไฟล์ใบอนุญาตที่คุณควรได้รับจากตัวแทนฝ่ายขายหรือฝ่ายสนับสนุน

  • ดำเนินการตามคำแนะนำบนหน้าจอต่อไป

WARNING: โปรดยกเลิกการเลือก “Install driver for USB dongles” หากใช้งาน Windows 10 หรือ 11

ตรวจสอบให้แน่ใจว่าติดตั้ง GigE Vision Filter (หมายเหตุ: สิ่งนี้จำเป็นหากคุณมีกล้อง GigE)

ค้นหาไฟล์ license.dat ที่คุณได้รับทางอีเมลแล้วคลิก Next

ดำเนินการติดตั้งให้เสร็จสิ้น หากได้รับแจ้งให้รีบูต ให้คลิก Yes
