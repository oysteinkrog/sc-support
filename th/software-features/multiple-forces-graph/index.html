การใช้งานกราฟแรงหลายรายการ

บทความนี้ครอบคลุมฟังก์ชันการทำงานที่มีอยู่ในเวอร์ชัน 10.0 ขึ้นไป

  • ซอฟต์แวร์ที่รองรับ: Motion Catalyst และ Swing Catalyst

  • เวอร์ชัน: 10.0 - 10.2

  • ใช้งานได้เฉพาะกับเลย์เอาต์ Data-Centric และ Detailed Data เท่านั้น

  • ฮาร์ดแวร์ที่จำเป็น: แผ่นวัดแรง / Motion Plate / Dual Motion Plate หรือการบันทึกที่มีข้อมูลแรง

ฉันใช้ซอฟต์แวร์เวอร์ชันใดอยู่?

บทความที่เกี่ยวข้อง:

  • การใช้งานไลบรารีกราฟใหม่

  • เฟสของกราฟแรง

กล่องข้อมูลกราฟแรงหลายรายการ

กล่องข้อมูลกราฟแรงหลายรายการเป็นกล่องข้อมูลที่มีฟังก์ชันการทำงานใหม่บางประการ

ยังคงทำงานในลักษณะเดียวกับกราฟที่มีอยู่เดิม คุณสามารถโต้ตอบกับกราฟได้ในแบบเดิม (ดูรายละเอียดในบทความข้างต้น “การใช้งานไลบรารีกราฟใหม่”)

คุณสมบัติที่น่าสังเกต ได้แก่:

  • มุมมองข้อมูลแบบรวม โดยแสดงข้อมูลแรงทั้งหมดในกล่องข้อมูลเดียว

  • คำอธิบายค่าเมื่อคลิกที่กราฟ โดยคำอธิบายจะติดตามตำแหน่งเคอร์เซอร์ของเมาส์

  • ความสามารถในการเปิด/ปิดการแสดงผลของแต่ละแหล่งข้อมูล

  • การเลือกแหล่งข้อมูลของคุณจะถูกจดจำแยกกันสำหรับเลย์เอาต์ Data Centric และ Detailed Data ตามลำดับ

  • รองรับการไฮไลต์เฟส

ตัวอย่างกล่องข้อมูลแรงหลายรายการในเลย์เอาต์ Detailed Data

ตัวอย่างจากเลย์เอาต์ Data Centric:

  • สังเกตว่าบางแหล่งข้อมูลถูกยกเลิกการเลือก การมองเห็นสามารถเปลี่ยนแปลงได้ง่ายโดยการสลับจากเมนูที่ไฮไลต์ด้วยลูกศรสีแดง

  • แหล่งข้อมูลที่ปิดอยู่จะแสดงสีที่หม่นกว่าเมื่อเทียบกับแหล่งข้อมูลที่เปิดใช้งาน

คำอธิบายค่า

การคลิกที่กราฟแต่ละรายการจะแสดงคำอธิบายของค่า ณ ตำแหน่งของเคอร์เซอร์เมาส์
