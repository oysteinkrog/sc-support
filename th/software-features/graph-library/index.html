การใช้งานไลบรารีกราฟ

บทนำ

บทความนี้มีจุดมุ่งหมายเพื่อแสดงฟีเจอร์ใหม่ที่รวมอยู่ในไลบรารีกราฟใหม่ที่มีใน Swing Catalyst (เวอร์ชัน 9.7 และใหม่กว่า)

ฟีเจอร์ที่รวมอยู่:

  • การซูมและการเลื่อนดูกราฟโดยใช้เมาส์ / แป้นพิมพ์

  • รองรับการแสดงข้อมูลรายบุคคลต่อแผ่นในการเตรียมตัวแบบ Dual Motion Plate / แผ่นวัดแรงคู่

  • ปรับปรุงประสิทธิภาพการเรนเดอร์อย่างมีนัยสำคัญ

รายละเอียด:

  • CTRL + เลื่อนเมาส์ เพื่อซูมเข้า / ออก ณ ตำแหน่งที่ตัวชี้เมาส์อยู่บนกราฟ

  • CTRL SHIFT + เลื่อนเมาส์ เพื่อเลื่อนดู (pan)

  • ดับเบิลคลิกเพื่อรีเซ็ตระดับการซูม

  • คลิกแล้วลากเพื่อซูม

มาดูฟังก์ชันการทำงานกัน!

ฟังก์ชันการซูม

คลิกและลาก

  • คลิกแล้วลากเพื่อเลือกส่วนที่ต้องการดูอย่างละเอียดมากขึ้น

Tip: ดับเบิลคลิกเมาส์เพื่อรีเซ็ตระดับการซูม

การซูมด้วย Ctrl + เลื่อนเมาส์

  • กด CTRL ค้างไว้ขณะเลื่อนเมาส์เพื่อซูมเข้า / ออกในข้อมูล

  • กด Shift ค้างไว้ขณะเลื่อนเมาส์เพื่อซูมตาม แกน X

Tip: หากต้องการรีเซ็ต ให้ดับเบิลคลิกเมาส์

การซูมตาม แกน X (Ctrl Shift + เลื่อนเมาส์):

การเลื่อนดู (Panning)

  • Ctrl Shift + เลื่อนเมาส์ เพื่อเลื่อนดู

การดูข้อมูลแผ่นรายบุคคล

  • Note: นี่คือฟังก์ชันเฉพาะของ Dual Motion Plate / แผ่นวัดแรงคู่

ด้วยแผ่นวัดแรงคู่ สามารถดูข้อมูลจากแต่ละแผ่นได้อย่างอิสระโดยคลิกที่ปุ่มตัวบ่งชี้แผ่นทางด้านซ้ายของไอคอนเฟือง แผ่นที่ถูกไฮไลต์จะแสดงว่ากำลังแสดงข้อมูลของแผ่นใด

ในตัวอย่างนี้เรากำลังดูข้อมูลรวม (กราฟบนสุด) แต่ยังดูข้อมูลจากแต่ละแผ่นได้อย่างอิสระด้วย (เท้าซ้ายและขวา):

ตัวเลือกการดูกราฟ

การคลิกที่ไอคอนเฟืองจะให้ตัวเลือกในการดูข้อมูล ตัวอย่างเช่น การแสดงข้อมูลในรูปแบบเปอร์เซ็นต์หรือ Newton (หรือปอนด์-ฟุต: lbf⋅ft หากเลือกระบบอิมพีเรียลในการตั้งค่าทั่วไป)

ปรับปรุงประสิทธิภาพ

ไลบรารีกราฟใหม่สามารถใช้การ์ดกราฟิกเพื่อเร่งความเร็วด้วยฮาร์ดแวร์ได้ ซึ่งหมายความว่าประสบการณ์การใช้งานของผู้ใช้จะตอบสนองได้ดีขึ้นอย่างมีนัยสำคัญโดยไม่มีต้นทุนที่มากนัก (ในแง่ของการใช้งาน CPU และหน่วยความจำ)
