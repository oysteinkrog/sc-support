ข้อมูลจำเพาะของคอมพิวเตอร์ที่แนะนำ

ข้อกำหนดคอมพิวเตอร์สำหรับ Swing Catalyst

หมายเหตุสำคัญ: Swing Catalyst ไม่สามารถใช้ได้กับ Mac OS (Arm Architecture) หรือ Windows 11 Arm

สรุปอย่างรวดเร็ว

เพื่อให้มั่นใจว่าการจับภาพและเล่นวิดีโอทำงานได้อย่างราบรื่น คอมพิวเตอร์ของคุณควรตรงตามข้อกำหนดพื้นฐานเหล่านี้:

  • แล็ปท็อปเกมเมอร์สมัยใหม่หรือคอมพิวเตอร์เดสก์ทอปที่มีประสิทธิภาพสูง

  • 32 GB ของหน่วยความจำ (RAM)

  • การ์ดกราฟิกสมัยใหม่ (NVIDIA RTX 3060 6GB หรือดีกว่า)

  • โปรเซสเซอร์ Intel หรือ AMD สมัยใหม่ที่มี 8 คอร์หรือมากกว่า

  • เราขอแนะนำอย่างยิ่งให้ใช้ซีรีส์ล่าสุดของ GPU NVIDIA เพื่อให้ได้เวลาการเข้ารหัสที่เร็วที่สุดและการประมวลผล MoCap ซีรีส์ล่าสุดในปัจจุบันคือ RTX 5060, 5070, 5080, 5090

ข้อกำหนดแล็ปท็อป

หากคุณใช้แล็ปท็อป เราขอแนะนำแล็ปท็อปเกมเมอร์ที่มีคุณสมบัติดังนี้:

  • หน่วยความจำ: 32 GB RAM

  • โปรเซสเซอร์: Intel i5, i7 หรือ i9 สมัยใหม่ (รุ่นที่ 9 หรือใหม่กว่า) ที่มีอย่างน้อย 8 คอร์

  • การ์ดกราฟิก: NVIDIA RTX 3060 (หรือใหม่กว่า) ที่มีหน่วยความจำเฉพาะอย่างน้อย 6GB

แนวทางการเชื่อมต่อกล้อง

  • ใช้เฉพาะสายเคเบิล USB ต้นฉบับและมีคุณภาพสูงที่มาพร้อมกับกล้องของคุณ หรือใช้สายเคเบิลที่ได้รับการรับรองโดยเครื่องวิจัยภาพอื่นๆ

  • เชื่อมต่อกล้องโดยตรงกับคอมพิวเตอร์ของคุณ (หลีกเลี่ยงฮับ USB หรือสายต่อขยาย)

  • สามารถเชื่อมต่อกล้อง USB ได้สูงสุดสองตัวพร้อมกัน

  • สำหรับกล้อง Ethernet (GigE) ตรวจสอบให้แน่ใจว่ามีช่อง PCI Express ว่างสำหรับการ์ดเครือข่ายเฉพาะหรือการ์ดเครือข่ายหลายตัว ขึ้นอยู่กับจำนวนกล้อง

คำแนะนำด้านฮาร์ดแวร์โดยละเอียด

โปรเซสเซอร์ที่แนะนำ

ตัวเลือก Intel (จากล่าสุดไปยังเก่าที่สุด)

รุ่นที่ 14 (ล่าสุด)

  • Intel Core i9-14900/14900K (ประสิทธิภาพที่ดีที่สุด)

  • Intel Core i7-14700KF (ประสิทธิภาพที่ยอดเยี่ยม)

  • Intel Core i5-14400F (ประสิทธิภาพดี)

รุ่นที่ 13

  • Intel Core i9-13900K/KF

  • Intel Core i7-13700K/KF

  • Intel Core i5-13600K/KF

รุ่นที่ 12

  • Intel Core i9-12900K

  • Intel Core i7-12700K

  • Intel Core i5-12600K

ตัวเลือก AMD

  • AMD Ryzen 9 9950X3D (16 cores, ประสิทธิภาพดีที่สุด)

  • AMD Ryzen 7 9800X3D (8 cores, ประสิทธิภาพดีมาก)

  • AMD Ryzen 9 7900X (12 cores, ประสิทธิภาพดีที่สุด)

  • AMD Ryzen 7 7700X (8 cores, ประสิทธิภาพดี)

  • AMD Ryzen 9 5900XT (16 cores, รุ่นก่อนหน้า, มีคุณค่าดี)

สำหรับ CPU AMD เราแนะนำให้ ซื้อการ์ดควบคุม USB 3 เพิ่มเติม เพื่อให้มีความเข้ากันได้ที่ดีที่สุด

หมายเหตุทางเทคนิค: โปรเซสเซอร์ของคุณควรสามารถให้ความเร็วที่ 3.8GHz หรือสูงกว่าเพื่อประสิทธิภาพที่ดีที่สุด ซอฟต์แวร์นี้ต้องใช้โปรเซสเซอร์ที่รองรับคำสั่ง AVX และ AVX2 (โปรเซสเซอร์สมัยใหม่ส่วนใหญ่รองรับสิ่งนี้)

การ์ดจอแนะนำ

เราแนะนำให้มี VRAM ที่ต่อพ่วงอย่างน้อย 6GB (ยิ่งมากยิ่งดี)

ชั้นสูง (ประสิทธิภาพพิเศษ)

  • RTX 5090 (ดีที่สุดที่มี)

  • RTX 4090

  • RTX 3090

  • RTX 4080

ชั้นสูง (ประสิทธิภาพยอดเยี่ยม)

  • RTX 5080

  • RTX 5070

  • RTX 4070

  • RTX 3080

ระดับกลาง (ประสิทธิภาพดี)

  • RTX 5060

  • RTX 3070

  • RTX 4060

ระดับเข้า (ขั้นต่ำที่แนะนำ)

  • RTX 3060

หมายเหตุ: การ์ดทั้งหมดที่ระบุไว้ข้างต้นตรงตามข้อกำหนดขั้นต่ำสำหรับซอฟต์แวร์ การ์ดระดับสูงกว่าจะให้ประสิทธิภาพที่ดีขึ้น โดยเฉพาะอย่างยิ่งเมื่อทำงานกับกล้องหลายตัวหรือวิดีโอความละเอียดสูง
