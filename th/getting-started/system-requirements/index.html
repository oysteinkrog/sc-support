ข้อกำหนดคอมพิวเตอร์สำหรับ SwingCatalyst

หมายเหตุสำคัญ: SwingCatalyst ไม่รองรับ Mac OS (สถาปัตยกรรม Arm) หรือ Windows 11 Arm

สรุปโดยย่อ

เพื่อให้การจับภาพวิดีโอและการเล่นกลับเป็นไปอย่างราบรื่น คอมพิวเตอร์ของคุณควรมีคุณสมบัติขั้นต่ำดังนี้:

  • แล็ปท็อปสำหรับเล่นเกมรุ่นใหม่ หรือคอมพิวเตอร์ตั้งโต๊ะที่มีประสิทธิภาพสูง

  • หน่วยความจำ (RAM) 32 GB

  • การ์ดจอรุ่นใหม่ (NVIDIA RTX 3060 6GB หรือดีกว่า)

  • โปรเซสเซอร์ Intel หรือ AMD รุ่นใหม่ที่มี 8 คอร์ขึ้นไป

  • เราแนะนำ อย่างยิ่ง ให้ใช้ GPU NVIDIA ซีรีส์ล่าสุดเพื่อความเร็วในการเข้ารหัสและการประมวลผล MoCap ที่เร็วที่สุด ขณะนี้ซีรีส์ล่าสุดคือ RTX 5060, 5070, 5080, 5090

ข้อกำหนดสำหรับแล็ปท็อป

หากคุณใช้แล็ปท็อป เราแนะนำแล็ปท็อปสำหรับเล่นเกมที่มีคุณสมบัติดังนี้:

  • หน่วยความจำ: RAM 32 GB

  • โปรเซสเซอร์: Intel i5, i7 หรือ i9 รุ่นใหม่ (รุ่นที่ 9 หรือใหม่กว่า) ที่มีอย่างน้อย 8 คอร์

  • การ์ดจอ: NVIDIA RTX 3060 (หรือใหม่กว่า) ที่มีหน่วยความจำเฉพาะอย่างน้อย 6GB

แนวทางการเชื่อมต่อกล้อง

  • ใช้เฉพาะสาย USB คุณภาพสูงของแท้ที่มาพร้อมกับกล้องของคุณ หรือสายที่ได้รับการรับรองสำหรับ machine vision เท่านั้น

  • เชื่อมต่อกล้องโดยตรงกับคอมพิวเตอร์ (หลีกเลี่ยงการใช้ USB hub หรือสายต่อขยาย)

  • สามารถเชื่อมต่อกล้อง USB ได้สูงสุดสองตัวในคราวเดียว

  • สำหรับกล้อง Ethernet (GigE) ให้ตรวจสอบว่ามีสล็อต PCI Express ว่างสำหรับการ์ดเน็ตเวิร์กเฉพาะ หรือหลายการ์ดเน็ตเวิร์กขึ้นอยู่กับจำนวนกล้อง

ข้อแนะนำฮาร์ดแวร์โดยละเอียด

โปรเซสเซอร์ที่แนะนำ

ตัวเลือก Intel (จากใหม่ที่สุดไปเก่าที่สุด)

รุ่นที่ 14 (ใหม่ที่สุด)

  • Intel Core i9-14900/14900K (การแสดงออกดีที่สุด)

  • Intel Core i7-14700KF (การแสดงออกยอดเยี่ยม)

  • Intel Core i5-14400F (การแสดงออกดี)

รุ่นที่ 13

  • Intel Core i9-13900K/KF

  • Intel Core i7-13700K/KF

  • Intel Core i5-13600K/KF

รุ่นที่ 12

  • Intel Core i9-12900K

  • Intel Core i7-12700K

  • Intel Core i5-12600K

ตัวเลือก AMD

  • AMD Ryzen 9 9950X3D (16 คอร์, การแสดงออกดีที่สุด)

  • AMD Ryzen 7 9800X3D (8 คอร์, การแสดงออกยอดเยี่ยม)

  • AMD Ryzen 9 7900X (12 คอร์, การแสดงออกดีที่สุด)

  • AMD Ryzen 7 7700X (8 คอร์, การแสดงออกดี)

  • AMD Ryzen 9 5900XT (16 คอร์, รุ่นก่อนหน้า, คุ้มค่าดี)

สำหรับ CPU ของ AMD เราแนะนำ อย่างยิ่ง ให้ซื้อการ์ดควบคุม USB 3 เพิ่มเติมเพื่อความเข้ากันได้ที่ดีที่สุด

หมายเหตุทางเทคนิค: โปรเซสเซอร์ของคุณควรสามารถทำงานที่ความเร็ว 3.8GHz ขึ้นไปเพื่อการแสดงออกที่ดีที่สุด ซอฟต์แวร์ต้องการโปรเซสเซอร์ที่รองรับคำสั่ง AVX และ AVX2 (โปรเซสเซอร์สมัยใหม่ส่วนใหญ่รองรับสิ่งนี้)

การ์ดจอที่แนะนำ

เราแนะนำให้มีหน่วยความจำ GPU เฉพาะ (VRAM) ขั้นต่ำ 6GB โดยยิ่งมากยิ่งดี

ระดับสูงสุด (การแสดงออกยอดเยี่ยมที่สุด)

  • RTX 5090 (ดีที่สุดในปัจจุบัน)

  • RTX 4090

  • RTX 3090

  • RTX 4080

ระดับสูง (การแสดงออกดีเยี่ยม)

  • RTX 5080

  • RTX 5070

  • RTX 4070

  • RTX 3080

ระดับกลาง (การแสดงออกดี)

  • RTX 5060

  • RTX 3070

  • RTX 4060

ระดับเริ่มต้น (ขั้นต่ำที่แนะนำ)

  • RTX 3060

หมายเหตุ: การ์ดทุกรุ่นที่ระบุไว้ข้างต้นตรงตามข้อกำหนดขั้นต่ำของซอฟต์แวร์ การ์ดในระดับที่สูงกว่าจะให้การแสดงออกที่ดีกว่า โดยเฉพาะเมื่อทำงานกับกล้องหลายตัว และ/หรือวิดีโอความละเอียดสูง

ต้องการความช่วยเหลือ?

ดูคู่มือที่เป็นประโยชน์เหล่านี้:

  • วิธีตรวจสอบข้อมูลจำเพาะของคอมพิวเตอร์

  • วิธีระบุการ์ดจอของคุณ
