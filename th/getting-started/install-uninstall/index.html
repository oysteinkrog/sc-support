วิธีติดตั้งหรือถอนการติดตั้ง Swing Catalyst

บทความสนับสนุนนี้อธิบายวิธีการติดตั้งหรือถอนการติดตั้ง Swing Catalyst*

*ใช้ได้กับ: Motion Catalyst

ก่อนที่คุณจะติดตั้ง Swing Catalyst บนคอมพิวเตอร์เครื่องใหม่ โปรดตรวจสอบให้แน่ใจว่าคอมพิวเตอร์ตรงตามข้อกำหนดและสเปคคอมพิวเตอร์ที่แนะนำของเรา

Note: Swing Catalyst ไม่รองรับฮาร์ดแวร์ของ Apple (Apple M1, M2 หรือรุ่นใหม่กว่าที่ใช้สถาปัตยกรรม ARM)

บทความนี้ยังถือว่าคุณมีใบอนุญาต (license) ที่ถูกต้อง (สำหรับเวอร์ชันที่คุณต้องการติดตั้ง) และมีใบอนุญาตพร้อมใช้งาน

การดาวน์โหลดเวอร์ชันล่าสุด

สามารถดาวน์โหลด Swing Catalyst เวอร์ชันล่าสุดได้จากหน้าดาวน์โหลดของเรา

  • คลิกปุ่ม “Download”

  • เมื่อดาวน์โหลดตัวติดตั้งเสร็จแล้ว ให้ดับเบิลคลิกที่ไฟล์ exe (โดยปกติจะอยู่ในโฟลเดอร์ Downloads ของคุณ)

  • ทำเครื่องหมายในช่องข้อตกลงใบอนุญาต แล้วคลิก “Install”

  • คลิก “Yes” เมื่อมีการแจ้งเตือนขอสิทธิ์การเข้าถึงระดับสูง

  • คลิก “Close” เมื่อการติดตั้งเสร็จสมบูรณ์

วิธีถอนการติดตั้ง Swing Catalyst

  • ไปที่การตั้งค่า Windows คลิกขวาที่ไอคอน Windows บนแถบงาน แล้วเลือก Settings

  • ในหน้า Settings คลิกที่ Apps จากนั้นเลื่อนลงจนกว่าจะเห็น Swing Catalyst หรือพิมพ์ Swing ในแถบค้นหา

  • คลิกที่ Swing Catalyst แล้วคลิก Uninstall

  • คลิก Yes และทำตามคำแนะนำบนหน้าจอ
