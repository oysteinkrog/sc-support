วิธีใช้ NVidia GPU เอนโคเดอร์ใน Swing Catalyst

บทความสนับสนุนนี้ครอบคลุมวิธีแก้ไขข้อผิดพลาดของ NVIDIA GPU Encoder

หมายเหตุ: GPU NVIDIA บางรุ่นอาจไม่รองรับ

หมายเหตุ: GPU AMD ATI ไม่รองรับเลย

ขั้นแรก ตรวจสอบให้แน่ใจว่าได้เลือก GPU NVIDIA ในการตั้งค่า Video & Capture ของ SwingCatalyst

หากคุณมีกล้องมากกว่า 2 ตัว ให้แน่ใจว่าเปิดใช้งาน patch ภายใต้ “Advanced Settings” ในส่วน Video Encoding

เข้าสู่โหมดจับภาพและบันทึกสวิง หากสวิงถูกกระตุ้นแต่ไม่เสร็จสมบูรณ์ ให้ดูคำแนะนำด้านล่าง

ขั้นตอนที่ 1: คลิกปุ่ม Start และค้นหา “Graphics setting” ใน Windows

ขั้นตอนที่ 2: เปิด “Reduce latency and improve performance”

ขั้นตอนที่ 3: ในส่วน Choose an app to set preference ตรวจสอบให้แน่ใจว่าตั้งค่าเป็น desktop app แล้วคลิก Browse

ขั้นตอนที่ 4: ไปที่ C:\Program Files\Initial Force\Swing Catalyst\bin และเลือก MotionCatalyst.exe จากนั้นคลิก Add

ขั้นตอนที่ 5: เลือก Motion Catalyst ที่เพิ่งเพิ่มเข้ามา แล้วคลิก “Options” จากนั้นเลือก “High performance GPU: NVIDIA XXXX”

วิธีแก้ปัญหาสำรองสำหรับแล็ปท็อปบางรุ่น

ขั้นตอนที่ 1: คลิกขวาบนเดสก์ท็อปแล้วไปที่ “NVIDIA Control Panel” หากไม่มีให้ดาวน์โหลดและติดตั้งไดรเวอร์และแผงควบคุมล่าสุดได้ที่นี่: https://www.nvidia.com/en-us/geforce/drivers/

ขั้นตอนที่ 2: ในแผงควบคุม ไปที่ “Manage 3D settings” ซึ่งควรเป็นตัวเลือกที่ 2 จากด้านบนทางด้านซ้าย

ขั้นตอนที่ 3: คลิกเมนูแบบเลื่อนลง “Preferred graphics processor” และเปลี่ยนจาก “Integrated graphics” เป็น “High-performance NVIDIA processor”

ขั้นตอนที่ 4: คลิก Apply และปิดแผงควบคุม จากนั้นเปิด SwingCatalyst และจับภาพการบันทึกอีกครั้งเพื่อดูว่าได้รับการแก้ไขแล้วหรือไม่ หากยังไม่ได้รับการแก้ไข กรุณาส่งอีเมลไปที่ support@swingcatalyst.com

*คลิกเพื่อขยาย
