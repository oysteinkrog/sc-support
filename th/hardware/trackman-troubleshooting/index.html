คู่มือแก้ไขปัญหาการเชื่อมต่อ TrackMan

คุณกำลังพบปัญหาดังต่อไปนี้:

TrackMan เชื่อมต่อแล้วและแสดงข้อมูลใน TPS แต่ Swing Catalyst ไม่ถูกกระตุ้น และไม่มีข้อมูลปรากฏใน Swing Catalyst

  • รีบูต TrackMan เอง

  • ตรวจสอบว่าคุณได้รับข้อมูลใน TPS หรือไม่ หากไม่ได้รับ ให้ตรวจสอบการปรับเทียบอีกครั้ง

  • ตรวจสอบว่าเปิดใช้งาน “Enable SDK Output” / “Legacy SDK” ใน TPS Settings แล้ว

ใน Swing Catalyst 9.7.8 และ 9.7.9 ปัญหานี้ได้รับการปรับปรุงเพิ่มเติมแล้ว หากคุณทำตามคำแนะนำเหล่านี้แล้วยังไม่สำเร็จ การตรวจสอบให้แน่ใจว่าคุณใช้งานเวอร์ชัน 9.7.9 หรือใหม่กว่าสามารถช่วยลดความล่าช้าได้

การชดเชยความล่าช้าของ Launch Monitor ใน Swing Catalyst

หากคุณได้รับข้อมูลแต่ Swing Catalyst ไม่กระตุ้นการบันทึก ลองเปลี่ยนค่า “Trigger delay” เป็น 1400

TrackMan 3e

คุณยังสามารถตรวจสอบว่าเปิดใช้งาน “legacy SDK” หรือไม่จากเว็บอินเทอร์เฟซของอุปกรณ์ คุณสามารถเข้าไปที่เว็บอินเทอร์เฟซได้จาก TPS Settings โดยเลือก force operator และตรวจสอบใต้ Setup

หาก SDK output ถูกตั้งค่าใน TPS และบนอุปกรณ์แล้วแต่คุณยังไม่ได้รับข้อมูล ลองเชื่อมต่อกับหน่วยหรือ SDK ด้วยเครื่องมือที่ชื่อว่า Hercules

ตรวจสอบการส่งออกข้อมูลจากหน่วยอุปกรณ์ / ซอฟต์แวร์ TPS:

  • ตรวจสอบให้แน่ใจว่า TPS กำลังทำงานและได้รับข้อมูลจากหน่วยอุปกรณ์

  • ดาวน์โหลดและเรียกใช้ Hercules

  • ไปที่แท็บ TCP Client

  • ป้อน IP และพอร์ตด้านล่างแล้วคลิกเชื่อมต่อ

ที่อยู่ IP สำหรับ WiFi & USB

TrackMan 4

  • Ethernet: ไม่รองรับ

  • ที่อยู่ USB 169.254.0.1 พอร์ต: 52950

  • ที่อยู่ WiFi 172.30.20.1 พอร์ต: 52950

  • แหล่งที่มาของที่อยู่ที่ไม่ทราบ: 169.254.88.214

TrackMan 3e:

  • ที่อยู่ USB 169.254.0.1 พอร์ต: 52950

  • ที่อยู่ WiFi 172.30.20.1 พอร์ต: 52950

TrackMan 2:

  • เชื่อมต่อโดยตรงกับ TPS SDK server ที่ 127.0.0.1 พอร์ต: 52950

หากเชื่อมต่อสำเร็จใน Hercules คุณควรเห็นผลลัพธ์ดังต่อไปนี้เมื่อคลิกปุ่มเชื่อมต่อ

หากไม่เห็น ให้ลองรีสตาร์ทอุปกรณ์ TrackMan เนื่องจาก TrackMan Legacy SDK ไม่ได้ส่งออกข้อมูล

หากคุณสามารถเชื่อมต่อได้ คุณควรได้รับข้อมูลรวมถึงข้อมูลการตีทันทีที่มีการติดตามการตี

นี่คือข้อมูลเดียวกับที่ Swing Catalyst ได้รับ และเป็นวิธีที่ดีในการตรวจสอบว่า TPS และ TrackMan ส่งข้อมูลจริงหรือไม่

หากคุณไม่สามารถเชื่อมต่อได้ ให้ตรวจสอบไฟร์วอลล์ หากเชื่อมต่อผ่าน WiFi TrackMan อาจถูกระบุว่าเป็นเครือข่ายสาธารณะซึ่งอาจเป็นปัญหากับไฟร์วอลล์บางชนิด ลองปิดไฟร์วอลล์สำหรับเครือข่ายสาธารณะแล้วตรวจสอบอีกครั้ง คุณได้รับข้อมูลแล้วหรือไม่? หากใช่ ให้ตรวจสอบให้แน่ใจว่า TPS และ Swing / Motion Catalyst ได้รับอนุญาตใน Windows Firewall

ตรวจสอบไฟล์บันทึกของ Swing Catalyst:

C:\ProgramData\Swing Catalyst\logs\log.txt หากคุณเห็นข้อความต่อไปนี้ในบันทึก TrackMan OEM Service กำลังทำงานอยู่ และต้องปิดใช้งาน

LaunchMonitorNetworkClientBase.OnTryConnectCompleted(): Successfully connected to [Trackman] on [127.0.0.1:8000].
