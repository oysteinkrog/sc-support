วิธีการเก็บรวบรวมล็อกสำหรับฝ่ายสนับสนุน

มีบางกรณีที่ฝ่ายสนับสนุนต้องการข้อมูลล็อกเฉพาะจากเหตุการณ์ที่เกิดขึ้น

โปรดทราบว่าสิ่งนี้จำเป็นเฉพาะเมื่อเจ้าหน้าที่ฝ่ายสนับสนุนร้องขอให้ส่งไฟล์ล็อกในลักษณะนี้โดยเฉพาะเท่านั้น

หากคุณทราบเวลาโดยประมาณที่เกิดปัญหา โปรดส่งไฟล์ที่มีวันที่แก้ไขล่าสุดใกล้เคียงกับเวลาที่เกิดปัญหามากที่สุด

ไฟล์ล็อกสามารถพบได้ที่ตำแหน่งต่อไปนี้: C:\ProgramData\Swing Catalyst\logs

  • ไปที่ไดเรกทอรี ProgramData โดยพิมพ์ %programdata% ใน Windows File Explorer แล้วกด Enter

  • เปิดไดเรกทอรี Swing Catalyst จากนั้นเปิดไดเรกทอรี log

  • คัดลอกไฟล์ log.txt และไฟล์ล็อกที่มีการแก้ไขล่าสุดก่อนหน้า

  • แนบไฟล์ดังกล่าวไปกับตั๋วสนับสนุนหรืออีเมลที่คุณกำลังส่งไปยังฝ่ายสนับสนุน

อัปเดตล่าสุด: 2024-10-22 | ดูบนเว็บไซต์สนับสนุนทางการ
