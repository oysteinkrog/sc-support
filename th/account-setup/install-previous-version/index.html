วิธีย้อนกลับไปใช้ซอฟต์แวร์เวอร์ชันเก่า

บทความสนับสนุนนี้อธิบายวิธีติดตั้ง Swing Catalyst เวอร์ชันก่อนหน้า

หากคุณเป็นผู้ใช้เบต้าและต้องการติดตั้งเวอร์ชันเสถียรก่อนหน้า:

  • โปรดยกเลิกการเลือก “allow beta versions” หลังจากติดตั้งเวอร์ชันก่อนหน้าเรียบร้อยแล้ว

เมื่อย้อนกลับไปใช้ซอฟต์แวร์เวอร์ชันเก่า SwingCatalyst จะพยายามค้นหาและโหลดเวอร์ชันฐานข้อมูลที่ตรงกันโดยอัตโนมัติ ในทุกการอัปเดตเวอร์ชันหลัก เช่น 9.8 -> 10.0, 10.0 -> 10.1 จะมีการเปลี่ยนแปลงเวอร์ชันฐานข้อมูล ซึ่งหมายความว่าการบันทึกที่ทำด้วยเวอร์ชันใหม่กว่าจะไม่สามารถใช้งานได้ในเวอร์ชันเก่า หากคุณมีการบันทึกสำคัญที่ต้องการบันทึกหรือสำรองข้อมูล เราขอแนะนำอย่างยิ่งให้ส่งออกก่อนที่จะย้อนกลับซอฟต์แวร์

ดังนั้นจึงเป็นสิ่งสำคัญที่ต้องคำนึงถึงเรื่องนี้เมื่อต้องการย้อนกลับเวอร์ชันซอฟต์แวร์

วิธีถอนการติดตั้ง Swing Catalyst

  • ไปที่การตั้งค่า Windows คลิกขวาที่ไอคอน Windows บนแถบงาน แล้วเลือก Settings

  • ในการตั้งค่า คลิกที่ Apps จากนั้นเลื่อนลงจนเห็น Swing Catalyst หรือพิมพ์ Swing ในแถบค้นหา

  • คลิกที่ Swing Catalyst แล้วคลิก Uninstall

  • คลิก Yes และทำตามคำแนะนำบนหน้าจอ
