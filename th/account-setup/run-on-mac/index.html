วิธีรัน Swing Catalyst บน Apple Mac

บทนำ

บทความสนับสนุนนี้อธิบายวิธีที่คุณสามารถใช้ Boot Camp เพื่อรัน Swing Catalyst บน Apple Mac ของคุณ

Boot Camp ช่วยให้คุณติดตั้ง Windows บนคอมพิวเตอร์ Mac ในพาร์ติชันแยกต่างหาก โดยใช้แผ่นติดตั้ง Microsoft Windows ที่คุณจัดเตรียมเอง

หลังจากติดตั้งเสร็จสิ้น คุณสามารถใช้งานได้ทั้ง Windows หรือ Mac OS X บนคอมพิวเตอร์ Mac ของคุณ

หมายเหตุ: Swing Catalyst ไม่รองรับการทำงานบนฮาร์ดแวร์ Apple (Apple M1 / M2 CPU ที่ใช้สถาปัตยกรรม ARM)

บทความนี้มีไว้เพื่อวัตถุประสงค์อ้างอิงเป็นหลัก เนื่องจากข้อมูลล้าสมัยแล้ว

ใช้งานกับ

  • ผู้ใช้ที่ใช้ Mac OS (10.5 - 10.11)

ความต้องการของระบบที่แนะนำ

  • Apple Mac (10.5 - 10.11)

  • แผ่น CD เปล่าหรืออุปกรณ์จัดเก็บข้อมูล USB สำหรับสร้างสื่อติดตั้ง Windows Boot Camp Support Software (ไดรเวอร์)

  • พื้นที่ว่างในดิสก์อย่างน้อย 16 GB สำหรับ Windows 32 บิต และ 20 GB สำหรับ Windows 64 บิต

  • Microsoft Windows เวอร์ชันแท้

โปรดทราบว่า Mac บางรุ่นไม่สามารถรัน Windows 64 บิตผ่าน Boot Camp ได้ และ Boot Camp รองรับเฉพาะ Mac ที่ใช้ชิป Intel เท่านั้น

การติดตั้ง

เพื่อใช้งาน Swing Catalyst บนแล็ปท็อปหรือเดสก์ท็อป Apple คุณจะต้องมี Mac OS เวอร์ชัน 10.5 - 10.11

Swing Catalyst ต้องการ Windows และรองรับ Windows Vista, 7, 8.1 และ Windows 10

เพื่อประสบการณ์การใช้งานที่ดีที่สุด เราแนะนำ Windows 7 64 บิตเป็นอย่างยิ่ง

แนะนำให้ติดตั้ง Windows ด้วย Boot Camp Assistant Boot Camp ช่วยให้คุณบูตได้ทั้ง Mac OS และ Windows แบบคู่ขนาน ทำให้สามารถเข้าถึงทั้งสองระบบปฏิบัติการได้อย่างสะดวก

การกดปุ่ม Option (Alt) ค้างไว้ขณะเปิดเครื่อง Mac จะช่วยให้คุณสามารถสลับระหว่าง Microsoft Windows และ Mac OS X ได้

ระบบปฏิบัติการเริ่มต้นจะเป็น Mac OS X แต่สามารถเปลี่ยนได้ง่ายใน Startup Disk Control Panel ใน Windows หรือในการตั้งค่า Startup Disk ของ Mac OS X เพื่อกำหนดดิสก์เริ่มต้น

ไปที่ http://support.apple.com/manuals/#bootcamp และค้นหาคู่มือที่ตรงกับ Mac ของคุณ

นอกจากนี้ยังอาจเป็นประโยชน์ในการดู Boot Camp FAQ ที่ http://support.apple.com/kb/HT4818 ซึ่งอาจช่วยแก้ปัญหาที่อาจเกิดขึ้นได้
