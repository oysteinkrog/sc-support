Kuinka asentaa ja ottaa käyttöön Tasapainolevy 3

Johdanto

Tässä tukiartikkelissa kuvataan, kuinka uusi Tasapainolevy 3 otetaan käyttöön Swing Catalystin kanssa.

Vaatimukset

  • Tietokone, jossa on vapaa USB-portti.

  • Swing Catalyst 7.1.8 tai uudempi.

Asennus

Asennuksen yksityiskohdat löytyvät artikkelin alaosassa olevasta liitetystä PDF-tiedostosta.

Tämä artikkeli kattaa Tasapainolevy 3:n ja Tasapainolevy 3s:n.

Haluatko vain suorittaa levyn kenttäkalibroinnin? Napsauta tästä

Varoitus

AMD 300-sarjan piirisarjoissa (AMD Ryzen 1700 / 2700 -sarja) USB 1.1 -laitteiden kanssa on havaittu ongelmia. Erityisesti Tasapainolevy-laitteen kohdalla, jolloin näytetaajuudeksi saadaan vain 75 näytettä sekunnissa noin 145 näytteen sijaan. Suosittelemme käyttämään USB 2.0 -hubia, jolloin Tasapainolevy voi siirtää dataa täydellä näytetaajuudella.

AMD 300-sarjan piirisarjojen käytössä USB 3.0 -laitteiden kanssa ei ole tunnettuja ongelmia.

Driverit-asennus

  • Asenna Driverit Windowsin Käynnistä-valikosta: Swing Catalyst - Driverit-kansio. 64-bittisessä Windowsissa suorita “Balance Plate #2 Driver Installer (x64)” 32-bittisessä Windowsissa suorita “Balance Plate #2 Driver Installer (x86)” Onko minulla 32-bittinen vai 64-bittinen Windows?

Löydät Driverit myös osoitteesta https://www.swingcatalyst.com/drivers

Kalibrointityökalun käynnistäminen

  • Lataa kalibrointityökalu

  • Jos sinua pyydetään asentamaan Driverit, napsauta kyllä.

  • Yhdistä Tasapainolevy tietokoneeseen.

  • Avaa juuri asennettu SE Utility.

  • Valitse kamera tai web-kamera ja kohdista se Tasapainolevyyn.
