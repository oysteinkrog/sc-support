Useiden näyttöjen asettaminen Swing Catalystin avulla

Useiden näyttöjen määrittäminen

Tämä tukiartikkeli käsittelee useiden näyttöjen määrittämistä ja konfigurointia Windows-järjestelmässä. Se kattaa palautenäytön asettamisen SwingCatalystissa, useiden näyttöjen käyttöskenaariot SwingCatalystissa sekä ohjeet ikkunoiden siirtämiseen ja navigointiin useammalla näytöllä.

Useiden näyttöjen määrittäminen Windowsissa:

  1. Varmista, että tietokoneesi pystyy muodostamaan yhteyksiä useisiin näyttöihin. Joillakin tietokoneilla tai kannettavilla tietokoneilla on rajoituksia, kuten enintään 2 näytöä.

Yli kahden näytön asennuksissa tarvitset joko näytönohjaimen, joka pystyy tuottamaan tarvitsemasi määrän ulostuloja, tai vaihtoehtoisesti jos haluat vain heijastaa näytön, voit tehdä sen HDMI-splittereillä (lisää tietoa alla).

  1. Tarkista, että sinulla on tarvittavat kaapelit näyttöön yhdistämistä varten. Yleisimmät yhteystyypit nykyään ovat: HDMI, DVI tai Display Port. Viimeksi mainittu vaatii usein sovitinta. Useimmissa nykyisissä tietokoneissa on HDMI-portti, mutta joissa kannettavissa tietokoneissa on HDMI mini tai Display Port.

On tärkeää huomata, mikä portti on se, johon olet yhdistämässä, jotta sinulla on sopiva sovitin tarvittaessa.

  1. Yhdistä näyttösi tietokoneeseen, napsauta hiiren oikealla painikkeella työpöydällä ja valitse Näyttöasetukset.

If the display has been successfully detected it should show more than one display.

To set your display as the main display, check the “Make this my main display” box.

Note: You may want to set your main display to display 1 (i.e the first output on the graphics card).

If you wish to extend the desktop to your secondary display select the option under Multiple displays.

Please note that if the display you’re connecting to has a higher or lower resolution the image might be slightly different. The DPI also might be different causing the text to be larger or smaller than what you might be used to. Use the recommended resolution where possible.

Now that we have more than one display set up in Windows, make sure you have the orientation right (i.e that the monitor on the right is to your right). Having this sorted helps a lot in navigating; especially if it’s more than two displays.

Note: Windows 7 has a different configuration for displays, but the overall process is the same.
