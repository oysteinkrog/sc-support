Halcon USB लाइसेंस डोंगल कनेक्ट करने पर कंप्यूटर ब्लूस्क्रीन हो जाता है

Halcon ग्राहकों के लिए उपयोग किए जाने वाले लाइसेंसिंग डोंगल के USB ड्राइवर में एक समस्या है। यह डोंगल एक हरे रंग का USB “Flexera” डोंगल है।

Halcon 12 के साथ बंडल किए गए ड्राइवर Windows को क्रैश करके ब्लूस्क्रीन का कारण बनते हैं।

ब्लूस्क्रीन से बचने के लिए हम अनुशंसा करते हैं कि यदि पुराने ड्राइवर इंस्टॉल हैं तो उन्हें Halcon को अनइंस्टॉल करके या ड्राइवर को मैन्युअल रूप से हटाकर हटा दें।

प्रभावित सिस्टम:

  • Windows 10 Version 2004 Build >= 19041.423, 20H2, 21H1, या 21H2

  • Windows 11.

हम अनुशंसा करते हैं कि Halcon को अनइंस्टॉल करें और फिर इस सपोर्ट आर्टिकल में नए ड्राइवर को इंस्टॉल करने के निर्देशों का पालन करें।

Halcon को अनइंस्टॉल करना

  • Add or Remove programs खोलें।

  • Apps & features के अंतर्गत, “halcon” खोजें।

  • सूची में मिले परिणाम पर क्लिक करें और “Uninstall” तथा “Uninstall” पर क्लिक करें।

  • Halcon को अनइंस्टॉल करने के लिए “Yes” पर क्लिक करें, Halcon अनइंस्टॉलर शुरू होने की प्रतीक्षा करें और फिर Halcon को हटाने के लिए “Uninstall” पर क्लिक करें।

वैकल्पिक विकल्प: Halcon USB डोंगल ड्राइवर को मैन्युअल रूप से हटाना

इस विकल्प का उपयोग तब किया जा सकता है जब आप कंप्यूटर को रीबूट नहीं करना चाहते या किसी कारण से Halcon को पुनः इंस्टॉल नहीं करना चाहते। अधिकांश मामलों में इसके बजाय “Halcon को अनइंस्टॉल करना” विकल्प का पालन करना सबसे अच्छा है।

जब कोई ड्राइवर इंस्टॉल होता है तो वह Windows DriverStore फ़ाइल रिपॉजिटरी में संग्रहीत होता है, जो यहाँ स्थित है:

C:\Windows\System32\DriverStore\FileRepository

सामान्यतः ड्राइवर हटाने के लिए आप Device Manager में जाकर डिवाइस को अनइंस्टॉल करते और ड्राइवर को डिलीट करने का विकल्प चुनते, लेकिन चूँकि USB डोंगल लगाने से Windows क्रैश हो जाता है, इसलिए हमें इसे मैन्युअल रूप से हटाना होगा। नया ड्राइवर इंस्टॉल करने के बाद Windows उपयुक्त (नया) ड्राइवर स्वयं ढूँढ लेगा।

pnputil का उपयोग करके डिवाइस ड्राइवर कैसे हटाएँ

नीचे दिए गए निर्देशों में “quotes” के अंदर वह टेक्स्ट है जो कमांड लाइन में बिना quotes के टाइप किया जाना चाहिए।

  • Command Prompt खोलें।

  • Command Prompt में, सभी इंस्टॉल किए गए ड्राइवरों की सूची देखने के लिए “pnputil -e” टाइप करें।

  • आउटपुट की शुरुआत में उन ड्राइवरों को देखें जिनके पैकेज नाम में Sentinel HASP या SafeNet है।

  • उनमें से प्रत्येक को हटाने के लिए “pnputil /delete-driver drivername.inf /uninstall” चलाएँ।

  • उदाहरण के लिए oem53.inf पब्लिशर नाम वाले ड्राइवर को हटाने के लिए टाइप करें: “pnputil /delete-driver oem53.inf /uninstall” और Enter दबाएँ।

कृपया ध्यान दें कि इस मामले में pnputil का आउटपुट एक कार्यशील सिस्टम से है जिसमें अपडेटेड ड्राइवर है (पुराने ड्राइवरों का स्क्रीनशॉट उपलब्ध नहीं है)।

एक गैर-कार्यशील सिस्टम के लिए इसी तरह के ड्राइवर सूचीबद्ध होने चाहिए लेकिन ड्राइवर पैकेज प्रदाता अलग होगा।

नया Halcon USB लाइसेंस डोंगल ड्राइवर इंस्टॉल करना

नीचे दिए गए निर्देशों में “quotes” के अंदर वह टेक्स्ट है जो कमांड लाइन में बिना quotes के टाइप किया जाना चाहिए।

  • नया ड्राइवर डाउनलोड करें और एक्सट्रैक्ट करें, डाउनलोड की गई zip फ़ाइल पर राइट क्लिक करें और “Extract All” और “Extract” पर क्लिक करें।

  • Command Prompt खोलें (यदि आपने इसे पहले बंद कर दिया था)

  • एक्सट्रैक्ट किए गए ड्राइवर फ़ोल्डर का स्थान कॉपी करें, जैसे C:\Users\stian\Downloads\haspdinst_8.53

  • Command Prompt में, “cd” टाइप करें और एक्सट्रैक्ट किए गए ड्राइवर का स्थान पेस्ट करें, जैसे “cd C:\Users\stian\Downloads\haspdinst_8.53”

  • Command Prompt में “haspdinst.exe /install” टाइप करें और Enter दबाएँ।

  • इंस्टॉलेशन आगे बढ़ना चाहिए।
