Lynx GigE कैमरों पर स्टैटिक IP कैसे सेट करें

परिचय

यह सपोर्ट आर्टिकल बताता है कि अपने Lynx कैमरों को स्टैटिक IP पते के साथ कैसे कॉन्फ़िगर करें। सामान्य उपयोग के लिए यह आवश्यक नहीं है क्योंकि Swing Catalyst IP कॉन्फ़िगरेशन को स्वचालित रूप से संभालता है।

आवश्यकताएँ

  • MVS एप्लिकेशन (IP कॉन्फ़िगर करने के लिए उपयोग किया जाता है)।

  • Swing Catalyst संस्करण 9.8.5 या उसके बाद का।

  • एक Swing Catalyst Lynx GigE कैमरा।

  • एक पहले से कार्यशील कैमरा सेटअप।

MVS एप्लिकेशन इंस्टॉल करना

  • MVS क्लाइंट एप्लिकेशन डाउनलोड करें और एक्सट्रैक्ट करें: https://swingcatalyst.s3.amazonaws.com/drivers/MVS_STD_3.4.1_220407.zip

  • MVS इंस्टॉल करें, स्क्रीन पर दिए गए निर्देशों का पालन करें।

  • “Open release notes” को अनचेक करें।

  • समाप्ति पर क्लिक करें।

Ethernet एडेप्टर पर स्टैटिक IP सेट करना

एक बार जब कैमरों को स्टैटिक IP पते असाइन हो जाते हैं, तो आपको उन नेटवर्क एडेप्टर को स्टैटिक IP के साथ कॉन्फ़िगर करना होगा जिन्हें आप उपयोग करने की योजना बना रहे हैं। इसे इस प्रकार कॉन्फ़िगर किया जाना चाहिए कि यह प्रत्येक कनेक्टेड कैमरे से मेल खाए।

इसका अर्थ है कि यदि आप कैमरा डिस्कनेक्ट करके किसी अलग Ethernet एडेप्टर से कनेक्ट करते हैं, तो जब तक उसे पुनः कॉन्फ़िगर नहीं किया जाता, वह “काम” नहीं करेगा।

Warning:

नीचे उल्लिखित “Ethernet एडेप्टर” नंबर, नेटवर्क एडेप्टर से जुड़ा वास्तविक नंबर नहीं है, बल्कि यह केवल उदाहरण के लिए है। कृपया प्रत्येक नेटवर्क एडेप्टर को प्रति कैमरा के आधार पर कॉन्फ़िगर करें, अर्थात् यदि आपके पास दो कैमरे कनेक्टेड हैं तो उन्हें क्रमिक रूप से कॉन्फ़िगर करें और Ethernet एडेप्टर 1 और 2 की तालिकाओं का संदर्भ लें; किसी भी ऐसे नेटवर्क एडेप्टर की सेटिंग न बदलें जिनसे कोई पहचाना हुआ कैमरा कनेक्ट नहीं है।

  • कनेक्टेड कैमरे के ऊपर Ethernet एडेप्टर पर राइट क्लिक करें।

  • “NIC Settings” पर क्लिक करें।

  • Jumbo Frame सक्षम करें।

  • Receive Buffers को अधिकतम मान पर सेट करें।

  • Transmit Buffers को अधिकतम मान पर सेट करें।

  • “Internet Protocol Properties” पर “Open” क्लिक करें।

  • नीचे दी गई तालिका के अनुसार नेटवर्क एडेप्टर को कॉन्फ़िगर करें।

प्रत्येक Ethernet एडेप्टर के लिए अनुशंसित स्टैटिक IP कॉन्फ़िगरेशन

यह स्टैटिक IP पतों के साथ एक कॉन्फ़िगरेशन का उदाहरण है। Ethernet एडेप्टर और संबंधित कैमरों के IP पर ध्यान दें।

कैमरे पर स्टैटिक IP सेट करना

सुनिश्चित करें कि आपका/आपके Lynx कैमरा(एँ) कनेक्टेड हैं। यदि आपने एप्लिकेशन शुरू करने के बाद इसे कनेक्ट किया है, तो माउस को “GigE” मेनू पर ले जाएँ और रिफ्रेश बटन पर क्लिक करें।

यह प्रक्रिया उन सभी कनेक्टेड Lynx कैमरों के लिए दोहरानी होगी जिन पर आपने स्टैटिक IP सेट की है।

कृपया ध्यान दें कि आपको पहले कैमरा 1 पर स्टैटिक IP सेट करनी होगी, फिर क्रमिक रूप से नेटवर्क कार्ड 1 पर। एक बार जब आप 1 के साथ काम पूरा कर लें तो 2 पर जाएँ, आदि। जिन नंबरों का उल्लेख किया गया है वे नेटवर्क एडेप्टर के वास्तविक नाम नहीं हैं, जैसे “Ethernet 2”, बल्कि केवल उदाहरण के लिए उपयोग किए गए हैं।

  • सूची में कैमरे पर राइट क्लिक करें और “Modify IP” पर क्लिक करें।

  • DHCP या LLA से चयन बदलकर Static IP करें।

  • नीचे दिए गए विवरण के अनुसार IP पता और Subnet Mask कॉन्फ़िगर करें।

  • प्रत्येक कैमरे के लिए IP अलग होनी चाहिए।
