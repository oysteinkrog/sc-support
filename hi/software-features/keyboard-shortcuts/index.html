कीबोर्ड शॉर्टकट और हॉटकीज़

Swing Catalyst & Motion Catalyst अनेक कीबोर्ड शॉर्टकट का समर्थन करता है।

यह लेख कीबोर्ड शॉर्टकट का विवरण देता है।

एक कीबोर्ड शॉर्टकट केवल एक कीबोर्ड प्रेस हो सकता है, लेकिन यह एक से अधिक कुंजियों का संयोजन भी हो सकता है।

इस लेख में, एक से अधिक कीबोर्ड प्रेस वाले शॉर्टकट को + का उपयोग करके जोड़ा गया है।

इसका मतलब यह नहीं है कि आपको कीबोर्ड पर + दबाना है, बल्कि यह दर्शाता है कि आपको दोनों (या अधिक) बटन एक साथ दबाने हैं।

प्लेबैक

कीबोर्ड हॉटकी / शॉर्टकट क्रिया

Space चलाएँ / विराम करें (टॉगल)

Right एक फ्रेम आगे बढ़ें

Left एक फ्रेम पीछे जाएँ

Shift Right अवधि का 5% आगे बढ़ें

Shift Left अवधि का 5% पीछे जाएँ

Up प्लेबैक गति बढ़ाएँ

Down प्लेबैक गति घटाएँ

बुकमार्क

कीबोर्ड हॉटकी / शॉर्टकट क्रिया / विवरण

1, 2 या 3 View Port A में खुली रिकॉर्डिंग के बुकमार्क(ों) 1 से 3 की स्थिति पर जाएँ

Alt + 1, 2 या 3 View Port B में खुली रिकॉर्डिंग के बुकमार्क(ों) 1 से 3 की स्थिति पर जाएँ

Ctrl + 1, 2 या 3 View Port A में बुकमार्क 1 से 3 को वर्तमान प्लेबैक स्थिति पर सेट करें

Ctrl + Alt 1, 2 या 3 View Port B में बुकमार्क 1 से 3 को वर्तमान प्लेबैक स्थिति पर सेट करें

Ctrl + Shift 1, 2 या 3 बुकमार्क 1-3 पर सिंक्रनाइज़ करें

Ctrl + B संपादन के लिए बुकमार्क लॉक / अनलॉक करें

ड्रॉइंग टूल्स

हॉटकी क्रिया (ड्रॉइंग टूल सक्षम करती है)

C वृत्त (Circle)

R आयत (Rectangle)

V तीर (Arrow)

L रेखा (Line)

A कोण

F मुक्त हाथ

S झूलना

E इरेज़र (Eraser)

H हाथ

T टेक्स्ट (Text)

B बकेट (सब कुछ मिटाएँ)

MoCap

हॉटकी क्रिया

Shift+S कंकाल छुपाएँ/दिखाएँ (टॉगल)

Shift+C द्रव्यमान का केंद्र प्रतीक छुपाएँ/दिखाएँ (टॉगल)

Shift+A कोण टूल टॉगल करें

Shift+L जोड़ जोड़ने का टूल टॉगल करें

Shift+T जोड़ ट्रेस टूल टॉगल करें

Shift+M जोड़ मूव टूल टॉगल करें

अन्य

हॉटकी क्रिया / विवरण

Ctrl + O एक्सप्लोरर खोलें / बंद करें

Ctrl + Mouse Scroll Up ज़ूम इन करें (वीडियो या डेटा ग्राफ़, माउस फ़ोकस के अनुसार)

Ctrl + Mouse Scroll Down ज़ूम आउट करें (वीडियो या ग्राफ़ डेटा, माउस फ़ोकस के अनुसार)

Alt + C कैप्चर मोड टॉगल करें (एक बार जब आपने कोई उपयोगकर्ता चुन लिया हो)

Alt + A स्टैक की अंतिम रिकॉर्डिंग View Port A में खोलें

Alt + B स्टैक की अंतिम रिकॉर्डिंग View Port B में खोलें
