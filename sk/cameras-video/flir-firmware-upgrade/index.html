Aktualizácia firmvéru na zariadení FLIR Blackfly S

Ako vykonať upgrade firmvéru na FLIR Blackfly S.

Tento článok pokrýva, ako upgradovať firmvér na FLIR Blackfly S GigE BFS-PGE-04S2C-CS.

Upozornenie: Nepokračujte v upgrade firmvéru, ak sa model produktu fotoaparátu nezhoduje s: BFS-PGE-04S2C-CS

Požiadavky:

  • Spinaker SpinView software (see flir-blackfly-gige-setup.md) for details.

  • FLIR Blackfly S BFS-PGE-04S2C-CS camera.

Download the firmware update, double click on the zip file and extract the ez2 file by clicking Extract all.

Start SpinView (Windows Start Menu, type SpinView), click Spinview icon.

Right click the camera you wish to update and click: Update Device Firmware.

Download the firmware file if you haven’t already:

https://cloudfront.swingcatalyst.com/files/bfs_ge_imx287_2005.0000.066.000.zip & extract the zip file.

Select the firmware file that you have downloaded.

Click Start and then click Yes

Link to old firmware: https://cloudfront.swingcatalyst.com/files/bfs_ge_imx287.zip
