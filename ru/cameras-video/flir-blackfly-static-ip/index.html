Как настроить статический IP на камерах FLIR Blackfly GigE

Введение

В этой статье технической поддержки описывается, как настроить камеры Blackfly (или Blackfly S) GigE со статическим IP-адресом. При обычном использовании это не требуется, поскольку SwingCatalyst выполняет настройку IP автоматически.

Требования

  • Приложение Spinview (входит в состав Spinnaker SDK).

  • SwingCatalyst.

  • Одна или несколько камер FLIR Blackfly (или Blackfly S) GigE.

Установка Spinnaker

  • Загрузите и запустите установщик Spinnaker.

  • Щёлкните правой кнопкой мыши по установщику Spinnaker и выберите «Запуск от имени администратора».

  • Установите флажок «Camera Evaluation» и нажмите «Далее».

  • Следуйте инструкциям на экране для продолжения установки.

  • После завершения перезагрузите компьютер.

Настройка статического IP на адаптере Ethernet

Каждая камера и сетевой адаптер должны иметь собственный уникальный статический IP-адрес. Например, если вы назначаете статические IP-адреса камерам, убедитесь, что сетевой адаптер настроен с соответствующим IP из матрицы «рекомендуемой конфигурации статического IP» ниже.

Предупреждение

Настраивайте сетевые адаптеры в соответствии с подключёнными к ним камерами, а не по номеру адаптера. Изменяйте настройки только для идентифицированных камер; остальные оставляйте без изменений. Если вы подключаете камеру к другому адаптеру, для корректной работы потребуется повторная настройка.

На панели управления перейдите в раздел «Сеть и Интернет», затем в «Центр управления сетями и общим доступом» и нажмите «Изменение параметров адаптера».

Здесь отображается список сетевых адаптеров, установленных на компьютере. В нашем случае мы хотим настроить Ethernet 2 и Ethernet 3 с именем устройства «Intel Pro/1000». Важно настраивать только те сетевые адаптеры, которые используются для камер, и не трогать остальные, так как это может повлиять на подключение к интернету.

Щёлкните правой кнопкой мыши по сетевому адаптеру, который хотите изменить, и выберите «Свойства», затем прокрутите вниз до пункта «Протокол Интернета версии 4 (TCP/IPv4)» и нажмите «Свойства».

  • Выберите «Использовать следующий IP-адрес».

  • Введите IP-адрес из матрицы рекомендуемой конфигурации статического IP ниже.

  • Введите маску подсети 255.255.255.0.

  • Выберите «Использовать следующие адреса DNS-серверов» — поля можно оставить пустыми.

  • Нажмите «OK».

Настройка статического IP на камере

Повторите эти шаги для каждой камеры, на которой вы хотите задать статический IP. Чтобы получить доступ к настройке IP камеры, откройте приложение SpinView и щёлкните правой кнопкой мыши по камере, для которой хотите настроить IP.

  • Щёлкните правой кнопкой мыши по камере в списке устройств и выберите «GigE Configuration».

  • Нажмите «IP Configuration».

Введите IP-адрес и маску подсети согласно матрице рекомендуемой конфигурации IP ниже.

  • Введите IP-адрес камеры, используя адрес из матрицы, например для камеры 1.

  • Введите маску подсети, например: 255.255.255.0.

  • Шлюз по умолчанию может быть пустым или равным IP-адресу сетевого адаптера, к которому подключена камера.

  • Снимите флажок DHCP.

  • Нажмите «Set Current and Persistent IP Configuration».

Рекомендуемая конфигурация статического IP для камер

Номер камерыIPМаска подсетиШлюз

IP шлюза — это IP-адрес сетевого адаптера, к которому подключена камера.

Например, камера 1 подключена к сетевому адаптеру 1.

Использование SpinView для включения jumbo frames и оптимизации сетевых адаптеров для камер

Обратите внимание, что эти изменения необходимо применить ко всем сетевым адаптерам, подключённым к вашим камерам.

  • В SpinView щёлкните правой кнопкой мыши по камере и выберите «GigE Configuration».

  • Нажмите «Configure Adapter Properties».

  • Нажмите «Да» при появлении запроса.

  • Нажмите «Далее».

  • Нажмите «Auto Fill All».

  • Нажмите «Далее».

  • Установите флажок «Enable Media Optimization».

  • Нажмите «Далее».

  • Нажмите «Configure», чтобы применить изменения.
