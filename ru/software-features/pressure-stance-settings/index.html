Использование новых настроек давления и стойки

Введение

Данная статья демонстрирует новые параметры в панели данных Pressure and Stance в Swing Catalyst 24.1 и более новых версиях. Параметры включают:

  • Dynamic Stance width: применяется ко всем сенсорным платформам

  • Position of Plates: применяется к двойной платформе давления

Dynamic Stance Width

Dynamic Stance Width — это новая функция, которая позволяет измерять ширину стойки в реальном времени или на определенных фазах на протяжении всего размаха. Это особенно полезно для понимания того, как ширина стойки изменяется динамически на различных фазах размаха, от стойки до контакта.

Основные преимущества

Обратная связь в реальном времени: получайте мгновенную обратную связь о том, как ширина стойки изменяется во время размаха.

Улучшенный анализ: сравните динамическую ширину стойки между различными размахами для выявления последовательности или вариативности.

Настройка: зафиксируйте ширину стойки на определенной фазе размаха на основе установленных закладок

Как использовать Dynamic Stance Width

Доступ к функции: перейдите в раздел инструментов анализа и выберите 1) “Зафиксировать на первой фазе”, 2) “Зафиксировать на текущей фазе” или 3) “Разблокировано”

Сравнительный анализ: используйте данные для сравнения нескольких размахов, помогая выявить закономерности или области для улучшения.

Configurable Plate Distance

The ‘Position of Plates’ feature in the ‘Pressure and Stance’ databox allows users to precisely set the distance between the Dual Pressure Plates. This ensures that the stance width is accurately captured and reflected during swing analysis, leading to more reliable data and insights. Properly setting the distance between the plates is crucial for obtaining correct stance width measurements.

Key Benefits

Accurate Stance Width: Ensures that the stance width is recorded correctly by adjusting the distance between the plates.

Customizable Settings: Allows for adjustments based on how the plates are positioned on the protection mat, ensuring flexibility and accuracy.

User-Friendly: Simple to set up with easy options for different plate configurations.

How to Use Position of Plates

Setup Based on Plate Positioning:

Narrow Setting: If the plates are placed together, right next to each other, select the ‘Narrow’ option. This is ideal for a closer stance where the plates are adjacent.

Wide Setting: If the plates are positioned on the outer edges of the protection mat, select the ‘Wide’ option. This setting is for wider stances where the plates are farther apart.

Custom Distance Configuration:

If the plates are placed at a custom distance that doesn’t align with the predefined ‘Narrow’ or ‘Wide’ settings, you need to manually measure the distance between them.

  • Measure the shortest distance between the inner edges of the plates. This distance should be entered into the software either in centimeters (cm) or inches (in), depending on your preference.

  • Enter this value in the provided field to set the correct stance width according to the actual plate positioning.

Ensuring Accuracy: Always double-check that the entered distance reflects the actual setup of the plates. Correct input is essential for precise stance width measurements.
