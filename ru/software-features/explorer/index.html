Как пользоваться Обозревателем

Введение

Обозреватель предоставляет интерфейс для просмотра, выбора и управления видеозаписями, организованными по сеансам. В этом документе описывается, как эффективно перемещаться по Обозревателю и использовать все его функции в версии 25.3 и более новых.

Обзор

Панель инструментов: Панель инструментов с кнопками для быстрого доступа ко всем основным функциям Обозревателя.

Список пользователей: Список зарегистрированных пользователей с удобными функциями, такими как строка поиска и кнопка сортировки.

Список загружаемого контента: Список загруженных записей, например свингов тура.

Сеансы и записи: Список сеансов, которые можно развернуть для отображения всех записей данного сеанса.

Предварительный просмотр записи: Окно предварительного просмотра с анимированным миниатюрным изображением и ключевой информацией о записи.

Список экспорта: Перетащите записи сюда, чтобы добавить их в список экспорта. Затем записи можно экспортировать как файл Дубля, позволяющий импортировать запись в SwingCatalyst позднее, или как файлы TSV с необработанными данными для пользовательского анализа.

Навигация с клавиатуры

Обозреватель поддерживает полную навигацию по миниатюрам записей с помощью клавиатуры:

Навигация с помощью клавиш со стрелками

  • ↑ — Переместиться на одну строку вверх

  • ↓ — Переместиться на одну строку вниз

  • ← — Переместиться на один столбец влево

  • → — Переместиться на один столбец вправо

Постраничная навигация

  • Home — Перейти к первому элементу в текущем сеансе

  • End — Перейти к последнему элементу в текущем сеансе

  • Page Up — Переместиться вверх на видимую страницу

  • Page Down — Переместиться вниз на видимую страницу

Навигация между сеансами

  • При достижении верхней/нижней части сеанса клавиши со стрелками автоматически переходят к соседним сеансам

  • Сеансы автоматически разворачиваются при переходе к ним

Поведение выбора

Обозреватель поддерживает стандартные возможности множественного выбора:

Одиночный выбор

  • Щелчок — Выбрать одну запись

  • Двойной щелчок — Открыть выбранную запись для просмотра

Множественный выбор с помощью мыши

  • Ctrl** + Щелчок** — Переключить выбор отдельных элементов

  • Shift** + Щелчок** — Выбрать диапазон от последнего выбранного элемента до элемента, по которому выполнен щелчок

Множественный выбор с помощью клавиатуры

  • Shift** + Клавиши со стрелками** — Расширить выбор в направлении навигации

  • Ctrl** + Клавиши со стрелками** — Перемещаться без изменения выбора

  • Ctrl** + **A — Выбрать все видимые записи в Обозревателе

  • Ctrl** + Shift + **A — Выбрать все видимые записи в текущем сеансе

  • Escape — Снять все видимые выборы

Информация о выборе

  • Счётчик выбора: Показывает общее количество выбранных элементов и количество видимых выбранных элементов

  • Скрытые выборы: Указывает на наличие элементов, выбранных в свёрнутых или отфильтрованных сеансах

  • Визуальная обратная связь: Выбранные элементы выделяются рамкой

Меню и контекстные действия

Контекстное меню записи

Щёлкните правой кнопкой мыши по любой записи для доступа к:

  • Открыть — Открыть запись

  • Добавить в Стопку — Добавить в стопку анализа для быстрого доступа в режиме анализа

  • Добавить в экспорт — Добавить в очередь экспорта

  • Удалить — Удалить запись

  • Загрузить в Online — Поделиться через SwingCatalyst Online

Контекстное меню Студента/Группы

Щёлкните правой кнопкой мыши по именам студентов, чтобы:

  • Добавить пользователя в список экспорта — Включить все записи пользователя в экспорт

  • Удалить пользователя — Удалить пользователя и все его записи

Глобальные команды

Доступны через сочетания клавиш:

  • Enter — Открыть выбранную запись (записи).

  • Delete — Удалить все выбранные записи

  • Ctrl** + **A — Выбрать все видимые записи в Обозревателе

  • Ctrl** + Shift + **A — Выбрать все записи в текущем сеансе

  • Escape — Снять текущий выбор

Перетаскивание

Перетаскивание дублей

  • Перетаскивайте дубли в зоны размещения

  • Визуальная обратная связь отображает элемент перетаскивания с миниатюрой записи

  • Индикаторы размещения выделяют допустимые места назначения

Зоны размещения

  • Зона размещения Окна просмотра A/B — Поместите сюда, чтобы открыть запись (записи) в Окне просмотра A или B

  • Зона размещения списка экспорта — Поместите сюда, чтобы добавить запись (записи) в очередь экспорта

Советы по эффективному использованию

  • Массовые операции: Используйте множественный выбор для выполнения действий над несколькими записями одновременно

  • Эффективность клавиатуры: Комбинируйте Ctrl, Shift и клавиши со стрелками для быстрых рабочих процессов выбора

  • Контекстная осведомлённость: Контекстные меню, вызываемые правой кнопкой мыши, предоставляют подходящие для контекста действия

  • Визуальная обратная связь: Обращайте внимание на счётчики выбора и индикаторы выделения

Обозреватель разработан для эффективного управления рабочим процессом, позволяя быстро перемещаться по большим коллекциям записей и выполнять массовые операции с минимальными усилиями.
