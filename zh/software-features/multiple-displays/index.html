如何在 Swing Catalyst 中设置多显示器

如何设置多显示器

本支持文章介绍了在 Windows 中设置和配置多显示器的方法，包括在 SwingCatalyst 中设置反馈屏幕、多显示器使用场景，以及如何在多台显示器之间导航和移动窗口。

如何在 Windows 中设置多显示器：

  1. 请确保您的计算机支持连接多台显示器。部分计算机或笔记本电脑存在限制，例如最多只能连接 2 台显示器。

如果需要连接两台以上的显示器，您需要拥有一块支持足够多输出接口的显卡；或者，如果您只需要镜像显示，可以使用 HDMI 分配器来实现（详见下文）。

  1. 检查您是否拥有连接显示器所需的线缆。目前最常见的接口类型有：HDMI、DVI 和 DisplayPort。DisplayPort 通常需要转接头。大多数计算机配有 HDMI 接口，但部分笔记本电脑配备的是 Mini HDMI 或 DisplayPort 接口。

了解您所连接的接口类型非常重要，以便在需要时准备合适的转接头。

  1. 将显示器连接到计算机，然后在桌面上右键单击并选择"显示设置"。

如果显示器已成功检测到，应会显示多台显示器。

若要将某台显示器设置为主显示器，请勾选"将此设备设为我的主显示器"复选框。

Note: 建议将主显示器设置为显示器 1（即显卡上的第一个输出接口）。

如果您希望将桌面扩展到第二台显示器，请在"多显示器"下选择相应选项。

请注意，如果所连接的显示器分辨率更高或更低，图像可能会略有差异。DPI 也可能不同，导致文字显示比您习惯的更大或更小。请尽量使用推荐分辨率。

在 Windows 中完成多显示器设置后，请确保方向设置正确（即右侧的显示器对应您的右侧）。正确设置方向对导航非常有帮助，尤其是在使用两台以上显示器时。

Note: Windows 7 的显示器配置方式有所不同，但整体流程相同。
