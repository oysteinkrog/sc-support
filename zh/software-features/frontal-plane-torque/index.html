额状面扭矩分析 - 用户指南

简介

什么是额状面扭矩？

额状面扭矩（FPT）衡量您在高尔夫挥杆过程中围绕额状面轴所产生的旋转力。可以将其理解为衡量您利用地面反作用力产生旋转动力的效率。

当您挥动高尔夫球杆时，双脚向地面施力，地面同时向您的身体反弹。您身体的质心与双脚所受力之间的相互作用产生了扭矩——一种有助于驱动挥杆的旋转力。

功能组成

FPT 功能包含两个主要组件：

FPT 图表（DataBox） - 一个时序图，显示整个挥杆过程中的扭矩值及关键指标数据

3D 可视化 - 在动作捕捉骨架视图上实时叠加显示力臂和力分解

为什么这很重要？

了解您的额状面扭矩可以帮助您：

识别发力模式 - 了解您将地面反作用力转化为旋转能量的效率

可视化生物力学杠杆 - 在 3D 中查看质心与地面反作用力之间的力臂关系

分析定时 - 了解峰值扭矩相对于击球瞬间的发生时机

分解力的分量 - 查看地面反作用力在不同方向上的分布情况

比较挥杆 - 追踪您发力方式随时间的变化

前提条件

要使用额状面扭矩分析，您需要：

必需：带有地面反作用力数据的力板录制

必需：用于质心追踪的动作捕捉数据

必需：已完成校准的摄像机设置

必需：体重测量数据（用于归一化数值）

入门指南

将 FPT DataBox 添加至布局

  • 在分析视图中打开一段已录制的挥杆

  • 点击 DataBox 菜单或布局编辑器

  • 在可用的 DataBox 列表中找到额状面扭矩

  • 将其添加至您的分析布局

  • DataBox 将自动填充来自录制内容的数据

启用 3D 可视化

力臂和力分解的视觉效果将与骨架一同显示在 3D 视频视口中。要启用这些功能：

  • 打开一段包含动作捕捉和力板数据的录制

  • 在视频视图中找到力矢量设置面板

  • 启用您希望查看的可视化选项

所需数据

要使 FPT 分析正常运行，您的录制必须包含：

数据类型 是否必需 用途
力板数据 是 提供地面反作用力（Fx、Fz）及压力中心
动作捕捉 是 提供质心位置，用于扭矩计算和 3D 可视化
体重 是 用于归一化扭矩值以便比较
摄像机校准 是 正确 3D 对齐所必需
击球瞬间书签 建议设置 可启用相对于击球接触时刻的定时指标

了解显示内容

图表

主图表显示随时间变化的扭矩值：

X轴（水平）：从挥杆开始到结束的时间

Y轴（竖直）：扭矩值（可显示百分比和/或绝对值）

零线：位于零点的水平线——零线上方和下方的值表示相反的旋转方向

双轴系统

图表可同时显示两种不同的刻度：

左轴（百分比）：显示按体重归一化后的扭矩（Nm/kg，以力因子表示）

右轴（绝对值）：显示以 Newton-meter（Nm）为单位的实际扭矩

关键指标

图表旁显示三个关键指标：

1. 最大扭矩（力因子）

显示内容：按体重归一化后的峰值扭矩大小

单位：Nm/kg（以力因子表示）

示例：值为 0.85 表示您的峰值扭矩为每千克体重 0.85 Newton-meter

2. 最大扭矩定时

显示内容：峰值扭矩相对于击球瞬间的发生时机

单位：毫秒（ms）

注意：仅在设置了击球瞬间书签时显示

示例：-50ms 表示峰值扭矩发生在击球瞬间之前 50ms；+20ms 表示击球瞬间之后 20ms；0ms 表示恰好在击球瞬间

3. 力因子（原始值）

显示内容：包含方向（正值或负值）的原始归一化扭矩值

单位：Nm/kg

示例：+0.85 和 -0.85 具有相同的力的大小，但旋转方向相反

阶段高亮

启用后，彩色色带将叠加显示在图表上，以标示挥杆的不同阶段：

  • 反向挥杆、下杆动作、击球瞬间、随伴动作

3D 可视化

力臂可视化

力臂可视化展示了您的质心（COM）与地面反作用力之间的生物力学杠杆关系。

元素 外观 显示内容
力臂线 橙色实线 从您的 CoM 到作用线的垂直距离
作用线 橙色虚线 力的作用方向延伸线
距离标签 深色背景上的白色文字 力臂距离，单位为厘米（±X.X cm）

力矢量分解

力分解可视化将总地面反作用力分解为三个垂直分量。无论摄像机视图如何，各颜色始终代表相同的物理力方向：

分量 颜色 物理方向 显示内容
X 分量 粉色 左右（内外侧） 侧向力分布
Y 分量 青色 上下（竖直） 竖直力分布
Z 分量 绿色 前后（前后方向） 前向/后向力分布

每个分量箭头还会显示一个百分比标签，表示该方向力占总力的比例。

摄像机视图行为

力矢量相对于您的摄像机视图显示。为保持清晰，指向深度方向（即进入/穿出屏幕）的分量将被隐藏：

摄像机视图 可见分量 隐藏分量
正面视角 X（粉色，水平）、Y（青色，竖直） Z（绿色，深度）
下杆线视角 Z（绿色，水平）、Y（青色，竖直） X（粉色，深度）

注意：各颜色始终代表相同的物理方向——粉色始终表示内外侧力，青色始终表示竖直力，绿色始终表示前后方向力。仅屏幕位置会根据摄像机角度而变化。

3D 可视化设置

力臂设置

设置 默认值 描述
显示力臂 关闭 切换从 CoM 到力作用线的橙色实线
显示作用线 关闭 切换显示力方向延伸的橙色虚线
显示距离标签 关闭 切换距离数值标签（±X.X cm）

力分解设置

设置 默认值 描述
显示 X/Y/Z 分量 关闭 切换所有三个分量箭头及百分比标签

配置选项（图表）

显示百分比（百分比轴）：默认开启 - 切换归一化扭矩（Nm/kg）

显示 Newton（绝对值轴）：默认关闭 - 切换绝对扭矩（Nm）

高亮阶段：默认关闭 - 显示标示挥杆各阶段的彩色色带

显示网格线：默认开启 - 显示水平网格线

图表类型：山形图（默认）或折线图

故障排除

显示"测力板上无人"消息

  • 确认运动员在开始录制时站在力板上

  • 检查运动员档案中是否已输入体重

  • 确认力板校准已完成

图表数据为空或缺失

  • 确认力板在录制期间处于激活状态

  • 确认已录制动作捕捉数据（FPT 计算必需）

  • 检查录制内容是否涵盖完整的挥杆时长

定时指标未显示

  • 在录制中设置击球瞬间书签
