键盘快捷键与热键

Swing Catalyst 与 Motion Catalyst 支持多种键盘快捷键。

本文详细介绍这些键盘快捷键。

键盘快捷键可以是单个按键，也可以是组合按键。

在本文中，超过单个按键的快捷键使用 + 连接。

这并不意味着您需要按键盘上的 +，而是表示您需要同时按下两个（或更多）按键。

播放

键盘热键 / 快捷键 操作

Space 切换播放 / 暂停

Right 向前步进一帧

Left 向后步进一帧

Shift Right 向前步进总时长的 5%

Shift Left 向后步进总时长的 5%

Up 提高播放速度

Down 降低播放速度

书签

键盘热键 / 快捷键 操作 / 说明

1、2 或 3 跳转至视图端口 A 中当前录制的书签 1 至 3 的位置

Alt + 1、2 或 3 跳转至视图端口 B 中当前录制的书签 1 至 3 的位置

Ctrl + 1、2 或 3 将视图端口 A 中的书签 1 至 3 设置为当前播放位置

Ctrl + Alt 1、2 或 3 将视图端口 B 中的书签 1 至 3 设置为当前播放位置

Ctrl + Shift 1、2 或 3 同步书签 1 至 3

Ctrl + B 锁定 / 解锁书签以进行编辑

绘图工具

热键 操作（启用绘图工具）

C 圆形

R 矩形

V 箭头

L 直线

A 角度

F 自由视角

S 身体摇晃

E 橡皮擦

H 手

T 文字

B 油漆桶（清除全部）

动作捕捉

热键 操作

Shift+S 切换隐藏骨架

Shift+C 切换隐藏质心符号

Shift+A 切换角度工具

Shift+L 切换连接关节工具

Shift+T 切换追踪关节工具

Shift+M 切换移动关节工具

其他

热键 操作 / 说明

Ctrl + O 打开 / 关闭资源管理器

Ctrl + 鼠标向上滚动 放大（视频或数据图表，取决于鼠标焦点）

Ctrl + 鼠标向下滚动 缩小（视频或数据图表，取决于鼠标焦点）

Alt + C 切换捕捉模式（选择用户后）

Alt + A 在视图端口 A 中打开堆栈中的最新录制

Alt + B 在视图端口 B 中打开堆栈中的最新录制
