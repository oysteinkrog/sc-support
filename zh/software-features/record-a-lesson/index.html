如何录制课程

简介

课程视频对教练来说是一个实用工具，既可用于练习，也可作为练习会话的总结。课程视频基本上会录制整个 Swing Catalyst 应用程序在屏幕上的显示内容，允许您打开并比较任意挥杆录制、使用绘图工具绘制线条和文字，并按需回放挥杆内容。当您满意后，结束视频录制，即可通过U盘以视频文件形式分享、通过电子邮件发送，或上传至 YouTube 分享。

适用对象

  • 希望以视频片段形式（可选配音频解说）创建练习或总结的教练。

相关内容

解决方案

  • 在挥杆分析模式下，点击顶部菜单中的录制按钮。

  • 计时器将开始计秒，表示整个 Swing Catalyst 应用程序正在被录制，甚至包括鼠标指针。

  • 录制过程中您可以自由操作，以下是一些建议：

  • 打开您想要回放或相互比较的挥杆录制。

  • 以慢动作从头到尾回放，提供整体概览。

  • 移动时间轴以展示高尔夫挥杆中感兴趣的特定时刻。

  • 使用绘图工具在挥杆的不同时刻添加线条或文字注释。

  • 使用课程麦克风在录制过程中添加语音解说。

  • 在某处移动鼠标指针以强调屏幕上的任何内容。它将在视频中被高亮显示，便于查看。

  • 使用暂停按钮，避免在设置线条、文字或打开需要较长时间的新挥杆录制时浪费视频时长。例如，如果您想逐一讲解挥杆中的多个要点，并为每个要点设置不同的线条或文字，可以在切换和设置各个位置之间使用暂停功能。

  • 当您满意后，点击停止按钮以显示预览对话框。

  • 回放预览，确认内容无误且已包含麦克风音频。

  • 选择将视频文件保存到磁盘、通过电子邮件分享，或分享至 YouTube。

  • 之前录制的课程可在挥杆资源管理器的课程标签页中找到。

故障排除

问题：麦克风在 Swing Catalyst 中无法正常工作。

Windows 10 2018年4月更新导致麦克风问题

对于部分用户，Windows 10 现在基于隐私设置阻止 Swing Catalyst 使用麦克风。

升级至1803版本后，少数用户反映麦克风已被检测到，但无法拾取任何声音。为解决此问题，Microsoft 建议您按照以下步骤在隐私设置中启用麦克风：

打开"设置" 点击"隐私" 点击"麦克风"

开启"允许应用访问您的麦克风"切换开关。

请访问此 Microsoft 网站了解更多详情。

在某些情况下，防病毒软件可能会导致课程录制出现问题。

某些防病毒软件（如卡巴斯基）会导致 Swing Catalyst 在录制课程时卡死。

请卸载卡巴斯基，并改用其他防病毒软件，例如 Windows Defender 或 Carbon Black。
