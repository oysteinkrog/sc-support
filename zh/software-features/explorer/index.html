如何使用资源管理器

简介

资源管理器提供了一个界面，用于浏览、选择和管理按会话组织的视频录制内容。本文档介绍了如何在 25.3 及更新版本中有效地导航和使用资源管理器的所有功能。

概览

工具栏： 工具栏包含用于快速访问资源管理器所有核心功能的按钮。

用户列表： 已注册用户的列表，提供搜索栏和排序按钮等实用功能。

可下载内容列表： 已下载录制内容的列表，例如巡回赛挥杆视频。

会话与录制： 会话列表，可展开以显示该会话下的所有录制内容。

预览录制： 预览窗口，显示动态缩略图以及录制内容的关键信息。

导出列表： 将录制内容拖放至此处以添加到导出列表。随后可将录制内容导出为 Take 文件（便于稍后导入 SwingCatalyst），或导出为原始数据 TSV 文件以供自定义分析使用。

键盘导航

资源管理器支持通过键盘对录制缩略图进行完整导航：

方向键导航

  • ↑ - 向上移动一行

  • ↓ - 向下移动一行

  • ← - 向左移动一列

  • → - 向右移动一列

页面导航

  • Home - 跳转到当前会话的第一项

  • End - 跳转到当前会话的最后一项

  • Page Up - 向上翻页

  • Page Down - 向下翻页

跨会话导航

  • 当位于某会话的顶部/底部时，方向键将自动导航至相邻会话

  • 导航进入会话时，会话将自动展开

选择行为

资源管理器实现了标准的多选功能：

单项选择

  • 单击 - 选择单个录制内容

  • 双击 - 打开所选录制内容进行查看

鼠标多选

  • Ctrl** + 单击** - 切换单个项目的选中状态

  • Shift** + 单击** - 从上次选中的项目到当前点击项目进行范围选择

键盘多选

  • Shift** + 方向键** - 沿导航方向扩展选择范围

  • Ctrl** + 方向键** - 移动光标但不改变选择

  • Ctrl** + **A - 选择资源管理器中所有可见的录制内容

  • Ctrl** + Shift + **A - 选择当前会话中所有可见的录制内容

  • Escape - 清除可见的选择

选择信息

  • 选择计数器：显示已选中的总数量及可见已选中数量

  • 隐藏选择：指示在已折叠或已筛选的会话中存在已选中的项目

  • 视觉反馈：已选中的项目将以边框高亮显示

菜单与上下文操作

录制内容上下文菜单

右键单击任意录制内容可访问：

  • 打开 - 打开该录制内容

  • 添加到堆栈 - 添加到分析堆栈，便于在分析模式下快速访问

  • 添加到导出 - 添加到导出队列

  • 删除 - 移除该录制内容

  • 上传至在线 - 通过 SwingCatalyst Online 分享

学生/组上下文菜单

右键单击学生姓名可：

  • 将用户添加到导出列表 - 将该用户的所有录制内容纳入导出

  • 删除用户 - 移除该用户及其所有录制内容

全局命令

可通过键盘快捷键使用：

  • Enter - 打开所选录制内容。

  • Delete - 删除所有已选中的录制内容

  • Ctrl** + **A - 选择资源管理器中所有可见的录制内容

  • Ctrl** + Shift + **A - 选择当前会话中的所有录制内容

  • Escape - 清除当前选择

拖放操作

拖动录制内容

  • 拖动录制内容至放置区域

  • 视觉反馈以录制缩略图的拖动装饰显示

  • 放置指示器会高亮显示有效的放置目标

放置区域

  • 视口 A/B 放置区域 - 将录制内容拖放至此处以在视口 A 或 B 中打开

  • 导出列表放置区域 - 将录制内容拖放至此处以添加到导出队列

高效使用技巧

  • 批量操作：使用多选功能同时对多个录制内容执行操作

  • 键盘效率：组合使用 Ctrl、Shift 和方向键，实现快速选择工作流

  • 上下文感知：右键菜单提供与当前上下文相匹配的操作

  • 视觉反馈：注意选择计数器和高亮指示器

资源管理器专为高效的工作流管理而设计，让您能够快速浏览大量录制内容并以最少的操作完成批量处理。
