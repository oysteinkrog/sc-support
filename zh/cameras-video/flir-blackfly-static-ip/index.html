如何为 FLIR Blackfly GigE 摄像头设置静态 IP

简介

本支持文章介绍如何为 Blackfly（或 Blackfly S）GigE 摄像头配置静态 IP 地址。正常使用时无需进行此操作，因为 Swing Catalyst 会自动处理 IP 配置。

前提条件

  • SpinView 应用程序（Spinnaker SDK 的一部分）。

  • Swing Catalyst。

  • 一个或多个 FLIR Blackfly（或 Blackfly S）GigE 摄像头。

安装 Spinnaker

  • 下载并运行 Spinnaker 安装程序。

  • 右键单击 Spinnaker 安装程序，以管理员身份运行。

  • 勾选"Camera Evaluation"，然后单击"下一步"。

  • 按照屏幕上的提示完成安装。

  • 安装完成后，重启计算机。

为以太网适配器设置静态 IP

每个摄像头和网络适配器都必须拥有各自唯一的静态 IP 地址。例如，如果您为摄像头分配了静态 IP 地址，请确保网络适配器按照下方"推荐静态 IP 配置"矩阵中的对应 IP 进行配置。

警告

请根据关联的摄像头而非适配器编号来配置网络适配器。仅对已识别的摄像头更改相关设置，其他设置保持不变。如果将摄像头连接到不同的适配器，则需要重新配置才能正常使用。

在控制面板中，依次进入"网络和 Internet"、“网络和共享中心”，然后单击"更改适配器设置"。

此处可以看到计算机上所有网络适配器的列表。在本示例中，我们希望配置设备名称为"Intel Pro/1000"的以太网 2 和以太网 3。请务必仅配置用于摄像头的网络适配器，避免修改其他适配器，以免影响互联网连接。

右键单击您要修改的网络适配器，选择"属性"，然后向下滚动找到"Internet 协议版本 4 (TCP/IPv4)"，单击"属性"。

  • 选择"使用下面的 IP 地址"。

  • 从下方推荐静态 IP 配置矩阵中输入一个 IP 地址。

  • 输入子网掩码 255.255.255.0。

  • 选择"使用下面的 DNS 服务器地址"，可留空。

  • 单击"OK"。

推荐静态 IP 配置

以太网适配器编号 以太网适配器 IP 子网掩码 网关 连接的摄像头 摄像头 IP
1 10.0.1.1 255.255.255.0 10.0.1.1 1 10.0.1.10
2 10.0.2.1 255.255.255.0 10.0.2.1 2 10.0.2.10
3 10.0.3.1 255.255.255.0 10.0.3.1 3 10.0.3.10
4 10.0.4.1 255.255.255.0 10.0.4.1 4 10.0.4.10

网关可同时在摄像头上设置

为摄像头设置静态 IP

对其他需要设置静态 IP 的摄像头重复以上步骤。要访问摄像头 IP 配置，请打开 SpinView 应用程序，右键单击您要配置 IP 的摄像头。

  • 在设备列表中右键单击摄像头，选择"GigE Configuration"。

  • 单击"IP Configuration"。

根据下方推荐 IP 配置矩阵输入 IP 和子网掩码。

  • 输入摄像头的 IP 地址，使用矩阵中的 IP 地址，例如摄像头 1 对应的地址。

  • 输入子网掩码，例如：255.255.255.0。

  • 默认网关可留空，或使用摄像头所连接网络适配器的 IP 地址。

  • 取消勾选 DHCP。

  • 单击"Set Current and Persistent IP Configuration"。

摄像头推荐静态 IP 配置

摄像头编号 IP 子网掩码 网关
1 10.0.1.10 255.255.255.0 10.0.1.1
2 10.0.2.10 255.255.255.0 10.0.2.1
3 10.0.3.10 255.255.255.0 10.0.3.1
4 10.0.4.10 255.255.255.0 10.0.4.1

网关 IP 为摄像头所连接网络适配器的 IP 地址。

例如，摄像头 1 连接到网络适配器 1。

使用 SpinView 启用巨型帧并优化摄像头的网络适配器

请注意，以下更改需应用于所有与摄像头连接的网络适配器。

  • 在 SpinView 中，右键单击摄像头，选择"GigE Configuration"。

  • 单击"Configure Adapter Properties"。

  • 出现提示时单击"是"。

  • 单击"下一步"。

  • 单击"Auto Fill All"。

  • 单击"下一步"。

  • 勾选"Enable Media Optimization"。

  • 单击"下一步"。

  • 单击"Configure"以应用更改。
