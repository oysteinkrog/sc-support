设置 Swing Catalyst Fox USB 3.0 摄像头

本文涵盖摄像头的基本信息，以及如何设置和配置 Swing Catalyst 的 Fox USB 3.0 摄像头。

如需简要的分步指南，请参阅：https://swingcatalyst.com/camera-guide

摄像头信息：

  • “Lynx” 和 “Fox” 摄像头仅在 Swing Catalyst 9.8.2 或更高版本中受支持。 我正在运行哪个版本的软件？

  • 最大帧率为 249 FPS。

  • 最大分辨率为 1440 x 1080。

入门：摄像头组装

使用摄像头附带的 4 颗黑色十字头螺丝，将三脚架适配器固定到摄像头机身上。

拆开镜头包装，确保取下镜头的塑料保护盖

取下摄像头上的保护盖

将镜头安装到摄像头上

调整摄像头镜头

此镜头有三个调节项，从上到下依次为：

  • 对焦：（向 ∞ 无穷大符号方向调节）可使较远处的物体清晰对焦，反方向调节则可使较近处的物体清晰对焦。

  • 光圈：调节光圈（也称为 Iris）可控制通过镜头的进光量，光圈越小，图像越清晰。

  • 变焦：调节镜头的广角或长焦范围。（变焦也会影响对焦，因此需要同时调节两者以获得清晰图像。）

连接 USB 线缆

将 USB3 线缆连接到摄像头，并轻轻拧紧锁定螺丝。

摄像头应开始红色闪烁（这是 OK 的，因为我们尚未安装驱动程序）。

驱动程序安装及启用摄像头：

第 1 步：点击下载并安装摄像头驱动程序。

第 2 步：打开 Swing Catalyst，点击主菜单左下角的齿轮图标，进入摄像头设置。

第 3 步：点击播放按钮获取预览画面。然后点击"Disabled"，为每个摄像头分配合适的角度。最后将摄像头从"Off"切换为"On"。

配置摄像头设置：

第 1 步：点击"Advanced"按钮，进入"Camera"选项卡。

第 2 步：按照下方图片设置相同的参数值。重要提示：为了在击球瞬间清晰地看到杆身和球杆，您需要将曝光值设置为 600 或以下。通过提高"gain"来增加图像亮度。如果图像仍然较暗，可以适当提高曝光值，但这会导致杆身模糊。为确保获得最佳光源，我们强烈建议安装三盏以下灯具：Thomann 100w，一盏沿线向下、一盏正面角度右侧、一盏正面角度左侧，可天花板安装或墙壁安装。灯具与球的距离应至少保持 1.5 米。

第 4 步：将所有显示"continuous"的参数设置为"off"。

第 5 步：对已连接的其他所有 Fox 摄像头重复上述操作。

第 4 步：现在您应该可以关闭设置，进入捕捉模式并开始录制。

故障排除

USB 3.0 的使用有时较为复杂。部分 USB 线缆的性能优于其他线缆，某些 USB 3.0 控制器也可能引发问题。详情请参阅我们的推荐 USB 组件文章：recommended-usb3-components.md

丢帧问题：

降低每个摄像头的帧率可能有助于避免或减少丢帧现象。

尤其是在多摄像头配置中，适当调整帧率可以以牺牲少量 FPS 为代价来提升系统稳定性。

以下示例说明单台摄像头所占用的带宽：USB 3.0 的标称传输速度为 5Gb/s，即 625 MB/s。

一台分辨率为 1920 x 1200、帧率为 150 FPS 的 USB 3.0 摄像头，每台大约占用 345MB/s 的带宽。因此，对于多摄像头配置，按照我们的建议为每台摄像头配备独立的 USB 3.0 控制卡非常重要（大多数情况下）。

另一种方法（通常与降低带宽占用结合使用）是利用 Region of Interest，通常称为 ROI。

如果您的配置仍存在丢帧问题，请尝试断开一台摄像头（如果是多摄像头配置），并关闭其他软件。如果此操作有所改善，则可能表明您的计算机资源不足。

Region Of Interest（ROI）：

使用 Region of Interest（或感兴趣区域）可以减小整体图像尺寸并提升 FPS，同时也有助于降低带宽占用，从而减少丢帧现象（有关如何使用 ROI，请参见上文）。

此外，USB 线缆对实际接收帧率也有重要影响，详见：recommended-usb3-components.md

连接问题（摄像头断开连接）：

USB 3 容易出现连接问题。这类问题通常源于劣质的 USB 3.0 延长线、线缆总长度过长，或线缆因过度弯折而损坏。

摄像头 LED 闪烁红灯而非绿灯：

这可能表明摄像头驱动程序未正确安装。请尝试重新安装驱动程序，并将摄像头断开后重新连接到其他 USB 端口。

驱动程序异常有时可在 Windows 设备管理器中看到相关提示，此处 Fox 摄像头显示为"USB3 Vision Device"：

其他问题：

根据您的硬件情况，开启锐化和降噪滤波器可能并非最佳选择，关闭这些功能可降低部分 CPU 和 GPU 的占用。您可以在高级摄像头设置的滤波器选项卡中找到摄像头滤波器。有关滤波器的更多信息，请参阅：improving-image-quality.md
