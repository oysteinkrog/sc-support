如何设置 Halcon 以配合 Swing Catalyst 使用

Swing Catalyst 6.0 版本新增了对三种最常见机器视觉标准的支持。

  USB3 Vision                      GigE Vision                             GENiCAM

开始之前

本文主要介绍 Halcon 的安装步骤、许可证的安装方法以及 Ximea USB3 摄像头的基本设置。我们无法保证与更新版本的兼容性，SwingCatalyst 仅支持 Halcon 12。

如需了解更多关于如何确认您的摄像头是否支持 Halcon 的信息，请参阅：如何查看您的摄像头支持哪些标准以配合 Halcon 使用。

WARNING

Swing Catalyst 仅支持 HALCON 第 12 版。

  • Halcon 12 支持：GenAPI v2.4.1。

USB 许可证加密狗驱动程序与 Windows 10 及 11 不兼容！

安装 Halcon 时，务必取消勾选"Install Driver for USB Dongles"（安装 USB 加密狗驱动程序），否则您的电脑将在启动时崩溃。

有关如何安装新 USB 驱动程序的详细信息，请参阅我们的支持文章：

  • 连接 Halcon USB 许可证加密狗时电脑出现蓝屏

在安装 Halcon 后，请参阅针对您摄像头品牌的专项文章，以在 SwingCatalyst 中进行特定厂商的配置。

硬件要求：

  • 通用摄像头支持加密狗或绑定到网卡的许可证。

  • 符合 USB3 Vision、GigE Vision 或 GenICam 标准的摄像头。

  • 用于许可证加密狗的空余 USB 接口。

请确保您的硬件符合制造商的建议要求。

Note: 特定制造商的摄像头配置说明可在本文底部找到。

更多信息

  • Ximea USB3 Vision 信息：http://www.ximea.com/en/usb3-vision-camera/usb3zone

  • Point Grey USB3 Vision 信息：http://www.ptgrey.com/usb3-vision-cameras

  • Basler USB3 Vision 信息：http://www.baslerweb.com/en/support/knowledge-base/frequently-asked-questions

  • GenICam（摄像头通用接口）：http://www.emva.org/standards-technology/genicam/

软件要求

  • Halcon 许可证文件。您应已通过电子邮件收到该文件。

  • 请确保已安装最新版本的 Halcon。如果在 SwingCatalyst 中收到警告提示，请联系技术支持寻求帮助。

安装 Halcon

  • Halcon 运行时可在我们的下载页面找到，也可从此处直接下载。

  • 下载完成后，右键单击文件并选择"解压全部"。

  • 打开解压后的文件夹并运行安装程序。

  • 打开安装程序，按照屏幕上的提示以及以下逐步说明进行操作。

  • 选择"Install x64 version"（安装 x64 版本）。

  • 在"Choose Components"（选择组件）中，可取消选择除"Runtime x64"以外的所有组件。

  • 在"Additional Drivers"（附加驱动程序）部分，请务必取消勾选"Install driver for USB dongles"（安装 USB 加密狗驱动程序），这一步非常重要。

  • 如果您使用 GigE 摄像头，请确保勾选"Install MVTec GigE Vision Streaming Filter"（安装 MVTec GigE Vision 流媒体滤波器）。

  • 安装许可证文件时，选择"I have a license file that should be installed"（我有一个需要安装的许可证文件），并指定您从销售或支持人员处收到的许可证文件路径。

  • 按照屏幕上的提示继续操作。

WARNING: 如果使用 Windows 10 或 11，请取消勾选"Install driver for USB dongles"

请确保安装 GigE Vision 滤波器（注意： 如果您使用 GigE 摄像头，此项为必须安装）。

找到您通过电子邮件收到的 license.dat 文件，然后单击下一步。

完成安装。如果提示重启，请单击"是"。
