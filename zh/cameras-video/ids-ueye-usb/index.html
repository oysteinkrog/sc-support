如何在 Swing Catalyst 中使用 IDS uEye USB 摄像头

简介

本支持文章介绍了如何配置和使用 IDS uEye USB 摄像头的实际操作细节。

点击此处 查看安装详情

如需了解 GigE（网络 IDS 摄像头），请参阅此文章：ids-ueye-gige.md

适用范围

  • 初次使用 IDS uEye USB 摄像头与 Swing Catalyst。

摄像头说明

uEye USB 摄像头由三个独立部件组成：

  • 摄像头主体

  • 镜头

  • USB 数据线

摄像头

摄像头主体本身没有物理调节装置，所有设置均通过软件控制。

镜头

随附镜头具有 3 个调节环，从摄像头向外依次为：

  • 变焦

  • Iris

  • 对焦

变焦/对焦

在变焦（可变焦距）镜头上，变焦环和对焦环相互配合，因此同时微调两个调节环有助于获得良好的对焦/变焦效果。

Iris

Iris 调节环决定进光量（即"光圈开口大小"）。

收缩光圈会使图像变暗，但通过增加景深（“对焦清晰"的区域范围）有助于获得更好的对焦效果。

如果图像曝光过度（例如在非常晴朗的天气下），建议收缩 Iris。

软件设置

在 SwingCatalyst 中，所有摄像头设置均可通过主菜单中"设置 - 摄像头"下的"摄像头设置"中的"高级"按钮进行访问。

点击"高级"按钮后，高级摄像头设置对话框将显示出来。

对于 uEye 摄像头，有一些重要设置决定了摄像头的若干关键特性：

像素时钟

像素时钟本质上是一个"速度"设置，提高该值将增加可用的最大帧率，但设置过高可能导致丢帧。

帧率

帧率设置支持自动和手动两种配置方式。

建议使用手动设置，因为自动模式会禁用其他自动功能，例如自动 Gain。

曝光快门

低快门速度对于捕捉快速运动和减少运动模糊至关重要。

对于高尔夫挥杆，建议使用最大 2ms（毫秒）的曝光时间，以获得清晰的图像。

若需要非常清晰的图像，0.5ms 的曝光设置效果良好，但需要充足的光线，仅推荐在室外使用。

可以将曝光快门设置为自动模式，并通过"Max"自动参数设置上限，这是一个很好的选项，可使摄像头在保持良好图像质量的同时适应不同的光照条件。

Gain

Gain 可提高图像亮度，但也会在图像中引入更多噪点。

在大多数情况下，建议使用 Auto Gain，让摄像头自动调节。

白平衡

建议将白平衡设置为 Auto，以使摄像头自动调整图像中的色彩平衡。

如果图像中的颜色显示不正确，请使用手动设置来微调红、绿、蓝参数。

最大化每秒帧数（FPS）

您的最大 FPS 将因计算机配置而异。当发生丢帧时，意味着系统无法处理所有数据，需要降低速度。

以下是帮助您最大化摄像头表现的分步操作流程。

  • 前往主菜单 -> 设置 -> 摄像头。

  • 点击 uEye 摄像头上的"高级"按钮。

  • 在高级设置对话框中，导航至"摄像头"选项卡。

  • 点击视频预览面板中的"播放"按钮，开始实时视频串流。

  • 将"速度（像素时钟）“滑块向右拖动，直到看到丢帧计数器开始增加（右下角）。

  • 将滑块稍微向左拖动，直到不再丢帧，并保留一定余量。例如，如果发现在 38 时停止丢帧，则将其设置为 35。

找到帧率尽可能高且不丢帧的速度后，即设置完成。

故障排除

播放时丢帧/“画面抖动”

如果摄像头出现丢帧，说明计算机上的 USB 总线可能无法满足摄像头的带宽需求。

请尝试降低速度（像素时钟），直到摄像头不再丢帧。

完全无法对焦（图像非常模糊）

如果完全无法对焦（使用对焦调节环），请检查摄像头与镜头之间是否安装了金属环。

该金属环是 CS 转 C 接口转接环，当摄像头和镜头均为 CS 接口时无需使用。

升级至 Windows 10

请注意，使用 Windows 更新升级至 Windows 10 时存在已知问题。如果在尝试升级至 Windows 10 时遇到错误或"蓝屏”，您需要先通过"程序和功能"卸载 IDS 软件，然后在升级完成后从我们的下载页面重新安装驱动程序。
