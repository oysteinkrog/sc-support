使用新的硬件视频编码器加速视频处理

在 SwingCatalyst 9.3 及更高版本中，新增了对利用计算机显卡加速视频处理的支持。

此功能利用显卡上专用于视频编码的芯片，将 CPU 从繁重的计算任务中解放出来。根据显卡和 CPU 的不同，这可以显著提升视频编码速度。当然，更改这些设置也有可能导致编码时间变长。

默认编码器为 CPU MPEG-4。

请使用内置的基准测试功能，查看哪种编码器最适合您。

支持的显卡（h264 编码器）：

  • NVIDIA NVENC：推荐使用 GeForce 系列显卡，例如 1070、1080、2060、2070、2080 系列。

  • Intel QuickSync：大多数较新的 Intel CPU 内置了专用视频编码硬件，推荐使用符合我们推荐计算机配置的 CPU。*

  • 部分 Intel CPU 没有内置显卡芯片，因此不支持 Intel QuickSync。

支持 QuickSync 的 Intel CPU 列表：https://ark.intel.com/content/www/us/en/ark/search/featurefilter.html?productType=873&0_QuickSyncVideo=True

不支持 AMD 显卡。
