运行校准工具

为了使用您的平衡板，它需要一个校准文件。每块平衡板都会创建一个专属的校准文件，因此没有两个文件是相同的。如果您尚未安装校准文件，您的平衡板很可能也尚未完成保修注册。本文介绍了获取校准文件及注册平衡板的流程。

本文适用于消除平衡板 3 及以上版本的噪声干扰并改善压力分布。

平衡板由 2048 个高精度压力传感器组成，可能需要使用 Sensor Edge 工具对平衡板进行清零，以确保最佳精度。本文是关于如何对平衡板进行清零设置的分步教程。

重要！ ** **

此流程分为两个部分：

第 1 部分：使用 Sensor Edge 工具获取适用于您平衡板的最新校准文件。

第 2 部分：在 Swing Catalyst 中安装该校准文件。请务必阅读本支持文章的全部内容。

第 1 部分：使用 SE 工具获取校准文件

  • 下载校准工具

  • 如果提示安装驱动程序，请点击"是"。

将平衡板连接到计算机。

  • 请确保 Swing Catalyst 软件已关闭，若 Swing Catalyst 正在运行，SE 工具将无法检测到您的平衡板。

  • 打开新安装的 SE 工具

  • 按照以下说明进行操作。

  • 请确保计算机已连接显示器或电视，以便在站在平衡板上时能够看到屏幕。

如果您已安装旧版本，请先通过添加或删除程序将其卸载。

点击"Start（开始）"：

点击"Start（开始）“后，工具将自动尝试扫描设备。如果未找到您的平衡板，请点击下拉菜单并选择您的平衡板。

点击"Scan（扫描）”

选择与您平衡板序列号匹配的设备，然后点击"Next（下一步）"。

注册您的平衡板

已填写注册信息的示例

填写保修和服务所需的信息后，点击"Continue（继续）"。

如有可能，请选择一个摄像头并将其对准平衡板，然后点击"Next（下一步）"。

摄像头不是必须的，即使未检测到摄像头，您仍可继续操作。

请务必移除平衡板上的地毯及其他任何物品，以确保读数不受外部因素影响。

执行校准流程

在踏上平衡板之前，工具会先收集数据，以建立用于比较的基线。

请确保在工具指示您站上平衡板之前，不要误踩平衡板。

站立位置

按照工具的指示站在平衡板上非常重要。

深色脚印表示您当前应站立的位置，灰色脚印表示您下一步应站立的位置。

请按照每个步骤操作，这对于激活平衡板的所有区域至关重要。

完成录制

如果您对录制结果不满意，例如操作有误，可以点击"Restart（重新开始）“轻松重启流程。

如果您希望继续，请点击"Continue（继续）"。

点击"Save（保存）“按钮，然后点击"Send（发送）“按钮

在将数据发送给制造商审核之前，请输入大概的体重和使用情况。

在备注中，您可以说明平衡板存在的问题，例如左脚区域偏弱或其他问题。

制造商希望收集这些数据，是为了进一步改善重新校准算法，从而提供更准确的传感器读数。

输入信息后点击"Send（发送）"：

完成后，校准文件将保存到您的"文档"文件夹，点击"No（否）"，然后关闭工具。

第 2 部分：安装校准文件

继续执行以下步骤

  • 启动 Swing Catalyst，然后在主菜单中进入"Settings（设置）”–> “Hardware（硬件）"。

平衡板应会被自动检测到，如未检测到，请参阅故障排除部分。

点击"Configure…（配置…）“按钮以打开配置对话框。

传感器板设置

进入"Stance Sensor（站姿传感器）“选项卡，点击"Browse and Install（浏览并安装）"。

前往您保存校准文件的目录，例如：C:\User\YourUsername\Documents，选择您刚从工具中保存的 mxd 文件，然后点击"Open（打开）"。

安装完成后，系统将发出通知，您可以点击 OK 关闭窗口。

您的平衡板现在应该可以使用了。 在挥杆分析中开始一个新会话，并验证在捕捉挥杆动作时，压力与站立数据框中能否获得压力读数。

注意：在大量使用后，可能需要对您的平衡板重新进行校准，可在 Swing Catalyst 设置中点击诊断按钮来完成此操作，这将启动 SE 工具。

故障排除

平衡板未被识别或未显示为已连接：

  • 请确保设备已被 Windows 识别。

打开 Windows 设备管理器。如何操作？

  • 确认 Sensor Edge 设备显示在 Ports（COM & LPT）（端口（COM 和 LPT）） 下

  • 如果未显示或存在警告符号，请尝试重新安装驱动程序并将设备重新连接到其他 USB 端口。

  • 将设备连接到计算机上的其他 USB 端口。

  • 如果使用了 USB 延长器，请尝试不使用延长器直接将设备连接到电脑。

  • 重启 Swing Catalyst。

  • 重启计算机。

  • 如果您已尝试以上所有步骤，但 Swing Catalyst 中仍显示未连接，请联系我们的支持团队。

校准未成功安装

  • 您从 Sensor Edge 工具获得的校准文件可能已损坏，请尝试重新运行工具并安装新的校准文件。如果仍无法解决，请联系我们的支持团队。

运行工具后平衡板仍有噪声

噪声可能由以下几种因素引起：

  • Swing Catalyst 中安装的校准文件有误或未安装校准文件。

  • 大量使用： 校准工具应定期运行，对于频繁使用的平衡板，建议每月至少运行一次。

  • 直接暴露在阳光下。

  • 传感器本身的磨损。

如果信噪比不足，工具可能无法滤除噪声，此时需要通过 RMA 流程对平衡板进行重新校准。制造商将手动检查工具生成的会话，以确认是否能够加以改善。

如果制造商无法解决该问题，且平衡板在保修期内或已购买 ESA（延长服务协议），则可在提供 RMA 的前提下将平衡板寄回制造商。

硬件兼容性问题

在使用 USB 1.1 设备时，AMD 300 系列芯片组（AMD Ryzen 1700 / 2700 系列）存在一些已知问题。具体体现在平衡板上，即每秒仅能获得 75 个采样，而非正常的约 145 个采样。我们建议使用 USB 2.0 集线器，以使平衡板能够以完整采样率进行数据传输。

目前，使用 AMD 300 系列芯片组与 USB 3.0 设备配合使用时，尚无已知问题。
