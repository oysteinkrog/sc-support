如何将 TrackMan 与 Swing Catalyst 配合使用

本文介绍如何将 Swing Catalyst 连接到 TrackMan，并将弹道仪数据与视频一同保存。要启用集成功能，必须在运行 Swing Catalyst 的同时运行 TrackMan 软件。

note: 若要将 TrackMan 与 Swing Catalyst 配合使用，您需要拥有一台支持视频流传输的摄像机。（请参阅支持的摄像机）

安装：TrackMan Pro/Launch 4.0.9

  • 将 TrackMan 设备连接到电脑

  • 启动 TrackMan Pro 或 TrackMan Launch，并导航至击球追踪界面

  • 启动 Swing Catalyst，在开始菜单中进入 设置 - 硬件

  • 启用 Launch Monitor 集成

  • 选择 TrackMan

安装：TrackMan Performance Studio

支持版本 2.2-4.0

  • 将 TrackMan 设备连接到电脑

  • 启动 TrackMan Performance Studio

  • 在开始菜单中导航至 设置 界面（图1：齿轮图标）

  • 启用 SDK Output（图2）

  • 导航至 开始 并点击 Shot analysis

  • 启动 Swing Catalyst，在开始菜单中进入 设置 - 硬件

  • 启用 Launch Monitor 集成

  • 选择 TrackMan

安装：TPS 配合 TM3e 或 TrackMan 4

  • 开启 TrackMan 3e 设备

  • 在 Windows 中连接到 TrackMan WiFi 网络，或使用 USB 线缆连接。

  • 除第1步外，其余步骤与上述安装指南相同

图1：在 TrackMan Performance Studio 中启用 SDK output。

将 Swing Catalyst 与 TrackMan Pro/Launch/Performance Studio 配合使用

  • 先启动 TrackMan 软件并进入击球追踪界面。

  • 启动 Swing Catalyst 并捕捉挥杆。

  • 打开已录制的挥杆，在视频旁的数据框中查看击球数据。

如果一切安装正确，系统现在应会自动捕捉 TrackMan 击球数据并与视频一同保存。

摄像机配置

在某些情况下，TPS 软件可能会锁定系统中的摄像机，导致其在 Swing Catalyst 软件中不可用。

在未来版本中，TPS 软件可能会引入禁用此行为的配置选项，但在此之前，TrackMan 提供了以下解决方法：

打开 TPS 软件，记下摄像机列表中显示的摄像机确切名称。

找到以下文件并用记事本打开：

C:\ProgramData\TrackMan\VideoManagement\ExcludeCameras.TMConfig

将摄像机名称添加到文件中。如果有多台摄像机，请将所有名称逐行添加。

故障排除

  • 检查 TrackMan 是否在 TPS 中被识别并成功连接。

  • 确保在 Swing Catalyst 硬件设置菜单中已启用 Launch Monitor 并选择了 TrackMan。

  • 检查 Swing Catalyst 中 Launch Monitor 设置下方的"触发器"是否已勾选。

  • 如果仍未触发，请在 TPS 中检查设置，确保已启用"SDK Output"。

  • 尝试重启 TrackMan 设备。

  • 如果已获取数据且在 Swing Catalyst 中显示为已连接，但未触发，请尝试重启电脑。

  • 已触发但延迟很长：尝试在 Launch Monitor 设置中调整延迟补偿，建议值约为 1500ms；具体数值取决于球的类型以及雷达是在室内还是室外使用。

如果在 Swing Catalyst 中仍未获取到任何数据：

  • 尝试重启 TrackMan 设备，并重新检查 SDK output 是否已启用。

  • 尝试禁用 Windows 防火墙，如果有效，请为 TPS 和 Swing Catalyst 添加例外。

  • 检查 TrackMan OEM 服务是否正在运行。如果是，请将其禁用后重试。有关 Windows 服务的更多信息，请参阅：http://www.7tutorials.com/what-are-windows-services-what-they-do-how-manage-
