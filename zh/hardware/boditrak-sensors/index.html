如何在 Swing Catalyst 中使用 BodiTrak 传感器

简介

本支持文章将介绍如何在 Swing Catalyst 中设置和配置 BodiTrak 2 Vector 传感器板。从技术角度而言，本文也适用于较旧的 BodiTrak 16x25 和 16x27（BT 型号）。

系统要求

  • 配有空闲 USB 端口的电脑。

  • SwingCatalyst 9.7 或更高版本，且需支持传感器板功能。

  • 下方支持传感器矩阵中列出的其中一款型号。

  • Windows 10 或 11 64 位（x64）（注意：我们不支持 ARM 或 x86 架构）。

支持哪些传感器？

我们支持以下型号，请注意其中部分型号已停产。截至 2024 年，我们并不支持 BodiTrak 的所有传感器型号。

型号 / 型号编号 行 x 列 尺寸（宽 x 高）厘米

BT7150 16x25 71 x 45.5

BT（原型机？） 16x27 75.6 x 44.8

BT2-1632-500 16x32 94 x 47

BT2-1625-500 16x25 73 x 47

BT2-1625-500 16x25 71 x 45.5

如需进行测力板标定，请联系 BodiTrak 支持团队。

驱动程序安装

驱动程序安装由 Windows 自动完成。

如果您的系统未安装任何 BodiTrak 软件，且传感器未显示为已连接或未被识别，请联系 BodiTrak 支持团队。

可能的问题来源：

  • USB 线缆问题。

  • 与 PC 的连接问题。

请参阅我们的故障排除部分以获取更多提示。

配置

以下步骤并非严格必要，但有助于验证传感器是否在 Swing Catalyst 中被正确检测并正常工作。

启动 Swing Catalyst，进入"设置 -> 硬件"。

  • 传感器板应会被自动检测（若未能自动检测，请尝试从下拉菜单中手动选择 BodiTrak 2 Vector）。

  • 请确保其已开启（否则集成功能将无法正常工作）。

如需打开传感器配置对话框，请点击"配置…"。

注意：如果您无法连接到传感器或收到错误提示，请参阅我们的故障排除部分

传感器板设置

您可以在传感器板设置窗口中查看实时数据、应用旋转，以及查看序列号等附加传感器信息。

中间的大白点表示压力中心 (CoP)， 用于衡量您身体的平衡状态。

若您处于平衡状态，CoP 将位于双脚之间的中心位置；当身体向前或向后倾斜时， CoP 将相应地向前或向后移动。 将重心向左或向右移动会使 CoP 向左或向右偏移。

每个脚印下方的两个较小圆点表示各脚的 COP， 显示每只足部区域内的压力中心位置。 两点之间的连线表示您站立的平面。

旋转（如何旋转、镜像或翻转压力数据）

点击"旋转站立数据"按钮可对传感器板进行旋转。点击该按钮可将数据旋转 180 度；如需更高级的设置，请参阅"高级"选项。

点击"高级"可访问高级旋转设置：

如需竖直翻转数据，可点击"翻转"。

故障排除

请注意：

如需任何支持、维修或退货服务，请联系 BodiTrak。

本故障排除部分旨在帮助您识别并解决在将传感器与 Swing Catalyst 配合使用时可能遇到的问题。

数据显示翻转，但垫子摆放方向正确

  • 您可以在传感器板设置中竖直翻转数据，请参阅旋转。

BodiTrak 传感器未被识别或未显示为已连接：

如果 BodiTrak 软件正在运行，可能会阻止对传感器的访问。同样，BodiTrak DataPort 是一项可能在您系统上运行的服务，会阻止 Swing Catalyst 连接到传感器。

  • 确保没有 BodiTrak 软件正在运行。

  • 停止 BodiTrak DataPort 服务。

停止服务：点击 Windows 开始菜单按钮，输入"服务"，点击"服务"应用程序，找到"BodiTrak Data Port"，右键点击并选择"停止"。

如需停止该服务，请按 Windows 开始菜单的 Windows 图标，然后输入"服务"。

打开"服务"应用程序，找到 BodiTrak DataPort，右键点击并选择"停止"。

停止该服务可能会导致其他使用 BodiTrak 的应用程序无法正常工作，但将允许 Swing Catalyst 连接到传感器。

如果未安装 BodiTrak DataPort，请继续执行以下故障排除步骤。

  • 打开 Windows 设备管理器。如何操作？

验证 BodiTrak 设备是否显示在 USB 串行设备下。

  • 如果没有显示，或旁边有警告符号，请尝试将设备重新连接到其他 USB 端口。

  • 将设备连接到电脑上的其他 USB 端口。

  • 如果使用了 USB 延长线，请尝试不使用延长线直接将设备连接到 PC。

  • 重新启动 Swing Catalyst。

  • 重新启动电脑。

  • 如果您已尝试以上所有步骤，且设备在 BodiTrak 软件中可以正常使用，但在 Swing Catalyst 中无法使用，您可以联系我们的支持团队。

传感器垫上存在噪点 / 校准问题

  • 长期大量使用后，传感器可能需要重新校准，请联系 BodiTrak 支持团队。

  • 传感器与顶部垫面之间可能存在杂物，请确保传感器区域无杂物。

  • 检查传感器底部是否有杂物顶压垫底。

脚印显示较浅

如果脚印显示较浅，可能与传感器对低压力值处理方式的校准有关。可能是传感器校准有误，或需要重新校准。

Swing Catalyst 不会对从 BodiTrak 传感器接收到的数据进行任何额外的滤波处理。但如果您的 BodiTrak 垫在 Swing Catalyst 中显示的脚印与其他程序中显示的不同，欢迎通过我们的帮助中心提交支持工单，我们将尽力进行排查。
