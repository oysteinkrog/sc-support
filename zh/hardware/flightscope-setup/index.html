如何将 FlightScope 与 Swing Catalyst 配合使用

简介

本支持文章介绍了如何将 FlightScope Launch Monitor 与 Swing Catalyst 配合使用。Swing Catalyst 在录制新录制时将整合并存储所有 FlightScope 数据。要启用该整合功能，FlightScope 软件必须与 Swing Catalyst 同时运行。

适用范围

  • 使用 FlightScope Launch Monitor 的用户。

支持的型号：

  • X1、X2、X2 elite 及 X3 系列。

  • Xi 及 Xi+ 系列。

安装

为使 Swing Catalyst 能够识别并读取 FlightScope 的击球数据，需要在 FlightScope 软件中启用服务器模式。

  • 启动 FlightScope，并在主菜单中点击"Advanced Settings"按钮。（在较新版本的 FlightScope 中，您只需按下键盘上的 ALT 键即可调出菜单栏。）

  • 点击位于右下角的 Advanced Settings 按钮，屏幕顶部将显示一个菜单栏。

  • 点击 Networking，并从列表中选择 Server。

  • 确认"Server Port"已设置为 1248，然后按 Ok。

注意：服务器名称和服务器 IP 地址可能因您是通过 USB X2（X2 Elite 使用以太网）还是 WiFi 连接而有所不同。通常无需更改此设置。

  • 在 FlightScope 中切换到 Player Comparison 或类似模式。

  • 确保 FlightScope 正在追踪并显示击球数据。

  • 启动 Swing Catalyst，并保持 FlightScope 在后台运行。

  • 进入 Swing Catalyst 主菜单 - 设置 - 硬件，勾选 Launch Monitor 下的"Enabled"选项。

如果显示已断开连接，请确认 FlightScope 应用程序正在运行，且 FlightScope 设备已连接到电脑或 WiFi 网络。

FlightScope 应显示"Server active, 1 clients"，这表示 Swing Catalyst 已成功连接到 FlightScope。

已知问题

  • 即使 FlightScope 软件正在运行、追踪击球且已启用服务器模式，FlightScope 仍未显示为已连接。

  • 尝试重启 FlightScope 和 Swing Catalyst。请先启动 FlightScope。

  • 尝试将服务器模式设置为 None，然后重新开启。请参见第 3 步。

  • FlightScope 显示在错误的屏幕上。

  • 若要将 FlightScope 移至其他屏幕：点击 FlightScope 程序窗口，然后将鼠标光标移动到目标显示器上。将鼠标光标停留在目标屏幕上，按下 F11 键。FlightScope 现在应在另一个屏幕上运行。
