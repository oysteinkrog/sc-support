如何在 Swing Catalyst 中使用 Foresight GCQuad

介绍

本支持文章将描述如何使用Swing Catalyst设置Foresight GCQuad / GCHawk。GCQuad可同时与FSX和Swing Catalyst配合使用。

要求

  • 配备可用USB端口或WiFi（独立于互联网连接）的计算机。

  • Swing Catalyst 8.0或更高版本

注意：如果您要将高清摄像机与Swing Catalyst一起使用，我们建议单独运行FSX（即不与Swing Catalyst同时运行）或在不同的计算机上运行。

请确保您至少拥有NVIDIA GeForce 1080或更好的显卡，并且PC充分满足Foresight的建议要求。

安装

  1. 通过USB、WiFi*或以太网连接GCQuad。

  2. 在Swing Catalyst设置 -> 硬件中选择Foresight GCQuad。

  3. 确保Launch Monitor已打开并选中"用作触发器"。

*** If connecting via Wi-Fi it’s important you have another means of internet connectivity as it must be validated through the internet in order to use the GCQuad.**

***If GC Hawk isn’t importing club data make sure firmware is updated to latest version. **

*Putting mode is not supported as a trigger in Swing Catalyst.

Troubleshooting

The Foresight GCQuad is not showing as connected or is not triggering

  • Power cycle the Foresight GCQuad / GCHawk.

  • Make sure that the Foresight GCQuad is showing up on your computer. It will show up as a Mass Storage Device under This PC.

  • Connect the device to a different USB port on the computer if it doesn’t show up.

  • If connected through WiFi make sure you have access to the internet through other means, or have a separate WiFi dongle. The connection to the GCQuad must be dedicated.

  • Make sure the GCQuad LED is green, not blue. If it is blue the club tracking is turned off. Club tracking must be on for it to work. See Foresight GCQuad manual for more information: https://www.foresightsports.com/sites/default/files/files/GCQuad_User_Manual.pdf

  • Restart Swing Catalyst.

  • Restart the computer.

  • If you tried all these steps and it still shows as not connected in Swing Catalyst, please contact support@swingcatalyst.com.
