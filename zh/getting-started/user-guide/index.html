安装软件和许可证密钥

每个新的 Swing Catalyst 许可证都随附一封电子邮件，其中包含相关说明。如果找不到该电子邮件，请检查您的垃圾邮件文件夹或搜索您的收件箱。

按照说明下载并安装 Swing Catalyst，安装完成后在软件提示时输入许可证密钥。

获取许可证密钥安装时遇到问题？请参阅我们的分步指南。

连接一个或多个摄像机

Note: 并非所有许可证都支持实时流摄像机，例如 Swing Catalyst Lite。

请参阅此支持的摄像机列表。

如果您使用的是 FLIR、IDS 或 AVT 摄像机，您可能需要下载并安装相应的驱动程序。请查看我们的驱动程序部分。如果您使用的是 FLIR 摄像机，请参阅我们的专用摄像机指南。

Note: 我们建议在执行任何摄像机相关驱动程序安装前，不要运行 Swing Catalyst。安装驱动程序后，您可能需要重新启动计算机。

从主菜单可以通过单击齿轮图标找到设置。

检测到的摄像机将自动列在摄像机列表中。

要使用摄像机，需要为其指定角度。

通过单击禁用图标选择角度，然后将"OFF"更改为"ON"以启用摄像机。

连接 Launch Monitor

注意：Launch Monitor 支持取决于许可证类型，如果您无法启用此部分，说明您的许可证不支持 Launch Monitor。如果是这种情况，您可能需要考虑从 BASIC 许可证升级到 PRO 许可证：https://shop-world.swingcatalyst.com/products/swing-catalyst-software-2019

在"硬件设置"下，您可以在支持的 Launch Monitor 之间进行选择。

在列表中选择您的 Launch Monitor，将其切换为"ON"，并启用"用作触发器"。

  • 确保 Launch Monitor 已打开并连接到电脑。

  • 我们始终建议使用有线连接（如可能），例如 USB 或以太网而非 WiFi。

有关如何设置 Launch Monitor 的更详细说明，请参阅以下指南：

  • Foresight GCQuad/GCHawk/GC3

  • Flightscope X-Series

  • FlightScope Mevo+

  • FullSwing (E6)

如果您选择了 Launch Monitor 作为触发器设备，它将在捕捉模式下自动录制您的挥杆。如果您没有 Launch Monitor，没关系，您可以改为使用麦克风作为触发器！

创建新用户

按以下步骤创建用户并录制挥杆。

从主菜单中，点击"开始"

点击"选择用户"下拉按钮，然后点击"新建"：

注意：根据您的许可证详情自动生成用户，如果您希望编辑这些信息或添加新用户，可以分别点击"新建"或"编辑"。

输入名称并点击"保存"

某些家庭版许可证有最大用户限制，这限制了可以在 Swing Catalyst 中存储的用户配置数量。

分析菜单工具栏

从左到右：菜单、资源管理器、切换用户、捕捉、捕捉选项和布局。

Swing Catalyst 图标也是菜单按钮，可快速访问设置和结束当前会话。

切换用户

捕捉

要录制挥杆，您需要处于捕捉模式。

点击"捕捉"按钮时，您会自动从播放模式切换到捕捉模式。

绿色的"捕捉就绪"图标表示系统已准备好进行捕捉。使用家庭版时，启动会话后您将自动进入此模式！

“捕捉就绪"只是表示捕捉模式已启用，Swing Catalyst 正在主动流传输数据。仅在触发事件发生时保存，例如（手动触发、Launch Monitor、麦克风）。

捕捉选项

选择不同的触发器选项，如麦克风或Launch Monitor，并更改捕捉模式。

布局

您可以通过使用"布局"下拉按钮在Swing Catalyst中选择不同的布局。

Swing Catalyst会分别记住在播放和捕捉模式中最后使用的布局。

如图标所示，布局在显示的内容和显示方式上存在一些差异。

摄像机布局选择

在同一下拉菜单"布局"中，您可以选择要显示的不同摄像机角度数量，具体取决于布局。在播放模式下（查看录制的挥杆时），摄像机选择仅取决于用于创建录制的摄像头数量。

在捕捉模式下，可见摄像头的数量取决于您的系统上启用了多少个摄像头，以及许可证是否支持您要使用的摄像头数量。

切换摄像机角度

如果您的录制具有多个摄像头，可以通过单击摄像机图标来更改所查看的摄像头。

也可以从此处进行一些小的摄像头调整，例如镜像和旋转摄像头角度。这些更改仅适用于录制，如果您希望比较左手用户和右手用户等，可能会很有帮助。

绘图工具

如上面的屏幕截图所示，绘图工具位于软件的左侧。

绘图工具允许您在视频图像上绘制，既可以在已录制的视频上绘制，也可以在实时视频"馈送"上绘制（在捕捉模式下）。绘图工具的选择可能因许可证而异。

请注意：绘图不会存储到录制本身，但它们会在每个会话中被记住，因此可以在一个录制上绘制，然后打开其他录制（例如以前的挥杆），绘图保持在相同位置。

同样适用于捕捉和播放，绘图位置已保存，但独立存储在捕捉和播放中，不会保存到录制本身。

线条工具有多种线条类型可供选择，标准的"线条"允许您在任意两点之间创建直线。

箭头工具

自由绘制，位于箭头工具下方，允许您自由绘制。功能上这些绘图工具中的大多数都很相似。同样，有三种形状可供选择：圆形、矩形和"人物"。这些通常用于跟踪整个运动类型中的运动。

绘图工具是展示挥杆过程中与初始站姿偏离程度的好方法。

有三种不同的线条粗细可供选择。

不同的颜色使得区分不同的线条更加容易。

角度工具

角度工具可用于获得角度的近似值，例如高尔夫挥杆中击球瞬间腕部的角度。

文本工具

缩放和平移工具

在工具栏的最底部，绘图工具下方，有缩放和平移工具以及"填充视频视图"按钮。

还可以通过同时按住 Ctrl 键并滚动鼠标滚轮来缩放和操纵视频图像。

保存常用布局

许多用户会根据他们的工作内容（教学、回放、对比、Launch Monitor 重点、压力/受力重点等）在不同的布局之间切换。每次重新构建设置——更改布局类型、摄像机排列和数据框中显示的内容——可能很耗时。

常用布局让你保存当前设置，以便稍后快速切换回它。常用布局可包括：

  • 选定的布局

  • 选择的摄像机布局

  • 数据框中显示的内容（图表/可视化）

如何保存常用布局

按照你想要的方式设置屏幕：

选择布局（例如，单个录制、对比、数据中心等）

  • 选择摄像机数量

  • 按照你的偏好配置数据框内容

  • 点击顶部菜单中的布局以打开布局下拉菜单。

  • 在常用布局部分，点击**+ 保存当前**。

  • 输入常用布局的名称（例如：动力学序列、弹道仪数据、课程回放等）。

  • 点击保存。

你的新常用布局现在将出现在常用布局列表中。

如何在常用布局之间切换

  • 点击顶部菜单中的布局以打开布局下拉菜单。

  • 在常用布局下，点击你想使用的常用布局。

SwingCatalyst 将立即应用保存的设置（布局、摄像机布局和数据框内容），使你可以快速在不同的教学或分析工作流之间切换。

注意和提示

  • SwingCatalyst 仍将记住你在播放和录制模式下最后使用的布局，如前所述。常用布局只是在需要时快速跳转到特定设置的更快方式。

  • 在播放模式中，可用的摄像机视图取决于录制时使用的摄像机数量。在录制模式中，可用的摄像机视图取决于有多少摄像机已启用以及你的许可证支持的内容。

  • 使用清晰的名称描述设置的用途（例如，压力和站姿、球杆数据、快速对比），以便在会话期间轻松切换

资源管理器

您可以在此轻松管理您的录制内容。资源管理器分为三个"部分"：

左侧是在系统中注册的用户，中间是相应用户的所有录制内容，右侧是预览部分。

录制内容会自动按会话分组，并按日期排序。

  • 点击一个挥杆，它会自动在"预览"部分（右侧）显示预览。

您也可以通过右键单击并选择要在其中打开录制内容的视口来打开录制内容，或者将其拖放到底部的"在此放置录制内容"区域。

滤波

可以根据不同的收集参数对录制内容进行滤波，例如：

  • 运动（虽然 Swing Catalyst 仅用于高尔夫，但可以查看不同运动的录制内容）

  • 球杆类型

  • Launch Monitor 弹道仪数据（飞行距离、旋转速度或击球效率）

  • 评级（1-3 星评级）
