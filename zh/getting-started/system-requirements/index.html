Swing Catalyst 的电脑要求

重要提示： Swing Catalyst 与 Mac OS（Arm 架构）或 Windows 11 Arm 不兼容。

快速摘要

为确保流畅的视频采集与播放，您的电脑应满足以下基本要求：

  • 近期款游戏笔记本电脑或高性能台式电脑

  • 32 GB 内存（RAM）

  • 现代显卡（NVIDIA RTX 3060 6GB 或更高）

  • 近期款 Intel 或 AMD 处理器，具备 8 个或更多核心

  • 我们强烈建议使用最新系列的 NVIDIA GPU，以获得最快的编码速度和 MoCap 处理能力。目前最新系列为 RTX 5060、5070、5080、5090。

笔记本电脑要求

如果您使用笔记本电脑，我们推荐配备以下规格的游戏本：

  • 内存：32 GB RAM

  • 处理器：近期款 Intel i5、i7 或 i9（第 9 代或更新），至少 8 个核心

  • 显卡：NVIDIA RTX 3060（或更新），至少 6GB 独立显存

摄像头连接指南

  • 仅使用随摄像头附带的原装高质量 USB 线缆，或使用其他机器视觉认证线缆

  • 将摄像头直接连接到电脑（避免使用 USB 集线器或延长线）

  • 最多可同时连接两台 USB 摄像头

  • 对于以太网（GigE）摄像头，请确保有空闲的 PCI Express 插槽，用于安装专用网卡（根据摄像头数量可能需要多张网卡）。

详细硬件推荐

推荐处理器

Intel 选项（从最新到最旧）

第 14 代（最新）

  • Intel Core i9-14900/14900K（最佳表现）

  • Intel Core i7-14700KF（优秀表现）

  • Intel Core i5-14400F（良好表现）

第 13 代

  • Intel Core i9-13900K/KF

  • Intel Core i7-13700K/KF

  • Intel Core i5-13600K/KF

第 12 代

  • Intel Core i9-12900K

  • Intel Core i7-12700K

  • Intel Core i5-12600K

AMD 选项

  • AMD Ryzen 9 9950X3D（16 核心，最佳表现）

  • AMD Ryzen 7 9800X3D（8 核心，优秀表现）

  • AMD Ryzen 9 7900X（12 核心，最佳表现）

  • AMD Ryzen 7 7700X（8 核心，良好表现）

  • AMD Ryzen 9 5900XT（16 核心，上一代产品，性价比高）

对于 AMD CPU，我们强烈建议额外购买一张 USB 3 控制器扩展卡，以获得最佳兼容性。

技术说明： 您的处理器应能达到 3.8GHz 或更高的频率，以获得最佳表现。本软件要求处理器支持 AVX 和 AVX2 指令集（大多数现代处理器均支持此功能）。

推荐显卡

我们建议最低配备 6GB 独立 GPU 显存（VRAM），显存越大越好。

顶级（卓越表现）

  • RTX 5090（最佳选择）

  • RTX 4090

  • RTX 3090

  • RTX 4080

高级（出色表现）

  • RTX 5080

  • RTX 5070

  • RTX 4070

  • RTX 3080

中级（良好表现）

  • RTX 5060

  • RTX 3070

  • RTX 4060

入门级（最低推荐）

  • RTX 3060

注意： 以上所列显卡均满足软件的最低要求。更高级别的显卡将提供更好的表现，尤其是在使用多台摄像头或处理高分辨率视频时。
