推荐的计算机规格

Swing Catalyst 的计算机要求

重要提示： Swing Catalyst 不兼容 Mac OS (Arm 架构) 或 Windows 11 Arm。

快速总结

为了确保顺畅的视频捕捉和播放，您的计算机应满足以下基本要求：

  • 一台近期发布的游戏笔记本电脑或功能强大的台式计算机

  • 32 GB 内存 (RAM)

  • 一张现代图形卡（NVIDIA RTX 3060 6GB 或更好）

  • 一个近期发布的具有 8 个或更多核心的 Intel 或 AMD 处理器

  • 我们强烈建议使用最新系列的 NVIDIA GPU，以获得最快的编码时间和 MoCap 处理速度。目前最新系列是 RTX 5060、5070、5080、5090。

笔记本电脑要求

如果您使用笔记本电脑，我们推荐一台游戏笔记本电脑，配置如下：

  • 内存：32 GB RAM

  • 处理器：近期发布的 Intel i5、i7 或 i9（第 9 代或更新版本），至少具有 8 个核心

  • 显卡：NVIDIA RTX 3060（或更新版本），至少具有 6GB 专用显存

摄像头连接指南

  • 仅使用随摄像头附带的原始高质量 USB 线缆，或使用其他机器视觉认证线缆

  • 将摄像头直接连接到您的计算机（避免使用 USB 集线器或延长线）

  • 最多一次只能连接两个 USB 摄像头

  • 对于以太网 (GigE) 摄像头，请确保有可用的 PCI Express 插槽用于专用网卡或多张网卡（取决于摄像头数量）。

详细的硬件建议

推荐处理器

Intel 选项（从最新到最旧）

第 14 代（最新）

  • Intel Core i9-14900/14900K（最佳性能）

  • Intel Core i7-14700KF（优异性能）

  • Intel Core i5-14400F（良好性能）

第13代

  • Intel Core i9-13900K/KF

  • Intel Core i7-13700K/KF

  • Intel Core i5-13600K/KF

第12代

  • Intel Core i9-12900K

  • Intel Core i7-12700K

  • Intel Core i5-12600K

AMD选项

  • AMD Ryzen 9 9950X3D（16核，最佳性能）

  • AMD Ryzen 7 9800X3D（8核，优异性能）

  • AMD Ryzen 9 7900X（12核，最佳性能）

  • AMD Ryzen 7 7700X（8核，良好性能）

  • AMD Ryzen 9 5900XT（16核，上一代，性价比高）

对于AMD处理器，我们强烈建议购买额外的USB 3控制器卡以获得最佳兼容性。

技术说明： 您的处理器应该能够达到3.8GHz或更高的速度，以获得最佳性能。该软件需要支持AVX和AVX2指令的处理器（大多数现代处理器都支持此功能）。

推荐图形卡

我们建议至少配备6GB的专用GPU显存（VRAM），越多越好。

顶级（卓越性能）

  • RTX 5090（最佳可用）

  • RTX 4090

  • RTX 3090

  • RTX 4080

高级（优异性能）

  • RTX 5080

  • RTX 5070

  • RTX 4070

  • RTX 3080

中端层级（性能良好）

  • RTX 5060

  • RTX 3070

  • RTX 4060

入门层级（最低推荐配置）

  • RTX 3060

注意： 上述所有显卡都满足该软件的最低要求。更高端的显卡将提供更好的性能，尤其是在使用多摄像头和/或高分辨率视频时。
