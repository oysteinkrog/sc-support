安装软件和许可证密钥

每个新的 Swing Catalyst 许可证都附带一封电子邮件，其中包含说明。如果您找不到该电子邮件，请检查您的垃圾邮件文件夹或搜索您的收件箱。

按照说明下载和安装 Swing Catalyst，安装后在软件出现提示时输入许可证密钥。

示例电子邮件：

无法安装许可证密钥？请参阅我们的分步说明文章。

连接一个或多个摄像头

请参阅此支持的摄像头列表。

如果您使用的是 FLIR、IDS 或 AVT 摄像头，您可能需要下载并安装相应的驱动程序。请查看我们的驱动程序部分。如果您使用的是 FLIR 摄像头，请参阅我们的专用摄像头指南。

注意：我们建议在执行任何与摄像头相关的驱动程序安装之前，确保 FSX 和 Swing Catalyst 未运行。驱动程序安装完成后，您可能需要重新启动计算机。

从主菜单，可以通过单击齿轮图标找到设置。

检测到的摄像头将自动列在摄像头列表中。

要使用摄像头，需要指定一个角度。

通过单击禁用的图标选择一个角度，然后将"OFF"更改为"ON"来启用摄像头。

连接弹道仪

在"硬件设置"下，您可以在支持的弹道仪之间进行选择。

在版本 9.7 和 9.8 中，您可以在列表中选择您的弹道仪，将其切换为"打开"并启用"用作触发器"。

在版本 10.0 及更高版本中，只需打开弹道仪支持并按搜索。SC 应该会检测到任何已连接且兼容的弹道仪。

  • 确保弹道仪已打开并连接到 PC。

  • 我们始终建议尽可能使用有线连接，例如 USB 或以太网而非 WiFi。

关于如何设置弹道仪的更详细说明，请参阅这些指南：

  • Foresight GCQuad/GCHawk

  • Foresight GC3 / Bushnell Launch Pro

  • Foresight GC2*

  • FlightScope X-Series

  • FullSwing (E6)

  • FlightScope Mevo+

*Foresight GC2 集成不支持与 FSX 同时连接，要将 GC2 与 FSX 一起使用，必须选择 Foresight GC2 (Sim)。

如果您选择弹道仪作为触发设备，它将在捕捉模式下自动录制您的挥杆。如果您没有弹道仪，没关系，您可以改为使用麦克风作为触发器！

创建用户

按照以下步骤创建用户并录制一次挥杆。

当您首次运行 Swing Catalyst 时，系统会自动生成一个用户。该用户是根据许可证详细信息生成的。如果您希望编辑配置文件信息，请随时进行编辑。

从主菜单中，点击"开始"

点击"选择用户"下拉按钮，然后点击"新建"：

注意：系统会根据您的许可证详细信息自动生成用户，如果您希望编辑这些或添加新用户，可以分别点击"新建"或"编辑"来进行操作。

输入名称并点击"保存"

某些家庭许可证有最大用户限制，这限制了可以在 Swing Catalyst 中存储多少个用户配置文件。

分析菜单工具栏

从左到右：菜单、资源管理器、切换用户、捕捉、捕捉选项和布局。

Swing Catalyst 图标也是菜单按钮，它可以快速访问设置和结束当前会话。

切换用户

捕捉

要录制挥杆，您需要进入捕捉模式。

点击"捕捉"按钮后，您会自动从播放模式切换到捕捉模式。

绿色的"捕捉就绪"图标表示系统已准备好捕捉。使用 Swing Catalyst Home 时，启动会话时会自动进入此模式！

“捕捉就绪"只是表示捕捉模式已启动，SwingCatalyst 正在主动流传输数据。仅在触发事件发生后（例如手动触发、弹道仪、麦克风）才会保存。

捕捉选项

在不同的触发选项（如麦克风或弹道仪）之间选择，并更改捕捉模式。

布局

您可以使用"布局"下拉按钮在 SwingCatalyst 中选择不同的布局。

SwingCatalyst 会分别记住在播放和捕捉模式下最后使用的布局。

如图标所示，这些布局在显示内容和显示方式上存在一些差异。

摄像头布局选择

在同一下拉菜单"布局"中，您可以根据布局选择要显示的不同摄像头角度数量。在播放模式（观看录制的挥杆时），摄像头选择仅取决于创建录制时使用了多少摄像头。

在捕捉模式下，可见摄像头的数量取决于系统上启用的摄像头数量，以及许可证是否支持您希望使用的摄像头数量。

切换摄像头角度

如果您的录制中有多个摄像头，可以通过单击摄像头图标来更改观看的摄像头。

您也可以从这里进行一些小的摄像头调整，例如镜像和旋转摄像头角度。这些更改仅适用于录制视频，如果您想比较左手用户和右手用户等情况，会很有帮助。

绘图工具

如上面的截图所示，绘图工具位于软件的左侧。

绘图工具允许您在视频图像上绘图，既可以在已录制的视频上绘图，也可以在实时视频"源"上绘图（捕捉模式下）。

线条工具有多种不同的线条类型可供选择，标准的"线条"允许您在任何两点之间创建直线。

有三种不同的线条粗细可供选择。

不同的颜色使您可以轻松区分不同的线条。

缩放和平移工具

在工具栏的最底部（绘图工具下方）是缩放和平移工具以及"填充视频视图"按钮。

您也可以通过按住 Ctrl 键并同时滚动鼠标滚轮来缩放和操作视频图像。

资源管理器

您可以在这里轻松管理您的录制。资源管理器分为三个"部分”：

左侧是系统中注册的用户，中间是该用户的所有录制，右侧是预览部分。

录制会自动按会话分组并按日期排序。

  • 点击一个挥杆，它将自动在"预览"部分（右侧）预览。

您也可以通过右键单击并选择要在哪个视口中打开录制来打开录制，或者将录制拖到底部的"将录制放在此处"区域。

最常见的问题

用户通常面临的最常见问题与外部连接的硬件有关，无论是摄像头、Launch Monitor 还是传感器板。简单的事情如坏电缆（例如，太长的电缆或不兼容的 USB 扩展器）都可能导致问题。因此，本指南的这一部分旨在帮助您解决问题或缩小问题原因的范围。

摄像头未显示在摄像头设置列表中

如果摄像头未显示在摄像头列表中，说明摄像头未被检测到或连接不正常。

  • 如果摄像头未显示在摄像头列表中，最有可能是未在Windows中被识别或被另一个应用程序占用。请尝试断开摄像头连接，然后重新连接。

  • 摄像头可能不被Swing Catalyst支持。

  • 对于The Imaging Source摄像头：如果您已安装制造商驱动程序，可能需要卸载它才能正常工作。

  • 以太网（网络）/ GigE摄像头可能需要IP配置。

未接收数据

这表示Swing Catalyst未接收任何视频图像或数据进行处理。

此类错误的原因示例包括：

  • 电缆/连接不良：尝试断开摄像头并将其连接到不同的USB端口。

  • 错误的设置：（特别是对于网络摄像头和DirectShow摄像头）。检查曝光设置，如果Auto未选中且曝光设置过高，帧率可能会明显下降。

  • 网络摄像头的一个解决方案可能是启用"手动时间戳”（见下图）

出现错误

如果摄像头正被另一个应用程序使用，这类错误很常见。特别是网络摄像头很容易被第三方软件占用，请尝试关闭其他程序并重启Swing Catalyst。

丢帧 / 接收数据不足

丢帧意味着从摄像头传输到计算机的视频帧/数据在不同程度上丢失。特别是在使用多个摄像头时，这不是好现象，因为突然一个摄像头会丢失挥杆的部分内容。Swing Catalyst会对此发出警告，如果系统丢帧过多，将无法触发录制。

造成此问题的原因可能包括：

  • USB3摄像头连接到USB 2.0端口。

  • 使用设计不良的电缆或延长线。

  • 超过推荐的电缆长度。

  • USB3摄像头连接到USB集线器，与其他设备共享同一集线器，带宽不足。

  • 以太网摄像头连接到未正确配置或不支持巨帧的网络端口。

  • 摄像头使用的带宽超过了系统可用的带宽。

提示：

对于USB摄像头，我们建议尝试降低帧率（和/或设备链接吞吐量 - 对于FLIR摄像头）以减少带宽消耗。

  • 降低帧率（和/或设备链接吞吐量）。

  • 如果使用多个摄像头，尝试断开或禁用一些摄像头，系统是否仍报告丢帧？

  • 检查电缆，摄像头是否连接到USB集线器或延长器？尝试直接连接到计算机。

  • 尝试关闭其他CPU和图形密集型软件以释放资源。

场景：设备未连接

在上述示例场景中，Launch Monitor 在设置中已启用，但设备未连接/无法识别。

建议的故障排除步骤：

  • 检查设备是否仍处于开启状态。

  • 尝试重新启动设备。

  • 尽可能尝试通过 USB 或以太网而非 WiFi 连接。

  • 尝试使用制造商的软件进行连接，以确认是否可能建立连接。

场景：未触发录制。

Launch Monitor 已连接并被识别，但在捕捉模式下未触发。

建议的故障排除步骤：

  • 确保触发器选项已启用。

  • 设备上是否显示球和/或球杆数据？（您能验证它在 Swing Catalyst 外部是否正常工作吗？）

  • 是否有任何丢帧或数据不足的警告？如果摄像头丢帧，Swing Catalyst 将不会触发。
