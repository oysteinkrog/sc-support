如何为您的 SwingCatalyst 数据库设置自动备份

本支持文章介绍如何设置 Backblaze 以备份您的 SwingCatalyst 数据库

如果您希望备份/复制您的数据库和挥杆记录，请参阅本文：backup-database.md

您也可以使用 Crashplan：https://www.crashplan.com/en-us/

设置过程类似，如果您希望使用其他备份服务商，也可以将本指南作为大多数步骤的参考。

我们建议在开始录制视频之前先设置备份系统，因为将大型数据库上传至云端需要很长时间；从一开始就逐步上传会更加轻松。

创建 Backblaze 账户

相关资料：

Backblaze 电脑备份指南：https://www.backblaze.com/backup-your-computer.html

前往 Backblaze.com，注册并按照付款说明操作。

点击"为 Windows 下载"。

客户端下载完成后，启动该程序。

如果安装后未显示控制面板，可能是由于您的 Windows 版本问题，请尝试从此处下载最新安装程序（无需卸载之前的版本）：http://files.backblaze.com/install_backblaze.exe

如果您的 SwingCatalyst 数据库保存在其他分区或硬盘上，请点击"设置"。

例如，请确保已选中 D:\。

Backblaze 将备份您的所有数据，包括 SwingCatalyst 设置文件夹、所有课程文件和学生信息。

在数据丢失时恢复挥杆记录

如果您已将数据（通过 Backblaze）备份到外部硬盘，且其内容与在线备份同样是最新的，则从外部介质恢复速度更快，推荐优先使用此方式。
