如何在 Apple Mac 上运行 SwingCatalyst

简介

本支持文章介绍了如何使用 Boot Camp 在 Apple Mac 上运行 SwingCatalyst。

Boot Camp 允许您使用自备的 Microsoft Windows 安装光盘，将 Windows 安装到 Mac 电脑的独立分区中。

安装完成后，您可以在 Mac 电脑上选择使用 Windows 或 Mac OS X。

注意：SwingCatalyst 不支持在 Apple 硬件（搭载 ARM 架构的 Apple M1 / M2 CPU）上运行。

本文主要作为历史参考，内容已过时。

适用范围

  • 使用 Mac OS（10.5 - 10.11）的用户

推荐配置要求

  • Apple Mac（10.5 - 10.11）

  • 一张空白 CD 或 USB 存储设备，用于创建 Windows Boot Camp 支持软件（木杆）安装介质。

  • 安装 32 位 Windows 时，目标磁盘至少需要 16 GB 可用空间；安装 64 位 Windows 时，至少需要 20 GB。

  • 正版 Microsoft Windows

请注意，并非所有 Mac 都能通过 Boot Camp 运行 64 位 Windows，且仅搭载 Intel 处理器的 Mac 才支持 Boot Camp。

安装说明

要在 Apple 笔记本电脑或台式电脑上使用 SwingCatalyst，您需要 Mac OS 10.5 - 10.11 版本。

SwingCatalyst 需要在 Windows 环境下运行，支持 Windows Vista、7、8.1 及 Windows 10。

为获得最佳使用体验，我们强烈推荐使用 Windows 7 64 位版本。

建议使用 Boot Camp 助理来安装 Windows。Boot Camp 允许您在同一台 Mac 上双启动 Mac OS 与 Windows，方便随时切换操作系统。

在启动 Mac 时按住 Option（Alt）键，即可在 Microsoft Windows 与 Mac OS X 之间进行切换。

默认操作系统为 Mac OS X，但您可以通过 Windows 中的"启动磁盘"控制面板，或 Mac OS X 的"启动磁盘"偏好设置，轻松更改默认启动磁盘。

请访问 http://support.apple.com/manuals/#bootcamp，找到适用于您 Mac 机型的手册。

您也可以参阅 Boot Camp 常见问题解答 http://support.apple.com/kb/HT4818，或许能帮助您解决使用过程中遇到的问题。
