Como configurar câmeras Basler GigE com o Swing Catalyst

Este artigo de suporte aborda a configuração das câmeras Basler com o Swing Catalyst.

note: Para usar câmeras Basler com o Swing Catalyst, você precisará de um dongle USB Halcon e uma licença. Entre em contato com contact@swingcatalyst.com para adquirir uma licença.

Instruções de instalação e configuração do Halcon aqui:

halcon-setup.md

Importante:

Certifique-se de que o Filtro de Driver MVTec Halcon está instalado — as câmeras não funcionarão corretamente sem ele. Certifique-se também de desmarcar quaisquer outros filtros de driver instalados, por exemplo, o filtro de driver Basler.

Certifique-se de que o Swing Catalyst tem permissão tanto em redes privadas quanto públicas no Firewall do Windows Defender.

Configurando o IP das câmeras

Configuração de IP

Cada câmera e placa de rede (NIC / controlador de interface de rede) deve ser configurada com IPs estáticos em sub-redes diferentes (e máscara de sub-rede)

note: O IP da NIC é o endereço IP do adaptador de rede no seu computador, e o IP da câmera é o endereço IP da câmera. O … indica um Intervalo, pois este é um exemplo de IP que você pode definir.

Exemplos para configurações com uma ou mais câmeras (com uma ou mais placas / adaptadores de rede):

Câmeras no adaptador de rede 1: nic ip: 10.0.1.1 cam ip: 10.0.1.10 … 10.0.1.20 subnet mask:255.255.255.0

Câmeras no adaptador de rede 2: nic ip: 10.0.2.1 cam ip: 10.0.2.10 … 10.0.2.20 subnet mask: 255.255.255.0

Câmeras no adaptador de rede 3: nic ip: 10.0.3.1 cam ip: 10.0.3.10 … 10.0.3.20 subnet mask: 255.255.255.0

Câmeras no adaptador de rede 4: nic ip: 10.0.4.1 cam ip: 10.0.4.10 … 10.0.4.20 subnet mask: 255.255.255.0

Primeiro, precisamos configurar o IP da câmera — isso é feito através do Pylon IP Configurator.

Pressione o botão do menu Iniciar no teclado, digite pylon ip e o IP Configurator deverá aparecer. Caso não apareça, é provável que o software não esteja instalado.

Para instalar o software Pylon, acesse: https://www.baslerweb.com/en/sales-support/downloads/software-downloads/ e procure por: pylon 5.1.0 Camera Software Suite Windows.

Clique na câmera e selecione IP Estático (Static IP)

Defina o endereço IP da câmera e a máscara de sub-rede conforme o exemplo acima.

Configurando câmeras Basler GigE através do Halcon

No Swing Catalyst, navegue até a aba Configurações e depois até Câmeras.

Clique em Avançado (Advanced).

  • Navegue até a aba Configuração (Configuration).

  • Ative a caixa de seleção GtlNumBuffers e insira 200 como valor.

Configurando câmeras Basler GigE:

Veja como definir a exposição, velocidade do obturador e Taxa de Quadros.

note: Se você não conseguir visualizar as configurações e receber um erro no Swing Catalyst, verifique as configurações do Firewall do Windows. Tente desativar o firewall para verificar se é ele que está bloqueando o acesso do Swing Catalyst às câmeras.

Se as configurações funcionarem e a transmissão ocorrer normalmente, certifique-se de que o Swing Catalyst tem permissão em redes públicas e privadas no Firewall do Windows Defender.

Expanda a aba AcquisitionTrigger e insira a Taxa de Quadros máxima (ou inferior), depois clique em Enable Acquisition Frame Rate. Isso permitirá que você defina a Taxa de Quadros. Nota: A Taxa de Quadros pode ser limitada pelos valores de exposição.

Definindo valores de exposição

Geralmente é melhor usar uma exposição manual para ambientes estáticos, como estúdios internos. Uma exposição totalmente automática pode alterar a Taxa de Quadros e gerar uma imagem inconsistente. Neste caso, não estamos usando a exposição automática pois queremos controlá-la manualmente. Em geral, recomenda-se um tempo de exposição inferior a 2000 (2ms).

Definindo valores de Gain

Assim como na exposição, definir o Gain manualmente é a melhor opção para condições de iluminação estáticas/internas. Quanto maior a exposição, mais granulada será a imagem e mais tempo levará a codificação do vídeo em comparação com um Gain baixo.

Para definir o Gain manual, altere Gain Auto de Continuous para Off, depois pause e reproduza a Reprodução para recarregar as configurações. Defina os valores de Gain alterando os valores numéricos em Gain (Raw).

Alterando o tamanho da imagem, área de interesse, Region of Interest e mais

Em alguns casos, você pode querer reduzir o tamanho da imagem para focar em uma área específica da imagem de vídeo — por exemplo, para visualizar o taco e a bola no Impacto em detalhes.

Isso pode ser feito com a área de interesse, também conhecida como AOI, e ROI, Region of Interest. Reduzir o tamanho geral da imagem com essa função também pode aumentar a Taxa de Quadros.

Salvando as configurações na câmera

É importante salvar as configurações na câmera. Se isso não for feito, tudo o que foi configurado será perdido.

Certifique-se de definir o Default Set Selector e o Default Startup Set. Existem diferentes conjuntos de Usuário para escolher e, em teoria, você pode ter diferentes configurações salvas em cada conjunto. Ou seja, você pode selecionar “User Set 1” como padrão e depois clicar em User Set Save para salvar as configurações atuais nesse perfil.
