Como configurar câmeras IDS uEye GigE para funcionar com o Swing Catalyst

Para configuração de câmera USB, consulte este artigo: ids-ueye-usb.md

Nota: Este artigo pressupõe que você instalou os drivers uEye disponíveis aqui: https://www.swingcatalyst.com/drivers

Este artigo aborda a configuração dos endereços IP tanto da câmera quanto da placa de rede.

Nota: O Swing Catalyst não oferece suporte ao IDS AOI (área de interesse) para câmeras IDS.

Adaptadores de rede compatíveis e configuração:

Consulte: gige-network-setup.md

Nota, importante para o Desempenho: Se você possui uma placa de rede Intel, faça o download e instale os drivers Intel, pois isso fornecerá opções para definir as taxas de moderação de interrupção, que podem não estar disponíveis com os drivers do Windows.

Configurando sua(s) câmera(s) IDS uEye GigE

Passos:

Antes de prosseguir, instale os drivers IDS uEye. Localize e abra o aplicativo IDS Camera Manager (ele pode ser encontrado em: C:\ProgramData\Microsoft\Windows\Start Menu\Programs\IDS).

O aplicativo IDS Camera Manager:

Observe o aviso na parte inferior do aplicativo. Há vários avisos que podem aparecer devido a endereços IP configurados incorretamente ou relacionados ao firmware da câmera.

Exemplo:

Nota sobre a configuração do endereço IP e nossas recomendações**

**

Nossa recomendação é ter uma placa de rede dedicada, ou interface de rede, para cada câmera. No entanto, com o modelo IDS UI-3220, é possível usar duas câmeras para cada porta de rede com o uso de um switch de rede (consulte Usando um switch de rede).

Nossa configuração de IP recomendada:

Cada câmera e placa Ethernet (também conhecida como NIC) deve ser configurada com IPs estáticos em sub-redes diferentes (e uma máscara de sub-rede).

Exemplo:

Câmeras na placa de rede 1: nic ip: 10.0.1.1 cam ip: 10.0.1.10 … 10.0.1.20 máscara de sub-rede: 255.255.255.0

Câmeras na placa de rede 2: nic ip: 10.0.2.1 (sub-rede diferente da nic1) cam ip: 10.0.2.10 … 10.0.2.20 (sub-rede diferente da nic1) máscara de sub-rede: 255.255.255.0

Ativando o serviço de rede uEye

Nota: Se você estiver usando tipos de câmeras diferentes de fabricantes distintos, ter o serviço de rede uEye ativado pode causar problemas ao usar uma câmera de outro fabricante.

Clique em ETH network service

Selecione o adaptador de rede que deseja configurar (neste caso, são os adaptadores de porta dupla)

O gráfico da placa de rede está acinzentado, pois ela não está configurada corretamente. O serviço de rede uEye precisa ser ativado para que a câmera fique visível na rede.

Certifique-se de definir o endereço IP e a máscara de sub-rede conforme recomendado (veja acima), depois clique em Enable uEye network service e em Apply changes (você acabou de definir um endereço IP estático para um dos adaptadores de porta dupla!).

Configuração automática de IP (para IP manual, veja abaixo)

Para usar a configuração automática de IP, clique em Automatic ETH configuration e clique em OK.

O IDS Camera Manager definirá automaticamente um endereço IP na placa de rede e na câmera para você.

Nota: Recomendamos a configuração manual de IP ao usar múltiplas câmeras.

Configuração manual de IP

De volta ao IDS Camera Manager, você deverá ver a(s) câmera(s) listada(s). Como você definiu anteriormente um endereço IP estático para o adaptador de rede, agora é necessário definir um IP estático para a câmera, para que o adaptador de rede e a câmera possam se comunicar corretamente entre si.

Marque a caixa Expert Mode conforme mostrado aqui:

Observe o aviso acima em vermelho.

Clique em Manual ETH configuration:

Na captura de tela acima, o endereço IP da câmera está definido como 10.0.1.10 (nossa placa de rede é 10.0.1.1). Insira conforme mostrado na captura de tela acima e clique em OK.

Nota: definir endereços IP estáticos não é obrigatório, mas é altamente recomendado, pois configurações de IP automáticas podem causar problemas com conflitos de endereços IP, por exemplo, o mesmo endereço IP sendo usado em outro lugar. Recomendamos fortemente uma configuração estática para todas as instalações em estúdio.

Repita o processo para as outras câmeras e NICs conforme nossas configurações de IP recomendadas acima.

Configurando o(s) Adaptador(es) de Rede para uso com câmeras IDS uEye

Supondo que você já configurou endereços IP estáticos tanto para a(s) câmera(s) quanto para a placa de rede, vamos prosseguir para a configuração do adaptador de rede para melhor Desempenho.

No Painel de Controle\Rede e Internet\Conexões de Rede, clique duas vezes no adaptador que deseja configurar — no nosso caso, é o Ethernet 4, Intel (PRO/1000 PT Dual port).

Clique duas vezes no adaptador de rede que deseja configurar.

Clique na aba Avançado. Nota: A configuração é diferente para cada adaptador de rede e depende do driver; consulte a documentação da sua placa de rede para obter informações específicas sobre como alterar as configurações mostradas abaixo.

Certifique-se de que a Moderação de Interrupção (Interrupt Moderation) está ativada e que a Taxa de Moderação de Interrupção (Interrupt Moderation Rate) está definida como Extreme.

Se a opção Extreme não estiver disponível, defina como High.

Em algumas circunstâncias, desativar a moderação de interrupção pode ajudar caso nenhuma das taxas de moderação de interrupção de valor alto funcione; mas desde que você tenha uma placa de rede recomendada, as opções High e Extreme devem estar disponíveis. Ter a moderação de interrupção ativada é fundamental para reduzir o uso de CPU ao lidar com grandes quantidades de pacotes, especialmente em câmeras de resolução mais alta e/ou com FPS elevado.

Taxa de moderação de interrupção:

Ative o suporte a Jumbo Packets (defina para 9014 Bytes):

Buffers de Recebimento:

Recomenda-se definir este valor o mais alto possível. Isso pode ajudar a evitar a perda de Quadros ao usar múltiplas câmeras e/ou câmeras GigE de resolução mais alta.

Usando um switch de rede:

Se você for usar um switch de rede, é importante que o switch suporte Jumbo Frames de 9KB e que o adaptador de rede esteja configurado para usar Jumbo Frames de 9KB. No entanto, em alguns casos, certos switches podem não funcionar bem com tamanhos de Quadro de 9KB; nesses casos, recomenda-se reduzir de 9KB para um valor menor e testar novamente a configuração.

Usando a(s) câmera(s) no Swing Catalyst

Após ter configurado os endereços IP e os adaptadores de rede conforme as recomendações acima, você pode iniciar o Swing Catalyst e a câmera deverá aparecer na lista de câmeras.

Defina um Ângulo de câmera e ative a câmera, depois clique em Configurar.

Certifique-se de que o clock de pixel está no máximo (ou reduza-o se estiver perdendo Quadros).

Defina a velocidade do obturador e o Gain (note que esses valores podem variar bastante dependendo dos requisitos, do tipo de câmera e da quantidade de luz disponível).

Solução de problemas em câmeras IDS

Se você estiver perdendo Quadros ou tendo problemas de sincronização com sua câmera IDS uEye GigE, use o utilitário uEye Cockpit.

Clique em Live Video

Clique no ícone de reprodução e depois clique na chave inglesa

Observe o uso de largura de banda listado. Na aba Camera, aumente o Pixel clock e marque a caixa Max em Taxa de Quadros (Freerun) e, em seguida, reduza o tempo de exposição (velocidade do obturador).

Após configurar suas câmeras para transmitir ao vivo, clique em Visualização -> Performance Overview

A Visualização de Desempenho do Host pode ser muito útil para solucionar problemas de estabilidade e perda de Quadros.
