Como configurar o Halcon para uso com o Swing Catalyst.

O lançamento do Swing Catalyst 6.0 traz suporte para três dos padrões de visão de máquina mais comuns.

  USB3 Vision                      GigE Vision                             GENiCAM

Antes de Começar

Este artigo aborda principalmente a instalação do Halcon, a instalação da licença e uma configuração básica de uma câmera Ximea USB3. Não podemos garantir compatibilidade com versões mais recentes e o Swing Catalyst suporta apenas o Halcon 12.

Para mais informações sobre como verificar se sua câmera suporta o Halcon, consulte: Como descobrir quais padrões suas câmeras suportam para uso com o Halcon.

WARNING

O Swing Catalyst suporta apenas a versão 12 do HALCON.

  • O Halcon 12 suporta: GenAPI v2.4.1.

O Driver da chave de licença USB é incompatível com o Windows 10 e 11!

Ao instalar o Halcon, é muito importante desmarcar “Install Driver for USB Dongles” durante a instalação; caso contrário, seu computador travará na inicialização.

Para detalhes sobre como instalar o novo Driver USB, consulte nosso artigo de suporte:

  • Computador apresenta tela azul ao conectar a chave de licença USB do Halcon

Consulte os artigos específicos da sua câmera para configurá-la no Swing Catalyst após a instalação do Halcon para configurações específicas do fabricante.

Requisitos de hardware:

  • Dongle de Suporte Universal a Câmeras ou licença vinculada à placa de rede.

  • Câmera(s) compatível(is) com os padrões USB3 Vision, GigE Vision ou GenICam.

  • Porta USB disponível para o dongle de licença.

Certifique-se de que seu hardware é compatível com as recomendações do fabricante.

Note: A configuração de câmeras específicas de cada fabricante pode ser encontrada na parte inferior deste artigo.

Mais informações

  • Informações sobre Ximea USB3 Vision: http://www.ximea.com/en/usb3-vision-camera/usb3zone

  • Informações sobre Point Grey USB3 Vision: http://www.ptgrey.com/usb3-vision-cameras

  • Informações sobre Basler USB3 Vision: http://www.baslerweb.com/en/support/knowledge-base/frequently-asked-questions

  • GenICam (Interface Genérica para Câmeras): http://www.emva.org/standards-technology/genicam/

Requisitos de software

  • Arquivo de licença do Halcon. Você deve tê-lo recebido por e-mail.

  • Certifique-se de estar executando a versão mais recente do Halcon instalada; se receber um aviso no Swing Catalyst, entre em contato com o suporte para obter assistência.

Instalando o Halcon

  • O runtime do Halcon pode ser encontrado em nossa página de Downloads ou pode ser baixado diretamente aqui.

  • Após o download, clique com o botão direito no arquivo e selecione “Extrair Tudo”.

  • Abra a pasta extraída e execute o instalador.

  • Abra o instalador e siga as instruções na tela juntamente com as instruções passo a passo abaixo.

  • Selecione “Install x64 version”.

  • Em “Choose Components”, você pode desmarcar todos os componentes exceto “Runtime x64”.

  • Na seção “Additional Drivers”, certifique-se de desmarcar “Install driver for USB dongles”; isso é importante.

  • Se você tiver uma câmera GigE, certifique-se de marcar “Install MVTec GigE Vision Streaming Filter”.

  • Para instalar o arquivo de licença, selecione “I have a license file that should be installed” e indique o caminho para o arquivo de licença que você deve ter recebido do seu agente de vendas ou suporte.

  • Prossiga com as instruções na tela.

WARNING: Desmarque “Install driver for USB dongles” se estiver usando Windows 10 ou 11

Certifique-se de instalar o Filtro GigE Vision (Observação: isso é obrigatório se você tiver uma câmera GigE).

Localize o arquivo license.dat recebido por e-mail e clique em avançar.

Conclua a instalação. Se solicitado a reiniciar, clique em sim.

Configuração básica de câmera do Halcon no Swing Catalyst

Consulte as instruções de configuração para os seguintes fabricantes:

  • Ximea USB3 Vision: ximea-usb3-setup.md

  • Basler GigE Vision: basler-gige-setup.md

Entre em contato com sales@swingcatalyst.com para solicitar o Suporte Universal a Câmeras do Swing Catalyst.

Solução de Problemas

P: O computador trava ou apresenta tela azul sempre que conecto o dongle USB

R: Siga os passos deste artigo para instalar Drivers mais recentes.
