Como configurar IP estático em câmeras FLIR Blackfly GigE

Introdução

Este artigo de suporte descreve como configurar suas câmeras FLIR Blackfly (ou Blackfly S) GigE com um endereço IP estático. Para uso normal, isso não é necessário, pois o SwingCatalyst gerencia a configuração de IP automaticamente.

Requisitos

  • O aplicativo Spinview (parte do Spinnaker SDK).

  • SwingCatalyst.

  • Uma ou mais câmeras FLIR Blackfly (ou Blackfly S) GigE.

Instalando o Spinnaker

  • Baixe e execute o instalador do Spinnaker.

  • Clique com o botão direito no instalador do Spinnaker e execute como administrador.

  • Marque “Camera Evaluation” e clique em Avançar.

  • Siga as instruções na tela para prosseguir com a instalação.

  • Após concluir, reinicie o computador.

Configurando um IP estático no Adaptador Ethernet

Cada câmera e adaptador de rede deve ter seu próprio endereço IP estático exclusivo. Por exemplo, ao atribuir endereços IP estáticos às câmeras, certifique-se de que o adaptador de rede esteja configurado com um IP correspondente da matriz de “configuração de IP estático recomendada” abaixo.

Aviso

Configure os adaptadores de rede com base na câmera associada, e não no número do adaptador. Altere as configurações apenas para as câmeras identificadas; deixe as demais sem alteração. Caso conecte uma câmera a um adaptador diferente, será necessário reconfigurar para garantir o funcionamento correto.

No Painel de Controle, acesse “Rede e Internet”, depois “Central de Rede e Compartilhamento” e clique em “Alterar configurações do adaptador”.

Aqui podemos ver uma lista dos adaptadores de rede presentes no computador. No nosso caso, desejamos configurar o Ethernet 2 e o Ethernet 3, com o nome de dispositivo “Intel Pro/1000”. É importante configurar apenas os adaptadores de rede utilizados pelas câmeras e não os demais, pois isso pode afetar a conectividade com a internet.

Clique com o botão direito no adaptador de rede que deseja modificar e selecione “Propriedades”; em seguida, role até “Protocolo de Internet Versão 4 (TCP/IPv4)” e clique em “Propriedades”.

  • Selecione “Usar o seguinte endereço IP”.

  • Insira um endereço IP da matriz de configuração de IP estático recomendada abaixo.

  • Insira a máscara de sub-rede 255.255.255.0.

  • Selecione “Usar os seguintes endereços de servidor DNS”; você pode deixar esses campos em branco.

  • Clique em “OK”.

Configuração de IP estático recomendada

Número do Adaptador Ethernet IP do Adaptador Ethernet Máscara de Sub-rede Gateway Conectado à Câmera IP da Câmera
1 10.0.1.1 255.255.255.0 10.0.1.1 1 10.0.1.10
2 10.0.2.1 255.255.255.0 10.0.2.1 2 10.0.2.10
3 10.0.3.1 255.255.255.0 10.0.3.1 3 10.0.3.10
4 10.0.4.1 255.255.255.0 10.0.4.1 4 10.0.4.10

O gateway pode ser configurado tanto na câmera

Configurando um IP estático na câmera

Repita estas etapas para qualquer outra câmera na qual deseje configurar um IP estático. Para acessar a configuração de IP da câmera, abra o aplicativo SpinView e clique com o botão direito na câmera que deseja configurar.

  • Clique com o botão direito na câmera na lista de Dispositivos e selecione “GigE Configuration”.

  • Clique em “IP Configuration”.

Insira o IP e a máscara de sub-rede de acordo com a matriz de configuração de IP recomendada abaixo.

  • Insira o endereço IP da câmera, utilizando o endereço IP da matriz; por exemplo, para a câmera 1.

  • Insira a máscara de sub-rede, ex.: 255.255.255.0.

  • O gateway padrão pode ser deixado em branco ou pode ser o endereço IP do adaptador de rede ao qual a câmera está conectada.

  • Desmarque DHCP.

  • Clique em “Set Current and Persistent IP Configuration”.

Configuração de IP estático recomendada para câmeras

Nº da Câmera IP Máscara de Sub-rede Gateway
1 10.0.1.10 255.255.255.0 10.0.1.1
2 10.0.2.10 255.255.255.0 10.0.2.1
3 10.0.3.10 255.255.255.0 10.0.3.1
4 10.0.4.10 255.255.255.0 10.0.4.1

O IP do gateway é o endereço IP do adaptador de rede ao qual a câmera está conectada.

Por exemplo, a Câmera 1 está conectada ao adaptador de rede 1.

Usando o SpinView para ativar quadros jumbo e otimizar os adaptadores de rede para as câmeras

Observe que essas alterações precisam ser feitas em todos os adaptadores de rede conectados às suas câmeras.

  • No SpinView, clique com o botão direito na câmera e selecione “GigE Configuration”.

  • Clique em “Configure Adapter Properties”.

  • Clique em Sim quando solicitado.

  • Clique em “Next”.

  • Clique em “Auto Fill All”.

  • Clique em “Next”.

  • Marque “Enable Media Optimization”.

  • Clique em “Next”.

  • Clique em “Configure” para aplicar as alterações.
