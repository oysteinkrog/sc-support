Como instalar e configurar uma Plataforma de Equilíbrio 3

Introdução

Este artigo de suporte descreve como configurar uma nova Plataforma de Equilíbrio 3 para uso com o Swing Catalyst.

Requisitos

  • Computador com uma porta USB disponível.

  • Swing Catalyst 7.1.8 ou posterior.

Instalação

Para detalhes sobre a instalação, consulte o PDF anexo no final do artigo.

Este artigo abrange a Plataforma de Equilíbrio 3 e a Plataforma de Equilíbrio 3s.

Deseja apenas executar uma Calibração de campo da sua plataforma? Clique aqui

Aviso

Alguns problemas foram identificados com chipsets AMD 300-Series (AMD Ryzen 1700 / 2700 series) em dispositivos USB 1.1. Especificamente com a Plataforma de Equilíbrio, onde são obtidas apenas 75 amostras por segundo em vez de ~145 amostras por segundo. Recomendamos o uso de um hub USB 2.0, o que permitirá que a Plataforma de Equilíbrio transmita na taxa de amostragem completa.

Não há problemas conhecidos no uso dos chipsets AMD 300 series com dispositivos USB 3.0.

Instalação do Driver

  • Instale os taco de saída a partir do Menu Iniciar do Windows - Swing Catalyst - pasta Taco de Saída. Para Windows 64 bits, execute “Balance Plate #2 Driver Installer (x64)” Para Windows 32 bits, execute “Balance Plate #2 Driver Installer (x86)” Tenho o Windows 32 bits ou 64 bits?

Você também pode encontrar os drivers em https://www.swingcatalyst.com/drivers

Executando o utilitário de calibração

  • Baixar o utilitário de calibração

  • Se solicitado a instalar drivers, clique em sim.

  • Conecte a Plataforma de Equilíbrio ao computador.

  • Abra o SE Utility recém-instalado.

  • Selecione uma câmera ou webcam e foque-a na Plataforma de Equilíbrio.
