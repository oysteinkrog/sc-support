Como usar o Launch Monitor Foresight GC2 & HMT com o Swing Catalyst

Introdução

Este artigo de suporte descreve como usar o Foresight GC2 com o Swing Catalyst.

Note: Se você deseja usar o FSX junto com o GC2, os dados do HMT não são fornecidos e é necessário iniciar o FSX primeiro, depois iniciar o Swing Catalyst e selecionar FSX Sim nas Configurações do Swing Catalyst.

Warning

A partir da versão 10.1.1 do Swing Catalyst, a integração com o GC2 será desativada por padrão para evitar problemas com o fechamento do FSX 2020 ao executar o Swing Catalyst.

Se você possui um GC2 e deseja continuar usando-o com o Swing Catalyst, é necessário habilitá-lo no arquivo de configurações (consulte a seção de solução de problemas abaixo).

Requisitos

  • Computador com uma porta USB livre ou WiFi (separada da conexão de internet).

  • Uma licença com suporte para câmera de transmissão ao vivo, câmera web ou câmera de alta velocidade.

  • Swing Catalyst 4.0 ou posterior

Importante: Recomendações de Computador.

O Swing Catalyst integra-se tanto ao GC2 quanto à unidade adicional, HMT.

Para usar o GC2 junto com o software de simulador Foresight (FR-1, FSX, FSX 2020 etc.), o Simulador Foresight deve ser selecionado nas configurações de Launch Monitor do Swing Catalyst.

Note: Se você não está familiarizado com as configurações de Launch Monitor do Swing Catalyst e como usar um Launch Monitor como Gatilho de Captura, consulte nosso artigo de suporte antes de continuar.

Conexão Direta (sem integração com FSX):

Este método de conexão conecta-se diretamente à unidade sem a necessidade de executar o FSX simultaneamente. Se você tiver uma unidade HMT, o Swing Catalyst também capturará os dados do taco.

Etapas de Configuração

Página de suporte do GC2 (Drivers, firmware e manuais do Usuário)

  • Siga o guia de instalação do Foresight GC2 (consulte o link acima) e instale os Drivers USB do GC2. Certifique-se de selecionar a versão correta de acordo com a sua versão do Windows.

  • Certifique-se de que o GC2 esteja usando a versão mais recente do firmware.

Com o GC2 desligado, conecte o GC2 ao seu computador com o cabo USB e, em seguida, ligue o GC2.

  • Inicie o Swing Catalyst e vá em Configurações (na tela principal, clique no ícone de engrenagem no canto inferior esquerdo) e selecione Hardware.

  • Ative a integração com o Launch Monitor. Certifique-se de que “Ativar como Gatilho” esteja marcado se você deseja que o Launch Monitor funcione como um Gatilho de Captura.

  • Selecione Foresight GC2

Integração com o Simulador

  1. Selecione ForesightSim na lista de seleção de Launch Monitor; caso não apareça automaticamente, pressione “Pesquisar” para atualizar a lista.

  2. Inicie o Simulador Foresight (variantes suportadas: FSX, FSX 2020 e FR-1).

  3. Acesse as configurações do Simulador Foresight, na seção “On-Screen Data”, ative “Write Shots CSV” (consulte o manual do Usuário do simulador para mais detalhes ou entre em contato com o suporte da Foresight para obter ajuda).

O Swing Catalyst monitora o arquivo Shots.CSV em busca de alterações e utiliza ativamente esse arquivo para capturar os dados de tacadas do simulador.

  1. Certifique-se de estar usando o modo Club Fitting (único modo que fornecerá todos os dados de bola).

Solução de Problemas

Esta seção contém etapas de solução de problemas para o Foresight GC2 e HMT, bem como para o uso do GC2 com FSX.

Acabei de atualizar o software e a integração não funciona mais!

Na versão 10.1.1 do Swing Catalyst, a integração com o GC2 é desativada por padrão para evitar que o FSX2020 feche sozinho enquanto o Swing Catalyst está em execução. Esta é uma solução temporária até que a Foresight consiga resolver o problema com o FSX.

Para reativar a integração com o GC2, feche o Swing Catalyst e navegue até a pasta de Configurações:

  • C:\ProgramData\Swing Catalyst\settings

  • Clique com o botão direito em “GeneralSettings.xml” e clique em abrir com o Bloco de Notas (ou clique em Editar).

  • Altere false para true e salve o documento.

  • Após salvar, inicie o Swing Catalyst novamente; o GC2 deverá aparecer na lista de Launch Monitor.

Conexão USB da Foresight

  • Certifique-se de que o USB da Foresight esteja selecionado nas Configurações do Swing Catalyst.

  • Verifique a conexão com a unidade Foresight GC2 e certifique-se de que o software do Simulador Foresight não esteja em execução.

  • Se houver dados ausentes ou se as tacadas não forem capturadas corretamente, isso pode indicar que o módulo flash precisa ser substituído. Ou pode ser que o taco esteja sem Marcadores ou que os Marcadores não estejam mais funcionando corretamente.

  • Se ainda não conseguir obter os Dados do Monitor de Lançamento do Foresight GC2 no Swing Catalyst, envie um ticket pelo nosso centro de ajuda.

Conexão com o Simulador Foresight

  1. Certifique-se de que está recebendo dados no Simulador Foresight.

  2. Tente fechar o Swing Catalyst, inicie o Simulador Foresight primeiro e, em seguida, inicie o Swing Catalyst.

  3. Certifique-se de estar usando o modo Club Fitting no Simulador Foresight e que o Shots.CSV esteja habilitado nas Configurações.

  4. Certifique-se de ter “Usar como Gatilho” ativado nas configurações do Swing Catalyst.
