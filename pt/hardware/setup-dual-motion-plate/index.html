Instalando e Configurando a Dual Motion Plate

Para material de instalação mais detalhado, consulte os arquivos PDF em anexo.

Instalação

Para informações sobre a instalação física, consulte o anexo do guia de instalação em PDF.

  • Consulte o PDF do Guia de Instalação para preparar seu ambiente para a instalação.

  • Consulte o PDF do Guia de Início para configurar a Motion Plate para uso.

Requisitos:

O software instala automaticamente os drivers para a Force Plate e a Pressure Plate (exceto o arquivo de Calibração). A instalação manual normalmente não é necessária.

Driver Bertec CDM instalado.

Driver MeasureX instalado. Clique para detalhes de instalação

  • Hardware da Dual Motion Plate.

Aplicável a:

  • MotionCatalyst & SwingCatalyst.

Além do guia de início, familiarize-se com o teste de Calibração descrito abaixo.

Conectando a placa

Com uma configuração de Placa Dupla, há um total de 4 cabos. Em muitos casos, pode ser útil utilizar um hub USB com alimentação própria para conectar os dispositivos, evitando ocupar todas as portas USB disponíveis no computador.

Procedimento de conexão

  • Conecte os dois cabos USB Mini B às duas Plataformas de Equilíbrio.

  • Conecte os dois cabos USB-B (conector maior que o USB Mini B) às Force Plates.

  • Conecte os 4 cabos das placas ao computador.

Se a configuração da placa não for detectada automaticamente, tente desconectar e reconectar alguns dos cabos e reinicie o software.

Clique em “Yes” para continuar.

Agora que o software identificou com sucesso todas as placas que compõem a Dual Motion Plate, é hora de calibrar a placa.

  • Certifique-se de que ninguém esteja sobre a placa e que as placas estejam livres de qualquer grama ou equipamento ao redor.

  • Clique em “Calibrate”

Isso zerará a Force Plate. Se a Calibração falhar, consulte nossa seção de solução de problemas.

Detecção de componentes

Para identificar qual placa está à frente ou à direita, você precisará executar este procedimento.

Clique em “Detect” e siga as instruções na tela.

Teste de Calibração

Existem dois tipos de Calibração:

  • O nível zero para a Force Plate.

  • O arquivo de Calibração para a Pressure Plate / Plataforma de Equilíbrio.

Este teste é específico para a parte de Force Plate da Motion Plate, para verificar se ela foi instalada corretamente.

É importante garantir uma boa Calibração para obter dados precisos. Recomendamos calibrar e testar a Calibração antes de cada Sessão de uma série de Gravações.

  • Clique no botão “Calibrate” no menu de configurações - Hardware - Placa de Sensor

  • Clique no botão “Configure” ao lado dele, depois clique no botão “Play” para visualizar os dados de força e Pressão ao vivo

  • Use a Haste do Taco ou o seu Calcanhar para aplicar Pressão em um dos Cantos da placa, depois verifique se os Dados de Pressão (mapa de calor colorido) estão alinhados com os Dados de Força (círculo total do COP).

  • Se não estiverem alinhados, é possível que uma ou mais placas precisem ser rotacionadas. Consulte “Como alterar a Rotação”.

  • Inicie uma Sessão e capture uma Gravação sem nenhuma pessoa sobre a placa. Abra a Gravação e verifique se as leituras de força estão dentro de 10 Newton de zero.

Queremos que os Dados de Pressão / Dados de Postura sejam lidos dos Dedos do Pé ao Calcanhar. Para isso, os Dados de Pressão precisam ser rotacionados 180 graus, de modo que o pé esquerdo apareça na placa esquerda (onde está a parte “Swing” do logotipo do SwingCatalyst) e o pé direito apareça na placa direita.

Solução de Problemas

Os Dados de Pressão e de Força não estão alinhados, ou a Calibração falha

Se o ponto COP não corresponder ao ponto de Pressão, provavelmente a placa não está nivelada ou algo está pressionando contra ela e obstruindo seu movimento livre.

  • Clique em “Calibrate” novamente e repita o teste de Calibração

  • Se ainda estiver desalinhado, reajuste o pé nivelador da Force Plate enquanto pressiona o canto oposto — primeiro encurte-o, depois estenda-o até o ponto em que ele toque o chão e você sinta uma leve resistência

  • Confirme que todos os quatro pés estão em contato firme com o chão pressionando os Cantos

  • Certifique-se de que não há grama ou material semelhante pressionando contra a placa

  • Repita o teste de Calibração

Abaixo estão exemplos de configurações incorretas que, esperamos, ajudarão a entender e solucionar esses tipos de problemas.

Dados de Pressão / pegada ausentes em uma placa

  • Verifique as conexões de cada Pressure Plate; tente desconectar e reconectar as placas.

  • Reinicie o software.

  • Verifique se o SwingCatalyst está reconhecendo ambas as placas. Em “Hardware Settings” -> “Configure” -> “Sensor Info”, devem aparecer dois números de série, por exemplo: 1230_1231. Se apenas um número for listado, provavelmente a segunda placa não está sendo reconhecida pelo SwingCatalyst.

  • Verifique o Gerenciador de Dispositivos do Windows; devem aparecer duas entradas em “Ports & COM” chamadas “MeasureX Pressure Controller”. Se não estiverem listadas, isso pode indicar um problema de conexão física.

Exemplos de configuração incorreta

Dados de Pressão estão invertidos

Essa configuração pode ser identificada ficando sobre as placas e inclinando o corpo para frente ou para trás.

Se o movimento do COP for oposto ao da Pressão, isso significa que a força ou a Pressão precisa ser rotacionada 180 graus.

Pressão está invertida e a força tem Rotação incorreta

Seguindo a lógica descrita no teste de Calibração acima, neste exemplo há vários problemas:

  • A pegada (Dados de Pressão, também chamados de Dados de Postura nas configurações do SwingCatalyst) está “invertida”.

  • O ponto COP (o ponto branco ao lado do “S” no logotipo do “Swing Catalyst” ao fundo) não está alinhado com a pegada.

  • O ponto COP não está aparecendo na mesma placa que a pegada.

Para corrigir isso, primeiro precisamos rotacionar os Dados de Pressão / Postura para que o pé esquerdo apareça no lado esquerdo e, em seguida, rotacionar os Dados de Força até que correspondam à pegada.

Para Placas Duplas, é importante aplicar a lógica do teste de Calibração a cada placa individualmente.

A placa errada é pisada durante a Fase de detecção de Placa Dupla

Neste exemplo, a placa errada foi pisada durante a Fase de “detectar componentes”. Quando isso ocorre, é possível observar que os Dados de Pressão e de Força não estão alinhados corretamente e, neste caso, o(s) ponto(s) COP estão fora das pegadas, o que normalmente não deveria acontecer.

Para corrigir isso, tente clicar em “detect components” novamente, mas pise na placa direita / placa traseira. Feito isso, os dados devem mudar para algo semelhante à imagem abaixo.

Como alterar a Rotação

Em vez de girar as placas fisicamente, é possível fazer isso pelo software.

Para rotacionar uma Placa de Sensor, acesse Configurações -> Hardware e clique em Configurar.

Nas Configurações da Placa de Sensor, certifique-se de que a aba “Flip & Rotate Devices” esteja selecionada.

  • Para rotacionar os Dados de Pressão, clique em “Rotate Stance Data”.

  • Para rotacionar os Dados de Força, clique em “Rotate Force Data”.

Consulte algumas das imagens de solução de problemas abaixo, pois elas ilustram uma configuração incorreta.

Para configurações de Placa Dupla, você deverá ver duas entradas de Dados de Força na lista; portanto, certifique-se de rotacionar ambas as Force Plates no software.
