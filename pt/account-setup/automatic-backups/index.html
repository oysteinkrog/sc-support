Como configurar backups automáticos do seu banco de dados do Swing Catalyst

Como configurar backups automáticos do seu banco de dados do Swing Catalyst

Este artigo de suporte aborda a configuração do Backblaze para fazer backup do seu banco de dados do Swing Catalyst

Se você deseja fazer um backup / cópia do seu banco de dados e Swings, consulte este artigo: backup-database.md

Você também pode usar o Crashplan, https://www.crashplan.com/en-us/

O processo de configuração é semelhante, e você pode usar este guia como referência para a maioria das etapas caso deseje utilizar um provedor de backup diferente.

Recomendamos que um sistema de backup seja configurado antes de você começar a capturar vídeo, pois o envio de um banco de dados grande para a nuvem leva muito tempo; fazer o upload de pequenas quantidades desde o início é mais fácil.

Criando uma conta no Backblaze

Material relacionado:

Guia de Backup de Computador do Backblaze: https://www.backblaze.com/backup-your-computer.html

Acesse Backblaze.com, cadastre-se e siga as instruções de pagamento.

Clique em Download para Windows.

Após o download do cliente, inicie o programa.

Caso o painel de controle não seja exibido após a instalação, isso pode ser devido à sua versão do Windows. Tente o instalador mais recente aqui (não é necessário desinstalar a versão anterior): http://files.backblaze.com/install_backblaze.exe

Se o seu banco de dados do Swing Catalyst estiver salvo em uma partição ou disco rígido diferente, clique em Configurações.

Por exemplo, certifique-se de que D:\ esteja selecionado.

O Backblaze fará backup de todos os seus dados, incluindo a pasta de Configurações do SwingCatalyst, todos os seus arquivos de Lição e Alunos.

Restaurando Swings em caso de perda de dados

Se você fez backup dos seus dados (com o Backblaze) em um disco rígido externo e ele está tão atualizado quanto o backup online, restaurar a partir de um meio externo é muito mais rápido e recomendado.
