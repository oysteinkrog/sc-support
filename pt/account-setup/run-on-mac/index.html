Como executar o Swing Catalyst em um Apple Mac

Introdução

Este artigo de suporte descreve como você pode usar o Boot Camp para executar o Swing Catalyst no seu Apple Mac.

O Boot Camp permite instalar o Windows em um computador Mac em sua própria partição, utilizando um disco de instalação do Microsoft Windows fornecido por você.

Após a instalação, você pode usar o Windows ou o Mac OS X no seu computador Mac.

Nota: O Swing Catalyst não funciona em hardware Apple (CPUs Apple M1 / M2 com arquitetura ARM).

Este artigo existe principalmente para fins históricos, pois está desatualizado.

Aplica-se a

  • Usuários com Mac OS (10.5 - 10.11)

Requisitos recomendados

  • Apple Mac (10.5 - 10.11)

  • Um CD em branco ou armazenamento USB para criar a mídia de instalação do Boot Camp Support Software (Taco de Saída) do Windows.

  • Pelo menos 16 GB de espaço livre no disco no qual você instalará o Windows de 32 bits, e 20 GB para o Windows de 64 bits.

  • Uma versão autêntica do Microsoft Windows

Observe que nem todos os Macs conseguem executar o Windows de 64 bits usando o Boot Camp, e que apenas Macs com processador Intel podem utilizar o Boot Camp.

Instalação

Para usar o Swing Catalyst em um laptop ou desktop Apple, você precisará do Mac OS versão 10.5 - 10.11.

O Swing Catalyst requer Windows e funciona no Windows Vista, 7, 8.1 e Windows 10.

Para a melhor experiência do Usuário, recomendamos fortemente o Windows 7 64 bits.

Recomenda-se instalar o Windows com o Assistente de Boot Camp. O Boot Camp permite inicializar o Mac OS e o Windows lado a lado — permitindo acesso fácil a ambos os sistemas operacionais.

Manter a tecla Option (Alt) pressionada ao iniciar o seu Mac oferece a possibilidade de alternar entre o Microsoft Windows e o Mac OS X.

O sistema operacional padrão será o Mac OS X, mas isso pode ser facilmente alterado no Painel de Controle do Disco de Inicialização no Windows, ou nas preferências de Disco de Inicialização do Mac OS X para definir o disco de inicialização padrão.

Acesse http://support.apple.com/manuals/#bootcamp e encontre o manual correspondente ao seu Mac.

Também pode ser útil consultar as Perguntas Frequentes do Boot Camp em http://support.apple.com/kb/HT4818, que podem ajudá-lo a resolver problemas que possam surgir.
