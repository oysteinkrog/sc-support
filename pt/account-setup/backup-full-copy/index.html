Como fazer uma cópia ou backup da pasta ProgramData e das Gravações do Swing Catalyst

Este artigo de suporte explica como fazer manualmente uma cópia da pasta Program Data do Swing Catalyst. Útil caso você queira mover uma instância do Swing Catalyst de um computador para outro.

Please note

Uma licença do Swing Catalyst não pode ser ativada em dois computadores ao mesmo tempo. Quando você inicia o Swing Catalyst, a licença é ativada. Isso significa que, se você pretende mover o Swing Catalyst do Computador A para o Computador B, não poderá iniciar o Swing Catalyst no Computador A novamente, caso contrário a licença ficará bloqueada por 24 horas.

Requisitos

  • Disco rígido externo ou secundário com espaço livre suficiente para o seu banco de dados do Swing Catalyst.

Passo 1: Fazendo um backup da pasta ProgramData

A pasta de dados do programa Swing Catalyst pode ser encontrada em C:\ProgramData\Swing Catalyst\

A pasta de dados do programa contém as configurações, quaisquer Calibrações de sensores, seu arquivo de licença, entre outros.

Observe que as Gravações podem estar armazenadas em um local diferente; anote esse local (consulte o passo 2).

  • Navegue até ProgramData digitando %programdata% e pressionando a tecla Enter.

  • Copie a pasta inteira do Swing Catalyst para um disco rígido externo.

Esta é a pasta ProgramData do Swing Catalyst:

Faça uma cópia do arquivo SwingCatalystDB.s3db para um disco rígido externo ou secundário.

Passo 2: Fazendo uma cópia das suas Gravações

Localizando onde as Gravações estão armazenadas

  • Acesse as Configurações do Swing Catalyst: clique em “General” e observe o “Path” especificado na seção Database (veja a área superior direita da captura de tela acima).

  • Anote o local do banco de dados; é lá que suas Gravações e Lições estão armazenadas.

Um cenário comum é ter o arquivo de banco de dados do Swing Catalyst no diretório ProgramData, mas ter as Gravações propriamente ditas — cujo conteúdo o banco de dados referencia — armazenadas em um disco rígido ou partição diferente devido a restrições de espaço.

Se o seu banco de dados (conforme a captura de tela acima) indicar C:\ProgramData\Swing Catalyst\database, faça uma cópia da pasta database.

Copiando os dados para o novo computador

Agora que fizemos uma cópia do diretório ProgramData do Swing Catalyst e de todas as Gravações (conforme definido pelo caminho mostrado na captura de tela acima) para um disco rígido externo ou similar, estamos prontos para copiá-los no novo computador.

Important: Antes de prosseguir, certifique-se de baixar e instalar o Swing Catalyst primeiro.

Requisitos:

  • Uma licença válida do Swing Catalyst.

Substituindo o diretório ProgramData do Swing Catalyst

No novo computador, devemos ter uma instalação limpa do Swing Catalyst; não deve haver nada que precisemos manter neste computador, ou seja, é seguro substituir os arquivos.

  • Conecte seu disco rígido externo e localize sua cópia do diretório ProgramData do Swing Catalyst.

  • Navegue até o diretório ProgramData no novo computador.

  • Substitua a pasta Swing Catalyst existente (no novo computador) pela cópia que você fez (do disco rígido externo).

Configurando o banco de dados

Em alguns casos em que o Swing Catalyst está configurado para usar um local diferente do padrão C:\ProgramData\Swing Catalyst\database, será necessário copiar o conteúdo da pasta para a pasta database no diretório ProgramData.

No nosso exemplo acima, o diretório era D:\Temp2, o que significa que seria necessário copiar o conteúdo dessa pasta para a pasta database.

Para verificar quais caminhos o Swing Catalyst está configurado para usar, podemos utilizar a ferramenta de edição de registro regedit para inspecionar isso.

Navegue até Computador –> HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Initial Force\Swing Catalyst. Clique na pasta conforme mostrado na captura de tela abaixo.

Aqui estão as entradas do registro; o DatabaseFilePath não deve ser alterado.

O DatabasePath é o local onde o Swing Catalyst procura as Gravações.
