Como ativar ou desativar versões beta do SwingCatalyst

Este artigo explica como aderir às versões beta e como cancelar a adesão para receber apenas atualizações de versões estáveis do Swing Catalyst*.

Uma versão beta é uma versão de pré-visualização com novos recursos, funcionalidades e correções de erros disponíveis para aqueles que optarem por permitir versões beta dentro do software.

  • Este artigo também se aplica ao Motion Catalyst.

Como ativar versões beta

  • Inicie o software SwingCatalyst.

  • Em Configurações, vá para Configurações Gerais, Notificações.

  • Certifique-se de que “Permitir versões beta” está marcado.

Após reiniciar o SwingCatalyst, as versões beta serão ativadas e você receberá notificações sobre novas versões beta quando disponíveis.

Consulte as capturas de ecrã no final do artigo, pois elas ilustram os pontos mencionados acima.

Como atualizar para uma nova versão beta

Se você tiver uma licença válida e o seu software estiver configurado para receber notificações de versões beta, receberá uma notificação semelhante à imagem abaixo ao iniciar o software.

Na janela pop-up de notificação de atualização, clique em “Atualizar”; isso deverá abrir um novo navegador web no site do SwingCatalyst: clique no botão “Baixar” para descarregar a versão mais recente. Faça duplo clique no ficheiro descarregado e execute o instalador.

Se precisar de ajuda para instalar o software, consulte: Como instalar o SwingCatalyst.

Como desativar versões beta

Certifique-se de seguir as instruções aplicáveis ao seu caso.

**Nota: Certifique-se de não desmarcar “permitir versões beta” antes de ter instalado ou desinstalado. **

Se não desejar mais utilizar uma versão beta, existem dois cenários que podem aplicar-se a si:

Cenário A: Desejo utilizar a versão estável anterior:

  • Consulte o nosso artigo de suporte sobre como instalar a versão anterior.

  • Alternativamente, consulte o nosso artigo de suporte “como instalar e desinstalar o SwingCatalyst” e consulte a secção “desinstalar”.

Cenário B: Quero permanecer na versão do software que estou a usar e não desejo mais receber notificações beta.

É importante garantir que a versão instalada não é de facto uma versão beta e que a notificação de atualização que está a ver menciona explicitamente “beta”; caso contrário, seguir estes passos pode bloquear o seu acesso ao software. Consulte a secção de resolução de problemas abaixo para ver exemplos dos diferentes tipos de notificações de atualização.

Verifique se está na versão mais recente

  • Verifique a sua licença. Em Configurações, Geral, em Informações de Licença, clique em “Configuração de licença”.

  • Anote a versão principal indicada no canto inferior direito, “Válido para versões até”.

  • Verifique a versão atualmente instalada na barra de título, por exemplo, 10.0.5 rev 37057.

  • Nas configurações gerais, certifique-se de que está ligado à internet e clique em “Verificar atualizações”; se não houver novas atualizações disponíveis, provavelmente está na versão estável mais recente.

  • Desmarque a caixa de seleção “permitir versões beta” para não receber novas notificações beta.

Como sei qual é a versão estável?

  • Visite o nosso arquivo de software: https://swingcatalyst.com/downloads/ e aceda ao Arquivo de Software. Todas as versões listadas neste arquivo são a versão estável mais recente para cada versão principal.
