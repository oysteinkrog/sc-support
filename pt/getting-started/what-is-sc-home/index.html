O que é o Swing Catalyst Home?

Introdução

Este suporte tem como objetivo abordar o Swing Catalyst Home.

Procurando o guia de introdução? Primeiros Passos.

O que é o Swing Catalyst Home?

O Home é uma versão do software SwingCatalyst voltada para o mercado doméstico. Possui menos recursos profissionais, como a ausência da funcionalidade de gravação de Lição, e incorpora um limite de Usuários.

O Home suporta até duas câmeras ao vivo e um Launch Monitor Foresight ou FlightScope.

Diferenças entre o Home e o Swing Catalyst Pro+ e Pro

O Swing Catalyst Home é voltado para o Usuário doméstico, com um preço significativamente mais baixo do que o Swing Catalyst Pro ou Pro+, destinados a Usuários profissionais.
