O que são Marcadores?

Introdução

Este artigo de suporte tem como objetivo descrever o que são Marcadores no Swing Catalyst e no Motion Catalyst, e para que são utilizados. Existem algumas diferenças entre o Motion Catalyst e o Swing Catalyst, mas os fundamentos sobre como os Marcadores funcionam e suas características são os mesmos, o que significa que este artigo pode ser utilizado para ambos os softwares.

Captura de tela de exemplo do Motion Catalyst de uma Gravação de salto com contramovimento

O que são Marcadores?

Os Marcadores são usados para identificar pontos-chave em uma Gravação. Para determinados Esportes e Atividades, os Marcadores se correlacionam com Fases específicas da Atividade, ou simplesmente indicam o início e o fim do movimento.

Para o salto com contramovimento (como ilustrado), essas Fases são: Descarregamento de Peso, frenagem, propulsão, decolagem e aterrissagem.

Se observarmos mais de perto as capturas de tela acima, veremos que há uma série de setas acima da linha do tempo de Reprodução; cada seta, ou Marcador, se correlaciona com diferentes Fases da Atividade gravada.

O número de Marcadores disponíveis depende da Atividade. Certas Atividades possuem mais Marcadores do que outras. Além disso, os Marcadores são definidos automaticamente para determinadas Atividades em que as Fases são identificadas a partir de Dados de Força. Estamos trabalhando para melhorar isso, portanto a lista abaixo está sujeita a alterações.

Atualmente, os Esportes e Atividades que possuem Marcadores automáticos definidos por Métricas Chave são:

As posições dos Marcadores são armazenadas no banco de dados para cada Gravação e em qualquer arquivo de Tomada exportado (Gravação com dados).

Como defino os Marcadores?

Para alterar ou definir manualmente as posições dos Marcadores:

  • “Desbloqueie” os Marcadores pressionando o botão “Marcadores”.

  • Uma vez selecionado, você pode alterar a posição dos Marcadores arrastando a(s) seta(s).

  • Ao terminar, certifique-se de “bloquear” os Marcadores novamente desmarcando o ícone de “Marcadores”, saindo do modo “editar Marcador”.

Para redefinir as posições, clique no(s) botão(ões) “redefinir A” (ou B) (exibido à esquerda do botão de Marcadores).

Marcadores cinzas indicam que não foram definidos ou alterados.

Os Marcadores também são representados nos gráficos de dados como linhas verticais, indicando onde na Gravação as diferentes Fases estão no tempo (eixo X do gráfico):

Dica: A posição do primeiro e (ou) último Marcador determina a quantidade de dados exibida nas caixas de dados. A duração antes do primeiro Marcador e após o último Marcador depende da Atividade e do Esporte, mas alterá-la manualmente pode ser útil para visualizar determinadas partes de uma Gravação. Isso é especialmente útil para Gravações feitas sob a Atividade de “movimento livre”, que podem ter até 30 segundos de duração.

Note: Estamos apenas alterando o que estamos visualizando “no tempo”; nenhum dos dados armazenados é de fato alterado de nenhuma forma.

Para mais detalhes sobre como visualizar e manipular os gráficos, consulte este artigo.

Por que devo definir os Marcadores?

Para permitir uma Sincronização fácil da Reprodução entre Gravações, recomendamos a definição de Marcadores.

Por exemplo, suponha que você queira visualizar duas Gravações lado a lado de um salto com contramovimento realizado por dois Usuários diferentes, onde deseja sincronizar a Reprodução em torno de uma Fase específica.

  • Clique no botão “Sincronizar”.

  • Selecione a Fase / Marcador no qual deseja sincronizar.

  • Pressione play.

Note: A quantidade de Marcadores disponíveis e o nome das Fases variam dependendo do Esporte e da Atividade.
