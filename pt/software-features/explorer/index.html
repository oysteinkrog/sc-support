Como usar o Explorador

Introdução

O Explorador fornece uma interface para navegar, selecionar e gerenciar Gravações de Vídeo organizadas por Sessões. Este documento explica como navegar e utilizar todos os recursos do Explorador de forma eficaz nas versões 25.3 e posteriores.

Visão Geral

Barra de ferramentas: Barra de ferramentas com botões para acesso rápido a todas as funcionalidades principais do Explorador.

Lista de Usuários: Lista de usuários registrados com recursos práticos, como barra de pesquisa e botão de ordenação.

Lista de conteúdo baixável: Lista de Gravações baixadas, como Swings do Tour.

Sessões e Gravações: Lista de Sessões que podem ser expandidas para exibir todas as Gravações daquela Sessão.

Pré-visualização da Gravação: Janela de pré-visualização exibindo uma miniatura animada e informações importantes sobre a Gravação.

Lista de exportação: Arraste e solte Gravações aqui para adicioná-las à lista de exportação. As Gravações podem então ser exportadas como um arquivo de Tomada, permitindo que sejam importadas no SwingCatalyst posteriormente, ou como arquivos TSV de dados brutos para análise personalizada.

Navegação por Teclado

O Explorador oferece suporte à navegação completa por teclado através das miniaturas de Gravação:

Navegação por Teclas de Seta

  • ↑ - Mover uma linha para cima

  • ↓ - Mover uma linha para baixo

  • ← - Mover uma coluna para a esquerda

  • → - Mover uma coluna para a direita

Navegação por Página

  • Home - Ir para o primeiro item da Sessão atual

  • End - Ir para o último item da Sessão atual

  • Page Up - Avançar uma página visível para cima

  • Page Down - Avançar uma página visível para baixo

Navegação entre Sessões

  • Quando estiver no topo ou na parte inferior de uma Sessão, as teclas de seta navegam automaticamente para as Sessões adjacentes

  • As Sessões serão expandidas automaticamente ao navegar para dentro delas

Comportamento de Seleção

O Explorador implementa recursos padrão de múltipla seleção:

Seleção Individual

  • Clique - Selecionar uma única Gravação

  • Clique duplo - Abrir a Gravação selecionada para visualização

Múltipla Seleção com o Mouse

  • Ctrl** + Clique** - Alternar a seleção de itens individuais

  • Shift** + Clique** - Selecionar o intervalo do último item selecionado até o item clicado

Múltipla Seleção com Teclado

  • Shift** + Teclas de Seta** - Estender a seleção na direção da navegação

  • Ctrl** + Teclas de Seta** - Navegar sem alterar a seleção

  • Ctrl** + **A - Selecionar todas as Gravações visíveis no Explorador

  • Ctrl** + Shift + **A - Selecionar todas as Gravações visíveis na Sessão atual

  • Escape - Limpar as seleções visíveis

Informações de Seleção

  • Contador de Seleção: Exibe o total de itens selecionados e a quantidade de itens selecionados visíveis

  • Seleções Ocultas: Indica quando há itens selecionados em Sessões recolhidas ou filtradas

  • Feedback Visual: Os itens selecionados são destacados com uma borda

Menus e Ações de Contexto

Menu de Contexto da Gravação

Clique com o botão direito em qualquer Gravação para acessar:

  • Abrir - Abrir a Gravação

  • Adicionar à Pilha - Adicionar à Pilha de análise para acesso rápido no Modo de Análise

  • Adicionar à Exportação - Adicionar à fila de exportação

  • Excluir - Remover a Gravação

  • Enviar para Online - Compartilhar via SwingCatalyst Online

Menu de Contexto de Aluno/Grupo

Clique com o botão direito nos nomes de Alunos para:

  • Adicionar Usuário à Lista de Exportação - Incluir todas as Gravações do usuário na exportação

  • Excluir Usuário - Remover o usuário e todas as suas Gravações

Comandos Globais

Disponíveis através de atalhos de teclado:

  • Enter- Abrir a(s) Gravação(ões) selecionada(s).

  • Delete - Excluir todas as Gravações selecionadas

  • Ctrl** + **A - Selecionar todas as Gravações visíveis no Explorador

  • Ctrl** + Shift + **A - Selecionar todas as Gravações da Sessão atual

  • Escape - Limpar a seleção atual

Arrastar e Soltar

Arrastando Tomadas

  • Arraste Tomadas para as zonas de soltar

  • Feedback visual exibe um indicador de arrastar com a miniatura da Gravação

  • Indicadores de soltar destacam os destinos válidos

Zonas de Soltar

  • Zona de soltar do Viewport A/B - Solte aqui para abrir a(s) Gravação(ões) no Viewport A ou B

  • Zona de soltar da lista de exportação - Solte aqui para adicionar a(s) Gravação(ões) à fila de exportação

Dicas para Uso Eficiente

  • Operações em Massa: Use a múltipla seleção para executar ações em várias Gravações simultaneamente

  • Eficiência com Teclado: Combine Ctrl, Shift e as teclas de seta para fluxos de trabalho de seleção rápida

  • Consciência de Contexto: Os menus do botão direito oferecem ações adequadas ao contexto

  • Feedback Visual: Preste atenção aos contadores de seleção e aos indicadores de destaque

O Explorador foi desenvolvido para um gerenciamento de fluxo de trabalho eficiente, permitindo que você navegue rapidamente por grandes coleções de Gravações e execute operações em massa com o mínimo de esforço.
