Métricas Chave

Este artigo aborda a nova Caixa de Dados de Métricas Chave introduzida na versão 10.0. Embora lançada na versão 10.0, este artigo cobre funcionalidades disponíveis na versão 10.2, que podem ser diferentes das versões anteriores.

  • Disponível na versão: 10.2 e superior.

  • Aplicável a: MotionCatalyst

  • Hardware necessário: Force Plate(s) / Motion Plate / Dual Motion Plate.

  • Licença de software que suporta Métricas Chave.

Qual versão eu tenho?

O que são Métricas Chave?

As Métricas Chave são derivadas de Dados de Força e a análise é realizada sobre esses dados.

Atividades diferentes possuem Métricas Chave diferentes, e nem todas as Atividades têm a mesma quantidade de Métricas Chave disponíveis.

Para quais Atividades as Métricas Chave estão disponíveis?

As Métricas Chave estão disponíveis para as seguintes Atividades no MotionCatalyst:

  • Counter Movement Jump

  • Dynamic Balance

  • Isometric Mid-Thigh Pull

  • Plyo-push up

  • Push Up

  • Repeated Hops

  • Equilíbrio Estático

  • Squat Jump

  • Upper Body Plank

Pretendemos expandir esta lista e oferecer suporte a outros Esportes no futuro, como golfe e beisebol.

A Caixa de Dados de Métricas Chave

Métricas Chave é uma nova Caixa de Dados que exibe valores principais de pontos relevantes em uma Atividade.

É possível personalizar quais Métricas Chave são exibidas selecionando cada “bloco” e escolhendo no menu suspenso de Métricas Chave. Essas seleções serão lembradas para a próxima Gravação que você abrir, de forma semelhante a como o sistema lembra qual Caixa de Dados está sendo exibida.

Opções de apresentação

É possível alterar o Layout da Caixa de Dados de Métricas Chave para 4, 6 ou 8 Métricas.

Reduzir a quantidade de Métricas pode ser útil para diminuir a poluição visual e melhorar a legibilidade.

Exportar todas as Métricas Chave (TSV)

A Caixa de Dados de Métricas Chave também suporta a exportação de todas as Métricas Chave disponíveis para um arquivo TSV (valores separados por tabulação) diretamente da própria Caixa de Dados.

Métricas Chave ausentes para esta Gravação

Em alguns casos, as Métricas Chave não estão disponíveis para uma Atividade específica ou para a Atividade gravada. Clicar em “Mais informações” pode revelar mais detalhes sobre o motivo pelo qual as Métricas Chave estão indisponíveis.

Causas comuns:

  • Não realizar a Atividade corretamente / de acordo com o protocolo.

  • Movimentar-se excessivamente antes de realizar a Atividade.

  • Configuração incorreta do Peso Corporal.

  • Calibração de Plataforma incorreta (tente calibrar / zerar as Force Plates).

  • Configuração da Placa inadequada.

Não tenho a Caixa de Dados de Métricas Chave

As Métricas Chave estão disponíveis apenas para o MotionCatalyst e para um número selecionado de Atividades.

Possíveis causas:

  • A licença não suporta Métricas Chave.

  • Não está utilizando o MotionCatalyst / sem licença para o MotionCatalyst.

  • A Atividade ou Esporte não suporta Métricas Chave.
