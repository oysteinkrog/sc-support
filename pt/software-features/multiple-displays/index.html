Como configurar múltiplos monitores com Swing Catalyst

Como configurar múltiplos monitores

Este artigo de suporte aborda a configuração e a instalação de múltiplos monitores no Windows. Configuração da tela de feedback no Swing Catalyst e o uso de cenários de múltiplos monitores no Swing Catalyst, bem como mostrando como navegar e mover janelas com mais de um monitor.

Como configurar múltiplos monitores no Windows:

  1. Certifique-se de que seu computador é capaz de conectar múltiplos monitores. Alguns computadores ou laptops têm algumas limitações, como máximo 2 monitores.

Para configurações com mais de dois monitores você precisará ter uma placa gráfica capaz de suportar a quantidade de saídas necessárias, ou alternativamente, se você deseja apenas espelhar a exibição, isso pode ser feito com divisores HDMI (mais sobre isso abaixo).

  1. Verifique se você possui os cabos necessários para conectar seu monitor. Os tipos de conexão mais comuns atualmente são: HDMI, DVI ou Display Port. Este último geralmente requer um adaptador. A maioria dos computadores atuais possui uma porta HDMI, porém alguns laptops possuem HDMI mini ou display port.

É importante observar a porta à qual você está conectando, para que você tenha o adaptador apropriado, se necessário.

  1. Conecte seu monitor ao computador e clique com o botão direito do mouse na área de trabalho e selecione Configurações de Exibição.

If the display has been successfully detected it should show more than one display.

To set your display as the main display, check the “Make this my main display” box.

Note: You may want to set your main display to display 1 (i.e the first output on the graphics card).

If you wish to extend the desktop to your secondary display select the option under Multiple displays.

Please note that if the display you’re connecting to has a higher or lower resolution the image might be slightly different. The DPI also might be different causing the text to be larger or smaller than what you might be used to. Use the recommended resolution where possible.

Now that we have more than one display set up in Windows, make sure you have the orientation right (i.e that the monitor on the right is to your right). Having this sorted helps a lot in navigating; especially if it’s more than two displays.

Note: Windows 7 has a different configuration for displays, but the overall process is the same.
