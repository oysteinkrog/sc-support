前額面トルク分析 - ユーザーガイド

はじめに

フロンタルプレーントルクとは

フロンタルプレーントルク（FPT）は、ゴルフスウィング中に前額面軸周りで身体が生成する回転力を測定します。地面反力を使用して回転パワーをいかに効果的に生成しているかを測定するものと考えてください。

ゴルフクラブをスウィングするとき、足は地面を押し、地面はそれに応じて身体を押し返します。身体の重心と足にかかる力との相互作用がトルク（回転力）を生成し、スウィングにパワーを与えるのに役立ちます。

機能構成

FPT機能には、2つの主要なコンポーネントが含まれます：

FPTグラフ（DataBox） - スウィング全体を通じてトルク値を表示するタイムシリーズグラフ（主要メトリクス付き）

3D可視化 - モーションキャプチャスケルトンビューのモーメントアームと力分解のリアルタイムオーバーレイ

なぜこれが重要なのか

フロンタルプレーントルクを理解することで、以下のことが可能になります：

パワー生成パターンを特定する - 地面反力を回転エネルギーにいかに効率よく転移しているかを確認

生体力学的なレバレッジを可視化する - 3D で重心と地面反力間のモーメントアームの関係を確認

タイミングを分析する - ピークトルクがボール衝撃に対して いつ発生するかを理解

力成分を分解する - 地面反力がさまざまな方向にどのように分布するかを確認

スウィングを比較する - 時間の経過に伴う力生成の変化を追跡

前提条件

フロンタルプレーントルク分析を使用するには、以下が必要です：

必須：地面反力データを含むフォースプレート記録

必須：重心追跡用のモーションキャプチャデータ

必須：キャリブレーション済みカメラセットアップ

必須：体重測定（正規化値用）

クイックスタート

レイアウトに FPT DataBox を追加する

  • 分析ビューで記録されたスウィングを開く

  • DataBox メニューまたはレイアウトエディタをクリック

  • 利用可能なDataBoxリストから横断面回転力を見つける

  • 分析レイアウトに追加する

  • DataBoxは記録からのデータで自動的に入力されます

3D可視化を有効にする

モーメントアームと力の分解ビジュアルは、スケルトンと共に3Dビデオビューポートに表示されます。これらを有効にするには：

  • モーションキャプチャーとフォースプレートデータを含む記録を開く

  • ビデオビュー内のForce Vector Settingsパネルを探す

  • 表示したい可視化オプションを有効にする

必要なデータ

FPT分析が正常に機能するには、記録に以下が含まれている必要があります：

データタイプ 必須 目的

フォースプレートデータ はい 地面反力（Fx、Fz）と圧力中心を提供

モーションキャプチャ はい トルク計算と3D可視化用の重心位置を提供

体重 はい 比較用にトルク値を正規化するために使用

カメラキャリブレーション はい 適切な3Dアライメントに必須

インパクトブックマーク 推奨 ボールコンタクトに相対的なタイミングメトリクスを有効にする

表示の理解

グラフ

メイングラフはスイング中の時間経過に伴うトルク値を表示します：

X軸（水平）：スウィング開始からフィニッシュまでの時間

Y軸（垂直）：トルク値（パーセンテージおよび/または絶対値で表示可能）

ゼロライン：ゼロの水平線 - 上下の値は反対の回転方向を示します

デュアル軸システム

グラフは同時に2つの異なるスケールを表示できます：

左軸（パーセンテージ）：体重で正規化されたトルク（Nm/kg、Force Factorとして表示）

右軸（絶対値）: ニュートンメートル（Nm）の実際のトルクを表示します

主要メトリクス

グラフの隣に3つの主要メトリクスが表示されます：

1. 最大トルク（力係数）

表示内容: ピークトルクの大きさを体重で正規化した値

単位: Nm/kg（力係数として表示）

例: 0.85 の値は、ピークトルクが体重1kg当たり0.85ニュートンメートルであることを意味します

2. 最大トルクタイミング

表示内容: ボールインパクト時を基準とした、ピークトルクが発生するタイミング

単位: ミリ秒（ms）

注: インパクトブックマークが設定されている場合のみ表示されます

例: -50ms はピークトルクがインパクトの50ms前に発生、+20ms は20ms後に発生、0ms はインパクト時に発生することを意味します

3. 力係数（生値）

表示内容: 方向を含む生の正規化トルク値（正または負）

単位: Nm/kg

例: +0.85 と -0.85 は同じ大きさですが、回転方向が反対です

フェーズハイライト

有効にされている場合、色付きのバンドがグラフにオーバーレイされ、スウィングのさまざまなフェーズを表示します：

  • バックスウィング、ダウンスウィング、インパクト、フォロースルー

3D 可視化

モーメントアーム可視化

モーメントアーム可視化は、重心（COM）と地面反力の間の生体力学的なレバレッジ関係を表示します。

要素 外観 表示内容

モーメントアームライン オレンジの実線 COMから力の作用線までの垂直距離

作用線 オレンジの破線 力が作用する直線を延長したライン

距離ラベル 白いテキスト、暗い背景 モーメントアームの距離（センチメートル単位、±X.X cm）

力ベクトル分解

力分解可視化は、総床反力を3つの直交成分に分解します。カメラビューに関わらず、色は常に同じ物理的な力の方向を表します：

成分 色 物理的方向 表示内容

X成分 ピンク 左右方向（内外側） 側方力の分布

Y成分 ティール 上下方向（鉛直） 鉛直力の分布

Z成分 緑 前後方向（前後） 前後方向の力分布

各成分矢印には、その方向の総力に対する割合を示すパーセンテージラベルも表示されます。

カメラビューの動作

力ベクトルはカメラビューを基準に表示されます。スクリーンに奥行き方向（画面の奥/手前に向かう）として表示される成分は、明確性のため非表示となります：

カメラビュー 表示される成分 非表示の成分

フェースオン X（ピンク、水平）、Y（ティール、鉛直） Z（緑、奥行き）

ダウン・ザ・ライン Z（緑、水平）、Y（ティール、鉛直） X（ピンク、奥行き）

注意：色は常に同じ物理的な方向を表します。ピンクは常に内外側方向の力、ティールは常に鉛直力、緑は常に前後方向の力です。スクリーン上の位置のみがカメラアングルに基づいて変わります。

3D 可視化設定

モーメントアーム設定

設定 デフォルト 説明

モーメントアームを表示 オフ COMから力のラインまでのオレンジ色の実線を切り替え

作用線を表示 オフ 力の方向の延長を示すオレンジ色の破線を切り替え

距離ラベルを表示 オフ 距離値ラベル（±X.X cm）を切り替え

力分解設定

設定 デフォルト 説明

X/Y/Z成分を表示 オフ 3つの成分矢印とパーセンテージラベルをすべて切り替え

設定オプション（グラフ）

パーセンテージを表示（パーセンテージ軸）：デフォルト オン - 正規化されたトルク（Nm/kg）を切り替え

ニュートン表示（絶対軸）: デフォルトOff - 絶対トルク（Nm）の表示/非表示を切り替えます

フェーズハイライト: デフォルトOff - スウィングフェーズを示す色付きバンドを表示します

グリッドラインを表示: デフォルトOn - 水平グリッドラインを表示します

チャートタイプ: マウンテンチャート（デフォルト）またはラインチャート

トラブルシューティング

「プレート上に人物がいません」というメッセージ

  • アスリートが記録開始時にフォースプレート上に立っていることを確認してください

  • アスリートプロフィールに体重が入力されていることを確認してください

  • フォースプレートのキャリブレーションが完了していることを確認してください

グラフデータが空または欠落している

  • 記録中にフォースプレートがアクティブだったことを確認してください

  • モーションキャプチャデータが記録されたことを確認してください（FPT計算に必須）

  • 記録にスウィング全体の期間が含まれていることを確認してください

タイミングメトリクスが表示されない

  • 記録内にインパクトブックマークを設定してください
