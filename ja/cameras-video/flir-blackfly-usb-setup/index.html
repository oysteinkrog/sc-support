FLIR Blackfly S USB カメラを Swing Catalyst で使用する方法

この記事では、Spinnaker 対応 USB カメラを Swing Catalyst でセットアップおよび設定する方法について説明します。

Chameleon USB 3.0 や Grasshopper USB 3.0 などの一部の旧モデルもサポートされており、この記事はそれらのカメラのリファレンスガイドとしてもご利用いただけます。モデルによって利用可能な設定や機能が異なるため、この記事の内容がお使いの画面と完全に一致しない場合があります。

Note: Spinnaker は Swing Catalyst バージョン 9.4 以降でのみサポートされています。現在実行中のバージョンを確認するには？

Swing Catalyst での FLIR Blackfly S GigE のセットアップ

レガシー記事：Swing Catalyst での Point Grey Blackfly GigE（旧バージョンの Swing Catalyst 向け）

はじめに：ハードウェアのセットアップ

カメラに付属の 4 本の黒いプラスネジを使用して、三脚アダプターをカメラ本体に取り付けます。

レンズを開梱し、プラスチック製のレンズカバーを必ず取り外してください。

カメラからセンサーカバーを取り外します：

レンズをカメラに取り付ける

ロックネジを締めてケーブルをカメラに固定します：

カメラレンズの調整：

このレンズには上から順に 3 つの調整機能があります：

  • フォーカス（∞ マークに向けて調整すると、背景の遠くにある被写体にピントが合います）

  • 絞り（Iris の調整。レンズを通過できる光量を調整します。絞りを絞るほど鮮明な画像が得られます）。

  • ズーム（レンズのズームをワイドまたは望遠に調整します）。

はじめに：ドライバーのインストール

ドライバーは弊社のダウンロードページ からダウンロードできます。

セットアップウィザードに従ってください。

  • 「Camera Evaluation」を選択します。

  • USB カメラを使用している場合は、「I will use GigE Cameras」のチェックボックスをオフにします。

ドライバーのインストールはこれで完了です。Swing Catalyst 9.4 以降がインストールされていれば、カメラが Swing Catalyst のカメラ設定に表示されるようになります。

Swing Catalyst 設定でのカメラの設定

カメラがコンピューターに接続されており、カメラ背面の LED が緑色に点滅していることを確認してください。

Swing Catalyst を起動し、設定 -> カメラをクリックします。

Spinnaker カメラは Spinnaker と表示されます（この例では USB カメラと GigE カメラが接続されており、BFS-U3 モデル（U3 は USB3 を意味します）を設定します）。

「Advanced…」をクリックします。

詳細カメラ設定ウィンドウには、便利なすべての設定が表示されます。各設定を個別に確認してみましょう。

上記の設定はデフォルトのカメラ設定です。ほとんどの設定が Auto に設定されていますが、スポーツ分析のためのビデオ画質をより細かく制御するために、これらの設定を変更することができます。

フレームレートの変更：

「Frame rate control enable」ボックスにチェックを入れると、フレームレートを手動で設定できるようになります。このボックスのチェックを外すと、フレームレートは実質的に Auto に設定されます（注：このカメラの最大フレームレートは 226 FPS です。最大フレームレートを達成するには、すべての設定を手動に設定する必要があります）。

フレームレートは、シャッタースピードとデバイスリンクスループットの設定によって制限される場合があります。

露出時間（シャッタースピード）の変更：

屋外の日光下でない限り、手動露出を使用することをお勧めします。Auto のままでは、スポーツ分析には映像がぼやけすぎる可能性があります。ブレを軽減するために、露出時間は 2ms（2000μs）未満に設定することをお勧めします。十分な照明がある環境では、露出時間は 1ms（1000μs）未満にするとよいでしょう。

ゴルフスイング全体を通してクラブを鮮明に映すためには、露出時間をさらに短くする必要があります。400 または 200 を試してみてください。

ビデオ画像の明るさは、シャッタースピード、Gain 設定、レンズの絞り、および利用可能な光量の組み合わせによって決まります。

カメラ Gain の変更：

光の状況が変化する環境では Gain を Auto に設定することが望ましいですが、屋内環境では Gain を手動に設定する方が適しています。

dB 値が高いほど画像は明るくなりますが、その結果ノイズも増加し、全体的な映像品質が低下する可能性があります。場合によっては、ノイズを犠牲にして Gain を若干高めに設定し、シャッタースピードを下げてフレームごとに被写体（インパクト時のクラブ、野球のバットなど）を鮮明に映すことが有効なこともあります。

Gamma とブラックレベルの変更：

ブラックレベルは輝度調整の一形態と考えることができ、カメラセンサーの任意のピクセルが返す最小値に対応します。

ブラックレベルの値を上げることで、画像を明るくすることができます。

デフォルト値のままにしておくことをお勧めします。

映像画質の改善に関する詳細については、比較写真付きのサポート記事をご覧ください：improving-image-quality.md

カメラのホワイトバランスの変更：

通常、この設定は Auto（継続）のままにしておくことをお勧めしますが、最大フレームレートを達成するにはこれもオフにする必要があります。

ホワイトバランスはビデオ画像の色温度に影響し、ホワイトバランスが大きくずれていると画像の見た目が悪くなり、赤みや緑みがかって見えることがよくあります。

Auto ホワイトバランスを有効にすると、カメラの最大値である 226 FPS の代わりに 200 FPS となり、フレームレートがやや低下します。

デバイスリンクスループット：

デフォルト設定のままにしておくことをお勧めしますが、値を下げるとフレームドロップを減らすことができる反面、FPS が低下します。

Region Of Interest (ROI) の適用：

Region of Interest は画像サイズを縮小し、それによって各画像に必要な帯域幅も削減する方法です。画像サイズを縮小することで、全体的なピクセル読み出し要件が小さくなり、フレームレートを向上させることができます。

高さと幅を縮小すると、フレームレートの向上と帯域幅要件の低減に良い効果をもたらす可能性があります。

Region of Interest を変更するには、高さスライダーを左にドラッグして画像の高さを縮小します。

画像の高さを変更したため、縮小された画像サイズによりカメラを物理的に移動する代わりの手段として、Y オフセットも変更できるようになりました。

カメラタブに戻ってフレームレートを確認すると、最大フレームレートが 288 に設定できるようになっていることがわかります（これはカメラセンサーの高さを縮小して ROI を適用したためです）。

トラブルシューティング

USB 3.0 の取り扱いは難しい場合があります。たとえば、USB ケーブルによって性能に差があったり、特定の USB 3.0 コントローラーが問題を引き起こしたりすることがあります。詳細については、推奨 USB コンポーネントの記事をご覧ください：recommended-usb3-components.md

フレームドロップ：

各デバイスのデバイスリンクスループットを下げることで、フレームドロップを回避できる場合があります。十分に下げると、スループットがフレームレートに影響します。

特に複数カメラのセットアップでは、スループットを下げることで、わずかなフレーム数を犠牲にしながらシステムを安定させることができます。

たとえば、USB 3.0 は 5Gb/s（625 MB/s）の転送速度が可能とされています。

解像度 1920 x 1200 で 150 FPS の USB 3.0 カメラ 1 台は、カメラ 1 台あたり約 345MB/s を使用します。そのため、複数カメラのセットアップでは、弊社の推奨事項に従い、専用の USB 3.0 コントローラーカードを用意することが重要です（ほとんどの場合）。

もう一つの方法として、スループットの低減と組み合わせて効果的なのが、Region of Interest（ROI）の活用です。

Region Of Interest (ROI)：

Region of Interest（またはエリアオブインタレスト）を使用すると、全体的な画像サイズが縮小されて FPS が向上するだけでなく、帯域幅の使用量を抑えることができ、フレームドロップの軽減にもつながります（ROI の使用方法については上記を参照してください）。

さらに、USB ケーブルは受信フレームレートに関して重要な要素になる場合があります。詳しくは：recommended-usb3-components.md

接続の問題（カメラの切断）：

USB 3 は接続の問題が発生しやすい場合があります。多くの場合、これらの問題は不良の USB 3.0 エクステンダー、ケーブル全体の長さが長すぎること、または単純にケーブルが急激に折り曲げられたことによる損傷が原因です。

カメラが繰り返し切断される場合：

  • ケーブルと接続を確認し、カメラを再接続してみてください。

  • 上記で解決しない場合は、別の USB3 ポートにカメラを接続してみてください。

  • 複数のカメラが接続されている場合は、一部のカメラを取り外してみてください。問題が改善または解決されますか？

2 と 3 に該当する場合は、リソースの問題またはハードウェアの互換性の問題が考えられます。

USB3 エクステンダーケーブルを使用している場合は、エクステンダーや USB ハブを使用せずにカメラを直接接続してみてください。

それでも問題が解決しない場合は、ヘルプセンターでサポートチケットを作成することをご検討ください。このような場合、通常はケーブルの長さを 5 メートルから 3 メートルに短くすることをお勧めしています。

ステータスインジケーター LED

LED 説明 推奨事項
消灯 電源なし、またはLEDがアクティブ状態、またはエラーなしのエラーステータス状態 ケーブルが PC に接続されているか確認し、別のケーブルと USB ポートを試してください
緑色点滅（1 回） カメラが USB 1 の速度で動作中 USB3 ポートの接続を確認し、ケーブルに損傷がないか点検し、USB エクステンダーなしで試してください
緑色点滅（2 回） カメラが USB 2 の速度で動作中 上記と同じ
緑色点滅（3 回） カメラが USB 3 の速度で動作中 問題ありません
緑色高速点滅 ファームウェアアップデート中 -
緑色点灯（常時） 収録開始 / カメラ使用中 -
緑色と赤色の交互点滅 エラー カメラの電源を入れ直し、別の USB ポートまたはケーブルを試してください

カメラを接続すると 3 回点滅するはずです。1 回または 2 回しか点滅しない場合は、USB ケーブルまたはカメラが接続されている USB ポートに問題がある可能性があります。

その他の問題：

お使いのハードウェアによっては、シャープニングとデノイズフィルターを有効にしない方がよい場合があります。これらをオフにすると、CPU と GPU の使用量を削減できます。カメラフィルターは詳細カメラ設定のフィルタータブで確認できます。フィルターの詳細はこちら：improving-image-quality.md
