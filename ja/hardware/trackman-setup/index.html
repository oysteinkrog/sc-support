TrackMan を Swing Catalyst で使用する方法

この記事では、Swing Catalyst を TrackMan に接続し、ローンチモニターデータを動画と一緒に保存する方法について説明します。連携を有効にするには、Swing Catalyst と同時に TrackMan ソフトウェアが起動している必要があります。

note: TrackMan を Swing Catalyst で使用するには、ストリーミング映像をサポートするカメラが必要です。（対応カメラ一覧を参照してください）

インストール: TrackMan Pro/Launch 4.0.9

  • TrackMan ユニットを PC に接続する

  • TrackMan Pro または TrackMan Launch を起動し、ショット追跡画面に移動する

  • Swing Catalyst を起動し、スタートメニューの 設定 - ハードウェア に移動する

  • Launch Monitor 連携を有効にする

  • TrackMan を選択する

インストール: TrackMan Performance Studio

対応バージョン: 2.2〜4.0

  • TrackMan ユニットを PC に接続する

  • TrackMan Performance Studio を起動する

  • スタートメニューの 設定 画面に移動する（図1: 歯車アイコン）

  • SDK Output を有効にする（図2）

  • スタート に移動し、Shot analysis をクリックする

  • Swing Catalyst を起動し、スタートメニューの 設定 - ハードウェア に移動する

  • Launch Monitor 連携を有効にする

  • TrackMan を選択する

インストール: TPS（TM3e または TrackMan 4 使用時）

  • TrackMan 3e デバイスの電源を入れる

  • Windows で TrackMan の WiFi ネットワークに接続する。または USB ケーブルで接続する。

  • 手順1を除き、上記のインストールガイドと同じ手順に従う

図1: TrackMan Performance Studio での SDK Output の有効化。

TrackMan Pro/Launch/Performance Studio と Swing Catalyst の併用

  • まず TrackMan ソフトウェアを起動し、ショット追跡画面に移動する。

  • Swing Catalyst を起動し、スイングをキャプチャする。

  • 録画したスイングを開き、動画の横にあるデータボックスでショットデータを確認する。

正しくインストールされていれば、TrackMan のショットデータが自動的にキャプチャされ、動画と一緒に保存されます。

カメラの設定

場合によっては、TPS ソフトウェアがシステム上のカメラをロックし、Swing Catalyst ソフトウェアから使用できなくなることがあります。

将来のバージョンでは、TPS ソフトウェアにこの動作を無効にする設定オプションが追加される可能性がありますが、当面の間、TrackMan は以下の回避策を提供しています。

TPS ソフトウェアを開き、カメラ一覧に表示されているカメラ名を正確に確認する。

以下のファイルを探し、メモ帳で開く:

C:\ProgramData\TrackMan\VideoManagement\ExcludeCameras.TMConfig

ファイルにカメラ名を追加する。複数のカメラがある場合は、それぞれ別々の行にすべての名前を追加する。

トラブルシューティング

  • TPS で TrackMan が認識・接続されていることを確認する。

  • Swing Catalyst のハードウェア設定メニューで Launch Monitor が有効になっており、TrackMan が選択されていることを確認する。

  • Swing Catalyst の Launch Monitor 設定の下にある「トリガー」にチェックが入っていることを確認する。

  • それでもトリガーされない場合は、TPS の設定を確認し、「SDK Output」が有効になっていることを確認する。

  • TrackMan デバイスを再起動してみる。

  • データは取得できており Swing Catalyst で接続済みと表示されているにもかかわらずトリガーされない場合は、コンピューターを再起動してみる。

  • トリガーされるが非常に遅い場合: Launch Monitor 設定の遅延補正を調整してみる。約 1500ms の値が推奨されるが、これはボールの種類やレーダーを屋内・屋外のどちらで使用しているかによって異なる。

Swing Catalyst でまだデータが取得できない場合:

  • TrackMan ユニットを再起動し、SDK Output が有効になっているか再確認する。

  • Windows ファイアウォールを無効にしてみる。これで解決する場合は、TPS と Swing Catalyst の例外を追加する。

  • TrackMan OEM サービスが実行中かどうかを確認する。実行中の場合は無効にして、再度試してみる。Windows サービスの詳細はこちら: http://www.7tutorials.com/what-are-windows-services-what-they-do-how-manage-

高度なトラブルシューティング手順を確認する。
