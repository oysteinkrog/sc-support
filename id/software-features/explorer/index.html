Cara menggunakan Penjelajah

Pengantar

Explorer menyediakan antarmuka untuk menjelajahi, memilih, dan mengelola perekaman video yang diatur menurut sesi. Dokumen ini mencakup cara menavigasi secara efektif dan menggunakan semua fitur Explorer dalam versi 25.3 dan lebih baru.

Gambaran Umum

Toolbar: Toolbar with buttons for quick access to all the core functionality of the explorer.

User list: List of registered users with quality of life features such as a search bar and a sort button.

Downloadable content list: List of downloaded recordings, such as Tour Swings.

Sessions and Recordings: List of sessions that can be expanded to display all recordings for that session.

Preview recording: Preview window showing an animated thumbnail and key information about the recording.

Export list: Drag and drop recordings here to add them to the export list. Recordings can then be exported as a Take file that enables the recording to be imported into Swing Catalyst later, or as raw data TSV files for custom analysis.

Keyboard Navigation

The Explorer supports full keyboard navigation through the recording thumbnails:

Arrow Key Navigation

  • ↑ - Move up one row

  • ↓ - Move down one row

  • ← - Move left one column

  • → - Move right one column

Page Navigation

  • Home - Jump to first item in current session

  • End - Jump to last item in current session

  • Page Up - Move up by visible page

  • Page Down - Move down by visible page

Cross-Session Navigation

  • When at the top/bottom of a session, arrow keys automatically navigate to adjacent sessions

  • Sessions will auto-expand when navigating into them

Selection Behavior

The Explorer implements standard multi-selection capabilities:

Single Selection

  • Click - Select a single recording

  • Double-click - Open the selected recording for viewing

Multi-Selection with Mouse

  • Ctrl** + Click** - Toggle selection of individual items

  • Shift** + Click** - Select range from last selected item to clicked item

Multi-Selection with Keyboard

  • Shift** + Arrow Keys** - Extend selection in the direction of navigation

  • Ctrl** + Arrow Keys** - Navigate without changing selection

  • Ctrl** + **A - Select all visible recordings in the explorer

  • Ctrl** + Shift + **A - Select all visible recordings in the current session

  • Escape - Clear visible selections

Selection Information

  • Selection Counter: Shows total selected count and visible selected count

  • Hidden Selections: Indicates when items are selected in collapsed or filtered sessions

  • Visual Feedback: Selected items are highlighted with a border

Menus and Context Actions

Recording Context Menu

Right-click on any recording to access:

  • Open - Open the recording

  • Add to Stack - Add to the analysis stack for quick access in Analysis Mode

  • Add to Export - Add to export queue

  • Delete - Remove the recording

  • Upload to Online - Share via SwingCatalyst Online

Student/Group Context Menu

Right-click on student names to:

  • Add User to Export List - Include all user recordings in export

  • Delete User - Remove the user and all their recordings

Global Commands

Available through keyboard shortcuts:

  • Enter- Open selected recording(s).

  • Delete - Delete all selected recordings

  • Ctrl** + **A - Select all visible recordings in the explorer

  • Ctrl** + Shift + **A - Select all recordings in current session

  • Escape - Clear current selection

Drag and Drop

Dragging Takes

  • Drag takes to drop zones

  • Visual feedback shows drag adorner with recording thumbnail

  • Drop indicators highlight valid drop targets

Drop Zones

  • **Viewport A/B drop zone **- Drop here to open recording(s) in either viewport A or B

  • **Export list drop zone **- Drop here to add recording(s) to export queue

Tips for Efficient Use

  • Bulk Operations: Use multi-selection to perform actions on multiple recordings simultaneously

  • Keyboard Efficiency: Combine Ctrl, Shift, and arrow keys for rapid selection workflows

  • Context Awareness: Right-click menus provide context-appropriate actions

  • Visual Feedback: Pay attention to selection counters and highlight indicators

The Explorer is designed for efficient workflow management, allowing you to quickly navigate large collections of recordings and perform bulk operations with minimal effort.
