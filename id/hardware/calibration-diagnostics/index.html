Menjalankan utilitas kalibrasi

Untuk menggunakan Plat Keseimbangan Anda, diperlukan file kalibrasi. File kalibrasi dibuat untuk setiap Plat Keseimbangan, sehingga tidak ada file yang sama. Jika Anda tidak memiliki file kalibrasi yang terinstal, kemungkinan besar plat Anda juga belum didaftarkan untuk keperluan garansi. Artikel ini membahas proses mendapatkan file kalibrasi & mendaftarkan plat.

Artikel ini ditujukan untuk menghilangkan kebisingan yang tidak diinginkan dan meningkatkan Distribusi Tekanan pada Plat Keseimbangan 3 ke atas.

Plat Keseimbangan terdiri dari 2048 Sensor Tekanan berkeakuratan tinggi, dan menggunakan Sensor Edge Utility untuk melakukan zeroing pada plat mungkin diperlukan guna memastikan akurasi terbaik. Artikel ini adalah tutorial langkah demi langkah tentang cara melakukan zero set pada Plat Keseimbangan.

PENTING! ** **

Ada dua bagian dalam proses ini

Bagian 1. Menggunakan utilitas Sensor Edge untuk mendapatkan file kalibrasi terbaru untuk plat Anda.

Bagian 2. Menginstal file kalibrasi tersebut di Swing Catalyst. Pastikan Anda membaca seluruh artikel dukungan ini.

Bagian 1: Menggunakan utilitas SE untuk mendapatkan file kalibrasi.

  • Unduh utilitas kalibrasi

  • Jika diminta untuk menginstal Driver, klik ya.

Hubungkan plat ke komputer.

  • Pastikan perangkat lunak Swing Catalyst sudah ditutup, SE Utility tidak akan dapat mendeteksi plat Anda jika Swing Catalyst sedang berjalan.

  • Buka SE Utility yang baru diinstal

  • Ikuti instruksi di bawah ini.

  • Pastikan Anda memiliki monitor atau TV yang terhubung ke komputer agar Anda dapat melihat layar saat berdiri di atas Plat Keseimbangan.

Jika Anda memiliki versi lama yang terinstal, harap hapus instalasinya terlebih dahulu melalui Tambah atau Hapus Program.

Klik Start:

Setelah mengklik start, utilitas akan secara otomatis mencoba memindai perangkat. Jika tidak menemukan plat Anda, klik menu dropdown dan pilih Plat Keseimbangan Anda.

Klik Scan

Pilih perangkat yang sesuai dengan nomor seri plat Anda dan klik Next.

Mendaftarkan Plat Keseimbangan Anda

Contoh informasi pendaftaran yang telah diisi

Setelah mengisi informasi yang diperlukan untuk keperluan garansi dan layanan, klik Continue.

Jika memungkinkan, pilih kamera dan arahkan untuk menampilkan Plat Keseimbangan, lalu klik Next.

Kamera tidak diwajibkan, Anda tetap dapat melanjutkan jika tidak ada kamera yang terdeteksi.

Pastikan untuk melepas karpet dan benda lain apa pun dari Plat Keseimbangan, hal ini untuk memastikan bahwa pembacaan tidak dipengaruhi oleh faktor eksternal apa pun.

Menjalankan proses kalibrasi

Sebelum melangkah ke atas plat, utilitas mengumpulkan data untuk memiliki Nilai Dasar sebagai pembanding.

Pastikan Anda tidak secara tidak sengaja berdiri di atas plat hingga utilitas menginstruksikan Anda untuk melakukannya.

Posisi

Penting bagi Anda untuk berdiri di atas plat sesuai petunjuk utilitas.

Gambar Kaki berwarna gelap menunjukkan di mana Anda harus berdiri sekarang, dan Kaki berwarna abu-abu menunjukkan di mana Anda harus berdiri berikutnya.

Harap ikuti setiap langkah karena penting untuk mengaktifkan semua area pada plat.

Rekaman selesai

Jika Anda tidak puas dengan Rekaman, mungkin Anda melakukan kesalahan? Anda dapat dengan mudah memulai ulang proses dengan mengklik restart.

Klik Continue jika Anda ingin melanjutkan.

Klik tombol Save lalu klik tombol Send

Sebelum data dikirim ke produsen untuk ditinjau, masukkan perkiraan berat badan dan penggunaan.

Di bagian catatan, Anda dapat menyebutkan masalah yang Anda alami dengan plat, misalnya Kaki kiri yang lemah, atau kekhawatiran lainnya.

Alasan produsen ingin mengumpulkan data ini adalah untuk terus meningkatkan algoritma rekalibrasi guna memberikan pembacaan sensor yang lebih akurat.

Masukkan informasi dan klik send:

Setelah selesai, file kalibrasi disimpan ke folder Dokumen Anda, tekan “No” lalu tutup utilitas.

Bagian 2: Menginstal file kalibrasi

Lanjutkan dengan langkah-langkah berikut

  • Mulai Swing Catalyst dan buka Settings –> Hardware di menu utama.

Plat akan terdeteksi secara otomatis, jika tidak, silakan lihat bagian pemecahan masalah.

Klik tombol “Configure…” untuk membuka dialog konfigurasi.

Pengaturan Pelat Sensor

Buka tab Stance Sensor, dan klik Browse and Install.

Buka direktori tempat Anda menyimpan file kalibrasi, misalnya: C:\User\YourUsername\Documents dan pilih file mxd yang baru saja Anda simpan dari utilitas, lalu klik Open.

Setelah instalasi selesai, Anda akan mendapat pemberitahuan dan dapat mengklik OK untuk menutup jendela.

Plat Keseimbangan Anda seharusnya sudah siap digunakan. Mulai Sesi baru di Swing Analysis dan verifikasi bahwa Anda mendapatkan Pembacaan Tekanan di kotak data Tekanan dan Stance saat merekam Ayunan.

Catatan: Mungkin perlu dilakukan rekalibrasi ulang Plat Keseimbangan Anda setelah penggunaan yang berat, hal ini dapat dilakukan dengan mengklik tombol diagnostics di Settings SwingCatalyst, yang akan meluncurkan SE Utility.

Pemecahan Masalah

Plat Keseimbangan tidak dikenali atau tidak terdeteksi sebagai terhubung:

  • Pastikan perangkat dikenali oleh Windows.

Buka Windows device manager. Bagaimana caranya?

  • Verifikasi bahwa perangkat Sensor Edge ada di bawah Ports (COM & LPT)

  • Jika tidak ada, atau memiliki simbol peringatan, coba instal ulang Driver dan hubungkan kembali perangkat ke port USB yang berbeda.

  • Hubungkan perangkat ke port USB yang berbeda di komputer.

  • Jika menggunakan extender USB, coba hubungkan perangkat langsung ke PC tanpa extender.

  • Mulai ulang Swing Catalyst.

  • Mulai ulang komputer.

  • Jika Anda telah mencoba semua langkah ini dan masih ditampilkan sebagai tidak terhubung di Swing Catalyst, silakan hubungi tim dukungan kami.

Kalibrasi tidak berhasil diinstal

  • File kalibrasi yang Anda terima dari Sensor Edge Utility mungkin rusak atau file tersebut mungkin telah mengalami korupsi data, coba jalankan ulang utilitas dan instal file kalibrasi baru. Jika ini tidak berhasil, hubungi tim dukungan kami.

Ada kebisingan pada plat meskipun saya telah menjalankan utilitas

Kebisingan dapat muncul karena beberapa faktor:

  • File kalibrasi yang salah atau tidak ada file kalibrasi yang terinstal di Swing Catalyst.

  • Penggunaan yang berat: Utilitas kalibrasi sebaiknya dijalankan secara rutin, bahkan sebulan sekali untuk plat yang sering digunakan.

  • Paparan langsung sinar matahari.

  • Keausan pada sensor itu sendiri.

Utilitas mungkin tidak dapat memfilter kebisingan jika rasio sinyal terhadap kebisingan tidak cukup baik, dalam hal ini plat perlu dikalibrasi ulang melalui RMA. Produsen kemudian akan memeriksa secara manual Sesi yang dihasilkan oleh utilitas untuk melihat apakah mereka dapat memperbaikinya.

Jika produsen tidak dapat memperbaiki masalah tersebut dan plat masih dalam masa garansi atau ESA (extended service agreement), plat dapat dikirim kembali ke produsen selama RMA tersedia.

Ketidakcocokan perangkat keras

Beberapa masalah telah ditemukan pada chipset AMD 300-Series (AMD Ryzen 1700 / 2700 series) dengan perangkat USB 1.1. Khususnya pada Plat Keseimbangan, di mana Anda hanya mendapatkan 75 sampel per detik alih-alih ~145 sampel per detik. Kami menyarankan penggunaan hub USB 2.0 yang akan memungkinkan Plat Keseimbangan untuk melakukan streaming pada sample rate penuh.

Tidak ada masalah yang diketahui sejauh ini terkait penggunaan chipset AMD 300 series dengan perangkat USB 3.0.
