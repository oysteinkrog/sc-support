Cara menggunakan Foresight GC2 & HMT Launch Monitor dengan Swing Catalyst

Pendahuluan

Artikel dukungan ini menjelaskan cara menggunakan Foresight GC2 dengan Swing Catalyst.

Note: Jika Anda ingin menggunakan FSX bersamaan dengan GC2, data HMT tidak tersedia dan Anda perlu memulai FSX terlebih dahulu kemudian memulai Swing Catalyst, lalu pilih FSX Sim di Pengaturan Swing Catalyst.

Warning

Mulai versi 10.1.1 dari Swing Catalyst, integrasi GC2 akan dinonaktifkan secara default untuk mencegah masalah FSX 2020 yang tertutup saat Swing Catalyst sedang berjalan.

Jika Anda memiliki GC2 dan ingin terus menggunakannya dengan Swing Catalyst, integrasi tersebut perlu diaktifkan dari file pengaturan (lihat bagian pemecahan masalah di bawah).

Persyaratan

  • Komputer dengan port USB kosong atau WiFi (terpisah dari koneksi internet).

  • Lisensi dengan dukungan untuk kamera siaran langsung, kamera web, atau kamera kecepatan tinggi.

  • Swing Catalyst 4.0 atau lebih baru

Penting: Rekomendasi Komputer.

Swing Catalyst terintegrasi dengan GC2 maupun unit tambahan, HMT.

Untuk menggunakan GC2 bersama perangkat lunak Simulator Foresight (FR-1, FSX, FSX 2020, dll.), Simulator Foresight harus dipilih di pengaturan Launch Monitor Swing Catalyst.

Note: Jika Anda belum familiar dengan pengaturan Launch Monitor Swing Catalyst dan cara menggunakan Launch Monitor sebagai Pemicu pengambilan, silakan baca artikel dukungan kami sebelum melanjutkan.

Koneksi Langsung (tanpa integrasi FSX):

Metode koneksi ini menghubungkan ke unit secara langsung tanpa perlu menjalankan FSX secara bersamaan. Jika Anda memiliki unit HMT, Swing Catalyst juga akan mengambil data klub.

Langkah-langkah Konfigurasi

Halaman Dukungan GC2 (Driver, firmware, dan panduan pengguna)

  • Ikuti panduan instalasi Foresight GC2 (lihat tautan di atas), dan instal Driver USB GC2. Pastikan Anda memilih versi yang sesuai dengan versi Windows Anda.

  • Pastikan GC2 menggunakan versi firmware terbaru

Dengan GC2 dalam keadaan mati, sambungkan GC2 ke komputer Anda menggunakan kabel USB, lalu nyalakan GC2.

  • Mulai Swing Catalyst dan buka Pengaturan (dari layar utama, klik ikon roda gigi di kiri bawah), pilih Hardware.

  • Aktifkan integrasi Launch Monitor. Pastikan Aktifkan sebagai pemicu dicentang jika Anda ingin Launch Monitor berfungsi sebagai Pemicu pengambilan.

  • Pilih Foresight GC2

Contoh tangkapan layar yang menunjukkan Foresight GC2 teridentifikasi dan terhubung:

Integrasi Simulator

  1. Pilih ForesightSim dalam daftar pilihan Launch Monitor; jika tidak muncul secara otomatis, tekan “Search” untuk memperbarui daftar.

  2. Mulai Simulator Foresight (varian yang didukung: FSX, FSX 2020, & FR-1).

  3. Buka pengaturan Simulator Foresight, di bagian “On-Screen Data” aktifkan “Write Shots CSV” (lihat panduan pengguna simulator untuk detail lebih lanjut atau hubungi dukungan Foresight untuk bantuan).

Swing Catalyst memantau file Shots.CSV untuk perubahan dan secara aktif menggunakan file tersebut untuk mengambil data tembakan dari simulator.

  1. Pastikan Anda menggunakan mode Club Fitting (satu-satunya mode yang akan menyediakan semua data bola).

Pemecahan Masalah

Bagian ini berisi langkah-langkah pemecahan masalah untuk Foresight GC2 dan HMT serta penggunaan GC2 dengan FSX.

Saya baru saja memperbarui perangkat lunak dan integrasi tidak lagi berfungsi!

Pada versi 10.1.1 dari Swing Catalyst, integrasi GC2 dinonaktifkan secara default untuk mencegah FSX2020 menutup sendiri saat Swing Catalyst sedang berjalan. Ini adalah solusi sementara hingga Foresight mampu menyelesaikan masalah dengan FSX.

Untuk mengaktifkan kembali integrasi GC2, tutup Swing Catalyst dan buka folder Pengaturan:

  • C:\ProgramData\Swing Catalyst\settings

  • Klik kanan pada “GeneralSettings.xml” dan klik buka dengan Notepad (atau klik Edit).

  • Ubah false menjadi true dan simpan dokumen.

  • Setelah disimpan, mulai Swing Catalyst kembali, GC2 seharusnya muncul dalam daftar Launch Monitor.

Koneksi USB Foresight

  • Pastikan USB Foresight dipilih di Pengaturan Swing Catalyst.

  • Periksa koneksi ke unit Foresight GC2, dan pastikan perangkat lunak Simulator Foresight tidak sedang berjalan.

  • Jika ada data yang hilang atau tembakan tidak terdeteksi dengan benar, kemungkinan hal ini menunjukkan modul flash perlu diganti. Atau mungkin klub tidak memiliki Penanda atau Penanda tidak lagi berfungsi dengan benar.

  • Jika Anda masih tidak dapat mendapatkan Data Pemantau Peluncuran Foresight GC2 di Swing Catalyst, silakan kirimkan tiket melalui pusat bantuan kami.

Contoh tangkapan layar yang menunjukkan perangkat terhubung ke komputer tetapi belum sepenuhnya diaktifkan, pastikan untuk memilih perangkat:

Koneksi Simulator Foresight

  1. Pastikan Anda menerima data di Simulator Foresight.

  2. Coba tutup Swing Catalyst, lalu mulai Simulator Foresight terlebih dahulu, kemudian mulai Swing Catalyst.

  3. Pastikan Anda menggunakan mode Club Fitting di simulator Foresight, dan bahwa Shots.CSV diaktifkan di Pengaturan.

  4. Pastikan Anda telah mengaktifkan “Use as trigger” di pengaturan Swing Catalyst.

Dukungan Foresight: http://www.foresightsports.com/support/faqs
