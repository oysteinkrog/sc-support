Cara menggunakan sensor BodiTrak dengan Swing Catalyst

Pendahuluan

Artikel dukungan ini akan menjelaskan cara melakukan Setup dan mengonfigurasi pelat sensor BodiTrak 2 Vector dengan Swing Catalyst. Secara teknis, artikel ini juga dapat digunakan untuk model BodiTrak 16x25 & 16x27 (model BT) yang lebih lama.

Persyaratan

  • Komputer dengan port USB yang tersedia.

  • Swing Catalyst 9.7 atau lebih baru dengan dukungan Pelat Sensor

  • Salah satu model yang tercantum di bawah ini dalam matriks sensor yang didukung.

  • Windows 10, atau 11 64-bit (x64) (Catatan: kami tidak mendukung arsitektur ARM atau x86).

Sensor apa saja yang didukung?

Kami mendukung model-model berikut. Perlu diperhatikan bahwa beberapa model ini sudah tidak diproduksi lagi. Kami tidak mendukung semua sensor BodiTrak per tahun 2024.

Model / Nomor Model Baris x Kolom Dimensi (Lebar x Tinggi) cm

BT7150 16x25 71 x 45.5

BT(Prototipe?) 16x27 75.6 x 44.8

BT2-1632-500 16x32 94 x 47

BT2-1625-500 16x25 73 x 47

BT2-1625-500 16x25 71 x 45.5

Untuk kebutuhan Kalibrasi Pelat, silakan hubungi dukungan BodiTrak.

Instalasi Driver

Instalasi Driver dilakukan secara otomatis oleh Windows.

Jika Anda memiliki sistem baru tanpa perangkat lunak BodiTrak yang terpasang dan sensor tidak terdeteksi atau tidak dikenali, silakan hubungi dukungan BodiTrak.

Kemungkinan sumber masalah:

  • Kabel USB.

  • Koneksi ke PC.

Lihat bagian pemecahan masalah kami untuk tips lebih lanjut.

Konfigurasi

Langkah-langkah ini tidak sepenuhnya wajib, tetapi membantu memverifikasi bahwa sensor terdeteksi dan berfungsi dengan baik di Swing Catalyst.

Mulai Swing Catalyst dan buka Settings -> Hardware.

  • Pelat akan terdeteksi secara otomatis (jika tidak terdeteksi otomatis, coba pilih BodiTrak 2 Vector dari menu dropdown).

  • Pastikan sudah diaktifkan (jika tidak, integrasi tidak akan berfungsi).

Untuk membuka dialog konfigurasi sensor, klik “Configure…”.

Catatan: Jika Anda tidak dapat terhubung ke sensor atau menerima pesan kesalahan, lihat bagian Pemecahan Masalah kami

Pengaturan Pelat Sensor

Anda dapat melihat data secara langsung, menerapkan Rotasi, serta melihat informasi sensor tambahan seperti nomor seri dari jendela Pengaturan Pelat Sensor.

Titik putih besar di tengah menunjukkan Pusat Tekanan (CoP), yang merupakan pengukuran Keseimbangan tubuh Anda.

Jika Anda dalam posisi seimbang, CoP akan berada di tengah antara kedua Kaki. Saat condong ke depan atau ke belakang, CoP akan bergeser ke depan atau ke belakang. Menggeser berat badan ke kiri atau ke kanan akan memindahkan CoP ke kiri atau ke kanan.

Dua titik lebih kecil di bawah setiap jejak Kaki adalah CoP per Kaki, yang menunjukkan pusat Tekanan di area Kaki untuk masing-masing Kaki. Garis penghubung di antara keduanya menunjukkan bidang tempat Anda berdiri.

Rotasi (Cara memutar, mencerminkan, atau membalik Data Tekanan)

Rotasi pelat dapat dilakukan dengan mengklik tombol “Rotate Stance Data”. Mengklik tombol ini memungkinkan Rotasi data sebesar 180 derajat. Untuk pengaturan yang lebih lanjut, lihat Advanced.

Pengaturan Rotasi lanjutan dapat diakses dengan mengklik Advanced:

Untuk membalik data secara Vertikal, Anda dapat mengklik flip.

Pemecahan Masalah

Harap diperhatikan:

Untuk segala dukungan, perbaikan, atau permintaan pengembalian, silakan hubungi BodiTrak.

Bagian pemecahan masalah ini dimaksudkan sebagai panduan untuk mengidentifikasi dan memperbaiki masalah yang mungkin Anda temui saat menggunakan sensor dengan Swing Catalyst.

Data tampak terbalik meskipun matras sudah diposisikan dengan benar

  • Anda dapat membalik data secara Vertikal di Pengaturan Pelat Sensor, silakan lihat Rotasi.

Sensor BodiTrak tidak dikenali atau tidak terdeteksi sebagai terhubung:

Jika perangkat lunak BodiTrak sedang berjalan, hal tersebut dapat menghalangi akses ke sensor. Demikian pula, BodiTrak DataPort adalah layanan yang mungkin berjalan di sistem Anda dan mencegah Swing Catalyst terhubung ke sensor.

  • Pastikan tidak ada perangkat lunak BodiTrak yang sedang berjalan.

  • Hentikan Layanan BodiTrak DataPort.

Untuk menghentikan layanan, klik tombol menu mulai Windows dan ketik Services, klik aplikasi Services & cari BodiTrak Data Port, klik kanan dan pilih Stop

Untuk menghentikan layanan, tekan ikon Windows pada menu mulai Windows lalu ketik Services.

Buka aplikasi Services dan temukan BodiTrak DataPort, klik kanan dan klik Stop.

Menghentikan layanan ini kemungkinan akan menyebabkan aplikasi lain yang menggunakan BodiTrak tidak dapat berfungsi, tetapi akan memungkinkan Swing Catalyst terhubung ke sensor.

Jika BodiTrak DataPort tidak terpasang, silakan lanjutkan dengan langkah-langkah pemecahan masalah di bawah ini.

  • Buka Windows device manager. Caranya?

Verifikasi bahwa perangkat BodiTrak ada di bawah USB Serial Devices. **

  • Jika tidak ada, atau memiliki simbol peringatan, coba sambungkan kembali perangkat ke port USB yang berbeda.

  • Sambungkan perangkat ke port USB lain di komputer.

  • Jika menggunakan eksterder USB, coba sambungkan perangkat langsung ke PC tanpa eksterder.

  • Mulai ulang Swing Catalyst.

  • Mulai ulang komputer.

  • Jika Anda telah mencoba semua langkah ini dan perangkat berfungsi dengan perangkat lunak BodiTrak tetapi tidak di Swing Catalyst, Anda dapat menghubungi tim dukungan kami.

Gangguan pada matras sensor / Kalibrasi

  • Dengan penggunaan yang intensif, sensor mungkin perlu di-Kalibrasi ulang, silakan hubungi dukungan BodiTrak.

  • Mungkin ada kotoran di bawah sensor atau di antara sensor dan penutup matras bagian atas, pastikan sensor bebas dari kotoran.

  • Periksa bagian bawah sensor apakah ada kotoran yang menekan bagian bawah matras.

Jejak kaki yang lemah

Dalam kasus jejak Kaki yang lemah, hal ini mungkin berkaitan dengan Kalibrasi sensor dalam cara nilai Tekanan rendah ditangani. Bisa jadi sensor dikalibrasi dengan salah atau perlu di-Kalibrasi ulang.

Swing Catalyst tidak melakukan Penyaringan tambahan apa pun terhadap data yang kami terima dari sensor BodiTrak. Namun, jika jejak Kaki berbeda di Swing Catalyst dibandingkan dengan program lain yang menggunakan matras BodiTrak Anda, jangan ragu untuk membuat tiket dukungan melalui pusat bantuan kami dan kami akan mencoba untuk menyelidikinya.
