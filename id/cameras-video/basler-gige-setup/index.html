Cara mengatur kamera Basler GigE dengan Swing Catalyst

Artikel dukungan ini membahas Setup dan konfigurasi kamera Basler dengan Swing Catalyst.

note: Untuk menggunakan kamera Basler dengan Swing Catalyst, Anda memerlukan dongle USB Halcon dan lisensi. Silakan hubungi contact@swingcatalyst.com untuk membeli lisensi.

Instruksi instalasi & konfigurasi Halcon ada di sini:

halcon-setup.md

Penting:

Pastikan Anda telah menginstal Filter driver MVTec Halcon; kamera tidak akan berfungsi dengan baik tanpanya. Juga pastikan untuk menghapus centang pada Filter driver lain yang terpasang, misalnya Filter driver Basler.

Pastikan SwingCatalyst diizinkan di jaringan privat & publik pada firewall Windows Defender.

example:

Mengatur IP kamera

Setup IP

Setiap kamera dan kartu Ethernet (NIC / Network interface controller) harus dikonfigurasi dengan IP statis pada subnet yang berbeda (dan subnet mask).

note: IP NIC adalah alamat IP adaptor jaringan pada komputer Anda dan IP kamera adalah alamat IP kamera. Tanda … menunjukkan sebuah Jangkauan, karena ini adalah contoh IP yang dapat Anda atur.

Contoh untuk Setup kamera tunggal atau multi-kamera (dengan satu atau lebih kartu / adaptor jaringan):

Kamera pada adaptor jaringan 1:
nic ip: 10.0.1.1
cam ip: 10.0.1.10 ... 10.0.1.20
subnet mask:255.255.255.0

Kamera pada adaptor jaringan 2:
nic ip: 10.0.2.1
cam ip: 10.0.2.10 ... 10.0.2.20
subnet mask: 255.255.255.0

Kamera pada adaptor jaringan 3:
nic ip: 10.0.3.1
cam ip: 10.0.3.10 ... 10.0.3.20
subnet mask: 255.255.255.0

Kamera pada adaptor jaringan 4:
nic ip: 10.0.4.1
cam ip: 10.0.4.10 ... 10.0.4.20
subnet mask: 255.255.255.0

Pertama kita perlu mengatur IP kamera, ini dilakukan melalui Pylon IP Configurator.

Tekan tombol menu mulai pada keyboard Anda dan ketik pylon ip, maka IP Configurator akan muncul. Jika tidak muncul, kemungkinan perangkat lunak tersebut belum terinstal.

Untuk menginstal perangkat lunak Pylon, lihat: https://www.baslerweb.com/en/sales-support/downloads/software-downloads/ dan cari: pylon 5.1.0 Camera Software Suite Windows.

Klik pada kamera lalu pilih Static IP

Atur alamat IP kamera dan subnet mask sesuai contoh di atas.

Mengonfigurasi kamera Basler GigE melalui Halcon

Di SwingCatalyst, navigasikan ke tab Pengaturan lalu ke Kamera.

Klik pada Advanced.

  • Navigasikan ke tab Configuration.

  • Aktifkan kotak centang GtlNumBuffers dan masukkan 200 sebagai nilainya.

Mengatur kamera Basler GigE:

Mari kita lihat cara mengatur eksposur, kecepatan rana, dan Laju Frame.

note: Jika Anda tidak dapat melihat pengaturan & mendapatkan kesalahan di SwingCatalyst, periksa pengaturan Windows Firewall. Coba matikan firewall untuk memeriksa apakah firewall memblokir akses SwingCatalyst ke kamera.

Jika pengaturan berfungsi & Anda dapat melakukan streaming dengan baik, pastikan SwingCatalyst diizinkan di jaringan publik & privat pada firewall Windows Defender.

Perluas tab AcquisitionTrigger dan masukkan Laju Frame maksimum (atau lebih rendah), lalu klik Enable Acquisition Frame Rate. Ini akan memungkinkan Anda menentukan Laju Frame. Catatan: Laju Frame dapat dibatasi oleh nilai eksposur.

Mengatur nilai eksposur

Biasanya lebih baik menggunakan eksposur manual untuk lingkungan yang statis, seperti studio dalam ruangan. Eksposur Auto penuh dapat menyebabkan Laju Frame berubah dan menghasilkan gambar yang tidak konsisten. Dalam hal ini kita tidak menggunakan eksposur Auto karena kita ingin bisa mengontrolnya sendiri. Umumnya waktu eksposur kurang dari 2000 (2ms) direkomendasikan.

Mengatur nilai Gain

Sama seperti eksposur, mengatur Gain ke manual untuk kondisi pencahayaan statis / dalam ruangan adalah yang terbaik. Semakin tinggi eksposur, gambar akan semakin berbintik dan encoding video akan memakan waktu lebih lama dibandingkan Gain rendah.

Untuk mengatur Gain manual, ubah Gain Auto dari Continuous ke Off, lalu Jeda dan putar Pemutaran untuk memuat ulang pengaturan. Atur nilai Gain dengan mengubah nilai angka pada Gain (Raw).

Mengubah ukuran gambar, area of interest, Region of Interest & lainnya

Dalam beberapa kasus Anda ingin memperkecil ukuran gambar untuk fokus pada area tertentu dari gambar video, misalnya untuk melihat stik dan bola pada saat Dampak secara detail.

Hal ini dapat dilakukan dengan area of interest, yang juga dikenal sebagai AOI, dan ROI, Region of Interest. Mengurangi ukuran gambar secara keseluruhan dengan fungsi ini juga dapat meningkatkan Laju Frame.

Menyimpan pengaturan ke kamera

Penting untuk menyimpan pengaturan ke kamera. Jika tidak dilakukan, semua yang telah Anda konfigurasi akan hilang.

Pastikan Anda mengatur Default Set Selector & Default Startup Set. Ada berbagai user set yang dapat dipilih dan pada dasarnya Anda dapat menyimpan pengaturan yang berbeda pada setiap set. Misalnya Anda dapat memilih “User Set 1” sebagai default, lalu tekan User Set Save untuk menyimpan pengaturan saat ini ke profil tersebut.
