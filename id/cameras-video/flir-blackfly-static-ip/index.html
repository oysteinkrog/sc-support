Cara mengatur IP statis pada kamera FLIR Blackfly GigE

Pendahuluan

Artikel dukungan ini menjelaskan cara mengonfigurasi kamera FLIR Blackfly (atau Blackfly S) GigE dengan alamat IP statis. Untuk penggunaan normal, hal ini tidak diperlukan karena SwingCatalyst menangani konfigurasi IP secara otomatis.

Persyaratan

  • Aplikasi Spinview (bagian dari Spinnaker SDK).

  • SwingCatalyst.

  • Satu atau lebih kamera FLIR Blackfly (atau Blackfly S) GigE.

Menginstal Spinnaker

  • Unduh dan jalankan penginstal Spinnaker.

  • Klik kanan penginstal Spinnaker & jalankan sebagai administrator.

  • Centang “Camera Evaluation” dan klik Next

  • Ikuti petunjuk di layar untuk melanjutkan proses instalasi.

  • Setelah selesai, restart komputer.

Mengatur IP statis pada Adaptor Ethernet

Setiap kamera dan adaptor jaringan harus memiliki alamat IP statis yang unik. Misalnya, jika Anda menetapkan alamat IP statis pada kamera, pastikan adaptor jaringan dikonfigurasi dengan IP yang sesuai dari matriks “konfigurasi IP statis yang direkomendasikan” di bawah ini.

Peringatan

Konfigurasikan adaptor jaringan berdasarkan kamera yang terhubung, bukan nomor adaptor. Ubah pengaturan hanya untuk kamera yang teridentifikasi; biarkan yang lain tidak berubah. Jika Anda menghubungkan kamera ke adaptor yang berbeda, diperlukan konfigurasi ulang agar berfungsi dengan benar.

Dari Control Panel, buka “Network and Internet”, lalu ke “Network and Sharing Center”, kemudian klik “Change adapter settings”.

Di sini kita dapat melihat daftar adaptor jaringan yang ada di komputer. Dalam kasus ini, kita ingin mengonfigurasi Ethernet 2 dan Ethernet 3, dengan nama perangkat “Intel Pro/1000”. Penting untuk hanya mengonfigurasi adaptor jaringan yang digunakan untuk kamera dan bukan yang lainnya, karena hal itu dapat memengaruhi konektivitas internet.

Klik kanan pada adaptor jaringan yang ingin Anda ubah dan klik “Properties”, lalu gulir ke bawah ke “Internet Protocol Version 4 (TCP/IPv4) dan klik “Properties”.

  • Pilih “Use the following IP address”.

  • Masukkan alamat IP dari matriks konfigurasi IP statis yang direkomendasikan di bawah ini.

  • Masukkan subnet mask 255.255.255.0

  • Pilih “Use the following DNS server addresses”, Anda dapat membiarkan kolom ini kosong.

  • Klik “OK”.

Gateway dapat diatur pada kedua kamera

Mengatur IP statis pada kamera

Ulangi langkah-langkah ini untuk kamera lain yang ingin Anda atur IP statisnya. Untuk mengakses konfigurasi IP kamera, buka aplikasi SpinView dan klik kanan pada kamera yang ingin Anda konfigurasikan IP-nya.

  • Klik kanan pada kamera di daftar Devices dan pilih “GigE Configuration”.

  • Klik “IP Configuration”.

Masukkan IP & subnet mask sesuai dengan matriks konfigurasi IP yang direkomendasikan di bawah ini.

  • Masukkan alamat IP kamera, gunakan alamat IP dari matriks, misalnya untuk kamera 1

  • Masukkan subnet mask, contoh: 255.255.255.0.

  • Default gateway dapat dibiarkan kosong, atau gunakan alamat IP adaptor jaringan tempat kamera terhubung.

  • Hapus centang DHCP.

  • Klik “Set Current and Persistent IP Configuration”.

Konfigurasi IP statis yang direkomendasikan untuk kamera

No. Kamera IP Subnet Mask Gateway
1 10.0.1.10 255.255.255.0 10.0.1.1
2 10.0.2.10 255.255.255.0 10.0.2.1
3 10.0.3.10 255.255.255.0 10.0.3.1
4 10.0.4.10 255.255.255.0 10.0.4.1

IP gateway adalah alamat IP adaptor jaringan tempat kamera terhubung.

Misalnya, Kamera 1 terhubung ke adaptor jaringan 1.

Menggunakan SpinView untuk mengaktifkan jumbo frame & mengoptimalkan adaptor jaringan untuk kamera

Perlu diperhatikan bahwa perubahan ini harus dilakukan pada semua adaptor jaringan yang terhubung ke kamera Anda.

  • Dari SpinView, klik kanan pada kamera dan pilih “GigE Configuration”.

  • Klik “Configure Adapter Properties”.

  • Klik Yes saat diminta konfirmasi.

  • Klik “Next”.

  • Klik “Auto Fill All”.

  • Klik “Next”.

  • Centang “Enable Media Optimization”.

  • Klik “Next”.

  • Klik “Configure” untuk menerapkan perubahan.
