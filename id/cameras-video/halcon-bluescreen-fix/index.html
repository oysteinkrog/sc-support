Komputer Bluescreen saat menghubungkan dongle lisensi USB Halcon

Ada masalah dengan Driver USB untuk dongle lisensi yang digunakan oleh pelanggan Halcon. Dongle ini adalah dongle USB “Flexera” berwarna hijau.

Driver yang disertakan dengan Halcon 12 menyebabkan Windows crash dan bluescreen.

Untuk menghindari bluescreen, kami menyarankan untuk menghapus Driver lama jika sudah terpasang, baik dengan menguninstall Halcon maupun dengan menghapus Driver secara manual.

Berlaku untuk:

  • Windows 10 Versi 2004 Build >= 19041.423, 20H2, 21H1, atau 21H2

  • Windows 11.

Kami menyarankan untuk menguninstall Halcon terlebih dahulu, kemudian ikuti petunjuk cara menginstal Driver baru dalam artikel dukungan ini.

Menguninstall Halcon

  • Buka Tambah atau Hapus Program.

  • Di bawah Aplikasi & fitur, cari “halcon”.

  • Klik entri yang muncul di daftar dan klik “Uninstall” serta “Uninstall”

  • Klik “Yes” untuk melanjutkan penghapusan Halcon, tunggu hingga uninstaller Halcon mulai berjalan, lalu klik “Uninstall” untuk menghapus Halcon.

Opsi Alternatif: Menghapus Driver dongle USB Halcon secara manual

Opsi ini dapat digunakan jika Anda tidak ingin me-restart komputer atau karena alasan tertentu tidak ingin menginstal ulang Halcon. Untuk sebagian besar keperluan, sebaiknya ikuti opsi “Menguninstall Halcon” sebagai gantinya.

Ketika sebuah Driver diinstal, Driver tersebut disimpan di repositori file DriverStore Windows, yang terletak di:

C:\Windows\System32\DriverStore\FileRepository

Biasanya untuk menghapus Driver, Anda akan membuka Device Manager dan menguninstall perangkat serta memilih untuk menghapus Driver tersebut, tetapi karena menancapkan dongle USB menyebabkan Windows crash, kita perlu menghapusnya secara manual. Windows akan menemukan Driver yang sesuai (baru) setelah kita menginstal Driver baru.

Cara menghapus Driver perangkat menggunakan pnputil

Petunjuk di bawah ini menggunakan “tanda kutip” di sekitar teks yang harus diketik ke dalam baris perintah tanpa tanda kutip.

  • Buka Command Prompt.

  • Di Command Prompt, ketik “pnputil -e” untuk menampilkan semua Driver yang terinstal.

  • Cari Driver di awal output yang memiliki nama paket yang mengandung Sentinel HASP atau SafeNet.

  • Hapus masing-masing Driver tersebut dengan menjalankan “pnputil /delete-driver drivername.inf /uninstall”

  • Contoh untuk menghapus Driver dengan nama penerbit oem53.inf, ketik: “pnputil /delete-driver oem53.inf /uninstall” lalu tekan enter.

Harap diperhatikan bahwa output dari pnputil dalam kasus ini berasal dari sistem yang berfungsi normal dan sudah memiliki Driver yang diperbarui (tangkapan layar Driver lama tidak tersedia).

Untuk sistem yang bermasalah, seharusnya akan menampilkan Driver serupa namun dengan penyedia paket Driver yang berbeda

Menginstal Driver dongle lisensi USB Halcon yang baru

Petunjuk di bawah ini menggunakan “tanda kutip” di sekitar teks yang harus diketik ke dalam baris perintah tanpa tanda kutip.

  • Unduh dan ekstrak Driver baru, klik kanan pada file zip yang telah diunduh dan klik “Extract All” & “Extract”.

  • Buka Command Prompt (jika sebelumnya sudah ditutup)

  • Salin lokasi folder Driver yang telah diekstrak, misalnya C:\Users\stian\Downloads\haspdinst_8.53

  • Di Command Prompt, ketik “cd” dan tempelkan lokasi Driver yang telah diekstrak, misalnya “cd C:\Users\stian\Downloads\haspdinst_8.53”

  • Ketik “haspdinst.exe /install” ke dalam Command Prompt lalu tekan enter.

  • Proses instalasi akan berjalan.
