캘리브레이션 유틸리티 실행하기

밸런스 플레이트를 사용하려면 캘리브레이션 파일이 필요합니다. 캘리브레이션 파일은 각 밸런스 플레이트마다 개별적으로 생성되므로 동일한 파일은 존재하지 않습니다. 캘리브레이션 파일이 설치되어 있지 않다면, 플레이트가 보증 목적으로 등록되지 않았을 가능성도 있습니다. 이 문서에서는 캘리브레이션 파일을 획득하고 플레이트를 등록하는 과정을 안내합니다.

이 문서는 밸런스 플레이트 3 이상 버전에서 원치 않는 노이즈를 제거하고 압력 분포를 개선하기 위한 내용입니다.

밸런스 플레이트는 2048개의 고정밀 압력 센서로 구성되어 있으며, 최상의 정확도를 보장하기 위해 Sensor Edge 유틸리티를 사용하여 플레이트를 영점 조정해야 할 수 있습니다. 이 문서는 밸런스 플레이트의 영점 설정 방법을 단계별로 안내하는 튜토리얼입니다.

중요!** **

이 과정은 두 부분으로 구성되어 있습니다.

1부. Sensor Edge 유틸리티를 사용하여 플레이트에 맞는 최신 캘리브레이션 파일을 획득합니다.

2부. 해당 캘리브레이션 파일을 Swing Catalyst에 설치합니다. 이 지원 문서 전체를 반드시 읽어주시기 바랍니다.

1부: SE 유틸리티를 사용하여 캘리브레이션 파일 획득하기

  • 캘리브레이션 유틸리티 다운로드

  • 드라이버 설치 여부를 묻는 창이 나타나면 예를 클릭합니다.

플레이트를 컴퓨터에 연결합니다.

  • Swing Catalyst 소프트웨어가 닫혀 있는지 확인하십시오. Swing Catalyst가 실행 중이면 SE 유틸리티가 플레이트를 감지하지 못합니다.

  • 새로 설치된 SE 유틸리티를 엽니다.

  • 아래 지침을 따르십시오.

  • 밸런스 플레이트 위에 서 있을 때 화면을 볼 수 있도록 모니터나 TV가 컴퓨터에 연결되어 있는지 확인하십시오.

이전 버전이 설치되어 있다면 프로그램 추가/제거를 통해 먼저 제거해 주십시오.

시작을 클릭합니다:

시작을 클릭하면 자동으로 장치 검색을 시도합니다. 플레이트를 찾지 못하는 경우 드롭다운 메뉴를 클릭하여 밸런스 플레이트를 선택하십시오.

Scan 클릭

플레이트의 시리얼 번호와 일치하는 장치를 선택하고 Next를 클릭합니다.

밸런스 플레이트 등록하기

등록 정보 입력 예시

보증 및 서비스 목적에 필요한 정보를 모두 입력한 후 Continue를 클릭합니다.

가능하다면 카메라를 선택하여 밸런스 플레이트가 보이도록 방향을 맞추고 Next를 클릭합니다.

카메라는 필수가 아니며, 카메라가 감지되지 않아도 계속 진행할 수 있습니다.

밸런스 플레이트에서 카펫 및 기타 물건을 반드시 제거하십시오. 이는 외부 요인이 측정값에 영향을 미치지 않도록 하기 위함입니다.

캘리브레이션 프로세스 실행

플레이트에 올라서기 전, 유틸리티는 비교 기준이 될 기준선 데이터를 수집합니다.

유틸리티가 지시하기 전까지 실수로 플레이트 위에 올라서지 않도록 주의하십시오.

위치 잡기

유틸리티에 표시된 대로 플레이트 위에 서는 것이 중요합니다.

어두운 발 모양은 현재 서야 할 위치를 나타내고, 회색 발 모양은 다음에 서야 할 위치를 나타냅니다.

플레이트의 모든 영역을 활성화하는 것이 중요하므로 각 단계를 따라주십시오.

녹화 완료

녹화 결과가 만족스럽지 않거나 실수를 한 경우, restart를 클릭하여 쉽게 처음부터 다시 시작할 수 있습니다.

계속 진행하려면 Continue를 클릭합니다.

Save 버튼을 클릭한 후 Send 버튼을 클릭합니다.

데이터가 제조사의 검토를 위해 전송되기 전에 대략적인 체중과 사용 빈도를 입력합니다.

notes 항목에는 왼발이 약하다거나 기타 문제 등 플레이트와 관련하여 겪고 있는 문제를 기재할 수 있습니다.

제조사가 이 데이터를 수집하는 이유는 재캘리브레이션 알고리즘을 지속적으로 개선하여 더욱 정확한 센서 측정값을 제공하기 위함입니다.

정보를 입력하고 send를 클릭합니다:

완료되면 캘리브레이션 파일이 문서 폴더에 저장됩니다. “No"를 누른 후 유틸리티를 닫습니다.

2부: 캘리브레이션 파일 설치하기

다음 단계를 계속 진행합니다

  • Swing Catalyst를 시작하고 메인 메뉴에서 Settings –> Hardware로 이동합니다.

플레이트는 자동으로 감지됩니다. 감지되지 않는 경우 문제 해결 섹션을 참조하십시오.

“Configure…” 버튼을 클릭하여 구성 대화 상자를 엽니다.

센서 플레이트 설정

Stance Sensor 탭으로 이동하여 Browse and Install을 클릭합니다.

캘리브레이션 파일을 저장한 디렉터리(예: C:\User\YourUsername\Documents)로 이동하여 유틸리티에서 저장한 mxd 파일을 선택하고 Open을 클릭합니다.

설치가 완료되면 완료 메시지가 표시되며 OK를 클릭하여 창을 닫을 수 있습니다.

이제 밸런스 플레이트를 사용할 준비가 되었습니다. Swing Analysis에서 새 세션을 시작하고 스윙을 캡처할 때 압력 및 자세 데이터 박스에 압력 측정값이 표시되는지 확인합니다.

참고: 밸런스 플레이트를 많이 사용한 경우 재캘리브레이션이 필요할 수 있으며, Swing Catalyst 설정에서 diagnostics 버튼을 클릭하면 SE 유틸리티가 실행되어 재캘리브레이션을 진행할 수 있습니다.

문제 해결

밸런스 플레이트가 인식되지 않거나 연결된 것으로 표시되지 않는 경우:

  • 장치가 Windows에서 인식되는지 확인합니다.

Windows 장치 관리자를 엽니다. 방법 보기

  • 포트(COM 및 LPT) 항목 아래에 Sensor Edge 장치가 있는지 확인합니다.

  • 장치가 없거나 경고 기호가 표시되면 드라이버를 재설치하고 장치를 다른 USB 포트에 다시 연결해 보십시오.

  • 장치를 컴퓨터의 다른 USB 포트에 연결합니다.

  • USB 연장선을 사용 중인 경우, 연장선 없이 PC에 직접 연결해 보십시오.

  • Swing Catalyst를 재시작합니다.

  • 컴퓨터를 재시작합니다.

  • 위의 모든 단계를 시도했는데도 Swing Catalyst에서 연결되지 않은 것으로 표시되면 지원팀에 문의하십시오.

캘리브레이션이 성공적으로 설치되지 않는 경우

  • Sensor Edge 유틸리티에서 받은 캘리브레이션 파일이 손상되었거나 문제가 있을 수 있습니다. 유틸리티를 다시 실행하여 새 캘리브레이션 파일을 설치해 보십시오. 그래도 해결되지 않으면 지원팀에 문의하십시오.

유틸리티를 실행했는데도 플레이트에 노이즈가 있는 경우

노이즈는 다음과 같은 여러 요인으로 인해 발생할 수 있습니다:

  • Swing Catalyst에 잘못된 캘리브레이션 파일이 설치되어 있거나 설치되지 않은 경우.

  • 과도한 사용: 캘리브레이션 유틸리티는 자주 실행해야 하며, 사용 빈도가 높은 플레이트의 경우 월 1회 이상 실행하는 것을 권장합니다.

  • 직사광선에 노출되는 경우.

  • 센서 자체의 마모.

신호 대 잡음비가 충분하지 않으면 유틸리티가 노이즈를 필터링하지 못할 수 있으며, 이 경우 플레이트는 RMA를 통해 재캘리브레이션이 필요합니다. 제조사는 유틸리티에서 생성된 세션을 수동으로 검토하여 개선 가능 여부를 확인합니다.

제조사가 문제를 해결하지 못하고 플레이트가 보증 기간 내에 있거나 ESA(연장 서비스 계약)에 해당하는 경우, RMA가 있는 한 플레이트를 제조사로 반송할 수 있습니다.

하드웨어 비호환성

AMD 300 시리즈 칩셋(AMD Ryzen 1700 / 2700 시리즈)과 USB 1.1 장치 간에 일부 문제가 확인되었습니다. 특히 밸런스 플레이트의 경우, 초당 약 145 샘플 대신 75 샘플만 수신되는 문제가 발생할 수 있습니다. USB 2.0 허브를 사용하면 밸런스 플레이트가 전체 샘플 레이트로 스트리밍될 수 있으므로 사용을 권장합니다.

AMD 300 시리즈 칩셋을 USB 3.0 장치와 함께 사용하는 경우에는 알려진 문제가 없습니다.
