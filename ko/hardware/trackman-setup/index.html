TrackMan을 Swing Catalyst와 함께 사용하는 방법

이 문서는 Swing Catalyst를 TrackMan에 연결하고 런치 모니터 데이터를 영상과 함께 저장하는 방법을 설명합니다. 통합 기능을 활성화하려면 Swing Catalyst와 동시에 TrackMan 소프트웨어가 실행 중이어야 합니다.

note: TrackMan을 Swing Catalyst와 함께 사용하려면 스트리밍 영상을 지원하는 카메라가 필요합니다. (지원되는 카메라 참조)

설치: TrackMan Pro/Launch 4.0.9

  • TrackMan 장치를 PC에 연결합니다.

  • TrackMan Pro 또는 TrackMan Launch를 시작하고 샷 추적 화면으로 이동합니다.

  • Swing Catalyst를 시작하고 시작 메뉴에서 설정 - 하드웨어로 이동합니다.

  • Launch Monitor 통합을 활성화합니다.

  • TrackMan을 선택합니다.

설치: TrackMan Performance Studio

지원 버전: 2.2-4.0

  • TrackMan 장치를 PC에 연결합니다.

  • TrackMan Performance Studio를 시작합니다.

  • 시작 메뉴에서 셋업 화면으로 이동합니다. (그림 1: 톱니바퀴 아이콘)

  • SDK Output을 활성화합니다. (그림 2)

  • 시작으로 이동하여 샷 분석을 클릭합니다.

  • Swing Catalyst를 시작하고 시작 메뉴에서 설정 - 하드웨어로 이동합니다.

  • Launch Monitor 통합을 활성화합니다.

  • TrackMan을 선택합니다.

설치: TM3e 또는 TrackMan 4가 포함된 TPS

  • TrackMan 3e 장치의 전원을 켭니다.

  • Windows에서 TrackMan WiFi 네트워크에 연결합니다. 또는 USB 케이블을 연결합니다.

  • 1단계를 제외하고 위의 설치 가이드와 동일한 단계를 따릅니다.

그림 1: TrackMan Performance Studio에서 SDK Output 활성화.

TrackMan Pro/Launch/Performance Studio와 함께 Swing Catalyst 사용하기

  • TrackMan 소프트웨어를 먼저 시작하고 샷 추적 화면으로 이동합니다.

  • Swing Catalyst를 시작하고 스윙을 캡처합니다.

  • 녹화된 스윙을 열면 영상 옆의 데이터 박스에서 샷 데이터를 확인할 수 있습니다.

모든 설치가 올바르게 완료되었다면 TrackMan 샷 데이터가 자동으로 캡처되어 영상과 함께 저장됩니다.

카메라 구성

일부 경우에는 TPS 소프트웨어가 시스템의 카메라를 잠글 수 있어 Swing Catalyst 소프트웨어에서 해당 카메라를 사용할 수 없게 됩니다.

향후 버전의 TPS 소프트웨어에서는 이 동작을 비활성화하는 구성 옵션이 도입될 수 있지만, 현재로서는 TrackMan이 다음과 같은 임시 해결 방법을 제공하고 있습니다:

TPS 소프트웨어를 열고 카메라 목록에 표시되는 카메라의 정확한 이름을 확인합니다.

다음 파일을 찾아 메모장에서 엽니다:

C:\ProgramData\TrackMan\VideoManagement\ExcludeCameras.TMConfig

파일에 카메라 이름을 추가합니다. 카메라가 여러 대인 경우 각 이름을 별도의 줄에 추가합니다.

문제 해결

  • TPS에서 TrackMan이 인식되고 연결되었는지 확인합니다.

  • Swing Catalyst 하드웨어 설정 메뉴에서 Launch Monitor가 활성화되어 있고 TrackMan이 선택되어 있는지 확인합니다.

  • Swing Catalyst의 런치 모니터 설정 아래에서 “트리거"가 체크되어 있는지 확인합니다.

  • 여전히 트리거가 작동하지 않으면 TPS의 설정을 확인하고 “SDK Output"이 활성화되어 있는지 확인합니다.

  • TrackMan 장치를 재시작해 봅니다.

  • 데이터가 수신되고 Swing Catalyst에서 연결된 것으로 표시되지만 트리거가 작동하지 않는 경우 컴퓨터를 재시작해 봅니다.

  • 트리거가 작동하지만 매우 늦게 반응하는 경우: Launch Monitor 설정에서 지연 보정을 조정해 보세요. 약 1500ms의 값이 권장됩니다. 이 값은 공의 종류와 레이더를 실내 또는 실외에서 사용하는지 여부에 따라 달라집니다.

Swing Catalyst에서 데이터가 여전히 수신되지 않는 경우:

  • TrackMan 장치를 재시작하고 SDK Output이 활성화되어 있는지 다시 확인합니다.

  • Windows 방화벽을 비활성화해 보세요. 이 방법이 효과가 있다면 TPS와 Swing Catalyst에 대한 예외를 추가합니다.

  • TrackMan OEM 서비스가 실행 중인지 확인합니다. 실행 중이라면 비활성화한 후 다시 시도합니다. Windows 서비스에 대한 자세한 내용은 여기를 참조하세요: http://www.7tutorials.com/what-are-windows-services-what-they-do-how-manage-

고급 문제 해결 단계를 확인하세요.
