FlightScope와 Swing Catalyst 함께 사용하는 방법

소개

이 지원 문서는 FlightScope Launch Monitor를 Swing Catalyst와 함께 사용하는 방법을 설명합니다. Swing Catalyst는 새로운 테이크를 녹화할 때 모든 FlightScope 데이터를 통합하고 저장합니다. 통합을 활성화하려면 Swing Catalyst와 동시에 FlightScope 소프트웨어가 실행 중이어야 합니다.

적용 대상

  • FlightScope Launch Monitor를 사용하는 사용자.

지원 모델:

  • X1, X2, X2 elite & X3 시리즈.

  • Xi & Xi+ 시리즈.

설치

Swing Catalyst가 FlightScope로부터 샷 데이터를 인식하고 읽으려면 FlightScope 소프트웨어에서 서버 모드를 활성화해야 합니다.

  • FlightScope를 시작하고 메인 메뉴에서 “Advanced Settings” 버튼을 클릭합니다. (최신 버전의 FlightScope에서는 키보드의 ALT 키를 누르면 메뉴 바가 표시됩니다.)

  • 화면 오른쪽 하단에 있는 Advanced Settings 버튼을 클릭하면 화면 상단에 메뉴 바가 나타납니다.

  • Networking을 클릭하고 목록에서 Server를 선택합니다.

  • “Server Port"가 1248로 설정되어 있는지 확인하고 Ok를 누릅니다.

참고: 서버 이름과 서버 IP 주소는 USB X2(X2 Elite의 경우 이더넷) 또는 WiFi 연결 여부에 따라 다를 수 있습니다. 이 값을 변경할 필요는 없습니다.

  • FlightScope에서 Player Comparison 또는 유사한 모드로 이동합니다.

  • FlightScope가 샷을 추적하고 표시하고 있는지 확인합니다.

  • Swing Catalyst를 시작하고 FlightScope는 백그라운드에서 계속 실행 상태로 유지합니다.

  • Swing Catalyst 메인 메뉴 - Settings - Hardware로 이동하여 Launch Monitor 아래의 “Enabled"에 체크합니다.

연결이 끊겼다고 표시되면 FlightScope 애플리케이션이 실행 중인지, FlightScope 장치가 PC 또는 WiFi 네트워크에 연결되어 있는지 확인하십시오.

FlightScope에 “Server active, 1 clients"라고 표시되어야 합니다. 이는 Swing Catalyst가 FlightScope에 성공적으로 연결되었음을 의미합니다.

알려진 문제

  • FlightScope 소프트웨어가 실행 중이고 샷을 추적하며 서버 모드가 활성화되어 있음에도 FlightScope가 연결된 것으로 표시되지 않는 경우.

  • FlightScope와 Swing Catalyst를 재시작해 보십시오. FlightScope를 먼저 시작하십시오.

  • 서버 모드를 None으로 설정한 후 다시 켜보십시오. 3단계를 참조하십시오.

  • FlightScope가 잘못된 화면에 표시되는 경우.

  • FlightScope를 다른 화면으로 이동하려면: FlightScope 프로그램을 클릭한 후 마우스 커서를 다른 모니터로 이동합니다. 원하는 화면에 마우스 커서를 둔 상태에서 F11 버튼을 클릭합니다. FlightScope가 해당 화면에서 실행됩니다.
