Foresight GC2 및 HMT Launch Monitor와 Swing Catalyst 함께 사용하는 방법

소개

이 지원 문서에서는 Foresight GC2를 Swing Catalyst와 함께 사용하는 방법을 설명합니다.

Note: GC2와 함께 FSX를 사용하려는 경우 HMT 데이터는 제공되지 않으며, FSX를 먼저 시작한 후 Swing Catalyst를 시작하고 Swing Catalyst 설정에서 FSX Sim을 선택해야 합니다.

Warning

Swing Catalyst 버전 10.1.1부터 Swing Catalyst 실행 시 FSX 2020이 종료되는 문제를 방지하기 위해 GC2 연동 기능이 기본적으로 비활성화됩니다.

GC2를 보유하고 있으며 Swing Catalyst와 계속 함께 사용하려면 설정 파일에서 해당 기능을 활성화해야 합니다(아래 문제 해결 섹션 참조).

요구 사항

  • 여분의 USB 포트 또는 WiFi(인터넷 연결과 별도)가 있는 컴퓨터.

  • 라이브 스트리밍 카메라, 웹 카메라 또는 고속 카메라를 지원하는 라이선스.

  • Swing Catalyst 4.0 이상

중요: 컴퓨터 권장 사양.

Swing Catalyst는 GC2 및 추가 장치인 HMT 모두와 연동됩니다.

Foresight 시뮬레이터 소프트웨어(FR-1, FSX, FSX 2020 등)와 함께 GC2를 사용하려면 Swing Catalyst의 런치 모니터 설정에서 Foresight Simulator를 선택해야 합니다.

Note: Swing Catalyst의 런치 모니터 설정 및 런치 모니터를 캡처 트리거로 사용하는 방법에 익숙하지 않다면, 계속하기 전에 지원 문서를 먼저 확인하시기 바랍니다.

직접 연결(FSX 연동 없음):

이 연결 방법은 FSX를 함께 실행하지 않고도 장치에 직접 연결합니다. HMT 장치가 있는 경우 Swing Catalyst가 클럽 데이터도 수집합니다.

구성 단계

GC2 지원 페이지(드라이버, 펌웨어 및 사용자 매뉴얼)

  • Foresight GC2 설치 가이드(위 링크 참조)를 따르고 GC2 USB 드라이버를 설치하세요. Windows 버전에 맞는 올바른 버전을 선택해야 합니다.

  • GC2가 최신 펌웨어 버전을 사용하고 있는지 확인하세요.

GC2가 꺼진 상태에서 USB 케이블로 GC2를 컴퓨터에 연결한 후 GC2를 켜세요.

  • Swing Catalyst를 시작하고 설정으로 이동합니다(메인 화면에서 왼쪽 하단의 기어 아이콘 클릭). 하드웨어를 선택하세요.

  • Launch Monitor 연동을 활성화합니다. Launch Monitor를 캡처 트리거로 사용하려면 트리거로 활성화 옵션이 체크되어 있는지 확인하세요.

  • Foresight GC2를 선택하세요.

Foresight GC2가 인식되어 연결된 상태를 나타내는 예시 스크린샷:

시뮬레이터 연동

  1. Launch Monitor 선택 목록에서 ForesightSim을 선택하세요. 자동으로 표시되지 않으면 “검색"을 눌러 목록을 업데이트하세요.

  2. Foresight 시뮬레이터를 시작합니다(지원 버전: FSX, FSX 2020, FR-1).

  3. Foresight 시뮬레이터 설정으로 이동하여 “On-Screen Data” 섹션에서 “Write Shots CSV"를 활성화합니다(자세한 내용은 시뮬레이터 사용자 매뉴얼을 참조하거나 Foresight 지원팀에 문의하세요).

Swing Catalyst는 Shots.CSV 파일의 변경 사항을 모니터링하며, 해당 파일을 통해 시뮬레이터의 샷 데이터를 수집합니다.

  1. Club Fitting 모드를 사용하고 있는지 확인하세요(모든 볼 데이터를 제공하는 유일한 모드입니다).

문제 해결

이 섹션에는 Foresight GC2 및 HMT, 그리고 FSX와 함께 GC2를 사용할 때의 문제 해결 단계가 포함되어 있습니다.

소프트웨어를 업데이트한 후 연동이 더 이상 작동하지 않습니다!

Swing Catalyst 버전 10.1.1에서는 Swing Catalyst 실행 중 FSX 2020이 자동으로 종료되는 문제를 방지하기 위해 GC2 연동 기능이 기본적으로 비활성화됩니다. 이는 Foresight가 FSX 문제를 해결할 때까지의 임시 해결 방법입니다.

GC2 연동을 다시 활성화하려면 Swing Catalyst를 종료하고 설정 폴더로 이동하세요:

  • C:\ProgramData\Swing Catalyst\settings

  • “GeneralSettings.xml"을 마우스 오른쪽 버튼으로 클릭하고 메모장으로 열기를 클릭합니다(또는 편집을 클릭).

  • false를 true로 변경하고 문서를 저장합니다.

  • 저장 후 Swing Catalyst를 다시 시작하면 런치 모니터 목록에 GC2가 표시됩니다.

Foresight USB 연결

  • Swing Catalyst 설정에서 Foresight USB가 선택되어 있는지 확인하세요.

  • Foresight GC2 장치의 연결 상태를 확인하고 Foresight 시뮬레이터 소프트웨어가 실행 중이 아닌지 확인하세요.

  • 데이터가 누락되거나 샷이 제대로 감지되지 않는 경우 플래시 모듈 교체가 필요한 것일 수 있습니다. 또는 클럽에 마커가 없거나 마커가 더 이상 제대로 작동하지 않는 것일 수 있습니다.

  • 그래도 Swing Catalyst에서 Foresight GC2 런치 모니터 데이터를 받을 수 없다면 고객 지원 센터를 통해 티켓을 제출하세요.

장치가 컴퓨터에 연결되었지만 완전히 활성화되지 않은 상태를 보여주는 예시 스크린샷. 장치를 선택해야 합니다:

Foresight 시뮬레이터 연결

  1. Foresight 시뮬레이터에서 데이터를 수신하고 있는지 확인하세요.

  2. Swing Catalyst를 종료한 후 Foresight 시뮬레이터를 먼저 시작한 다음 Swing Catalyst를 시작해 보세요.

  3. Foresight 시뮬레이터에서 Club Fitting 모드를 사용하고 있는지, 그리고 설정에서 Shots.CSV가 활성화되어 있는지 확인하세요.

  4. Swing Catalyst 설정에서 “트리거로 사용"이 활성화되어 있는지 확인하세요.

Foresight 지원: http://www.foresightsports.com/support/faqs
