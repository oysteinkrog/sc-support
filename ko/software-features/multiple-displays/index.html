Swing Catalyst에서 다중 디스플레이를 설정하는 방법

다중 디스플레이 설정 방법

이 지원 문서에서는 Windows에서 다중 디스플레이를 설정하고 구성하는 방법을 안내합니다. Swing Catalyst에서 피드백 화면을 설정하는 방법, Swing Catalyst에서 다중 디스플레이를 활용하는 다양한 시나리오, 그리고 모니터가 두 대 이상인 환경에서 창을 탐색하고 이동하는 방법을 설명합니다.

Windows에서 다중 디스플레이를 설정하는 방법:

  1. 컴퓨터가 다중 디스플레이 연결을 지원하는지 확인하세요. 일부 컴퓨터나 노트북은 최대 2개의 디스플레이만 지원하는 등 제한이 있을 수 있습니다.

디스플레이를 세 개 이상 연결하는 셋업의 경우, 필요한 출력 수를 지원하는 그래픽 카드가 있어야 합니다. 또는 단순히 화면을 미러링하려는 경우 HDMI 분배기를 사용할 수 있습니다(자세한 내용은 아래를 참조하세요).

  1. 디스플레이에 연결하는 데 필요한 케이블이 있는지 확인하세요. 현재 가장 일반적인 연결 방식은 HDMI, DVI 또는 DisplayPort입니다. DisplayPort는 어댑터가 필요한 경우가 많습니다. 대부분의 컴퓨터에는 HDMI 포트가 있지만, 일부 노트북은 HDMI 미니 또는 DisplayPort를 사용합니다.

연결하려는 포트의 종류를 확인하여 필요한 경우 적절한 어댑터를 준비하는 것이 중요합니다.

  1. 모니터를 컴퓨터에 연결한 후 바탕화면에서 마우스 오른쪽 버튼을 클릭하고 디스플레이 설정을 선택하세요.

디스플레이가 성공적으로 감지되었다면 두 개 이상의 디스플레이가 표시됩니다.

해당 디스플레이를 주 디스플레이로 설정하려면 “이 디스플레이를 주 모니터로 만들기” 확인란을 체크하세요.

Note: 주 디스플레이를 디스플레이 1(즉, 그래픽 카드의 첫 번째 출력)로 설정하는 것이 좋습니다.

보조 디스플레이로 데스크톱을 확장하려면 다중 디스플레이 아래의 옵션을 선택하세요.

연결하는 디스플레이의 해상도가 더 높거나 낮을 경우 화면이 약간 다르게 보일 수 있습니다. DPI도 달라져 텍스트가 익숙한 것보다 크거나 작게 표시될 수 있습니다. 가능하면 권장 해상도를 사용하세요.

이제 Windows에서 디스플레이를 두 개 이상 설정했으므로, 방향이 올바른지 확인하세요(즉, 오른쪽에 있는 모니터가 실제로 오른쪽에 위치하도록). 이를 올바르게 설정하면 특히 디스플레이가 세 개 이상인 경우 탐색이 훨씬 수월해집니다.

Note: Windows 7은 디스플레이 구성 화면이 다르지만 전체적인 과정은 동일합니다.

관련 지원 문서: 피드백 화면 설정 방법

Swing Catalyst는 마지막으로 실행된 디스플레이에서 시작됩니다. Swing Catalyst를 다른 디스플레이로 이동하려면 제목 표시줄을 클릭한 후 드래그하세요.

사용 예시: 피드백 화면을 활성화하면 별도의 화면(예: 바닥 모니터)을 통해 골퍼에게 즉각적인 피드백을 제공할 수 있습니다.
