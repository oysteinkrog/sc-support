레슨을 녹화하는 방법

소개

레슨 동영상은 드릴이나 연습 세션 요약을 위해 강사에게 유용한 도구입니다. 레슨 동영상은 기본적으로 전체 Swing Catalyst 애플리케이션을 화면에 표시된 그대로 녹화하며, 원하는 스윙을 열어 비교하고, 그리기 도구를 사용하여 선이나 텍스트를 그리고, 원하는 대로 스윙을 재생할 수 있습니다. 만족스러운 결과를 얻으면 동영상을 종료하고, USB 드라이브의 동영상 파일로 공유하거나, 이메일로 전송하거나, YouTube로 공유할 수 있습니다.

적용 대상

  • 선택적 음성 해설이 포함된 동영상 클립 형태로 드릴이나 요약을 만들고자 하는 강사.

관련 항목

  • 마이크 볼륨을 조절하는 방법

해결 방법

  • 스윙 분석 모드에서 상단 메뉴의 녹화 버튼을 클릭합니다.

  • 전체 Swing Catalyst 애플리케이션이 녹화 중임을 나타내기 위해 타이머가 초 단위로 카운트되기 시작합니다. 마우스 포인터도 함께 녹화됩니다.

  • 녹화 중에 무엇을 할지는 전적으로 사용자에게 달려 있지만, 다음과 같은 몇 가지 제안을 참고하시기 바랍니다:

  • 재생하거나 서로 비교하고 싶은 스윙을 엽니다.

  • 전체적인 개요를 보여주기 위해 처음부터 끝까지 슬로우 모션으로 재생합니다.

  • 타임라인을 이동하여 골프 스윙에서 관심 있는 특정 지점을 표시합니다.

  • 그리기 도구를 사용하여 스윙의 다양한 지점에 선이나 텍스트를 주석으로 추가합니다.

  • 레슨 마이크를 사용하여 녹화 중에 음성 해설을 추가합니다.

  • 화면에서 강조하고 싶은 부분 주위로 마우스 포인터를 움직입니다. 동영상에서 해당 부분이 강조 표시되어 쉽게 확인할 수 있습니다.

  • 선이나 텍스트를 설정하거나 시간이 걸리는 새 스윙을 열 때 동영상 시간을 낭비하지 않으려면 일시 중지 버튼을 사용하세요. 예를 들어, 스윙의 여러 지점을 살펴보고 각 지점마다 다른 선이나 텍스트를 사용하려는 경우, 각 위치 사이를 이동하고 설정하는 동안 일시 중지를 활용할 수 있습니다.

  • 만족스러우면 중지 버튼을 클릭하여 미리보기 대화 상자를 표시합니다.

  • 미리보기를 재생하여 내용이 올바른지, 마이크 오디오가 포함되었는지 확인합니다.

  • 디스크에 동영상 파일로 저장하거나, 이메일로 공유하거나, YouTube에 공유하는 옵션 중에서 선택합니다.

  • 이전에 녹화된 레슨은 스윙 탐색기의 레슨 탭에서 찾을 수 있습니다.

문제 해결

문제: Swing Catalyst에서 마이크가 작동하지 않습니다.

Windows 10 2018년 4월 업데이트로 인한 마이크 문제

일부 사용자의 경우 Windows 10이 개인 정보 보호 설정을 근거로 Swing Catalyst의 마이크 사용을 차단하고 있습니다.

버전 1803으로 업그레이드한 후, 소수의 사용자들이 마이크는 감지되지만 소리가 입력되지 않는 문제를 보고하고 있습니다. 이 문제를 해결하기 위해 Microsoft는 다음 단계를 사용하여 개인 정보 보호 설정에서 마이크를 활성화해야 한다고 권장합니다:

설정 열기 개인 정보 보호 클릭 마이크 클릭

앱에서 마이크에 액세스하도록 허용 토글 스위치를 켭니다.

자세한 내용은 이 Microsoft 웹사이트를 참조하세요.

경우에 따라 바이러스 백신 소프트웨어가 레슨 녹화에 문제를 일으킬 수 있습니다.

Kaspersky와 같은 일부 바이러스 백신 소프트웨어는 레슨 녹화 중에 Swing Catalyst를 멈추게 합니다.

Kaspersky를 제거하고 Windows Defender 또는 Carbon Black과 같은 다른 바이러스 백신 소프트웨어를 사용하시기 바랍니다.
