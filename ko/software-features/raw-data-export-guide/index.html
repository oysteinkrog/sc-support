원시 데이터 내보내기 빠른 가이드

이 가이드는 TSV (탭으로 구분된 값) 파일 형식으로 제공되는 원시 데이터 내보내기의 주요 구성 요소를 이해하는 데 도움을 드립니다.

원시 데이터 내보내기에 포함된 항목은 무엇인가요?

  • Force Plates 또는 Pressure Plate와 같은 외부 센서의 원시 데이터 파일이 각각의 파일로 제공됩니다.

  • 북마크 정보 및 각 북마크의 시간 위치.

  • CoP 속도

  • COP 분포

  • 복합력 데이터 (다중 플레이트 셋업의 경우).

  • 동영상 파일 (각 카메라 각도).

데이터 파일에는 여러 열이 포함되어 있으며, 각 열은 서로 다른 측정값을 나타냅니다:

Fx, Fy, Fz: X축, Y축, Z축 방향의 힘 측정 값입니다.

Mx, My, Mz: X축, Y축, Z축을 기준으로 한 모멘트 (토크) 측정 값입니다.

CoPx, CoPy: X 및 Y 방향의 압력 중심입니다.

Fz 위아래 방향으로 가해지는 힘 (수직 힘).

Mz Z축을 기준으로 한 토크 (제자리 회전).

CoPx 플레이트 위에서 힘이 가해지는 좌우 위치.

CoPy 플레이트 위에서 힘이 가해지는 앞뒤 위치.
