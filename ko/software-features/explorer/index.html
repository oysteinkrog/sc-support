탐색기 사용 방법

소개

탐색기는 세션별로 정리된 비디오 녹화를 탐색, 선택 및 관리하는 인터페이스를 제공합니다. 이 문서에서는 25.3 이상 버전에서 탐색기의 모든 기능을 효과적으로 탐색하고 사용하는 방법을 다룹니다.

개요

툴바: 탐색기의 핵심 기능에 빠르게 접근할 수 있는 버튼이 포함된 툴바입니다.

사용자 목록: 검색 바 및 정렬 버튼과 같은 편의 기능이 포함된 등록된 사용자 목록입니다.

다운로드 가능한 콘텐츠 목록: 투어 스윙 등 다운로드된 녹화 목록입니다.

세션 및 녹화: 각 세션의 모든 녹화를 표시하도록 확장할 수 있는 세션 목록입니다.

녹화 미리보기: 애니메이션 썸네일과 녹화에 대한 주요 정보를 보여주는 미리보기 창입니다.

내보내기 목록: 녹화를 여기에 드래그 앤 드롭하여 내보내기 목록에 추가합니다. 그런 다음 녹화를 나중에 SwingCatalyst로 가져올 수 있는 테이크 파일로 내보내거나, 사용자 지정 분석을 위한 원시 데이터 TSV 파일로 내보낼 수 있습니다.

키보드 탐색

탐색기는 녹화 썸네일을 통한 전체 키보드 탐색을 지원합니다:

방향키 탐색

  • ↑ - 한 행 위로 이동

  • ↓ - 한 행 아래로 이동

  • ← - 한 열 왼쪽으로 이동

  • → - 한 열 오른쪽으로 이동

페이지 탐색

  • Home - 현재 세션의 첫 번째 항목으로 이동

  • End - 현재 세션의 마지막 항목으로 이동

  • Page Up - 표시된 페이지 단위로 위로 이동

  • Page Down - 표시된 페이지 단위로 아래로 이동

세션 간 탐색

  • 세션의 맨 위/아래에 있을 때 방향키를 사용하면 인접한 세션으로 자동 이동합니다

  • 세션으로 탐색할 때 세션이 자동으로 확장됩니다

선택 동작

탐색기는 표준 다중 선택 기능을 구현합니다:

단일 선택

  • 클릭 - 단일 녹화 선택

  • 더블 클릭 - 선택한 녹화를 열어 보기

마우스를 이용한 다중 선택

  • Ctrl** + 클릭** - 개별 항목 선택 토글

  • Shift** + 클릭** - 마지막으로 선택한 항목부터 클릭한 항목까지 범위 선택

키보드를 이용한 다중 선택

  • Shift** + 방향키** - 탐색 방향으로 선택 범위 확장

  • Ctrl** + 방향키** - 선택을 변경하지 않고 탐색

  • Ctrl** + **A - 탐색기에서 표시된 모든 녹화 선택

  • Ctrl** + Shift + **A - 현재 세션에서 표시된 모든 녹화 선택

  • Escape - 표시된 선택 항목 모두 해제

선택 정보

  • 선택 카운터: 전체 선택 수 및 표시된 선택 수를 표시합니다

  • 숨겨진 선택 항목: 접혀 있거나 필터링된 세션에서 항목이 선택된 경우 표시합니다

  • 시각적 피드백: 선택된 항목은 테두리로 강조 표시됩니다

메뉴 및 컨텍스트 작업

녹화 컨텍스트 메뉴

녹화를 마우스 오른쪽 버튼으로 클릭하여 접근:

  • 열기 - 녹화 열기

  • 스택에 추가 - 분석 모드에서 빠르게 접근할 수 있도록 분석 스택에 추가

  • 내보내기에 추가 - 내보내기 대기열에 추가

  • 삭제 - 녹화 제거

  • 온라인에 업로드 - SwingCatalyst Online을 통해 공유

학생/그룹 컨텍스트 메뉴

학생 이름을 마우스 오른쪽 버튼으로 클릭하여:

  • 사용자를 내보내기 목록에 추가 - 해당 사용자의 모든 녹화를 내보내기에 포함

  • 사용자 삭제 - 해당 사용자 및 모든 녹화 제거

전역 명령

키보드 단축키를 통해 사용 가능:

  • Enter - 선택한 녹화를 엽니다.

  • Delete - 선택한 모든 녹화 삭제

  • Ctrl** + **A - 탐색기에서 표시된 모든 녹화 선택

  • Ctrl** + Shift + **A - 현재 세션의 모든 녹화 선택

  • Escape - 현재 선택 해제

드래그 앤 드롭

테이크 드래그

  • 테이크를 드래그하여 드롭 영역에 놓기

  • 시각적 피드백으로 녹화 썸네일이 포함된 드래그 표시자를 보여줍니다

  • 드롭 표시기가 유효한 드롭 대상을 강조 표시합니다

드롭 영역

  • 뷰포트 A/B 드롭 영역 - 여기에 놓으면 뷰포트 A 또는 B에서 녹화를 엽니다

  • 내보내기 목록 드롭 영역 - 여기에 놓으면 내보내기 대기열에 녹화를 추가합니다

효율적인 사용을 위한 팁

  • 일괄 작업: 다중 선택을 사용하여 여러 녹화에 동시에 작업을 수행합니다

  • 키보드 효율성: Ctrl, Shift 및 방향키를 조합하여 빠른 선택 작업을 수행합니다

  • 컨텍스트 인식: 마우스 오른쪽 버튼 클릭 메뉴는 상황에 맞는 작업을 제공합니다

  • 시각적 피드백: 선택 카운터와 강조 표시 표시기에 주의를 기울이세요

탐색기는 효율적인 작업 흐름 관리를 위해 설계되어 있으며, 대량의 녹화 컬렉션을 빠르게 탐색하고 최소한의 노력으로 일괄 작업을 수행할 수 있습니다.
