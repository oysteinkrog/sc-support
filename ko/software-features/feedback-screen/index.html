피드백 화면 셋업 방법

이 문서에서는 스윙 녹화 시 자동 영상 재생과 같은 즉각적인 피드백을 표시하기 위해 별도의 모니터를 셋업하는 방법을 설명합니다.

요구 사항

피드백 화면을 사용하려면 PC 모니터가 두 대 이상 연결되어 있어야 합니다.

단계

  • 메인 메뉴로 이동하여 설정 - 화면으로 이동합니다.

  • 디스플레이 식별 버튼을 클릭하면 각 화면에 번호가 표시됩니다. 피드백을 표시할 모니터의 번호를 확인합니다.

  • 해당 번호와 일치하는 디스플레이 아이콘을 클릭하여 해당 화면에서 피드백을 활성화합니다.

  • 이제 골프 스윙을 캡처할 때 해당 화면에 즉각적인 피드백이 표시됩니다.

피드백 화면 사용 체크박스가 활성화되어 있는지 확인하고, 사용할 디스플레이를 선택합니다.

카메라가 여러 대인 경우, SwingCatalyst 메인 창의 왼쪽에 원하는 각도를 배치하면 피드백 화면에 표시되는 카메라 각도를 변경할 수 있습니다. 예를 들어, 아래 그림과 같이 설정하면 피드백 화면에 다운더라인 각도가 표시됩니다.
