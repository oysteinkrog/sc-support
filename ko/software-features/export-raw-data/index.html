스프레드시트에서 볼 수 있도록 데이터를 내보내는 방법

이 문서에서는 Swing Catalyst 또는 Motion Catalyst에서 원시 데이터를 TSV 파일로 내보내는 방법을 설명합니다.

학생 세부 정보를 제외한 내보낸 파일은 탭으로 구분되어 있으므로, 스프레드시트 뷰어에서 반드시 탭 구분 기호를 선택하십시오.

학생 정보를 내보내려면 이 문서를 참조하십시오.

데이터를 내보내는 방법에는 여러 가지가 있으며, 탐색기를 통한 방법과 스택에서 내보내는 방법이 있습니다. 두 옵션 모두 동일한 기능을 제공합니다.

탐색기에서 데이터 내보내기

탐색기에서는 녹화를 마우스 오른쪽 버튼으로 클릭한 후 내보내기를 선택하고 사용 가능한 옵션 중에서 선택하거나, 녹화를 내보내기 목록으로 드래그하여 데이터를 내보낼 수 있습니다.

메뉴 항목

기능

녹화를 내보내기 목록에 추가 선택한 녹화를 내보내기 목록에 추가합니다. 녹화를 내보내기 목록으로 드래그하는 것과 동일합니다.

세션을 내보내기 목록에 추가 전체 세션을 내보내기 목록에 추가합니다. 내보내기 목록에 표시되는 녹화 수는

세션 자체에 포함된 녹화 수에 따라 다릅니다.

녹화를 원시 데이터 파일로 내보내기 선택한 녹화를 원시 데이터 내보내기 옵션과 함께 내보냅니다.

세션을 원시 데이터 파일로 내보내기 전체 세션을 원시 데이터 내보내기 옵션과 함께 내보냅니다.

데이터 내보내기 선택

데이터를 내보낼 때 몇 가지 다양한 옵션 중에서 선택할 수 있습니다.

이 문서는 주로 원시 데이터에 초점을 맞춥니다.

원시 데이터를 내보내려면 내보내기 대화 상자에서 “Raw Data"를 선택하십시오.

원시 데이터 옵션

이 기능은 아직 개선 중임을 참고하십시오. 현재 많은 옵션이 “Raw data"에 함께 포함되어 있습니다.
