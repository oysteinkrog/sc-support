정면 평면 토크 분석 - 사용자 가이드

소개

정면 평면 토크란?

정면 평면 토크(FPT)는 골프 스윙 중 신체가 정면 평면 축을 중심으로 생성하는 회전력을 측정합니다. 쉽게 말해, 지면 반력을 얼마나 효과적으로 활용하여 회전 파워를 만들어 내는지를 측정하는 지표입니다.

골프 클럽을 스윙할 때, 발이 지면을 누르면 지면은 반대로 몸을 밀어 올립니다. 신체의 질량 중심과 발에 작용하는 힘 사이의 이러한 상호작용이 토크, 즉 스윙의 파워를 만들어 내는 회전력을 발생시킵니다.

기능 구성 요소

FPT 기능은 두 가지 주요 구성 요소로 이루어져 있습니다:

FPT 그래프 (DataBox) - 핵심 지표와 함께 스윙 전반에 걸친 토크 값을 시계열로 보여주는 그래프

3D 시각화 - 모션 캡처 골격 뷰에 실시간으로 표시되는 모멘트 팔 및 힘 분해 오버레이

왜 중요한가?

정면 평면 토크를 이해하면 다음과 같은 도움을 얻을 수 있습니다:

파워 생성 패턴 파악 - 지면 반력을 회전 에너지로 얼마나 효율적으로 전환하는지 확인

생체역학적 레버리지 시각화 - 3D에서 질량 중심과 지면 반력 사이의 모멘트 팔 관계 확인

타이밍 분석 - 임팩트 대비 첨두 토크 발생 시점 파악

힘 구성 요소 분해 - 지면 반력이 다양한 방향으로 어떻게 분산되는지 확인

스윙 비교 - 시간에 따른 힘 생성 변화 추적

사전 요구 사항

정면 평면 토크 분석을 사용하려면 다음이 필요합니다:

필수: 지면 반력 데이터가 포함된 포스 플레이트 녹화

필수: 질량 중심 추적을 위한 모션 캡처 데이터

필수: 캘리브레이션된 카메라 셋업

필수: 정규화된 값 산출을 위한 체중 측정

시작하기

레이아웃에 FPT DataBox 추가하기

  • 분석 뷰에서 녹화된 스윙 열기

  • DataBox 메뉴 또는 레이아웃 편집기 클릭

  • 사용 가능한 DataBox 목록에서 정면 평면 토크 찾기

  • 분석 레이아웃에 추가

  • DataBox가 녹화 데이터로 자동으로 채워집니다

3D 시각화 활성화

모멘트 팔 및 힘 분해 시각 요소는 골격과 함께 3D 비디오 뷰포트에 표시됩니다. 활성화 방법:

  • 모션 캡처 및 포스 플레이트 데이터가 포함된 녹화 열기

  • 비디오 뷰에서 힘 벡터 설정 패널 찾기

  • 원하는 시각화 옵션 활성화

필요한 데이터

FPT 분석이 올바르게 작동하려면 녹화에 다음이 포함되어야 합니다:

데이터 유형 필수 여부 목적

포스 플레이트 데이터 예 지면 반력(Fx, Fz) 및 압력 중심 제공

모션 캡처 예 토크 계산 및 3D 시각화를 위한 질량 중심 위치 제공

체중 예 비교를 위한 토크 값 정규화에 사용

카메라 캘리브레이션 예 올바른 3D 정렬에 필요

임팩트 북마크 권장 볼 접촉 대비 타이밍 메트릭 활성화

화면 구성 이해하기

그래프

메인 그래프는 시간에 따른 토크 값을 표시합니다:

X축 (수평): 스윙 시작부터 피니시까지의 시간

Y축 (수직): 토크 값 (퍼센트 및/또는 절댓값으로 표시 가능)

영점 선: 가로 방향의 0 기준선 - 위아래 값은 반대 방향의 회전력을 나타냄

이중 축 시스템

그래프는 두 가지 다른 척도를 동시에 표시할 수 있습니다:

왼쪽 축 (퍼센트): 체중으로 정규화된 토크 표시 (Nm/kg, 력 계수로 표시)

오른쪽 축 (절댓값): 실제 토크를 Newton-meter (Nm) 단위로 표시

핵심 지표

세 가지 핵심 지표가 그래프와 함께 표시됩니다:

1. 최대 토크 (력 계수)

표시 내용: 체중으로 정규화된 첨두 토크 크기

단위: Nm/kg (력 계수로 표시)

예시: 0.85 값은 첨두 토크가 체중 1킬로그램당 0.85 Newton-meter임을 의미

2. 최대 토크 타이밍

표시 내용: 볼 임팩트 대비 첨두 토크 발생 시점

단위: 밀리초 (ms)

참고: 임팩트 북마크가 설정된 경우에만 표시됨

예시: -50ms는 임팩트 50ms 전에 첨두 토크 발생; +20ms는 임팩트 20ms 후; 0ms는 임팩트 시점

3. 력 계수 (원시값)

표시 내용: 방향(양수 또는 음수)을 포함한 원시 정규화 토크 값

단위: Nm/kg

예시: +0.85와 -0.85는 크기는 같지만 회전 방향이 반대

페이즈 강조 표시

활성화하면 스윙의 각 페이즈를 나타내는 색상 밴드가 그래프에 오버레이됩니다:

  • 백스윙, 다운스윙, 임팩트, 팔로우스루

3D 시각화

모멘트 팔 시각화

모멘트 팔 시각화는 질량 중심(COM)과 지면 반력 사이의 생체역학적 레버리지 관계를 보여줍니다.

요소 외형 표시 내용

모멘트 팔 선 주황색 실선 COM에서 작용선까지의 수직 거리

작용선 주황색 점선 힘이 작용하는 방향의 연장선

거리 레이블 어두운 배경에 흰색 텍스트 모멘트 팔 거리 (센티미터, ±X.X cm)

힘 벡터 분해

힘 분해 시각화는 전체 지면 반력을 세 가지 수직 성분으로 분해합니다. 색상은 카메라 뷰에 관계없이 항상 동일한 물리적 힘의 방향을 나타냅니다:

성분 색상 물리적 방향 표시 내용

X 성분 분홍색 좌우 방향 (내외측) 측면력 분포

Y 성분 청록색 상하 방향 (수직) 수직 힘 분포

Z 성분 녹색 앞뒤 방향 (전후방) 전후방 힘 분포

각 성분 화살표에는 해당 방향의 전체 힘 대비 비율을 나타내는 퍼센트 레이블도 표시됩니다.

카메라 뷰 동작

힘 벡터는 카메라 뷰를 기준으로 표시됩니다. 화면 깊이 방향(화면 안/밖)으로 나타나는 성분은 명확성을 위해 숨겨집니다:

카메라 뷰 표시 성분 숨김 성분

정면 뷰 X (분홍색, 수평), Y (청록색, 수직) Z (녹색, 깊이)

다운더라인 Z (녹색, 수평), Y (청록색, 수직) X (분홍색, 깊이)

참고: 색상은 항상 동일한 물리적 방향을 나타냅니다 - 분홍색은 항상 내외측 힘, 청록색은 항상 수직 힘, 녹색은 항상 전후방 힘입니다. 카메라 각도에 따라 화면상 위치만 달라집니다.

3D 시각화 설정

모멘트 팔 설정

설정 기본값 설명

모멘트 팔 표시 꺼짐 COM에서 힘 작용선까지의 주황색 실선 토글

작용선 표시 꺼짐 힘 방향 연장선을 나타내는 주황색 점선 토글

거리 레이블 표시 꺼짐 거리 값 레이블 토글 (±X.X cm)

힘 분해 설정

설정 기본값 설명

X/Y/Z 성분 표시 꺼짐 세 가지 성분 화살표 및 퍼센트 레이블 모두 토글

설정 옵션 (그래프)

% 표시 (퍼센트 축): 기본값 켜짐 - 정규화된 토크 (Nm/kg) 토글

Newton 표시 (절댓값 축): 기본값 꺼짐 - 절대 토크 (Nm) 토글

페이즈 강조 표시: 기본값 꺼짐 - 스윙 페이즈들을 나타내는 색상 밴드 표시

그리드선 표시: 기본값 켜짐 - 수평 그리드선 표시

차트 유형: 마운틴 차트 (기본값) 또는 라인 차트

문제 해결

“포스 플레이트 위에 사람 없음” 메시지

  • 녹화 시작 시 선수가 포스 플레이트 위에 서 있었는지 확인

  • 선수 프로필에 체중이 입력되어 있는지 확인

  • 포스 플레이트 캘리브레이션이 완료되었는지 확인

그래프 데이터가 비어 있거나 누락됨

  • 녹화 중 포스 플레이트가 활성화되어 있었는지 확인

  • 모션 캡처 데이터가 녹화되었는지 확인 (FPT 계산에 필수)

  • 녹화에 전체 스윙 지속 시간이 포함되어 있는지 확인

타이밍 메트릭이 표시되지 않음

  • 녹화에서 임팩트 북마크 설정
