키보드 단축키 및 핫키

Swing Catalyst & Motion Catalyst는 여러 키보드 단축키를 지원합니다.

이 문서에서는 키보드 단축키를 자세히 설명합니다.

키보드 단축키는 한 번의 키 입력일 수도 있지만, 여러 키의 조합일 수도 있습니다.

이 문서에서는 한 번의 키 입력보다 긴 단축키를 + 기호로 연결하여 표시합니다.

이것이 키보드에서 + 를 누르라는 의미는 아니며, 여러 개의 버튼을 함께 눌러야 함을 나타냅니다.

재생

키보드 핫키 / 단축키 작업

스페이스 재생 / 일시 중지 전환

오른쪽 한 프레임 앞으로 이동

왼쪽 한 프레임 뒤로 이동

Shift 오른쪽 지속 시간의 5% 앞으로 이동

Shift 왼쪽 지속 시간의 5% 뒤로 이동

위쪽 재생 속도 증가

아래쪽 재생 속도 감소

북마크

키보드 핫키 / 단축키 작업 / 설명

1, 2 또는 3 뷰포트 A에서 열려 있는 녹화의 북마크 1~3 위치로 이동

Alt + 1, 2 또는 3 뷰포트 B에서 열려 있는 녹화의 북마크 1~3 위치로 이동

Ctrl + 1, 2 또는 3 뷰포트 A의 북마크 1~3을 현재 재생 위치로 설정

Ctrl + Alt 1, 2 또는 3 뷰포트 B의 북마크 1~3을 현재 재생 위치로 설정

Ctrl + Shift 1, 2 또는 3 북마크 1~3에서 동기화

Ctrl + B 북마크 편집 잠금 / 잠금 해제

그리기 도구

단축키 작업 (그리기 도구 활성화)

C 원

R 직사각형

V 화살표

L 선

A 각도

F 프리핸드

S 스웨이

E 지우개

H 손

T 텍스트

B 버킷 (모두 지우기)

모션 캡처

단축키 작업

Shift+S 골격 숨기기/표시 전환

Shift+C 무게중심 기호 숨기기/표시 전환

Shift+A 각도 도구 전환

Shift+L 관절 연결 도구 전환

Shift+T 관절 추적 도구 전환

Shift+M 관절 이동 도구 전환

기타

단축키 작업 / 설명

Ctrl + O 탐색기 열기/닫기

Ctrl + 마우스 스크롤 위 확대 (비디오 또는 데이터 그래프, 마우스 포커스에 따라)

Ctrl + 마우스 스크롤 아래 축소 (비디오 또는 데이터 그래프, 마우스 포커스에 따라)

Alt + C 캡처 모드 전환 (사용자를 선택한 후)

Alt + A 스택의 마지막 녹화를 뷰포트 a에서 열기

Alt + B 스택에서 마지막 녹화를 View Port B에서 열기
