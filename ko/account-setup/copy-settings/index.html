Swing Catalyst 설정 및 라이선스를 새 컴퓨터로 이전하는 방법

소개

이 문서에서는 Swing Catalyst 설정, 라이선스 및 모든 항목을 새 컴퓨터 또는 하드 드라이브에 복사하는 방법을 설명합니다.

데이터베이스 복사본을 만드는 방법은 별도의 문서를 참조하십시오.

준비

데이터베이스를 복사할 컴퓨터에 Swing Catalyst가 설치되어 있는지 확인하십시오.

설정 파일 복사

컴퓨터 간에 설정을 전송할 때 설정을 저장하려면 외장 하드 드라이브 또는 USB 드라이브를 사용하는 것을 권장합니다.

  • Windows 파일 탐색기를 엽니다.

  • 다음을 입력하고 Enter 키를 누릅니다: %programdata% 그러면 프로그램 데이터 폴더 내에서 Windows 탐색기가 열립니다.

  • “Swing Catalyst” 폴더로 이동합니다.

Tip: 키보드에서 CTRL 키를 누른 상태로 마우스로 각 폴더를 클릭하여 선택합니다.

데이터베이스 폴더 또는 골퍼 폴더를 제외한 모든 폴더를 선택합니다. 또한 SwingCatalystDB.s3db 파일(데이터베이스 파일)도 선택합니다.

마우스 오른쪽 버튼을 클릭하고 복사를 선택한 다음 USB 드라이브에 내용을 붙여넣습니다.

새 컴퓨터에 설정 복사하기

Note: 진행하기 전에 Swing Catalyst가 실행되고 있지 않은지 확인하십시오. 이 작업을 수행하면 설정이 덮어쓰여집니다. 즉, 이전 컴퓨터의 기존 설정이 현재 설정을 대체합니다.

USB 드라이브에 복사한 후, 새 컴퓨터에 연결하고 새 컴퓨터의 동일한 위치에 내용을 붙여넣습니다.

위의 단계를 반복하되, 선택하여 복사하는 대신 폴더와 파일을 Swing Catalyst 프로그램 데이터 폴더에 붙여넣습니다.
