Motion Catalyst 바로 가기 만드는 방법

Motion Catalyst는 Swing Catalyst를 설치할 때 함께 설치됩니다. 이 문서에서는 바탕 화면에 Motion Catalyst 바로 가기를 추가하는 방법을 설명합니다.

  1. Swing Catalyst를 설치한 후, 작업 표시줄의 폴더 아이콘을 클릭하여 Windows 파일 탐색기를 엽니다.

  2. C:\Program Files\Initial Force\Swing Catalyst\bin 경로로 이동합니다.

  3. 해당 폴더에서 Motion Catalyst 애플리케이션을 찾아 마우스 오른쪽 버튼으로 클릭합니다.

  4. “보내기 > 바탕 화면에 바로 가기 만들기"를 선택합니다.

  5. 이제 바탕 화면에 Motion Catalyst 아이콘이 생성된 것을 확인할 수 있습니다.
