Swing Catalyst의 ProgramData 폴더 및 녹화 파일 복사 또는 백업 방법

이 지원 문서에서는 Swing Catalyst 프로그램 데이터 폴더를 수동으로 복사하는 방법을 설명합니다. 한 컴퓨터에서 다른 컴퓨터로 Swing Catalyst를 이전하려는 경우에 유용합니다.

Please note

Swing Catalyst 라이선스는 두 대의 컴퓨터에서 동시에 활성화할 수 없습니다. Swing Catalyst를 시작하면 라이선스가 활성화됩니다. 즉, Swing Catalyst를 컴퓨터 A에서 컴퓨터 B로 이전하려는 경우, 컴퓨터 A에서 Swing Catalyst를 다시 실행하면 라이선스가 24시간 동안 잠길 수 있습니다.

Requirements

  • Swing Catalyst 데이터베이스를 저장할 충분한 여유 공간이 있는 외장 하드 드라이브 또는 보조 하드 드라이브.

1단계: ProgramData 폴더 백업

Swing Catalyst 프로그램 데이터 폴더는 C:\ProgramData\Swing Catalyst\에 있습니다.

프로그램 데이터 폴더에는 설정, 센서 캘리브레이션, 라이선스 파일 등이 포함되어 있습니다.

녹화 파일은 다른 위치에 저장될 수 있으므로, 해당 위치를 반드시 확인해 두시기 바랍니다 (2단계 참조).

  • %programdata%를 입력한 후 Enter 키를 눌러 ProgramData 폴더로 이동합니다.

  • Swing Catalyst 폴더 전체를 외장 하드 드라이브에 복사합니다.

아래는 Swing Catalyst ProgramData 폴더입니다:

SwingCatalystDB.s3db 파일을 외장 하드 드라이브 또는 보조 하드 드라이브에 복사합니다.

2단계: 녹화 파일 복사

녹화 파일 저장 위치 확인

  • Swing Catalyst 설정으로 이동하여 “General"을 클릭하고, 데이터베이스 섹션에 지정된 “Path"를 확인합니다 (위 스크린샷의 오른쪽 상단 영역 참조).

  • 데이터베이스 위치를 기록해 두십시오. 녹화 파일과 레슨이 이 위치에 저장됩니다.

일반적인 경우, Swing Catalyst 데이터베이스 파일은 ProgramData 디렉터리에 있지만, 실제 녹화 파일(데이터베이스가 참조하는 콘텐츠)은 공간 제약으로 인해 다른 하드 드라이브나 파티션에 저장되는 경우가 많습니다.

위 스크린샷과 같이 데이터베이스 경로가 C:\ProgramData\Swing Catalyst\database로 표시된 경우, 해당 database 폴더를 복사하십시오.

새 컴퓨터로 데이터 복사

Swing Catalyst의 ProgramData 디렉터리와 모든 녹화 파일(위 스크린샷에 표시된 경로 기준)을 외장 하드 드라이브 등에 복사했다면, 이제 새 컴퓨터로 데이터를 옮길 준비가 되었습니다.

Important: 진행하기 전에 먼저 Swing Catalyst를 다운로드하여 설치하십시오.

Requirements:

  • 유효한 Swing Catalyst 라이선스.

Swing Catalyst ProgramData 디렉터리 교체

새 컴퓨터에는 Swing Catalyst가 새로 설치되어 있어야 하며, 해당 컴퓨터에 보존해야 할 파일이 없으므로 파일을 교체해도 무방합니다.

  • 외장 하드 드라이브를 연결하고 복사해 둔 Swing Catalyst의 ProgramData 디렉터리를 찾습니다.

  • 새 컴퓨터에서 ProgramData 디렉터리로 이동합니다.

  • 새 컴퓨터의 기존 Swing Catalyst 폴더를 외장 하드 드라이브에서 복사한 폴더로 교체합니다.

데이터베이스 설정

Swing Catalyst가 기본 경로인 C:\ProgramData\Swing Catalyst\database가 아닌 다른 위치를 사용하도록 구성된 경우, 해당 폴더의 내용을 ProgramData 디렉터리 내의 database 폴더로 복사해야 합니다.

위 예시에서 디렉터리가 D:\Temp2였다면, 해당 폴더의 내용을 database 폴더로 복사해야 합니다.

Swing Catalyst에 구성된 경로를 확인하려면 regedit 레지스트리 편집기 도구를 사용하여 확인할 수 있습니다.

컴퓨터 –> HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Initial Force\Swing Catalyst로 이동한 후, 아래 스크린샷과 같이 해당 폴더를 클릭합니다.

DatabasePath는 Swing Catalyst가 녹화 파일을 검색하는 위치입니다.
