Point Grey GigE 카메라를 Swing Catalyst와 함께 작동하도록 셋업하는 방법

카메라 설정 구성에 대해서는 다음 문서를 참조하십시오: point-grey-flir-usb.md

이 문서는 카메라와 네트워크 카드 모두의 IP 주소 셋업을 다룹니다.

참고: 카메라 지원은 제한적이며, 카메라 제어는 FlyCapture(Point Grey 소프트웨어)로 제한됩니다.

호환되는 네트워크 어댑터 및 구성:

다음을 참조하십시오: gige-network-setup.md

참고: Spinnaker SDK 지원 카메라의 경우 Spinnaker 문서를 확인하십시오.

참고, 퍼포먼스에 중요: Intel 네트워크 카드를 사용하는 경우, Intel 드라이버를 다운로드하여 설치하십시오. Windows 드라이버에서는 사용할 수 없을 수 있는 인터럽트 조절 속도 설정 옵션을 제공합니다.

IP 구성으로 바로 이동하려면 여기를 클릭하십시오

중요:

Region of Interest (ROI)는 Blackfly BFLY-PGE-03S3C 카메라에서 작동하지 않습니다.

카메라당 전용 네트워크 어댑터(포트) 하나를 사용하는 것을 권장합니다.

Point Grey / FLIR GigE 카메라 셋업:

요구 사항:

  • 당사 웹사이트에서 Point Grey Flycap 소프트웨어를 설치하십시오: https://www.swingcatalyst.com/drivers

  • 권장 네트워크 카드 중 하나

  • 네트워크 카드가 설치되어 전원이 공급되고 있을 것.

  • 카메라가 네트워크 카드에 연결되어 있을 것.

참고: Flycap 설치 시, Point Grey Image Filter 드라이버의 체크박스가 선택되어 있는지 확인하십시오.

네트워크 카드 설치

네트워크 카드 설치에 대해서는 다음 단계를 참고하십시오: https://www.wikihow.com/Install-a-PCI-Card FLiR의 듀얼 포트 네트워크 카드 설치 단계도 이와 거의 동일합니다.

<>GigE Configurator 유틸리티를 사용하여 IP 주소 설정

네트워크 어댑터(포트)와 연결된 카메라 모두의 IP 주소를 구성해야 합니다.

네트워크 어댑터 셋업부터 시작하겠습니다!

  • Point Grey GigE Configurator 애플리케이션을 여십시오. 다음 경로에서 찾을 수 있습니다: C:\Program Files\Point Grey Research\FlyCap2 Viewer\bin64
  1. Point Grey GigE Configurator 애플리케이션을 열고 카메라를 클릭하십시오.

카메라가 연결된 네트워크 어댑터를 확인하십시오(빨간색으로 강조 표시된 부분 참조).

여기서는 카메라가 Ethernet 9에 연결되어 있습니다.

위 스크린샷 왼쪽의 목록에서 Network Adapters 아래 Ethernet 9를 클릭하십시오.

네트워크 어댑터의 IP 주소 설정:

아래 스크린샷과 일치하도록 IP 주소와 서브넷 마스크를 변경하고, Set IP address / Subnet을 클릭한 후 Yes와 OK를 클릭하십시오.

이제 첫 번째 네트워크 어댑터의 IP 주소를 설정했습니다. 다음 단계는 네트워크 어댑터의 설정을 최적화하는 것입니다.

네트워크 어댑터 최적화

아래 스크린샷에서 빨간색으로 표시된 MTU 숫자를 확인하십시오.

이 숫자를 늘려야 합니다. 아래 강조 표시된 영역에 따라 Open Network Connections를 클릭하십시오.

Advanced 탭을 클릭하고 Jumbo Packet을 찾아 값을 9014 Bytes로 설정하십시오.

인터럽트 조절(Interrupt Moderation) 변경

Interrupt Moderation을 Enabled로 설정하십시오.

Interrupt Moderation Rate를 클릭하고 값을 Extreme으로 설정하십시오.

중요: 카메라를 2대 이상 사용할 경우, 프레임 드롭을 방지하기 위해 Interrupt Moderation을 Disabled로 설정해야 할 수 있습니다.

카메라의 IP 주소 설정

목록에서 사용 가능한 카메라를 클릭하십시오(여기서는 카메라가 하나만 연결되어 있으므로 올바른 카메라임을 알 수 있습니다).

다음 IP를 입력하십시오(위의 Ethernet 9에 연결된 카메라의 IP 주소를 설정하는 것입니다):

Set IP Address / Subnet을 클릭하고 Yes, 그 다음 OK를 클릭하십시오.

FLiR GigE Configurator 왼쪽 목록에서 방금 IP 주소를 설정한 카메라를 찾아 클릭하십시오.

IP 주소 할당 구성 설정

카메라의 IP 주소 변경이 지속적으로 유지되어야 하므로 이 작업이 중요합니다. 그렇지 않으면 전원이 차단된 후 카메라가 구성을 잊어버립니다.

DHCP의 체크를 해제하고 Persistent IP를 체크하십시오.

Copy from Current을 클릭한 후 Set IP Address / Subnet을 클릭하십시오.

패킷 크기 확인

패킷 크기(MTU)가 올바르게 설정되었는지 확인합니다.

Discover Maximum Packet Size를 클릭하면 9000으로 표시되어야 합니다.

Test Camera Connection을 클릭하여 연결이 작동 중이며 카메라에서 데이터를 수신하고 있는지 확인하십시오.

카메라 1대 이상 셋업하기

하나의 카메라와 하나의 네트워크 어댑터를 구성했다면, 위의 단계를 반복하여 여러 카메라를 구성할 수 있습니다.

위의 단계 및 스크린샷을 참고하여, 카메라와 Ethernet 어댑터 9의 IP를 이미 설정했습니다. 여러 카메라를 셋업하는 과정도 동일하며 IP만 다르게 설정합니다.

편의를 위해 Ethernet 어댑터 1, 2, 3 등으로 부르겠습니다..

Ethernet 어댑터 1: IP: 10.0.1.1 Subnet: 255.255.255.0

카메라 1: IP: 10.0.1.10 Subnet: 255.255.255.0 Ethernet 어댑터 2: IP: 10.0.2.1 Subnet: 255.255.255.0 카메라 2: IP: 10.0.2.10 Subnet: 255.255.255.0

Ethernet 어댑터 3: IP: 10.0.3.1 Subnet: 255.255.255.0

카메라 3: IP: 10.0.3.10 Subnet: 255.255.255.0

Ethernet 어댑터 4: IP: 10.0.4.1 Subnet: 255.255.255.0

카메라 4: IP: 10.0.4.10 Subnet: 255.255.255.0

Swing Catalyst에서 카메라 사용하기

Swing Catalyst에서 Point Grey 카메라를 사용하려면 카메라 각도를 설정하고 활성화를 클릭하기만 하면 됩니다. Play 버튼을 클릭하여 카메라가 정상 작동하는지 확인하십시오.

모든 카메라 구성은 Point Grey의 FlyCapture 소프트웨어를 통해 수행해야 합니다.

셔터 속도 및 기타 카메라 설정 변경 방법

Point Grey Flycap2 소프트웨어를 시작하고 Camera Settings로 이동하십시오.

  1. Shutter 아래에서 Auto의 체크가 해제되어 있는지 확인하십시오.

실내 스튜디오와 같은 정적인 환경에서는 수동 노출을 사용하는 것이 일반적으로 가장 좋습니다. 완전 Auto 노출은 프레임 레이트가 변경될 수 있으며 일관성 없는 이미지로 이어질 수 있습니다.

  1. 이 경우 직접 제어하기 위해 Auto 노출을 사용하지 않습니다. 일반적으로 2000(2ms) 미만의 노출 시간을 권장합니다.

설정 저장은 3을 참조하십시오.

프레임 레이트를 조정해야 할 수도 있습니다. Auto의 체크를 해제하고 원하는 프레임 레이트로 설정한 후 3단계를 따르십시오.

프레임 레이트를 조정해야 할 수도 있습니다. Auto의 체크를 해제하고 원하는 프레임 레이트로 설정한 후 3단계를 따르십시오.

Gain 값 설정

노출과 마찬가지로, 정적/실내 조명 환경에서는 Gain을 수동으로 설정하는 것이 가장 좋습니다. 노출이 높을수록 이미지가 더 거칠어지고, 낮은 Gain에 비해 동영상 인코딩에 더 오랜 시간이 걸립니다.

수동 Gain을 설정하려면 Auto의 체크를 해제하십시오.

카메라 셋업 방법에 대한 자세한 내용은 다음 문서를 참조하십시오: point-grey-flir-usb.md

문제 해결 및 추가 최적화

FLiR / Point Grey 카메라에서 프레임이 드롭되거나 동기화 문제가 있는 경우, Flycapture2 -> Custom Video modes에서 패킷 크기를 확인하십시오.

패킷 크기를 최대값인 9000에서 더 작은 값으로 낮춰볼 수 있습니다. CPU에 따라 컴퓨터마다 최적의 값이 다를 수 있습니다.

하나의 네트워크 어댑터에 카메라 2대를 사용하는 경우 패킷 지연(packet delay)을 9500으로 설정하는 것을 권장합니다.

Advanced Camera Settings로 이동하여 카메라 셋업 문서에서 설명한 대로 bank 1에 설정을 저장하는 것을 잊지 마십시오, ** point-grey-flir-usb.md**

Memory Channels에서 저장을 클릭하고 Channel 1이 선택되어 있는지 반드시 확인하십시오!

이미지가 표시되지 않거나 Swing Catalyst에서 오류가 발생하는 경우, 패킷 크기를 변경하고 bank 1에 저장해 보십시오(위 그림 참조).

카메라 4대 셋업 시 프레임 드롭:

일부 카메라 4대 셋업에서는 인터럽트 조절을 끄거나, 인터럽트 조절 속도를 extreme에서 low로 변경하는 것을 권장합니다. 조절 속도가 높으면 인터럽트 횟수가 억제되어 CPU 부하가 낮아집니다. 그러나 인터럽트 발생 빈도가 낮을수록 호스트의 ACK 응답이 느려질 가능성이 높습니다. 빠른 프레임 레이트로 이미지를 스트리밍하는 경우 패킷이 드롭될 수 있습니다.

시스템에 따라 다른 조절 속도를 선택하면 네트워크 및 시스템 퍼포먼스를 향상시킬 수 있습니다.

이에 대한 자세한 내용은 다음 문서의 Interrupt Moderation Rate 섹션에서 확인할 수 있습니다: https://www.flir.com/ support-center/iis/machine- vision/application-note/ troubleshooting-image- consistency-errors/ .

더 자세한 정보는 프레임 드롭에 관한 FLiR / Point Grey 지원 문서를 참조하십시오: https://eu.ptgrey.com/tan/10899

Blackfly 카메라 모델의 Point Grey 기술 참조 매뉴얼은 다음을 참조하십시오: https://www.ptgrey.com/support/downloads/10113/

추가 네트워크 어댑터 최적화

Receive Buffers

이 값을 최대한 높게 설정하는 것을 권장합니다. 이는 여러 대의 카메라 및/또는 고해상도 GigE 카메라 사용 시 프레임 드롭을 방지하는 데 도움이 될 수 있습니다.

네트워크 스위치에서 카메라 2대 사용:

Blackfly BFLY-PGE-03S3C (90FPS) 카메라만 지원됩니다. 다른 카메라를 사용하면 프레임 드롭이 발생할 수 있습니다.

중요: 네트워크 스위치는 9KB Jumbo 프레임을 지원해야 합니다(대부분의 네트워킹 스위치에서 지원함). 다음 스위치 또는 GS105 모델과 유사한 스위치를 권장합니다: https://www.netgear.com/support/product/GS105.aspx

네트워크 스위치를 사용하는 경우, 아래 스크린샷과 같이 Packet Delay를 9500으로 설정하는 것이 중요합니다.

Packet Delay를 9500으로 설정한 후, Advanced Camera Settings로 이동하여 카메라 셋업 문서에서 설명한 대로 bank 1에 저장하십시오, ** point-grey-flir-usb.md**

Packet Delay를 설정하면 하나의 네트워크 어댑터에서 Blackfly 03S3C 카메라 2대를 사용할 때 프레임 드롭을 줄이는 데 도움이 됩니다.

다중 카메라 셋업에 대한 더 자세한 내용은 여기에서 확인할 수 있습니다: https://www.ptgrey.com/tan/10351
