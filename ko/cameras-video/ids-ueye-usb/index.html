IDS uEye USB 카메라를 Swing Catalyst와 함께 사용하는 방법

소개

이 지원 문서는 IDS uEye USB 카메라를 구성하고 사용하는 방법에 대한 실질적인 세부 정보를 설명합니다.

설치에 관한 자세한 내용은 여기를 클릭하세요

GigE (네트워크 IDS 카메라)에 대해서는 이 문서를 참조하세요: ids-ueye-gige.md

적용 대상

  • IDS uEye USB 카메라와 Swing Catalyst 시작하기.

카메라 설명

uEye USB 카메라는 세 가지 별도 구성 요소로 이루어져 있습니다:

  • 카메라 본체

  • 렌즈

  • USB 케이블

카메라

카메라 본체에는 물리적인 조정 장치가 없으며, 모든 설정은 소프트웨어로 제어됩니다.

렌즈

제공된 렌즈에는 3개의 조정 링이 있으며, 카메라에서 바깥쪽 방향으로 순서대로 다음과 같습니다:

  • 줌

  • Iris

  • 포커스

줌/포커스

가변 초점(줌) 렌즈에서는 줌 링과 포커스 링이 함께 작동하므로, 선명한 포커스/줌을 위해 두 조정 링을 모두 조절하는 것이 도움이 될 수 있습니다.

Iris

Iris 조정 링은 빛의 양(“개구부”)을 결정합니다.

Iris를 닫으면 이미지가 어두워지지만, 초점 심도(초점이 맞는 영역)를 높여 더 나은 초점을 얻는 데 도움이 됩니다.

이미지가 과다 노출된 경우(예: 매우 맑은 날) Iris를 닫는 것을 권장합니다.

소프트웨어 설정

Swing Catalyst에서 모든 카메라 설정은 메인 메뉴의 설정 - 카메라에서 찾을 수 있는 “카메라 설정"의 “고급” 버튼을 통해 이용할 수 있습니다.

“고급” 버튼을 클릭하면 고급 카메라 설정 대화 상자가 표시됩니다.

uEye 카메라의 경우 카메라의 여러 주요 특성을 결정하는 몇 가지 중요한 설정이 있습니다:

픽셀 클록

픽셀 클록은 기본적으로 “속도” 설정으로, 이를 높이면 사용 가능한 최대 프레임 레이트가 증가하지만, 너무 높이면 프레임 드롭이 발생할 수 있습니다.

프레임 레이트

프레임 레이트 설정은 자동 및 수동 구성 모두를 지원합니다.

자동 모드는 자동 Gain과 같은 다른 자동 기능을 비활성화하므로, 수동 설정을 사용하는 것을 권장합니다.

노출 셔터

빠른 움직임을 포착하고 모션 블러를 줄이기 위해서는 낮은 셔터 속도가 필수적입니다.

골프 스윙의 경우 적절한 이미지를 얻기 위해 최대 2ms(밀리초) 노출을 사용하는 것을 권장합니다.

매우 선명한 이미지를 위해서는 0.5ms의 노출 설정이 좋지만, 많은 빛이 필요하며 실외 사용에만 권장됩니다.

“Max” 자동 파라미터를 통해 상한선을 설정하여 노출 셔터를 자동 모드로 설정할 수 있으며, 이는 카메라가 다양한 조명 조건에 적응하면서 좋은 이미지 품질을 유지할 수 있는 좋은 옵션입니다.

Gain

Gain은 이미지 밝기를 높이지만, 이미지에 더 많은 노이즈를 발생시킵니다.

대부분의 경우 카메라가 스스로 조정할 수 있도록 Auto Gain을 사용하는 것을 권장합니다.

화이트 밸런스

카메라가 이미지의 색상 밸런스를 조정할 수 있도록 화이트 밸런스를 Auto로 설정하는 것을 권장합니다.

이미지의 색상이 잘못 표시되는 경우 수동 설정을 사용하여 빨강, 초록, 파랑 파라미터를 조정하세요.

초당 프레임 수 (FPS) 최대화

최대 FPS는 컴퓨터 사양에 따라 달라집니다. 프레임 드롭이 발생하면 시스템이 모든 데이터를 처리하지 못하는 것이므로 속도를 낮춰야 합니다.

다음은 카메라 퍼포먼스를 최대화하는 데 도움이 되는 단계별 절차입니다.

  • 메인 메뉴 -> 설정 -> 카메라로 이동합니다.

  • uEye 카메라의 “고급” 버튼을 클릭합니다.

  • 고급 설정 대화 상자에서 카메라 탭으로 이동합니다.

  • 비디오 미리보기 패널의 “재생” 버튼을 클릭하여 라이브 비디오 스트리밍을 시작합니다.

  • “속도(픽셀 클록)” 슬라이더를 오른쪽으로 드래그하여 드롭된 프레임 카운터가 증가하기 시작할 때까지 조정합니다(오른쪽 하단).

  • 슬라이더를 왼쪽으로 약간 드래그하여 더 이상 프레임이 드롭되지 않는 지점보다 조금 더 여유를 줍니다. 예를 들어, 38에서 프레임 드롭이 멈추면 35로 설정하세요.

프레임을 잃지 않으면서 프레임 레이트가 최대한 높은 속도를 찾으면 설정이 완료됩니다.

문제 해결

프레임 드롭 / 재생 시 “끊김” 현상

카메라에서 프레임 드롭이 발생하는 경우 컴퓨터의 USB 버스가 카메라의 대역폭 요구 사항을 처리하지 못할 수 있습니다.

카메라에서 프레임 드롭이 발생하지 않을 때까지 속도(픽셀 클록)를 낮춰 보세요.

전혀 초점을 맞출 수 없는 경우 (매우 흐릿한 이미지)

초점 조정 링을 사용하여 카메라의 초점을 전혀 맞출 수 없는 경우, 카메라와 렌즈 사이에 금속 링이 장착되어 있지 않은지 확인하세요.

금속 링은 CS-to-C 마운트 어댑터 링으로, 카메라와 렌즈 모두 CS 마운트인 경우에는 필요하지 않습니다.

Windows 10으로 업그레이드

Windows 업데이트를 통해 Windows 10으로 업그레이드할 때 알려진 문제가 있습니다. Windows 10으로 업그레이드 시 오류 또는 “블루 스크린"이 발생하면, “프로그램 및 기능"을 통해 IDS 소프트웨어를 먼저 제거해야 합니다. 그런 다음 업그레이드 후 다운로드 페이지에서 드라이버를 재설치하세요.
