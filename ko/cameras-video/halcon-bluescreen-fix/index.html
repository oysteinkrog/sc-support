Halcon USB 라이선스 동글 연결 시 컴퓨터 블루스크린 발생

Halcon 고객이 사용하는 라이선스 동글의 USB 드라이버에 문제가 있습니다. 이 동글은 녹색 USB “Flexera” 동글입니다.

Halcon 12에 포함된 드라이버는 Windows를 충돌시키고 블루스크린을 유발합니다.

블루스크린을 방지하려면 Halcon을 제거하거나 드라이버를 수동으로 제거하는 방법으로 기존 드라이버를 삭제하는 것을 권장합니다.

영향을 받는 환경:

  • Windows 10 Version 2004 Build >= 19041.423, 20H2, 21H1, 또는 21H2

  • Windows 11.

Halcon을 제거한 후 이 지원 문서의 새 드라이버 설치 방법에 따라 진행하실 것을 권장합니다.

Halcon 제거

  • 앱 추가 또는 제거를 엽니다.

  • 앱 및 기능에서 “halcon"을 검색합니다.

  • 목록에 나타난 항목을 클릭한 후 “제거” 및 “제거"를 클릭합니다.

  • “예"를 클릭하여 Halcon 제거를 진행하고, Halcon 제거 프로그램이 시작될 때까지 기다린 후 “제거"를 클릭하여 Halcon을 삭제합니다.

대안: Halcon USB 동글 드라이버 수동 제거

이 옵션은 컴퓨터를 재부팅하고 싶지 않거나 어떤 이유로 Halcon을 재설치하고 싶지 않을 때 사용할 수 있습니다. 대부분의 경우 “Halcon 제거” 옵션을 따르는 것이 더 좋습니다.

드라이버가 설치되면 다음 위치에 있는 Windows DriverStore 파일 저장소에 저장됩니다:

C:\Windows\System32\DriverStore\FileRepository

일반적으로 드라이버를 제거하려면 장치 관리자에서 장치를 제거하고 드라이버 삭제를 선택하면 되지만, USB 동글을 연결하면 Windows가 충돌하기 때문에 수동으로 제거해야 합니다. 새 드라이버를 설치하면 Windows가 적절한 (새) 드라이버를 자동으로 찾습니다.

pnputil을 사용하여 장치 드라이버 제거하는 방법

아래 지침에서 “따옴표"로 묶인 텍스트는 따옴표 없이 명령줄에 입력해야 합니다.

  • 명령 프롬프트를 엽니다.

  • 명령 프롬프트에서 “pnputil -e"를 입력하여 설치된 모든 드라이버를 나열합니다.

  • 출력 결과 앞부분에서 패키지 이름에 Sentinel HASP 또는 SafeNet이 포함된 드라이버를 찾습니다.

  • “pnputil /delete-driver drivername.inf /uninstall"을 실행하여 각 드라이버를 제거합니다.

  • 예를 들어 게시자 이름이 oem53.inf인 드라이버를 제거하려면 “pnputil /delete-driver oem53.inf /uninstall"을 입력하고 Enter 키를 누릅니다.

이 경우 pnputil의 출력은 업데이트된 드라이버가 설치된 정상 작동 시스템에서 가져온 것입니다(이전 드라이버의 스크린샷 없음).

정상 작동하지 않는 시스템에서는 유사한 드라이버가 나열되지만 드라이버 패키지 제공자가 다를 수 있습니다.

새 Halcon USB 라이선스 동글 드라이버 설치

아래 지침에서 “따옴표"로 묶인 텍스트는 따옴표 없이 명령줄에 입력해야 합니다.

  • 새 드라이버를 다운로드하고 압축을 풉니다. 다운로드한 zip 파일을 마우스 오른쪽 버튼으로 클릭하고 “모두 압축 풀기” 및 “압축 풀기"를 클릭합니다.

  • 명령 프롬프트를 엽니다(이전에 닫은 경우).

  • 압축을 푼 드라이버 폴더의 경로를 복사합니다(예: C:\Users\stian\Downloads\haspdinst_8.53).

  • 명령 프롬프트에서 “cd"를 입력하고 압축을 푼 드라이버 경로를 붙여넣습니다(예: “cd C:\Users\stian\Downloads\haspdinst_8.53”).

  • 명령 프롬프트에 “haspdinst.exe /install"을 입력한 후 Enter 키를 누릅니다.

  • 설치가 진행됩니다.
