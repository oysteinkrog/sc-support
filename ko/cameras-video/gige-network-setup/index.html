Swing Catalyst에서 GigE 카메라를 설정하는 방법

이 문서에서는 Swing Catalyst와 함께 사용할 GigE 카메라를 설정하는 방법을 설명합니다.

GigE Vision은 머신 비전 카메라를 위한 인터페이스 표준입니다. Swing Catalyst는 라이선스가 부여된 USB 동글을 통해 GigE Vision 표준을 지원합니다.

Swing Catalyst는 다양한 제조사의 기가비트 이더넷 카메라도 지원합니다.

  • Swing Catalyst 브랜드: Fox & Lynx.

  • FLIR (Spinnaker SDK).

  • AVT, IDS, Point Grey (레거시 / 구버전 SDK 통합).

  • 서드파티 라이선싱을 통한 기타 GigE Vision 카메라.

지원되는 카메라에 대한 자세한 내용은 다음 문서를 참조하십시오: supported-cameras.md

가장 정확한 권장 사항은 카메라 제조사의 셋업 문서를 참조하십시오.

이 문서는 다음 섹션으로 구성되어 있습니다:

네트워크 어댑터

  • 권장 어댑터

  • PoE 어댑터

  • 지원되지 않는 어댑터

네트워크 어댑터 구성

  • IP 주소 구성

  • 선택적 구성

  • 점보 프레임

  • 인터럽트 조절

  • 수신 버퍼

문제 해결

권장 사항

권장 네트워크 어댑터

GigE 카메라를 설정하고 설치하려면 컴퓨터에 하나 이상의 사용 가능한 네트워크 포트가 필요합니다. 올바른 유형의 PCIe 슬롯이 있는지 확인하십시오. 일반적으로 대부분의 듀얼 포트 카드는 1 x4 PCIe 슬롯이 필요합니다.

다음 네트워크 카드들은 제조사에 의해 테스트 및 검증되었으므로 사용을 권장합니다:

  • Intel Pro 1000 PT Dual Port (PCIe x4, 2포트)

  • Intel Pro 1000 PT Quad Port Low Profile (PCIe x4, 4포트)

  • Intel Pro 1000 PT (PCIe x1, 1포트)

  • Intel CT (PCIe x1, 1포트)

당사 웹샵에서 판매하는 네트워크 카드는 Intel을 사용하며 머신 비전 카메라와의 호환성이 검증되었습니다: https://shop-world.swingcatalyst.com/products/poe-dual-network-card

PoE 네트워크 카드

권장 모델:

  • Swing Catalyst 브랜드 듀얼 포트 또는 쿼드 포트 네트워크 카드 (PCIe 2x 또는 4x)

  • Adlink GIE72/74 듀얼 또는 쿼드 포트 카드

  • Adlink GIE64 쿼드 포트 카드 (PCIe x4, 4포트)

PoE 네트워크 카드는 컴퓨터 전원 공급 장치로부터 전력을 공급받아야 하므로, SATA to 4핀 Molex 커넥터 / 어댑터가 필요할 수 있습니다.

다른 기가비트 네트워크 카드를 사용하는 것도 가능하지만, 해당 카드가 점보 프레임 / 점보 패킷을 지원해야 한다는 점에 유의하십시오. 호환성을 위해 일반적으로 Intel 이외의 칩셋 사용은 권장하지 않습니다.

지원되지 않는 어댑터

다음은 문제가 발생한 적이 있어 일반적으로 사용을 권장하지 않는 네트워크 카드입니다:

  • Qualcomm Killer / Etherkiller e2200 네트워크 카드 시리즈.

  • Realtek 네트워크 카드

  • StarTech 네트워크 카드.

일부 Realtek 네트워크 어댑터는 인터럽트 조절 제어를 지원하지 않습니다.

경우에 따라 인터럽트 조절을 비활성화하면 드롭된 프레임 문제를 해결하는 데 도움이 될 수 있습니다.

네트워크 어댑터당 두 대 이상의 카메라 사용

현재 판매되는 카메라는 이전보다 프레임 레이트가 높고 훨씬 많은 대역폭을 사용하기 때문에 더 이상 이 방법을 권장하지 않습니다.

각 카메라마다 전용 네트워크 어댑터를 사용하는 것이 가장 좋습니다.

네트워크 어댑터 구성

네트워크 어댑터를 구성하려면 제어판 -> 네트워크 및 인터넷 -> 네트워크 및 공유 센터로 이동한 후 (왼쪽의) “어댑터 설정 변경"을 클릭하십시오.

  • 네트워크 카드가 “점보 프레임 (9K)“을 허용하도록 구성하십시오.

  • 드라이버를 설치하고 “필터” 드라이버 설치에 반드시 동의하십시오 (참고: 필터 드라이버는 카메라 제조사마다 다르므로, 사용 중인 카메라 유형에 맞는 드라이버를 설치하고 활성화해야 합니다).

  • 인터럽트 조절을 활성화하고 속도를 Extreme 또는 High로 설정하십시오.

  • 네트워크 카드에서 IPv4 및 필터 드라이버를 제외한 모든 네트워크 모듈을 비활성화하십시오.

구성 예시:

사용하지 않는 / 불필요한 항목을 선택 해제했습니다. 이는 필수 요구 사항은 아닙니다.

IP 주소 구성

최적의 안정성을 위해 카메라와 네트워크 어댑터 모두에 고정 IP 설정을 사용하는 것을 권장합니다.

각 네트워크 어댑터의 IP 주소를 변경하기 전에 먼저 카메라의 IP 주소를 설정하십시오. 예를 들어 페이스온 우측의 경우, 카메라가 고정 IP를 사용하도록 설정되어 있는지 확인하고 IP를 10.0.1.10으로 설정하십시오 (아래 권장 사항 참조). 카메라에 변경 사항을 저장한 후 네트워크 어댑터를 변경하십시오.

이 문서는 일반적인 내용을 다루고 있으므로, 카메라 IP 설정에 대한 구체적인 사항은 카메라별 전용 문서를 참조하십시오.

듀얼 포트 네트워크 카드에 연결된 두 대의 GigE 카메라에 대한 구성 예시:

네트워크 어댑터 1

-페이스온 우측 카메라에 연결됨.

어댑터 IP: 10.0.1.1 카메라 IP: 10.0.1.10 서브넷 마스크: 255.255.255.0

네트워크 어댑터 2

-다운더라인 카메라에 연결됨.

어댑터 IP: 10.0.2.1 카메라 IP: 10.0.2.10 서브넷 마스크: 255.255.255.0

선택 사항

불필요한 항목 선택 해제:

항목을 선택 해제한 경우 “OK"를 클릭한 후 다시 네트워크 어댑터 속성으로 돌아가십시오.

고급 네트워크 어댑터 구성

점보 프레임: 점보 패킷 / 점보 프레임을 활성화하고 9000바이트 이상의 값으로 설정하십시오.

인터럽트 조절: 사용 가능한 경우 High 또는 Extreme으로 설정하십시오.

수신 버퍼: 수신 버퍼를 최대값으로 설정하십시오.

문제 해결

드롭된 프레임

각 카메라의 프레임 레이트를 낮추면 드롭된 프레임을 방지하거나 줄이는 데 도움이 될 수 있습니다.

권장 네트워크 카드를 사용하고 계십니까? 그렇지 않은 경우 네트워크 카드 자체가 문제의 원인일 수 있습니다. 적절한 네트워크 장비를 갖추고 있는지 확인하려면 영업팀에 문의하십시오.

  • 잘못된 네트워크 카드 구성. 각 네트워크 어댑터에서 9kB 점보 프레임이 활성화되어 있는지 확인하십시오. 권장 구성에 대한 지원 문서 참조

  • 카메라를 2대 이상 사용하는 경우 GEV SCPD를 150으로 설정하십시오 (카메라 설정의 Device / Link 섹션 참조).

  • 링크 속도가 100Mbps가 아닌 1000Mbps인지 확인하십시오 (카메라 설정의 Device / Link 섹션에서 “Device Link Speed” 참조).

링크 속도가 100Mbps인 경우:

  • 링크 속도가 1000Mbps 대신 100Mbps인 경우 사용 중인 케이블이 불량이거나 손상되었거나, 네트워크 어댑터가 기가비트 속도를 지원하지 않을 수 있습니다. 케이블을 교체해 보십시오.

  • 카메라 설정을 기본값으로 초기화한 후 카메라 설정의 “Device / Link” 섹션에서 링크 속도를 다시 확인하십시오.

  • Windows 제어판에서 네트워크 어댑터 상태를 확인하십시오.

참고: 속도는 100Mbps가 아닌 1.0 Gbps (1000Mbps)여야 합니다.

Region of Interest (ROI)를 사용하여 드롭된 프레임 추가 감소:

Region of interest (또는 관심 영역)를 사용하면 전체 이미지 크기가 줄어들고 FPS가 향상되며, 대역폭 사용량을 낮춰 드롭된 프레임을 줄이는 데도 도움이 될 수 있습니다 (ROI 활용 방법은 위 내용 참조).

연결 문제 (카메라 연결 끊김):

  • 네트워크 케이블을 점검하십시오.

  • 카메라에 외부 전원 공급 장치를 사용하는 경우 전원 공급 장치 연결 상태를 확인하십시오.

기타 문제:

하드웨어에 따라 샤프닝 및 노이즈 제거 필터를 사용하는 것이 적합하지 않을 수 있으며, 이를 끄면 CPU 및 GPU 사용량이 줄어듭니다. 고급 카메라 설정의 필터 탭에서 카메라 필터를 찾을 수 있습니다. 필터에 대한 자세한 정보: improving-image-quality.md

점보 프레임 호환성

모든 네트워크 어댑터가 9KB 점보 프레임을 지원하는 것은 아닙니다. 네트워크 어댑터가 지원하는 가장 높은 점보 프레임 KB 크기를 사용하는 것이 좋지만, 일반적으로 퍼포먼스 향상을 위해 9KB를 지원하는 네트워크 어댑터를 사용하는 것이 가장 좋습니다.

예시:

-스위치를 통해 NIC에 연결된 여러 대의 카메라.

모든 네트워크 스위치가 9KB 점보 프레임을 지원하는 것은 아니며, NIC (네트워크 어댑터)가 9KB (또는 스위치가 처리할 수 있는 것보다 큰 패킷 크기)를 사용하도록 설정된 경우 패킷 손실이 발생합니다. 이로 인해 Swing Catalyst에서 프레임이 드롭됩니다.

많은 스위치가 점보 프레임을 지원하지만 (사양에 명시된 경우가 많음), 9KB 점보 프레임을 지원하지 않는 경우도 있으며, 장비가 최대 4KB까지만 지원하는 경우도 종종 있습니다.

예를 들어 4KB 점보 프레임만 지원하는 스위치에 카메라를 연결하고 네트워크 어댑터를 9KB 점보 프레임으로 설정하면 문제가 발생합니다.

명령줄 유틸리티 ping을 사용하여 네트워크 어댑터의 퍼포먼스를 테스트할 수 있습니다 (스크린샷 참조):

여기서는 9000바이트 (9KB)의 패킷 크기로 네트워크 어댑터에 ping을 보내고 있습니다. 요청이 시간 초과되면 9KB 점보 프레임을 지원하지 않을 가능성이 높습니다.
