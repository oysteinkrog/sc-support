Swing Catalyst와 Basler GigE 카메라 셋업 방법

이 지원 문서는 Swing Catalyst와 Basler 카메라의 셋업 및 구성 방법을 다룹니다.

note: Swing Catalyst와 Basler 카메라를 함께 사용하려면 Halcon USB 동글과 라이선스가 필요합니다. 라이선스 구매는 contact@swingcatalyst.com으로 문의하시기 바랍니다.

Halcon 설치 및 구성 방법은 아래를 참조하세요:

halcon-setup.md

중요:

MVTec Halcon 드라이버 필터가 설치되어 있는지 확인하세요. 해당 필터 없이는 카메라가 정상적으로 작동하지 않습니다. 또한 Basler 필터 드라이버 등 다른 필터 드라이버가 설치되어 있다면 체크를 해제하세요.

Swing Catalyst가 Windows Defender 방화벽에서 개인 네트워크 및 공용 네트워크 모두 허용되어 있는지 확인하세요.

example:

카메라 IP 설정

IP 셋업

각 카메라와 이더넷 카드(NIC / 네트워크 인터페이스 컨트롤러)는 서로 다른 서브넷(및 서브넷 마스크)에서 고정 IP로 구성해야 합니다.

note: NIC IP는 컴퓨터의 네트워크 어댑터 IP 주소이며, 카메라 IP는 카메라의 IP 주소입니다. …은 범위를 나타내며, 아래는 설정 가능한 IP의 예시입니다.

단일 또는 다중 카메라 셋업(네트워크 카드/어댑터가 하나 이상인 경우)의 예시:

네트워크 어댑터 1의 카메라:
nic ip: 10.0.1.1
cam ip: 10.0.1.10 ... 10.0.1.20
subnet mask:255.255.255.0

네트워크 어댑터 2의 카메라:
nic ip: 10.0.2.1
cam ip: 10.0.2.10 ... 10.0.2.20
subnet mask: 255.255.255.0

네트워크 어댑터 3의 카메라:
nic ip: 10.0.3.1
cam ip: 10.0.3.10 ... 10.0.3.20
subnet mask: 255.255.255.0

네트워크 어댑터 4의 카메라:
nic ip: 10.0.4.1
cam ip: 10.0.4.10 ... 10.0.4.20
subnet mask: 255.255.255.0

먼저 카메라의 IP를 셋업해야 합니다. 이 작업은 Pylon IP Configurator를 통해 수행합니다.

키보드에서 시작 메뉴 버튼을 누르고 pylon ip를 입력하면 IP Configurator가 나타납니다. 나타나지 않는다면 소프트웨어가 설치되지 않은 것입니다.

Pylon 소프트웨어 설치는 https://www.baslerweb.com/en/sales-support/downloads/software-downloads/를 방문하여 pylon 5.1.0 Camera Software Suite Windows를 찾으세요.

카메라를 클릭한 후 Static IP를 선택하세요.

위의 예시에 따라 카메라의 IP 주소와 서브넷 마스크를 설정하세요.

note: 카메라를 여러 대 사용하는 경우 각 카메라에 대해 동일한 작업을 수행해야 합니다.

Halcon을 통한 Basler GigE 카메라 구성

Swing Catalyst에서 설정 탭으로 이동한 후 카메라 항목으로 이동하세요.

고급(Advanced)을 클릭하세요.

  • 구성(Configuration) 탭으로 이동하세요.

  • GtlNumBuffers 체크박스를 활성화하고 값으로 200을 입력하세요.

Basler GigE 카메라 셋업:

노출, 셔터 속도 및 프레임 레이트 설정 방법을 살펴보겠습니다.

warning: Swing Catalyst에서 설정을 볼 수 없거나 오류가 발생하는 경우, Windows 방화벽 설정을 확인하세요. 방화벽을 일시적으로 끄고 방화벽이 Swing Catalyst의 카메라 접근을 차단하는지 확인해 보세요.

설정이 정상적으로 작동하고 스트리밍에 문제가 없다면, Windows Defender 방화벽에서 Swing Catalyst가 공용 네트워크 및 개인 네트워크 모두에서 허용되어 있는지 확인하세요.

AcquisitionTrigger 탭을 펼치고 최대(또는 그 이하의) 프레임 레이트를 입력한 후 Enable Acquisition Frame Rate를 클릭하세요. 이렇게 하면 프레임 레이트를 직접 설정할 수 있습니다. 참고: 프레임 레이트는 노출 값에 따라 제한될 수 있습니다.

노출 값 설정

실내 스튜디오와 같이 환경이 일정한 경우에는 수동 노출을 사용하는 것이 일반적으로 가장 좋습니다. 완전 Auto 노출은 프레임 레이트를 변경시켜 불안정한 영상을 초래할 수 있습니다. 이 경우 직접 제어할 수 있도록 Auto 노출을 사용하지 않습니다. 일반적으로 노출 시간은 2000(2ms) 미만으로 설정하는 것을 권장합니다.

Gain 값 설정

노출과 마찬가지로, 실내 조명처럼 환경이 일정한 경우에는 Gain을 수동으로 설정하는 것이 좋습니다. 노출이 높을수록 이미지가 더 거칠어지고, 낮은 Gain에 비해 동영상 인코딩 시간이 길어집니다.

수동 Gain을 설정하려면 Gain Auto를 Continuous에서 Off로 변경한 후, 재생을 일시 중지했다가 다시 재생하여 설정을 다시 로드하세요. Gain (Raw)의 숫자 값을 변경하여 Gain 값을 설정하세요.

이미지 크기, 관심 영역, Region of Interest 등 변경

경우에 따라 이미지 크기를 줄여 특정 영역에 집중하고 싶을 수 있습니다. 예를 들어 임팩트 순간의 클럽과 볼을 자세히 보고 싶은 경우입니다.

이는 AOI(Area of Interest)라고도 하는 관심 영역 또는 ROI(Region of Interest) 기능으로 수행할 수 있습니다. 이 기능으로 전체 이미지 크기를 줄이면 프레임 레이트를 높이는 효과도 있습니다.

카메라에 설정 저장

설정을 카메라에 저장하는 것이 중요합니다. 저장하지 않으면 구성한 모든 내용이 손실됩니다.

Default Set Selector와 Default Startup Set을 반드시 설정하세요. 선택할 수 있는 사용자 셋이 여러 가지 있으며, 이론적으로 각 셋에 서로 다른 설정을 저장할 수 있습니다. 예를 들어 “User Set 1"을 기본값으로 선택한 후 User Set Save를 눌러 현재 설정을 해당 프로필에 저장할 수 있습니다.
