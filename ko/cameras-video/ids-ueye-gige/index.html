IDS uEye GigE 카메라를 Swing Catalyst와 함께 사용하도록 셋업하는 방법

USB 카메라 셋업은 다음 문서를 참조하세요: ids-ueye-usb.md

참고: 이 문서는 다음 링크에서 제공되는 uEye 드라이버가 이미 설치되어 있다고 가정합니다: https://www.swingcatalyst.com/drivers

이 문서는 카메라와 네트워크 카드의 IP 주소 설정 방법을 다룹니다.

참고: SwingCatalyst는 IDS 카메라에 대한 IDS AOI(관심 영역)를 지원하지 않습니다.

호환 가능한 네트워크 어댑터 및 구성:

다음을 참조하세요: gige-network-setup.md

참고, 퍼포먼스에 중요: Intel 네트워크 카드를 사용하는 경우, Intel 드라이버를 다운로드하여 설치하세요. 이를 통해 Windows 드라이버에서는 사용할 수 없는 인터럽트 조절 속도(interrupt moderation rate) 설정 옵션을 이용할 수 있습니다.

IDS uEye GigE 카메라 셋업하기

단계:

진행하기 전에 IDS uEye 드라이버를 설치하세요. IDS Camera Manager 애플리케이션을 찾아 실행하세요 (C:\ProgramData\Microsoft\Windows\Start Menu\Programs\IDS 경로에서 찾을 수 있습니다).

IDS Camera Manager 애플리케이션:

애플리케이션 하단의 경고 메시지를 확인하세요. IP 주소가 잘못 설정되거나 카메라 펌웨어와 관련된 문제로 인해 여러 가지 경고가 표시될 수 있습니다.

예시:

참고, IP 주소 구성 및 권장 사항**

**

각 카메라마다 전용 네트워크 카드 또는 네트워크 인터페이스를 사용하는 것을 권장합니다. 단, IDS UI-3220 모델의 경우 네트워크 스위치를 사용하여 각 네트워크 포트에 카메라 두 대를 연결할 수 있습니다(네트워크 스위치 사용 항목 참조).

권장 IP 셋업:

각 카메라와 이더넷 카드(NIC라고도 함)는 서로 다른 서브넷의 고정 IP 및 서브넷 마스크로 구성해야 합니다.

예시:

네트워크 카드 1의 카메라: nic ip: 10.0.1.1 cam ip: 10.0.1.10 … 10.0.1.20 subnet mask:255.255.255.0

네트워크 카드 2의 카메라: nic ip: 10.0.2.1 (nic1과 다른 서브넷) cam ip: 10.0.2.10 … 10.0.2.20 (nic1과 다른 서브넷) subnet mask: 255.255.255.0

uEye 네트워크 서비스 활성화

참고: 서로 다른 제조사의 카메라를 혼용하는 경우, uEye 네트워크 서비스를 활성화하면 다른 제조사의 카메라 사용 시 문제가 발생할 수 있습니다.

ETH 네트워크 서비스를 클릭하세요.

구성할 네트워크 어댑터를 선택하세요 (이 경우 듀얼 포트 어댑터입니다)

네트워크 카드 그래픽이 회색으로 표시되는 것은 올바르게 셋업되지 않았기 때문입니다. 카메라가 네트워크에서 인식되려면 uEye 네트워크 서비스를 활성화해야 합니다.

위의 권장 사항에 따라 IP 주소와 서브넷 마스크를 설정한 후 uEye 네트워크 서비스 활성화를 클릭하고 변경 사항 적용을 클릭하세요 (이제 듀얼 포트 어댑터 중 하나에 고정 IP 주소가 설정되었습니다!).

자동 IP 셋업 (수동 IP 설정은 아래 참조)

자동 IP 셋업 구성을 사용하려면 자동 ETH 구성을 클릭하고 OK를 클릭하세요.

IDS Camera Manager가 네트워크 카드와 카메라의 IP 주소를 자동으로 설정합니다.

참고: 여러 대의 카메라를 사용할 경우 수동 IP 셋업을 권장합니다.

수동 IP 셋업

IDS Camera Manager로 돌아가면 카메라 목록이 표시됩니다. 이전에 네트워크 어댑터에 고정 IP 주소를 설정했으므로, 이제 네트워크 어댑터와 카메라가 서로 제대로 통신할 수 있도록 카메라의 고정 IP 주소를 설정해야 합니다.

다음과 같이 Expert Mode 체크박스를 선택하세요:

위의 빨간색 경고에 주의하세요.

수동 ETH 구성을 클릭하세요:

위 스크린샷에서 카메라의 IP 주소는 10.0.1.10으로 설정되어 있습니다 (네트워크 카드는 10.0.1.1). 위 스크린샷과 같이 입력하고 OK를 클릭하세요.

참고, 고정 IP 주소 설정이 필수는 아니지만 강력히 권장합니다. 자동 IP 구성은 동일한 IP 주소가 다른 곳에서 사용되는 등 IP 주소 충돌 문제를 일으킬 수 있습니다. 모든 스튜디오 설치 환경에서는 고정 셋업을 구성하는 것을 강력히 권장합니다.

다른 카메라 및 NIC에 대해서도 위의 권장 IP 구성에 따라 동일하게 반복하세요.

IDS uEye 카메라에 사용할 네트워크 어댑터 구성

카메라와 네트워크 카드 모두에 고정 IP 주소를 설정했다면, 이제 최적의 퍼포먼스를 위해 네트워크 어댑터를 구성하는 단계로 넘어갑니다.

제어판\네트워크 및 인터넷\네트워크 연결에서 구성할 어댑터를 더블 클릭하세요. 이 경우에는 이더넷 4, Intel (PRO/1000 PT 듀얼 포트)입니다.

구성할 네트워크 어댑터를 더블 클릭하세요.

고급 탭을 클릭하세요. 참고: 구성은 네트워크 어댑터와 드라이버에 따라 다르므로, 아래에 표시된 특정 설정 변경 방법은 네트워크 카드 문서를 참조하세요.

인터럽트 조절(Interrupt Moderation)이 활성화되어 있고 인터럽트 조절 속도(Interrupt Moderation Rate)가 Extreme으로 설정되어 있는지 확인하세요.

Extreme 옵션이 없으면 High로 설정하세요.

경우에 따라 높은 인터럽트 조절 속도가 작동하지 않을 때 인터럽트 조절을 끄면 도움이 될 수 있습니다. 그러나 권장 네트워크 카드를 사용하는 한 High 및 Extreme 옵션을 사용할 수 있어야 합니다. 인터럽트 조절 활성화는 특히 고해상도 및/또는 고 FPS 카메라에서 대량의 패킷을 처리할 때 CPU 사용량을 줄이는 데 매우 중요합니다.

인터럽트 조절 속도:

점보 패킷(Jumbo Packets) 지원 활성화 (9014 바이트로 설정):

수신 버퍼(Receive Buffers):

이 값을 최대한 높게 설정하는 것이 좋습니다. 이는 여러 대의 카메라 및/또는 고해상도 GigE 카메라 사용 시 프레임 손실을 방지하는 데 도움이 됩니다.

네트워크 스위치 사용:

네트워크 스위치를 사용하는 경우, 스위치가 9KB 점보 프레임을 지원하고 네트워크 어댑터도 9KB 점보 프레임을 사용하도록 구성되어 있어야 합니다. 단, 일부 스위치에서는 9KB 프레임 크기가 제대로 작동하지 않을 수 있으며, 이 경우 9KB에서 더 낮은 값으로 줄이고 셋업을 다시 테스트하는 것이 좋습니다.

Swing Catalyst에서 카메라 사용하기

위의 권장 사항에 따라 IP 주소와 네트워크 어댑터를 구성한 후 SwingCatalyst를 시작하면 카메라 목록에 카메라가 표시됩니다.

카메라 각도를 설정하고 카메라를 활성화한 후 구성(Configure)을 클릭하세요.

픽셀 클럭이 최대로 설정되어 있는지 확인하세요 (프레임이 손실되는 경우 낮추세요).

셔터 속도와 Gain을 설정하세요 (이 값은 요구 사항, 카메라 종류, 조명 조건에 따라 크게 달라질 수 있습니다).

IDS 카메라 문제 해결

IDS uEye GigE 카메라에서 프레임이 손실되거나 동기화 문제가 발생하는 경우 uEye Cockpit 유틸리티를 사용하세요.

라이브 비디오(Live Video)를 클릭하세요.

재생 아이콘을 클릭한 후 렌치 아이콘을 클릭하세요.

표시된 대역폭 사용량을 확인하세요. 카메라 탭에서 픽셀 클럭을 높이고 프레임 레이트(Freerun) 아래의 Max 체크박스를 선택한 후 노출 시간(셔터 속도)을 낮추세요.

카메라를 라이브 스트리밍으로 설정한 후 뷰 -> 퍼포먼스 개요(View -> Performance Overview)를 클릭하세요.

호스트 퍼포먼스 뷰는 안정성 문제 및 프레임 손실 문제를 해결하는 데 매우 유용합니다.

uEye Cockpit의 상태 표시줄을 사용하여 비디오 스트리밍 중 프레임 손실 또는 연결 문제를 확인하세요:

스크린샷에서와 같이 카메라 해상도, 수신된 프레임, 표시된 프레임, 실패한 프레임 및 재연결 시도 횟수:
