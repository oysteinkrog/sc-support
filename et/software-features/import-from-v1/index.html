Kuidas importida videoid V1-st

See artikkel kirjeldab, kuidas importida oma olemasolevat V1 teeki Swing Catalysti.

Kehtib

Swing Catalyst 4.6 ja uuemad versioonid.

Lahendus

  1. Klõpsake ülemises menüüs või kiirkäivitusmenüüs Kiige Uurija.

  1. Vajutage Kiige Uurija akna ülaosas olevat impordimenüü kirjet.

  1. Valige „Import V1 Database"

  1. Navigeerige kausta, kuhu teie V1 videod on salvestatud. Tavaliselt on see c:\v1_video. Valige fail nimega v1data.mdb

  1. Vajutage „Ava" ja import peaks algama. Palun olge kannatlik, kuni kiigud imporditakse. See võib võtta aega olenevalt andmebaasi suurusest.

Probleeme andmebaasi importimisel Swing Catalysti?

Veenduge, et teil on installitud Microsoft Access Database Engine 2010.

Kui ei ole, laadige alla ja installige 64-bitine või 32-bitine andmebaasimotor (olenevalt teie operatsioonisüsteemist) siit: http://www.microsoft.com/en-us/download/details.aspx?id=13255

Pärast installimist taaskäivitage arvuti ja proovige andmebaasi uuesti importida.

Võib olla vajalik käivitada SC 32-bitises režiimis. Kui nii on, saab seda teha käsuviiba abil järgmise käsuga: C:\Program Files\Initial Force\Swing Catalyst\bin>MotionCatalyst.x86.exe /p SwingCatalyst

Videoid ei impordita, import näib olevat takerdunud?

Kui olete V1-d kasutanud ilma ühtki salvestatud videot õpilasele määramata, ei sisalda teie V1 andmebaas tõenäoliselt ühtki õpilast.

Swing Catalyst otsib õpilasi ja kui teie andmebaasis õpilasi ei ole, ei impordita videoid kahjuks.

Sel juhul võtke palun lisaabi saamiseks ühendust toega.
