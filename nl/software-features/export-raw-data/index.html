Onbewerkte gegevens exporteren

Gegevens exporteren om weer te geven in een spreadsheet

Dit artikel behandelt het exporteren van onbewerkte gegevens van Swing Catalyst of Motion Catalyst als TSV-bestanden.

Let op: bestanden die worden geëxporteerd, afgezien van studentengegevens, zijn tabgescheiden. Zorg ervoor dat u tabbegrensde indeling selecteert in uw spreadsheetweergaver.

Looking to export student information? See this article.

There are several ways to export data, through the Explorer and from the stack. Both options allow the same functionality.

Exporting data from the Explorer

In the Explorer data can be exported by right clicking on a recording, selecting Export and choosing from the available options, or dragging the recording(s) to the Export List.

Menu selection

Function

Add recording to export list Adds the selected recording to the export list. Same as dragging the recording to the export list

Add session to export list Adds a whole session to the export list. Amount of recordings that appear in the export list

depend on how many recordings are in the session itself.

Export recording as raw data files Exports the selected recording with the raw data export options

Export session as raw data files Exports the whole session with raw data export options

Data Export selection

It’s possible to choose from a few different options when exporting data.

This article mainly focuses on raw data.

To export raw data, make sure to select “Raw Data” in the Export dialog.

Raw Data options

Please note that this functionality is still being improved on, currently a lot of options are bundled with “Raw data”.
