Keyboard shortcuts and Hotkeys

Swing Catalyst & Motion Catalyst supports a number of keyboard shortcuts.

This article details the keyboard shortcuts.

A keyboard shortcut can be just one keyboard press but also a combination of presses.

In this article shortcuts that are longer than just one keyboard press are strung together using + .

This does not mean you need to press + on the keyboard, but it indicates you need to press both (or more) buttons together.

Playback

Keyboard hotkey / shortcut Action

Space Toggle play / pause

Right Step one frame forward

Left Step one frame backward

Shift Right Step 5% of the duration forward

Shift Left Step 5% of the duration backward

Up Increase playback speed

Down Decrease playback speed

Bookmarks

Keyboard hotkey / shortcut Action / description

1,2 or 3 Go to position of bookmark(s) 1 to 3 of the recording open in View Port A

Alt + 1, 2 or 3 Go to position of bookmark(s) 1 to 3 of the recording open in View Port B

Ctrl + 1, 2 or 3 Set bookmark 1 to 3 in View Port A to current playback position

Ctrl + Alt 1, 2 or 3 Set bookmark 1 to 3 in View Port B to current playback position

Ctrl + Shift  1, 2 or 3 Synchronize on bookmark 1-3

Ctrl +B Lock / unlock bookmarks for editing

Drawing tools

Hotkey Action (enables the drawing tool)

C Circle

R **Rectangle **

V **Arrow **

L Line

A Angle

F Freehand

S Sway

E Eraser

H Hand

T Text

B Bucket (erase all)

Motion Capture

Hotkey Action

Shift+S Toggle hide skeleton

Shift+C Toggle hide center of mass symbol

Shift+A Toggle angle tool

Shift+L Toggle connect joint tool

Shift+T Toggle trace joint tool

Shift+M Toggle move joint tool

Other

Hotkey Action / description

Ctrl + O Open / close Explorer

Ctrl + Mouse Scroll Up Zoom in (video or data graph, depending on mouse focus

Ctrl + Mouse Scroll Down Zoom out (video or graph data, depending on mouse focus)

Alt + C Toggle capture mode (once you have selected a user)

Alt + A Open last recording in the stack in View Port a

Alt + B Open last recording in the stack in View Port B
