FlightScope'u Swing Catalyst ile Nasıl Kullanılır

Giriş

Bu destek makalesi, FlightScope fırlatma monitörünü Swing Catalyst ile nasıl kullanabileceğinizi açıklamaktadır. Swing Catalyst, yeni bir çekim kaydederken tüm FlightScope verilerini entegre edecek ve depolayacaktır. Entegrasyonu etkinleştirmek için FlightScope yazılımı, Swing Catalyst ile aynı anda çalışıyor olması gerekir.

Uygulanır

  • FlightScope fırlatma monitörüne sahip kullanıcılar.

Desteklenen modeller:

  • X1, X2, X2 elite & X3 serisi.

  • Xi & Xi+ serisi.

Kurulum

Swing Catalyst’in FlightScope’dan vuruş verilerini tanıması ve okuması için FlightScope yazılımında sunucu modunu etkinleştirmek gerekir.

  • FlightScope’u başlatın ve ana menüde “Advanced Settings” (Gelişmiş Ayarlar) düğmesine tıklayın. (FlightScope’un daha yeni sürümlerinde, menü çubuğunu açmak için klavyenizde ALT tuşuna basabilirsiniz).

  • Click the Advanced Settings button, located bottom right and a menu bar will show on the top of the screen.

  • Click Networking, and select Server from the list.

  • Verify that “Server Port” is set to 1248 and press Ok.

Note: The server name and server IP address may vary depending on if you’re connected via USB X2 (Ethernet for X2 Elite) and or WiFi. It should not be necessary to change this.

  • Go to Player Comparison or similar mode in FlightScope.

  • Make sure FlightScope is tracking and displaying shots.

  • Start Swing Catalyst and keep FlightScope running in the background.

  • Go to the Swing Catalyst Main Menu - Settings - Hardware and tick off “Enabled” under Launch Monitor.

If it says disconnected, make sure the FlightScope application is running and that the FlightScope unit is connected to the PC or WiFi network.

FlightScope should say, Server active, 1 clients. This means Swing Catalyst successfully has connected to the FlightScope.

 Known Issues

  • FlightScope is not shown as connected, even if FlightScope software is running and tracking shots and server mode is enabled.

  • Try restarting FlightScope and Swing Catalyst. Start FlightScope first.

  • Try setting server mode to None, then turn it back on again. See step 3.

  • FlightScope is displayed on the wrong screen.

  • To move FlightScope to another screen: Click on the FlightScope program, and move the mouse cursor to the other monitor. While leaving the mouse cursor on the desired screen, click the F11 button. FlightScope should now be running on the other screen.
