使用 Swing Catalyst 設定 Ximea USB3 Vision 攝影機

本支援文章說明如何搭配 Swing Catalyst 設定及配置 Ximea 攝影機。

note: 若要在 Swing Catalyst 中使用 Ximea 攝影機，您需要一個 Halcon USB 加密狗及授權。請聯繫 contact@swingcatalyst.com 購買授權。

Halcon 安裝與配置說明請參閱：

halcon-setup.md

韌體變更需求

您的 Ximea 攝影機可能需要進行韌體升級。此操作可透過 xiCOP 完成，xiCOP 已隨 Ximea API 一同提供。

請確認狀態，確保您擁有可用的 USB 3 主機控制器。

您可透過 xiCOP 工具將攝影機切換至 USB3 Vision，點擊「Switch Camera to USB3 Vision」即可變更裝置的韌體。

安裝通用 USB3 驅動程式

大多數 USB3 攝影機製造商的安裝程式都會附帶自家的驅動程式。若要在 Halcon 中使用符合 USB3 Vision 規範的攝影機，必須將驅動程式從 Ximea 的驅動程式更換為 WinUSB。

此操作需使用名為 Zadig 的工具（已隨 Swing Catalyst 通用攝影機支援壓縮檔一同提供）。開啟 Zadig，在「Options」下選取「List All Devices」並取消勾選「Ignore Hubs or Composite Parents」。找到攝影機後，點擊「Replace Driver」。

您需要在複合父裝置（composite parent）上更換驅動程式。視攝影機型號不同，其名稱可能有所差異。

不同的攝影機型號，相同的操作步驟。

現在攝影機應可在 Swing Catalyst 中顯示。

透過 Halcon 配置 Ximea USB 3 攝影機

在 Swing Catalyst 中，前往「Settings」頁籤，然後進入「Cameras」，在清單中找到您的 Ximea 攝影機，並點擊「Advanced」。

  • 前往「Configuration」頁籤。

  • 勾選「num_buffers」核取方塊，並將值設為 200。

設定 Ximea USB3 Vision 攝影機

讓我們來看看如何設定曝光、快門速度與幀速率。

點擊「Settings」頁籤，展開「AcquisitionControl」頁籤，然後輸入最大（或較低的）幀速率。接著可將「Acquisition Timing Mode」設定為「Frame rate」模式或「FreeRun」模式。「Frame rate」模式可讓您自訂幀速率，而「FreeRun」模式則會以可能達到的最高幀速率運行。

note: 幀速率可能受曝光值限制。

設定曝光值

對於靜態環境（例如室內攝影棚），通常最好使用手動曝光。全自動曝光可能導致幀速率改變，並造成影像不穩定。在此情況下，我們不使用自動曝光，以便自行控制。一般建議曝光時間低於 2000（2ms）。

設定 Gain 值

與曝光類似，在靜態或室內照明條件下，將 Gain 設為手動最為合適。Gain 越高，影像顆粒感越強，且影片編碼所需的時間也會比低 Gain 時更長。

變更影像尺寸

在某些情況下，您可能希望縮小影像範圍，以聚焦於影像的特定區域，例如在擊球時詳細觀察球桿與球的位置。

此操作可透過感興趣區域（即 AOI，也稱為 ROI、Region of Interest）來完成。使用此功能縮小整體影像尺寸，同時也可提升幀速率。
