如何在 Swing Catalyst 中設定 Basler GigE 攝影機

本支援文章說明如何在 Swing Catalyst 中設定與配置 Basler 攝影機。

note: 若要在 Swing Catalyst 中使用 Basler 攝影機，您需要 Halcon USB 加密狗及授權。請聯絡 contact@swingcatalyst.com 購買授權。

Halcon 安裝與配置說明請參閱：

halcon-setup.md

重要事項：

請確認已安裝 MVTec Halcon 驅動程式濾波器，若未安裝，攝影機將無法正常運作。同時請確認取消勾選其他已安裝的濾波器驅動程式，例如 Basler 濾波器驅動程式。

請確認 Swing Catalyst 在 Windows Defender 防火牆中已允許私人網路與公用網路的存取。

設定攝影機的 IP

IP 設定

每個攝影機和乙太網路卡（NIC／網路介面控制器）應設定為不同子網路（及子網路遮罩）上的靜態 IP。

note: NIC IP 是您電腦上網路介面卡的 IP 位址，cam ip 是攝影機的 IP 位址。「…」表示一個範圍，這只是您可以設定的 IP 範例。

單一或多攝影機設定（搭配一個或多個網路卡／介面卡）的範例：

Cameras on network adapter 1: nic ip: 10.0.1.1 cam ip: 10.0.1.10 … 10.0.1.20 subnet mask:255.255.255.0

Cameras on network adapter 2: nic ip: 10.0.2.1 cam ip: 10.0.2.10 … 10.0.2.20 subnet mask: 255.255.255.0

Cameras on network adapter 3: nic ip: 10.0.3.1 cam ip: 10.0.3.10 … 10.0.3.20 subnet mask: 255.255.255.0

Cameras on network adapter 4: nic ip: 10.0.4.1 cam ip: 10.0.4.10 … 10.0.4.20 subnet mask: 255.255.255.0

首先，我們需要設定攝影機的 IP，這可透過 Pylon IP Configurator 完成。

按下鍵盤上的開始功能表按鈕，輸入 pylon ip，IP Configurator 應該會出現。如果未出現，可能是您尚未安裝該軟體。

若要安裝 Pylon 軟體，請參閱：https://www.baslerweb.com/en/sales-support/downloads/software-downloads/，並搜尋：pylon 5.1.0 Camera Software Suite Windows。

設定 Basler GigE 攝影機：

讓我們來看看如何設定曝光時間、快門速度及幀速率。

NOTE: 如果您無法檢視設定，或在 Swing Catalyst 中出現錯誤，請檢查 Windows 防火牆設定。請嘗試關閉防火牆，以確認是否為防火牆封鎖了 Swing Catalyst 存取攝影機。

若設定正常且可順利串流，請確認 Swing Catalyst 在 Windows Defender 防火牆中已允許公用網路與私人網路的存取。

展開 AcquisitionTrigger 索引標籤，輸入最大（或更低）幀速率，然後點選「Enable Acquisition Frame Rate」。這將允許您自行定義幀速率。注意：幀速率可能受曝光值限制。

設定曝光值

對於靜態環境（例如室內工作室），通常最好使用手動曝光。全自動曝光可能導致幀速率改變，進而造成影像不穩定。在此情況下，我們不使用自動曝光，以便自行控制。一般建議曝光時間低於 2000（2ms）。

設定增益值

與曝光類似，在靜態／室內照明條件下，將增益設定為手動模式最為合適。曝光越高，影像顆粒感越強，且視訊編碼所需的時間也會比低增益時更長。

若要設定手動增益，請將 Gain Auto 從「Continuous」改為「Off」，然後暫停再播放播放功能以重新載入設定。透過修改 Gain（Raw）中的數值來設定增益值。

變更影像大小、感興趣區域、Region of Interest 及其他設定

在某些情況下，您可能希望縮小影像大小，以聚焦於視訊影像的特定區域，例如在擊球瞬間詳細檢視球桿與球的狀況。

這可透過感興趣區域（AOI）以及 ROI（Region of Interest）來實現。使用此功能縮小整體影像大小，同時也能提升幀速率。

將設定儲存至攝影機

將設定儲存至攝影機非常重要。若未執行此步驟，您所有的配置將會遺失。

請確認設定「Default Set Selector」與「Default Startup Set」。系統提供多種使用者設定組可供選擇，理論上您可以在每個設定組中儲存不同的設定。例如，您可以選擇「User Set 1」作為預設值，再點選「User Set Save」將目前的設定儲存至該設定檔。
