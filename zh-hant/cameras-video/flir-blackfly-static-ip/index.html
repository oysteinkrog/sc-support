如何為 FLIR Blackfly GigE 攝影機設定靜態 IP

簡介

本支援文章說明如何為 Blackfly（或 Blackfly S）GigE 攝影機設定靜態 IP 位址。一般使用情況下無需進行此設定，因為 Swing Catalyst 會自動處理 IP 配置。

需求

  • Spinview 應用程式（Spinnaker SDK 的一部分）。

  • Swing Catalyst。

  • 一台或多台 FLIR Blackfly（或 Blackfly S）GigE 攝影機。

安裝 Spinnaker

  • 下載並執行 Spinnaker 安裝程式。

  • 在 Spinnaker 安裝程式上按右鍵，以系統管理員身分執行。

  • 勾選「Camera Evaluation」並點擊「Next」。

  • 依照螢幕上的指示繼續完成安裝。

  • 安裝完成後，重新啟動電腦。

在乙太網路介面卡上設定靜態 IP

每個攝影機和網路介面卡必須擁有各自唯一的靜態 IP 位址。例如，若您為攝影機指定靜態 IP 位址，請確保網路介面卡依照下方「建議靜態 IP 配置」對照表，設定對應的 IP 位址。

警告

請根據所對應的攝影機來設定網路介面卡，而非依介面卡編號。僅針對已識別的攝影機變更設定，其他介面卡保持不變。若將攝影機連接至不同的介面卡，則必須重新設定才能正常使用。

在控制台中，前往「網路和網際網路」，再進入「網路和共用中心」，然後點擊「變更介面卡設定」。

此處可看到電腦上所有網路介面卡的清單。在本例中，我們希望設定裝置名稱為「Intel Pro/1000」的「Ethernet 2」和「Ethernet 3」。請務必只設定用於攝影機的網路介面卡，避免影響其他介面卡的網際網路連線。

在您要修改的網路介面卡上按右鍵，點擊「內容」，然後向下捲動至「網際網路通訊協定第 4 版 (TCP/IPv4)」並點擊「內容」。

  • 選取「使用下列 IP 位址」。

  • 輸入下方建議靜態 IP 配置對照表中的 IP 位址。

  • 輸入子網路遮罩 255.255.255.0。

  • 選取「使用下列 DNS 伺服器位址」，可留空不填。

  • 點擊「OK」。

建議靜態 IP 配置

2 10.0.2.1 255.255.255.0 10.0.2.1 2 10.0.2.10
3 10.0.3.1 255.255.255.0 10.0.3.1 3 10.0.3.10
4 10.0.4.1 255.255.255.0 10.0.4.1 4 10.0.4.10

閘道可同時在攝影機上設定。

在攝影機上設定靜態 IP

請對每台需要設定靜態 IP 的攝影機重複以下步驟。若要進入攝影機 IP 配置，請開啟 SpinView 應用程式，並在您要設定 IP 的攝影機上按右鍵。

  • 在裝置清單中的攝影機上按右鍵，選取「GigE Configuration」。

  • 點擊「IP Configuration」。

依照下方建議 IP 配置對照表輸入 IP 位址和子網路遮罩。

  • 輸入攝影機的 IP 位址，使用對照表中的 IP 位址，例如攝影機 1 的對應位址。

  • 輸入子網路遮罩，例如：255.255.255.0。

  • 預設閘道可留空，或使用攝影機所連接之網路介面卡的 IP 位址。

  • 取消勾選 DHCP。

  • 點擊「Set Current and Persistent IP Configuration」。

攝影機建議靜態 IP 配置

攝影機編號 IP 子網路遮罩 閘道
1 10.0.1.10 255.255.255.0 10.0.1.1
2 10.0.2.10 255.255.255.0 10.0.2.1
3 10.0.3.10 255.255.255.0 10.0.3.1
4 10.0.4.10 255.255.255.0 10.0.4.1

閘道 IP 為攝影機所連接之網路介面卡的 IP 位址。

例如，攝影機 1 連接至網路介面卡 1。

使用 SpinView 啟用巨型幀並優化攝影機的網路介面卡

請注意，以下變更須對所有連接攝影機的網路介面卡執行。

  • 在 SpinView 中，於攝影機上按右鍵，選取「GigE Configuration」。

  • 點擊「Configure Adapter Properties」。

  • 出現提示時點擊「Yes」。

  • 點擊「Next」。

  • 點擊「Auto Fill All」。

  • 點擊「Next」。

  • 勾選「Enable Media Optimization」。

  • 點擊「Next」。

  • 點擊「Configure」以套用變更。
