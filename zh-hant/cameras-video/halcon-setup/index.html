如何設定 Halcon 以搭配 Swing Catalyst 使用

Swing Catalyst 6.0 的發布帶來了對三種最常見機器視覺標準的支援。

  USB3 Vision                      GigE Vision                             GENiCAM

開始之前

本文主要涵蓋 Halcon 的安裝、授權的安裝，以及 Ximea USB3 相機的基本設定。我們無法保證與較新版本的相容性，且 Swing Catalyst 僅支援 Halcon 12。

如需瞭解如何確認您的相機是否支援 Halcon，請參閱：如何確認您的相機支援哪些標準以搭配 Halcon 使用。

警告

Swing Catalyst 僅支援 HALCON 第 12 版。

  • Halcon 12 支援：GenAPI v2.4.1。

USB 授權狗驅動程式與 Windows 10 及 11 不相容！

安裝 Halcon 時，請務必取消勾選「Install Driver for USB Dongles」，否則您的電腦將在啟動時當機。

有關如何安裝新 USB 驅動程式的詳細資訊，請參閱我們的支援文章：

  • 連接 Halcon USB 授權狗時電腦出現藍色畫面

在安裝 Halcon 後，請參閱針對您相機的專屬文章，以便在 Swing Catalyst 中進行設定及廠商特定配置。

硬體需求：

  • 通用相機支援加密狗或鎖定至網路卡的授權。

  • 符合 USB3 Vision、GigE Vision 或 GenICam 標準的相機。

  • 用於授權加密狗的備用 USB 連接埠。

請確保您的硬體符合製造商的建議規格。

Note: 製造商特定的相機設定可在本文底部找到。

軟體需求

  • Halcon 授權檔案。您應已透過電子郵件收到此檔案。

  • 請確保已安裝最新版本的 Halcon；若在 Swing Catalyst 中出現警告，請聯絡支援人員以取得協助。

安裝 Halcon

  • Halcon 執行環境可在我們的下載頁面找到，或直接從此處下載。

  • 下載完成後，在檔案上按右鍵並點選「解壓縮全部」。

  • 開啟解壓縮後的資料夾並執行安裝程式。

  • 開啟安裝程式，依照畫面上的指示及以下逐步說明進行操作。

  • 選取「Install x64 version」。

  • 在「Choose Components」中，您可以取消勾選所有元件，僅保留「Runtime x64」。

  • 在「Additional Drivers」區段，請務必取消勾選「Install driver for USB dongles」，這一點非常重要。

  • 若您使用 GigE 相機，請確保勾選「Install MVTec GigE Vision Streaming Filter」。

  • 安裝授權檔案時，選取「I have a license file that should be installed」，並指向您從銷售或支援人員收到的授權檔案。

  • 依照畫面上的指示繼續操作。

警告：若使用 Windows 10 或 11，請取消勾選「Install driver for USB dongles」

請務必安裝 GigE Vision 濾波器（注意： 若您使用 GigE 相機，此為必要步驟）。

找到您透過電子郵件收到的 license.dat 檔案，然後點選下一步。

完成安裝。若提示需要重新開機，請點選「是」。
