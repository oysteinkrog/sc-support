如何在 Swing Catalyst 中使用 IDS uEye USB 相機

簡介

本支援文章說明如何設定和使用 IDS uEye USB 相機的實際操作細節。

點擊此處 查看安裝詳情

若需使用 GigE（網路 IDS 相機），請參閱此文章：ids-ueye-gige.md

適用範圍

  • 開始使用 IDS uEye USB 相機與 Swing Catalyst。

相機說明

uEye USB 相機由三個獨立元件組成：

  • 相機本體

  • 鏡頭

  • USB 線材

相機

相機本體沒有任何實體調整功能，所有設定均透過軟體控制。

鏡頭

隨附的鏡頭有 3 個調整環，從相機端由內而外依序為：

  • 變焦

  • Iris

  • 對焦

變焦／對焦

在可變焦（變焦）鏡頭上，變焦環與對焦環需相互配合，因此同時微調這兩個調整環有助於達到良好的對焦與縮放效果。

Iris

Iris 調整環決定進光量（即「開口大小」）。

縮小 Iris 會使影像變暗，但可藉由增加景深（「對焦」範圍）來提升對焦效果。

若影像曝光過度（例如在非常晴朗的戶外），建議縮小 Iris。

軟體設定

在 SwingCatalyst 中，所有相機設定均可透過「相機設定」中的「進階」按鈕進行調整，該選項位於主選單的「設定 - 相機」下。

點擊「進階」按鈕後，進階相機設定對話框將會顯示。

對於 uEye 相機，有幾項重要設定可決定相機的關鍵特性：

像素時脈

像素時脈本質上是一個「速度」設定，提高此值將增加可用的最大幀速率，但若設定過高可能導致掉幀。

幀速率

幀速率設定支援自動與手動兩種配置方式。

建議使用手動設定，因為自動模式會停用其他自動功能，例如自動 Gain。

曝光快門

低快門速度對於捕捉快速動作並減少動態模糊至關重要。

對於高爾夫揮桿，建議最大曝光時間不超過 2ms（毫秒），以獲得清晰的影像。

若需非常銳利的影像，曝光設定 0.5ms 是個好選擇，但需要充足的光源，僅建議於戶外使用。

可將曝光快門設為自動模式，並透過「Max」自動參數設定上限，此選項可讓相機在不同光線條件下自動調整，同時維持良好的影像品質。

Gain

Gain 可提升影像亮度，但同時也會在影像中引入更多雜訊。

在大多數情況下，建議使用自動 Gain，讓相機自行調整。

白平衡

建議將白平衡設為 Auto，以讓相機自動調整影像的色彩平衡。

若影像中的色彩顯示不正確，請使用手動設定來微調紅、綠、藍參數。

最大化每秒幀數 (FPS)

您的最大 FPS 會因電腦規格而有所不同。當發生掉幀時，表示系統無法處理所有資料，需要降低速度。

以下是幫助您最大化相機性能的逐步操作程序。

  • 前往主選單 -> 設定 -> 相機。

  • 點擊 uEye 相機上的「進階」按鈕。

  • 在進階設定對話框中，切換至「相機」索引標籤。

  • 點擊影片預覽面板中的「播放」按鈕以開始串流即時影像。

  • 將「速度（像素時脈）」滑桿向右拖曳，直到您看到掉幀計數器開始增加（右下角）。

  • 將滑桿稍微向左拖曳，直到不再發生掉幀，並留有一定餘裕。例如，若您發現在 38 時停止掉幀，則將其設定為 35。

一旦找到在不丟失幀的情況下幀速率盡可能高的速度，即完成設定。

疑難排解

掉幀／播放時影像「不穩定」

若相機發生掉幀，可能是電腦的 USB 匯流排無法滿足相機的頻寬需求。

請嘗試降低速度（像素時脈），直到相機不再掉幀。

完全無法對焦（影像非常模糊）

若您完全無法對焦相機（使用對焦調整環），請確認相機與鏡頭之間是否裝有金屬環。

該金屬環為 CS 轉 C 接環轉接環，當相機與鏡頭均為 CS 接環時，不需要使用此轉接環。

升級至 Windows 10

請注意，使用 Windows 更新升級至 Windows 10 時存在已知問題。若您在嘗試升級至 Windows 10 時遇到錯誤或「藍色螢幕」，您需要先透過「程式和功能」解除安裝 IDS 軟體，然後在升級完成後從我們的下載頁面重新安裝驅動程式。
