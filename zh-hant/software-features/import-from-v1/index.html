如何從 V1 匯入影片

本文說明如何將您現有的 V1 資料庫匯入 Swing Catalyst。

適用範圍

Swing Catalyst 4.6 及更新版本。

解決方案

  1. 從頂部選單或快速啟動選單點擊「Swing 檔案總管」。

  1. 按下「Swing 檔案總管」視窗頂部的匯入選單項目。

  1. 選擇「Import V1 Database」

  1. 瀏覽至儲存 V1 影片的資料夾，通常為 c:\v1_video。選擇名為 v1data.mdb 的檔案。

  1. 按下「開啟」，匯入即會開始。匯入揮桿資料時請耐心等候，所需時間可能因資料庫大小而有所不同。

匯入資料庫至 Swing Catalyst 時遇到問題？

請確認您已安裝 Microsoft Access Database Engine 2010。

若尚未安裝，請依您的作業系統從以下連結下載並安裝 64 位元或 32 位元的資料庫引擎：http://www.microsoft.com/en-us/download/details.aspx?id=13255

安裝完成後，請重新啟動電腦，然後再次嘗試匯入資料庫。

可能需要以 32 位元模式執行 SC。若有此需要，可透過命令提示字元使用以下指令來完成：C:\Program Files\Initial Force\Swing Catalyst\bin>MotionCatalyst.x86.exe /p SwingCatalyst

沒有影片被匯入，匯入似乎停止回應？

如果您在使用 V1 時未將任何已儲存的影片指定給學生，則您的 V1 資料庫很可能不包含任何學生資料。

Swing Catalyst 會搜尋學生資料，若您的資料庫中沒有任何學生，很遺憾地將無法匯入您的影片。

若發生此情況，請聯繫客服以獲得進一步協助。
