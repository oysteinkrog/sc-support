Swing Catalyst 動作擷取 (MoCap) 常見問題

問：什麼是 Swing Catalyst 動作擷取？

答：Swing Catalyst 動作擷取 (MoCap) 是一種無標記點的 2D動作捕捉技術，透過攝影機與 AI 演算法分析高爾夫動作，無需任何實體標記點或感測器。

問：主要功能有哪些？

答：Swing Catalyst 動作擷取提供以下功能：

  • 智慧人體偵測

  • 精確的 2D姿態估計，最多可偵測 26 個關鍵點

  • 近即時姿態視覺化，延遲極低

  • 帶有關節標記點的骨骼疊加顯示

  • CoM（質量中心）視覺化

  • 關節角度測量

  • 自訂關節對關節連線視覺化

  • 特定關節的動作軌跡追蹤

問：系統需求為何？

  • 有效的 Swing Catalyst Pro 或 Pro+ 訂閱（版本 25.1 及更新版本）

  • 符合建議規格的相容電腦

  • 一台或多台支援的攝影機

問：此功能在哪個版本中提供？

答：Swing Catalyst 動作擷取功能於版本 25.1 中提供。

問：支援哪些攝影機配置？

  • 最多支援 4 台攝影機同時使用（不含俯視角度）

  • 相容角度：

正面右側角度

  • 正面左側角度

  • 球道線視角

  • 注意：不支援俯視角度及自由角度

問：建議使用哪些顯示卡？

答：針對多攝影機或高 FPS 設定：

  • 較新一代且擁有更多 VRAM（8-12GB 或更多）的 NVIDIA 顯示卡通常能提供更佳性能，尤其是在使用 TensorRT 或 CUDA 搭配較大批次大小時。以下列出的 GPU 型號亦包含 NVIDIA 的 Ti、Ti Super 及 Super 變體。

  • NVIDIA RTX 3070、3080、3090

  • NVIDIA RTX 4060、4070、4080、4090

  • NVIDIA RTX 5060、5070、5080、5090（不支援 Swing Catalyst 25.1，僅支援 25.2）

問：建議的設定為何？

  • 執行提供者優先順序（NVIDIA）：TensorRT → CUDA → DirectML

  • AMD 或 Intel GPU 使用者請使用 DirectML

  • 批次大小：取決於攝影機數量及電腦的獨立 GPU 記憶體，請參閱我們的支援文章

  • 可選優化項目：

啟用 Nano 偵測模型（若非預設值）

  • FP16 可進一步提升性能（此選項會降低模型精確度，目前僅適用於 TensorRT）

問：如何優化攝影機設定以獲得最佳效果？

  • 完成相機校準流程

  • 確保適當的攝影機對齊與定位（例如：確保受試者置中，且攝影機保持水平）

  • 維持一致且分佈均勻的照明

問：若錄製處理速度緩慢，應該怎麼做？

  • 確認執行提供者的選擇（建議 NVIDIA 顯示卡使用 TensorRT）

  • 初次 TensorRT 優化可能需要數分鐘；後續錄製將會更快

  • 考慮啟用 Nano 偵測模型 以提升性能

問：是否有任何限制？

答：有的。一般而言，快速動作與複雜姿態偶爾可能導致追蹤錯誤。此功能目前仍持續開發中，相關規格可能有所變動。

問：如何啟用 MoCap？

  • 確認您的軟體已是最新版本（版本 25.1 或更新版本）

  • 在頂部選單列中找到 MoCap 按鈕

  • 點擊以切換功能開啟/關閉

  • 注意：MoCap 功能可在捕捉或播放模式下獨立開啟/關閉。

如需更多資訊，請參閱我們的使用者指南。

問：支援哪些攝影機？

答：所有 Swing Catalyst 支援的即時串流攝影機均可使用。請參閱我們的支援攝影機文章。

問：處理時間大約需要多久？

答：處理時間在很大程度上取決於硬體配置。

顯示卡類型、批次大小、執行提供者等因素都會對處理速度產生顯著影響。啟用 MoCap 後，我們估計錄製的處理時間（從觸發錄製到可開啟檔案的時間）將比未啟用時增加約 30-50%。

若您需要連續進行大量錄製，可先關閉 MoCap 進行錄製，待稍後開啟錄製檔案時再開啟 MoCap，然後執行重新處理步驟。

問：雖然 MoCap 已啟用且骨骼檢視已開啟，但骨骼卻不顯示、閃爍或偶爾消失。

答：在此情況下，很可能是人體偵測失敗所致。

  • 嘗試切換捕捉模式的開啟/關閉

  • 嘗試切換 MoCap 的關閉/開啟

  • 嘗試將偵測模型從 Nano 更改為 Medium，詳情請參閱我們的設定說明

  • 確認您的攝影機已依照我們的建議正確設定
