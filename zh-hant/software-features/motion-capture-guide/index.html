Swing Catalyst 動作擷取（MoCap）指南

簡介

Swing Catalyst 動作擷取（MoCap）是一套功能強大的 2D 無標記動作擷取系統，專為提升您的高爾夫揮桿分析而設計。此功能提供近即時追蹤、動作分析及進階視覺化工具，協助您改善球技。

注意： 動作擷取功能可能並非適用於所有授權類型。請參閱我們的 常見問題 以獲取更多資訊。

系統需求

必要元件：

  • 有效的 Swing Catalyst Pro 或 Pro+ 授權

  • Swing Catalyst 版本 25.1 或更新版本

  • 已在元件目錄中安裝所需元件

  • 符合我們建議規格的相容電腦

  • 一部或多部相容攝影機

初始設定與配置

建議設定步驟：

  • 依照我們的安裝指南安裝所需元件

  • 使用我們的詳細設定指南進行配置

  • 確保攝影機位置擺放正確（請參閱下方影片）

  • 執行自動鏡頭校準以達到最佳精確度，並降低鏡頭畸變的影響

影響精確度的因素

重要注意事項

攝影機品質與設定 高解析度、穩定的影像對於精確追蹤至關重要。請避免使用低品質或不穩定的攝影機設定。

光線條件 確保光線均勻且分布良好。避免燈光閃爍及強烈陰影。

最佳攝影機角度 以下角度可獲得最佳效果：

正面右側角度

  • 正面左側角度

  • 球道線視角（需有適當照明）

請注意以下情況：

  • 當身體部位被遮擋，或啟用 TensorRT 的 FP16 時，精確度可能降低。

  • DLP 投影機或閃爍燈光可能對精確度造成不良影響，尤其是在球道線視角下，請參閱我們關於如何降低閃爍影響的文章

開始使用

啟用動作擷取

在繼續操作之前，請確認您已遵循建議的設定步驟並安裝了所需元件。

  • 在頂部工具列找到 MoCap 按鈕

  • 點擊以切換功能為開啟狀態。

  • 開啟骨骼檢視以確認功能正常運作。

MoCap 工具列功能

檢視控制

  • 切換骨骼疊加的顯示狀態

  • 顯示/隱藏質量中心（COM）標記點

分析工具

標記點角度工具 透過選取特定標記點來測量並顯示關節角度

標記點軌跡工具 追蹤並視覺化所選點的動作路徑

直線工具 在任意兩個標記點之間建立參考線以進行平面分析

清除工具 移除所有作用中的測量結果與視覺化內容

視覺化範例

可點擊的關鍵點： 將滑鼠懸停於關鍵點上時，會以白色指示標誌加以識別。

質量中心追蹤： 隱藏骨骼後單獨顯示 CoM 標記點

關節角度分析： 搭配骨骼疊加的即時角度測量

動作追蹤： 腕部動作路徑視覺化

平面分析： 用於動作研究的自訂參考線

為現有錄製新增動作擷取

若您有現有錄製但缺少動作擷取資料，可依照以下步驟為其補充執行 MoCap 分析：

  • 在檔案總管中找到您希望新增 MoCap 的錄製並開啟

  • 點擊分析選單上的動作擷取按鈕以展開下拉選單

  • 點擊「Process MoCap」按鈕

請注意，執行動作擷取分析可能需要數分鐘，尤其是第一次執行時，因為 SwingCatalyst 需要載入所需的動作擷取資料模型。在此期間，不建議退出分析模式或開始捕捉，因為處理過程需要大量硬體資源，並會對 GPU（顯示卡）造成負擔。此期間性能可能會受到影響。

  • 模型載入完成後，實際分析程序將開始執行，並會顯示進度列以呈現目前的分析進度。

  • 若您希望取消 MoCap 處理，請點擊 MoCap 下拉選單中的「Cancel」按鈕。請注意，當 SwingCatalyst 正在載入 MoCap 模型時，此按鈕不可用，因為該程序無法取消。

  • 處理完成後，畫面頂部將顯示訊息提示，且目前開啟的錄製將自動啟用動作擷取功能。

  • 若您希望日後重新執行動作擷取分析，例如使用不同的動作擷取設定（可在：設定 -> 影像與捕捉 中調整），可在分析模式下開啟該錄製時，點擊 MoCap 下拉選單中的「Reprocess MoCap」按鈕。

疑難排解

若您在使用 Swing Catalyst 動作擷取（MoCap）系統時遇到問題，請參考以下常見問題及其解決方案：

1. MoCap 功能不可用

問題：動作擷取功能無法存取。

解決方案：

授權驗證：請確認您擁有有效的 Swing Catalyst Pro 或 Pro+ 訂閱，因為 MoCap 需要這些授權類型。

軟體版本：確認您的 Swing Catalyst 軟體已更新至版本 25.1 或更新版本，該版本包含 MoCap 功能。

2. 處理速度緩慢

問題：啟用 MoCap 後，錄製處理時間比預期更長。

解決方案：

執行提供者：為您的硬體選擇最佳的執行提供者。

對於 NVIDIA GPU，建議使用 TensorRT 以獲得最佳性能。

  • 嘗試為 TensorRT 啟用 FP16（但請注意精確度可能會降低）。

批次大小：在 MoCap 設定中調整批次大小。批次大小 32 為最佳值，但若遇到記憶體問題，可考慮降低批次大小。

硬體規格：確認您的系統符合建議規格，尤其是 GPU 需求。升級至更強大的 GPU 可提升處理速度。

3. 骨骼不顯示

問題：錄製期間骨骼疊加未出現。

解決方案：

人物偵測：人物偵測可能失敗。請嘗試關閉再開啟捕捉模式，或停用後重新啟用 MoCap。

偵測模型：若正在使用 Nano 偵測模型，請切換至 Medium 模型以提升精確度。進行此變更後請重新啟動 SwingCatalyst。

攝影機設定：確保攝影機依照建議指南正確定位並完成校準。適當的攝影機設定對於精確的人物偵測至關重要。

4. 動作擷取資料不準確

問題：擷取的動作資料不準確或不一致。

解決方案：

光線條件：在錄製區域維持均勻且分布良好的光線。避免燈光閃爍及強烈陰影，因為這些情況會影響偵測精確度。

攝影機品質：確保攝影機在錄製期間不會移動，因為移動可能導致追蹤效果不佳。請重新檢視您的取景方式，確認攝影機位置及鏡頭設定是否正確。

執行提供者設定：若您已啟用 TensorRT 並勾選「FP16 for TensorRT」，請考慮取消勾選，以確認精確度是否有所改善。

  • 若不準確的情況持續發生，請考慮向我們提交支援工單。

5. 動作擷取處理失敗

問題：處理失敗

解決方案：

執行提供者： 嘗試更換執行提供者。DirectML 具有最佳相容性。

記憶體消耗： 請確認您未耗盡記憶體。

開啟 Windows 工作管理員並前往性能索引標籤。

  • 監控記憶體使用量及 GPU 記憶體使用量，以確認是否即將耗盡記憶體。

  • 若記憶體不足，請嘗試使用較低的批次大小，或若您正在使用 TensorRT 執行提供者，可嘗試啟用「FP16 for TensorRT」。

電腦規格： 您的電腦是否符合執行 MoCap 的最低需求？

降低攝影機幀速率： 降低幀速率可減少需處理的幀數，從而降低系統負擔。

關閉 MoCap： 嘗試關閉 MoCap 功能，以確認錯誤是否與 MoCap 功能本身無關。
