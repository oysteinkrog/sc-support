額狀平面扭矩分析 - 使用者指南

簡介

什麼是額狀平面扭矩？

額狀平面扭矩（FPT）測量您在高爾夫揮桿過程中，身體圍繞額狀平面軸所產生的旋轉力。可以將其理解為測量您利用地面反作用力產生旋轉動力的效率。

當您揮動高爾夫球桿時，雙腳向地面施力，地面同時向上反推。您身體的質量中心與腳部所受力量之間的相互作用，產生了扭矩——一種有助於驅動揮桿的旋轉力。

功能組成

FPT 功能包含兩個主要組成部分：

FPT 圖表（DataBox） - 一個時間序列圖表，顯示整個揮桿過程中的扭矩數值及關鍵指標

3D 視覺化 - 在動作擷取骨骼檢視上即時疊加力臂與力分解的視覺效果

為什麼這很重要？

了解您的額狀平面扭矩可以幫助您：

識別動力產生模式 - 了解您將地面力量轉化為旋轉能量的效率

視覺化生物力學槓桿 - 在 3D 中查看質量中心與地面力量之間的力臂關係

分析計時 - 了解峰值扭矩相對於擊球時機的發生時間

分解力的組成 - 查看地面反作用力如何分布於不同方向

比較揮桿 - 追蹤您在力量產生方面的變化

前置條件

若要使用額狀平面扭矩分析，您需要：

必要條件：含地面反作用力數據的力量板錄製

必要條件：用於質量中心追蹤的 MoCap 數據

必要條件：已完成相機校準的設置

必要條件：體重測量數據（用於標準化數值）

快速入門

將 FPT DataBox 加入您的版面配置

  • 在分析檢視中開啟已錄製的揮桿

  • 點擊 DataBox 選單或版面配置編輯器

  • 在可用的 DataBox 清單中找到額狀平面扭矩

  • 將其加入您的分析版面配置

  • DataBox 將自動從您的錄製中填入數據

啟用 3D 視覺化

力臂與力分解的視覺效果會在 3D 影像檢視區中與骨骼一同顯示。若要啟用：

  • 開啟包含 MoCap 與力量板數據的錄製

  • 在影像檢視中找到力向量設定面板

  • 啟用您想查看的視覺化選項

所需數據

若要讓 FPT 分析正常運作，您的錄製必須包含：

數據類型是否必要用途
力量板數據是提供地面反作用力（Fx、Fz）及壓力中心
MoCap是提供質量中心位置，用於扭矩計算及 3D 視覺化
體重是用於標準化扭矩數值以便比較
相機校準是確保正確的 3D 對齊所需
擊球書籤建議啟用相對於擊球接觸的計時指標

了解顯示內容

圖表

主圖表顯示隨時間變化的扭矩數值：

X軸（水平）：從揮桿開始到完成位置的時間

Y軸（垂直）：扭矩數值（可顯示百分比及/或絕對值）

零線：位於零點的水平線——高於與低於零線的數值分別代表相反的旋轉方向

雙軸系統

圖表可同時顯示兩種不同的刻度：

左軸（百分比）：顯示以體重標準化的扭矩（Nm/kg，以力因數表示）

右軸（絕對值）：顯示以 Newton-meter（Nm）為單位的實際扭矩

關鍵指標

圖表旁顯示三項關鍵指標：

1. 最大扭矩（力因數）

顯示內容：峰值扭矩力度，以體重標準化

單位：Nm/kg（以力因數表示）

範例：數值 0.85 表示您的峰值扭矩為每公斤體重 0.85 Newton-meter

2. 最大扭矩計時

顯示內容：峰值扭矩相對於擊球時機的發生時間

單位：毫秒（ms）

注意：僅在設置了擊球書籤時才會顯示

範例：-50ms 表示峰值扭矩發生在擊球前 50ms；+20ms 表示擊球後 20ms；0ms 表示恰好在擊球時

3. 力因數（原始值）

顯示內容：包含方向（正或負）的原始標準化扭矩數值

單位：Nm/kg

範例：+0.85 與 -0.85 具有相同的力度，但旋轉方向相反

階段高亮顯示

啟用後，彩色色帶將疊加在圖表上，顯示您揮桿的不同階段：

  • 後揮、下揮桿、擊球、隨揮

3D 視覺化

力臂視覺化

力臂視覺化顯示您的質量中心（CoM）與地面反作用力之間的生物力學槓桿關係。

元素外觀顯示內容
力臂線橘色實線從您的 CoM 到作用線的垂直距離
作用線橘色虛線力的作用方向延伸線
距離標籤深色背景上的白色文字力臂距離，單位為公分（±X.X cm）

力向量分解

力分解視覺化將總地面反作用力分解為三個垂直分量。無論相機視角為何，各顏色始終代表相同的物理力方向：

分量顏色物理方向顯示內容
X 分量粉紅色左右（內外側）側向力分布
Y 分量青色上下（垂直）垂直力分布
Z 分量綠色前後（前後側）前後力分布

每個分量箭頭同時顯示一個百分比標籤，表示該方向占總力的比例。

相機視角行為

力向量相對於您的相機視角顯示。為清晰起見，呈現為深度方向（進入/穿出螢幕）的分量將被隱藏：

相機視角可見分量隱藏分量
正面角度X（粉紅色，水平）、Y（青色，垂直）Z（綠色，深度）
目標線視角Z（綠色，水平）、Y（青色，垂直）X（粉紅色，深度）

注意：顏色始終代表相同的物理方向——粉紅色始終代表內外側力，青色始終代表垂直力，綠色始終代表前後側力。僅螢幕位置會根據相機角度而改變。

3D 視覺化設定

力臂設定

設定預設值說明
顯示力臂關閉切換從 CoM 到力作用線的橘色實線
顯示作用線關閉切換顯示力方向延伸的橘色虛線
顯示距離標籤關閉切換距離數值標籤（±X.X cm）

力分解設定

設定預設值說明
顯示 X/Y/Z 分量關閉切換所有三個分量箭頭及百分比標籤

設定選項（圖表）

顯示百分比（百分比軸）：預設開啟 - 切換標準化扭矩（Nm/kg）

顯示 Newton（絕對值軸）：預設關閉 - 切換絕對扭矩（Nm）

高亮揮桿階段：預設關閉 - 顯示標示揮桿階段的彩色色帶

顯示網格線：預設開啟 - 顯示水平網格線

圖表類型：山形圖表（預設）或折線圖

疑難排解

顯示「平臺上無人」訊息

  • 確認運動員在開始錄製時站在力量板上

  • 確認已在運動員資料中輸入體重

  • 確認力量板校準已完成

圖表數據空白或遺失

  • 確認錄製期間力量板處於啟用狀態

  • 確認已錄製 MoCap 數據（FPT 計算必要條件）

  • 確認錄製包含完整的揮桿時長

計時指標未顯示

  • 在您的錄製中設置擊球書籤
