使用 RTMPose 和 RTMDet 增強高爾夫和棒球揮桿無標記動作捕捉：由上而下方法

摘要

本白皮書記錄了 RTMPose 和 RTMDet 在高爾夫和棒球揮桿精確且高效姿態估計中的應用。利用針對實時性能優化的最先進技術，這些模型能夠詳細追蹤高爾夫和棒球揮桿期間的身體運動——這是改進運動分析性能的關鍵功能。我們強調了由上而下方法的優勢，其中現成的 RTMDet 檢測器識別每一幀中的高爾夫球手和棒球選手，RTMPose 估計關鍵身體關節的位置。

1. 簡介

姿態估計已成為運動表現分析的關鍵，允許精確追蹤運動員的動作。在高爾夫和棒球中，捕捉球手揮桿的生物力學資料提供了對揮桿動力學的寶貴見解，幫助專業人士和業餘愛好者改進技術。傳統的 2D 姿態估計方法通常面臨延遲和準確性挑戰，尤其是在實時場景中。本文提出使用 MMPose 框架內的 RTMPose 和 RTMDet 在高爾夫和棒球揮桿期間進行詳細姿態估計的解決方案。

2. 背景

高爾夫和棒球揮桿的複雜性需要精確測量身體運動。現有的姿態估計方法可能無法為實時性能提供必要的準確性。深度學習和電腦視覺的進步引入了 RTMPose 和 RTMDet 等模型，這些模型提供了改進的準確性和效率。

3. RTMPose：高性能姿態估計模型

RTMPose [1] 專為高性能、實時姿態估計而設計，經過優化可在有限的硬體上高效運行。

主要特性：

模型架構和效率：RTMPose 利用 CSPNeXt 作為其主幹 [1, 2]，平衡速度和準確性。CSPNeXt 針對密集預測任務（如姿態估計和物體檢測）進行了最佳化，提供高解析度和精度，同時保持計算效率。

關鍵點預測：採用基於 SimCC 的演算法 [1, 3]，將關鍵點的水平和垂直位置視為獨立的分類任務。這種緊湊表示減少了計算負荷，適合在各種設備上部署。

4. RTMDet：檢測主幹

RTMDet [4] 在由上而下的管道中充當 RTMPose 之前的檢測器，識別每一幀中高爾夫球手或棒球選手的位置。

主要特性：

模型架構和效率：RTMDet 利用修改版本的 CSPDarkNet [5]，比許多 YOLO 模型更易訓練和精確。修改版本利用大核深度卷積來平衡複雜性和速度，在 GPU 和 CPU 上都很高效。它非常適合運動表現追蹤等實時應用。

多功能性：處理各種物體檢測任務，包括實例分割和旋轉物體檢測。確保精確定位球手，即使在動態場景中也是如此。

5.1 非擁擠場景中的更高準確性

RTMPose-X和RTMDet-M的整合為實時高爾夫揮桿分析提供了強大的解決方案。憑藉高精度、低延遲和跨各種硬體平臺的相容性，此由上而下方法提供對揮桿力學的詳細見解。它對幫助業餘和職業高爾夫球手增強其表現具有重大潛力。

詳細方法論：使用RTMPose-X和RTMDet-M進行高爾夫揮桿姿態估計的由上而下方法

概述

此處說明的方法概述了涉及高爾夫和棒球揮桿實時姿態估計的由上而下方法的詳細步驟，利用RTMPose用於關鍵點定位和RTMDet用於物體檢測的優勢。該過程分為幾個階段：檢測、關鍵點定位和後期處理，每個階段都有助於對高爾夫揮桿中身體關節的精確有效估計，用於生物力學分析。

–插入圖表–

1. 檢測階段：使用RTMDet-M進行實時定位

由上而下方法的第一個階段涉及在影片的每一幀中檢測高爾夫球手。在運動場景中，特別是高爾夫運動中，場景通常由單一球員組成，與人群場景相比簡化了檢測任務。

1.1 模型架構

RTMDet-M 被用作管道中的物體偵測器。它使用卷積神經網路 (CNN) 主幹，特別是 CSPNeXt 主幹，旨在最佳化實時物體偵測性能，同時保持速度和準確度之間的平衡。架構的主要方面包括：

大核心深度級卷積：這些在主幹和頸部層中使用，增加了感受野，同時保持了較低的計算成本。

特徵金字塔網路 (FPN)：一種多尺度特徵擷取技術，可以檢測各種尺度的物體，確保無論高爾夫球手距離攝影機的遠近，都能被偵測到。

1.2 動態標籤指派

RTMDet-M 利用動態標籤指派策略，透過基於分類和定位損失組合向物體指派軟標籤來提高偵測準確度。標籤指派由 SimOTA 演算法控制，該演算法根據與地面真實物體匹配的可能性動態選擇正樣本。此方法確保在戶外高爾夫場景中經常遇到的各種光照和環境條件下進行魯棒偵測。

1.3 邊界框預測

偵測器輸出在每個影格中包含高爾夫球手的邊界框。這些邊界框提供了姿態估計模型將在其中運作的空間約束，透過僅關注影格的相關區域來降低後續姿態估計階段的計算負荷。在此背景下，RTMDet-M 在高性能硬體上以超過 300 FPS 的實時速率生成邊界框，確保它能跟上高爾夫揮桿的快速動態。

1.4 人物非最大值抑制 (NMS)

在多人設置中（儘管在高爾夫揮桿分析中很少見），RTMDet-M 包含一個姿態非最大值抑制 (NMS) 演算法，該演算法消除冗餘的關鍵點偵測，確保只有最有信心的偵測被保留。這在可能在擁擠場景或影片序列中偵測到重疊邊界框的情況下至關重要。

1.5 訓練資料集和效能

RTMDet-M 在 Object356 資料集中對人物實例進行二分類任務的訓練。

2. 姿態估計階段：RTMPose-X 關鍵點定位

一旦確立了高爾夫球手的邊界框，下一階段涉及估計此區域內關鍵身體關節的精確位置。利用高性能姿態估計模型 RTMPose-X 來完成此目的。

2.1 基於 SimCC 的關鍵點定位

RTMPose-X 採用 SimCC（簡單坐標分類）演算法，將關鍵點定位視為分類問題。與傳統的熱力圖方法相比，SimCC 將每個關鍵點的 x 和 y 座標分成多個區間，並對每個關鍵點所在的確切區間進行分類。此方法顯著降低了計算複雜度，提高了推論速度，同時為人體姿態估計任務保持了高準確度。

2.2 CSPNeXt 主幹

與 RTMDet-M 類似，RTMPose-X 也使用 CSPNeXt 主幹，該主幹專為密集預測任務（如姿態估計）量身定製。CSPNeXt 主幹在此情景中的優點如下：

輕量級架構：該模型的架構設計用於最小化參數數量，同時最大化吞吐量，使其非常適合實時應用。

高效特徵擷取：CSPNeXt 的特徵擷取層經過最佳化以處理高解析度影像，這對於在高爾夫揮桿期間檢測快速移動身體部位（如腕部、肘部和膝蓋）的細微細節至關重要。

2.3 關鍵點表示

RTMPose-X 為所有相關身體部位輸出關鍵點位置，包括：

上身關節：肩膀、肘部、腕部和頸部

下身關節：髖部、膝蓋和踝關節

其他關節：頭部、脊椎和其他與揮桿分析相關的關鍵點

384x288 的輸入影像解析度確保即使是關節的細微動作也能被準確捕捉，同時也保持了系統實時運行的能力。

2.4 RTMPose 前處理：無偏差資料處理 (UDP)

在裁切影像進入 RTMpose 模型之前，會執行無偏差資料處理 (UDP) 步驟。UDP 解決 RTMpose 在訓練和測試期間資料處理中的關鍵偏差，特別是在座標系統和關鍵點格式轉換中。在傳統人體姿態估計管道中，標準操作（如翻轉和調整大小）經常導致輸出錯位，特別是由於基於像素的轉換，導致精度損失和翻轉影像的不對齊。UDP 通過建立無偏差座標系統轉換來修正這些問題，在關鍵操作（裁切、調整大小、旋轉、翻轉）期間保持語義對齊。UDP 還通過將關鍵點編碼為熱力圖而不引入位置偏差來引入無偏差關鍵點格式轉換，並通過高斯分佈感知解碼過程進一步精煉。這種資料處理方法系統性地改進模型性能，如在 COCO 和 CrowdPose 資料集上的廣泛測試所示，其中它在自上而下和自下而上模型中實現了增強的準確度和降低的推論延遲 [Ref]。

3. 後期處理和姿態精煉

一旦預測關鍵點，就會應用多個後期處理步驟來精煉姿態估計並確保跨幀的穩定性。

3.1 姿態平滑化

高爾夫揮桿涉及快速動作，這可能會在跨幀的估計關鍵點位置中引入雜訊或波動。為了減輕這一問題，應用了One-Euro 濾波器來隨時間平滑關鍵點軌跡，確保關鍵點預測中的小型非物理波動被消除。One-Euro 濾波器通過根據動作速度動態調整濾波器的帶寬來運作，這對於高爾夫揮桿等情景是理想的，其中動作在不同階段（後揮、下揮桿和隨揮）的速度變化顯著。

3.2 幀跳過機制

為進一步最佳化，實現了幀跳過機制，其中偵測僅在關鍵幀上執行，並為中間幀內插姿態估計。這大幅減少計算負荷，而不在幀之間動作有限的情景中犧牲準確度，例如高爾夫揮桿的慢動作分析。

4. 時間追蹤和序列一致性

鑑於高爾夫揮桿本質上是序列性的，在姿態估計中保持時間一致性至關重要。RTMPose-X 通過時間追蹤技術解決這一問題，確保關鍵點預測跨連續幀的一致性。這涉及隨時間追蹤關鍵點位置，並確保它們的軌跡遵循基於生物力學約束的現實動作模式。

4.1 關鍵點速度和加速度分析

除了追蹤關鍵點位置外，RTMPose-X 還估計每個關鍵點的速度和加速度。這些資訊對於分析高爾夫揮桿的動態至關重要，提供關鍵性能指標的洞察，例如：

揮桿速度：基於下揮桿期間的腕速度計算。

髖部旋轉：通過髖關節的旋轉速度進行分析。

球桿路徑和球桿頭速度：從腕部和肘部軌跡間接推斷。

這些指標可與專業基準進行比較，以提供有關球手揮桿力學的反饋。

5. 推論和實時性能

整個自上而下管道針對實時性能進行了最佳化，允許在現代 GPU 上以超過 90 FPS 的速率執行姿態估計。使用高效率模型架構 (CSPNeXt) 和快速推論技術 (SimCC) 確保系統可以處理高幀速率影片輸入，使其適合於訓練課程期間的實時反饋。

6. 評估和驗證

RTMPose-X 和 RTMDet-M 模型在 COCO 和 MPII 等標準資料集上進行評估，在 COCO 資料集上的身體關鍵點顯示強大的性能，平均精度 (AP) 為 75.8%。這些結果針對高爾夫揮桿資料集中的地面真實標註進行驗證，確保模型在擷取動態運動動作中的穩健性。

6.1 性能指標

均方誤差 (MSE)：用於量化關鍵點預測對地面真實標註的準確度。

平均精度 (AP)：評估姿態估計模型的整體性能。

幀處理時間：基準測試以確保系統符合實時要求（每幀 <10 毫秒）。

7. 結論

使用 RTMPose-X 和 RTMDet-M 的由上而下方法為運動分析（特別是高爾夫揮桿分析）中的即時姿態估計提供了高效且準確的方法。透過強健的關鍵點檢測、時間追蹤和即時推論，此方法論為高爾夫揮桿動力學提供詳細的生物力學見解，有助於提升表現和預防受傷。
