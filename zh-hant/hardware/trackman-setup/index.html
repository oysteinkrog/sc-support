如何在 Swing Catalyst 中使用 TrackMan

本文說明如何將 Swing Catalyst 連接至 TrackMan，並將發球監測數據與影片一同儲存。若要啟用整合功能，TrackMan 軟體必須與 Swing Catalyst 同時運行。

note: 若要在 Swing Catalyst 中使用 TrackMan，您需要一台支援串流影片的攝影機。（請參閱支援的攝影機）

安裝：TrackMan Pro/Launch 4.0.9

  • 將 TrackMan 裝置連接至電腦

  • 啟動 TrackMan Pro 或 TrackMan Launch，並進入擊球追蹤畫面

  • 啟動 Swing Catalyst，並在開始選單中前往 設定 - 硬體

  • 啟用 Launch Monitor 整合功能

  • 選擇 TrackMan

安裝：TrackMan Performance Studio

支援版本 2.2-4.0

  • 將 TrackMan 裝置連接至電腦

  • 啟動 TrackMan Performance Studio

  • 在開始選單中進入 設定 畫面（圖1：齒輪符號）

  • 啟用 SDK Output（圖2）

  • 前往 開始 並點選 Shot analysis

  • 啟動 Swing Catalyst，並在開始選單中前往 設定 - 硬體

  • 啟用 Launch Monitor 整合功能

  • 選擇 TrackMan

安裝：搭配 TM3e 或 TrackMan 4 的 TPS

  • 開啟 TrackMan 3e 裝置電源

  • 在 Windows 中連接至 TrackMan WiFi 網路，或改用 USB 連接線連接。

  • 除第1步外，請依照上述安裝指南的相同步驟操作

圖1：在 TrackMan Performance Studio 中啟用 SDK 輸出。

搭配 TrackMan Pro/Launch/Performance Studio 使用 Swing Catalyst

  • 請先啟動 TrackMan 軟體，並進入擊球追蹤畫面。

  • 啟動 Swing Catalyst 並捕捉揮桿動作。

  • 開啟已錄製的揮桿，即可在影片旁的數據框中檢視擊球數據。

若一切安裝正確，系統現在應會自動捕捉 TrackMan 擊球數據，並將其與影片一同儲存。

攝影機設定

在某些情況下，TPS 軟體可能會鎖定系統上的攝影機，導致 Swing Catalyst 軟體無法使用這些攝影機。

未來版本的 TPS 軟體可能會新增設定選項以停用此行為，但在此之前，TrackMan 提供了以下暫時解決方案：

開啟 TPS 軟體，並記下攝影機清單中顯示的確切攝影機名稱。

找到以下檔案並以記事本開啟：

C:\ProgramData\TrackMan\VideoManagement\ExcludeCameras.TMConfig

將攝影機名稱新增至檔案中。若有多台攝影機，請將所有名稱各自新增於獨立的一行。

疑難排解

  • 確認 TrackMan 已在 TPS 中被識別並成功連接。

  • 確認已在 Swing Catalyst 硬體設定選單中啟用 Launch Monitor 並選擇 TrackMan。

  • 確認 Swing Catalyst 的 Launch Monitor 設定下方已勾選「trigger」。

  • 若仍未觸發，請檢查 TPS 的設定，並確認「SDK Output」已啟用。

  • 嘗試重新啟動 TrackMan 裝置。

  • 若您已接收到數據且 Swing Catalyst 顯示已連接，但未觸發，請嘗試重新啟動電腦。

  • 已觸發但延遲過長：請嘗試在 Launch Monitor 設定中調整延遲補償，建議值約為 1500ms；此數值視球的種類以及雷達是在室內或室外使用而有所不同。

若您在 Swing Catalyst 中仍未收到任何數據：

  • 嘗試重新啟動 TrackMan 裝置，並重新確認 SDK 輸出是否已啟用。

  • 嘗試停用 Windows 防火牆，若此方法有效，請為 TPS 和 Swing Catalyst 新增例外規則。

  • 確認 TrackMan OEM 服務是否正在運行，若是，請停用它並再次嘗試。有關 Windows 服務的更多資訊，請參閱：http://www.7tutorials.com/what-are-windows-services-what-they-do-how-manage-
