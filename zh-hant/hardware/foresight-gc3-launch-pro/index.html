如何將 Foresight GC3 / Bushnell Launch Pro 與 SwingCatalyst 搭配使用

簡介

本篇支援文章將說明如何設定 Foresight GC3 或 Bushnell Launch Pro 以與 SwingCatalyst 搭配使用。

Foresight GC3 提供 WiFi、WiFi Direct、USB 及乙太網路等多種方式，可用於連接 Launch Monitor 裝置。

請注意，此處的 WiFi 並非直接連接至 GC3，直接連接的方式稱為 WiFi Direct。WiFi 是指讓 GC3 / BLP 連接至現有無線網路所使用的網路。

需求

  • 電腦須具備可用的 USB 連接埠、乙太網路連接埠或 WiFi（另需具備網際網路連線能力）。

  • SwingCatalyst 10.0 或更新版本

Note: 若您打算在 SwingCatalyst 中使用 HD 攝影機，我們建議單獨執行 FSX（即不與 SwingCatalyst 同時執行），或在不同的電腦上執行。

請確認您至少配備 NVIDIA GeForce 1080 或更高規格的顯示卡，且電腦符合 Foresight 的建議規格。

連線與設定

  1. 透過 USB、WiFi* 或乙太網路連接 GC3。

  2. 在「設定」->「硬體」->「Launch Monitor」中，應會列出可選擇的 Launch Monitor 及其不同連線介面。

  3. 請確認選取您希望使用的 Launch Monitor 及連線介面：

* 若透過 Wi-Fi 連線，您必須具備其他網際網路連線方式，因為使用 GC3 需透過網際網路進行驗證。

疑難排解

Foresight GC3 未顯示為已連線或未觸發

SwingCatalyst 10.0 至 10.1.0 版本中，Foresight SDK 存在一個已知的錯誤（bug）。

此錯誤會導致 SwingCatalyst 無法從 GC3 / BLP 接收資料。

因應措施：

  • 關閉 SwingCatalyst，並透過 USB 將 GC3 / Launch Pro 連接至電腦。

  • 確認 Foresight GC3 已顯示在您的電腦上，它將在「本機」下顯示為大量儲存裝置。

  • 從以下連結下載並解壓縮因應措施：https://cloudfront.swingcatalyst.com/files/GC3-BLP-Workaround.zip

  • 開啟解壓縮後的資料夾，並雙擊「Workaround.exe」。這將開啟一個命令提示字元視窗，並嘗試連接及中斷與您的 Launch Monitor 的連線。

其他疑難排解建議：

  • 若裝置未顯示，請嘗試將其連接至電腦上不同的 USB 連接埠。

  • 若透過 WiFi Direct 連線，請確認您可透過其他方式存取網際網路，或備有獨立的 WiFi 網路卡。

  • 嘗試透過不同的介面連線，例如若您已嘗試使用 WiFi，請改用乙太網路或 USB。

  • 確認沒有其他軟體同時嘗試連接該裝置。

Foresight GC3 已連線且已觸發，但錄製內容不含任何資料

  • 嘗試將 GC3 / BLP 裝置重新開機（電源循環）。

  • 確認您使用的球桿已正確貼上貼紙。

  • 確認附近沒有其他以攝影機為基礎的 Launch Monitor，以免干擾 GC3 / BLP 追蹤球的能力。

如需進一步疑難排解，請參閱 Foresight 的疑難排解文章。
