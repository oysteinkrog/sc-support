如何在 Swing Catalyst 中使用 BodiTrak 感測器

簡介

本篇支援文章將說明如何在 Swing Catalyst 中設定與配置 BodiTrak 2 Vector 感測板。技術上，本文也適用於較舊款的 BodiTrak 16x25 & 16x27（BT 型號）。

系統需求

  • 具備可用 USB 連接埠的電腦。

  • Swing Catalyst 9.7 或更新版本，並支援感測板功能。

  • 以下支援感測器對照表中列出的其中一款型號。

  • Windows 10 或 11 64 位元（x64）（注意：不支援 ARM 或 x86 架構）。

支援哪些感測器？

我們支援以下型號，請注意部分型號已停產。截至 2024 年，我們並不支援 BodiTrak 的全部感測器型號。

型號 / 型號編號 行 x 列 尺寸（寬 x 高）cm

BT7150 16x25 71 x 45.5

BT（原型機？） 16x27 75.6 x 44.8

BT2-1632-500 16x32 94 x 47

BT2-1625-500 16x25 73 x 47

BT2-1625-500 16x25 71 x 45.5

如需平臺校正相關事宜，請聯繫 BodiTrak 支援團隊。

驅動程式安裝

驅動程式安裝由 Windows 自動完成。

若您的系統尚未安裝任何 BodiTrak 軟體，且感測器未顯示為已連接或未被識別，請聯繫 BodiTrak 支援團隊。

可能的問題來源：

  • USB 連接線。

  • 與電腦的連接。

請參閱我們的疑難排解章節以取得更多提示。

配置

以下步驟並非絕對必要，但有助於確認感測器已被偵測並在 Swing Catalyst 中正常運作。

啟動 SwingCatalyst，並前往「設定」->「硬體」。

  • 感測板應會被自動偵測（若未自動偵測，請嘗試從下拉選單中手動選擇 BodiTrak 2 Vector）。

  • 確認其已開啟（否則整合功能將無法運作）。

若要開啟感測器配置對話框，請點擊「Configure…」。

注意：若無法連接至感測器或收到錯誤訊息，請參閱我們的疑難排解章節

感測板設定

您可以在感測板設定視窗中檢視即時數據、套用旋轉，以及查看其他感測器資訊（例如序號）。

中間的大白點表示壓力中心（CoP）， 這是衡量您身體平衡狀態的指標。

當您保持平衡時，CoP 將位於雙腳之間的中央位置；當身體向前或向後傾斜時， CoP 會相應地向前或向後移動。 將重心向左或向右移動，將使 CoP 向左或向右偏移。

每個足部印記下方各有兩個較小的點，代表每隻足部的 CoP， 顯示各足部區域內的壓力中心。 兩點之間的連線則表示您站立的平面。

旋轉（如何旋轉、鏡像或翻轉壓力數據）

點擊「Rotate Stance Data」按鈕即可旋轉感測板的方向。點擊此按鈕可將數據旋轉 180 度，如需更進階的設定，請參閱「進階」選項。

點擊「進階」即可存取進階旋轉設定：

若要垂直翻轉數據，可點擊「翻轉」。

疑難排解

請注意：

如需任何支援、維修或退貨申請，請聯繫 BodiTrak。

本疑難排解章節旨在協助您識別並解決在使用 Swing Catalyst 搭配感測器時可能遇到的問題。

數據顯示翻轉，即使墊子方向擺放正確

  • 您可以在感測板設定中垂直翻轉數據，請參閱旋轉。

BodiTrak 感測器未被識別或未顯示為已連接：

若 BodiTrak 軟體正在執行，可能會阻止對感測器的存取。同樣地，BodiTrak DataPort 是一項可能在您的系統上執行的服務，會阻止 Swing Catalyst 連接至感測器。

  • 確認沒有任何 BodiTrak 軟體正在執行。

  • 停止 BodiTrak DataPort 服務。

停止服務：點擊 Windows 開始功能表按鈕並輸入「服務」，點擊「服務」應用程式，找到「BodiTrak Data Port」，按右鍵並選擇停止。

若要停止服務，請按下 Windows 開始功能表的 Windows 圖示，然後輸入「服務」。

開啟服務應用程式，找到 BodiTrak DataPort，按右鍵並點擊停止。

停止該服務可能會導致其他使用 BodiTrak 的應用程式無法正常運作，但將允許 Swing Catalyst 連接至感測器。

若未安裝 BodiTrak DataPort，請繼續執行以下疑難排解步驟。

  • 開啟 Windows 裝置管理員。如何開啟？

確認 BodiTrak 裝置出現在 USB Serial Devices 底下。 **

  • 若未出現，或顯示警告符號，請嘗試將裝置重新連接至不同的 USB 連接埠。

  • 將裝置連接至電腦上的其他 USB 連接埠。

  • 若使用了 USB 延長線，請嘗試不透過延長線直接將裝置連接至電腦。

  • 重新啟動 Swing Catalyst。

  • 重新啟動電腦。

  • 若您已嘗試上述所有步驟，且裝置在 BodiTrak 軟體中可正常運作但在 Swing Catalyst 中無法使用，您可以聯繫我們的支援團隊。

感測墊上的雜訊 / 校準問題

  • 長期大量使用後，感測器可能需要重新校準，請聯繫 BodiTrak 支援團隊。

  • 感測器與頂部墊子蓋之間可能存在異物，請確認感測器周圍沒有雜物。

  • 檢查感測器底部下方是否有異物頂住墊子底部。

足部印記不清晰

若足部印記不清晰，這可能與感測器對低壓力值處理方式的校準有關。可能是感測器校準不正確或需要重新校準。

Swing Catalyst 不會對從 BodiTrak 感測器接收到的數據進行任何額外的濾波處理，但若您的足部印記在 Swing Catalyst 中顯示效果與其他程式中使用您的 BodiTrak 墊子時不同，歡迎透過我們的服務中心建立支援票單，我們將嘗試進行調查。
