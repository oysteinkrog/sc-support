TrackMan 連線問題疑難排解指南

您遇到了以下問題：

TrackMan 已連線且在 TPS 中顯示資料，但 SwingCatalyst 未被觸發，且 SwingCatalyst 內沒有任何資料。

  • 重新啟動 TrackMan 裝置本身。

  • 確認您是否在 TPS 中收到資料，若未收到，請再次檢查校準設定。

  • 確認 TPS 設定中已啟用「Enable SDK Output」/「Legacy SDK」。

在 SwingCatalyst 9.7.8 與 9.7.9 版本中，此問題已進一步改善。若您已按照上述指示操作但仍無效，請確保您使用的是 9.7.9 或更新版本，這有助於減少延遲問題。

SwingCatalyst Launch Monitor 延遲補償

若您已收到資料但 SwingCatalyst 未觸發錄製，請嘗試將「Trigger delay」值更改為 1400。

Trackman 3e

您也可以透過裝置的網頁介面確認「Legacy SDK」是否已啟用。您可以從 TPS 設定進入網頁介面，強制切換為操作員模式，並在擊球準備中確認相關設定。

若 SDK 輸出已在 TPS 及裝置上完成設定，但您仍未收到資料，請嘗試使用名為 Hercules 的工具連線至裝置或 SDK。

監控裝置 / TPS 軟體的輸出：

  • 確保 TPS 正在執行並從裝置接收資料。

  • 下載並執行 Hercules。

  • 切換至 TCP Client 分頁。

  • 輸入以下 IP 與連接埠，然後按一下連線。

WiFi 與 USB IP 位址

Trackman 4

  • 有線網路：不支援。

  • USB 位址 169.254.0.1 連接埠：52950

  • WiFi 位址 172.30.20.1 連接埠：52950

  • 未知位址來源：169.254.88.214

Trackman 3e：

  • USB 位址 169.254.0.1 連接埠：52950

  • WiFi 位址 172.30.20.1 連接埠：52950

Trackman 2：

  • 直接連線至 127.0.0.1 上的 TPS SDK 伺服器，連接埠：52950

若在 Hercules 中正確連線，按下連線按鈕後您應會看到以下輸出。

若未看到上述輸出，請嘗試重新啟動 TrackMan 裝置本身，因為 TrackMan Legacy SDK 目前未輸出資料。

若您能成功連線，您應會收到資料，以及在追蹤到揮桿後隨即出現的揮桿資料。

這與 SwingCatalyst 所接收的資料相同，是確認 TPS 及 TrackMan 是否確實在傳送資料的好方法。

若您無法連線，請檢查防火牆設定。若是透過 WiFi 連線，TrackMan 可能被識別為公用網路，這在某些防火牆設定下可能造成問題；請嘗試關閉公用網路的防火牆後再次確認，現在是否能收到資料？若可以，請確保 TPS 及 Swing / Motion Catalyst 已在 Windows 防火牆中設為允許。

檢查 SwingCatalyst 的日誌檔案：

C:\ProgramData\Swing Catalyst\logs\log.txt 若您在日誌中看到以下訊息，表示 TrackMan OEM Service 正在執行，需要將其停用。

LaunchMonitorNetworkClientBase.OnTryConnectCompleted(): Successfully connected to [Trackman] on [127.0.0.1:8000].
