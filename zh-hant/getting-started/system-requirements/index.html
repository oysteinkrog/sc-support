Swing Catalyst 的電腦需求

重要提示： Swing Catalyst 與 Mac OS（Arm 架構）或 Windows 11 Arm 不相容。

快速摘要

為確保影片擷取與播放順暢，您的電腦應符合以下基本需求：

  • 近期款式的電競筆記型電腦或高效能桌上型電腦

  • 32 GB 記憶體（RAM）

  • 現代顯示卡（NVIDIA RTX 3060 6GB 或更佳）

  • 近期款式具備 8 核心或以上的 Intel 或 AMD 處理器

  • 我們強烈建議使用最新系列的 NVIDIA GPU，以獲得最快的編碼速度及 MoCap 處理效能。目前最新系列為 RTX 5060、5070、5080、5090。

筆記型電腦需求

若您使用筆記型電腦，我們建議選擇具備以下規格的電競筆記型電腦：

  • 記憶體：32 GB RAM

  • 處理器：近期款式的 Intel i5、i7 或 i9（第 9 代或更新），至少 8 核心

  • 顯示卡：NVIDIA RTX 3060（或更新），至少 6GB 獨立顯示記憶體

相機連接指引

  • 僅使用隨相機附贈的原廠高品質 USB 線，或使用其他機器視覺認證線材

  • 將相機直接連接至電腦（避免使用 USB 集線器或延長線）

  • 最多可同時連接兩台 USB 相機

  • 若使用乙太網路（GigE）相機，請確保有空閒的 PCI Express 插槽，可依相機數量安裝專用網路卡。

詳細硬體建議

建議處理器

Intel 選項（由新至舊）

第 14 代（最新）

  • Intel Core i9-14900/14900K（最佳性能）

  • Intel Core i7-14700KF（優異性能）

  • Intel Core i5-14400F（良好性能）

第 13 代

  • Intel Core i9-13900K/KF

  • Intel Core i7-13700K/KF

  • Intel Core i5-13600K/KF

第 12 代

  • Intel Core i9-12900K

  • Intel Core i7-12700K

  • Intel Core i5-12600K

AMD 選項

  • AMD Ryzen 9 9950X3D（16 核心，最佳性能）

  • AMD Ryzen 7 9800X3D（8 核心，優異性能）

  • AMD Ryzen 9 7900X（12 核心，最佳性能）

  • AMD Ryzen 7 7700X（8 核心，良好性能）

  • AMD Ryzen 9 5900XT（16 核心，上一代，性價比佳）

對於 AMD CPU，我們強烈建議額外購買 USB 3 控制卡，以獲得最佳相容性。

技術說明： 您的處理器應能達到 3.8GHz 或更高的速度，以獲得最佳性能。本軟體需要支援 AVX 及 AVX2 指令集的處理器（大多數現代處理器均支援）。

建議顯示卡

我們建議至少具備 6GB 的 GPU 獨立顯示記憶體（VRAM），越多越好。

頂級（卓越性能）

  • RTX 5090（最佳選擇）

  • RTX 4090

  • RTX 3090

  • RTX 4080

高階（優異性能）

  • RTX 5080

  • RTX 5070

  • RTX 4070

  • RTX 3080

中階（良好性能）

  • RTX 5060

  • RTX 3070

  • RTX 4060

入門級（建議最低規格）

  • RTX 3060

注意： 以上所列顯示卡均符合本軟體的最低需求。較高階的顯示卡將提供更佳的性能，尤其在使用多台相機或高解析度影片時效果更為顯著。
