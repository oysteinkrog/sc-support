如何找到我的軟體授權名稱？

  1. 開啟 Swing Catalyst 並前往「General」設定。

  2. 點擊「Show license configuration」

  3. 在這裡您將看到「Owned by ______」，以及適用於您授權的任何到期日期。

如何為我的平衡板安裝校準檔案？

  1. 開啟 SwingCatalyst 軟體並前往設定。

  2. 前往「Hardware」區段並點擊「Configure」按鈕。

  3. 前往左上角第 2 個標籤，名稱為「Stance Sensor」。

  4. 點擊「browse and install」並導覽至您儲存校準檔案的位置，預設通常位於「Download」區段。

如何找到我的平衡板序號？

  • 開啟 SwingCatalyst 軟體並前往設定。

  • 前往「Hardware」區段並點擊「Configure」按鈕。

  • 前往左上角第 3 個標籤，名稱為「Sensor Info」。

  • 在這裡您將看到平衡板的 4 位數序號。

如何改善相機設定（亮度與球桿軸清晰度）

步驟 1：開啟 Swing Catalyst 並前往相機設定

步驟 2：點擊「Advanced」並前往「Camera」標籤。

*如果您的球桿軸有嚴重的模糊，這是因為曝光值過高。

  • 降低「Exposure」= 減少球桿軸模糊，但影像較暗。（低曝光值也是達到最高 FPS 的必要條件）。

  • 您可以提高「Gain」以增加亮度。但這會使影像略微出現顆粒感。

  • 確保實體鏡頭上的光圈完全開啟，這將讓您有更多空間降低曝光值。（見下圖）

  • 如有需要，您也可以提高「Gamma」以進一步提亮影像，並進一步降低曝光值。

此鏡頭有三個調整項目，由上至下：

  • 對焦（向 ∞ 符號方向調整，將使背景中較遠的物體清晰對焦）

  • 光圈（Iris 調整，用於控制通過鏡頭的進光量，較小的光圈將產生較清晰的影像）。

  • 變焦（調整鏡頭的廣角或望遠縮放）。

Launch Monitor 整合無法運作

  • 如果整個 Launch Monitor 區段呈「灰色」，您很可能使用的是 Swing Catalyst 的 Basic 版本。只有「Pro」版本支援 Launch Monitor 整合。

  • 請確認 Launch Monitor 已啟用、「use as trigger」已勾選，且已選擇正確的 Launch Monitor。當「(not connected)」消失時，表示 Swing Catalyst 已連接到您的 Launch Monitor。

  • 如果您無法連接，請參閱：我們的支援網站並尋找對應的擊球準備文章／指南；某些 Launch Monitor 需要進行設定才能與 Swing Catalyst 搭配使用。

  • 如果您仍遇到問題，歡迎聯繫我們的支援團隊。

遠端支援

步驟 1：開啟 Swing Catalyst 並點擊左下角的「?」按鈕。

步驟 2：點擊「Start Remote Support」按鈕。這將開啟一個名為 Swing Catalyst Remote Support 的小程式。

步驟 3：只要您已連接網際網路，應該就會取得一組 ID 號碼，請將此號碼傳送給您的支援人員。

*如果您無法啟動 Swing Catalyst 或遠端支援，請參閱我們的遠端支援文章以取得其他方式。

如何購買更新與支援

  1. 較早期購買終身軟體的客戶，可在第一年後選擇購買更新與支援，以確保能夠存取最新更新及電話／遠端支援。

  2. 一年的更新與支援方案可從我們的網路商店以 249 美元購買。https://shop.swingcatalyst.com/products/support-update-plan

  3. 如果您擁有多個授權，您需要為每個希望延長的授權個別購買更新與支援方案。

  4. 請在結帳時於備註欄中填入授權名稱，以確保購買套用至正確的授權。如何找到授權名稱的說明，請參閱本常見問題解答頂部的內容。

*只要您在結帳時於備註中填入授權名稱，您不必使用特定帳戶進行此購買。
