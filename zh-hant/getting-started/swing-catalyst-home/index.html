快速入門 - Swing Catalyst Home

安裝軟體和授權金鑰

每個新的 Swing Catalyst 授權都附帶一封電子郵件，其中包含說明。如果您找不到該電子郵件，請檢查您的垃圾郵件資料夾或搜索您的收件匣。

按照說明下載並安裝 Swing Catalyst，安裝完成後在軟體提示時輸入授權金鑰。

範例電子郵件：

安裝授權金鑰時遇到問題？請參考我們的逐步說明文章。

連接一台或多台攝影機

請參考此支援的攝影機清單。

如果您使用 FLIR、IDS 或 AVT 攝影機，您可能需要下載並安裝適當的驅動程式。請查看我們的驅動程式部分。如果您使用 FLIR 攝影機，請參考我們的攝影機專用指南。

注意：我們建議在執行任何攝影機相關的驅動程式安裝之前，確保 FSX 和 Swing Catalyst 未運行。驅動程式安裝完成後，您可能需要重新啟動電腦。

從主功能表，點擊齒輪圖示即可找到設定。

偵測到的攝影機會自動列在攝影機清單中。

為了使用攝影機，需要指定一個角度。

點擊已停用的圖示選擇一個角度，然後將「關閉」變更為「開啟」以啟用攝影機。

連接 Launch Monitor

在「硬體設定」下，您可以在支援的 Launch Monitor 之間進行選擇。

在版本 9.7 和 9.8 中，您可以從清單中選擇 Launch Monitor，將其切換為「開啟」並啟用「用作觸發器」。

在版本 10.0 及更新版本中，只需開啟 Launch Monitor 支援並按下搜尋。SwingCatalyst 應會偵測到任何已連接且相容的 Launch Monitor。

  • 確保 Launch Monitor 已開啟並連接到電腦。

  • 我們始終建議盡可能使用有線連接，例如 USB 或乙太網而非 WiFi。

如需更詳細的 Launch Monitor 設定說明，請參閱以下指南：

  • Foresight GCQuad/GCHawk

  • Foresight GC3 / Bushnell Launch Pro

  • Foresight GC2*

  • Flightscope X-Series

  • FullSwing (E6)

  • FlightScope Mevo+

*Foresight GC2 整合不支援與 FSX 同時連接；若要搭配 FSX 使用 GC2，必須選擇 Foresight GC2 (Sim)。

如果您選擇 Launch Monitor 作為觸發器裝置，它會在捕捉模式中自動錄製您的揮桿。如果您沒有 Launch Monitor，也沒關係，您可以改為使用麥克風作為觸發器！

建立使用者

按照以下步驟建立使用者並錄製揮桿。

首次執行 Swing Catalyst 時會自動生成使用者。此使用者是根據授權詳細資訊產生的。如果您想編輯設定檔資訊，可以隨時進行。

從主功能表中，按一下「開始」

按一下「選擇使用者」下拉式按鈕並按一下「新增」：

note: 使用者會根據您的授權詳細資訊自動生成，如果您想編輯這些或新增使用者，可以分別按一下「新增」或「編輯」。

輸入名稱並按一下「保存」

某些家庭授權有最大使用者限制，這限制了 Swing Catalyst 中可儲存多少個使用者設定檔。

分析功能表工具列

切換使用者

捕捉

為了錄製揮桿，您需要進入捕捉模式。

點擊「捕捉」按鈕時，您會自動從播放模式切換到捕捉模式。

綠色的「捕捉就緒」圖示表示系統已準備好捕捉。使用 Swing Catalyst Home 時，您在開始工作階段時會自動進入此模式！

「捕捉就緒」只是表示捕捉模式已啟用，SwingCatalyst 正在主動串流數據。只有在觸發事件發生時才會保存（例如手動觸發、Launch Monitor、麥克風）。

捕捉選項

在不同的觸發選項（如麥克風或 Launch Monitor）之間選擇，並更改捕捉模式。

您可以使用「版面配置」下拉按鈕在 SwingCatalyst 中選擇不同的版面配置。

SwingCatalyst 會記住在播放和捕捉模式中最後使用的版面配置。

攝影機版面配置選擇

在相同的下拉菜單「版面配置」中，您可以根據版面配置選擇要顯示的不同攝影機角度的數量。在播放模式（查看錄製的揮桿時），攝影機選擇取決於用於建立錄製內容的攝影機數量。

在捕捉模式中，可見攝影機的數量取決於您的系統上啟用的攝影機數量，以及授權是否支持您要使用的攝影機數量。

切換攝影機角度

如果您的錄製內容使用多台攝影機，可以通過點擊攝影機圖示來更改檢視的攝影機。

您也可以從這裡進行一些小型攝影機調整，例如鏡像和旋轉攝影機角度。這些變更僅適用於錄製內容，如果您想比較左手使用者與右手使用者等情況時會很有幫助。

繪圖工具

如上面的螢幕擷取畫面所示，繪圖工具位於軟體的左側。

繪圖工具可讓您在影片影像上繪圖，既可以在已錄製的影片上繪圖，也可以在即時影片「饋送」上繪圖（在捕捉模式中）。

線條工具提供多種不同的線條類型供您選擇，標準「線條」允許您在任何點之間建立直線。

有三種不同的線條粗細可供選擇。

不同的顏色可以更輕鬆地區分不同的線條。

縮放和移動工具

在工具列底部、繪圖工具下方，是縮放和移動工具以及「填滿影片檢視」按鈕。

您也可以通過按住 Ctrl 鍵並同時滾動滑鼠滾輪來縮放和操作影片影像。

檔案總管

您可以在這裡輕鬆管理您的錄製內容。檔案總管分為三個「部分」：

左側是系統中註冊的使用者，中間是該使用者的所有錄製內容，右側是預覽部分。

錄製內容會自動分組為工作階段並按日期排序。

  • 點擊一個揮桿，它將自動在「預覽」部分（右側）預覽。

您也可以通過右鍵點擊並選擇要在哪個檢視埠中開啟錄製內容，或者拖動底部的「將錄製內容拖放到此處」區域來開啟錄製內容。

檔案總管選單的特寫檢視

濾波處理

可以根據不同的收集參數來濾波錄製內容，例如：

  • 運動（雖然 Swing Catalyst 僅用於高爾夫球，但可以檢視來自不同運動的錄製內容）

  • 球桿類型

  • 發球監測數據（飛行距離、旋轉速率或撞擊係數）

  • 評等（1-3 星評等）

資源與疑難排解

在這裡您可以找到資源和疑難排解提示來解決最常見的問題。

最常見的問題

使用者通常遇到的最常見問題通常與外部連接的硬體有關，無論是攝影機、Launch Monitor 還是感測板。簡單的東西（例如劣質的纜線（例如過長的纜線或不相容的 USB 延長器））可能會導致問題。因此，本指南的這一部分旨在幫助您解決問題或縮小問題原因的範圍。

攝影機未顯示在攝影機設定清單中

如果攝影機未顯示在攝影機清單中，表示攝影機未被偵測到或連線不正確。

  • 如果攝影機未顯示在攝影機清單中，最有可能是 Windows 未識別該攝影機，或該攝影機正被另一個應用程式使用。請嘗試中斷攝影機的連線並重新連接。

  • 該攝影機可能不受 Swing Catalyst 支援。

  • 若為 The Imaging Source 攝影機：如果您已安裝製造商的驅動程式，您可能需要將其解除安裝才能正常運作。

  • 乙太網路 (網路) / GigE 攝影機可能需要 IP 配置。

未收到資料

這表示 Swing Catalyst 未接收到任何視訊影像或資料進行處理。

造成此類錯誤的原因範例可能包括：

  • 電纜/連線不良：嘗試中斷攝影機的連線，並將其連接到不同的 USB 連接埠。

  • 設定錯誤：(特別是針對網路攝影機和 DirectShow 攝影機)。檢查曝光設定，如果停用自動功能且曝光設定非常高，幀速率會大幅下降。

  • 網路攝影機的一個修正方法可能是啟用「手動時間戳」(請參閱下面的影像)

發生錯誤

如果攝影機正被另一個應用程式使用，此類錯誤很常見。特別是網路攝影機很容易被第三方軟體使用，請嘗試關閉其他程式並重新啟動 Swing Catalyst。

丟失幀 / 接收的資料不足

丟失幀表示從攝影機傳輸到電腦的視訊幀/資料在不同程度上遺失。特別是在有多個攝影機的情況下，這不太理想，因為突然間一個攝影機會遺失揮桿的某些部分。Swing Catalyst 會發出警告，如果系統丟失的幀數過多，將無法觸發錄製。

造成這種情況的原因可能包括：

  • USB3 攝影機連接到 USB 2.0 連接埠。

  • 使用設計不良的電纜或延長電纜。

  • 超過建議的電纜長度。

  • USB3 攝影機連接到 USB 集線器，其他裝置共享同一集線器，導致頻寬不足。

  • 乙太網路攝影機連接到未正確配置或不支援大幀的網路連接埠。

  • 攝影機使用的頻寬超過系統可用的頻寬。

提示：

對於 USB 攝影機，我們建議嘗試降低幀速率 (和/或裝置連結輸送量 - 適用於 FLIR 攝影機) 以減少頻寬消耗。

  • 降低幀速率 (和/或裝置連結輸送量)。

  • 如果使用多個攝影機，請嘗試拔除或停用某些攝影機，系統是否仍報告丟失幀？

  • 檢查電纜，攝影機是否連接到 USB 集線器或延長器？請嘗試直接將其連接到電腦。

  • 嘗試關閉其他 CPU 和圖形密集型軟體以釋放資源。

Launch Monitor 故障排除

  • Launch Monitor 支援文章部分

您可以在此找到 Launch Monitor 常見問題及其解決方案的清單。

情景：裝置未連接

在上述範例情景中，Launch Monitor 在設定中已啟用，但裝置未連接/未被識別。

建議的疑難排解步驟：

  • 檢查裝置是否仍然開啟。

  • 嘗試重新啟動裝置。

  • 盡可能嘗試透過 USB 或乙太網路連接，而不是 WiFi。

  • 嘗試使用製造商的軟體連接，以確認是否可以建立連接。

情景：未觸發錄製。

Launch Monitor 已連接並被識別，但在捕捉模式下未觸發。

建議的疑難排解步驟：

  • 確保觸發器選項已啟用。

  • 球和/或球桿數據是否出現在裝置上？（您能驗證它在 Swing Catalyst 外是否正常運作嗎？）

  • 是否有任何影格遺漏或資料不足的警告？如果攝影機遺漏影格，Swing Catalyst 將不會觸發。
