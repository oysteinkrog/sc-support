Як налаштувати камери Basler GigE з Swing Catalyst

Ця стаття технічної підтримки охоплює налаштування та конфігурацію камер Basler з Swing Catalyst.

note: Для використання камер Basler з Swing Catalyst вам знадобляться USB-донгл Halcon та ліцензія. Будь ласка, зверніться на contact@swingcatalyst.com для придбання ліцензії.

Інструкції з встановлення та налаштування Halcon тут:

halcon-setup.md

Важливо:

Переконайтеся, що у вас встановлений драйвер-фільтр MVTec Halcon — без нього камери не працюватимуть належним чином. Також переконайтеся, що всі інші встановлені драйвери-фільтри вимкнені, наприклад драйвер-фільтр Basler.

Переконайтеся, що SwingCatalyst дозволено в брандмауері Windows Defender як для приватних, так і для публічних мереж.

example:

Налаштування IP-адрес камер

Налаштування IP

Кожна камера та карта Ethernet (NIC / мережевий інтерфейсний контролер) мають бути налаштовані зі статичними IP у різних підмережах (та масці підмережі).

note: IP NIC — це IP-адреса мережевого адаптера на вашому комп’ютері, а IP камери — це IP-адреса самої камери. Позначення … вказує на діапазон, оскільки це лише приклад IP-адрес, які ви можете встановити.

Приклади для одно- або багатокамерних конфігурацій (з однією або декількома мережевими картами / адаптерами):

Камери на мережевому адаптері 1:
nic ip: 10.0.1.1
cam ip: 10.0.1.10 ... 10.0.1.20
subnet mask:255.255.255.0

Камери на мережевому адаптері 2:
nic ip: 10.0.2.1
cam ip: 10.0.2.10 ... 10.0.2.20
subnet mask: 255.255.255.0

Камери на мережевому адаптері 3:
nic ip: 10.0.3.1
cam ip: 10.0.3.10 ... 10.0.3.20
subnet mask: 255.255.255.0

Камери на мережевому адаптері 4:
nic ip: 10.0.4.1
cam ip: 10.0.4.10 ... 10.0.4.20
subnet mask: 255.255.255.0

Спершу нам потрібно налаштувати IP-адресу камери — це робиться через Pylon IP Configurator.

Натисніть кнопку «Пуск» на клавіатурі та введіть pylon ip — має з’явитися IP Configurator. Якщо цього не сталося, швидше за все, програмне забезпечення не встановлено.

Щоб встановити програмне забезпечення Pylon, перейдіть на: https://www.baslerweb.com/en/sales-support/downloads/software-downloads/ та знайдіть: pylon 5.1.0 Camera Software Suite Windows.

Клацніть на камеру, потім виберіть Static IP

Встановіть IP-адресу камери та маску підмережі відповідно до наведеного вище прикладу.

note: Якщо ви використовуєте декілька камер, вам необхідно

Налаштування камер Basler GigE через Halcon

У SwingCatalyst перейдіть на вкладку «Налаштування», а потім до розділу «Камери».

Натисніть Advanced.

  • Перейдіть на вкладку Configuration.

  • Увімкніть прапорець GtlNumBuffers та введіть значення 200.

Налаштування камер Basler GigE:

Розгляньмо, як налаштувати витримку, швидкість затвора та Частоту кадрів.

warning: Якщо ви не можете переглянути налаштування та отримуєте помилку в SwingCatalyst, перевірте налаштування брандмауера Windows. Спробуйте вимкнути брандмауер, щоб перевірити, чи він блокує доступ SwingCatalyst до камер.

Якщо налаштування працюють і потокове передавання відбувається нормально, переконайтеся, що SwingCatalyst дозволено як у публічних, так і в приватних мережах у брандмауері Windows Defender.

Розгорніть вкладку AcquisitionTrigger, введіть максимальну (або нижчу) Частоту кадрів, а потім натисніть Enable Acquisition Frame Rate. Це дозволить вам визначити Частоту кадрів. Примітка: Частота кадрів може бути обмежена значеннями витримки.

Налаштування значень витримки

Зазвичай найкраще використовувати ручну витримку для статичних середовищ, наприклад закритих студій. Повністю автоматична витримка може змінити Частоту кадрів та призвести до нестабільного зображення. У цьому випадку ми не використовуємо авторежим витримки, оскільки хочемо керувати нею самостійно. Загалом рекомендується час витримки менше 2000 (2 мс).

Налаштування значень Gain

Подібно до витримки, для статичних / закритих умов освітлення найкраще встановити Gain вручну. Чим вище значення витримки, тим зернистішим буде зображення та тим довше триватиме кодування відео порівняно з низьким Gain.

Щоб встановити Gain вручну, змініть Gain Auto з Continuous на Off, потім зупиніть та відновіть Відтворення для перезавантаження налаштувань. Встановіть значення Gain, змінюючи числові значення у полі Gain (Raw).

Зміна розміру зображення, зони інтересу, Region of Interest тощо

У деяких випадках ви хочете зменшити розмір зображення, щоб зосередитись на певній ділянці відеозображення, наприклад, для детального перегляду клюшки та м’яча в Момент удару.

Це можна зробити за допомогою зони інтересу (AOI) та ROI (Region of Interest). Зменшення загального розміру зображення за допомогою цієї функції також може збільшити Частоту кадрів.

Збереження налаштувань на камеру

Важливо зберегти налаштування на камеру. Якщо цього не зробити, всі внесені вами зміни буде втрачено.

Переконайтеся, що ви налаштували Default Set Selector та Default Startup Set. Існують різні набори користувача на вибір, і теоретично ви можете зберегти різні налаштування в кожному наборі. Тобто ви можете вибрати «User Set 1» як стандартний, а потім натиснути User Set Save, щоб зберегти поточні налаштування до цього профілю.
