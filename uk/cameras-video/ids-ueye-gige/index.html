Як налаштувати камери IDS uEye GigE для роботи з Swing Catalyst

Для налаштування USB-камери, будь ласка, зверніться до цієї статті: ids-ueye-usb.md

Примітка: У цій статті передбачається, що ви вже встановили Драйвери uEye, які можна знайти тут: https://www.swingcatalyst.com/drivers

Ця стаття охоплює налаштування IP-адрес як камери, так і мережевої карти.

Примітка: SwingCatalyst не підтримує функцію IDS AOI (area of interest) для камер IDS.

Сумісні мережеві адаптери та конфігурація:

Будь ласка, зверніться до: gige-network-setup.md

Примітка, важливо для продуктивності: Якщо у вас мережева карта Intel, завантажте та встановіть Драйвери Intel, оскільки це надасть вам можливість налаштувати частоту переривань (interrupt moderation rates), яка може бути недоступна зі стандартними Драйверами Windows.

Налаштування камер IDS uEye GigE

Кроки:

Перш ніж продовжити, встановіть Драйвери IDS uEye. Знайдіть та відкрийте програму IDS Camera Manager (її можна знайти за шляхом: C:\ProgramData\Microsoft\Windows\Start Menu\Programs\IDS).

Програма IDS Camera Manager:

Зверніть увагу на попередження внизу програми. Можуть з’являтися різні попередження, пов’язані з неправильно налаштованими IP-адресами або мікропрограмою камери.

Приклад:

Примітка щодо налаштування IP-адреси та наших рекомендацій**

**

Ми рекомендуємо використовувати одну виділену мережеву карту або мережевий інтерфейс для кожної камери. Однак для моделі IDS UI-3220 можна підключити дві камери до одного мережевого порту за допомогою мережевого комутатора (дивіться розділ «Використання мережевого комутатора»).

Рекомендоване налаштування IP:

Кожна камера та мережева карта (також відома як NIC) повинні бути налаштовані зі статичними IP-адресами в різних підмережах (і маскою підмережі).

Приклад:

Камери на мережевій карті 1: nic ip: 10.0.1.1 cam ip: 10.0.1.10 … 10.0.1.20 subnet mask:255.255.255.0

Камери на мережевій карті 2: nic ip: 10.0.2.1 (інша підмережа, ніж у nic1) cam ip: 10.0.2.10 … 10.0.2.20 (інша підмережа, ніж у nic1) subnet mask: 255.255.255.0

Увімкнення мережевої служби uEye

Примітка: Якщо ви використовуєте різні типи камер від різних виробників, увімкнення мережевої служби uEye може спричинити проблеми при роботі з камерою іншого виробника.

Натисніть на ETH network service

Виберіть мережевий адаптер, який ви хочете налаштувати (у цьому випадку це двопортовий адаптер)

Зображення мережевої карти відображається сірим кольором — це означає, що вона налаштована неправильно. Для того щоб камера була видимою в мережі, необхідно увімкнути мережеву службу uEye.

Обов’язково встановіть IP-адресу та маску підмережі відповідно до рекомендацій (дивіться вище), потім натисніть Enable uEye network service і Apply changes (тепер ви встановили статичну IP-адресу для одного з портів двопортового адаптера!).

Автоматичне налаштування IP (для ручного налаштування IP дивіться нижче)

Щоб скористатися автоматичним налаштуванням IP, натисніть Automatic ETH configuration і натисніть OK.

IDS Camera Manager автоматично встановить IP-адресу для мережевої карти та камери.

Примітка: При використанні кількох камер ми рекомендуємо ручне налаштування IP.

Ручне налаштування IP

Повернувшись до IDS Camera Manager, ви тепер маєте бачити список камер. Оскільки раніше ви вже встановили статичну IP-адресу для мережевого адаптера, тепер необхідно встановити статичну IP-адресу для камери, щоб мережевий адаптер і камера могли коректно обмінюватися даними між собою.

Встановіть прапорець Expert Mode, як показано тут:

Зверніть увагу на попередження, виділене червоним кольором вище.

Натисніть Manual ETH configuration:

На знімку екрана вище IP-адреса камери встановлена як 10.0.1.10 (IP-адреса нашої мережевої карти — 10.0.1.1). Введіть значення, як показано на знімку екрана вище, і натисніть OK.

Примітка: встановлення статичних IP-адрес не є обов’язковим, але настійно рекомендується, оскільки автоматичне налаштування IP може спричиняти проблеми через конфлікти IP-адрес, наприклад, коли одна й та сама IP-адреса використовується в іншому місці. Ми настійно рекомендуємо використовувати статичне налаштування для всіх студійних інсталяцій.

Повторіть ті самі дії для інших камер та NIC відповідно до наших рекомендованих конфігурацій IP вище.

Налаштування мережевих адаптерів для використання з камерами IDS uEye

Припускаючи, що ви вже встановили статичні IP-адреси як для камер, так і для мережевої карти, перейдемо до налаштування мережевого адаптера для досягнення найкращої продуктивності.

У розділі Панель керування\Мережа та Інтернет\Мережеві підключення двічі клацніть на адаптері, який потрібно налаштувати — у нашому випадку це Ethernet 4, Intel (PRO/1000 PT Dual port).

Двічі клацніть на мережевому адаптері, який потрібно налаштувати.

Перейдіть на вкладку «Додатково». Примітка: Конфігурація відрізняється для кожного мережевого адаптера і залежить від Драйвера. Будь ласка, зверніться до документації вашої мережевої карти для отримання конкретної інформації про зміну наведених нижче параметрів.

Переконайтеся, що Interrupt Moderation увімкнено, а Interrupt Moderation Rate встановлено на Extreme.

Якщо параметр Extreme недоступний, встановіть значення High.

У деяких випадках вимкнення interrupt moderation може допомогти, якщо жодне з високих значень не працює, але якщо у вас рекомендована мережева карта, параметри High і Extreme мають бути доступні. Увімкнення interrupt moderation є критично важливим для зниження навантаження на CPU при обробці великої кількості пакетів, особливо при використанні камер з високою роздільною здатністю та/або високим FPS.

Interrupt moderation rate:

Увімкніть підтримку Jumbo Packets (встановіть значення 9014 Bytes):

Receive Buffers:

Рекомендується встановити це значення якомога вище. Це може допомогти уникнути втрати Кадрів при використанні кількох камер та/або GigE-камер з високою роздільною здатністю.

Використання мережевого комутатора:

Якщо ви використовуєте мережевий комутатор, важливо, щоб він підтримував 9KB Jumbo Frames, а мережевий адаптер був налаштований на використання 9KB Jumbo Frames. Однак у деяких випадках окремі комутатори можуть некоректно працювати з розміром Кадрів 9KB — у таких ситуаціях рекомендується зменшити значення нижче 9KB і повторно перевірити налаштування.

Використання камер у SwingCatalyst

Після налаштування IP-адрес та мережевих адаптерів відповідно до наведених вище рекомендацій можна запустити SwingCatalyst — камера має відобразитися у списку камер.

Встановіть Кут камери, увімкніть камеру та натисніть Configure.

Переконайтеся, що pixel clock встановлено на максимум (або зменште його, якщо спостерігається втрата Кадрів).

Встановіть витримку та Gain (зверніть увагу, що ці значення можуть значно змінюватися залежно від вимог, типу камери та рівня освітлення).

Усунення несправностей камер IDS

Якщо у вас спостерігається втрата Кадрів або проблеми із синхронізацією камери IDS uEye GigE, скористайтеся утилітою uEye Cockpit.

Натисніть Live Video

Натисніть на іконку відтворення, потім натисніть на іконку гайкового ключа

Зверніть увагу на показник використання пропускної здатності. На вкладці Camera збільште Pixel clock, встановіть прапорець Max у розділі Frame rate (Freerun), а потім зменште час експозиції (витримку).

Після налаштування камер для потокового відтворення в реальному часі натисніть Вид -> Performance Overview

Вид Host Performance може бути дуже корисним для діагностики проблем зі стабільністю та втратою Кадрів.

Використання рядка стану в uEye Cockpit для відображення втрати Кадрів або проблем із підключенням під час потокового відтворення відео:

Роздільна здатність камери, отримані Кадри, відображені Кадри, невдалі Кадри та спроби повторного підключення — як показано на знімку екрана:
