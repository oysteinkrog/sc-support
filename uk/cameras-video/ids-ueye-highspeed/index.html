Як налаштувати високошвидкісні USB-камери

У цій статті технічної підтримки описано, як встановити та налаштувати камеру USB 2.0 або 3.0 для використання в Swing Catalyst.

Наступні USB-камери наразі підтримуються в останній версії Swing Catalyst:

USB 2.0:

  • IDS uEye UI-1220LE-C-HQ

  • IDS uEye UI-1220LE-M-HQ

USB 3.0:

  • IDS uEye UI-3220CP-C-HQ

  • IDS uEye UI-3240LE

  • IDS uEye UI-3240CP Rev. 2

Примітка: Не можна поєднувати камери USB 3.0 та USB 2.0, оскільки в більшості випадків це призводить до втрати кадрів, якщо у вас немає окремого хост-контролера для USB 2.0 і USB 3.0.

Апаратні вимоги та встановлення

USB 3.0:

Для використання камери USB 3.0 потрібен комп’ютер із портом USB 3.0. Варто зазначити, що деякі комп’ютери можуть бути не здатні забезпечити максимальну частоту кадрів камери USB 3.0, оскільки ці камери наразі обмежені максимальною пропускною здатністю порту USB 3.0.

У багатьох випадках для отримання оптимальної частоти кадрів на деяких камерах необхідно використовувати окремий контролер USB 3.0, наданий виробником.

Див.: Рекомендовані компоненти USB3

У випадках, коли це є проблемою, рекомендується знизити «тактову частоту пікселів». Це також знизить максимальну частоту кадрів.

USB-камери не потребують зовнішнього джерела живлення, а єдиний необхідний кабель — це сертифікований кабель USB 3.0 для машинного зору. Ми не рекомендуємо кабелі довжиною понад 5 метрів як для USB 3, так і для USB 2.

Для більших відстаней необхідні активні подовжувальні кабелі USB, а для камер USB 3.0 вони мають бути сертифіковані для роботи з камерами машинного зору.

Для камер USB 2.0 підійде будь-який кабель USB A — Mini-B довжиною до 5 метрів.

Встановлення програмного забезпечення

Перш ніж використовувати USB-камеру, необхідно встановити драйвери. Необхідні Драйвери можна завантажити з наступного веб-сайту:

https://www.swingcatalyst.com/drivers

Після завантаження драйверів (оберіть 32-розрядну або 64-розрядну версію залежно від вашої версії Windows) запустіть файл і дотримуйтесь інструкцій на екрані.

Налаштування та використання
