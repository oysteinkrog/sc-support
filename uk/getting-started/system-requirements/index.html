Вимоги до комп’ютера для SwingCatalyst

Важлива примітка: SwingCatalyst не сумісний з Mac OS (архітектура Arm) або Windows 11 Arm.

Короткий огляд

Щоб забезпечити плавне Відеозахоплення та Відтворення, ваш комп’ютер має відповідати таким основним вимогам:

  • Сучасний ігровий ноутбук або потужний настільний комп’ютер

  • 32 ГБ оперативної пам’яті (RAM)

  • Сучасна відеокарта (NVIDIA RTX 3060 6 ГБ або краща)

  • Сучасний процесор Intel або AMD з 8 або більше ядрами

  • Ми НАПОЛЕГЛИВО рекомендуємо використовувати найновіші серії GPU від NVIDIA для найшвидшого кодування та обробки MoCap. Наразі найновішою серією є RTX 5060, 5070, 5080, 5090.

Вимоги до ноутбука

Якщо ви використовуєте ноутбук, ми рекомендуємо ігровий ноутбук із такими характеристиками:

  • Пам’ять: 32 ГБ RAM

  • Процесор: Сучасний Intel i5, i7 або i9 (9-е покоління або новіше) з щонайменше 8 ядрами

  • Відеокарта: NVIDIA RTX 3060 (або новіша) з щонайменше 6 ГБ виділеної пам’яті

Рекомендації щодо підключення камер

  • Використовуйте лише оригінальні високоякісні USB-кабелі, що входили до комплекту камер, або інші кабелі, сертифіковані для машинного зору

  • Підключайте камери безпосередньо до комп’ютера (уникайте USB-концентраторів або подовжувальних кабелів)

  • Одночасно можна підключити не більше двох USB-камер

  • Для камер Ethernet (GigE) переконайтеся, що є вільний слот PCI Express для окремої мережевої карти або мережевих карт залежно від кількості камер.

Детальні рекомендації щодо апаратного забезпечення

Рекомендовані процесори

Варіанти Intel (від найновіших до найстаріших)

14-е покоління (найновіше)

  • Intel Core i9-14900/14900K (найкраща Продуктивність)

  • Intel Core i7-14700KF (висока Продуктивність)

  • Intel Core i5-14400F (хороша Продуктивність)

13-е покоління

  • Intel Core i9-13900K/KF

  • Intel Core i7-13700K/KF

  • Intel Core i5-13600K/KF

12-е покоління

  • Intel Core i9-12900K

  • Intel Core i7-12700K

  • Intel Core i5-12600K

Варіанти AMD

  • AMD Ryzen 9 9950X3D (16 ядер, найкраща Продуктивність)

  • AMD Ryzen 7 9800X3D (8 ядер, висока Продуктивність)

  • AMD Ryzen 9 7900X (12 ядер, найкраща Продуктивність)

  • AMD Ryzen 7 7700X (8 ядер, хороша Продуктивність)

  • AMD Ryzen 9 5900XT (16 ядер, попереднє покоління, хороше співвідношення ціни та якості)

Для CPU від AMD ми наполегливо рекомендуємо придбати додаткову карту контролера USB 3 для оптимальної сумісності.

Технічна примітка: Ваш процесор повинен бути здатний досягати швидкості 3,8 ГГц або вище для оптимальної продуктивності. Програмне забезпечення вимагає процесорів із підтримкою інструкцій AVX та AVX2 (більшість сучасних процесорів це підтримують).

Рекомендовані відеокарти

Ми рекомендуємо щонайменше 6 ГБ виділеної пам’яті GPU (VRAM) — чим більше, тим краще.

Найвищий рівень (виняткова Продуктивність)

  • RTX 5090 (найкращий варіант)

  • RTX 4090

  • RTX 3090

  • RTX 4080

Високий рівень (відмінна Продуктивність)

  • RTX 5080

  • RTX 5070

  • RTX 4070

  • RTX 3080

Середній рівень (хороша Продуктивність)

  • RTX 5060

  • RTX 3070

  • RTX 4060

Початковий рівень (мінімально рекомендований)

  • RTX 3060

Примітка: Усі карти, перелічені вище, відповідають мінімальним вимогам програмного забезпечення. Карти вищого рівня забезпечують кращу Продуктивність, особливо при роботі з кількома камерами та/або відео у високій роздільній здатності.
