Як налаштувати кілька дисплеїв

Ця стаття підтримки охоплює налаштування та конфігурацію кількох дисплеїв у Windows. Налаштування екрана зворотного зв’язку в Swing Catalyst та використання сценаріїв із кількома дисплеями в Swing Catalyst, а також показує, як навігувати та переміщувати вікна з більш ніж одним монітором.

Як налаштувати кілька дисплеїв у Windows:

  1. Переконайтеся, що ваш комп’ютер здатен підключатися до кількох дисплеїв. Деякі комп’ютери або ноутбуки мають обмеження, такі як максимум 2 дисплеї.

Для налаштування з більш ніж двома дисплеями вам потрібна графічна карта, здатна забезпечити необхідну кількість виходів, або, якщо ви просто хочете дублювати дисплей, це можна зробити за допомогою HDMI сплітерів (докладніше про це нижче).

  1. Переконайтеся, що у вас є необхідні кабелі для підключення до дисплея. Найпоширеніші типи з’єднань сьогодні: HDMI, DVI або Display Port. Останній часто вимагає адаптера. Більшість сучасних комп’ютерів мають порт HDMI, проте деякі ноутбуки мають HDMI mini або display port.

Важливо знати тип порту, до якого ви підключаєтесь, щоб мати відповідний адаптер, якщо необхідно.

  1. Підключіть монітор до комп’ютера, натисніть правою кнопкою миші на робочому столі та виберіть Параметри дисплея.

If the display has been successfully detected it should show more than one display.

To set your display as the main display, check the “Make this my main display” box.

Note: You may want to set your main display to display 1 (i.e the first output on the graphics card).

If you wish to extend the desktop to your secondary display select the option under Multiple displays.

Please note that if the display you’re connecting to has a higher or lower resolution the image might be slightly different. The DPI also might be different causing the text to be larger or smaller than what you might be used to. Use the recommended resolution where possible.

Now that we have more than one display set up in Windows, make sure you have the orientation right (i.e that the monitor on the right is to your right). Having this sorted helps a lot in navigating; especially if it’s more than two displays.

Note: Windows 7 has a different configuration for displays, but the overall process is the same.
