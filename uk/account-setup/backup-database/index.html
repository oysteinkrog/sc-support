Як створити резервну копію бази даних SwingCatalyst

Ця стаття підтримки описує, як вручну створити резервну копію бази даних SwingCatalyst

Щоб налаштувати автоматичне резервне копіювання, перегляньте статтю automatic-backups.md

Вимоги:

  • Зовнішній жорсткий диск або додатковий жорсткий диск із достатньою кількістю вільного місця для бази даних SwingCatalyst.

Крок 1: Створення резервної копії файлу бази даних

Note: Файл бази даних SwingCatalyst містить інформацію про кожен Замах і Урок, що були записані. По суті, це одна велика таблиця пошуку.

Важливо створити резервну копію цього файлу, яка відповідатиме фактичним відео- та файлам даних.

База даних SwingCatalyst знаходиться за шляхом C:\ProgramData\Swing Catalyst\

  1. Перейдіть до ProgramData, ввівши %programdata% і натиснувши клавішу Enter.

Скопіюйте файл SwingCatalystDB.s3db на зовнішній жорсткий диск або додатковий жорсткий диск.

Крок 2: Резервне копіювання самих замахів

Визначення розташування бази даних

  • Перейдіть до налаштувань SwingCatalyst, натисніть «Загальні» та зверніть увагу на розділ «База даних» праворуч.

  • Занотуйте розташування бази даних — саме тут зберігаються ваші записи та уроки.

У цьому прикладі вміст бази даних (замахи, мініатюри та дані) знаходиться на диску D:. Базу даних було переміщено з диска C:\ через обмежений простір, що можна побачити тут:

Стандартне розташування: C:\Program Data\ Swing Catalyst\database.

Щоб перемістити базу даних на більший жорсткий диск або розділ, перегляньте цю статтю: move-database.md

Зверніть увагу, що ця папка містить файли уроків, гольфістів, резервні копії попередніх баз даних SwingCatalyst тощо. Найкраще скопіювати весь вміст цієї папки.

Якщо ваша база даних (відповідно до наведеного вище знімка екрана) вказує на C:\ProgramData\Swing Catalyst\database, створіть копію папки database.

У нашому випадку ми хочемо створити копію папки Swing Catalyst Databases.

Цю папку та файл SwingCatalystDB.s3db можна скопіювати на зовнішній жорсткий диск або до резервного розташування для зберігання.

Якщо ви надалі захочете оновити резервну копію, ви можете замінити файл SwingCatalystDB.s3db (у резервному розташуванні) та скопіювати нових гольфістів, щоб підтримувати резервну копію в актуальному стані.
