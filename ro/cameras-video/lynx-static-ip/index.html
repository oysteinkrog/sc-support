Cum să setați IP static pe camerele Lynx GigE

Introducere

Acest articol de asistență descrie cum să configurați camerele Lynx cu o adresă IP statică. Pentru utilizarea normală, acest lucru nu este necesar, deoarece Swing Catalyst gestionează configurarea IP în mod automat.

Cerințe

  • Aplicația MVS (utilizată pentru configurarea IP-urilor).

  • Swing Catalyst versiunea 9.8.5 sau ulterioară.

  • O cameră Swing Catalyst Lynx GigE.

  • O configurație de cameră deja funcțională.

Instalarea aplicației MVS

  • Descărcați și extrageți aplicația client MVS: https://swingcatalyst.s3.amazonaws.com/drivers/MVS_STD_3.4.1_220407.zip

  • Instalați MVS, urmând instrucțiunile de pe ecran.

  • Debifați opțiunea de deschidere a notelor de Eliberare.

  • Faceți clic pe Terminare.

Setarea unui IP static pe Adaptorul Ethernet

Odată ce camerele au adrese IP statice atribuite, trebuie să configurați adaptoarele de rețea pe care intenționați să le utilizați cu un IP static. Aceasta trebuie configurată astfel încât să corespundă fiecărei camere conectate.

Aceasta înseamnă că, dacă deconectați camera și o conectați la un alt adaptor Ethernet, nu va „funcționa" dacă nu este reconfigurată.

Avertisment:

Numărul „Adaptorului Ethernet" menționat mai jos nu este numărul asociat cu adaptorul de rețea, ci este folosit doar în scop ilustrativ. Vă rugăm să configurați fiecare adaptor de rețea pentru fiecare cameră în parte, adică dacă aveți două camere conectate, configurați-le secvențial și consultați tabelele pentru adaptorul Ethernet 1 și 2; nu modificați setările adaptorilor de rețea la care nu sunt conectate camere identificate.

  • Faceți clic dreapta pe Adaptorul Ethernet de deasupra camerei conectate.

  • Faceți clic pe „Setări NIC".

  • Activați Jumbo Frame.

  • Setați Receive Buffers la valoarea maximă.

  • Setați Transmit Buffers la valoarea maximă.

  • Faceți clic pe „Deschide" la „Proprietăți protocol Internet".

  • Configurați adaptorul de rețea conform tabelului de mai jos.

Configurație IP static recomandată pentru fiecare adaptor Ethernet

Acesta este un exemplu de configurație cu adrese IP statice. Rețineți IP-ul pentru Adaptorul Ethernet și camerele respective.

Numărul Adaptorului Ethernet IP Adaptor Ethernet Mască de subrețea Gateway Conectat la Camera IP Cameră
1 10.0.1.1 255.255.255.0 10.0.1.1 1 10.0.1.10
2 10.0.2.1 255.255.255.0 10.0.2.1 2 10.0.2.10
3 10.0.3.1 255.255.255.0 10.0.3.1 3 10.0.3.10
4 10.0.4.1 255.255.255.0 10.0.4.1 4 10.0.4.10

Setarea unui IP static pe cameră

Asigurați-vă că camera (camerele) Lynx este conectată. Dacă ați conectat-o după pornirea aplicației, plasați cursorul mouse-ului peste meniul „GigE" și faceți clic pe butonul de reîmprospătare.

Acest proces trebuie repetat pentru toate camerele Lynx conectate pe care ați setat un IP static.

Rețineți că va trebui să setați IP static pe camera 1, apoi pe placa de rețea 1, secvențial. După ce ați terminat cu 1, treceți la 2 etc. Numerele menționate nu reprezintă numele reale ale adaptoarelor de rețea, de exemplu „Ethernet 2", ci sunt folosite doar în scop ilustrativ.

  • Faceți clic dreapta pe cameră în listă și faceți clic pe „Modificare IP".

  • Schimbați selecția din DHCP sau LLA în IP Static.

  • Configurați adresa IP și masca de subrețea conform descrierii de mai jos.

  • IP-ul trebuie să fie diferit pentru fiecare cameră.

Configurație IP static recomandată pentru camere

Nr. Cameră IP Mască de subrețea Gateway
1 10.0.1.10 255.255.255.0 10.0.1.1
2 10.0.2.10 255.255.255.0 10.0.2.1
3 10.0.3.10 255.255.255.0 10.0.3.1
4 10.0.4.10 255.255.255.0 10.0.4.1
