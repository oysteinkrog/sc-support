Cum se configurează camerele USB de înaltă viteză IDS uEye

Cum să configurați camere USB de înaltă viteză

Acest articol de suport va descrie cum să instalați și să configurați o cameră USB 2.0 sau 3.0 pentru utilizare în Swing Catalyst.

Următoarele camere USB sunt în prezent acceptate în cea mai recentă versiune a Swing Catalyst:

USB 2.0:

  • IDS uEye UI-1220LE-C-HQ

  • IDS uEye UI-1220LE-M-HQ

USB 3.0:

  • IDS uEye UI-3220CP-C-HQ

  • IDS uEye UI-3240LE

  • IDS uEye UI-3240CP Rev. 2

Notă: Nu puteți amesteca camere USB 3.0 și 2.0, deoarece va rezulta în cadre pierdute în majoritatea cazurilor, decât dacă aveți un controler gazdă dedicat pentru USB 2.0 și 3.0 separat.

Cerințe hardware și instalare

USB 3.0:

Pentru a utiliza o cameră USB 3.0, aveți nevoie de un computer cu port USB 3.0. Este important de menționat că unele computere ar putea să nu fie în stare să utilizeze viteza maximă/completă a cadrelor unei camere USB 3.0, deoarece aceste camere sunt în prezent limitate de lărgimea de bandă maximă disponibilă pe portul USB 3.0.

În multe cazuri, este necesar să utilizați un controler USB 3.0 dedicat furnizat de producător pentru a obține rate de cadru optime pe unele camere.

See: Recommended USB3 Components

In cases where this is a problem it is recommended to lower the “pixel clock” . This will also lower the maximum frame rate.

USB cameras require no external power supply and the only cable required is a machine vision certified USB 3.0 cable. We do not recommend cables longer than 5 meters, both for USB 3 and USB 2.

For longer distances Active USB repeater cables are required and for USB 3.0 cameras they need to be certified to work with machine vision cameras.

For USB 2.0 cameras any cable that is USB A to Mini-B will work up to 5 meters.

Software installation

Before you can use your USB camera you must install drivers, the required drivers can be downloaded from the following website:

https://www.swingcatalyst.com/drivers

After having downloaded the drivers (choosing 32 bit or 64 bit depending on your windows version) please run the file and follow the on-screen instructions.

For configuration and usage of a uEye camera please see the following support article, as well as the attached Install Guide pdf.
