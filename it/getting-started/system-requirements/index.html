Specifiche computer consigliate

Requisiti del Computer per Swing Catalyst

Nota Importante: Swing Catalyst non è compatibile con Mac OS (Architettura Arm) o Windows 11 Arm.

Riepilogo Rapido

Per garantire un’acquisizione video e una Riproduzione fluide, il tuo computer dovrebbe soddisfare questi requisiti di base:

  • Un laptop da gaming recente o un computer desktop potente

  • 32 GB di memoria (RAM)

  • Una scheda grafica moderna (NVIDIA RTX 3060 6GB o superiore)

  • Un processore Intel o AMD recente con 8 o più core

  • Raccomandiamo VIVAMENTE di utilizzare le ultime serie di GPU NVIDIA per i tempi di codifica più rapidi e l’elaborazione MoCap. Attualmente l’ultima serie è la RTX 5060, 5070, 5080, 5090.

Requisiti per Laptop

Se utilizzi un laptop, raccomandiamo un laptop da gaming con:

  • Memoria: 32 GB RAM

  • Processore: Intel i5, i7 o i9 recente (9ª generazione o successiva) con almeno 8 core

  • Scheda Grafica: NVIDIA RTX 3060 (o più recente), con almeno 6 GB di memoria dedicata

Linee Guida per il Collegamento delle Telecamere

  • Utilizza solo i cavi USB originali di alta qualità forniti con le telecamere, oppure altri cavi certificati per machine vision

  • Collega le telecamere direttamente al computer (evita hub USB o cavi di estensione)

  • Massimo due telecamere USB possono essere collegate contemporaneamente

  • Per le telecamere Ethernet (GigE), assicurati che ci sia uno slot PCI Express libero per una scheda di rete dedicata o più schede di rete, a seconda del numero di telecamere.

Raccomandazioni Hardware Dettagliate

Processori Consigliati

Opzioni Intel (dal più recente al più vecchio)

14ª Generazione (Più Recente)

  • Intel Core i9-14900/14900K (Prestazione Migliore)

  • Intel Core i7-14700KF (Ottima Prestazione)

  • Intel Core i5-14400F (Buona Prestazione)

13ª Generazione

  • Intel Core i9-13900K/KF

  • Intel Core i7-13700K/KF

  • Intel Core i5-13600K/KF

12ª Generazione

  • Intel Core i9-12900K

  • Intel Core i7-12700K

  • Intel Core i5-12600K

Opzioni AMD

  • AMD Ryzen 9 9950X3D (16 core, Prestazione Migliore)

  • AMD Ryzen 7 9800X3D (8 core, Ottima Prestazione)

  • AMD Ryzen 9 7900X (12 core, Prestazione Migliore)

  • AMD Ryzen 7 7700X (8 core, Buona Prestazione)

  • AMD Ryzen 9 5900XT (16 core, Generazione Precedente, buon rapporto qualità-prezzo)

Per i CPU AMD, raccomandiamo vivamente di acquistare una scheda controller USB 3 aggiuntiva per una compatibilità ottimale.

Nota Tecnica: Il tuo processore dovrebbe essere in grado di raggiungere velocità di 3,8 GHz o superiori per prestazioni ottimali. Il software richiede processori che supportino le istruzioni AVX e AVX2 (la maggior parte dei processori moderni le supporta).

Schede Grafiche Consigliate

Raccomandiamo un minimo di 6 GB di memoria GPU dedicata (VRAM); più è meglio.

Fascia Alta (Prestazione Eccezionale)

  • RTX 5090 (La Migliore Disponibile)

  • RTX 4090

  • RTX 3090

  • RTX 4080

Fascia Alta-Media (Eccellente Prestazione)

  • RTX 5080

  • RTX 5070

  • RTX 4070

  • RTX 3080

Fascia Media (Buona Prestazione)

  • RTX 5060

  • RTX 3070

  • RTX 4060

Fascia Base (Minimo Consigliato)

  • RTX 3060

Nota: Tutte le schede elencate sopra soddisfano i requisiti minimi per il software. Le schede di fascia superiore offriranno prestazioni migliori, specialmente quando si lavora con più telecamere e/o video ad alta risoluzione.
