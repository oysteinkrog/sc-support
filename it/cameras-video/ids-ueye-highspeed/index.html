Come configurare le telecamere USB ad alta velocità iDS uEye

Come configurare telecamere USB ad alta velocità

Questo articolo di supporto descrive come installare e configurare una telecamera USB 2.0 o 3.0 per l’uso in Swing Catalyst.

Le seguenti telecamere USB sono attualmente supportate nell’ultima versione di Swing Catalyst:

USB 2.0:

  • IDS uEye UI-1220LE-C-HQ

  • IDS uEye UI-1220LE-M-HQ

USB 3.0:

  • IDS uEye UI-3220CP-C-HQ

  • IDS uEye UI-3240LE

  • IDS uEye UI-3240CP Rev. 2

Nota: Non è possibile mescolare telecamere USB 3.0 e 2.0 poiché nella maggior parte dei casi si verificheranno perdite di fotogrammi, a meno che non si disponga di un controller host dedicato per USB 2.0 e 3.0 separatamente.

Requisiti hardware e installazione

USB 3.0:

Per utilizzare una telecamera USB 3.0 è necessario un computer con una porta USB 3.0. Vale la pena notare che alcuni computer potrebbero non essere in grado di utilizzare la frequenza fotogrammi massima/completa di una telecamera USB 3.0, poiché queste telecamere sono attualmente limitate dalla larghezza di banda massima disponibile sulla porta USB 3.0.

In molti casi è necessario utilizzare un controller USB 3.0 dedicato fornito dal produttore per ottenere frequenze fotogrammi ottimali su alcune telecamere.

See: Recommended USB3 Components

In cases where this is a problem it is recommended to lower the “pixel clock” . This will also lower the maximum frame rate.

USB cameras require no external power supply and the only cable required is a machine vision certified USB 3.0 cable. We do not recommend cables longer than 5 meters, both for USB 3 and USB 2.

For longer distances Active USB repeater cables are required and for USB 3.0 cameras they need to be certified to work with machine vision cameras.

For USB 2.0 cameras any cable that is USB A to Mini-B will work up to 5 meters.

Software installation

Before you can use your USB camera you must install drivers, the required drivers can be downloaded from the following website:

https://www.swingcatalyst.com/drivers

After having downloaded the drivers (choosing 32 bit or 64 bit depending on your windows version) please run the file and follow the on-screen instructions.
