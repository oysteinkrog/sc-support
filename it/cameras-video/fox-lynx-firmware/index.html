Come aggiornare o ripristinare il firmware per le fotocamere Fox o Lynx.

Prerequisiti:

  • Una fotocamera Fox o Lynx.

  • La suite software MVS.

  • Una copia del firmware per il modello di fotocamera che si desidera aggiornare o ripristinare.

Panoramica delle versioni firmware note come funzionanti / non funzionanti; scaricare il firmware dalla sezione download firmware.

ModelloDownload firmwareVersione firmware problematicaVersione firmware nota come funzionante
FoxScaricaV1.6.3 201222_551351V1.6.3 220416_798858
LynxScarica3.3.1 2209153.3.0 220408

Il software MVS può essere scaricato da: https://cloudfront.swingcatalyst.com/drivers/MVS_STD_3.4.1_220407.zip

Aggiornamento del firmware

  • Scaricare il firmware per la fotocamera che si desidera aggiornare o ripristinare dalla tabella precedente ed estrarre il file zip.

  • Installare il software MVS (se non è già installato)

Una volta installato, avviare l’applicazione MVS. La fotocamera collegata dovrebbe comparire nell’elenco a sinistra. Se è presente nell’elenco delle fotocamere, fare clic su Tool (nella barra degli strumenti in alto) e selezionare “Firmware Updater”.

L’applicazione Firmware Updater

Annotare il nome del modello e la versione del firmware; la versione 3.3.1 è una versione firmware nota come non funzionante (come indicato nella tabella precedente).

Selezionare la fotocamera o le fotocamere da aggiornare spuntando la casella di controllo a sinistra di “Model Name”, quindi fare clic sull’icona “cartella” in alto a destra e navigare fino alla cartella in cui è stato estratto il firmware.

Selezionare il file firmware e fare clic su “OK”. La finestra “Select Update File” si chiuderà e sarà possibile procedere facendo clic su “Update” nel software Firmware Updater.

Note: È possibile aggiornare più fotocamere contemporaneamente, ma devono essere dello stesso tipo / modello. Selezionare il file firmware che si desidera installare.
