Guida alla risoluzione dei problemi di connettività TrackMan

Si sta verificando il seguente problema:

TrackMan è connesso e visualizza i dati in TPS, ma Swing Catalyst non viene attivato e non sono presenti dati al suo interno.

  • Riavviare l’unità TrackMan.

  • Verificare di ricevere dati in TPS; in caso contrario, controllare nuovamente la Calibrazione.

  • Verificare che “Enable SDK Output” / “Legacy SDK” sia abilitato nelle impostazioni di TPS.

In Swing Catalyst 9.7.8 e 9.7.9 questo problema è stato ulteriormente migliorato. Se si sono seguite queste istruzioni senza successo, assicurarsi di utilizzare la versione 9.7.9 o successiva può contribuire a ridurre il ritardo.

Compensazione del ritardo del Launch Monitor di Swing Catalyst

Se si ricevono dati ma Swing Catalyst non attiva una Registrazione, provare a modificare il valore di “Trigger delay” a 1400.

TrackMan 3e

È possibile verificare se “Legacy SDK” è abilitato anche dall’interfaccia web del dispositivo. È possibile accedere all’interfaccia web dalle impostazioni di TPS, forzare l’operatore e controllare in Posizionamento.

Se l’output SDK è impostato in TPS e sul dispositivo ma non si ricevono ancora dati, provare a connettersi all’unità o all’SDK con uno strumento chiamato Hercules.

Monitorare l’output dall’unità / dal software TPS:

  • Assicurarsi che TPS sia in esecuzione e stia ricevendo dati dall’unità.

  • Scaricare ed eseguire Hercules.

  • Passare alla scheda TCP Client.

  • Inserire l’IP e la porta indicati di seguito e fare clic su connetti.

Indirizzi IP WiFi e USB

TrackMan 4

  • Ethernet: Non supportato.

  • Indirizzo USB 169.254.0.1 porta: 52950

  • Indirizzo WiFi 172.30.20.1 porta: 52950

  • Indirizzo sconosciuto: 169.254.88.214

TrackMan 3e:

  • Indirizzo USB 169.254.0.1 porta: 52950

  • Indirizzo WiFi 172.30.20.1 porta: 52950

TrackMan 2:

  • Connettersi direttamente al server TPS SDK su 127.0.0.1 porta: 52950

Se connesso correttamente in Hercules, si dovrebbe visualizzare il seguente output facendo clic sul pulsante di connessione.

In caso contrario, provare a riavviare il dispositivo TrackMan: il TrackMan Legacy SDK non sta inviando dati.

Se si riesce a connettersi, si dovrebbero ricevere dati nonché i dati dei colpi non appena viene rilevato un colpo.

Questi sono gli stessi dati che riceve Swing Catalyst, ed è un buon metodo per verificare che TPS e il TrackMan stiano effettivamente inviando dati.

Se non si riesce a connettersi, controllare il firewall: se connessi tramite WiFi, il TrackMan potrebbe essere identificato come rete pubblica, il che potrebbe causare problemi con alcuni firewall. Provare a disattivare il firewall per le reti pubbliche e verificare di nuovo: si ricevono ora i dati? In tal caso, assicurarsi che TPS e Swing / Motion Catalyst siano consentiti nel Firewall di Windows.

Controllare il file di log di Swing Catalyst:

C:\ProgramData\Swing Catalyst\logs\log.txt Se nel log viene visualizzato il seguente messaggio, il servizio TrackMan OEM è in esecuzione e deve essere disabilitato.

LaunchMonitorNetworkClientBase.OnTryConnectCompleted(): Successfully connected to [Trackman] on [127.0.0.1:8000].
