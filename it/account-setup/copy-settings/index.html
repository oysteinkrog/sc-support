Come spostare le impostazioni e la licenza di Swing Catalyst su un nuovo computer

Introduzione

Questo articolo descrive come copiare le impostazioni, la licenza e tutto il resto di Swing Catalyst su un nuovo computer o disco rigido.

Per effettuare una copia del database, fare riferimento al nostro articolo dedicato.

Preparazione

Assicurarsi che Swing Catalyst sia installato sul computer sul quale si desidera copiare il database.

Copiare i file delle impostazioni

Si consiglia di utilizzare un disco rigido esterno o una chiavetta USB per salvare le impostazioni durante il trasferimento tra i computer.

  • Aprire Esplora Risorse di Windows

  • Digitare quanto segue e premere Invio: %programdata% Si aprirà Esplora Risorse all’interno della cartella dei dati del programma.

  • Navigare nella cartella “Swing Catalyst”.

Tip: Tenere premuto CTRL sulla tastiera e selezionare ogni cartella facendo clic con il mouse.

Selezionare tutte le cartelle ad eccezione della cartella del database o dei Golfisti. Selezionare anche il file SwingCatalystDB.s3db, che è il file del database.

Fare clic con il tasto destro e selezionare Copia, quindi incollare il contenuto sulla chiavetta USB.

Copiare le impostazioni sul nuovo computer

Note: Assicurarsi che Swing Catalyst non sia in esecuzione prima di procedere. Questa operazione sovrascriverà le impostazioni, ovvero le impostazioni precedenti del vecchio computer sostituiranno quelle attuali.

Una volta copiato il contenuto sulla chiavetta USB, collegarla al nuovo computer e incollare il contenuto nella stessa posizione sul nuovo computer.

Ripetere i passaggi precedenti, ma invece di selezionare e copiare, incollare le cartelle e i file nella cartella dei dati del programma di Swing Catalyst.
