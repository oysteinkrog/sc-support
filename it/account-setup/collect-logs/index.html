Come raccogliere i log per il supporto

Ci sono casi in cui il supporto richiede informazioni specifiche sui log relativi a un problema.

Si prega di notare che ciò è necessario solo se il personale di supporto richiede esplicitamente l’invio dei file di log in questo modo.

Se si conosce l’orario approssimativo in cui si è verificato il problema, si prega di inviare il file con la data di ultima modifica più vicina al momento in cui si è verificato l’errore.

I file di log si trovano nella seguente posizione: C:\ProgramData\Swing Catalyst\logs

  • Vai alla directory ProgramData, digita %programdata% in Esplora Risorse di Windows e premi Invio.

  • Apri la directory di Swing Catalyst, quindi apri la directory dei log.

  • Copia il file log.txt e il file di log modificato più di recente in precedenza.

  • Allegalo al ticket di supporto o all’email che stai inviando al supporto.
