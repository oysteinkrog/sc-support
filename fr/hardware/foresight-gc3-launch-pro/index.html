Comment utiliser le Foresight GC3 / Bushnell Launch Pro avec Swing Catalyst

Introduction

Cet article de support décrit comment configurer le Foresight GC3 ou le Bushnell Launch Pro avec Swing Catalyst.

Le Foresight GC3 dispose du WiFi et du WiFi Direct, ainsi que de l’USB et de l’Ethernet, comme différentes façons de se connecter au Launch Monitor.

Veuillez noter que le WiFi, dans ce contexte, ne correspond pas à une connexion directe au GC3 — c’est ce qu’on appelle le WiFi Direct. Le WiFi désigne ici le réseau utilisé par le GC3 / BLP pour se connecter à un réseau sans fil existant.

Prérequis

  • Un ordinateur disposant d’un port USB libre, d’un port Ethernet ou du WiFi (en plus d’une connexion Internet).

  • Swing Catalyst 10.0 ou version ultérieure

Note: Si vous utilisez des caméras HD avec Swing Catalyst, nous recommandons d’exécuter FSX séparément (c’est-à-dire pas en même temps que Swing Catalyst) ou sur un autre ordinateur.

Veuillez vous assurer de disposer au minimum d’une NVIDIA GeForce 1080 ou supérieure et que le PC répond correctement aux recommandations de Foresight.

Connexion et configuration

  1. Connectez le GC3 via USB, WiFi* ou Ethernet.

  2. Dans Paramètres -> Matériel -> Launch Monitor, une sélection de Launch Monitor(s) avec différentes interfaces devrait être affichée.

  3. Assurez-vous de sélectionner le Launch Monitor que vous souhaitez utiliser avec l’interface de votre choix :

*** Si vous vous connectez via Wi-Fi, il est important de disposer d’un autre moyen de connexion Internet, car la validation par Internet est obligatoire pour utiliser le GC3.**

Dépannage

Le Foresight GC3 n’apparaît pas comme connecté ou ne se déclenche pas

Un bug connu dans le SDK Foresight affecte les versions 10.0 à 10.1.0 de Swing Catalyst.

Ce bug empêche Swing Catalyst de recevoir les données du GC3 / BLP.

Solution de contournement :

  • Fermez Swing Catalyst et connectez le GC3 / Launch Pro via USB à votre ordinateur.

  • Assurez-vous que le Foresight GC3 apparaît sur votre ordinateur. Il s’affichera en tant que périphérique de stockage de masse sous Ce PC.

  • Téléchargez et extrayez la solution de contournement depuis : https://cloudfront.swingcatalyst.com/files/GC3-BLP-Workaround.zip

  • Ouvrez le dossier extrait et double-cliquez sur « Workaround.exe ». Une fenêtre d’invite de commandes s’ouvrira et tentera de se connecter puis de se déconnecter de votre Launch Monitor.

Autres suggestions de dépannage :

  • Connectez l’appareil à un port USB différent sur l’ordinateur s’il n’apparaît pas.

  • Si vous êtes connecté via WiFi Direct, assurez-vous d’avoir accès à Internet par d’autres moyens, ou disposez d’une clé WiFi distincte.

  • Essayez de vous connecter via une interface différente ; par exemple, si vous avez tenté d’utiliser le WiFi, essayez l’Ethernet ou l’USB.

  • Assurez-vous qu’aucun autre logiciel ne tente de se connecter à l’appareil en même temps.

Le Foresight GC3 est connecté et se déclenche, mais les Enregistrements ne contiennent aucune donnée

  • Essayez d’éteindre puis de rallumer l’appareil GC3 / BLP.

  • Assurez-vous d’utiliser un club avec des autocollants correctement positionnés.

  • Assurez-vous qu’aucun autre Launch Monitor à base de caméra ne se trouve à proximité et ne pourrait interférer avec la capacité du GC3 / BLP à suivre la balle.

Pour un dépannage plus approfondi, veuillez consulter les articles de dépannage de Foresight ci-dessous.
