Guide de dépannage des problèmes de connectivité TrackMan

Vous rencontrez le problème suivant :

TrackMan est connecté et affiche des données dans TPS, mais SwingCatalyst n’est pas déclenché et aucune donnée n’est présente dans SwingCatalyst.

  • Redémarrez l’unité TrackMan elle-même.

  • Vérifiez si vous recevez des données dans TPS ; si ce n’est pas le cas, vérifiez de nouveau l’Étalonnage.

  • Assurez-vous que « Enable SDK Output » / « Legacy SDK » est activé dans les paramètres TPS.

Dans SwingCatalyst 9.7.8 et 9.7.9, ce problème a été davantage amélioré. Si vous avez suivi ces instructions sans succès, vérifier que vous utilisez la version 9.7.9 ou une version plus récente peut aider à réduire le délai.

Compensation du délai du Launch Monitor dans SwingCatalyst

Si vous recevez des données mais que SwingCatalyst ne déclenche pas d’Enregistrement, essayez de changer la valeur du « Trigger delay » à 1400.

TrackMan 3e

Vous pouvez également vérifier si le « Legacy SDK » est activé depuis l’interface web de l’appareil. Vous pouvez accéder à l’interface web depuis les paramètres TPS, en forçant le mode opérateur, puis en vérifiant sous Prise de Position.

Si la sortie SDK est configurée dans TPS et sur l’appareil et que vous ne recevez toujours pas de données, essayez de vous connecter à l’unité ou au SDK à l’aide d’un outil appelé Hercules.

Surveillez la sortie de l’unité / du logiciel TPS :

  • Assurez-vous que TPS est en cours d’exécution et qu’il reçoit des données de l’unité.

  • Téléchargez et exécutez Hercules.

  • Accédez à l’onglet TCP Client.

  • Saisissez l’IP et le port ci-dessous, puis cliquez sur Connecter.

Adresses IP WiFi & USB

TrackMan 4

  • Ethernet : Non pris en charge.

  • Adresse USB 169.254.0.1 port : 52950

  • Adresse WiFi 172.30.20.1 port : 52950

  • Source d’adresse inconnue : 169.254.88.214

TrackMan 3e :

  • Adresse USB 169.254.0.1 port : 52950

  • Adresse WiFi 172.30.20.1 port : 52950

TrackMan 2 :

  • Connectez-vous directement au serveur TPS SDK sur 127.0.0.1 port : 52950

Si la connexion dans Hercules est correctement établie, vous devriez voir la sortie suivante lorsque vous cliquez sur le bouton de connexion.

Si ce n’est pas le cas, essayez de redémarrer l’appareil TrackMan lui-même ; le TrackMan Legacy SDK n’émet pas de données.

Si vous parvenez à vous connecter, vous devriez recevoir des données ainsi que les données de tir dès qu’un tir est détecté.

Ce sont les mêmes données que reçoit SwingCatalyst, et c’est un bon moyen de s’assurer que TPS et le TrackMan envoient effectivement des données.

Si vous ne parvenez pas à vous connecter, vérifiez le pare-feu. Si vous êtes connecté via WiFi, le TrackMan peut être identifié comme un réseau public, ce qui peut poser problème avec certains pare-feux ; essayez de désactiver le pare-feu pour les réseaux publics et vérifiez à nouveau — recevez-vous des données maintenant ? Si oui, assurez-vous que TPS ainsi que Swing / Motion Catalyst sont autorisés dans le pare-feu Windows.

Vérifiez le fichier journal de SwingCatalyst :

C:\ProgramData\Swing Catalyst\logs\log.txt Si vous voyez le message suivant dans le journal, le service TrackMan OEM est en cours d’exécution et doit être désactivé.

LaunchMonitorNetworkClientBase.OnTryConnectCompleted(): Successfully connected to [Trackman] on [127.0.0.1:8000].
