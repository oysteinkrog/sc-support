Comment installer et configurer une Plateforme d’Équilibre 3

Introduction

Cet article d’assistance décrit comment configurer une nouvelle Plateforme d’Équilibre 3 pour une utilisation avec Swing Catalyst.

Prérequis

  • Un ordinateur avec un port USB disponible.

  • Swing Catalyst 7.1.8 ou version ultérieure.

Installation

Pour les détails d’installation, veuillez consulter le PDF joint en bas de l’article.

Cet article concerne la Plateforme d’Équilibre 3 et la Plateforme d’Équilibre 3s.

Vous souhaitez uniquement effectuer un étalonnage terrain de votre plateforme ? Cliquez ici

Avertissement

Certains problèmes ont été constatés avec les chipsets AMD 300 Series (AMD Ryzen 1700 / 2700 series) avec des périphériques USB 1.1. Plus précisément avec la Plateforme d’Équilibre, où vous n’obtenez que 75 échantillons par seconde au lieu de ~145 échantillons par seconde. Nous recommandons d’utiliser un hub USB 2.0, ce qui permettra à la Plateforme d’Équilibre de transmettre les données à la fréquence d’échantillonnage maximale.

Aucun problème connu n’a été répertorié concernant l’utilisation des chipsets AMD 300 Series avec des périphériques USB 3.0.

Installation des Drivers

  • Installez les Drivers depuis le menu Démarrer de Windows - Swing Catalyst - dossier Drivers. Pour Windows 64 bits, exécutez « Balance Plate #2 Driver Installer (x64) » Pour Windows 32 bits, exécutez « Balance Plate #2 Driver Installer (x86) » Mon Windows est-il en 32 bits ou 64 bits ?

Vous pouvez également trouver les Drivers sur https://www.swingcatalyst.com/drivers

Exécution de l’utilitaire d’étalonnage

  • Télécharger l’utilitaire d’étalonnage

  • Si vous êtes invité à installer des Drivers, cliquez sur Oui.

  • Connectez la Plateforme d’Équilibre à l’ordinateur.

  • Ouvrez l’utilitaire SE nouvellement installé.

  • Sélectionnez une caméra ou une webcam et faites-la pointer sur la Plateforme d’Équilibre.
