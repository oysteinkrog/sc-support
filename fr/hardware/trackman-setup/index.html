Comment utiliser TrackMan avec Swing Catalyst

Cet article décrit comment connecter Swing Catalyst à TrackMan et enregistrer les Données du Moniteur de Lancement avec la vidéo. Pour activer l’intégration, le logiciel TrackMan doit être en cours d’exécution en même temps que Swing Catalyst.

Note: Pour utiliser TrackMan avec Swing Catalyst, vous devez disposer d’une caméra compatible avec la diffusion vidéo en continu. (Voir les caméras compatibles)

Installation : TrackMan Pro/Launch 4.0.9

  • Connecter l’unité TrackMan au PC

  • Démarrer TrackMan Pro ou TrackMan Launch et accéder à l’écran de suivi des coups

  • Démarrer Swing Catalyst et accéder à Paramètres - Matériel dans le menu de démarrage

  • Activer l’intégration du Launch Monitor

  • Sélectionner TrackMan

Installation : TrackMan Performance Studio

Versions compatibles 2.2-4.0

  • Connecter l’unité TrackMan au PC

  • Démarrer TrackMan Performance Studio

  • Accéder à l’écran Paramètres dans le menu de démarrage (Image 1 : symbole d’engrenage)

  • Activer la Sortie SDK (Image 2)

  • Accéder à Démarrer et cliquer sur Analyse de coup

  • Démarrer Swing Catalyst et accéder à Paramètres - Matériel dans le menu de démarrage

  • Activer l’intégration du Launch Monitor

  • Sélectionner TrackMan

Installation : TPS avec TM3e ou TrackMan 4

  • Mettre sous tension l’appareil TrackMan 3e

  • Se connecter au réseau WiFi TrackMan dans Windows. Vous pouvez également connecter le câble USB.

  • À l’exception de l’étape 1, suivre les mêmes étapes que dans le guide d’installation ci-dessus

Image 1 : Activation de la sortie SDK dans TrackMan Performance Studio.

Utilisation de Swing Catalyst avec TrackMan Pro/Launch/Performance Studio

  • Démarrer le logiciel TrackMan en premier et accéder à l’écran de suivi des coups.

  • Démarrer Swing Catalyst et effectuer des Swings en Capture.

  • Ouvrir un Swing enregistré pour afficher les données du coup dans une boîte de données à côté de la vidéo.

Si tout a été correctement installé, les données de coup TrackMan devraient désormais être capturées automatiquement et enregistrées avec la vidéo.

Configuration de la caméra

Dans certains cas, le logiciel TPS peut verrouiller les caméras du système, les rendant indisponibles dans le logiciel Swing Catalyst.

Dans une version future, le logiciel TPS pourrait introduire une option de configuration pour désactiver ce comportement, mais en attendant, TrackMan a fourni la solution de contournement suivante :

Ouvrir le logiciel TPS et noter le nom exact de la caméra tel qu’il apparaît dans la liste des caméras.

Localiser le fichier suivant et l’ouvrir dans le Bloc-notes :

C:\ProgramData\TrackMan\VideoManagement\ExcludeCameras.TMConfig

Ajouter le nom de la caméra dans le fichier. Si vous avez plusieurs caméras, ajoutez tous les noms, chacun sur une ligne séparée.

Dépannage

  • Vérifier que TrackMan est reconnu et connecté dans TPS.

  • S’assurer que le Launch Monitor est activé et que TrackMan est sélectionné dans le menu des paramètres matériels de Swing Catalyst.

  • Vérifier que « Déclencheur » est coché sous les paramètres du Launch Monitor dans Swing Catalyst.

  • Si le déclenchement ne fonctionne toujours pas, vérifier les Paramètres dans TPS et s’assurer que la « Sortie SDK » est activée.

  • Essayer de redémarrer l’appareil TrackMan.

  • Si vous recevez des données et que la connexion s’affiche dans Swing Catalyst mais que le déclenchement ne fonctionne pas, essayer de redémarrer l’ordinateur.

  • Le déclenchement se produit mais avec beaucoup de retard : essayer d’ajuster la compensation du délai dans les paramètres du Launch Monitor ; une valeur d’environ 1500 ms est recommandée. Cela dépend du type de balle et de l’utilisation du radar en intérieur ou en extérieur.

Si vous ne recevez toujours aucune donnée dans Swing Catalyst :

  • Essayer de redémarrer l’unité TrackMan et vérifier à nouveau si la sortie SDK est activée.

  • Essayer de désactiver le pare-feu Windows ; si cela fonctionne, ajouter une exception pour TPS et Swing Catalyst.

  • Vérifier si le service OEM TrackMan est en cours d’exécution. Si c’est le cas, le désactiver et réessayer. Plus d’informations sur les services Windows ici : http://www.7tutorials.com/what-are-windows-services-what-they-do-how-manage-
