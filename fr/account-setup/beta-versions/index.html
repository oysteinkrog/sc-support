Comment activer ou désactiver les versions bêta de SwingCatalyst

Cet article explique comment s’inscrire aux versions bêta, et comment se désinscrire pour ne recevoir que les mises à jour des versions stables de Swing Catalyst*.

Une version bêta est une version d’aperçu comprenant de nouvelles fonctionnalités et des corrections de bugs, disponible pour ceux qui choisissent d’autoriser les versions bêta depuis le logiciel.

  • Cet article s’applique également à Motion Catalyst.

Comment activer les versions bêta

  • Démarrez le logiciel SwingCatalyst.

  • Dans Paramètres, accédez à Paramètres généraux, puis Notifications.

  • Assurez-vous que l’option « Autoriser les versions bêta » est cochée.

Une fois SwingCatalyst redémarré, les versions bêta seront activées et vous recevrez des notifications pour les nouvelles versions bêta lorsqu’elles seront disponibles.

Veuillez consulter les captures d’écran en bas de l’article, car elles illustrent les points mentionnés ci-dessus.

Comment mettre à jour vers une nouvelle version bêta

Si vous disposez d’une licence valide et que votre logiciel est configuré pour recevoir les notifications de versions bêta, vous recevrez une notification similaire à l’image ci-dessous au démarrage du logiciel.

Depuis la fenêtre contextuelle de notification de mise à jour, cliquez sur « Mettre à jour » ; cela devrait ouvrir un navigateur web vers le site de SwingCatalyst : cliquez sur le bouton « Télécharger » pour télécharger la dernière version. Double-cliquez sur le fichier téléchargé et exécutez le programme d’installation.

Si vous avez besoin d’aide pour l’installation du logiciel, veuillez consulter : Comment installer SwingCatalyst.

Comment désactiver les versions bêta

Veuillez vous assurer de suivre les instructions correspondant à votre situation.

**Remarque : Veillez à ne pas décocher « Autoriser les versions bêta » avant d’avoir effectué l’installation ou la désinstallation. **

Si vous ne souhaitez plus utiliser une version bêta, deux scénarios peuvent s’appliquer à vous :

Scénario A : Je souhaite revenir à la version stable précédente :

  • Veuillez consulter notre article de support sur comment installer la version précédente.

  • Vous pouvez également consulter notre article de support « comment installer et désinstaller SwingCatalyst » et vous référer à la section « désinstallation ».

Scénario B : Je veux rester sur la version du logiciel que j’utilise et ne plus recevoir de notifications bêta.

Il est important de s’assurer que la version installée n’est effectivement pas une version bêta, et que la notification de mise à jour que vous voyez mentionne explicitement « bêta », sans quoi ces étapes pourraient vous bloquer l’accès au logiciel. Veuillez consulter la section de dépannage ci-dessous pour voir des exemples des différentes notifications de mise à jour.

Vérifier que vous utilisez la dernière version

  • Vérifiez votre licence. Dans Paramètres, Général, sous Informations de licence, cliquez sur « Configuration de la licence ».

  • Notez la version majeure indiquée en bas à droite, « Valide pour les versions jusqu’à ».

  • Vérifiez la version actuellement installée dans la barre de titre, par exemple 10.0.5 rev 37057.

  • Dans les paramètres généraux, assurez-vous d’être connecté à Internet et cliquez sur « Vérifier les mises à jour » ; si aucune nouvelle mise à jour n’est disponible, vous êtes probablement sur la dernière version stable.

  • Décochez la case « Autoriser les versions bêta » pour ne plus recevoir de nouvelles notifications bêta.

Comment savoir quelle version est la version stable ?

  • Visitez notre archive de logiciels : https://swingcatalyst.com/downloads/ et accédez à l’Archive de logiciels. Toutes les versions répertoriées dans cette archive correspondent à la dernière version stable de chaque version majeure.
