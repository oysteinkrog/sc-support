Comment faire une copie ou une sauvegarde du dossier ProgramData et des enregistrements de SwingCatalyst

Cet article d’assistance explique comment effectuer manuellement une copie du dossier Program Data de SwingCatalyst. Utile si vous souhaitez transférer une instance de SwingCatalyst d’un ordinateur à un autre.

Please note

Une licence SwingCatalyst ne peut pas être activée sur deux ordinateurs en même temps. Lorsque vous démarrez SwingCatalyst, la licence est activée. Cela signifie que si vous avez l’intention de déplacer SwingCatalyst de l’ordinateur A vers l’ordinateur B, vous ne pouvez plus démarrer SwingCatalyst sur l’ordinateur A, faute de quoi la licence sera bloquée pendant 24 heures.

Requirements

  • Un disque dur externe ou un disque dur secondaire disposant de suffisamment d’espace libre pour votre base de données SwingCatalyst.

Étape 1 : Effectuer une sauvegarde du dossier ProgramData

Le dossier de données du programme SwingCatalyst se trouve dans C:\ProgramData\Swing Catalyst\

Le dossier de données du programme contient les paramètres, les étalonnages des capteurs, votre fichier de licence, etc.

Veuillez noter que les enregistrements peuvent être stockés à un emplacement différent ; prenez note de cet emplacement (voir étape 2).

  • Accédez à ProgramData en tapant %programdata% puis en appuyant sur la touche Entrée.

  • Copiez l’intégralité du dossier Swing Catalyst sur un disque dur externe.

Faites une copie du fichier SwingCatalystDB.s3db sur un disque dur externe ou un disque dur secondaire.

Étape 2 : Faire une copie de vos enregistrements

Localiser l’emplacement de stockage des enregistrements

  • Accédez aux paramètres de SwingCatalyst : cliquez sur « Général » et consultez le « Chemin » indiqué dans la section Base de données (voir la zone en haut à droite de la capture d’écran ci-dessus).

  • Notez l’emplacement de la base de données, c’est là que vos enregistrements et vos Leçons sont stockés.

Un cas fréquent est d’avoir le fichier de base de données SwingCatalyst dans le répertoire ProgramData, mais d’avoir les enregistrements réels — vers lesquels pointe la base de données — stockés sur un disque dur ou une partition différente en raison de contraintes d’espace.

Si votre base de données (comme indiqué dans la capture d’écran ci-dessus) indique C:\ProgramData\Swing Catalyst\database, faites une copie du dossier database.

Copier les données sur le nouvel ordinateur

Maintenant que nous avons fait une copie du répertoire ProgramData de SwingCatalyst ainsi que de tous les enregistrements (tels que définis par le chemin indiqué dans la capture d’écran ci-dessus) sur un disque dur externe ou similaire, nous sommes prêts à les copier sur le nouvel ordinateur.

Important: Avant de continuer, assurez-vous de télécharger et d’installer SwingCatalyst en premier.

Requirements:

  • Une licence SwingCatalyst valide.

Remplacer le répertoire ProgramData de SwingCatalyst

Sur le nouvel ordinateur, nous devrions disposer d’une installation fraîche de SwingCatalyst ; il ne devrait rien y avoir à conserver sur cet ordinateur, c’est-à-dire qu’il est possible de remplacer les fichiers sans problème.

  • Connectez votre disque dur externe et localisez votre copie du répertoire ProgramData de SwingCatalyst.

  • Accédez au répertoire ProgramData sur le nouvel ordinateur.

  • Remplacez le dossier Swing Catalyst existant (sur le nouvel ordinateur) par la copie que vous avez effectuée (depuis le disque dur externe).

Configurer la base de données

Dans certains cas où SwingCatalyst est configuré pour utiliser un emplacement différent de l’emplacement par défaut C:\ProgramData\Swing Catalyst\database, il sera nécessaire de copier le contenu du dossier dans le dossier database du répertoire ProgramData.

Dans notre exemple ci-dessus, notre répertoire était D:\Temp2, ce qui signifie qu’il faudrait copier le contenu de ce dossier dans le dossier database.

Pour voir les chemins configurés dans SwingCatalyst, nous pouvons utiliser l’outil d’édition du registre regedit pour les consulter.

Accédez à Ordinateur –> HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Initial Force\Swing Catalyst. Cliquez sur le dossier comme indiqué dans la capture d’écran ci-dessous.
