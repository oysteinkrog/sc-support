Comment configurer les caméras IDS uEye GigE pour fonctionner avec Swing Catalyst

Pour la configuration d’une caméra USB, veuillez consulter cet article : ids-ueye-usb.md

Remarque : Cet article suppose que vous avez installé les Drivers uEye disponibles ici : https://www.swingcatalyst.com/drivers

Cet article explique comment configurer les adresses IP de la caméra et de la carte réseau.

Remarque : Swing Catalyst ne prend pas en charge l’AOI IDS (zone d’intérêt) pour les caméras IDS.

Adaptateurs réseau compatibles et configuration :

Veuillez consulter : gige-network-setup.md

Remarque, important pour les performances : Si vous disposez d’une carte réseau Intel, veuillez télécharger et installer les Drivers Intel, car cela vous donnera accès aux options de réglage des taux de modération des interruptions, qui peuvent ne pas être disponibles avec les Drivers Windows.

Configuration de vos caméras IDS uEye GigE

Étapes :

Avant de commencer, installez les Drivers IDS uEye. Localisez et ouvrez l’application IDS Camera Manager (elle se trouve dans : C:\ProgramData\Microsoft\Windows\Start Menu\Programs\IDS).

L’application IDS Camera Manager :

Notez l’avertissement en bas de l’application. Plusieurs avertissements peuvent s’afficher en raison d’adresses IP incorrectement configurées, ou liés au micrologiciel de la caméra.

Remarque sur la configuration des adresses IP et nos recommandations**

**

Notre recommandation est de disposer d’une carte réseau dédiée, ou d’une interface réseau, pour chaque caméra. Cependant, avec le modèle IDS UI-3220, vous pouvez utiliser deux caméras par port réseau à l’aide d’un commutateur réseau (voir Utilisation d’un commutateur réseau).

Notre configuration IP recommandée :

Chaque caméra et carte Ethernet (également appelée NIC) doit être configurée avec des IP statiques sur des sous-réseaux différents (ainsi qu’un masque de sous-réseau).

Exemple :

Caméras sur la carte réseau 1 : nic ip: 10.0.1.1 cam ip: 10.0.1.10 … 10.0.1.20 subnet mask:255.255.255.0

Caméras sur la carte réseau 2 : nic ip: 10.0.2.1 (sous-réseau différent de nic1) cam ip: 10.0.2.10 … 10.0.2.20 (sous-réseau différent de nic1) subnet mask: 255.255.255.0

Activation du service réseau uEye

Remarque : Si vous utilisez différents types de caméras provenant de fabricants différents, l’activation du service réseau uEye peut provoquer des problèmes lors de l’utilisation d’une caméra d’un autre fabricant.

Cliquez sur ETH network service

Sélectionnez l’adaptateur réseau que vous souhaitez configurer (dans cet exemple, il s’agit des adaptateurs double port)

Le graphique de la carte réseau est grisé, car elle n’est pas correctement configurée. Le service réseau uEye doit être activé pour que la caméra soit visible sur le réseau.

Assurez-vous de définir l’adresse IP et le masque de sous-réseau conformément aux recommandations (voir ci-dessus), puis cliquez sur Enable uEye network service et sur Apply changes (vous venez ainsi de définir une adresse IP statique pour l’un des adaptateurs double port !).

Configuration IP automatique (pour la configuration IP manuelle, voir ci-dessous)

Pour utiliser la configuration IP automatique, cliquez sur Automatic ETH configuration et cliquez sur OK.

L’IDS Camera Manager définira automatiquement une adresse IP sur la carte réseau et sur la caméra à votre place.

Remarque : Nous recommandons une configuration IP manuelle lors de l’utilisation de plusieurs caméras.

Configuration IP manuelle

De retour dans l’IDS Camera Manager, vous devriez maintenant voir la ou les caméras listées. Puisque vous avez précédemment défini une adresse IP statique pour l’adaptateur réseau, vous devez maintenant définir une IP statique pour la caméra afin que l’adaptateur réseau et la caméra puissent communiquer correctement entre eux.

Cochez la case Expert Mode comme indiqué ici :

Notez l’avertissement ci-dessus en rouge.

Cliquez sur Manual ETH configuration :

Dans la capture d’écran ci-dessus, l’adresse IP de la caméra est réglée sur 10.0.1.10 (notre carte réseau est en 10.0.1.1). Saisissez les valeurs comme indiqué dans la capture d’écran ci-dessus et cliquez sur OK.

Remarque : la définition d’adresses IP statiques n’est pas obligatoire, mais elle est fortement recommandée, car les configurations IP automatiques peuvent entraîner des conflits d’adresses IP, par exemple si la même adresse IP est utilisée ailleurs. Nous recommandons vivement une configuration statique pour toutes les installations en studio.

Répétez l’opération pour les autres caméras et NIC conformément à nos configurations IP recommandées ci-dessus.

Configuration du ou des adaptateurs réseau pour une utilisation avec les caméras IDS uEye

En supposant que vous avez maintenant défini des adresses IP statiques pour la ou les caméras et la carte réseau, passons à la configuration de l’adaptateur réseau pour des performances optimales.

Depuis Panneau de configuration\Réseau et Internet\Connexions réseau, double-cliquez sur l’adaptateur que vous souhaitez configurer — dans notre cas, il s’agit d’Ethernet 4, Intel (PRO/1000 PT Dual port).

Double-cliquez sur l’adaptateur réseau que vous souhaitez configurer.

Cliquez sur l’onglet Avancé. Remarque : la configuration varie selon chaque adaptateur réseau et selon le Driver ; veuillez consulter la documentation de votre carte réseau pour obtenir des informations spécifiques sur la modification des paramètres indiqués ci-dessous.

Assurez-vous que la modération des interruptions (Interrupt Moderation) est activée et que le taux de modération des interruptions (Interrupt Moderation Rate) est réglé sur Extreme.

Si l’option Extreme n’est pas disponible, réglez-la sur High.

Dans certains cas, désactiver la modération des interruptions peut aider si aucun des taux de modération élevés ne fonctionne, mais tant que vous disposez d’une carte réseau recommandée, les options High et Extreme devraient être disponibles. L’activation de la modération des interruptions est essentielle pour réduire l’utilisation du CPU lors du traitement d’un grand nombre de paquets, en particulier avec des caméras à haute résolution et/ou à FPS élevé.

Taux de modération des interruptions :

Activez la prise en charge des Jumbo Packets (réglez-la sur 9014 octets) :

Tampons de réception (Receive Buffers) :

Il est recommandé de régler cette valeur au maximum possible. Cela peut aider à éviter la perte de Trames lors de l’utilisation de plusieurs caméras et/ou de caméras GigE à haute résolution.

Utilisation d’un commutateur réseau :

Si vous utilisez un commutateur réseau, il est important que celui-ci prenne en charge les Jumbo Frames 9 Ko, et que l’adaptateur réseau soit configuré pour utiliser des Jumbo Frames 9 Ko. Cependant, dans certains cas, certains commutateurs peuvent ne pas bien fonctionner avec des tailles de Cadre de 9 Ko ; dans ce cas, il est recommandé de réduire cette valeur en dessous de 9 Ko et de tester à nouveau la configuration.

Utilisation de la ou des caméras dans Swing Catalyst

Après avoir configuré les adresses IP et les adaptateurs réseau conformément aux recommandations ci-dessus, vous pouvez démarrer Swing Catalyst et la caméra devrait apparaître dans la liste des caméras.

Définissez un Angle de caméra et activez la caméra, puis cliquez sur Configure.

Assurez-vous que la fréquence d’horloge pixel est au maximum (ou réduisez-la si vous perdez des Trames).

Réglez la vitesse d’obturation et le Gain (notez que ces valeurs peuvent varier considérablement selon les besoins, le type de caméra et la quantité de lumière disponible).

Dépannage des caméras IDS

Si vous perdez des Trames ou rencontrez des problèmes de synchronisation avec votre caméra IDS uEye GigE, utilisez l’utilitaire uEye Cockpit.

Cliquez sur Live Video

Cliquez sur l’icône de lecture puis sur la clé à molette

Notez l’utilisation de la bande passante indiquée. Sous l’onglet Camera, augmentez la fréquence d’horloge pixel (Pixel clock) et cochez la case Max sous Frame rate (Freerun), puis réduisez le temps d’exposition (vitesse d’obturation).

Après avoir configuré vos caméras pour diffuser en direct, cliquez sur Vue -> Performance Overview

La Vue Performance hôte peut être très utile pour résoudre les problèmes de stabilité et de perte de Trames.
