Comment mettre à niveau ou rétrograder le firmware des caméras Fox ou Lynx.

Prérequis :

  • Une caméra Fox ou Lynx.

  • La suite logicielle MVS.

  • Une copie du firmware pour le modèle de caméra que vous souhaitez mettre à niveau ou rétrograder.

Aperçu des versions de firmware connues comme fonctionnelles ou défectueuses — veuillez télécharger le firmware dans la section téléchargement de firmware.

ModèleTéléchargement du firmwareFirmware concernéVersion de firmware connue comme fonctionnelle
FoxTéléchargerV1.6.3 201222_551351V1.6.3 220416_798858
LynxTélécharger3.3.1 2209153.3.0 220408

Le logiciel MVS peut être téléchargé depuis : https://cloudfront.swingcatalyst.com/drivers/MVS_STD_3.4.1_220407.zip

Mise à niveau du firmware

  • Téléchargez le firmware pour la caméra que vous souhaitez mettre à niveau ou rétrograder depuis le tableau ci-dessus, puis extrayez le fichier zip.

  • Installez le logiciel MVS (s’il n’est pas déjà installé)

Une fois installé, lancez l’application MVS. La caméra connectée devrait apparaître dans la liste sur la gauche. Si elle figure dans la liste des caméras, cliquez sur Outil (dans la barre d’outils supérieure) et sélectionnez « Firmware Updater ».

L’application Firmware Updater

Notez le nom du modèle ainsi que la version du firmware ; la version 3.3.1 est une version connue comme non fonctionnelle (voir le tableau ci-dessus).

Sélectionnez la ou les caméras que vous souhaitez mettre à jour en cochant la case à gauche de « Model Name », puis cliquez sur l’icône « dossier » en haut à droite et naviguez jusqu’au dossier dans lequel vous avez extrait le firmware.

Sélectionnez le fichier de firmware et cliquez sur « OK ». La fenêtre « Select Update File » se fermera et vous pourrez ensuite cliquer sur « Update » dans le logiciel Firmware Updater.

Remarque : Il est possible de mettre à jour plusieurs caméras à la fois, mais elles doivent être du même type / modèle. Sélectionnez le fichier de firmware que vous souhaitez utiliser pour la mise à jour.
