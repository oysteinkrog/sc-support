Comment configurer les caméras Basler GigE avec Swing Catalyst

Cet article de support couvre la configuration des caméras Basler avec Swing Catalyst.

note: Pour utiliser les caméras Basler avec Swing Catalyst, vous aurez besoin d’une clé USB Halcon et d’une licence. Veuillez contacter contact@swingcatalyst.com pour acheter une licence.

Instructions d’installation et de configuration de Halcon ici :

halcon-setup.md

Important :

Assurez-vous que le Filtre de pilote MVTec Halcon est installé, les caméras ne fonctionneront pas correctement sans lui. Assurez-vous également de décocher tout autre Filtre de pilote installé, par exemple le Filtre de pilote Basler.

Assurez-vous que Swing Catalyst est autorisé à la fois sur les réseaux privés et publics dans le pare-feu Windows Defender.

Définir l’IP des caméras

Configuration IP

Chaque caméra et carte Ethernet (NIC / contrôleur d’interface réseau) doit être configurée avec des IP statiques sur des sous-réseaux différents (et un masque de sous-réseau).

note: L’IP de la NIC est l’adresse IP de l’adaptateur réseau de votre ordinateur, et l’IP de la caméra est l’adresse IP de la caméra. Les … indiquent une plage, car il s’agit d’un exemple d’IP que vous pouvez définir.

Exemples pour des configurations à une ou plusieurs caméras (avec une ou plusieurs cartes / adaptateurs réseau) :

Caméras sur l’adaptateur réseau 1 : nic ip: 10.0.1.1 cam ip: 10.0.1.10 … 10.0.1.20 subnet mask:255.255.255.0

Caméras sur l’adaptateur réseau 2 : nic ip: 10.0.2.1 cam ip: 10.0.2.10 … 10.0.2.20 subnet mask: 255.255.255.0

Caméras sur l’adaptateur réseau 3 : nic ip: 10.0.3.1 cam ip: 10.0.3.10 … 10.0.3.20 subnet mask: 255.255.255.0

Caméras sur l’adaptateur réseau 4 : nic ip: 10.0.4.1 cam ip: 10.0.4.10 … 10.0.4.20 subnet mask: 255.255.255.0

Nous devons d’abord configurer l’IP de la caméra, ce qui se fait via le Pylon IP Configurator.

Appuyez sur la touche Démarrer de votre clavier et tapez pylon ip ; le Configurateur IP devrait apparaître. S’il n’apparaît pas, il est probable que le logiciel ne soit pas installé.

Pour installer le logiciel Pylon, consultez : https://www.baslerweb.com/en/sales-support/downloads/software-downloads/ et recherchez : pylon 5.1.0 Camera Software Suite Windows.

Cliquez sur la caméra, puis sélectionnez Static IP.

Définissez l’adresse IP de la caméra et le masque de sous-réseau conformément à l’exemple ci-dessus.

Configuration des caméras Basler GigE via Halcon

Dans Swing Catalyst, accédez à l’onglet Paramètres, puis à Caméras.

Cliquez sur Avancé.

  • Accédez à l’onglet Configuration.

  • Activez la case à cocher GtlNumBuffers et entrez 200 comme valeur.

Configuration des caméras Basler GigE :

Voyons comment définir l’exposition, la vitesse d’obturation et la Fréquence d’images.

NOTE : Si vous ne parvenez pas à afficher les paramètres et obtenez une erreur dans Swing Catalyst, veuillez vérifier les paramètres du pare-feu Windows. Essayez de désactiver le pare-feu pour vérifier s’il bloque l’accès de Swing Catalyst aux caméras.

Si les paramètres fonctionnent et que vous pouvez diffuser correctement, assurez-vous que Swing Catalyst est autorisé sur les réseaux publics et privés dans le pare-feu Windows Defender.

Développez l’onglet AcquisitionTrigger et entrez la Fréquence d’images maximale (ou inférieure), puis cliquez sur Enable Acquisition Frame Rate. Cela vous permettra de définir la Fréquence d’images. Remarque : la Fréquence d’images peut être limitée par les valeurs d’exposition.

Définir les valeurs d’exposition

Il est généralement préférable d’utiliser une exposition manuelle pour les environnements statiques, tels que les studios intérieurs. Une exposition entièrement automatique peut entraîner une modification de la Fréquence d’images et produire une image inconsistante. Dans ce cas, nous n’utilisons pas l’exposition automatique car nous souhaitons pouvoir la contrôler nous-mêmes. En général, un temps d’exposition inférieur à 2000 (2 ms) est recommandé.

Définir les valeurs de Gain

Comme pour l’exposition, il est préférable de régler le Gain en mode manuel pour les conditions d’éclairage statiques / en intérieur. Plus l’exposition est élevée, plus l’image sera granuleuse et plus l’encodage vidéo prendra du temps par rapport à un Gain faible.

Pour définir le Gain manuel, changez Gain Auto de Continuous à Off, puis mettez en Pause et relancez la Lecture pour recharger les paramètres. Définissez les valeurs de Gain en modifiant les valeurs numériques dans Gain (Raw).

Modifier la taille de l’image, la zone d’intérêt, la Region of Interest et plus encore

Dans certains cas, vous souhaitez réduire la taille de l’image pour vous concentrer sur une zone spécifique de l’image vidéo, par exemple pour voir la tête de club et la balle à l’Impact en détail.

Cela peut être fait avec la zone d’intérêt, également connue sous le nom d’AOI, et le ROI, Region of Interest. La réduction de la taille globale de l’image avec cette fonction peut également augmenter la Fréquence d’images.

Enregistrer les paramètres dans la caméra

Il est important d’enregistrer les paramètres dans la caméra. Si cela n’est pas fait, tous les réglages que vous avez configurés seront perdus.

Assurez-vous de définir le Default Set Selector et le Default Startup Set. Il existe différents jeux d’Utilisateur parmi lesquels choisir et, en théorie, vous pouvez avoir des paramètres différents enregistrés sur chaque jeu. C’est-à-dire que vous pouvez sélectionner « User Set 1 » comme jeu par défaut, puis cliquer sur User Set Save pour enregistrer vos paramètres actuels dans ce profil.
