Comment utiliser l'Explorateur

Introduction

L’Explorateur fournit une interface permettant de parcourir, sélectionner et gérer les Enregistrements Vidéo organisés par Sessions. Ce document explique comment naviguer efficacement et utiliser toutes les fonctionnalités de l’Explorateur dans les versions 25.3 et ultérieures.

Vue d’ensemble

Barre d’outils : Barre d’outils avec des boutons permettant d’accéder rapidement à toutes les fonctionnalités principales de l’Explorateur.

Liste des Utilisateurs : Liste des Utilisateurs enregistrés avec des fonctionnalités pratiques telles qu’une barre de recherche et un bouton de tri.

Liste du contenu téléchargeable : Liste des Enregistrements téléchargés, tels que les Swings de Tour.

Sessions et Enregistrements : Liste des Sessions pouvant être développées pour afficher tous les Enregistrements de cette Session.

Aperçu de l’Enregistrement : Fenêtre d’aperçu affichant une miniature animée et des informations clés sur l’Enregistrement.

Liste d’exportation : Faites glisser et déposez des Enregistrements ici pour les ajouter à la liste d’exportation. Les Enregistrements peuvent ensuite être exportés en tant que fichier Prise permettant d’importer l’Enregistrement dans SwingCatalyst ultérieurement, ou en tant que fichiers TSV de données brutes pour une analyse personnalisée.

Navigation au clavier

L’Explorateur prend en charge la navigation complète au clavier dans les miniatures d’Enregistrements :

Navigation par touches fléchées

  • ↑ - Monter d’une ligne

  • ↓ - Descendre d’une ligne

  • ← - Se déplacer d’une colonne vers la gauche

  • → - Se déplacer d’une colonne vers la droite

Navigation par page

  • Home - Aller au premier élément de la Session en cours

  • End - Aller au dernier élément de la Session en cours

  • Page Up - Remonter d’une page visible

  • Page Down - Descendre d’une page visible

Navigation entre Sessions

  • Lorsque vous êtes en haut ou en bas d’une Session, les touches fléchées permettent de naviguer automatiquement vers les Sessions adjacentes

  • Les Sessions se développent automatiquement lors de la navigation vers celles-ci

Comportement de la sélection

L’Explorateur met en œuvre des fonctionnalités de multi-sélection standard :

Sélection simple

  • Clic - Sélectionner un seul Enregistrement

  • Double-clic - Ouvrir l’Enregistrement sélectionné pour le visualiser

Multi-sélection à la souris

  • Ctrl** + Clic** - Activer/désactiver la sélection d’éléments individuels

  • Shift** + Clic** - Sélectionner une plage depuis le dernier élément sélectionné jusqu’à l’élément cliqué

Multi-sélection au clavier

  • Shift** + Touches fléchées** - Étendre la sélection dans la direction de navigation

  • Ctrl** + Touches fléchées** - Naviguer sans modifier la sélection

  • Ctrl** + **A - Sélectionner tous les Enregistrements visibles dans l’Explorateur

  • Ctrl** + Shift + **A - Sélectionner tous les Enregistrements visibles dans la Session en cours

  • Escape - Effacer les sélections visibles

Informations sur la sélection

  • Compteur de sélection : Affiche le nombre total d’éléments sélectionnés et le nombre d’éléments sélectionnés visibles

  • Sélections masquées : Indique quand des éléments sont sélectionnés dans des Sessions réduites ou filtrées

  • Retour visuel : Les éléments sélectionnés sont mis en évidence avec une bordure

Menus et actions contextuelles

Menu contextuel d’Enregistrement

Faites un clic droit sur n’importe quel Enregistrement pour accéder à :

  • Ouvrir - Ouvrir l’Enregistrement

  • Ajouter à la Pile - Ajouter à la Pile d’analyse pour un accès rapide en mode Analyse

  • Ajouter à l’exportation - Ajouter à la file d’attente d’exportation

  • Supprimer - Supprimer l’Enregistrement

  • Téléverser en ligne - Partager via SwingCatalyst Online

Menu contextuel Étudiant/Groupe

Faites un clic droit sur les noms d’Étudiants pour :

  • Ajouter l’Utilisateur à la liste d’exportation - Inclure tous les Enregistrements de l’Utilisateur dans l’exportation

  • Supprimer l’Utilisateur - Supprimer l’Utilisateur et tous ses Enregistrements

Commandes globales

Disponibles via des raccourcis clavier :

  • Enter - Ouvrir le(s) Enregistrement(s) sélectionné(s).

  • Delete - Supprimer tous les Enregistrements sélectionnés

  • Ctrl** + **A - Sélectionner tous les Enregistrements visibles dans l’Explorateur

  • Ctrl** + Shift + **A - Sélectionner tous les Enregistrements de la Session en cours

  • Escape - Effacer la sélection actuelle

Glisser-déposer

Faire glisser des Prises

  • Faites glisser des Prises vers les zones de dépôt

  • Le retour visuel affiche un élément de glissement avec la miniature de l’Enregistrement

  • Les indicateurs de dépôt mettent en évidence les cibles de dépôt valides

Zones de dépôt

  • Zone de dépôt de la Fenêtre d’Affichage A/B - Déposez ici pour ouvrir le(s) Enregistrement(s) dans la Fenêtre d’Affichage A ou B

  • Zone de dépôt de la liste d’exportation - Déposez ici pour ajouter le(s) Enregistrement(s) à la file d’attente d’exportation

Conseils pour une utilisation efficace

  • Opérations en masse : Utilisez la multi-sélection pour effectuer des actions sur plusieurs Enregistrements simultanément

  • Efficacité au clavier : Combinez Ctrl, Shift et les touches fléchées pour des flux de travail de sélection rapides

  • Conscience du contexte : Les menus contextuels proposent des actions adaptées au contexte

  • Retour visuel : Prêtez attention aux compteurs de sélection et aux indicateurs de mise en évidence

L’Explorateur est conçu pour une gestion efficace du flux de travail, vous permettant de naviguer rapidement dans de grandes collections d’Enregistrements et d’effectuer des opérations en masse avec un minimum d’effort.
