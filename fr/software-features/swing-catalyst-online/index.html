Comment utiliser Swing Catalyst Online

Introduction

Cet article est une introduction à Swing Catalyst Online et vise à présenter les fonctionnalités disponibles depuis la partie bureau de Swing Catalyst Online.

Prérequis

  • Une licence Swing Catalyst valide (Quelle version ai-je ?))

  • Un compte Swing Catalyst Online

  • Une connexion Internet

Qu’est-ce que Online

Swing Catalyst Online est le point de connexion qui relie le logiciel bureau SwingCatalyst aux applications iOS & Android, et peut être utilisé pour partager des enregistrements et des leçons avec d’autres utilisateurs.

Toutes les licences sont associées à un compte Online.

Vu depuis le logiciel bureau SwingCatalyst

Voici Swing Catalyst Online tel qu’il apparaît depuis la partie bureau.

Le bouton de connexion se trouve en haut du logiciel, dans le coin droit.

Vos identifiants Online sont utilisés pour vous connecter.

Une fois connecté, le bouton « Se connecter » change pour indiquer que vous êtes connecté.

Enregistrements

L’Explorateur Online est distinct de l’Explorateur normal.

Pour télécharger des enregistrements depuis Online vers le logiciel bureau, cliquez sur un enregistrement puis sur « Télécharger ». Le téléchargement démarre et l’enregistrement apparaîtra dans l’Explorateur normal.

Explorateur

Tous les enregistrements qui ont été partagés avec vous ou téléversés depuis le logiciel bureau sont visibles ici.

Notez l’icône « partager » sur les enregistrements qui vous ont été partagés par quelqu’un d’autre.

Le bouton orange « + » est le bouton « Téléverser une vidéo », qui vous permet de téléverser des enregistrements vers votre compte.

Affichage des détails d’un enregistrement

Le lecteur vidéo prend en charge la vitesse de Lecture réglable.

Leçons

L’onglet Leçons contient toutes les leçons que vous avez téléversées sur Online, ou les leçons qui vous ont été partagées.

Vous pouvez partager des enregistrements et des leçons que vous avez créés, c’est-à-dire ceux qui ne vous ont pas été partagés.

Téléverser une vidéo

Les enregistrements peuvent facilement être téléversés vers Swing Catalyst en appuyant sur l’icône « + » dans l’Explorateur.

Supprimer une vidéo

Pour supprimer une vidéo, cliquez sur l’onglet Explorateur, puis cliquez sur l’une des vidéos que vous souhaitez supprimer, et cliquez ensuite sur le bouton « Supprimer ». Remarque : La suppression d’enregistrements partagés avec d’autres personnes supprimera également l’accès des destinataires à la vidéo.

Stockage

Lors du téléversement d’un enregistrement ou d’une leçon sur Online, cela utilise votre espace de stockage. 50 enregistrements et leçons (au total) sont gratuits. Vous pouvez gérer votre quota de stockage sur cette page.

Si vous rencontrez des problèmes lors du téléversement d’enregistrements, votre quota de stockage est peut-être plein ; dans ce cas, vous devrez soit souscrire un abonnement de stockage supplémentaire, soit supprimer des enregistrements existants pour libérer de l’espace.

Si votre quota de stockage est atteint, un avertissement s’affichera sur la page de l’Explorateur.

Consulter vos licences

Toutes les licences SwingCatalyst sont associées à un compte Online. Vous avez peut-être perdu votre clé de licence ? Vous pouvez vous connecter à Online et consulter les licences directement depuis le bouton « Voir les licences ».

Veuillez noter que pour résilier votre licence, cela doit être effectué via notre boutique.
