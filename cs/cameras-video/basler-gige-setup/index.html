Jak nastavit kamery Basler GigE se Swing Catalyst

Tento článek podpory popisuje Příprava a konfiguraci kamer Basler se Swing Catalyst.

note: Pro použití kamer Basler se Swing Catalyst budete potřebovat Halcon USB dongle a licenci. Pro zakoupení licence kontaktujte prosím contact@swingcatalyst.com.

Pokyny k instalaci a konfiguraci Halconu naleznete zde:

halcon-setup.md

Důležité:

Ujistěte se, že máte nainstalovaný filtr driveru MVTec Halcon – bez něj kamery nebudou fungovat správně. Také se ujistěte, že máte odškrtnuté veškeré ostatní nainstalované filtr drivery, např. Basler filtr driver.

Ujistěte se, že je SwingCatalyst povolen na privátních i veřejných sítích v bráně firewall programu Windows Defender.

Nastavení IP adres kamer

IP Příprava

Každá kamera a síťová karta (NIC / Network interface controller) by měla být nakonfigurována se statickými IP adresami v různých podsítích (a masce podsítě).

note: IP adresa NIC je IP adresa síťového adaptéru ve vašem počítači a IP adresa kamery je IP adresa samotné kamery. Symbol … označuje rozsah, protože se jedná o příklad IP adresy, kterou můžete nastavit.

Příklady pro jednokamerové nebo vícekamerové Příprava (s jednou nebo více síťovými kartami / adaptéry):

Kamery na síťovém adaptéru 1:
nic ip: 10.0.1.1
cam ip: 10.0.1.10 ... 10.0.1.20
subnet mask:255.255.255.0

Kamery na síťovém adaptéru 2:
nic ip: 10.0.2.1
cam ip: 10.0.2.10 ... 10.0.2.20
subnet mask: 255.255.255.0

Kamery na síťovém adaptéru 3:
nic ip: 10.0.3.1
cam ip: 10.0.3.10 ... 10.0.3.20
subnet mask: 255.255.255.0

Kamery na síťovém adaptéru 4:
nic ip: 10.0.4.1
cam ip: 10.0.4.10 ... 10.0.4.20
subnet mask: 255.255.255.0

Nejprve je třeba nastavit IP adresu kamery, což se provádí prostřednictvím nástroje Pylon IP Configurator.

Stiskněte tlačítko Start na klávesnici, napište pylon ip a měl by se zobrazit IP Configurator. Pokud se nezobrazí, pravděpodobně nemáte software nainstalovaný.

Pro instalaci softwaru Pylon navštivte: https://www.baslerweb.com/en/sales-support/downloads/software-downloads/ a vyhledejte: pylon 5.1.0 Camera Software Suite Windows.

Klikněte na kameru a vyberte Static IP.

Nastavte IP adresu kamery a masku podsítě podle výše uvedeného příkladu.

Konfigurace kamer Basler GigE prostřednictvím Halconu

Ve SwingCatalyst přejděte na záložku Nastavení a poté na Kamery.

Klikněte na Rozšířené (Advanced).

  • Přejděte na záložku Konfigurace (Configuration).

  • Zaškrtněte políčko GtlNumBuffers a zadejte hodnotu 200.

Nastavení kamer Basler GigE:

Podívejme se, jak nastavit expozici, rychlost závěrky a Snímkovou Frekvenci.

note: Pokud nemůžete zobrazit nastavení a v SwingCatalyst se zobrazí chyba, zkontrolujte nastavení brány Windows Firewall. Zkuste bránu firewall dočasně vypnout a ověřte, zda firewall neblokuje přístup SwingCatalyst ke kamerám.

Pokud nastavení fungují a přenos obrazu probíhá správně, ujistěte se, že SwingCatalyst je povolen na veřejných i privátních sítích v bráně firewall programu Windows Defender.

Rozbalte záložku AcquisitionTrigger, zadejte maximální (nebo nižší) Snímkovou Frekvenci a klikněte na Enable Acquisition Frame Rate. Tím si budete moci definovat Snímkovou Frekvenci. Poznámka: Snímková Frekvence může být omezena hodnotami expozice.

Nastavení hodnot expozice

Pro statická prostředí, jako jsou vnitřní studia, je obvykle nejlepší použít ruční expozici. Plně automatická expozice může způsobit změnu Snímkové Frekvence a vést k nekonzistentnímu obrazu. V tomto případě nepoužíváme automatickou expozici, protože chceme mít tuto funkci pod vlastní kontrolou. Obecně se doporučuje doba expozice kratší než 2000 (2 ms).

Nastavení hodnot Gainu

Podobně jako u expozice je pro statické / vnitřní světelné podmínky nejlepší nastavit Gain na ruční režim. Čím vyšší je expozice, tím více bude obraz zrnitý a tím déle bude trvat kódování videa oproti nízkému Gainu.

Chcete-li nastavit ruční Gain, změňte Gain Auto z hodnoty Continuous na Off, poté pozastavte (Pauza) a znovu spusťte Přehrávání, aby se nastavení znovu načetla. Hodnoty Gainu nastavte změnou číselných hodnot v poli Gain (Raw).

Změna velikosti obrazu, oblasti zájmu, Region of Interest a dalšího

V některých případech chcete zmenšit velikost obrazu, abyste se zaměřili na konkrétní část videoobrazů, například abyste při Úderu detailně viděli hůl a míček.

Toho lze dosáhnout pomocí oblasti zájmu, také známé jako AOI, a ROI, Region of Interest. Celkové zmenšení velikosti obrazu pomocí této funkce může také zvýšit Snímkovou Frekvenci.

Uložení nastavení do kamery

Je důležité uložit nastavení do kamery. Pokud tak neučiníte, vše, co jste nakonfigurovali, bude ztraceno.

Ujistěte se, že nastavíte Default Set Selector a Default Startup Set. K dispozici jsou různé uživatelské sady a teoreticky můžete mít v každé sadě uložena různá nastavení. Například můžete jako výchozí vybrat „User Set 1" a poté kliknout na User Set Save, čímž uložíte aktuální nastavení do tohoto profilu.
