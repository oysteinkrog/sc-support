Πώς να εγκαταστήσετε κάμερες AVT Manta/Prosilica GigE

Αυτό το άρθρο υποστήριξης περιγράφει πώς να συνδέσετε κάμερες AVT GigE σε έναν υπολογιστή, πώς να ρυθμίσετε το σύστημα καθώς και τις απαιτήσεις υλικού για τη χρήση κάμερας GigE.

Απαιτήσεις Υλικού

Για την Προετοιμασία και εγκατάσταση καμερών GigE θα χρειαστείτε μία ή περισσότερες ελεύθερες θύρες δικτύου στον υπολογιστή σας.

Συνιστούμε τη χρήση μιας από τις παρακάτω κάρτες δικτύου, καθώς έχουν δοκιμαστεί και επαληθευτεί ότι λειτουργούν από τον κατασκευαστή:

  • Intel Pro 1000 GT (PCI, 1 θύρα)

  • Intel Pro 1000 PT (PCIe x1, 1 θύρα)

  • Intel CT (PCIe x1, 1 θύρα)

  • Intel Pro 1000 PT Dual Port (PCIe x4, 2 θύρες)

  • Intel Pro 1000 PT Quad Port Low Profile (PCIe x4, 4 θύρες)

Είναι επίσης δυνατή η χρήση των περισσότερων άλλων καρτών δικτύου gigabit, αλλά είναι σημαντικό να σημειωθεί ότι η κάρτα πρέπει να υποστηρίζει “jumbo frames”.

Εάν επιθυμείτε να χρησιμοποιήσετε περισσότερες από μία κάμερες, μπορεί σε ορισμένες περιπτώσεις να είναι απαραίτητη και η χρήση ενός gigabit switch δικτύου. Οι περισσότεροι gigabit switches θα λειτουργήσουν, αλλά είναι σημαντικό να διασφαλίσετε ότι το switch υποστηρίζει επίσης jumbo frames.

  • Netgear GS105 gigabit switch 5 θυρών

Εγκατάσταση Υλικού και Ντράιβερ

Για κάμερες Allied Vision Tech (AVT) παρακαλούμε ανατρέξτε στην τεκμηρίωση του κατασκευαστή (σελίδες 19-26), στο κάτω μέρος αυτής της σελίδας.

Τα πιο σημαντικά βήματα είναι:

  • Κατεβάστε τους Ντράιβερ από https://www.swingcatalyst.com/drivers

  • Εγκαταστήστε τους Ντράιβερ και βεβαιωθείτε ότι αποδέχεστε την εγκατάσταση του “Φίλτρου”.

  • Ρυθμίστε την κάρτα δικτύου ώστε να αποδέχεται “Jumbo Frames (9K)”

  • Απενεργοποιήστε όλες τις μονάδες δικτύου στην κάρτα δικτύου εκτός από το Φίλτρο AVT και το IPV4

Εάν δεν είστε σίγουροι για το πώς να εκτελέσετε οποιοδήποτε από αυτά τα βήματα, παρακαλούμε ανατρέξτε στον οδηγό του κατασκευαστή που συνδέεται παραπάνω· περιέχει έναν ολοκληρωμένο οδηγό που εξηγεί όλα τα βήματα λεπτομερώς.

Σύνδεση της/των κάμερας/ών GigE

Για να συνδέσετε μία μόνο κάμερα GigE, χρησιμοποιήστε ένα κανονικό καλώδιο δικτύου CAT5e/6 RJ45 για να συνδέσετε την κάμερα απευθείας στην κάρτα/θύρα δικτύου gigabit.

Εάν επιθυμείτε να συνδέσετε περισσότερες από μία κάμερες, μπορείτε να χρησιμοποιήσετε πολλαπλές κάρτες δικτύου ή σε ορισμένες περιπτώσεις ένα switch δικτύου για να συνδέσετε πολλαπλές κάμερες σε μία κάρτα.

Η χρήση switch δικτύου είναι δυνατή μόνο σε ορισμένες περιπτώσεις (όπου το συνολικό εύρος ζώνης όλων των καμερών δεν υπερβαίνει αυτό μιας θύρας gigabit)· παρακαλούμε επικοινωνήστε μαζί μας εάν δεν είστε σίγουροι αν αυτό είναι εφικτό στην περίπτωσή σας.

Σύνδεση 2 καμερών σε μία κάρτα/θύρα δικτύου

Σε ορισμένες περιπτώσεις είναι δυνατή η σύνδεση 2 καμερών σε μία κάρτα/θύρα δικτύου.

Ορισμός στατικής IP στον Προσαρμογέα Ethernet

Μόλις οι κάμερες έχουν εκχωρηθεί στατικές διευθύνσεις IP, πρέπει να ρυθμίσετε τους προσαρμογείς δικτύου που σκοπεύετε να χρησιμοποιήσετε με στατική IP. Αυτό πρέπει να ρυθμιστεί έτσι ώστε να αντιστοιχεί σε κάθε συνδεδεμένη κάμερα.

Αυτό σημαίνει ότι εάν αποσυνδέσετε την κάμερα και την συνδέσετε σε διαφορετικό προσαρμογέα Ethernet, δεν θα “λειτουργεί” εκτός αν επαναρυθμιστεί.

Προειδοποίηση:

Ο αριθμός “Προσαρμογέα Ethernet” που αναφέρεται παρακάτω δεν είναι ο αριθμός που σχετίζεται με τον προσαρμογέα δικτύου αλλά χρησιμοποιείται για επεξηγηματικούς σκοπούς. Παρακαλούμε ρυθμίστε κάθε προσαρμογέα δικτύου ανά κάμερα, δηλαδή εάν έχετε δύο κάμερες συνδεδεμένες ρυθμίστε τες διαδοχικά και ανατρέξτε στους πίνακες για τον Προσαρμογέα Ethernet 1 & 2· μην αλλάξετε τις ρυθμίσεις σε προσαρμογείς δικτύου που δεν έχουν συνδεδεμένες κάμερες.

  • Κάντε δεξί κλικ στον Προσαρμογέα Ethernet πάνω από τη συνδεδεμένη κάμερα.

  • Κάντε κλικ στο “NIC Settings”.

  • Ενεργοποιήστε το Jumbo Frame.

  • Ορίστε τα Receive Buffers στη μέγιστη τιμή.

  • Ορίστε τα Transmit Buffers στη μέγιστη τιμή.

  • Κάντε κλικ στο “Open” στις “Internet Protocol Properties”

  • Ρυθμίστε τον προσαρμογέα δικτύου σύμφωνα με τον παρακάτω πίνακα.

Ορισμός στατικής IP στην κάμερα

Βεβαιωθείτε ότι η/οι κάμερα/ές Lynx είναι συνδεδεμένη/ες. Εάν την συνδέσατε αφού ξεκινήσατε την εφαρμογή, τοποθετήστε το ποντίκι πάνω από το μενού “GigE” και κάντε κλικ στο κουμπί ανανέωσης.

Αυτή η διαδικασία πρέπει να επαναληφθεί για όλες τις συνδεδεμένες κάμερες Lynx στις οποίες έχετε ορίσει στατική IP.

Παρακαλούμε σημειώστε ότι θα πρέπει να ορίσετε στατική IP στην κάμερα 1, στη συνέχεια στην κάρτα δικτύου 1 διαδοχικά. Μόλις ολοκληρώσετε με την 1 προχωρήστε στη 2 κ.ο.κ. Οι αριθμοί που αναφέρονται δεν είναι τα πραγματικά ονόματα των προσαρμογέων δικτύου, π.χ. “Ethernet 2”, αλλά χρησιμοποιούνται απλώς για επεξηγηματικούς σκοπούς.

  • Κάντε δεξί κλικ στην κάμερα στη λίστα και κάντε κλικ στο “Modify IP”

  • Αλλάξτε την επιλογή από DHCP ή LLA σε Static IP.

  • Ρυθμίστε τη διεύθυνση IP και τη μάσκα υποδικτύου σύμφωνα με την παρακάτω περιγραφή.

  • Η IP πρέπει να είναι διαφορετική για κάθε κάμερα.
