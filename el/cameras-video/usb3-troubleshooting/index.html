Αντιμετώπιση προβλημάτων κάμερας USB3

Αντιμετώπιση προβλημάτων (πιο συνηθισμένα προβλήματα)

Τα πιο συνηθισμένα προβλήματα σχετίζονται με το καλώδιο της κάμερας, τη σύνδεση, το εκτεταμένο USB κ.λπ.

Αυτό το άρθρο έχει ως στόχο να σας βοηθήσει είτε να επιλύσετε το πρόβλημα είτε να εντοπίσετε την αιτία του.

Ανεπαρκή Δεδομένα Ελήφθησαν / Η συσκευή δεν είναι συγχρονισμένη (το ρολόι παρεκκλίνει)

  1. Ανεπαρκή Δεδομένα Ελήφθησαν (Το SwingCatalyst / MotionCatalyst δεν διαθέτει αρκετά αποκτηθέντα δεδομένα βίντεο για Σύλληψη)

  • Αιτίες για αυτό μπορεί να είναι χαμένα Πλαίσια. (παρακαλώ δείτε την ενότητά μας για χαμένα πλαίσια παρακάτω για βήματα αντιμετώπισης προβλημάτων).

  • Περιορισμοί υλικού ή πόρων, ελέγξτε αν εκτελούνται άλλες απαιτητικές εφαρμογές.

  • Εάν χρησιμοποιείτε φορητό υπολογιστή με μπαταρία, προσπαθήστε να συνδέσετε το φορτιστή — εξαφανίζεται το σφάλμα; Αν ναι, η αλλαγή του σχεδίου παροχής ενέργειας (σε υψηλή Απόδοση) μπορεί να βοηθήσει.

  1. Το λογισμικό δεν έχει λάβει αρκετά δεδομένα, που σημαίνει ότι τα δεδομένα βίντεο που ελήφθησαν δεν είναι συγχρονισμένα με το ρολόι του υπολογιστή.

  • Ανάλογα με τον τύπο της κάμεράς σας υπάρχουν διαφορετικά πράγματα να δοκιμάσετε. Πολλές φορές το σφάλμα “Η συσκευή δεν είναι συγχρονισμένη” ακολουθεί το “Ανεπαρκή δεδομένα ελήφθησαν”· ωστόσο, αν λαμβάνετε μόνο το “Η συσκευή δεν είναι συγχρονισμένη (το ρολόι παρεκκλίνει)”, δοκιμάστε να επανεκκινήσετε τη λειτουργία Σύλληψης ή τον υπολογιστή.

  • Η παραμονή του συστήματος σε λειτουργία Σύλληψης για μεγαλύτερα χρονικά διαστήματα μπορεί να προκαλέσει αυτό. Επαναφέρουμε το ρολόι μόλις ξεκινήσει (ή επανεκκινήσει) η λειτουργία Σύλληψης, αλλά εάν παραμείνει σε Σύλληψη αρκετά μεγάλο διάστημα, το ρολόι της κάμερας και το ρολόι του υπολογιστή θα αρχίσουν να αποκλίνουν.

  • Τελευταία λύση για χρήστες web κάμερας: Δοκιμάστε να ενεργοποιήσετε την επιλογή “timestamp manually” από τις Ρυθμίσεις Κάμερας για Προχωρημένους –> καρτέλα Επιλογές.

Χαμένα Πλαίσια

Ε: Τι είναι τα χαμένα Πλαίσια;

Α: Χαμένα Πλαίσια σημαίνει ότι τα Πλαίσια βίντεο που λαμβάνονται από την/τις κάμερα/ες χάνονται σε διαφορετικό βαθμό.

Ανάλογα με τον αριθμό των χαμένων Πλαισίων, μπορεί να υπάρξει σοβαρή επίπτωση στο εγγεγραμμένο βίντεο. Σε περιβάλλοντα με πολλές κάμερες αυτό δεν είναι καλό, καθώς θα φαίνεται εκτός συγχρονισμού και βασικές στιγμές της εγγεγραμμένης Δραστηριότητας μπορεί να λείπουν.

Αιτίες χαμένων Πλαισίων

  • Κάμερα USB3 συνδεδεμένη σε θύρα USB 2.0.

  • Χρήση κακής ποιότητας καλωδίων ή καλωδίων επέκτασης.

  • Υπέρβαση του συνιστώμενου μήκους καλωδίου (5 μέτρα για USB3).

  • Κάμερα USB3 συνδεδεμένη σε hub USB με άλλες συσκευές που μοιράζονται το ίδιο hub, έλλειψη εύρους ζώνης.

  • Η κάμερα χρησιμοποιεί περισσότερο εύρος ζώνης από αυτό που διατίθεται στο σύστημα.

  • Ανεπαρκείς διαθέσιμοι πόροι συστήματος λόγω άλλων εκτελούμενων εφαρμογών.

Πώς να διορθώσετε τα χαμένα Πλαίσια

Για κάμερες USB η σύστασή μας είναι να μειώσετε τον Ρυθμό Πλαισίων (και/ή τη ροή δεδομένων της σύνδεσης συσκευής - για κάμερες FLIR) ώστε να μειωθεί η κατανάλωση εύρους ζώνης.

Βήματα αντιμετώπισης προβλημάτων:

  • Εάν χρησιμοποιείτε πολλές κάμερες, δοκιμάστε να αποσυνδέσετε ή να απενεργοποιήσετε μερικές κάμερες — το σύστημα εξακολουθεί να αναφέρει χαμένα Πλαίσια;

Αν αυτό βοηθήσει, μπορεί να υποδηλώνει πρόβλημα Απόδοσης ή πρόβλημα πόρων εύρους ζώνης. Δοκιμάστε να μειώσετε τον Ρυθμό Πλαισίων και στις δύο κάμερες και δείτε αν βελτιώνεται η σταθερότητα.

  • Κλείστε άλλο λογισμικό που μπορεί να είναι απαιτητικό σε CPU & Γραφικά, ώστε να ελευθερωθούν πόροι.

  • Δοκιμάστε να μειώσετε τον Ρυθμό Πλαισίων: (παράδειγμα για FLIR Blackfly S)

  • Δοκιμάστε να μειώσετε τη “ροή δεδομένων σύνδεσης συσκευής”, δείτε “μείωση εύρους ζώνης κάμερας” παρακάτω.

  • Εξετάστε τα καλώδια — είναι οι κάμερες συνδεδεμένες σε hub USB ή επεκτατή; Είναι το καλώδιο έντονα λυγισμένο ή έχει ορατές ζημιές; Δοκιμάστε να τις συνδέσετε απευθείας στον υπολογιστή.

  • Πληροί ο υπολογιστής τις συνιστώμενες προδιαγραφές; Αν όχι, ίσως χρησιμοποιείτε περισσότερες κάμερες από όσες μπορεί να διαχειριστεί το σύστημα.

Ορισμένα καλώδια USB λειτουργούν καλύτερα από άλλα και ορισμένοι ενσωματωμένοι ελεγκτές USB 3.0 μπορεί να προκαλέσουν προβλήματα.

Καθώς το USB3 μπορεί να είναι αρκετά περίπλοκο, συνιστούμε να ακολουθείτε τις οδηγίες που προτείνουν οι μεγάλοι αξιόπιστοι κατασκευαστές καμερών Machine Vision. Δείτε το άρθρο μας για τα συνιστώμενα εξαρτήματα USB για λεπτομέρειες: recommended-usb3-components.md

Μείωση κατανάλωσης εύρους ζώνης κάμερας

Η μείωση του Ρυθμού Πλαισίων μόνη της ή σε συνδυασμό με το Region Of Interest (ROI) μπορεί να επηρεάσει το πόσο εύρος ζώνης καταναλώνει μια κάμερα και να μειώσει ή να σταματήσει αποτελεσματικά τα χαμένα Πλαίσια.

Για παράδειγμα, το USB 3.0 διαφημίζεται ότι είναι ικανό για 5Gb/s, δηλαδή 625 MB/s.

Μία κάμερα USB 3.0 με ανάλυση: 1920 x 1200 στα 150 FPS θα χρησιμοποιεί περίπου 345MB/s ανά κάμερα. - Είναι επομένως σημαντικό να διαθέτετε αποκλειστική κάρτα ελεγκτή USB 3.0 σύμφωνα με τις συστάσεις μας για ρυθμίσεις με πολλές κάμερες (στις περισσότερες περιπτώσεις). Σε πολλές περιπτώσεις, ένας φορητός υπολογιστής δεν θα μπορεί να οδηγήσει δύο κάμερες USB3 πλήρους HD υψηλού FPS.

Μια άλλη προσέγγιση, συχνά χρήσιμη σε συνδυασμό με τη μείωση της ροής δεδομένων, είναι η χρήση της περιοχής ενδιαφέροντος, γνωστής ως ROI.

Πώς να γνωρίζω πόσο εύρος ζώνης καταναλώνει μια κάμερα;

Μπορείτε να χρησιμοποιήσετε τον τύπο: Ρυθμός Δεδομένων = Ανάλυση * Ρυθμός Πλαισίων * βάθος bit.

Στις περισσότερες περιπτώσεις το βάθος bit θα είναι 8 bits.

Ρυθμός Δεδομένων MB/s Ανάλυση (πλάτος x ύψος) Ρυθμός Πλαισίων Βάθος bit (bits ανά pixel)
30,7 640x480 100 8
92,1 1280x720 100 8
131,1 1280x1024 100 8
207,4 1920x1080 100 8

Region Of Interest (ROI)

Note: Υποστηριζόμενες κάμερες: Swing Catalyst Fox, FLIR Blackfly S

Η χρήση του Region Of Interest (ή περιοχής ενδιαφέροντος) μπορεί να βοηθήσει στη μείωση του εύρους ζώνης που καταναλώνει μια κάμερα και στην ενίσχυση των FPS. Μπορεί επίσης να χρησιμοποιηθεί για τη μείωση των χαμένων Πλαισίων.

Δείτε το άρθρο μας σχετικά με τον τρόπο χρήσης του Region Of Interest.

Δεν Ελήφθησαν Δεδομένα

Αυτό υποδηλώνει ότι το SwingCatalyst δεν λαμβάνει εικόνες βίντεο ή δεδομένα προς επεξεργασία.

Παραδείγματα αιτιών για αυτόν τον τύπο σφάλματος μπορεί να είναι:

  • Κακό καλώδιο ή σύνδεση: Δοκιμάστε να αποσυνδέσετε την κάμερα και να τη συνδέσετε σε διαφορετική θύρα USB.

  • Εσφαλμένες ρυθμίσεις: (Ειδικά για web κάμερες και κάμερες DirectShow). Ελέγξτε τη ρύθμιση έκθεσης· αν το Auto έχει αποεπιλεγεί και η έκθεση είναι ρυθμισμένη πολύ υψηλά, ο Ρυθμός Πλαισίων μπορεί να μειωθεί σημαντικά.

Κάτι πήγε στραβά

Αυτός ο τύπος σφάλματος είναι συνηθισμένος όταν η κάμερα χρησιμοποιείται από άλλη εφαρμογή.

Ειδικά οι web κάμερες μπορεί εύκολα να χρησιμοποιούνται από λογισμικό τρίτων· δοκιμάστε να κλείσετε άλλα προγράμματα και να προσπαθήσετε ξανά. Αν το σφάλμα επιμένει, δοκιμάστε να επανεκκινήσετε τον υπολογιστή.

Η κάμερα δεν εμφανίζεται στη λίστα ρυθμίσεων κάμερας

Εάν η κάμερα δεν εμφανίζεται στη λίστα καμερών, δεν ανιχνεύεται ή δεν είναι σωστά συνδεδεμένη.

  • Εάν η κάμερα δεν εμφανίζεται στη λίστα καμερών, πιθανότατα δεν αναγνωρίζεται στα Windows ή χρησιμοποιείται από άλλη εφαρμογή. Δοκιμάστε να αποσυνδέσετε την κάμερα και να τη συνδέσετε ξανά.

  • Η κάμερα μπορεί να μην υποστηρίζεται από το SwingCatalyst.

  • Για κάμερες The Imaging Source: Εάν έχετε εγκατεστημένο το Driver του κατασκευαστή, ίσως χρειαστεί να το απεγκαταστήσετε για να λειτουργήσει.

  • Οι κάμερες Ethernet (δικτύου) / GigE μπορεί να απαιτούν διαμόρφωση IP (παρακαλώ αναζητήστε ένα άρθρο για το συγκεκριμένο μοντέλο/κατασκευαστή στο κέντρο βοήθειάς μας).

Προβλήματα συνδεσιμότητας (αποσύνδεση κάμερας)

Το USB 3 μπορεί να είναι επιρρεπές σε προβλήματα συνδεσιμότητας. Τις περισσότερες φορές αυτά τα προβλήματα προέρχονται από έναν κακής ποιότητας επεκτατή USB 3.0, υπερβολικά μακρύ καλώδιο (συνολικά) ή απλώς ένα καλώδιο που έχει υποστεί ζημιά από έντονη κάμψη.

Άλλα

Ανάλογα με το υλικό σας, μπορεί να μην είναι ιδανικό να έχετε ενεργοποιημένα τα Φίλτρα sharpening και denoise· απενεργοποιώντας τα θα μειωθεί κάπως η χρήση CPU & GPU. Μπορείτε να βρείτε τα Φίλτρα κάμερας στην καρτέλα Φίλτρα των Ρυθμίσεων Κάμερας για Προχωρημένους. Περισσότερες πληροφορίες για τα Φίλτρα εδώ: improving-image-quality.md
