Πώς να χρησιμοποιήσετε κάμερες IDS uEye USB με το Swing Catalyst

Εισαγωγή

Αυτό το άρθρο υποστήριξης περιγράφει τις πρακτικές λεπτομέρειες για τη διαμόρφωση και χρήση μιας κάμερας IDS uEye USB.

Κάντε κλικ εδώ για λεπτομέρειες εγκατάστασης

Για GigE (δικτυακές κάμερες IDS) δείτε αυτό το άρθρο: ids-ueye-gige.md

Εφαρμόζεται σε

  • Ξεκινώντας με μια κάμερα IDS uEye USB και το Swing Catalyst.

Περιγραφή της Κάμερας

Η κάμερα uEye USB αποτελείται από τρία ξεχωριστά εξαρτήματα:

  • Η ίδια η κάμερα

  • Ο φακός

  • Το καλώδιο USB

Κάμερα

Η ίδια η κάμερα δεν διαθέτει φυσικές ρυθμίσεις· όλες οι ρυθμίσεις ελέγχονται από το λογισμικό.

Φακός

Ο παρεχόμενος φακός διαθέτει 3 δακτυλίους ρύθμισης, οι οποίοι, με σειρά από την κάμερα προς τα έξω, είναι:

  • Ζουμ

  • Iris

  • Εστίαση

Ζουμ/Εστίαση

Σε έναν φακό μεταβλητής εστίασης (ζουμ), οι δακτύλιοι Ζουμ και Εστίασης λειτουργούν μαζί, οπότε μπορεί να χρειαστεί να ρυθμίσετε και τους δύο δακτυλίους για καλή εστίαση/ζουμ.

Iris

Ο δακτύλιος ρύθμισης Iris καθορίζει την ποσότητα φωτός (το «άνοιγμα»).

Το κλείσιμο του Iris θα έχει ως αποτέλεσμα μια πιο σκοτεινή εικόνα, αλλά θα βοηθήσει στην καλύτερη εστίαση αυξάνοντας το βάθος εστίασης (η περιοχή που βρίσκεται «εντός εστίασης»).

Εάν η εικόνα είναι υπερεκτεθειμένη (π.χ. σε μια πολύ ηλιόλουστη μέρα), συνιστάται το κλείσιμο του Iris.

Οι Ρυθμίσεις Λογισμικού

Στο Swing Catalyst, όλες οι ρυθμίσεις κάμερας είναι διαθέσιμες μέσω του κουμπιού “Advanced” στις “Camera Settings”, που βρίσκεται στο κύριο μενού υπό Ρυθμίσεις - Κάμερες.

Κάνοντας κλικ στο κουμπί “Advanced”, εμφανίζεται το παράθυρο διαλόγου Προηγμένων Ρυθμίσεων Κάμερας.

Για τις κάμερες uEye υπάρχουν ορισμένες σημαντικές ρυθμίσεις που καθορίζουν βασικά χαρακτηριστικά της κάμερας:

Ρολόι Pixel

Το Ρολόι Pixel είναι ουσιαστικά μια ρύθμιση «ταχύτητας»· η αύξησή του θα αυξήσει τον μέγιστο διαθέσιμο ρυθμό πλαισίων, αλλά η υπερβολική αύξησή του μπορεί να οδηγήσει σε απώλεια πλαισίων.

Ρυθμός Πλαισίων

Η ρύθμιση ρυθμού πλαισίων επιτρέπει τόσο αυτόματη όσο και χειροκίνητη διαμόρφωση του ρυθμού πλαισίων.

Συνιστάται η χρήση χειροκίνητης ρύθμισης, καθώς η αυτόματη λειτουργία απενεργοποιεί άλλες αυτόματες λειτουργίες, όπως το αυτόματο Gain.

Κλείστρο Έκθεσης

Ένας χαμηλός χρόνος κλείστρου είναι απαραίτητος για την καταγραφή γρήγορης κίνησης και τη μείωση της θολούρας κίνησης.

Για μια Αιώρηση γκολφ, συνιστάται η χρήση μέγιστης έκθεσης 2ms (χιλιοστών του δευτερολέπτου) για να ληφθεί μια αξιοπρεπής εικόνα.

Για μια πολύ καθαρή εικόνα, μια ρύθμιση έκθεσης 0,5ms είναι καλή, αλλά απαιτεί πολύ φωτισμό και συνιστάται μόνο για εξωτερική χρήση.

Είναι δυνατό να ρυθμίσετε το Κλείστρο Έκθεσης σε αυτόματη λειτουργία, με ανώτατο όριο μέσω της παραμέτρου “Max” της αυτόματης λειτουργίας· αυτή είναι μια καλή επιλογή για να επιτρέψετε στην κάμερα να προσαρμόζεται σε διάφορες συνθήκες φωτισμού διατηρώντας παράλληλα καλή ποιότητα εικόνας.

Gain

Το Gain αυξάνει τη φωτεινότητα της εικόνας, αλλά εισάγει επίσης περισσότερο θόρυβο στην εικόνα.

Στις περισσότερες περιπτώσεις, συνιστάται η χρήση αυτόματου Gain για να επιτρέψετε στην κάμερα να αυτορυθμίζεται.

Ισορροπία Λευκού

Συνιστάται να ρυθμίσετε την ισορροπία λευκού σε Auto για να επιτρέψετε στην κάμερα να ρυθμίζει την ισορροπία χρωμάτων στην εικόνα.

Εάν τα χρώματα στην εικόνα φαίνονται λανθασμένα, χρησιμοποιήστε τη χειροκίνητη ρύθμιση για να τροποποιήσετε τις παραμέτρους Κόκκινου, Πράσινου και Μπλε.

Μεγιστοποίηση Πλαισίων ανά Δευτερόλεπτο (FPS)

Ο μέγιστος αριθμός FPS σας θα ποικίλλει ανάλογα με τις προδιαγραφές του υπολογιστή σας. Όταν εμφανίζεται απώλεια πλαισίων, σημαίνει ότι το σύστημα δεν μπορεί να ανταποκριθεί σε όλα τα δεδομένα και πρέπει να μειώσετε την ταχύτητα.

Ακολουθεί μια βήμα προς βήμα διαδικασία για να σας βοηθήσει να μεγιστοποιήσετε την Απόδοση της κάμεράς σας.

  • Μεταβείτε στο Κύριο Μενού -> Ρυθμίσεις -> Κάμερες.

  • Κάντε κλικ στο κουμπί “Advanced” στην κάμερα uEye σας.

  • Στο παράθυρο διαλόγου προηγμένων ρυθμίσεων, μεταβείτε στην καρτέλα Camera.

  • Κάντε κλικ στο κουμπί “Play” στον πίνακα προεπισκόπησης βίντεο για να ξεκινήσει η ζωντανή ροή βίντεο.

  • Σύρετε το ρυθμιστικό “Speed (pixel clock)” προς τα δεξιά μέχρι να δείτε τον μετρητή απωλειών πλαισίων να αρχίζει να αυξάνεται (κάτω δεξιά).

  • Σύρετε το ρυθμιστικό ελαφρά προς τα αριστερά μέχρι να σταματήσει η απώλεια πλαισίων, και λίγο ακόμα. Για παράδειγμα, εάν διαπιστώσετε ότι σταματά να χάνει πλαίσια στο 38, τότε ρυθμίστε το στο 35.

Μόλις βρείτε την ταχύτητα κατά την οποία ο ρυθμός πλαισίων είναι όσο το δυνατόν υψηλότερος χωρίς απώλεια πλαισίων, είστε έτοιμοι.

Αντιμετώπιση Προβλημάτων

Απώλεια πλαισίων/«Τρεμοπαίξιμο» εικόνας κατά την Αναπαραγωγή

Εάν η κάμερα χάνει πλαίσια, το δίαυλος USB του υπολογιστή ενδέχεται να μην μπορεί να διαχειριστεί τις απαιτήσεις εύρους ζώνης της κάμερας.

Δοκιμάστε να μειώσετε την Ταχύτητα (ρολόι pixel) μέχρι η κάμερα να σταματήσει να χάνει πλαίσια.

Αδυναμία εστίασης (πολύ θολή εικόνα)

Εάν δεν μπορείτε καθόλου να εστιάσετε την κάμερα (χρησιμοποιώντας τον δακτύλιο ρύθμισης εστίασης), ελέγξτε ότι δεν υπάρχει μεταλλικός δακτύλιος τοποθετημένος μεταξύ της κάμερας και ενός φακού.

Ο μεταλλικός δακτύλιος είναι ένας προσαρμογέας CS-to-C-mount και δεν απαιτείται όταν τόσο η κάμερα όσο και ο φακός είναι CS-mount.

Αναβάθμιση σε Windows 10

Σημειώστε ότι υπάρχει ένα γνωστό πρόβλημα κατά τη χρήση ενημερώσεων των Windows για αναβάθμιση σε Windows 10. Εάν αντιμετωπίσετε σφάλμα ή «μπλε οθόνη» κατά την προσπάθεια αναβάθμισης σε Windows 10, θα πρέπει πρώτα να απεγκαταστήσετε το λογισμικό IDS μέσω «προγράμματα και δυνατότητες». Στη συνέχεια, επανεγκαταστήστε το πρόγραμμα οδήγησης από τη σελίδα λήψεων μας μετά την αναβάθμιση.
