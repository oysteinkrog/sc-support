Πώς να ρυθμίσετε κάμερες Basler GigE με το Swing Catalyst

Αυτό το άρθρο υποστήριξης καλύπτει την Προετοιμασία και τη διαμόρφωση καμερών Basler με το Swing Catalyst.

note: Για να χρησιμοποιήσετε κάμερες Basler με το Swing Catalyst θα χρειαστείτε ένα Halcon USB dongle και άδεια χρήσης. Επικοινωνήστε με contact@swingcatalyst.com για να αγοράσετε άδεια χρήσης.

Οδηγίες εγκατάστασης και διαμόρφωσης Halcon εδώ:

halcon-setup.md

Σημαντικό:

Βεβαιωθείτε ότι έχετε εγκαταστήσει το φίλτρο Ντράιβερ MVTec Halcon, καθώς οι κάμερες δεν θα λειτουργούν σωστά χωρίς αυτό. Επίσης, βεβαιωθείτε ότι έχετε αποεπιλέξει τυχόν άλλα φίλτρα Ντράιβερ που είναι εγκατεστημένα, π.χ. φίλτρο Ντράιβερ Basler.

Βεβαιωθείτε ότι το Swing Catalyst επιτρέπεται τόσο σε ιδιωτικά όσο και σε δημόσια δίκτυα στο τείχος προστασίας Windows Defender

Παράδειγμα:

Ρύθμιση της IP των καμερών

Προετοιμασία IP

Κάθε κάμερα και κάρτα Ethernet (NIC / Network interface controller) πρέπει να διαμορφωθεί με στατικές IP σε διαφορετικά subnets (και subnet mask)

note: Η IP του NIC είναι η διεύθυνση IP του προσαρμογέα δικτύου στον υπολογιστή σας και η IP της κάμερας είναι η διεύθυνση IP της κάμερας. Το … υποδηλώνει ένα Εύρος, καθώς αυτό είναι παράδειγμα IP που μπορείτε να ορίσετε.

Παραδείγματα για μεμονωμένες ή πολλαπλές κάμερες (με μία ή περισσότερες κάρτες δικτύου / προσαρμογείς):

Κάμερες σε προσαρμογέα δικτύου 1: nic ip: 10.0.1.1 cam ip: 10.0.1.10 … 10.0.1.20 subnet mask:255.255.255.0

Κάμερες σε προσαρμογέα δικτύου 2: nic ip: 10.0.2.1 cam ip: 10.0.2.10 … 10.0.2.20 subnet mask: 255.255.255.0

Κάμερες σε προσαρμογέα δικτύου 3: nic ip: 10.0.3.1 cam ip: 10.0.3.10 … 10.0.3.20 subnet mask: 255.255.255.0

Κάμερες σε προσαρμογέα δικτύου 4: nic ip: 10.0.4.1 cam ip: 10.0.4.10 … 10.0.4.20 subnet mask: 255.255.255.0

Αρχικά πρέπει να ρυθμίσουμε την IP της κάμερας, κάτι που γίνεται μέσω του Pylon IP Configurator.

Πατήστε το κουμπί του μενού έναρξης στο πληκτρολόγιό σας και πληκτρολογήστε pylon ip και ο IP Configurator θα εμφανιστεί. Αν δεν εμφανιστεί, πιθανόν να μην έχετε εγκατεστημένο το λογισμικό.

Για να εγκαταστήσετε το λογισμικό Pylon δείτε: https://www.baslerweb.com/en/sales-support/downloads/software-downloads/ και αναζητήστε: pylon 5.1.0 Camera Software Suite Windows.

Κάντε κλικ στην κάμερα και επιλέξτε Static IP

Ορίστε τη διεύθυνση IP της κάμερας και το subnet mask σύμφωνα με το παραπάνω παράδειγμα.

Διαμόρφωση καμερών Basler GigE μέσω Halcon

Στο Swing Catalyst, μεταβείτε στην καρτέλα Ρυθμίσεων και στις Κάμερες.

Κάντε κλικ στο Advanced.

  • Μεταβείτε στην καρτέλα Configuration.

  • Ενεργοποιήστε το πλαίσιο ελέγχου GtlNumBuffers και εισαγάγετε 200 ως τιμή.

Ρύθμιση καμερών Basler GigE:

Ας δούμε πώς να ορίσετε την έκθεση, την ταχύτητα κλείστρου και τον Ρυθμό Πλαισίων.

ΣΗΜΕΙΩΣΗ: Αν δεν μπορείτε να δείτε τις ρυθμίσεις και λαμβάνετε σφάλμα στο Swing Catalyst, ελέγξτε τις ρυθμίσεις του τείχους προστασίας Windows. Δοκιμάστε να απενεργοποιήσετε το τείχος προστασίας για να ελέγξετε αν αυτό εμποδίζει την πρόσβαση του Swing Catalyst στις κάμερες.

Αν οι ρυθμίσεις λειτουργούν και η ροή εικόνας είναι ομαλή, βεβαιωθείτε ότι το Swing Catalyst επιτρέπεται τόσο σε δημόσια όσο και σε ιδιωτικά δίκτυα στο τείχος προστασίας Windows Defender.

Αναπτύξτε την καρτέλα AcquisitionTrigger και εισαγάγετε τον μέγιστο (ή χαμηλότερο) Ρυθμό Πλαισίων, έπειτα κάντε κλικ στο Enable Acquisition Frame Rate. Αυτό θα σας επιτρέψει να ορίσετε τον Ρυθμό Πλαισίων. Σημείωση: Ο Ρυθμός Πλαισίων μπορεί να περιοριστεί από τις τιμές έκθεσης.

Ρύθμιση τιμών έκθεσης

Συνήθως είναι καλύτερο να χρησιμοποιείτε χειροκίνητη έκθεση για στατικά περιβάλλοντα, όπως εσωτερικά στούντιο. Μια πλήρως αυτόματη έκθεση μπορεί να προκαλέσει αλλαγή του Ρυθμού Πλαισίων και να οδηγήσει σε ασταθή εικόνα. Στην προκειμένη περίπτωση δεν χρησιμοποιούμε αυτόματη έκθεση καθώς θέλουμε να την ελέγχουμε εμείς. Γενικά, συνιστάται χρόνος έκθεσης μικρότερος από 2000 (2ms).

Ρύθμιση τιμών Gain

Παρόμοια με την έκθεση, η ρύθμιση του Gain σε χειροκίνητο για στατικές / εσωτερικές συνθήκες φωτισμού είναι η καλύτερη επιλογή. Όσο υψηλότερη είναι η έκθεση, τόσο πιο κοκκώδης θα είναι η εικόνα και τόσο περισσότερο χρόνο θα χρειαστεί η κωδικοποίηση βίντεο σε σύγκριση με χαμηλό Gain.

Για να ορίσετε χειροκίνητο Gain, αλλάξτε το Gain Auto από Continuous σε Off, έπειτα θέστε σε Παύση και ξεκινήστε την Αναπαραγωγή για να επαναφορτώσετε τις ρυθμίσεις. Ορίστε τις τιμές Gain αλλάζοντας τις αριθμητικές τιμές στο Gain (Raw).

Αλλαγή μεγέθους εικόνας, περιοχής ενδιαφέροντος, Region of Interest και άλλα

Σε ορισμένες περιπτώσεις θέλετε να μειώσετε το μέγεθος της εικόνας για να εστιάσετε σε μια συγκεκριμένη περιοχή της βιντεοεικόνας, για παράδειγμα για να δείτε τη μπαστούνα και τη μπάλα κατά την Κρούση με λεπτομέρεια.

Αυτό μπορεί να γίνει με την περιοχή ενδιαφέροντος, γνωστή και ως AOI, και ROI, Region of Interest. Η μείωση του συνολικού μεγέθους εικόνας με αυτή τη λειτουργία μπορεί επίσης να αυξήσει τον Ρυθμό Πλαισίων.

Αποθήκευση ρυθμίσεων στην κάμερα

Είναι σημαντικό να αποθηκεύετε τις ρυθμίσεις στην κάμερα. Αν δεν γίνει αυτό, όλες οι διαμορφώσεις που έχετε κάνει θα χαθούν.

Βεβαιωθείτε ότι έχετε ορίσει το Default Set Selector & Default Startup Set. Υπάρχουν διαφορετικά σύνολα χρήστη για να επιλέξετε και θεωρητικά μπορείτε να έχετε διαφορετικές ρυθμίσεις αποθηκευμένες σε κάθε σύνολο. Δηλαδή, μπορείτε να επιλέξετε “User Set 1” ως προεπιλογή σας και στη συνέχεια να πατήσετε User Set Save για να αποθηκεύσετε τις τρέχουσες ρυθμίσεις σας σε αυτό το προφίλ.
