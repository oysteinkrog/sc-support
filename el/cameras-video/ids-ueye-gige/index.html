Πώς να ρυθμίσετε τις κάμερες IDS uEye GigE για χρήση με το Swing Catalyst

Για την Προετοιμασία κάμερας USB, παρακαλούμε δείτε αυτό το άρθρο: ids-ueye-usb.md

Σημείωση: Αυτό το άρθρο προϋποθέτει ότι έχετε εγκαταστήσει τους Ντράιβερ uEye που βρίσκονται εδώ: https://www.swingcatalyst.com/drivers

Αυτό το άρθρο καλύπτει την Προετοιμασία των διευθύνσεων IP τόσο της κάμερας όσο και της κάρτας δικτύου.

Σημείωση: Το Swing Catalyst δεν υποστηρίζει IDS AOI (περιοχή ενδιαφέροντος) για κάμερες IDS.

Συμβατοί προσαρμογείς δικτύου και ρύθμιση παραμέτρων:

Παρακαλούμε δείτε: gige-network-setup.md

Σημείωση, σημαντικό για την Απόδοση: Εάν διαθέτετε κάρτα δικτύου Intel, παρακαλούμε κατεβάστε και εγκαταστήστε τους Ντράιβερ Intel, καθώς αυτό θα σας παρέχει επιλογές για τη ρύθμιση ρυθμών διαμόρφωσης διακοπής, που ενδέχεται να μην είναι διαθέσιμες με τους Ντράιβερ των Windows.

Ρύθμιση της/των κάμερας/καμερών IDS uEye GigE

Βήματα:

Πριν προχωρήσετε, εγκαταστήστε τους Ντράιβερ IDS uEye. Εντοπίστε και ανοίξτε την εφαρμογή IDS Camera Manager (μπορεί να βρεθεί στη διαδρομή: C:\ProgramData\Microsoft\Windows\Start Menu\Programs\IDS).

Η εφαρμογή IDS Camera Manager:

Παρατηρήστε την προειδοποίηση στο κάτω μέρος της εφαρμογής. Υπάρχουν αρκετές προειδοποιήσεις που μπορεί να εμφανιστούν λόγω εσφαλμένης ρύθμισης διευθύνσεων IP ή λόγω θεμάτων που σχετίζονται με το firmware της κάμερας.

Παράδειγμα:

Σημείωση σχετικά με τη ρύθμιση παραμέτρων διεύθυνσης IP και τις συστάσεις μας**

**

Η σύσταση μας είναι να έχετε μία αποκλειστική κάρτα δικτύου ή διεπαφή δικτύου για κάθε κάμερα. Ωστόσο, με το μοντέλο IDS UI-3220 μπορείτε να χρησιμοποιήσετε δύο κάμερες για κάθε θύρα δικτύου με τη χρήση ενός μεταγωγέα δικτύου (δείτε Χρήση μεταγωγέα δικτύου).

Η συνιστώμενη Προετοιμασία IP:

Κάθε κάμερα και κάρτα Ethernet (γνωστή επίσης ως NIC) θα πρέπει να διαμορφωθεί με στατικές IP σε διαφορετικά υποδίκτυα (και μάσκα υποδικτύου).

Παράδειγμα:

Κάμερες σε κάρτα δικτύου 1: nic ip: 10.0.1.1 cam ip: 10.0.1.10 … 10.0.1.20 subnet mask:255.255.255.0

Κάμερες σε κάρτα δικτύου 2: nic ip: 10.0.2.1 (διαφορετικό υποδίκτυο από το nic1) cam ip: 10.0.2.10 … 10.0.2.20 (διαφορετικό υποδίκτυο από το nic1) subnet mask: 255.255.255.0

Ενεργοποίηση της υπηρεσίας δικτύου uEye

Σημείωση: Εάν χρησιμοποιείτε διαφορετικούς τύπους καμερών από διαφορετικούς κατασκευαστές, η ενεργοποίηση της υπηρεσίας δικτύου uEye ενδέχεται να προκαλέσει προβλήματα κατά τη χρήση κάμερας άλλου κατασκευαστή.

Κάντε κλικ στο ETH network service

Επιλέξτε τον προσαρμογέα δικτύου που θέλετε να ρυθμίσετε (σε αυτή την περίπτωση είναι οι προσαρμογείς διπλής θύρας)

Το γραφικό της κάρτας δικτύου εμφανίζεται γκριζαρισμένο, επειδή δεν έχει ρυθμιστεί σωστά. Η υπηρεσία δικτύου uEye πρέπει να είναι ενεργοποιημένη για να είναι ορατή η κάμερα στο δίκτυο.

Βεβαιωθείτε ότι έχετε ορίσει τη διεύθυνση IP και τη μάσκα υποδικτύου όπως συνιστάται (βλέπε παραπάνω), στη συνέχεια κάντε κλικ στο Enable uEye network service και κλικ στο Apply changes (έχετε πλέον ορίσει μια στατική διεύθυνση IP για έναν από τους προσαρμογείς διπλής θύρας!).

Αυτόματη Προετοιμασία IP (για χειροκίνητη IP δείτε παρακάτω)

Για να χρησιμοποιήσετε τη ρύθμιση αυτόματης παραμέτρου IP, κάντε κλικ στο Automatic ETH configuration και κλικ στο OK.

Ο IDS Camera Manager θα έχει ορίσει αυτόματα μια διεύθυνση IP στην κάρτα δικτύου και στην κάμερα για εσάς.

Σημείωση: Συνιστούμε χειροκίνητη Προετοιμασία IP όταν χρησιμοποιείτε πολλές κάμερες.

Χειροκίνητη Προετοιμασία IP

Πίσω στον IDS Camera Manager, θα πρέπει τώρα να βλέπετε τη/τις κάμερα/κάμερες στη λίστα. Δεδομένου ότι προηγουμένως ορίσατε μια στατική διεύθυνση IP για τον προσαρμογέα δικτύου, πρέπει τώρα να ορίσετε μια στατική IP για την κάμερα, ώστε ο προσαρμογέας δικτύου και η κάμερα να μπορούν να επικοινωνούν μεταξύ τους σωστά.

Επιλέξτε το πλαίσιο Expert Mode όπως φαίνεται εδώ:

Παρατηρήστε την παραπάνω προειδοποίηση με κόκκινο χρώμα.

Κάντε κλικ στο Manual ETH configuration:

Στο παραπάνω στιγμιότυπο οθόνης, η διεύθυνση IP της κάμερας έχει οριστεί σε 10.0.1.10 (η κάρτα δικτύου μας είναι 10.0.1.1). Εισαγάγετε τα δεδομένα όπως φαίνεται στο παραπάνω στιγμιότυπο οθόνης και κάντε κλικ στο OK.

Σημείωση: Ο ορισμός στατικών διευθύνσεων IP δεν είναι απαραίτητος, αλλά συνιστάται ανεπιφύλακτα, καθώς οι αυτόματες ρυθμίσεις IP μπορούν να προκαλέσουν προβλήματα με διενέξεις διευθύνσεων IP, π.χ. η ίδια διεύθυνση IP να χρησιμοποιείται αλλού. Συνιστούμε ανεπιφύλακτα τη ρύθμιση στατικής Προετοιμασίας για όλες τις εγκαταστάσεις studio.

Επαναλάβετε τα βήματα για τις υπόλοιπες κάμερες και NICs σύμφωνα με τις συνιστώμενες ρυθμίσεις IP που αναφέρονται παραπάνω.

Ρύθμιση παραμέτρων του/των προσαρμογέα/ών δικτύου για χρήση με κάμερες IDS uEye

Υποθέτοντας ότι έχετε πλέον ορίσει στατικές διευθύνσεις IP τόσο για τη/τις κάμερα/κάμερες όσο και για την κάρτα δικτύου, ας προχωρήσουμε στη ρύθμιση του προσαρμογέα δικτύου για βέλτιστη Απόδοση.

Από τον Πίνακα Ελέγχου\Δίκτυο και Internet\Συνδέσεις Δικτύου κάντε διπλό κλικ στον προσαρμογέα που θέλετε να ρυθμίσετε, στην προκειμένη περίπτωση είναι το Ethernet 4, Intel (PRO/1000 PT Dual port).

Κάντε διπλό κλικ στον προσαρμογέα δικτύου που θέλετε να ρυθμίσετε.

Κάντε κλικ στην καρτέλα Για προχωρημένους. Σημείωση: Η ρύθμιση παραμέτρων διαφέρει για κάθε προσαρμογέα δικτύου και ανάλογα με τον Driver, παρακαλούμε ανατρέξτε στην τεκμηρίωση της κάρτας δικτύου σας για συγκεκριμένες πληροφορίες σχετικά με την αλλαγή των συγκεκριμένων ρυθμίσεων που εμφανίζονται παρακάτω.

Βεβαιωθείτε ότι η Διαμόρφωση Διακοπής είναι ενεργοποιημένη και ο Ρυθμός Διαμόρφωσης Διακοπής έχει οριστεί σε Extreme.

Εάν δεν έχετε την επιλογή Extreme, ορίστε το σε High.

Σε ορισμένες περιπτώσεις, η απενεργοποίηση της διαμόρφωσης διακοπής μπορεί να βοηθήσει εάν κανένας από τους υψηλούς ρυθμούς διαμόρφωσης διακοπής δεν λειτουργεί, αλλά εφόσον διαθέτετε συνιστώμενη κάρτα δικτύου, οι επιλογές High και Extreme θα πρέπει να είναι διαθέσιμες. Η ενεργοποίηση της διαμόρφωσης διακοπής είναι καθοριστική για τη μείωση της χρήσης CPU κατά τον χειρισμό μεγάλου αριθμού πακέτων, ειδικά σε κάμερες υψηλότερης ανάλυσης ή/και υψηλού FPS.

Ρυθμός διαμόρφωσης διακοπής:

Ενεργοποίηση υποστήριξης για Jumbo Packets (ορίστε το σε 9014 Bytes):

Receive Buffers:

Συνιστάται να ορίσετε αυτή την τιμή στο μέγιστο δυνατό. Αυτό μπορεί να βοηθήσει στην αποφυγή απώλειας Πλαισίων κατά τη χρήση πολλών καμερών ή/και GigE καμερών υψηλότερης ανάλυσης.

Χρήση μεταγωγέα δικτύου:

Εάν πρόκειται να χρησιμοποιήσετε μεταγωγέα δικτύου, είναι σημαντικό ο μεταγωγέας να υποστηρίζει Jumbo Frames 9KB και ο προσαρμογέας δικτύου να έχει ρυθμιστεί για χρήση Jumbo Frames 9KB. Ωστόσο, σε ορισμένες περιπτώσεις μερικοί μεταγωγείς ενδέχεται να μην λειτουργούν καλά με μεγέθη Πλαισίων 9KB. Σε αυτές τις περιπτώσεις συνιστάται να μειώσετε από 9KB σε μικρότερο αριθμό και να επαναδοκιμάσετε την Προετοιμασία.

Χρήση της/των κάμερας/καμερών στο Swing Catalyst

Αφού ρυθμίσετε τις διευθύνσεις IP και τους προσαρμογείς δικτύου σύμφωνα με τις παραπάνω συστάσεις, μπορείτε να εκκινήσετε το Swing Catalyst και η κάμερα θα πρέπει να είναι ορατή στη λίστα καμερών.

Ορίστε μια Γωνία κάμερας και ενεργοποιήστε την κάμερα, στη συνέχεια κάντε κλικ στο Configure.

Βεβαιωθείτε ότι το pixel clock βρίσκεται στο μέγιστο (ή μειώστε το εάν χάνετε Πλαίσια).

Ορίστε την ταχύτητα κλείστρου και το Gain (σημειώστε ότι αυτές οι τιμές μπορεί να ποικίλλουν σημαντικά ανάλογα με τις απαιτήσεις, τον τύπο κάμερας και τον διαθέσιμο φωτισμό).

Αντιμετώπιση προβλημάτων καμερών IDS

Εάν χάνετε Πλαίσια ή αντιμετωπίζετε προβλήματα συγχρονισμού με την κάμερα IDS uEye GigE, χρησιμοποιήστε το βοηθητικό πρόγραμμα uEye Cockpit.

Κάντε κλικ στο Live Video

Κάντε κλικ στο εικονίδιο αναπαραγωγής και στη συνέχεια κάντε κλικ στο κλειδί

Παρατηρήστε τη χρήση εύρους ζώνης που αναφέρεται. Στην καρτέλα Camera, αυξήστε το Pixel clock και επιλέξτε το πλαίσιο Max κάτω από το Frame rate (Freerun), στη συνέχεια μειώστε τον χρόνο έκθεσης (ταχύτητα κλείστρου).

Αφού ρυθμίσετε τις κάμερές σας για ζωντανή ροή, κάντε κλικ στο Προβολή -> Performance Overview

Η Προβολή Host Performance μπορεί να είναι πολύ χρήσιμη για την αντιμετώπιση προβλημάτων σταθερότητας και απώλειας Πλαισίων.

Χρήση της γραμμής κατάστασης στο uEye Cockpit για την ένδειξη απώλειας Πλαισίων ή προβλημάτων συνδεσιμότητας κατά τη ροή βίντεο:

Ανάλυση κάμερας, Πλαίσια που ελήφθησαν, Πλαίσια που εμφανίστηκαν, Αποτυχημένα Πλαίσια και Προσπάθειες επανασύνδεσης όπως στο στιγμιότυπο:

Το Transfer OK και ο Ρυθμός Πλαισίων μπορούν επίσης να εμφανιστούν στη γραμμή κατάστασης:
