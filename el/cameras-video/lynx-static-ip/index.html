Πώς να ορίσετε στατική IP σε κάμερες Lynx GigE

Εισαγωγή

Αυτό το άρθρο υποστήριξης περιγράφει πώς να ρυθμίσετε τις κάμερες Lynx με στατική διεύθυνση IP. Για κανονική χρήση αυτό δεν απαιτείται, καθώς το Swing Catalyst διαχειρίζεται αυτόματα τη ρύθμιση IP.

Απαιτήσεις

  • Η εφαρμογή MVS (που χρησιμοποιείται για τη ρύθμιση των IP).

  • SwingCatalyst έκδοση 9.8.5 ή νεότερη.

  • Μια κάμερα SwingCatalyst Lynx GigE.

  • Μια ήδη λειτουργούσα εγκατάσταση κάμερας.

Εγκατάσταση της εφαρμογής MVS

  • Κατεβάστε και αποσυμπιέστε την εφαρμογή-πελάτη MVS: https://swingcatalyst.s3.amazonaws.com/drivers/MVS_STD_3.4.1_220407.zip

  • Εγκαταστήστε το MVS ακολουθώντας τις οδηγίες που εμφανίζονται στην οθόνη

  • Αποεπιλέξτε το άνοιγμα των σημειώσεων έκδοσης.

  • Κάντε κλικ στο Τερματισμός.

Ορισμός στατικής IP στον προσαρμογέα Ethernet

Μόλις οι κάμερες αποκτήσουν στατικές διευθύνσεις IP, πρέπει να ρυθμίσετε τους προσαρμογείς δικτύου που σκοπεύετε να χρησιμοποιήσετε με στατική IP. Αυτό πρέπει να ρυθμιστεί έτσι ώστε να αντιστοιχεί σε κάθε συνδεδεμένη κάμερα.

Αυτό σημαίνει ότι εάν αποσυνδέσετε την κάμερα και τη συνδέσετε σε διαφορετικό προσαρμογέα Ethernet, δεν θα «λειτουργεί» εκτός αν επαναρυθμιστεί.

Προειδοποίηση:

Ο αριθμός «Προσαρμογέα Ethernet» που αναφέρεται παρακάτω δεν είναι ο αριθμός που σχετίζεται με τον προσαρμογέα δικτύου, αλλά χρησιμοποιείται για λόγους επεξήγησης. Παρακαλώ ρυθμίστε κάθε προσαρμογέα δικτύου ξεχωριστά για κάθε κάμερα, δηλ. εάν έχετε δύο κάμερες συνδεδεμένες, ρυθμίστε τις διαδοχικά και ανατρέξτε στους πίνακες για τον προσαρμογέα Ethernet 1 και 2· μην αλλάξετε τις ρυθμίσεις σε προσαρμογείς δικτύου που δεν έχουν αναγνωρισμένες κάμερες συνδεδεμένες.

  • Κάντε δεξί κλικ στον προσαρμογέα Ethernet πάνω από τη συνδεδεμένη κάμερα.

  • Κάντε κλικ στο «NIC Settings».

  • Ενεργοποιήστε το Jumbo Frame.

  • Ορίστε τα Receive Buffers στη μέγιστη τιμή.

  • Ορίστε τα Transmit Buffers στη μέγιστη τιμή.

  • Κάντε κλικ στο «Open» για τις «Internet Protocol Properties»

  • Ρυθμίστε τον προσαρμογέα δικτύου σύμφωνα με τον παρακάτω πίνακα.

Συνιστώμενη ρύθμιση στατικής IP για κάθε προσαρμογέα Ethernet

Αυτό είναι ένα παράδειγμα ρύθμισης με στατικές διευθύνσεις IP. Σημειώστε την IP για τον προσαρμογέα Ethernet και τις αντίστοιχες κάμερες.

Αριθμός Προσαρμογέα Ethernet IP Προσαρμογέα Ethernet Μάσκα Υποδικτύου Πύλη Συνδεδεμένη σε Κάμερα IP Κάμερας
1 10.0.1.1 255.255.255.0 10.0.1.1 1 10.0.1.10
2 10.0.2.1 255.255.255.0 10.0.2.1 2 10.0.2.10

Ορισμός στατικής IP στην κάμερα

Βεβαιωθείτε ότι η/οι κάμερα/ες Lynx είναι συνδεδεμένες. Εάν τη συνδέσατε αφού ξεκινήσατε την εφαρμογή, τοποθετήστε τον δείκτη του ποντικιού πάνω από το μενού «GigE» και κάντε κλικ στο κουμπί ανανέωσης.

Αυτή η διαδικασία πρέπει να επαναληφθεί για όλες τις συνδεδεμένες κάμερες Lynx στις οποίες έχετε ορίσει στατική IP.

Σημειώστε ότι θα πρέπει να ορίσετε στατική IP στην κάμερα 1 και στη συνέχεια στην κάρτα δικτύου 1 διαδοχικά. Μόλις τελειώσετε με την 1, προχωρήστε στην 2 κ.ο.κ. Οι αριθμοί που αναφέρονται δεν είναι τα πραγματικά ονόματα των προσαρμογέων δικτύου, π.χ. «Ethernet 2», αλλά χρησιμοποιούνται απλώς για λόγους επεξήγησης.

  • Κάντε δεξί κλικ στην κάμερα στη λίστα και κάντε κλικ στο «Modify IP»

  • Αλλάξτε την επιλογή από DHCP ή LLA σε Static IP.

  • Ρυθμίστε τη διεύθυνση IP και τη μάσκα υποδικτύου σύμφωνα με την παρακάτω περιγραφή.

  • Η IP πρέπει να είναι διαφορετική για κάθε κάμερα.
