Απαιτήσεις Υπολογιστή για το SwingCatalyst

Σημαντική Σημείωση: Το SwingCatalyst δεν είναι συμβατό με Mac OS (Αρχιτεκτονική Arm) ή Windows 11 Arm.

Σύντομη Περίληψη

Για να εξασφαλίσετε ομαλή Σύλληψη Βίντεο και Αναπαραγωγή, ο υπολογιστής σας θα πρέπει να πληροί αυτές τις βασικές απαιτήσεις:

  • Ένα πρόσφατο gaming laptop ή ένας ισχυρός επιτραπέζιος υπολογιστής

  • 32 GB μνήμης (RAM)

  • Μια σύγχρονη κάρτα γραφικών (NVIDIA RTX 3060 6GB ή καλύτερη)

  • Ένας πρόσφατος επεξεργαστής Intel ή AMD με 8 ή περισσότερους πυρήνες

  • Συνιστούμε ΑΝΕΠΙΦΥΛΑΚΤΑ τη χρήση της πιο πρόσφατης σειράς GPU της NVIDIA για τους ταχύτερους χρόνους κωδικοποίησης και επεξεργασίας MoCap. Αυτή τη στιγμή η πιο πρόσφατη σειρά είναι η RTX 5060, 5070, 5080, 5090.

Απαιτήσεις Laptop

Αν χρησιμοποιείτε laptop, συνιστούμε ένα gaming laptop με:

  • Μνήμη: 32 GB RAM

  • Επεξεργαστής: Πρόσφατος Intel i5, i7 ή i9 (9ης γενιάς ή νεότερος) με τουλάχιστον 8 πυρήνες

  • Κάρτα Γραφικών: NVIDIA RTX 3060 (ή νεότερη), με τουλάχιστον 6GB αποκλειστικής μνήμης

Οδηγίες Σύνδεσης Καμερών

  • Χρησιμοποιείτε μόνο τα αυθεντικά, υψηλής ποιότητας καλώδια USB που συνόδευαν τις κάμερές σας, ή άλλα πιστοποιημένα καλώδια machine vision

  • Συνδέετε τις κάμερες απευθείας στον υπολογιστή σας (αποφύγετε hubs USB ή καλώδια επέκτασης)

  • Μέγιστος αριθμός δύο καμερών USB μπορούν να συνδεθούν ταυτόχρονα

  • Για κάμερες Ethernet (GigE), βεβαιωθείτε ότι υπάρχει ελεύθερη υποδοχή PCI Express για αποκλειστική κάρτα δικτύου ή κάρτες δικτύου, ανάλογα με τον αριθμό των καμερών.

Αναλυτικές Συστάσεις Υλικού

Προτεινόμενοι Επεξεργαστές

Επιλογές Intel (από νεότερο σε παλαιότερο)

14η Γενιά (Νεότερη)

  • Intel Core i9-14900/14900K (Βέλτιστη Απόδοση)

  • Intel Core i7-14700KF (Εξαιρετική Απόδοση)

  • Intel Core i5-14400F (Καλή Απόδοση)

13η Γενιά

  • Intel Core i9-13900K/KF

  • Intel Core i7-13700K/KF

  • Intel Core i5-13600K/KF

12η Γενιά

  • Intel Core i9-12900K

  • Intel Core i7-12700K

  • Intel Core i5-12600K

Επιλογές AMD

  • AMD Ryzen 9 9950X3D (16 πυρήνες, Βέλτιστη Απόδοση)

  • AMD Ryzen 7 9800X3D (8 πυρήνες, Εξαιρετική Απόδοση)

  • AMD Ryzen 9 7900X (12 πυρήνες, Βέλτιστη Απόδοση)

  • AMD Ryzen 7 7700X (8 πυρήνες, Καλή Απόδοση)

  • AMD Ryzen 9 5900XT (16 πυρήνες, Προηγούμενη Γενιά, καλή σχέση τιμής-απόδοσης)

Για CPU AMD συνιστούμε ανεπιφύλακτα την αγορά μιας επιπλέον κάρτας ελεγκτή USB 3 για βέλτιστη συμβατότητα.

Τεχνική Σημείωση: Ο επεξεργαστής σας θα πρέπει να είναι ικανός να φτάνει ταχύτητες 3,8GHz ή υψηλότερες για βέλτιστη απόδοση. Το λογισμικό απαιτεί επεξεργαστές που υποστηρίζουν οδηγίες AVX και AVX2 (οι περισσότεροι σύγχρονοι επεξεργαστές υποστηρίζουν αυτό).

Προτεινόμενες Κάρτες Γραφικών

Συνιστούμε ελάχιστο 6GB αποκλειστικής μνήμης GPU (VRAM), όσο περισσότερο τόσο καλύτερο.

Κορυφαία Κατηγορία (Εξαιρετική Απόδοση)

  • RTX 5090 (Καλύτερη Διαθέσιμη)

  • RTX 4090

  • RTX 3090

  • RTX 4080

Υψηλή Κατηγορία (Άριστη Απόδοση)

  • RTX 5080

  • RTX 5070

  • RTX 4070

  • RTX 3080

Μεσαία Κατηγορία (Καλή Απόδοση)

  • RTX 5060

  • RTX 3070

  • RTX 4060

Εισαγωγική Κατηγορία (Ελάχιστη Συνιστώμενη)

  • RTX 3060

Σημείωση: Όλες οι κάρτες που αναφέρονται παραπάνω πληρούν τις ελάχιστες απαιτήσεις για το λογισμικό. Οι κάρτες υψηλότερης κατηγορίας θα παρέχουν καλύτερη απόδοση, ιδιαίτερα κατά την εργασία με πολλές κάμερες και/ή βίντεο υψηλής ανάλυσης.
