Πώς να χρησιμοποιείτε τον Περιηγητή

Εισαγωγή

Ο Περιηγητής παρέχει μια διεπαφή για την περιήγηση, επιλογή και διαχείριση Εγγραφών Βίντεο οργανωμένων ανά Συνεδρίες. Αυτό το έγγραφο καλύπτει πώς να πλοηγείστε αποτελεσματικά και να χρησιμοποιείτε όλες τις λειτουργίες του Περιηγητή στην έκδοση 25.3 και νεότερες.

Επισκόπηση

Γραμμή εργαλείων: Γραμμή εργαλείων με κουμπιά για γρήγορη πρόσβαση σε όλες τις βασικές λειτουργίες του Περιηγητή.

Λίστα χρηστών: Λίστα εγγεγραμμένων χρηστών με λειτουργίες ευκολίας όπως γραμμή αναζήτησης και κουμπί ταξινόμησης.

Λίστα περιεχομένου με δυνατότητα λήψης: Λίστα ληφθεισών εγγραφών, όπως Αιωρήσεις Tour.

Συνεδρίες και Εγγραφές: Λίστα Συνεδριών που μπορούν να αναπτυχθούν ώστε να εμφανίζονται όλες οι εγγραφές για τη συγκεκριμένη Συνεδρία.

Προεπισκόπηση εγγραφής: Παράθυρο προεπισκόπησης που εμφανίζει ένα κινούμενο μικρογράφημα και βασικές πληροφορίες σχετικά με την εγγραφή.

Λίστα εξαγωγής: Σύρετε και αποθέστε εγγραφές εδώ για να τις προσθέσετε στη λίστα εξαγωγής. Οι εγγραφές μπορούν στη συνέχεια να εξαχθούν ως αρχείο Λήψης που επιτρέπει την εισαγωγή της εγγραφής στο SwingCatalyst αργότερα, ή ως αρχεία TSV ακατέργαστων δεδομένων για προσαρμοσμένη ανάλυση.

Πλοήγηση με πληκτρολόγιο

Ο Περιηγητής υποστηρίζει πλήρη πλοήγηση με πληκτρολόγιο μέσω των μικρογραφημάτων εγγραφής:

Πλοήγηση με πλήκτρα βέλους

  • ↑ - Μετακίνηση μία σειρά πάνω

  • ↓ - Μετακίνηση μία σειρά κάτω

  • ← - Μετακίνηση μία στήλη αριστερά

  • → - Μετακίνηση μία στήλη δεξιά

Πλοήγηση σελίδας

  • Home - Μετάβαση στο πρώτο στοιχείο της τρέχουσας Συνεδρίας

  • End - Μετάβαση στο τελευταίο στοιχείο της τρέχουσας Συνεδρίας

  • Page Up - Μετακίνηση πάνω κατά ορατή σελίδα

  • Page Down - Μετακίνηση κάτω κατά ορατή σελίδα

Πλοήγηση μεταξύ Συνεδριών

  • Όταν βρίσκεστε στην κορυφή/κάτω μέρος μιας Συνεδρίας, τα πλήκτρα βέλους πλοηγούνται αυτόματα στις γειτονικές Συνεδρίες

  • Οι Συνεδρίες αναπτύσσονται αυτόματα κατά την πλοήγηση σε αυτές

Συμπεριφορά επιλογής

Ο Περιηγητής υλοποιεί τυπικές δυνατότητες πολλαπλής επιλογής:

Μεμονωμένη επιλογή

  • Κλικ - Επιλογή μιας μεμονωμένης εγγραφής

  • Διπλό κλικ - Άνοιγμα της επιλεγμένης εγγραφής για προβολή

Πολλαπλή επιλογή με ποντίκι

  • Ctrl** + Κλικ** - Εναλλαγή επιλογής μεμονωμένων στοιχείων

  • Shift** + Κλικ** - Επιλογή εύρους από το τελευταίο επιλεγμένο στοιχείο έως το στοιχείο στο οποίο κάνατε κλικ

Πολλαπλή επιλογή με πληκτρολόγιο

  • Shift** + Πλήκτρα βέλους** - Επέκταση επιλογής προς την κατεύθυνση πλοήγησης

  • Ctrl** + Πλήκτρα βέλους** - Πλοήγηση χωρίς αλλαγή επιλογής

  • Ctrl** + **A - Επιλογή όλων των ορατών εγγραφών στον Περιηγητή

  • Ctrl** + Shift + **A - Επιλογή όλων των ορατών εγγραφών στην τρέχουσα Συνεδρία

  • Escape - Εκκαθάριση ορατών επιλογών

Πληροφορίες επιλογής

  • Μετρητής επιλογής: Εμφανίζει τον συνολικό αριθμό επιλεγμένων και τον αριθμό ορατών επιλεγμένων

  • Κρυφές επιλογές: Υποδεικνύει πότε υπάρχουν επιλεγμένα στοιχεία σε συμπτυγμένες ή φιλτραρισμένες Συνεδρίες

  • Οπτική ανάδραση: Τα επιλεγμένα στοιχεία επισημαίνονται με περίγραμμα

Μενού και ενέργειες περιβάλλοντος

Μενού περιβάλλοντος εγγραφής

Κάντε δεξί κλικ σε οποιαδήποτε εγγραφή για πρόσβαση:

  • Άνοιγμα - Άνοιγμα της εγγραφής

  • Προσθήκη στον Σωρό - Προσθήκη στον Σωρό ανάλυσης για γρήγορη πρόσβαση στη Λειτουργία Ανάλυσης

  • Προσθήκη στην Εξαγωγή - Προσθήκη στην ουρά εξαγωγής

  • Διαγραφή - Αφαίρεση της εγγραφής

  • Αποστολή στο Online - Κοινοποίηση μέσω SwingCatalyst Online

Μενού περιβάλλοντος Μαθητή/Ομάδας

Κάντε δεξί κλικ στα ονόματα μαθητών για:

  • Προσθήκη χρήστη στη λίστα εξαγωγής - Συμπερίληψη όλων των εγγραφών του χρήστη στην εξαγωγή

  • Διαγραφή χρήστη - Αφαίρεση του χρήστη και όλων των εγγραφών του

Καθολικές εντολές

Διαθέσιμες μέσω συντομεύσεων πληκτρολογίου:

  • Enter- Άνοιγμα επιλεγμένης/επιλεγμένων εγγραφής/εγγραφών.

  • Delete - Διαγραφή όλων των επιλεγμένων εγγραφών

  • Ctrl** + **A - Επιλογή όλων των ορατών εγγραφών στον Περιηγητή

  • Ctrl** + Shift + **A - Επιλογή όλων των εγγραφών στην τρέχουσα Συνεδρία

  • Escape - Εκκαθάριση τρέχουσας επιλογής

Σύρσιμο και απόθεση

Σύρσιμο Λήψεων

  • Σύρετε Λήψεις σε ζώνες απόθεσης

  • Οπτική ανάδραση εμφανίζει ένα στολίδι σύρσιμου με μικρογράφημα εγγραφής

  • Δείκτες απόθεσης επισημαίνουν έγκυρους στόχους απόθεσης

Ζώνες απόθεσης

  • Ζώνη απόθεσης Θύρας Προβολής A/B - Αποθέστε εδώ για να ανοίξετε εγγραφή/εγγραφές στη Θύρα Προβολής A ή B

  • Ζώνη απόθεσης λίστας εξαγωγής - Αποθέστε εδώ για να προσθέσετε εγγραφή/εγγραφές στην ουρά εξαγωγής

Συμβουλές για αποδοτική χρήση

  • Μαζικές λειτουργίες: Χρησιμοποιήστε πολλαπλή επιλογή για να εκτελέσετε ενέργειες σε πολλές εγγραφές ταυτόχρονα

  • Αποδοτικότητα πληκτρολογίου: Συνδυάστε Ctrl, Shift και πλήκτρα βέλους για γρήγορες ροές εργασίας επιλογής

  • Επίγνωση περιβάλλοντος: Τα μενού δεξιού κλικ παρέχουν ενέργειες κατάλληλες για το περιβάλλον

  • Οπτική ανάδραση: Δώστε προσοχή στους μετρητές επιλογής και τους δείκτες επισήμανσης

Ο Περιηγητής είναι σχεδιασμένος για αποδοτική διαχείριση ροής εργασίας, επιτρέποντάς σας να πλοηγείστε γρήγορα σε μεγάλες συλλογές εγγραφών και να εκτελείτε μαζικές λειτουργίες με ελάχιστη προσπάθεια.
