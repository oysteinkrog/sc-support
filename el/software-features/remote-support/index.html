Πώς να Χρησιμοποιήσετε την Απομακρυσμένη Υποστήριξη

Αυτό το άρθρο περιγράφει πώς να χρησιμοποιήσετε την εφαρμογή Απομακρυσμένης Υποστήριξης του Swing Catalyst, ώστε να επιτρέψετε στην τεχνική υποστήριξη του Swing Catalyst να συνδεθεί προσωρινά στον υπολογιστή σας και να ελέγξει το ποντίκι και το πληκτρολόγιό σας. Θεωρείται δεδομένο ότι κάποιος από το προσωπικό υποστήριξης του Swing Catalyst σας κατεύθυνε εδώ.

Η απομακρυσμένη υποστήριξη είναι χρήσιμη για διάφορους λόγους:

  • Επιλύει προβλήματα που είναι δύσκολο να περιγραφούν μέσω email και τηλεφώνου

  • Επιταχύνει τη διαδικασία — η ανταλλαγή email απαιτεί πολύ χρόνο

  • Παρέχει άμεση βοήθεια όταν η ανάγκη είναι επείγουσα

Παρατηρήσεις

Η Απομακρυσμένη Υποστήριξη του Swing Catalyst είναι διαθέσιμη μόνο σε πελάτες με έγκυρο πρόγραμμα Υποστήριξης & Ενημερώσεων. Η βασική υποστήριξη καλύπτει μόνο επικοινωνία μέσω email.

Δεν θα έχουμε πρόσβαση στον υπολογιστή σας χωρίς την άδειά σας και μπορείτε να παρακολουθείτε ό,τι γίνεται ανά πάσα στιγμή. Αυτή η εφαρμογή προορίζεται αποκλειστικά για την εξυπηρέτηση του πελάτη και θα χρησιμοποιείται με υπευθυνότητα.

Βήμα 1 - Ανοίξτε το SwingCatalyst

Από το κύριο μενού, μεταβείτε στο Βοήθεια και κάντε κλικ στο «Έναρξη Απομακρυσμένης Υποστήριξης».

Θα εμφανιστεί ένα παράθυρο με έναν αριθμό ID. Φροντίστε να τον στείλετε στον εκπρόσωπο υποστήριξής σας όταν σας ζητηθεί.

Εναλλακτικός τρόπος εκκίνησης της απομακρυσμένης υποστήριξης

  • Κάντε κλικ στο μενού Έναρξη των Windows· αν χρησιμοποιείτε Windows 8, πατήστε το πλήκτρο με το λογότυπο των Windows στο πληκτρολόγιό σας.

  • Πληκτρολογήστε «remote support». Θα πρέπει να βρείτε την εφαρμογή Swing Catalyst Remote Support. Κάντε κλικ σε αυτήν για να την εκτελέσετε.

         ![remote_support_win8.png](../../assets/images/zendesk/token_hab7g2hzn1jqpci_remote_support_win8.png)

  1. Η εφαρμογή απομακρυσμένης υποστήριξης θα εμφανίσει ένα παράθυρο διαλόγου παρόμοιο με την παρακάτω εικόνα. Σημειώστε τον αριθμό ID που εμφανίζεται, 9 ψηφία. Διατηρήστε την εφαρμογή σε λειτουργία ώστε το προσωπικό υποστήριξης να μπορεί να συνδεθεί στον υπολογιστή σας.

Βήμα 3 - Ειδοποιήστε το Προσωπικό Υποστήριξης του Swing Catalyst

Εφόσον κάποιος από το προσωπικό υποστήριξης σας κατεύθυνε σε αυτό το άρθρο, ειδοποιήστε τον υπεύθυνο υποστήριξης για το ID που μόλις σημειώσατε στην εφαρμογή απομακρυσμένης υποστήριξης. Συνήθως θα παρέχετε αυτό το ID μέσω του αιτήματος υποστήριξής σας. Δεν χρειάζεται να δώσετε κανέναν κωδικό πρόσβασης, μόνο το ID.

Εάν δεν έχετε ανοιχτό αίτημα υποστήριξης μαζί μας, μπορείτε να δημιουργήσετε ένα νέο επικοινωνώντας με την ομάδα υποστήριξής μας. Εξηγήστε με τι χρειάζεστε βοήθεια και συμπεριλάβετε το ID για να επιταχύνετε τη διαδικασία.

Ένας υπεύθυνος υποστήριξης θα συνδεθεί στον υπολογιστή σας και θα επικοινωνεί μαζί σας μέσω της εφαρμογής απομακρυσμένης υποστήριξης. Όταν η συνεδρία ολοκληρωθεί, μπορείτε ελεύθερα να κλείσετε την εφαρμογή απομακρυσμένης υποστήριξης του Swing Catalyst. Δεν θα μπορούμε να συνδεθούμε όταν αυτή δεν είναι σε λειτουργία.
