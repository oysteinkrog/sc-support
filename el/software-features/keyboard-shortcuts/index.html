Συντομεύσεις πληκτρολογίου και Hotkeys

Το Swing Catalyst & Motion Catalyst υποστηρίζει έναν αριθμό συντομεύσεων πληκτρολογίου.

Αυτό το άρθρο περιγράφει αναλυτικά τις συντομεύσεις πληκτρολογίου.

Μια συντόμευση πληκτρολογίου μπορεί να είναι απλώς ένα πάτημα πλήκτρου, αλλά και συνδυασμός πατημάτων.

Σε αυτό το άρθρο, οι συντομεύσεις που αποτελούνται από περισσότερα από ένα πλήκτρα συνδέονται μεταξύ τους με το σύμβολο + .

Αυτό δεν σημαίνει ότι χρειάζεται να πατήσετε + στο πληκτρολόγιο, αλλά υποδεικνύει ότι πρέπει να πατήσετε και τα δύο (ή περισσότερα) πλήκτρα ταυτόχρονα.

Αναπαραγωγή

Συντόμευση πληκτρολογίου / hotkey Ενέργεια

Space Εναλλαγή αναπαραγωγής / παύσης

Right Μετακίνηση ενός καρέ μπροστά

Left Μετακίνηση ενός καρέ πίσω

Shift Right Μετακίνηση 5% της διάρκειας μπροστά

Shift Left Μετακίνηση 5% της διάρκειας πίσω

Up Αύξηση ταχύτητας αναπαραγωγής

Down Μείωση ταχύτητας αναπαραγωγής

Σελιδοδείκτες

Συντόμευση πληκτρολογίου / hotkey Ενέργεια / περιγραφή

1, 2 ή 3 Μετάβαση στη θέση του/των σελιδοδείκτη/-ών 1 έως 3 της εγγραφής που είναι ανοιχτή στο View Port A

Alt + 1, 2 ή 3 Μετάβαση στη θέση του/των σελιδοδείκτη/-ών 1 έως 3 της εγγραφής που είναι ανοιχτή στο View Port B

Ctrl + 1, 2 ή 3 Ορισμός σελιδοδείκτη 1 έως 3 στο View Port A στην τρέχουσα θέση αναπαραγωγής

Ctrl + Alt 1, 2 ή 3 Ορισμός σελιδοδείκτη 1 έως 3 στο View Port B στην τρέχουσα θέση αναπαραγωγής

Ctrl + Shift 1, 2 ή 3 Συγχρονισμός στον σελιδοδείκτη 1-3

Ctrl + B Κλείδωμα / ξεκλείδωμα σελιδοδεικτών για επεξεργασία

Άλλα

Hotkey Ενέργεια / περιγραφή

Ctrl + O Άνοιγμα / κλείσιμο Περιηγητή

Ctrl + Mouse Scroll Down Σμίκρυνση (βίντεο ή γράφημα δεδομένων, ανάλογα με την εστίαση του ποντικιού)
