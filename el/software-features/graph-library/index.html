Χρήση της βιβλιοθήκης γραφημάτων

Εισαγωγή

Αυτό το άρθρο στοχεύει να παρουσιάσει τις νέες λειτουργίες που περιλαμβάνονται στη νέα βιβλιοθήκη γραφημάτων του Swing Catalyst (εκδόσεις 9.7 και νεότερες)

Οι λειτουργίες περιλαμβάνουν:

  • Μεγέθυνση και μετακίνηση του γραφήματος με τη χρήση του ποντικιού / πληκτρολογίου.

  • Υποστήριξη εμφάνισης μεμονωμένων δεδομένων ανά πλάκα σε ρυθμίσεις Dual Motion Plate / Διπλής Πλάκας Δύναμης.

  • Σημαντικά βελτιωμένη απόδοση απόδοσης.

Αναλυτικά:

  • CTRL + κύλιση ποντικιού για μεγέθυνση / σμίκρυνση στη θέση του δείκτη του ποντικιού στο γράφημα.

  • CTRL SHIFT + κύλιση ποντικιού για μετακίνηση.

  • Διπλό κλικ για επαναφορά του επιπέδου μεγέθυνσης.

  • Κλικ και σύρσιμο για μεγέθυνση.

Ας ρίξουμε μια ματιά στη λειτουργικότητα!

Λειτουργία μεγέθυνσης

Κλικ και σύρσιμο

  • Κάντε κλικ και σύρτε για να επιλέξετε ένα τμήμα που επιθυμείτε να εξετάσετε πιο προσεκτικά.

Tip: Κάντε διπλό κλικ με το ποντίκι για επαναφορά του επιπέδου μεγέθυνσης.

Μεγέθυνση με κύλιση Ctrl

  • Κρατήστε πατημένο το CTRL ενώ κυλάτε το ποντίκι για μεγέθυνση / σμίκρυνση στα δεδομένα.

  • Κρατήστε πατημένο το Shift ενώ κυλάτε το ποντίκι για μεγέθυνση ως προς τον Άξονα X.

Tip: Για επαναφορά, κάντε διπλό κλικ με το ποντίκι.

Προβολή μεμονωμένων δεδομένων πλάκας

  • Note: Αυτή είναι λειτουργικότητα ειδική για Dual Motion Plate / Διπλή Πλάκα Δύναμης

Με τις Διπλές Πλάκες Δύναμης είναι δυνατή η προβολή δεδομένων από κάθε πλάκα ξεχωριστά, κάνοντας κλικ στο κουμπί ένδειξης πλάκας που βρίσκεται αριστερά από το εικονίδιο γραναζιού. Η επισημασμένη πλάκα υποδεικνύει ποια πλάκα εμφανίζεται.

Σε αυτό το παράδειγμα βλέπουμε συνδυασμένα δεδομένα (ανώτατο γράφημα), αλλά και δεδομένα από κάθε πλάκα ξεχωριστά (αριστερό & δεξί Πόδι):

Επιλογές προβολής γραφήματος

Κάνοντας κλικ στο εικονίδιο γραναζιού εμφανίζονται επιλογές για τον τρόπο προβολής των δεδομένων. Για παράδειγμα, για εμφάνιση δεδομένων σε ποσοστό ή Newton (ή Pound foot: lbf⋅ft, εάν έχει επιλεγεί το Αγγλοσαξονικό σύστημα μέτρησης στις Γενικές Ρυθμίσεις).

Βελτιωμένη απόδοση

Η νέα βιβλιοθήκη γραφημάτων μπορεί να αξιοποιεί κάρτες γραφικών για επιτάχυνση υλικού, γεγονός που σημαίνει σημαντικά πιο ανταποκρίσιμη εμπειρία χρήστη χωρίς σημαντικό κόστος (ως προς τη χρήση CPU και μνήμης).
