Cómo configurar una IP estática en cámaras Lynx GigE

Introducción

Este artículo de soporte describe cómo configurar sus cámaras Lynx con una dirección IP estática. Para el uso habitual, esto no es necesario, ya que Swing Catalyst gestiona la configuración de IP de forma automática.

Requisitos

  • La aplicación MVS (utilizada para configurar las IP).

  • Swing Catalyst versión 9.8.5 o posterior.

  • Una cámara Swing Catalyst Lynx GigE.

  • Una Configuración de cámara que ya funcione correctamente.

Instalación de la aplicación MVS

  • Descargue y extraiga la aplicación cliente MVS: https://swingcatalyst.s3.amazonaws.com/drivers/MVS_STD_3.4.1_220407.zip

  • Instale MVS siguiendo las instrucciones en pantalla.

  • Desmarque la opción para abrir las notas de la versión.

  • Haga clic en Terminación.

Configuración de una IP estática en el adaptador Ethernet

Una vez que las cámaras tienen direcciones IP estáticas asignadas, es necesario configurar los adaptadores de red que se utilizarán con una IP estática. Esto debe configurarse de modo que coincida con cada cámara conectada.

Esto significa que si desconecta la cámara y la conecta a un adaptador Ethernet diferente, no “funcionará” a menos que se reconfigure.

Warning:

El número de “Adaptador Ethernet” al que se hace referencia a continuación no es el número asociado al adaptador de red, sino que se usa con fines ilustrativos. Configure cada adaptador de red de forma individual por cámara; es decir, si tiene dos cámaras conectadas, configúrelas de manera secuencial y consulte las tablas para el adaptador Ethernet 1 y 2. No modifique la configuración de ningún adaptador de red que no tenga cámaras identificadas conectadas a él.

  • Haga clic derecho en el Adaptador Ethernet situado encima de la cámara conectada.

  • Haga clic en “NIC Settings”.

  • Active Jumbo Frame.

  • Establezca los Receive Buffers en el valor máximo.

  • Establezca los Transmit Buffers en el valor máximo.

  • Haga clic en “Open” en “Internet Protocol Properties”.

  • Configure el adaptador de red según la tabla a continuación.

Configuración de IP estática recomendada para cada adaptador Ethernet

Este es un ejemplo de una configuración con direcciones IP estáticas. Tenga en cuenta la IP del Adaptador Ethernet y las cámaras respectivas.

Configuración de una IP estática en la cámara

Asegúrese de que sus cámaras Lynx estén conectadas. Si las conectó después de iniciar la aplicación, coloque el cursor sobre el menú “GigE” y haga clic en el botón de actualizar.

Este proceso debe repetirse para todas las cámaras Lynx conectadas a las que haya asignado una IP estática.

Tenga en cuenta que deberá configurar la IP estática en la cámara 1 y luego en la tarjeta de red 1 de forma secuencial. Una vez que haya terminado con la 1, continúe con la 2, y así sucesivamente. Los números a los que se hace referencia no son los nombres reales de los adaptadores de red, por ejemplo, “Ethernet 2”, sino que se usan únicamente con fines ilustrativos.

  • Haga clic derecho en la cámara de la lista y haga clic en “Modify IP”.

  • Cambie la selección de DHCP o LLA a IP estática.

  • Configure la dirección IP y la máscara de subred según la descripción a continuación.

  • La IP debe ser diferente para cada cámara.
