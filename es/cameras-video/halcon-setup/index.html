Cómo configurar Halcon para su uso con Swing Catalyst.

La versión de Swing Catalyst 6.0 incorpora compatibilidad con tres de los estándares de visión artificial más comunes.

  USB3 Vision                      GigE Vision                             GENiCAM

Antes de comenzar

Este artículo cubre principalmente la instalación de Halcon, la instalación de la licencia y una Configuración básica de una cámara Ximea USB3. No podemos garantizar la compatibilidad con versiones más recientes y Swing Catalyst solo es compatible con Halcon 12.

Para obtener más información sobre cómo verificar si su cámara es compatible con Halcon, consulte: Cómo determinar qué estándares admiten sus cámaras para su uso con Halcon.

WARNING

Swing Catalyst solo es compatible con HALCON versión 12.

  • Halcon 12 es compatible con: GenAPI v2.4.1.

¡El Driver del dongle de licencia USB es incompatible con Windows 10 y 11!

Al instalar Halcon, es muy importante desmarcar la opción “Install Driver for USB Dongles” durante la instalación; de lo contrario, su equipo se bloqueará al arrancar.

Para obtener información detallada sobre cómo instalar el nuevo Driver USB, consulte nuestro artículo de soporte:

  • El equipo muestra pantalla azul al conectar el dongle de licencia USB de Halcon

Consulte los artículos específicos para su cámara a fin de configurarla en Swing Catalyst después de instalar Halcon, para obtener configuraciones específicas de cada fabricante.

Requisitos de hardware:

  • Dongle de soporte de cámara universal o licencia vinculada a la tarjeta de red.

  • Cámara(s) compatibles con los estándares USB3 Vision, GigE Vision o GenICam.

  • Puerto USB libre para el dongle de licencia.

Asegúrese de que su hardware sea compatible con las recomendaciones del fabricante.

Nota: La configuración de cámara específica de cada fabricante se encuentra hacia la parte inferior de este artículo.

Más información

  • Información sobre Ximea USB3 Vision: http://www.ximea.com/en/usb3-vision-camera/usb3zone

  • Información sobre Point Grey USB3 Vision: http://www.ptgrey.com/usb3-vision-cameras

  • Información sobre Basler USB3 Vision: http://www.baslerweb.com/en/support/knowledge-base/frequently-asked-questions

  • GenICam (Interfaz genérica para cámaras): http://www.emva.org/standards-technology/genicam/

Requisitos de software

  • Archivo de licencia de Halcon. Debería haberlo recibido por correo electrónico.

  • Asegúrese de tener instalada la versión más reciente de Halcon. Si aparece una advertencia en Swing Catalyst, comuníquese con el soporte técnico para obtener ayuda.

Instalación de Halcon

  • El entorno de ejecución de Halcon se puede encontrar en nuestra página de Descargas, o puede descargarse directamente desde aquí.

  • Una vez descargado, haga clic derecho en el archivo y seleccione “Extraer todo”.

  • Abra la carpeta extraída y ejecute el instalador.

  • Abra el instalador y siga las instrucciones en pantalla junto con las instrucciones paso a paso que se indican a continuación.

  • Seleccione “Install x64 version”.

  • En “Choose Components”, puede desmarcar todos los componentes excepto “Runtime x64”.

  • En la sección “Additional Drivers”, asegúrese de desmarcar “Install driver for USB dongles”; esto es importante.

  • Si dispone de una cámara GigE, asegúrese de marcar “Install MVTec GigE Vision Streaming Filter”.

  • Para instalar el archivo de licencia, seleccione “I have a license file that should be installed” e indique la ruta al archivo de licencia que debería haber recibido de su agente de ventas o soporte.

  • Continúe siguiendo las instrucciones en pantalla.

WARNING: Asegúrese de desmarcar “Install driver for USB dongles” si utiliza Windows 10 u 11

Asegúrese de instalar el Filtro GigE Vision (Nota: esto es obligatorio si dispone de una cámara GigE).

Localice el archivo license.dat que recibió por correo electrónico y haga clic en siguiente.

Complete la instalación. Si se le solicita reiniciar, haga clic en sí.

Configuración básica de cámara de Halcon en Swing Catalyst

Solución de problemas

P: El equipo se bloquea o muestra pantalla azul cada vez que conecto el dongle USB

R: Siga los pasos de este artículo para instalar Drivers más recientes.
