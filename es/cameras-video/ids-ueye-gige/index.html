Cómo configurar cámaras IDS uEye GigE para trabajar con Swing Catalyst

Para la configuración de cámaras USB, consulta este artículo: ids-ueye-usb.md

Nota: Este artículo asume que has instalado los Drivers de uEye disponibles aquí: https://www.swingcatalyst.com/drivers

Este artículo explica cómo configurar las direcciones IP tanto de la cámara como de la tarjeta de red.

Nota: Swing Catalyst no es compatible con IDS AOI (área de interés) para cámaras IDS.

Adaptadores de red compatibles y configuración:

Consulta: gige-network-setup.md

Nota, importante para el Rendimiento: Si tienes una tarjeta de red Intel, descarga e instala los Drivers de Intel, ya que esto te dará opciones para configurar las tasas de moderación de interrupciones, que pueden no estar disponibles con los Drivers de Windows.

Configuración de tus cámaras IDS uEye GigE

Pasos:

Antes de continuar, instala los Drivers de IDS uEye. Localiza y abre la aplicación IDS Camera Manager (se encuentra en: C:\ProgramData\Microsoft\Windows\Start Menu\Programs\IDS).

La aplicación IDS Camera Manager:

Observa el aviso en la parte inferior de la aplicación. Pueden aparecer varios avisos debido a direcciones IP configuradas incorrectamente o relacionados con el firmware de la cámara.

Ejemplo:

Nota sobre la configuración de la dirección IP y nuestras recomendaciones**

**

Nuestra recomendación es disponer de una tarjeta de red dedicada, o interfaz de red, para cada cámara. Sin embargo, con el modelo IDS UI-3220 puedes usar dos cámaras por cada puerto de red mediante el uso de un switch de red (consulta Uso de un switch de red).

Nuestra configuración de IP recomendada:

Cada cámara y tarjeta Ethernet (también conocida como NIC) debe configurarse con IP estáticas en subredes diferentes (y una máscara de subred).

Ejemplo:

Cámaras en la tarjeta de red 1: nic ip: 10.0.1.1 cam ip: 10.0.1.10 … 10.0.1.20 subnet mask:255.255.255.0

Cámaras en la tarjeta de red 2: nic ip: 10.0.2.1 (subred diferente a la nic1) cam ip: 10.0.2.10 … 10.0.2.20 (subred diferente a la nic1) subnet mask: 255.255.255.0

Activar el servicio de red uEye

Nota: Si usas diferentes tipos de cámaras de distintos fabricantes, tener el servicio de red uEye activado puede causar problemas al usar una cámara de otro fabricante.

Haz clic en ETH network service

Selecciona el adaptador de red que deseas configurar (en este caso son los adaptadores de doble puerto)

El gráfico de la tarjeta de red aparece en gris, esto se debe a que no está configurada correctamente. El servicio de red uEye debe estar activado para que la cámara sea visible en la red.

Asegúrate de establecer la dirección IP y la máscara de subred según las recomendaciones (ver arriba), luego haz clic en Enable uEye network service y en Apply changes (¡ahora has asignado una IP estática a uno de los adaptadores de doble puerto!).

Configuración automática de IP (para IP manual, ver más abajo)

Para usar la configuración automática de IP, haz clic en Automatic ETH configuration y luego en OK.

El IDS Camera Manager asignará automáticamente una dirección IP a la tarjeta de red y a la cámara.

Nota: Recomendamos una configuración de IP manual cuando se usan varias cámaras.

Configuración manual de IP

De vuelta en el IDS Camera Manager, ahora deberías ver las cámaras listadas. Dado que anteriormente configuraste una IP estática para el adaptador de red, ahora debes asignar una IP estática a la cámara para que el adaptador de red y la cámara puedan comunicarse correctamente entre sí.

Marca la casilla Expert Mode como se muestra aquí:

Observa el aviso en rojo mostrado arriba.

Haz clic en Manual ETH configuration:

En la captura de pantalla anterior, la dirección IP de la cámara está configurada como 10.0.1.10 (nuestra tarjeta de red es 10.0.1.1). Introduce los valores como se muestra en la captura de pantalla anterior y haz clic en OK.

Nota: Configurar direcciones IP estáticas no es obligatorio, pero sí muy recomendable, ya que las configuraciones de IP automáticas pueden generar problemas por conflictos de direcciones IP, por ejemplo, que la misma dirección IP se use en otro lugar. Recomendamos encarecidamente configurar una instalación estática para todas las instalaciones de estudio.

Repite el proceso para las demás cámaras y NICs según nuestras configuraciones de IP recomendadas anteriores.

Configuración de los adaptadores de red para usarlos con cámaras IDS uEye

Dado que ya has configurado las direcciones IP estáticas tanto para las cámaras como para la tarjeta de red, pasemos a configurar el adaptador de red para obtener el mejor Rendimiento.

Desde Panel de control\Red e Internet\Conexiones de red, haz doble clic en el adaptador que deseas configurar; en nuestro caso es Ethernet 4, Intel (PRO/1000 PT Dual port).

Haz doble clic en el adaptador de red que deseas configurar.

Haz clic en la pestaña Avanzado. Nota: La configuración varía según el adaptador de red y el Driver; consulta la documentación de tu tarjeta de red para obtener información específica sobre cómo modificar los ajustes indicados a continuación.

Asegúrate de que la moderación de interrupciones esté activada y de que la tasa de moderación de interrupciones esté configurada en Extreme.

Si no tienes la opción Extreme, configúrala en High.

En algunas circunstancias, desactivar la moderación de interrupciones puede ayudar si ninguna de las tasas de moderación de interrupciones de valor alto funciona; sin embargo, siempre que tengas una tarjeta de red recomendada, las opciones High y Extreme deberían estar disponibles. Tener la moderación de interrupciones activada es fundamental para reducir el uso de CPU al gestionar grandes cantidades de paquetes, especialmente con cámaras de mayor resolución y/o alta velocidad en FPS.

Tasa de moderación de interrupciones:

Activa el soporte para Jumbo Packets (configúralo en 9014 Bytes):

Búferes de recepción:

Se recomienda establecer este valor lo más alto posible. Esto puede ayudar a evitar la pérdida de Fotogramas al usar varias cámaras y/o cámaras GigE de mayor resolución.

Uso de un switch de red:

Si vas a usar un switch de red, es importante que el switch sea compatible con Jumbo Frames de 9 KB y que el adaptador de red esté configurado para usar Jumbo Frames de 9 KB. Sin embargo, en algunos casos ciertos switches pueden no funcionar bien con tamaños de Fotograma de 9 KB; en esos casos se recomienda reducir el valor de 9 KB a uno inferior y volver a probar la configuración.

Uso de las cámaras en Swing Catalyst

Tras haber configurado las direcciones IP y los adaptadores de red según las recomendaciones anteriores, puedes iniciar Swing Catalyst y la cámara debería aparecer visible en la lista de cámaras.

Establece un Ángulo de cámara y activa la cámara, luego haz clic en Configure.

Asegúrate de que el reloj de píxeles esté al máximo (o redúcelo si estás perdiendo Fotogramas).

Configura la velocidad de obturador y el Gain (ten en cuenta que estos valores pueden variar considerablemente según los requisitos, el tipo de cámara y la cantidad de luz disponible).

Solución de problemas con cámaras IDS

Si estás perdiendo Fotogramas o tienes problemas de sincronización con tu cámara IDS uEye GigE, usa la utilidad uEye Cockpit.

Haz clic en Live Video

Haz clic en el icono de reproducción y luego en la llave inglesa

Observa el uso de ancho de banda indicado. En la pestaña Camera, aumenta el Pixel clock y marca la casilla Max bajo Frame rate (Freerun), luego reduce el tiempo de exposición (velocidad de obturador).

Después de configurar tus cámaras para transmitir en directo, haz clic en Vista -> Performance Overview

La Vista de Rendimiento del host puede ser muy útil para solucionar problemas de estabilidad y pérdida de Fotogramas.
