Cómo usar el Launch Monitor Foresight GC2 y HMT con Swing Catalyst

Introducción

Este artículo de soporte describe cómo usar el Foresight GC2 con Swing Catalyst.

Note: Si deseas usar FSX junto con el GC2, los datos de HMT no están disponibles y debes iniciar FSX primero, luego iniciar Swing Catalyst y seleccionar FSX Sim en la Configuración de Swing Catalyst.

Warning

A partir de la versión 10.1.1 de Swing Catalyst, la integración con el GC2 estará desactivada de forma predeterminada para evitar problemas con el cierre de FSX 2020 al ejecutar Swing Catalyst.

Si tienes un GC2 y deseas seguir usándolo con Swing Catalyst, deberás habilitarlo desde el archivo de configuración (consulta la sección de solución de problemas a continuación).

Requisitos

  • Computadora con un puerto USB libre o WiFi (independiente de la conexión a internet).

  • Una licencia compatible con una cámara de transmisión en vivo, cámara web o cámara de alta velocidad.

  • Swing Catalyst 4.0 o posterior

Importante: Recomendaciones de equipo.

Swing Catalyst se integra tanto con el GC2 como con la unidad adicional, HMT.

Para usar el GC2 junto con el software simulador de Foresight (FR-1, FSX, FSX 2020, etc.), se debe seleccionar Foresight Simulator en la configuración del Launch Monitor de Swing Catalyst.

Note: Si no estás familiarizado con la configuración del Launch Monitor de Swing Catalyst y cómo usar un Launch Monitor como Disparador de captura, consulta nuestro artículo de soporte antes de continuar.

Conexión directa (sin integración con FSX):

Este método de conexión se conecta directamente a la unidad sin necesidad de ejecutar FSX en paralelo. Si tienes una unidad HMT, Swing Catalyst también recogerá los datos del palo.

Pasos de configuración

Página de soporte del GC2 (Drivers, firmware y manuales de Usuario)

  • Sigue la guía de instalación del Foresight GC2 (consulta el enlace anterior) e instala los Drivers USB del GC2. Asegúrate de seleccionar la versión correcta según tu versión de Windows.

  • Asegúrate de que el GC2 tenga instalada la última versión de firmware.

Con el GC2 apagado, conéctalo a tu computadora mediante el cable USB y luego enciende el GC2.

  • Inicia Swing Catalyst y ve a Configuración (desde la pantalla principal, haz clic en el ícono de engranaje en la parte inferior izquierda), luego selecciona Hardware.

  • Habilita la integración con el Launch Monitor. Asegúrate de marcar “Habilitar como Disparador” si deseas que el Launch Monitor actúe como Disparador de captura.

  • Selecciona Foresight GC2

Integración con el simulador

  1. Selecciona ForesightSim en la lista de selección de Launch Monitor; si no aparece automáticamente, presiona “Buscar” para actualizar la lista.

  2. Inicia el simulador de Foresight (las variantes compatibles son: FSX, FSX 2020 y FR-1).

  3. Ve a la configuración del simulador de Foresight, en la sección “Datos en pantalla” habilita “Escribir Shots CSV” (consulta el manual de Usuario del simulador para más detalles o contacta al soporte de Foresight para obtener ayuda con esto).

Swing Catalyst monitorea el archivo Shots.CSV en busca de cambios y lo utiliza activamente para detectar los datos de los golpes desde el simulador.

  1. Asegúrate de estar usando el modo Club Fitting (el único modo que proporcionará todos los datos de la bola).

Solución de problemas

Esta sección contiene pasos para solucionar problemas con el Foresight GC2 y HMT, así como el uso del GC2 con FSX.

¡Acabo de actualizar el software y la integración ya no funciona!

En la versión 10.1.1 de Swing Catalyst, la integración con el GC2 está desactivada de forma predeterminada para evitar que FSX2020 se cierre solo al ejecutar Swing Catalyst. Esta es una solución temporal hasta que Foresight pueda resolver el problema con FSX.

Para volver a activar la integración con el GC2, cierra Swing Catalyst y navega hasta la carpeta de configuración:

  • C:\ProgramData\Swing Catalyst\settings

  • Haz clic derecho en “GeneralSettings.xml” y selecciona abrir con el Bloc de notas (o haz clic en Editar).

  • Cambia false por true y guarda el documento.

  • Una vez guardado, inicia Swing Catalyst nuevamente; el GC2 debería aparecer en la lista de Launch Monitor.

Conexión USB de Foresight

  • Asegúrate de que USB de Foresight esté seleccionado en la Configuración de Swing Catalyst.

  • Verifica la conexión con la unidad Foresight GC2 y asegúrate de que el software simulador de Foresight no esté en ejecución.

  • Si faltan datos o los golpes no se detectan correctamente, podría indicar que el módulo flash necesita reemplazo. O bien, es posible que al palo le falten Marcadores o que estos ya no funcionen correctamente.

  • Si todavía no puedes obtener Datos del Monitor de Lanzamiento del Foresight GC2 en Swing Catalyst, envía un ticket a través de nuestro centro de ayuda.

Conexión con el simulador de Foresight

  1. Asegúrate de estar recibiendo datos en el simulador de Foresight.

  2. Intenta cerrar Swing Catalyst, iniciar primero el simulador de Foresight y luego iniciar Swing Catalyst.

  3. Asegúrate de estar usando el modo Club Fitting en el simulador de Foresight y de que Shots.CSV esté habilitado en la Configuración.

  4. Asegúrate de tener habilitada la opción “Usar como Disparador” en la configuración de Swing Catalyst.
