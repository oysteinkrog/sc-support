Cómo usar Foresight GC3 / Bushnell Launch Pro con Swing Catalyst

Introducción

Este artículo de soporte describe cómo configurar el Foresight GC3 o Bushnell Launch Pro con Swing Catalyst.

El Foresight GC3 dispone de WiFi y WiFi Direct, además de USB y Ethernet, como diferentes formas de conectarse al dispositivo Launch Monitor.

Ten en cuenta que WiFi en este contexto no implica conectarse directamente al GC3; eso se denomina WiFi Direct. WiFi es la red que utiliza el GC3 / BLP para conectarse a una red inalámbrica existente.

Requisitos

  • Ordenador con un puerto USB libre, puerto Ethernet o WiFi (además de conectividad a internet).

  • Swing Catalyst 10.0 o posterior

Note: Si vas a utilizar cámaras HD con Swing Catalyst, recomendamos ejecutar FSX por separado (es decir, no al mismo tiempo que Swing Catalyst) o en un ordenador diferente.

Asegúrate de tener al menos una NVidia GeForce 1080 o superior y de que el PC cumple adecuadamente las recomendaciones de Foresight.

Conexión y Configuración

  1. Conecta el GC3 mediante USB, WiFi* o Ethernet.

  2. En Configuración -> Hardware -> Launch Monitor debería aparecer una selección de Launch Monitor(s) con diferentes interfaces.

  3. Asegúrate de seleccionar el Launch Monitor que deseas usar con la interfaz con la que quieres conectarte:

*** Si te conectas por Wi-Fi, es importante que dispongas de otro medio de conectividad a internet, ya que debe validarse a través de internet para poder usar el GC3.**

Solución de problemas

El Foresight GC3 no aparece como conectado o no está disparando

Existe un error conocido en el SDK de Foresight que afecta a las versiones 10.0 a 10.1.0 de Swing Catalyst.

Este error hace que Swing Catalyst no reciba datos del GC3/BLP.

Solución alternativa:

  • Cierra Swing Catalyst y conecta el GC3 / Launch Pro al ordenador mediante USB.

  • Asegúrate de que el Foresight GC3 aparece en tu ordenador. Se mostrará como un dispositivo de almacenamiento masivo en Este PC.

  • Descarga y extrae la solución alternativa desde: https://cloudfront.swingcatalyst.com/files/GC3-BLP-Workaround.zip

  • Abre la carpeta extraída y haz doble clic en “Workaround.exe”. Esto abrirá una ventana del símbolo del sistema donde intentará conectarse y desconectarse de tu Launch Monitor.

Otras sugerencias para la solución de problemas:

  • Conecta el dispositivo a un puerto USB diferente del ordenador si no aparece.

  • Si estás conectado a través de WiFi Direct, asegúrate de tener acceso a internet por otros medios o de disponer de un adaptador WiFi adicional.

  • Intenta conectarte a través de una interfaz diferente; por ejemplo, si has intentado usar WiFi, prueba con Ethernet o USB.

  • Asegúrate de que ningún otro software intenta conectarse al dispositivo al mismo tiempo.

El Foresight GC3 está conectado y disparando, pero las Grabaciones no contienen datos

  • Intenta reiniciar el dispositivo GC3 / BLP apagándolo y volviéndolo a encender.

  • Asegúrate de estar usando un palo con las pegatinas colocadas correctamente.

  • Asegúrate de que no haya otros Launch Monitors basados en cámara cerca que puedan interferir con la capacidad del GC3 / BLP para rastrear la pelota.

Para más información sobre solución de problemas, consulta los artículos de Foresight a continuación.
