Requisitos de Computadora para SwingCatalyst

Nota importante: SwingCatalyst no es compatible con Mac OS (arquitectura Arm) ni con Windows 11 Arm.

Resumen Rápido

Para garantizar una Captura de Video y Reproducción fluidas, tu computadora debe cumplir estos requisitos básicos:

  • Una laptop para gaming reciente o una computadora de escritorio potente

  • 32 GB de memoria (RAM)

  • Una tarjeta gráfica moderna (NVIDIA RTX 3060 de 6 GB o superior)

  • Un procesador Intel o AMD reciente con 8 núcleos o más

  • Recomendamos ENCARECIDAMENTE usar la última serie de GPU NVIDIA para obtener los tiempos de codificación más rápidos y el mejor procesamiento MoCap. Actualmente, la última serie es la RTX 5060, 5070, 5080, 5090.

Requisitos para Laptops

Si usas una laptop, recomendamos una laptop para gaming con:

  • Memoria: 32 GB de RAM

  • Procesador: Intel i5, i7 o i9 reciente (9.ª generación o más nueva) con al menos 8 núcleos

  • Tarjeta gráfica: NVIDIA RTX 3060 (o más nueva), con al menos 6 GB de memoria dedicada

Pautas de Conexión de Cámaras

  • Usa únicamente los cables USB originales de alta calidad que vinieron con tus cámaras, o utiliza otros cables certificados para visión artificial

  • Conecta las cámaras directamente a tu computadora (evita hubs USB o cables de Extensión)

  • Se pueden conectar un máximo de dos cámaras USB a la vez

  • Para cámaras Ethernet (GigE), asegúrate de que haya una ranura PCI Express libre para una tarjeta de red dedicada o varias tarjetas de red, según la cantidad de cámaras.

Recomendaciones Detalladas de Hardware

Procesadores Recomendados

Opciones Intel (de más nuevo a más antiguo)

14.ª Generación (Más Reciente)

  • Intel Core i9-14900/14900K (Mejor Rendimiento)

  • Intel Core i7-14700KF (Excelente Rendimiento)

  • Intel Core i5-14400F (Buen Rendimiento)

13.ª Generación

  • Intel Core i9-13900K/KF

  • Intel Core i7-13700K/KF

  • Intel Core i5-13600K/KF

12.ª Generación

  • Intel Core i9-12900K

  • Intel Core i7-12700K

  • Intel Core i5-12600K

Opciones AMD

  • AMD Ryzen 9 9950X3D (16 núcleos, Mejor Rendimiento)

  • AMD Ryzen 7 9800X3D (8 núcleos, Excelente Rendimiento)

  • AMD Ryzen 9 7900X (12 núcleos, Mejor Rendimiento)

  • AMD Ryzen 7 7700X (8 núcleos, Buen Rendimiento)

  • AMD Ryzen 9 5900XT (16 núcleos, Generación Anterior, buena relación calidad-precio)

Para CPU AMD, recomendamos encarecidamente adquirir una tarjeta controladora USB 3 adicional para una compatibilidad óptima.

Nota Técnica: Tu procesador debe ser capaz de alcanzar velocidades de 3,8 GHz o superiores para un Rendimiento óptimo. El software requiere procesadores compatibles con instrucciones AVX y AVX2 (la mayoría de los procesadores modernos las admiten).

Tarjetas Gráficas Recomendadas

Recomendamos un mínimo de 6 GB de memoria GPU dedicada (VRAM); cuanta más, mejor.

Nivel Superior (Rendimiento Excepcional)

  • RTX 5090 (La Mejor Disponible)

  • RTX 4090

  • RTX 3090

  • RTX 4080

Nivel Alto (Rendimiento Excelente)

  • RTX 5080

  • RTX 5070

  • RTX 4070

  • RTX 3080

Nivel Medio (Buen Rendimiento)

  • RTX 5060

  • RTX 3070

  • RTX 4060

Nivel Básico (Mínimo Recomendado)

  • RTX 3060

Nota: Todas las tarjetas listadas anteriormente cumplen los requisitos mínimos del software. Las tarjetas de nivel superior ofrecerán un mejor Rendimiento, especialmente al trabajar con múltiples cámaras y/o video de alta resolución.
