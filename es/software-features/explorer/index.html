Cómo usar el Explorador

Introducción

El Explorador proporciona una interfaz para navegar, seleccionar y gestionar Grabaciones de Video organizadas por Sesiones. Este documento explica cómo navegar y utilizar de manera efectiva todas las funciones del Explorador en las versiones 25.3 y posteriores.

Descripción General

Barra de herramientas: Barra de herramientas con botones para acceder rápidamente a todas las funciones principales del Explorador.

Lista de Usuarios: Lista de Usuarios registrados con funciones de comodidad como una barra de búsqueda y un botón de ordenación.

Lista de contenido descargable: Lista de Grabaciones descargadas, como Swings de Tour.

Sesiones y Grabaciones: Lista de Sesiones que se pueden expandir para mostrar todas las Grabaciones de cada Sesión.

Vista previa de Grabación: Ventana de vista previa que muestra una miniatura animada e información clave sobre la Grabación.

Lista de exportación: Arrastra y suelta Grabaciones aquí para añadirlas a la lista de exportación. Las Grabaciones pueden exportarse como un archivo de Toma que permite importarlas en SwingCatalyst posteriormente, o como archivos TSV de datos sin procesar para análisis personalizados.

Navegación con Teclado

El Explorador admite navegación completa con teclado a través de las miniaturas de Grabación:

Navegación con Teclas de Flecha

  • ↑ - Subir una fila

  • ↓ - Bajar una fila

  • ← - Moverse una columna a la izquierda

  • → - Moverse una columna a la derecha

Navegación por Páginas

  • Home - Saltar al primer elemento de la Sesión actual

  • End - Saltar al último elemento de la Sesión actual

  • Page Up - Subir una página visible

  • Page Down - Bajar una página visible

Navegación entre Sesiones

  • Al estar en la parte superior/inferior de una Sesión, las teclas de flecha navegan automáticamente a las Sesiones adyacentes

  • Las Sesiones se expanden automáticamente al navegar hacia ellas

Comportamiento de Selección

El Explorador implementa capacidades estándar de selección múltiple:

Selección Individual

  • Clic - Seleccionar una Grabación individual

  • Doble clic - Abrir la Grabación seleccionada para verla

Selección Múltiple con Ratón

  • Ctrl** + Clic** - Alternar la selección de elementos individuales

  • Shift** + Clic** - Seleccionar el Rango desde el último elemento seleccionado hasta el elemento en el que se hace clic

Selección Múltiple con Teclado

  • Shift** + Teclas de Flecha** - Ampliar la selección en la dirección de navegación

  • Ctrl** + Teclas de Flecha** - Navegar sin cambiar la selección

  • Ctrl** + **A - Seleccionar todas las Grabaciones visibles en el Explorador

  • Ctrl** + Shift + **A - Seleccionar todas las Grabaciones visibles en la Sesión actual

  • Escape - Borrar las selecciones visibles

Información de Selección

  • Contador de Selección: Muestra el total de elementos seleccionados y la cantidad de elementos seleccionados visibles

  • Selecciones Ocultas: Indica cuándo hay elementos seleccionados en Sesiones contraídas o filtradas

  • Retroalimentación Visual: Los elementos seleccionados se resaltan con un borde

Menús y Acciones Contextuales

Menú Contextual de Grabación

Haz clic derecho en cualquier Grabación para acceder a:

  • Abrir - Abrir la Grabación

  • Añadir a la Pila - Añadir a la Pila de análisis para acceso rápido en el Modo de Análisis

  • Añadir a Exportación - Añadir a la cola de exportación

  • Eliminar - Eliminar la Grabación

  • Subir a Online - Compartir a través de SwingCatalyst Online

Menú Contextual de Estudiante/Grupo

Haz clic derecho en los nombres de Estudiantes para:

  • Añadir Usuario a la Lista de Exportación - Incluir todas las Grabaciones del Usuario en la exportación

  • Eliminar Usuario - Eliminar al Usuario y todas sus Grabaciones

Comandos Globales

Disponibles mediante atajos de teclado:

  • Enter- Abrir las Grabaciones seleccionadas.

  • Delete - Eliminar todas las Grabaciones seleccionadas

  • Ctrl** + **A - Seleccionar todas las Grabaciones visibles en el Explorador

  • Ctrl** + Shift + **A - Seleccionar todas las Grabaciones de la Sesión actual

  • Escape - Borrar la selección actual

Arrastrar y Soltar

Arrastrar Tomas

  • Arrastra Tomas a las zonas de destino

  • Retroalimentación visual muestra un indicador de arrastre con la miniatura de la Grabación

  • Indicadores de destino resaltan los destinos válidos para soltar

Zonas de Destino

  • Zona de destino de Ventana de Visualización A/B - Suelta aquí para abrir las Grabaciones en la Ventana de Visualización A o B

  • Zona de destino de la lista de exportación - Suelta aquí para añadir las Grabaciones a la cola de exportación

Consejos para un Uso Eficiente

  • Operaciones Masivas: Usa la selección múltiple para realizar acciones en varias Grabaciones simultáneamente

  • Eficiencia con el Teclado: Combina Ctrl, Shift y las teclas de flecha para flujos de trabajo de selección rápidos

  • Conciencia del Contexto: Los menús del clic derecho ofrecen acciones apropiadas según el contexto

  • Retroalimentación Visual: Presta atención a los contadores de selección y los indicadores de resaltado

El Explorador está diseñado para una gestión eficiente del flujo de trabajo, permitiéndote navegar rápidamente por grandes colecciones de Grabaciones y realizar operaciones masivas con el mínimo esfuerzo.
