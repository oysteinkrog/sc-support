Cómo usar el soporte remoto

Este artículo describe cómo usar la aplicación de soporte remoto de Swing Catalyst para permitir que el equipo de soporte técnico de Swing Catalyst inicie sesión temporalmente en tu computadora y controle el ratón y el teclado. Se asume que alguien del equipo de soporte de Swing Catalyst te indicó que vinieras aquí.

El soporte remoto es útil para varias cosas:

  • Resolver problemas que de otro modo serían difíciles de describir por correo electrónico o teléfono

  • Acelerar el proceso: el intercambio de correos electrónicos lleva mucho tiempo

  • Obtener asistencia inmediata cuando la necesidad es urgente

Observaciones

El soporte remoto de Swing Catalyst solo está disponible para clientes con un plan de Soporte y Actualizaciones vigente. El soporte básico cubre únicamente la comunicación por correo electrónico.

No tendremos acceso a tu computadora sin tu permiso y podrás ver en todo momento lo que se está haciendo. Esta aplicación tiene como único propósito ayudar al cliente y será utilizada de forma responsable.

Paso 1 - Abrir SwingCatalyst

Desde el menú principal, ve a Ayuda y haz clic en “Start Remote Support”.

Se abrirá una ventana con un número de ID. Asegúrate de enviárselo a tu representante de soporte cuando se te indique.

Forma alternativa de iniciar el soporte remoto

  • Haz clic en el menú de inicio de Windows; si tienes Windows 8, presiona la tecla con el logo de Windows en tu teclado.

  • Escribe “remote support”. Deberías encontrar la aplicación Swing Catalyst Remote Support. Haz clic en ella para ejecutarla.

         ![remote_support_win8.png](../../assets/images/zendesk/token_hab7g2hzn1jqpci_remote_support_win8.png)

  1. La aplicación de soporte remoto mostrará una ventana de diálogo similar a la imagen a continuación. Toma nota del número de ID que aparece, de 9 dígitos. Mantén la aplicación en ejecución para permitir que el personal de soporte se conecte a tu computadora.

Paso 3 - Notificar al equipo de soporte de Swing Catalyst

Suponiendo que alguien del equipo de soporte te indicó que siguieras este artículo, notifica al agente de soporte el ID que acabas de anotar en la aplicación de soporte remoto. Normalmente proporcionarás este ID a través de tu ticket de soporte. No es necesario que compartas ninguna contraseña, solo el ID.

Si no tienes un ticket de soporte abierto con nosotros, puedes crear uno nuevo contactando a nuestro equipo de soporte. Explica con qué necesitas ayuda e incluye el ID para agilizar el proceso.

Un agente de soporte se conectará a tu computadora y se comunicará contigo a través de la aplicación de soporte remoto. Cuando la sesión haya terminado, puedes cerrar la aplicación de soporte remoto de Swing Catalyst cuando quieras. No podremos conectarnos cuando no esté en ejecución.
