Hur man spelar in en lektion

Introduktion

Lektionsvideor är ett användbart verktyg för instruktören, antingen för övningar eller som en sammanfattning av träningssessionen. Lektionsvideon spelar i princip in hela SwingCatalyst-applikationen så som den visas på skärmen, och låter dig öppna och jämföra valfria Swings, rita och skriva text med ritverktygen samt spela upp Swings efter eget tycke. När du är nöjd avslutar du videon och kan dela den som en videofil via USB-minne, skicka med e-post eller dela via YouTube.

Gäller för

  • Instruktörer som vill skapa övningar eller sammanfattningar i form av ett videoklipp med valfri ljudkommentar.

Relaterat till

  • Hur man justerar mikrofonvolymen

Lösning

  • I Swing Analysis-läge klickar du på Spela in-knappen i toppmenyn.

  • Timern börjar räkna sekunder för att indikera att hela SwingCatalyst-applikationen spelas in. Även muspekaren.

  • Vad du vill göra under inspelningen är helt upp till dig, men här är några förslag:

  • Öppna de Swings du vill spela upp eller jämföra med varandra.

  • Spela upp från start till slut i slow motion för att ge en överblick.

  • Flytta tidslinjen för att visa särskilda intressanta punkter i golfsvingen.

  • Använd ritverktygen för att lägga till linjer eller text som anteckningar vid olika punkter i Swingen.

  • Använd lektionsmikrofonen för att lägga till röstkommentarer under Inspelningen.

  • Flytta muspekaren runt ett ställe för att framhäva något på skärmen. Det kommer att markeras i videon och vara lätt att se.

  • Använd pausknappen för att undvika att använda videotid när du ställer in linjer, text eller när du öppnar nya Swings som tar tid. Om du till exempel vill gå igenom ett antal punkter i Swingen och ha olika linjer eller text för var och en, kan du använda Pausa när du förflyttar dig mellan och ställer in varje position.

  • När du är nöjd klickar du på Stoppa-knappen för att visa förhandsgranskningsdialogrutan.

  • Spela upp förhandsgranskningen för att säkerställa att allt ser bra ut och att mikrofonljudet inkluderades.

  • Välj att antingen spara som videofil på disk, dela via e-post eller dela till YouTube.

  • Tidigare inspelade lektioner finns i din Swing-utforskare under lektionsfliken.

Felsökning

Problem: Mikrofonen fungerar inte i SwingCatalyst.

Windows 10 April 2018 Update orsakar mikrofonproblem

För vissa användare blockerar Windows 10 nu SwingCatalyst från att använda mikrofonen, baserat på sekretessinställningar.

Efter uppgradering till version 1803 har ett litet antal användare rapporterat att mikrofonen identifieras, men att den inte fångar upp något ljud. För att komma runt det här problemet rekommenderar Microsoft att du aktiverar mikrofonen i dina sekretessinställningar genom att följa dessa steg:

Öppna Inställningar Klicka på Sekretess Klicka på Mikrofon

Slå på reglaget Tillåt appar att komma åt din mikrofon.

Se den här Microsoft-webbplatsen för mer information.

I vissa fall kan antivirusprogram orsaka problem med lektionsinspelning.

Vissa antivirusprogram som Kaspersky gör att SwingCatalyst fryser under inspelning av lektioner.

Avinstallera Kaspersky och använd ett annat antivirusprogram, till exempel Windows Defender eller Carbon Black.
