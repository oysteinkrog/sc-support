Hur man använder Utforskaren

Introduktion

Utforskaren tillhandahåller ett gränssnitt för att bläddra, välja och hantera videoinspelningar organiserade efter sessioner. Det här dokumentet beskriver hur du effektivt navigerar och använder alla funktioner i Utforskaren i version 25.3 och senare.

Översikt

Verktygsfält: Verktygsfält med knappar för snabb åtkomst till all kärnfunktionalitet i utforskaren.

Användarlista: Lista över registrerade användare med praktiska funktioner som ett sökfält och en sorteringsknapp.

Lista över nedladdningsbart innehåll: Lista över nedladdade inspelningar, till exempel Tour Swings.

Sessioner och Inspelningar: Lista över sessioner som kan expanderas för att visa alla inspelningar för den sessionen.

Förhandsgranska inspelning: Förhandsgranskningsfönster som visar en animerad miniatyrbild och viktig information om inspelningen.

Exportlista: Dra och släpp inspelningar här för att lägga till dem i exportlistan. Inspelningar kan sedan exporteras som en Take-fil som gör det möjligt att importera inspelningen till Swing Catalyst senare, eller som rådata-TSV-filer för anpassad analys.

Tangentbordsnavigering

Utforskaren stöder fullständig tangentbordsnavigering genom inspelningsthumbnails:

Navigering med piltangenter

  • ↑ - Flytta upp en rad

  • ↓ - Flytta ned en rad

  • ← - Flytta ett steg åt vänster

  • → - Flytta ett steg åt höger

Sidnavigering

  • Home - Hoppa till första objektet i aktuell Session

  • End - Hoppa till sista objektet i aktuell Session

  • Page Up - Flytta upp en synlig sida

  • Page Down - Flytta ned en synlig sida

Navigering mellan sessioner

  • När du befinner dig längst upp/ned i en Session navigerar piltangenterna automatiskt till angränsande sessioner

  • Sessioner expanderas automatiskt när du navigerar in i dem

Urvalsbeteende

Utforskaren implementerar standardfunktioner för flera markeringar:

Enstaka markering

  • Klick - Markera en enstaka inspelning

  • Dubbelklick - Öppna den markerade inspelningen för visning

Flera markeringar med musen

  • Ctrl** + Klick** - Växla markering av enskilda objekt

  • Shift** + Klick** - Markera ett intervall från det senast markerade objektet till det klickade objektet

Flera markeringar med tangentbordet

  • Shift** + Piltangenter** - Utöka markeringen i navigeringsriktningen

  • Ctrl** + Piltangenter** - Navigera utan att ändra markeringen

  • Ctrl** + **A - Markera alla synliga inspelningar i utforskaren

  • Ctrl** + Shift + **A - Markera alla synliga inspelningar i aktuell Session

  • Escape - Rensa synliga markeringar

Markningsinformation

  • Markeringsräknare: Visar totalt antal markerade och antalet synliga markerade objekt

  • Dolda markeringar: Indikerar när objekt är markerade i kollapsade eller filtrerade sessioner

  • Visuell återkoppling: Markerade objekt framhävs med en kantlinje

Menyer och kontextåtgärder

Kontextmeny för inspelning

Högerklicka på valfri inspelning för att komma åt:

  • Öppna - Öppna inspelningen

  • Lägg till i Stack - Lägg till i analysstacken för snabb åtkomst i analysläge

  • Lägg till i export - Lägg till i exportkön

  • Ta bort - Radera inspelningen

  • Ladda upp till Online - Dela via SwingCatalyst Online

Kontextmeny för Student/Grupp

Högerklicka på studentnamn för att:

  • Lägg till användare i exportlista - Inkludera alla användarens inspelningar i exporten

  • Ta bort användare - Ta bort användaren och alla deras inspelningar

Globala kommandon

Tillgängliga via tangentbordsgenvägar:

  • Enter- Öppna markerade inspelning(ar).

  • Delete - Ta bort alla markerade inspelningar

  • Ctrl** + **A - Markera alla synliga inspelningar i utforskaren

  • Ctrl** + Shift + **A - Markera alla inspelningar i aktuell Session

  • Escape - Rensa aktuell markering

Dra och släpp

Dra Takes

  • Dra Takes till släppzoner

  • Visuell återkoppling visar en dragindikator med inspelningens miniatyrbild

  • Släppindikatorer framhäver giltiga släppmål

Släppzoner

  • Visningsruta A/B-släppzon - Släpp här för att öppna inspelning(ar) i antingen Visningsruta A eller B

  • Exportlistans släppzon - Släpp här för att lägga till inspelning(ar) i exportkön

Tips för effektiv användning

  • Massåtgärder: Använd flera markeringar för att utföra åtgärder på flera inspelningar samtidigt

  • Tangentbordseffektivitet: Kombinera Ctrl, Shift och piltangenter för snabba markeringsarbetsflöden

  • Kontextmedvetenhet: Högerklicksmenyer tillhandahåller kontextanpassade åtgärder

  • Visuell återkoppling: Uppmärksamma markeringsräknare och markeringsindikatorer

Utforskaren är utformad för effektiv arbetsflödeshantering och gör det möjligt för dig att snabbt navigera i stora samlingar av inspelningar och utföra massåtgärder med minimal ansträngning.
