Hur man konfigurerar Basler GigE-kameror med Swing Catalyst

Den här supportartikeln beskriver Setup och konfiguration av Basler-kameror med Swing Catalyst.

note: För att kunna använda Basler-kameror med Swing Catalyst behöver du en Halcon USB-dongel och en licens. Kontakta contact@swingcatalyst.com för att köpa en licens.

Instruktioner för installation och konfiguration av Halcon finns här:

halcon-setup.md

Viktigt:

Se till att du har MVTec Halcon-drivrutionsfiltret installerat – kamerorna fungerar inte korrekt utan det. Se också till att avmarkera eventuella andra Filter-drivrutiner som är installerade, t.ex. Baslers Filter-drivrutin.

Se till att Swing Catalyst är tillåtet på både privata och offentliga nätverk i Windows Defender-brandväggen.

Exempel:

Ange kamerornas IP-adress

IP Setup

Varje kamera och Ethernet-kort (NIC / nätverksgränssnittskontroller) bör konfigureras med statiska IP-adresser på olika subnät (och nätmask)

note: NIC-IP är IP-adressen för nätverksadaptern på din dator och kamerans IP är kamerans IP-adress. … anger ett Omfattning, eftersom detta är ett exempel på en IP-adress du kan ange.

Exempel för en eller flera kameror (med ett eller flera nätverkskort / adaptrar):

Kameror på nätverksadapter 1: nic ip: 10.0.1.1 cam ip: 10.0.1.10 … 10.0.1.20 subnet mask:255.255.255.0

Kameror på nätverksadapter 2: nic ip: 10.0.2.1 cam ip: 10.0.2.10 … 10.0.2.20 subnet mask: 255.255.255.0

Kameror på nätverksadapter 3: nic ip: 10.0.3.1 cam ip: 10.0.3.10 … 10.0.3.20 subnet mask: 255.255.255.0

Kameror på nätverksadapter 4: nic ip: 10.0.4.1 cam ip: 10.0.4.10 … 10.0.4.20 subnet mask: 255.255.255.0

Först behöver vi ange kamerans IP-adress, vilket görs via Pylon IP Configurator.

Tryck på Start-knappen på tangentbordet och skriv pylon ip – IP Configurator bör då visas. Om den inte visas är det troligt att programvaran inte är installerad.

För att installera Pylon-programvaran, se: https://www.baslerweb.com/en/sales-support/downloads/software-downloads/ och leta efter: pylon 5.1.0 Camera Software Suite Windows.

Klicka på kameran och välj sedan Static IP

Ange kamerans IP-adress och nätmask enligt exemplet ovan.

Konfigurera Basler GigE-kameror via Halcon

I Swing Catalyst, navigera till fliken Inställningar och sedan till Kameror.

Klicka på Avancerat.

  • Navigera till fliken Konfiguration.

  • Aktivera kryssrutan GtlNumBuffers och ange 200 som värde.

Konfigurera Basler GigE-kameror:

Låt oss titta på hur man ställer in exponering, slutartid och bildhastighet.

note: Om du inte kan se inställningarna och får ett felmeddelande i Swing Catalyst, kontrollera brandväggsinställningarna i Windows. Försök att stänga av brandväggen för att kontrollera om det är brandväggen som blockerar Swing Catalysts åtkomst till kamerorna.

Om inställningarna fungerar och du kan strömma utan problem, se till att Swing Catalyst är tillåtet på både offentliga och privata nätverk i Windows Defender-brandväggen.

Expandera fliken AcquisitionTrigger och ange den maximala (eller lägre) bildhastigheten, klicka sedan på Enable Acquisition Frame Rate. Detta gör att du kan definiera bildhastigheten. Observera: Bildhastigheten kan begränsas av exponeringsvärden.

Ange exponeringsvärden

Det är vanligtvis bäst att använda manuell exponering i statiska miljöer, som inomhusstudior. En helt automatisk exponering kan orsaka att bildhastigheten förändras och leda till en inkonsekvent bild. I det här fallet använder vi inte auto-exponering eftersom vi vill kunna styra detta själva. Generellt rekommenderas en exponeringstid kortare än 2000 (2 ms).

Ange Gain-värden

Liksom för exponering är det bäst att ställa in Gain till manuellt vid statiska/inomhusljusförhållanden. Ju högre exponering, desto kornigare blir bilden och desto längre tid tar videokodningen jämfört med låg Gain.

För att ställa in manuell Gain, ändra Gain Auto från Continuous till Off, pausa sedan och spela upp uppspelningen igen för att ladda om inställningarna. Ange Gain-värden genom att ändra siffervärdena i Gain (Raw).

Ändra bildstorlek, intresseområde, Region of Interest med mera

I vissa fall vill du minska bildstorleken för att fokusera på ett specifikt område av videobilden, till exempel för att se klubban och bollen vid Slag i detalj.

Detta kan göras med intresseområde, även känt som AOI, och ROI, Region of Interest. Att minska den totala bildstorleken med den här funktionen kan också ge dig en ökad bildhastighet.

Spara inställningar till kameran

Det är viktigt att spara inställningarna till kameran. Om detta inte görs kommer allt du har konfigurerat att gå förlorat.

Se till att du anger Default Set Selector och Default Startup Set. Det finns olika användaruppsättningar att välja mellan och i teorin kan du ha olika inställningar sparade på varje uppsättning. Du kan till exempel välja “User Set 1” som standard och sedan klicka på User Set Save för att spara dina aktuella inställningar till den profilen.
