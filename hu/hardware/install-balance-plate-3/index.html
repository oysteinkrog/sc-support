Az Egyensúlyozó platform 3 telepítése és beállítása

Bevezetés

Ez a támogatási cikk leírja, hogyan lehet beállítani egy új Egyensúlyozó platform 3-at a Swing Catalyst használatához.

Követelmények

  • Szabad USB porttal rendelkező számítógép.

  • Swing Catalyst 7.1.8 vagy újabb verzió.

Telepítés

A telepítési részletekért kérjük, tekintse meg a cikk alján csatolt PDF dokumentumot.

Ez a cikk az Egyensúlyozó platform 3-ra és az Egyensúlyozó platform 3s-re vonatkozik.

Csak a platform helyszíni Kalibrálását szeretné elvégezni? Kattintson ide

Figyelmeztetés

Egyes problémák tapasztalhatók az AMD 300-as sorozatú chipkészletekkel (AMD Ryzen 1700 / 2700 sorozat) USB 1.1 eszközök esetén. Konkrétan az Egyensúlyozó platformnál, ahol csak másodpercenként 75 mintát kap ~145 minta helyett. Javasoljuk egy USB 2.0 hub használatát, amely lehetővé teszi, hogy az Egyensúlyozó platform teljes mintavételi sebességgel streameljen.

Az AMD 300-as sorozatú chipkészletek USB 3.0 eszközökkel való használatával kapcsolatban nem ismertek problémák.

Driver telepítése

  • Telepítse a Hosszú Ütőket a Windows Start Menüből – Swing Catalyst – Hosszú Ütők mappából. 64 bites Windows esetén futtassa a „Balance Plate #2 Driver Installer (x64)" programot. 32 bites Windows esetén futtassa a „Balance Plate #2 Driver Installer (x86)" programot. 32 bites vagy 64 bites Windows rendszerem van?

A Hosszú Ütőket a következő címen is megtalálhatja: https://www.swingcatalyst.com/drivers

A kalibrálási segédprogram futtatása

  • Kalibrálási segédprogram letöltése

  • Ha a rendszer a Hosszú Ütők telepítésére kéri, kattintson az Igen gombra.

  • Csatlakoztassa az Egyensúlyozó platformot a számítógéphez.

  • Nyissa meg az újonnan telepített SE Utility programot.

  • Válasszon ki egy kamerát vagy webkamerát, és irányítsa az Egyensúlyozó platformra.
