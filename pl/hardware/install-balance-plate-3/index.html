Jak zainstalować i skonfigurować Płytę Równowagi 3

Wprowadzenie

Ten artykuł pomocy technicznej opisuje, jak skonfigurować nową Płytę Równowagi 3 do użytku z Swing Catalyst.

Wymagania

  • Komputer z wolnym portem USB.

  • Swing Catalyst 7.1.8 lub nowszy.

Instalacja

Szczegółowe informacje dotyczące instalacji znajdują się w załączonym PDF na dole artykułu.

Ten artykuł dotyczy Płyty Równowagi 3 oraz Płyty Równowagi 3s.

Chcesz jedynie przeprowadzić kalibrację polową swojej płyty? Kliknij tutaj

Ostrzeżenie

Zaobserwowano pewne problemy z chipsetami AMD 300-Series (AMD Ryzen 1700 / 2700 series) w połączeniu z urządzeniami USB 1.1. Dotyczy to w szczególności Płyty Równowagi, gdzie uzyskuje się jedynie 75 próbek na sekundę zamiast ~145 próbek na sekundę. Zalecamy używanie koncentratora USB 2.0, który umożliwi Płycie Równowagi przesyłanie danych z pełną częstotliwością próbkowania.

Nie są znane żadne problemy związane z używaniem chipsetów AMD 300 series z urządzeniami USB 3.0.

Instalacja Drajwerów

  • Zainstaluj drajwery z menu Start systemu Windows — Swing Catalyst — folder Drivers. W przypadku 64-bitowego systemu Windows uruchom „Balance Plate #2 Driver Installer (x64)" W przypadku 32-bitowego systemu Windows uruchom „Balance Plate #2 Driver Installer (x86)" Czy mam 32-bitowy czy 64-bitowy system Windows?

Drajwery można również znaleźć na stronie https://www.swingcatalyst.com/drivers

Uruchamianie narzędzia do kalibracji

  • Pobierz narzędzie do kalibracji

  • Jeśli zostaniesz poproszony(-a) o zainstalowanie drajwerów, kliknij tak.

  • Podłącz Płytę Równowagi do komputera.

  • Otwórz nowo zainstalowane narzędzie SE Utility.

  • Wybierz kamerę lub kinkiet internetowy i skieruj ją na Płytę Równowagi.
