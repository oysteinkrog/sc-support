Jak skonfigurować wiele wyświetlaczy za pomocą Swing Catalyst

Jak skonfigurować wiele wyświetlaczy

Ten artykuł pomocy obejmuje ustawienie i konfigurację wielu wyświetlaczy w systemie Windows. Konfiguracja ekranu informacji zwrotnej w Swing Catalyst oraz użycie scenariuszy z wieloma wyświetlaczami w Swing Catalyst, a także pokazanie, jak nawigować i przesuwać okna z więcej niż jednym monitorem.

Jak skonfigurować wiele wyświetlaczy w systemie Windows:

  1. Upewnij się, że twój komputer ma możliwość podłączenia do wielu wyświetlaczy. Niektóre komputery lub laptopy mają ograniczenia, takie jak maksymalnie 2 wyświetlacze.

W przypadku ustawień z więcej niż dwoma wyświetlaczami musisz posiadać kartę graficzną zdolną do liczby wyjść, której potrzebujesz, lub alternatywnie, jeśli chcesz po prostu dublować wyświetlacz, można to zrobić za pomocą splitterów HDMI (więcej na ten temat poniżej).

  1. Sprawdź, czy masz potrzebne kable do podłączenia do wyświetlacza. Najpopularniejsze typy połączeń dzisiaj to: HDMI, DVI lub Display Port. Ten ostatni często wymaga adaptera. Większość komputerów dzisiaj ma port HDMI, jednak niektóre laptopy mają HDMI mini lub display port.

Ważne jest zanotowanie portu, do którego się podłączasz, abyś miał odpowiedni adapter, jeśli będzie potrzebny.

  1. Podłącz monitor do komputera i kliknij prawym przyciskiem myszy na pulpicie, a następnie wybierz Ustawienia wyświetlacza.

If the display has been successfully detected it should show more than one display.

To set your display as the main display, check the “Make this my main display” box.

Note: You may want to set your main display to display 1 (i.e the first output on the graphics card).

If you wish to extend the desktop to your secondary display select the option under Multiple displays.

Please note that if the display you’re connecting to has a higher or lower resolution the image might be slightly different. The DPI also might be different causing the text to be larger or smaller than what you might be used to. Use the recommended resolution where possible.

Now that we have more than one display set up in Windows, make sure you have the orientation right (i.e that the monitor on the right is to your right). Having this sorted helps a lot in navigating; especially if it’s more than two displays.

Note: Windows 7 has a different configuration for displays, but the overall process is the same.
